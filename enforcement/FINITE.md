# Finite causal synthesis and the delayed peer-brake instance

Status: derived finite-model theorems with exhaustive executable checking and independent mathematical/semantic audit. This artifact supports E1, E3, E4 and E5 of [ENFORCEMENT-CONTRACT](../ENFORCEMENT-CONTRACT.md), and gives a finite integer realization of the peer-brake mechanism. The independent review and its limits are recorded in AUDIT.md. Repository acceptance and physical validation are unclaimed. The companion [finite_model.py](finite_model.py) generates [finite_results.json](finite_results.json); the JSON is reproducible evidence, not a second authoritative statement of the theory.

## Finite causal interface

Fix finite actors I, a finite family F of static joint component faults, finite physical states X, finite local observation alphabets O_i and command alphabets U_i. A single f determines the compliant policy executors C(f) and the sensor, link, actuator and enforcement faults. Those projections do not assert independent failure budgets. For each f, initialization is a nonempty relation between physical states and actual local initial inputs j_i.

A round first generates local observations, then executes the compliant local programs, then chooses faulty issued commands and independent physical actuator effects, then updates physical state and mission monitors. The implemented subclass allows the adversary to respond to the current compliant commands; it therefore has that explicit causal power. A simultaneous-command source model requires its own phase-preserving adapter. Faulty-issued commands are included in the queues and effects, not deleted because the issuer is faulty. An actuator fault can realize an effect different from its planner's command.

A local table has initialization mu_i:J_i->M_i, output lambda_i:M_i x O_i->U_i and update delta_i:M_i x O_i->M_i. Its only arguments are its memory and its own observation. The checker knows f; the table does not. Equal local invocation histories therefore produce equal local memories and commands, by induction. A missing invocation is represented by None, which leaves local memory unchanged and issues no new command; it is not an observable global clock tick. The peer-brake instance makes a stronger, explicit scheduling assumption: every compliant planner is invoked once per physical tick. Its delays are physical command/sample queues, and it does not cover arbitrary missed invocations.

Physical state retains everything needed for future effects and judgments: capability modes, pending commands, sample history and physical resources. General mission-history monitors can be included in that state; they must have actual update functions. World-level safety and rights apply to all effects. Response admissibility applies to issued commands of C(f), including their joint consequences. A compliant planner's independently faulty actuator remains adversarial at the physical interface.

The generic checker advances actual-service ages on every physical tick, resets them only on a delivered service event, and rejects an age reaching its deadline. Initialization may specify nonzero ages; None means fresh age zero for every obligation. An initial age outside the declared deadline is rejected. Recurring-service checking additionally rejects every reachable cycle with no delivery, including cycles that have outgoing edges; checking only bottom components would be unsound. A rank strictly decreasing on every delivery-free edge is computed when that subgraph is acyclic.

An empty initial family fails. An empty observation or effect iterator fails as a missing continuation. If one admitted primitive choice has no outcome while other choices do, the kernel must emit an explicit violation for that choice; silently omitting it from an iterator is not a faithful encoding. The API cannot infer transitions that its caller leaves out. Maximal finite runs and deadlocks lose in the perpetual-service subclass. One may equivalently complete these failures with an absorbing losing state; the implementation reports the finite failure directly.

### Exact fixed-memory theorem

For fixed positive finite memory bounds, finite causal kernels, finite history monitors, bounded-service counters and optional recurring-service obligations, exhaustive local-table synthesis terminates and is sound and complete for deterministic programs at those bounds.

Proof. Fix tables before selecting f. The exploration vertex is (f,x,m_1,...,m_n,ages), and f never changes along an edge. Every admitted observation tuple is considered, each compliant command is obtained from its own table, and every admitted faulty command/effect is enumerated. Induction over these phases gives correspondence with the declared causal executions and the same local histories. A missing continuation gives precisely the losing terminal verdict. Reachability checks therefore characterize all safety and bounded-deadline violations. In a finite graph, an infinite suffix without a delivery exists exactly when a reachable delivery-free cycle exists, which the rank procedure decides.

There are finitely many local tables. For memory size m_i, observation count o_i, command count u_i and initial-input count j_i, the number is m_i^j_i (u_i m_i)^(m_i o_i). Enumerating their Cartesian product and checking each exhausts every deterministic bounded implementation. A smaller implementation can be padded with unused states. The checker terminates on the promised finite, complete kernel. These facts give soundness, completeness and termination. They do not establish practical efficiency. QED.

The reusable enumeration function supports arbitrary positive memory bounds. The executable peer-brake synthesis specializes it to one state per planner, two observations and two commands, giving 4^3=64 local table families. A negative bounded result excludes only that class unless a separate impossibility argument is supplied. Increasing memory bounds is a positive semiprocedure, not a general unrealizability decision procedure.

## Integer peer-brake realization

There are three independently controlled brake modules protecting one target motor. The state is integer speed x, integer heat h, a queue of three-bit issued-command vectors and, in stale-observation comparisons, a sample-history queue. A joint fault selects whether the target motor/output mechanism is faulty, which brake planners are faulty and which brake actuators are faulty. The union of affected planner/actuator brake identities has size at most one. Planner and actuator failure are separate: a correctly executing planner can command a malicious actuator, while a faulty planner can command an otherwise functioning actuator. There are twenty reduced fault classes.

The ordinary motor has actual input u=4; a faulty motor independently chooses any integer u in 0,...,6 each tick. Each normal actuator realizes its queued command after one tick; each faulty actuator independently chooses its current engagement in {0,1}. Let E be the sum of the three actual engagements. For the main integer instance,

\[
x'=\max\{0,\lfloor(5x+10u-10E)/10\rfloor\},\qquad
h'=\lfloor(5h+Ex)/10\rfloor.
\]

The operating envelope supplies normal drive input four and the passive heat-loss term indefinitely; it does not assert a finite unmodeled fuel store. Loss of a target's drive/output function is admitted through that target's faulty mode, subject to the stated global budget. An additional shared energy outage or finite consumable reserve would require a new state/fault interface and could invalidate sustained service. The lower truncation represents the stipulated nonnegative-speed dynamics, not an upper safety gate. Unsafe upper values are retained. Removing braking leaves the faulty motor's independently chosen input and ordinary motor service active.

Initialization has all queued commands OFF, h in 0,...,6, and x in 1,...,4 for a normal motor or 0,...,4 for a faulty motor. The world-level conditions are x<=10 and h<=6, regardless of the actuator or planner responsible. A normal motor additionally has x>=1 and delivers actual quantity x' every tick. A faulty output mechanism may withhold its output even while the motor moves. Service is not assumed for that target; positive aggregate service follows only after composition with at least one normal motor.

Faulty delivered quantities are represented by the endpoints 0 and x'. Intermediate nonnegative quantities do not affect any policy observation, future physical state, thermal or response monitor in this model. In a composed winning family the required aggregate floor is already met by normal motors alone, so intermediate faulty output does not change that verdict either. This quotient is specific to these consumers; exact quantitative faulty-output requirements would require restoring the intermediate values.

### Sensor-fault adapter and independent conduct rule

Each planner has its own three-source observation group. At most one source in each group may report an arbitrary integer; the other two readings lie in [x-1,x+1]. Each source identity is permitted to be faulty in the source fault family, even when its planner is correct. A median remains in [x-1,x+1]: two values in that interval prevent its middle order statistic from lying outside. This argument covers arbitrary corrupt values, not just the finite examples checked by the script.

The planner observes only whether its median is below threshold q=3 or at least q. Thus the exact integer label relation is

\[
\text{low is possible iff }x\le3,\qquad
\text{high is possible iff }x\ge2.
\]

Both labels are possible at x=2 and x=3, independently for distinct groups in the declared source/noise envelope. Every allowed label can be realized by all three truthful readings at a suitable endpoint; arbitrary sensor corruption identities therefore introduce no additional label traces. The fault map erases these source identities while preserving planner compliance. The twenty-class checker does not assume those sources are correct or their identities known. If shared sources impose additional correlations, this relation remains a sound overapproximation but reverse correspondence and completeness require rechecking.

Finite synthesis completeness is relative to the declared LOW/HIGH interface and its fixed local observation front end, not to every memoryless policy that could inspect the raw reports or distinguish their source-specific values. For three readings, median>=q iff at least two individual readings are >=q. A bounded implementation can therefore threshold each report and take a three-bit majority inside the same faultable planner; this is not an exempt filter or enforcement gate. An explicit fixed-width variant has each faultable source path deliver its threshold bit, with the intact-bit condition inherited from the stated reading/error relation. A faulty path may supply either bit. Neither variant claims a bounded-latency parser for arbitrary-length malicious numerals. The many-to-one raw-to-label map preserves the outcomes of the selected front-end policy and supplies a sound observation adapter. Equality of available label traces alone does not reflect every raw-report strategy back into the label-table search space. The 64-table completeness and four-winner characterization retain that interface index.

The conduct rule is separately fixed at r=2: a compliant planner may issue ON only when the actual target speed at that invocation is at least two. This is not a constraint on the physical effect relation. It is evaluated against current invocation state, not a delayed observation's historical sample or the later actuation state. In the positive context, observation age is zero, so high certifies that current speed is at least two and low->OFF, high->ON is admissible. A delayed previously justified command may take effect after current speed has fallen below two; the reachable graph exhibits this case. In stale-observation comparisons the same current-state rule remains fixed: an old high reading can fail to justify a newly issued command after deceleration. Always-ON remains physically viable under the base force margins but violates conduct at an admitted low initial speed; information matters through admissibility, not solely through mechanical braking.

For integer inputs and engagements, the speed identity follows from max(0,floor z)=floor(max(0,z)); the heat identity is immediate. The finite input and engagement alphabets are admitted subsets of the real-valued capability envelopes; this inclusion does not assert completeness for every real-valued policy/input context.

This is a concrete mathematical adapter to the parameter theorem and the inspected Lean stream hypotheses, not a machine-checked compiler from Python executions into Lean proof objects. ### Carrier bound and positive induction

The finite carrier is derived before checking safety: with u<=6 and nonnegative counterforce, x<=12 implies x'<=12. Initialization lies in this carrier. Since E<=3, x<=12 and h<=8 imply h'<=floor((40+36)/10)=7<=8. The code uses speed cap 12 and heat cap 8 and asserts their preservation; it never clips x to the safety bound ten or h to the rights bound six. Parameter comparisons recompute the physical carrier from their admitted maximum effects.

For the all-threshold policy and one-tick delay, speed is in fact at most nine. The first successor is at most eight. Thereafter, if the previous sample x_(t-1)>=4, every correct planner must have observed high and at least two planner/actuator pairs implement ON at t, so E_t>=2. If x_t<=9, the next speed is then at most floor(4.5+6-2)=8. Otherwise x_(t-1)<=3, which implies x_t<=7 and x_(t+1)<=floor(3.5+6)=9. This proves x<=9 by induction.

For a normal motor, x>=1 and E<=3 imply x'>=floor(0.5+4-3)=1. Hence actual output is positive every tick and the normal motor's deadline-one monitor always resets. Heat satisfies h'<=floor((30+27)/10)=5 whenever h<=6 and x<=9, preserving h<=6 from initialization. ON commands satisfy the independent conduct rule by the label implication. Faulty planners and actuators remain fully represented in these inequalities. These inductions prove the unbounded-run guarantee without assuming the computed winning set.

A material integer parameter family replaces the force term 10E by kE for integer 1<=k<=10 while retaining the stated heat-conversion law. This varies mechanical effectiveness while holding the modeled thermal cost of engagement fixed; it is a declared discrete model variation, not a claim of physical calibration. The same policy gives x<=10: if the previous sample is at least four, E>=2 and floor((50+60-2k)/10)<=10; otherwise the next speed is at most nine. The normal-motor floor still follows from k<=10, and x<=10, E<=3 preserve h<=6. The endpoints and comparisons in the JSON supplement this algebraic argument. In particular k=2 still wins. Rounding changes the insufficient-force boundary relative to an unrounded recurrence; that successful comparison must not be reported as an obstruction.

For memoryless binary tables, the exact winning families have every low output OFF and at least two high outputs ON. A low ON is refuted by an initially normal motor at x=1 with no brake faults. With at least two high ON outputs, at least one such planner/actuator pair remains effective, and the preceding induction with E>=1 gives x<=10. With at most one high ON output, corrupting that actuator to remain OFF leaves every actual brake OFF; faulty input six produces 0,6,9,10,11. The executable search independently enumerates all 64 families and obtains precisely those four winners.

## Composition with actual positive aggregate service

The product wrapper models M independent physical devices with separate heat stores. A single global f is a tuple of local fault projections, with at most p<M faulty target motors and at most one affected planner/actuator brake identity in each projection. Arbitrary ownership or failure correlations may restrict this family; no probability factorization is assumed. Sharing an actuator's finite force budget across targets would violate this product interface and needs another compatibility proof.

Each actor observes only its own target's label and issues only its target's command. The wrapper's global state is the tuple of physical states; global effects are tuples of admitted local effects under the same f. Its actual delivered quantity is the sum of actual component deliveries and its aggregate heat is the sum of the separate physical heat stores. No pooled state or global gate is exposed to a local table.

For each local f_j let R_(f_j) be the closed reachable set checked under the all-threshold policy. Define the global certificate as the union, over admitted global f, of the Cartesian products of these sets. Every admitted global initial state lies in it. Every global transition projects to a checked local transition, so closure follows coordinatewise. Fault correlations cannot invalidate the proof because each actual projection is still covered.

Each normal target delivers at least one on every transition; faulty deliveries are nonnegative. Therefore actual aggregate delivery is at least M-p>0 per tick on the very executions whose physical safety is proved. Also sum h_j<=6M. This is a sum of separate thermal stores with capacity 6M, not a newly assumed shared cooling process. A single shared heat dynamics or smaller shared capacity needs its own invariant.

The JSON constructs this certificate for M=2,p=1 from the local closed-set counts, checks every permitted joint fault projection, and exercises every effect profile at a declared initial boundary state. It records the Cartesian certificate's state-count upper bound. It does not claim to enumerate the full global graph. The general product theorem, not those boundary samples, establishes all M>=2 and p<M.

## Comparisons and obstructions

The result file records actual transitions and first violating prefixes, with no normative filtering. Removing the brake channel loses against a faulty motor, while ordinary motor input four continues to deliver positive service without brakes. The removed channel therefore has an attack-prevention burden distinct from routine operation.

Three-tick actuation delay is an all-policy obstruction for the stated initialization: from x=4, initial OFF queues and faulty input six, the first three speeds are 8,10,11 before any newly issued command can act. Two-tick observation age with one-tick actuation delay also has an all-admissible-policy obstruction while preserving the current-invocation conduct rule. Fix the same fault scenario in two worlds: the target motor/output chain is faulty, every brake planner and actuator is correct, and source reports are truthful. Both initialize at x=0 with sample history (0,0), OFF command queues and identical private inputs. In the quiet world, input remains zero. Any universally admissible deterministic policy must issue OFF at every invocation there because actual current speed stays zero. In the accelerating world choose inputs 4,6,6,6. Through invocations t=0,1,2, all received samples are still zero; choose the same permitted readings and hence the same low labels. Induction on local histories transfers the quiet world's OFF commands to the accelerating world, whose successive speeds are 4,8,10. At t=3 the first nonzero sample is four and a high label may finally distinguish the worlds, but the command applied at that tick is the previous OFF command. Every possible newly issued command therefore leads to x(4)=11 before it can act.

This argument covers the declared ON/OFF command and delayed local-reading interface; it does not silently suppress an additional inspection, communication or sensing action. Both worlds use the same permitted observation delay, source envelope and invocation schedule. It is enough to exhibit these admitted matching readings against each candidate policy; universal correctness must cover them. The JSON separately replays the matched prefix and all eight possible last-round command profiles. Its ordinary threshold-policy search honestly records its first failure, which may instead be a current-conduct violation caused by an old high sample during deceleration. That first found failure is not substituted for the two-world all-policy proof. A separate reachable old-high/current-zero regression checks that the stale historical speed never authorizes a new command under the fixed mission.

For blind observations, even unbounded deterministic local memory cannot solve the unchanged mission. Fix the same all-compliant brake fault scenario and faulty target in two runs. In the first, x initially zero and motor input always zero; universal response admissibility forces all planners to remain OFF forever. In the second, initial observations and invocation histories are identical but motor input is six. Equal local histories force the same OFF commands, and speed reaches eleven. A policy issuing ON in the first run already violates conduct. Thus the two-run argument refutes every deterministic blind policy, not merely the eight tables checked at memory bound one.

The exact-information capability comparison admits all three actuators as faulty and OFF. Then perfect current measurements cannot make any issued command influence speed; faulty input six again leaves the safety set. This changes the fault envelope visibly. Zero force is also checked while retaining engagement's thermal effect. Neither comparison is presented as a failure inside the positive one-fault force envelope.

The overpowered-enforcer comparison admits one faulty actuator with engagement up to ten. From the admitted bad-motor initial state x=4,h=6, engagement ten produces h'=7 and a true world-rights violation. The physical transition remains present even though the actuator is faulty. The same wider envelope can suppress normal actual service. This is an out-of-envelope sensitivity witness, not a tolerated base attack.

Prohibiting every correct ON command leaves the physical ON action available but makes it inadmissible. With no brake faults, every admissible policy then keeps the brake effect zero and the faulty motor wins. The finite synthesis rejects every table; the direct effect argument gives the broader impossibility. This is separate from changing physical capability.

A naive product proof can fail even without faults. Two independently legal unit diversions into a shared basin of capacity one produce level two. Each isolated model accepts its own action, but the safe joint relation {(0,0),(1,0),(0,1)} is not the product of its projections. The product wrapper above excludes that coupling explicitly; it cannot be reused for a shared basin by relabeling its coordinates.

## Refinement and implementation preservation

A sound source adapter supplies one whole-run fault map, initial-state coverage, local prefix-preserving observation encoders, local action realizations and a phase-preserving alternating simulation. For every concrete pre-outcome, there must be a related abstract observation tuple simultaneously; after the locally realized compliant commands, every concrete independent effect must have a related abstract outcome. State relations retain queues, resources and capabilities required for continued matching. Abstract service cannot count a delivery absent concretely; concrete forbidden outcomes and terminal failures cannot map to successful abstract runs. Deadline preservation also requires a stated time correspondence.

The realized policy is pi_i^C(h)=L_i(h,pi_i^A(E_i(h))). Its arguments remain local. Proof witnesses may depend on global state or f, but E_i and L_i cannot. Phase induction constructs a related abstract path for every concrete run; mission reflection then transports winning. A pointwise existence of an appropriate concrete action at every hidden state does not suffice: an action lift must be uniform across the actor's indistinguishable histories.

The sensor-fault quotient above is an instantiated observation/fault adapter. The product theorem is an instantiated assembly law for separate physical devices. Continuous hardware behavior, shared physical budgets and unmodeled sample/command timing are not discharged by either. A finite-state observation encoder can also enlarge realized local memory; fixed-memory completeness transfers only with a strategy-reflection and memory-accounting argument, not from forward simulation alone.
