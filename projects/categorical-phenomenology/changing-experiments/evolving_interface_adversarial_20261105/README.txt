Adversarial audit of changing experimental interfaces and composition
Completed 2026-11-05. This directory is ready for the final source ZIP.

Files:
- audit_report.md: source-ready mathematical report with proofs, finite witnesses,
  exact scope, and references to the restored prior manuscripts.
- finite_checks.py: standalone executable checks using Python standard library.
- finite_check_results.json: structured results from a successful run.
- check_run.txt: human-readable successful execution log.

Key findings: mixed evidence-restriction/test-forgetting square is generally
lax, with an explicit nonempty supported 3-object strict witness; row-realizing
evidence gives a sufficient exact class. Disjunction-closed Boolean witness
tests make the object Dowker nerve a full simplex on live objects. Cyclic
pairwise lifting can fail; surjective edge projections on a tree give an
existence theorem. Native/resource realization remains a separate obligation.
