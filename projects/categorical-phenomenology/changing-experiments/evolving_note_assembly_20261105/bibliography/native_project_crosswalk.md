**Comparison to the current proposal.** Guitart exactness of an allocation-category square can prove a Set-valued Kan comparison. It is not automatically the O1 Beck–Chevalley mate on the actual contentad, and an equivalence of allocation posets is not an equivalence of the relative module categories. To claim a bridge, construct the relevant allocation-to-O1 realization, specify how endpoint squares and native cells map, and prove its compatibility with occurrence accumulation. A budget trichotomy is useful as a transparent restricted example; it does not strengthen O1's native general theorem merely by using the word “witness.”

## Earlier FCA/Dowker adequacy theorem is especially close

Source: `file_recovery_audit_20261105/recovered_deliverables/contextual_reduction_wiring.tex`, lines 1955–2145.

For a realized inclusion L⊆Z with the same labelled tests E, Theorem `v:thm:three` proves:

1. Equality of behavioral row quotients exactly when every ambient row is realized in L.
2. The canonical closed-extent restriction Ext(Z)→Ext(L) is an isomorphism exactly when every ambient row is an intersection of realized rows (equivalently equal intent closure systems).
3. Under (2), supported concept cores are isomorphic exactly when existence of a universal row r(z)=E is preserved. This support flag is not recoverable from the unmarked lattice alone.
4. Row domination gives an actual simplicial inclusion with a contiguous retraction, hence homotopy equivalence of object Dowker complexes. This condition is sufficient, not asserted necessary.

Proposition `v:prop:domains` then transports this comparison through typed Chu operations on their exact supported domains and preserves the domain-of-composition identity. The finite counterexamples later in the file separate row, lattice, support and topology.

**Comparison.** A new mixed-variance theorem should cite this inherited adequacy result and explain what changes when BOTH object carriers and test repertoires move. Merely restating one of these inclusion tests or the need to retain support is not a new contribution. For adding tests on a fixed carrier, the canonical state/concept coarsening arrow and the positive-witness Dowker inclusion have opposite directions, as recorded in report.md §3.
