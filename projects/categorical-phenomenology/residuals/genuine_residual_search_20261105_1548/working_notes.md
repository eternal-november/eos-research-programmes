## Immediate exclusion tests

1. If each new instrument/primitive has a uniform old-runtime implementation, closure under all old programs already includes its finite experiments. A new *installed* capability or cheaper availability can still be real, but it is not global semantic expressivity growth.
2. If arbitrary genuinely new tests may be adjoined, no present nonidentity quotient is guaranteed stable under every extension: adjoin a test separating any identified pair. This is an elementary underdetermination fact, not a new categorical theorem.
3. If operations available from tests are generated monotonically, an alternating closure is ordinary monotone fixed-point theory. If manufacture consumes capabilities, a transition system/state-threaded semantics is needed instead of a closure operator; this source already supplies it.
4. A new category/fibration collecting evidence, resources and witnesses is not by itself an unexplained mathematical fact. Need a theorem or actual obstruction surviving known reductions.
