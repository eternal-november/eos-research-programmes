# What survives the residual search?

5 November 2026, 16:05 UTC. This is a focused research assessment, not an exhaustive historical-priority audit.

## Verdict

I did not find a justified original residual in the higher-order co-evolution proposal. It is not enough to say that devices create probes, probes change models, and models select new devices. The project's adaptive manuscript already implements that loop with residual beliefs and native resource accounting. Several outside theories are closer than the original map makes apparent: data informativity, generative-state logical relations, sequential uniformization, and categorical computable reducibility.

There is a defensible *new task to investigate*, grounded in the actual two-cell latch, but its originality remains unestablished: a completeness theorem for native experimental certification and synthesis of robust reusable interfaces from unknown components. This must be posed as a test of the programme, not announced as its discovered new principle.

## 1. Exact object for the co-evolution candidate

Use the adaptive manuscript's fixed source class M, with states s=(theta,q), where q includes devices, residual stock, physical state, controller memory and records. At visible history h, B_h is the set of compatible actual residual states, not just a set of laws with fresh stock. Native commands have witnessed outcome relations E_a(s) subset O_a x S x W. A command is usable only when safe on every member of B_h.

For a named mathematical interface I (for example a reusable Boolean bit, a specified finite transducer, or an operation on a marked concept lattice), define T_I subset S to be configurations carrying an independently checkable realization certificate for I. A policy's success is that every leaf belief B_h is contained in T_I, retaining actual execution witnesses. Its cost is the worst branch resource expenditure, with vector resources retained when needed.

The resulting formation value is

  V_I(B) = inf over observation-uniform safe native policies pi of their worst cost,

where every leaf is certified for I. Infinity means no such policy. This is the appropriate exact quantity; it distinguishes existence in each hidden world from one warranted construction.

It is not, by this definition alone, a new invariant. For the source's finite deterministic specialization it is exactly the value of its already supplied belief-state reachability game. Adding “the current test language” or “the current characterization” to the state does not defeat that reduction. If there are finitely many effective primitive transitions, the whole co-evolution is absorbed.

## 2. The two easy boundaries are not residuals

### Uniformly implemented creation

If a newly exposed operation has a uniform native implementation in the original runtime, every finite experiment using it compiles to an original program. This is the source's whole-runtime boundary. Installed availability, costs and resource depletion still change, but new labels do not produce an unexplained increase in total semantics. Higher-order languages and generative abstract types make the same distinction between new runtime objects and new metalanguage powers.

### Unrestricted external novelty

If one may adjoin an arbitrary new observation on the old carrier X, no nonidentity observational quotient can be certified stable under all such extensions. For q(x)=q(y), x not equal y, adjoin a Boolean column containing x and not y. The pair is separated. Likewise a finite run cannot certify future time-invariance against an extension that agrees throughout the observed interval and changes later. These are elementary underdetermination arguments, not new impossibility theorems.

Thus the promising middle needs an explicitly restricted and independently justified class of *native* extensions. Without it, “unforeseen” either means already implementable or imposes no mathematical constraints.

## 3. Closest explanations, with precise scope

- **Generative state:** Ahmed–Dreyer–Rossberg's *State-dependent representation independence* handles abstract data representations depending on mutable state. Neis–Dreyer–Rossberg's *Non-Parametric Parametricity* handles dynamically generated type names using growing Kripke worlds. These do not prove empirical discovery guarantees, but they refute the suggestion that changing state, representation and available interfaces is itself beyond existing semantics. https://www.khoury.northeastern.edu/home/amal/papers/sdri.pdf and https://people.mpi-sws.org/~rossberg/papers/Neis%2C%20Dreyer%2C%20Rossberg%20-%20Non-Parametric%20Parametricity.pdf

- **Action discovery:** Halpern–Rong–Saxena, *MDPs with Unawareness*, UAI 2010, characterize learning near-optimal behavior when actions must first be discovered under an explicit discovery model. They do not eliminate the need to specify that model. https://proceedings.mlr.press/r8/halpern10a.html

- **Optimal online witnesses:** Winter, *Uniformization Problems for Synchronizations of Automatic Relations on Words*, ICALP 2018, studies sequential uniformizers with constrained synchronization. Boker–Lehtinen, *History Determinism vs. Good for Gameness in Quantitative Automata*, FSTTCS 2021, separate optimal online resolution from game-compositional properties. Therefore pointwise exactness not supplying one finite-state optimal compiler is a known phenomenon; an additional endpoint/resource obligation needs a demonstrated nontrivial effect. https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ICALP.2018.142 and https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.FSTTCS.2021.38

- **Warrant without identification:** van Waarde–Eising–Trentelman–Camlibel's *Data informativity* asks when data justify a property of every compatible model or supply one controller valid for all of them, sometimes when the model is not identifiable. This is directly relevant to four-probe certification of the latch. It does not automatically solve the endogenous manufacture and residual-stock problem, but the finite source's belief game already supplies that part. https://arxiv.org/abs/1908.00468

- **Universal properties of realizability:** Trotta–Valenti–de Paiva, *Categorifying Computable Reducibilities*, LMCS 2025, characterize reducibility doctrines by quantifier completion and relate extended Weihrauch to Dialectica. Brattka–Pauly 2018 develop the sequential/parallel algebra and failures of distributivity of Weihrauch degrees. Physical linearity is a possible mismatch, but it requires comparison with linear realizability/effectful semantics, not just appending a resource word. https://lmcs.episciences.org/15226/pdf and https://arxiv.org/abs/1604.08348

- **Resources and epistemic update:** Baltag–Coecke–Sadrzadeh's quantale/module semantics already combines epistemic update and resource-sensitive action composition. It does not settle every manufacturing model, but there is no unoccupied generic “knowledge plus resources” gap. https://eprints.soton.ac.uk/262824/1/JLC2.pdf

## 4. A concrete research test using the existing latch

Keep exactly the source's leaky cells:

  dx_i/dt = -x_i + phi_i(u_i) + eta_i,

with unknown time-independent nondecreasing Lipschitz phi_i, |phi_i| <= 1, bounded disturbance, finite-error reads, native clamps and links, and actual post-probe states. Do not invent an external separating gadget. Reserve final-device stock as the manuscript does. The existing four-probe theorem is sound but sufficient only and may return inconclusive.

Ask for a necessary-and-sufficient theorem for *finite native certifiability of a reusable interface*, including which probes and links are physically available and what resources they leave. For the binary-memory instance, distinguish:

1. Every compatible plant has some robust latch implementation.
2. One fixed implemented latch and write/read protocol works for every compatible plant.
3. One observation-uniform native probing/manufacturing policy reaches a warranted implementation from the present stock for every compatible plant.

The source proves a sufficient route to (3), not a general exact characterization. The proposed object is the correspondence from compatible plant/residual state to its native positive-margin memory realizations. The obstruction is failure to select, by accessible experiments, a common compatible native realization before resource loss. It should be measured by a proved lower bound on V_I(B), not by naming the correspondence.

### What would count as a substantial theorem

A finite, native and robustly complete synthesis procedure for a nontrivial class of unknown component networks: if a positive-margin implementation of a prescribed finite-state interface can be warranted from available resources, the procedure finds it and produces a checkable certificate from those actual residual components; otherwise it provides a complete obstruction. It must identify the exact boundary where no such finite certification is possible and prove preservation under subsequent allowed manufacture/wiring.

The hypotheses cannot simply assume the desired certificate. They need a source class with effective compactness/regularity or another proved finiteness condition, explicit finite encodings, and an independently warranted error model.

### Decisive tests and reasons to abandon

- First solve the unchanged two-cell example with arbitrary admissible transfer functions. If the answer is only monotone lower/upper envelopes plus standard invariant rectangles, the proposed residual has collapsed into existing data-driven robust control. Retain any useful specialized theorem, drop the foundational claim.
- Then allow actual native finite networks and alternative robust memory realizations, not just the preselected rectangle. Establish necessity, not merely soundness of a chosen barrier template.
- Compare the resulting completeness theorem to data informativity, robust abstraction-based synthesis and safe experimental design. An unexplained word “manufacture” is not enough; show what standard translation fails to preserve (stock, timing, hidden-state uniformity, or the available observation alphabet) and prove it matters.
- If a finite belief-game encoding preserves every such obligation, acknowledge that the generic problem is already described. Originality would then have to lie in a new structural theorem or tractable class within that familiar problem.

## 5. Recommended conclusion to parent

The useful outcome of this search is a better falsifiable test and a closer prior-art map, not an endorsed new foundation. No new mathematical fact has yet been exposed that the imported theories fail to explain. The continuous native-certification problem is worth testing because the present source gives an actual construction and an explicit sufficiency/completeness gap. It is not yet justified as the major original next target. Keeping that null conclusion live is mathematically necessary.
