# Do the four distinctions yield an unexplained interaction?

Research checkpoint, 5 November 2026. Scope: explicit finite witnesses and targeted primary-source comparisons, not an exhaustive priority search.

## Finding

The interactions do produce real failures of interchange. Two are established below, with native programs, resources, and a declared warrant condition. Neither presently supplies a new unexplained constraint. One is the loss of consumable-use information when native tests become extensional predicates. The other is the loss of a common executable witness when existence is asserted separately in each possible world. Linear/resource semantics and uniform-strategy semantics respectively explain these mechanisms; published work already combines resources, knowledge change and executable strategies.

The negative finding is stronger than “the ingredients have precedents” but weaker than “nothing original is possible.” It identifies the actual mechanisms in these witnesses and locates close joint theories. It does not show every physically grounded native problem can be encoded in one existing framework with useful algorithms or a faithful compiler.

## 2. Minimal common model, without assuming a shared theory

Fix a nonempty finite set W of possible source worlds, actual configurations S with a world tag, a finite native command grammar P, state/resource transitions, and observable outputs. A specification φ is semantically defined on terminal configurations. A policy is chosen from visible history, not from the hidden world. Warrant here means: **under the declared source-model promise**, the policy terminates correctly in every compatible world and respects the resource bound along every run.

This is one explicit meaning of warrant. It is not an assertion that logical omniscience, a complete physical model, proof search, controller memory, or a certificate verifier is available for free. If warrant instead means derivability in a fixed proof calculus, that calculus and the cost/access contract must also be supplied.

For a one-step program p and budget r, let

    A_w(φ,r) = {p : p is native, achieves φ in w, and respects r in w}.

The analogous sets for complete policies must use the same syntactic observation-based policy in every world. This retains the four distinctions: φ may be defined; A_w may be empty for native reasons; a budget may remove witnesses; and nonempty individual sets may have no uniformly warranted member.

## 3. First order comparison: semantic conjunction versus bounded native composition

### Native experiment

The unknown sample contains two bits (x,y) in {0,1}². There are two installed measurements: read x or read y. Either returns that coordinate and destroys the entire specimen. There is no copying, recovery, hidden second specimen, or additional readout. Constants and ordinary Boolean processing of observed bits are allowed. Resource r is the number of supplied specimens prepared in the **same** unknown state. Correctness means the Boolean response is right for all four possible states.

Write N_r for response columns realized by native decision trees with at most r measurements per branch. At r=1:

    N_1 = {∅, X, [x=0], [x=1], [y=0], [y=1]}.

Each coordinate test is both native and warranted within one specimen. After forgetting native consumption, their semantic conjunction is

    [x=1] ∩ [y=1] = {(1,1)}.

It belongs to Meet(N_1), but not to N_1. Any native one-query tree either asks x and is constant on each x-fibre, asks y and is constant on each y-fibre, or asks nothing. The target singleton has neither property. This proves impossibility for the whole declared native class, not only a failed search.

Thus the two paths are different:

- Check each operand at resource one, forget the witnesses, then form semantic conjunction: the target column exists.
- Form an executable conjunctive experiment under **one shared specimen**, then evaluate: there is no target witness.

Both routes have nontrivial successful tests, so failure is not caused by an empty native class. Conjunction becomes executable at r=2 by measuring x and, if needed, y on the second same-state specimen. The counts are |N_0|=2, |N_1|=6, |Meet(N_1)|=10, |N_2|=16; the last count allows arbitrary Boolean processing, not just conjunction.

### Why this is not a mysterious commutator

These are different typed routes, not two endomorphisms on one unnamed space. Semantic ∧ is total; native bounded conjunction is partial because both operands can demand the same consumable input. With resource grades retained, composition has the sound type N_r × N_s → N_{r+s}, rather than N_r × N_r → N_r. The extra semantic route has silently supplied a contraction/diagonal unavailable in the native class. This is the familiar linear-resource explanation and precisely the hazard already flagged in the manuscript.

No claim is made that absence of copying always forbids conjunction. A less expressive target may require only one read, or native physics may provide another measurement. The lower bound uses the specified complete grammar.

## 4. Second order comparison: local existence versus one warranted implementation

There are two indistinguishable initial worlds θ=0,1. Native commands a_0 and a_1 each cost one, terminate, and install a device outputting the selected bit. The semantic task is to install the correct θ. Both commands are executable in both worlds; one succeeds and the other fails. Before diagnosis, the agent receives the same observations in both worlds.

At budget one,

    ∀θ ∃p [p achieves the target in θ within budget]       is true,
    ∃p ∀θ [p achieves the target in θ within budget]       is false.

Equivalently, A_0={a_0}, A_1={a_1}; both are nonempty and their intersection is empty. Randomization cannot guarantee correctness in both worlds because its support must obey the same restriction.

These are the orderings “existentially forget native witnesses, then close under compatible worlds” and “retain one native witness valid across compatible worlds, then existentially forget.” The failure is not merely uncertainty about the existence of some device: both devices are installed capabilities, and only uniform selection is absent.

Now add a native diagnostic d that reveals θ at cost k≥1 and preserves the actuator stock. Then the observation-based policy

    run d; on output θ, execute a_θ

is warranted at cost k+1. This is optimal: a policy must either choose an actuator before information, which fails in one world, or pay k for the only informative command and one for the actuator. Pointwise optimum remains one while uniform optimum is k+1. Hence a perfectly ordinary interaction can have arbitrarily large resource premium.

If d also destroys the only stock required by either actuator, no amount of the scalar budget restores success. Information improves while native capability is lost. The exact posterior must retain the destroyed-stock configuration. Updating only the possible-world set and silently replenishing stock changes the task. This is why the recovered project theorem retains world/configuration correlations.

### Exact equality criterion and limitation

For a fixed nonempty belief B, the pointwise and uniform existence claims agree whenever either some A_w is empty or their total intersection is nonempty. When all pointwise witnesses exist, equality is exactly the common-witness condition. This criterion is correct but not an independent new explanation: it is the elementary ∀∃/∃∀ distinction underlying de re knowing-how and uniform strategies.

The minimum budget function

    β(B,φ) = inf {r : one native observation-based policy achieves φ from B within r}

is a useful invariant of a declared native/observation/resource contract. Its preservation under a faithful budget- and observation-preserving compiler is useful, but this is an optimal-control value function, not a newly established universal invariant of usable mathematics. It can be infinite; replacing it with unbounded feasibility destroys information.

## 5. A negative universality test: arbitrary higher-order incompatibility

The four distinctions by themselves impose no unexpected topology on common-witness feasibility. Let K be any nonempty finite simplicial complex on an ambient world set W. Introduce one unit-cost native terminal command p_F for every maximal face F. In world w, p_F produces a successful terminal state iff w∈F, and a failure state otherwise. All commands are deterministic and total; initial worlds are observationally indistinguishable. No diagnosis is provided.

A belief B has a uniformly warranted unit-cost command iff B⊆F for some facet F, which is equivalent to B∈K. Therefore **every finite simplicial complex** occurs as this feasibility complex. This construction is just the standard facet-incidence/Dowker representation in operational language, not a novelty claim.

In particular, take W=P={1,…,n} and make program p succeed at every world except w=p. Every proper subfamily of n worlds shares a successful program, yet all n worlds share none. Pairwise checks, or any fixed lower-order overlap check, cannot establish global warrant in this unrestricted native class. This is a hypergraph/constraint compatibility phenomenon already visible in the project's relation-based methods.

This gives a useful guard against premature unification: stronger global laws require stronger hypotheses on the actual native class. Merely naming four layers does not supply such hypotheses.

## 6. Targeted prior-art findings

### Resources and native realization

Dal Lago–Hofmann, **Quantitative Models and Implicit Complexity**, cs/0506079v3 (2005), later **Realizability Models and Implicit Complexity**, TCS (2011). Their resource-bounded realizers/resource monoids connect semantic interpretations to computational resource bounds. This is directly relevant to retaining cost in evidence, but time-complexity realizers are not automatically physical consumable-stock models or epistemic warranties. [Primary full text](https://arxiv.org/html/cs/0506079v3); [published article](https://www.sciencedirect.com/science/article/pii/S0304397510007164).

### Warrant, observation and resources already interact

Alechina–Dastani–Logan, **Verifying Existence of Resource-Bounded Coalition Uniform Strategies**, IJCAI 2016, pp. 24–29. Actions affect both the world and knowledge and consume/produce resources. Theorem 1 establishes decidable model checking for their coalition-uniform strategy classes and decidable indistinguishability. Knowledge is syntactic. This is a direct joint precedent, but its exact initial-state/coalition semantics must not be silently identified with the all-compatible-world single-policy criterion above. [Primary proceedings full text](https://ijcai.org/proceedings/2016/11).

Fervari–Herzig–Li–Wang, **Strategically knowing how**, IJCAI 2017, pp. 1031–1038. Its uniform executable strategy semantics directly addresses the distinction between knowing that some success exists and knowing how to ensure success. [Primary proceedings](https://ijcai.org/proceedings/2017/143).

Demri–Doyen–Fervari, **Knowing-How Reasoning with Budgets Recasted: Universal Reachability Problem on VASS**, RP 2025, pp. 140–155. Theorem 1 proves Ackermann-completeness of budgeted knowing-how model checking even for one resource. Section 3 reduces it to a synchronized all-runs word problem for complete labelled VASS. Thus even very high computational complexity arising from this interaction has a precise existing problem class. Their linear-word semantics is not arbitrary adaptive contingent planning. [Primary author PDF](https://cs.famaf.unc.edu.ar/~rfervari/files/papers/2025-rp.pdf); [DOI](https://doi.org/10.1007/978-3-032-09524-4_10).

### A published structural interaction, not just a vocabulary match

Van Ditmarsch–Galmiche–Gawek, **An Epistemic Separation Logic with Action Models**, JLLaI 32 (2023), 89–116, online 2022. Plain model restriction can remove the neutral resource, breaking the required resource monoid. Their state-to-resource models and covering action condition preserve the needed structure. Proposition 2 gives reduction axioms and Theorem 5 eliminates dynamic modalities. This is an actual interaction-induced structural constraint and its repair, already in print. Its resource semantics should not be mistaken for our native compiler. [Primary full text](https://doi.org/10.1007/s10849-022-09372-z).

### Fibrations and evidence-sensitive semantics

Cohen–Miquey–Tate, **Evidenced Frames: A Unifying Framework Broadening Realizability Models**, LICS 2021. Definition V.4 makes indexed entailment require one evidence e for all indices; Theorem V.5 constructs a tripos. Theorem V.13 gives biadjoint biequivalences between their evidenced-frame and Set-based-tripos categories, under the stated morphism and metatheoretic assumptions. Explicit evidence need not be functionally reconstructed by the inverse. This is a close prior universal property, not merely a use of category language. A finite native grammar without their conjunction/implication/evidence closure is not automatically an evidenced frame. [Primary PDF](https://www.lironcohenlab.com/pubs/LICS21-EF.pdf).

Liron Cohen's FSCD 2025 survey independently clarifies the higher-order-fibration viewpoint and effects such as state and nondeterminism. It is useful orientation rather than a replacement for the 2021 theorem. [Primary survey](https://doi.org/10.4230/LIPIcs.FSCD.2025.1).

### Existing repair/exactness mechanisms

Ranzato–Tapparo, **Strong Preservation as Completeness in Abstract Interpretation**, ESOP 2004; journal extension **Generalized Strong Preservation by Abstract Interpretation**, JLC 17(1) (2007), 157–197. Complete-shell refinement explains a least domain repair relative to declared semantic operators. [Opened primary PDF](https://www.math.unipd.it/~ranzato/papers/esop04.pdf); [journal DOI](https://doi.org/10.1093/logcom/exl035).

Batanin–Kock–Weber, **Regular patterns, substitudes, Feynman categories and operads**, TAC 33 (2018), Lemmas 2.2/2.4 and Theorem 2.11. The prior project audit verified the connected factorization criterion and its relation to convolution. This probe inspected that audit, not every source proof anew. [Primary PDF](https://webercat.au/rpfc.pdf).

## 7. Assessment of originality and next falsifiable question

- **Real phenomena:** bounded native composition can fail where semantic conjunction exists; pointwise realizability can fail to uniformize; gaining information can consume the very resources needed to act; compatibility can first fail at arbitrarily high arity.
- **Explanatory status:** the tested mechanisms are explained by linear/resource semantics, uniform strategies, exact residual-state planning, and relation/nerve compatibility. Existing literature contains joint treatments and relevant universal constructions.
- **Not established:** a new theorem historically, a new universal property, or a problem these existing theories cannot adequately describe. The four labels alone do not determine a canonical category, an order of completion, or a comparison map.
- **Still open:** a particular physically specified native class could enforce a new restricted obstruction theorem, computable criterion, or representation theorem. Such a result must be extracted from that class and tested against the matching literature, not inferred from the failure of an abstract square or from absence of a search hit.

The most useful next question is therefore concrete: **which native problem has a verified representational or theorem-level failure in the current repertoire, after resource stock, policy uniformity, observations, certificates and computation have actually been retained?** This probe found none, and does not recommend choosing a shared theory in advance.

## 8. Reproducibility and limits

`check_witnesses.py` exhaustively generates depth-bounded native test truth tables and checks the 2/6/16 counts and the 10-element meet completion. It verifies the diagnostic budget thresholds for k=1,…,4 and reconstructs every downward-closed family on up to four ambient worlds from its facets (2, 5, 19 and 167 nonempty complexes). `checks.json` records the outputs. The general proofs above, not finite enumeration, establish the unbounded statements.

The source ledger records read status and caveats. No solver failure is treated as a physical negative observation; no semantic existence is reported as a selected native implementation; and no search result is treated as proof of historical novelty or non-novelty.
