## A common field interpretation

For any of the declared finite Kernel implementations, World consists of its actual source state, service ages, sticky violation history, previous performed/failed event and terminal status. The joint fault f is retained unchanged. Correct is precisely kernel.compliant(f,i), so sensor, key, motor, installer and actuator compromise never removes an intact planner or authority's prescribed duties unless its executor field says so. Mem is the source Table state. Obs is the source local symbol type; Option.none means no invocation. Cmd is the declared local command alphabet, including bit-packed physical and administrative commands where the source uses them.

The initial relation is initializedBy with the source Initial.local_inputs and the same fixed Table.start functions in every fault/world alternative. It also retains actual initial service ages and initial verdicts. Observations is exactly the source joint iterator. Effects takes the masked actually issued compliant command tuple, calls every source Outcome, retains faulty command/effect choices inside that iterator and advances the actual-delivery monitor. It prepares next observations without another physical tick. Missing observation/effect continuations receive the declared losing completion; a failed effect attempt commits completed invocation-memory updates and makes future invocations absent.

The Python modules can define different Node classes even when their fields agree. The application decoder reconstructs the original finite_model.Node(f,state,memory,ages) before applying a source envelope; it does not equate wrapper object identity with source membership. Private Observation.physical_sample is reconstructed from retained World: Enactment uses state.x, and SharedPlannerFleet uses the tuple of component physical speeds. Neither value is added to actor-local observations. Initial-good verdicts and the initializedBy binding are checked separately from transition closure.

For each nonterminal decision boundary, the forward map sends a source round to the same source state, updated local memories, actual event/mission record and each admitted next observation. The converse reads those fields and the Outcome witness used by the effect relation. There is no union of separately selected worlds, no new physical outcome and no lost admitted outcome. The memory equality is obtained by Table.react on invoked compliant slots and holding the others; this is exactly issuedMask/memoryMask. This field-by-field identity proves the SourceRound equivalence, after which core_step_iff_source_round and core_run_iff_source_rounds lift it to every run.

This is not a new assumption that independently good components compose: the antecedent is the actual shared-variable join constructed in STRUCTURE, with its source scenario coverage.

The source tables are fixed locally implementable functions. The concrete following-profile constructor may inspect f solely to fill unused ghost entries; these entries never reach a source consumer. On all compliant invoked entries it evaluates only that actor's memory and local observation. follows_masks proves arbitrary ghost completions yield identical source behavior. World safety, prescribed current-command conduct, authorization-history facts, signed-artifact acceptance, installation/release facts and delivered service are decoded from the actual retained source state and events. The finite-state abstraction intentionally omits unmodeled physical variables and empirical calibration; the bridge cannot validate those.

## Fallible enactment

Enactment supplies seven local program slots: four independently affected brake paths and three authorities. Its source fault distinguishes motor, planner, actuator, installer, READY key, authority executor and authority key. Kernel.compliant uses only planner/authority executor faults. Its joint bounds consume all relevant physical and signing-path fault coordinates in the original component proof.

The source observations include current local threshold information, local installation stage or received authorization, and optional authority invocations. At most one authority is invoked on a physical interval; others receive no call. Thus splitting administrative subphases into extra global synchronous decisions would alter information or service. The boundary normalization instead retains the original one physical transition and the absent slots.

Every source outcome can contain continuing old engagement after nominal retirement, failed spare installation, key-produced READY, key-produced approvals, actual authority issuance, queued brake commands and independent motor/output choices. All these remain in the same World/event record under the source f. The safety proof covers unsuccessful replacement indefinitely. Functional completion keeps its separate intact-path and fairness assumptions; normalization does not supply them.

applications.py enumerates both an actual initial state and an inductive warm/retired state for every one of the 500 reduced joint faults, every local observation tuple there, every actual outcome and every next observation. It independently constructs the expected source command/memory/age/event tuple and compares the complete multiset of boundary successors. This tests both absent authorities and key-only compromise. It is not a full reachable-state traversal; the general identity interpretation above and the existing enactment invariant supply the all-run claim.

## Shared physical command ownership

SharedPlannerFleet supplies five program slots for two devices. The shared planner's command feeds two independent queues; four private planners each control one target-local brake. Its local pair signal is the declared conjunction of the two source frontends, not access to both physical states. The same global fault can affect the shared owner on both devices.

The core preserves that single shared command, each independently realized effect, differing component modes, actual aggregate delivery and the two separate heat stores. The structural join therefore exports one local policy whose actual runs are precisely those decoded by this bridge. It cannot substitute two inconsistent local copies of the shared actor. The conflicting-duty variant stays losing because its source violations are retained rather than filtered.

The application checks all 48 joint faults at an actual initial state, a two-high boundary and an unequal ambiguous-source boundary. It covers every admitted joint observation, hostile effect and next observation at those scenarios. The checker memoizes repeated pure observation queries at immutable (fault,state) keys, then directly re-evaluates every cached key to verify equality; it does not sample or discard the repeated branches. The measured READY-key counter means faults with intact brake planners, and may also contain installer or actuator compromise. The all-run property follows from the prior supplied-envelope closure and actual product/projection theorem, not from these selected boundary cases. Separate thermal stores and declared source-signal timing remain the original conditions.
