# Finite direct-port inference without raw-record copies in working RAM

Status: conditional construction with written proofs, selected Lean checks and executable adversarial traces. It refines the information interface in [INFORMATION](INFORMATION.md); it does not admit INSTANCE or establish physical isolation, renewable input availability, processor startup, elapsed-time bounds or the joint mission. The order/count reasoning is existing mathematics reconstructed for this source-memory interface, not a novelty claim. Self-checking is a first pass; independent source and implementation review remains required.

## S1: Actual locations and capabilities

The candidate receiver has external input stores I_0,...,I_(n-1), mutable instructions C, and private inference state W. I_0 is the consumed shared primary frontend; its entire frame may be replaced while execution remains intact. The auxiliary stores have separate actual origin/path/write incidence. Every slot may be reached in some admitted history; no fixed clean subset or complete trusted backup frame is supplied.

This is a physical capability proposal, not a partition created by renaming bytes. A raw C/W write lead has no route to the external I stores or to a common input remapper. An I write changes actual input data while the reference inference program continues executing normally. A private-state alteration of counters, thresholds, flags, bounds or results is an inference-execution fault declared by the location/transition relation before its consequence is known. Intact execution here concerns the complete job's actual private transition history; an attempted write that changes no private/code value does not change its classification. Corruption of a reference/template used as evidence remains a separate source defect when it leaves the inference program and its private transition state intact. A broad raw-write capability that actually reaches all input records must be retained as a whole-frame input fault, even if those records occupy nominally private RAM.

| Actual location | Meaning and permitted use | Required write-reach interpretation |
|---|---|---|
| External I slot and its input-record cache | Raw bounded word, physical key binding and any untrusted metadata | Input-only changes leave execution intact. Every replica, DMA buffer or retained raw word used as an input belongs to this surface. |
| Transient raw operand between I and comparison | The one word being compared | In this source operation it is a combinational operand, not writable retained state. A realization with a latch must expose that latch and its writer/alias reach as I; a shared writable latch can affect every slot over the job window. |
| Comparison flag | Result of the actual word comparison | Derived private instruction state. Altering it after comparison changes the inference execution, not the external observation. |
| Count, slot index, lower/upper search bounds and pivot | Derived state of the finite algorithm | Mutable W, with actual nominal update laws and explicit execution-corruption cases. These are not cached records with a new label. |
| Result and completion state | Derived inference output for the same consuming executor | A private mutation remains an execution fault. Sending this result to another executor creates a new fallible observation/message interface there. |
| Instruction/entry state | The actual procedure and its control flow | Startup and correct entry are root suppliers. No protected implementation or successful-reset primitive is introduced. |

The elementary observation operation compares ONE fixed-width word from an actual addressed port with a private threshold and produces one Boolean flag. It does not return truth, a median, permission, a source-health map or a whole frame. Private count/branch operations follow separately. Input changes may occur between every operation. The program does not read fault identities, analyst time, a physical truth variable or payload-asserted origin labels.

A compiler or hardware adapter must enumerate the actual load operand, register spill, DMA and cache locations. If it copies all n input records into writable W and later consumes those copies, input-only replacement of those records still forges the whole consumed frame. The implementation has not realized this separation. Likewise, a shared input mux with arbitrary remapping reach invalidates the proposed independent-slot support; an address label is not physical origin binding. The executable retains both failures.

## S2: Window-indexed observation law

Fix n=2q+1 distinct logical slots, a finite unsigned word alphabet and a search range [0,M] covering nominal values. Signed measurements use a fixed known offset. The receiver's register width must also represent 2M for midpoint arithmetic and n for counts, without overflow. Bad inputs may contain any encoded word, including values outside [0,M]; the nominal-envelope theorem below only constrains nominal slots.

For one complete job window, choose one actual gamma in Gamma and E in admissible_window_sets(gamma), using INFORMATION I1's causal incidence. Let F be the union of affected logical slots in this SAME history/window, with |F|<=q. For every actual read of i outside F, require its quantized value to lie in a common interval [L,U], where 0<=L<=U<=M. Words may change between reads, including on nominal slots, and the adversary may react to the current private threshold. There is no fixed-snapshot assumption. The interval must refer to the eventual consumer's physical quantity/key and cover sample age, measurement error, intervening dynamics, the full job duration and the later effect interval. This component does not derive that envelope or timely availability. A missing or invalid slot can be normalized to an arbitrary bounded word only when its influence is included in F; otherwise the consumer must remain unknown rather than assert a certificate.

The bad set is proof data, not a policy input, and is defined by causal reach rather than which values happened to be false. A current-at-each-instant bound does not suffice: one writer can visit a different slot before each read and corrupt the entire pass. Repeated jobs may have different F and rotate through every slot; the source must establish actual return and the window bound each time.

## S3: Direct permission counts

For an upper-load certificate choose threshold T_load from the fixed load limit minus the complete error/growth allowance. Scan all n load slots once and count the actual comparisons y_i<=T_load. Authorize this conjunct only when the count is at least q+1. At most q successes can be affected, so some nominal observation y_i<=T_load exists. Its physical envelope implies the required upper bound on actual load. For isolation, count y_i>=T_gap and require q+1; the dual argument supplies the lower bound. Different nominal witnesses may establish the two conjuncts because they refer to the same actual target and include their respective age margins.

No record vector is retained: the private state contains an index, a count and a comparison flag. A pass takes exactly n port reads even if the threshold is reached early. This fixed work bound is convenient rather than necessary for soundness. If every nominal load value is below its threshold, or every nominal isolation value above its threshold, the corresponding pass succeeds because n-q=q+1; useful availability is therefore explicit and separate from the witness argument. If an allowance makes a threshold infeasible, the calling policy defers rather than manufactures an observation.

For the proposed fixed rule, take y_load and y_gap in milliunits, L_safe=1000 and Z_safe=800. With total margins beta_load,beta_gap, use T_load=1000-beta_load and T_gap=800+beta_gap. The sample-to-effect envelope must hold throughout the consequential operation interval, not merely when the count finishes. A completed count is not permission to retain the result indefinitely or through an unaccounted pause. Its key and validity must survive until action, or it must be recomputed.

## S4: Quantile by repeated direct scans

For a point-valued row estimate, initialize lo=0 and hi=M. While lo<hi, set p=floor((lo+hi)/2), clear count and index, and scan each physical slot once using y_i<=p. If count>=q+1 set hi=p; otherwise set lo=p+1. Return lo when lo=hi. All retained values are derived search/count state; raw words exist only in I and the single comparison operand.

If a pass succeeds, at least one nominal read is <=p, so L<=p. If it fails and p>=U, every one of the at least q+1 nominal reads would be <=p, a contradiction. Hence a failed pass has p<U. The invariant L<=hi and lo<=U holds initially and survives either update. At termination lo=hi gives L<=result<=U. This proof uses the common envelope across ALL passes; it does not require a monotone sequence of adversarial answers or unchanged slot contents.

For width w=hi-lo>0, either new width is at most floor(w/2). Thus at most K=ceil(log2(M+1)) passes occur (K=0 when M=0), with at most nK actual reads. The executable uses M.bit_length(), the same integer bound. With a fixed input vector whose median lies in [0,M], this is the ordinary median by threshold counting. With changing inputs it is an envelope-certified representative, not necessarily the median of any simultaneous snapshot. For example, three slots can all contain3 during the first pass and all contain0 during the second, making the algorithm return2 although the observed snapshots' medians were only3 and0. The source judgment consumed by the controller is the containing envelope, not a fictitious snapshot identity.

Two rank-one estimates s,d can then be inverted as ((s+d)/2,(s-d)/2), with the fixed encoding offset removed from d. Row errors beta_s,beta_d give coordinate error at most (beta_s+beta_d)/2, including quantization. The current component supplies row inference; the actual complementary sensing arrangement, cross-region physical binding and source/controller refinement remain separate. Whole-job sample age must include both searches and the final private arithmetic before an effect.

## S5: Finite machine and work

streaming_model.py executes explicit initialization writes, a pivot-selection block, a one-word compare operation, a separate accumulation step, and a private bound-update block. The private register set is finite: lo,hi,pivot,count,index,flag,result plus finite program/control state. Initialization writes those fields one at a time; invocation at the actual initialization entry is a source prerequisite, not something obtained by naming a new job. Neither an opaque median library call nor a sorting buffer supplies the result.

The source work measure counts the compare itself, each port read, and all private blocks. Its decomposition is two operations for each initialization store/control advance; at most seven for midpoint selection and scan setup; two for one port comparison and control advance; four for count/index updates, flag clearing and conditional control advance; three for a bound/result decision; and three for final equality test/result return. A conditional branch comparing bounded registers is an ordinary private word operation. Thus with z initialization writes, one permission pass uses at most 2z+6n+3 bounded-word operations, and quantile search at most 2z+K(6n+10)+3. The model records these branch costs and separately records every read. Simulator assertions, diagnostic counters and traces are analyst instrumentation, not instructions of that source routine; deploying the Python interpreter itself would need a different cost analysis. The private blocks expand to bounded word operations; grouping them does not grant immunity against private-state corruption. Relating these word-operation counts to real time and energy still requires the actual processor rate, raw ingress admission work and shared-resource accounting. These counts do not make unsolicited upstream packet handling free.

For n=13 and M=2000, K=11: a row estimate needs at most143 port reads, and two rows need at most286 before coordinate inversion. Actual W sizes and opcode costs, not a runtime-independent median oracle, determine the resulting sample-to-effect age. No nominal clock phase is inherited. Bounded pauses must enter that elapsed-time envelope; an unbounded pause or power loss requires actual invalidation/restart before a stored result is used. This component does not install that startup/age supplier.

## S6: Consumption and obstruction witnesses

The thirteen-slot primary is not decorative. With twelve auxiliary values split six at970 and six at990, load threshold970 and q=6, primary970 gives seven successful comparisons while replacing that primary field by990 gives six. The same intact executor permits versus defers with unchanged auxiliary words. The replacement is executed after initialization and immediately before the first actual comparison, during the consumed job; it changes no private state. A sum-row example similarly changes the estimated coordinates and actual feedback commands when one frontend event replaces both primary fields and their claimed keys; the other row remains independently consumed. Primary origin must be excluded from the auxiliaries, bank copies count once per physical origin, and the actual shared-domain window must justify q=6. This finite example does not derive those source bounds.

All-input replacement is retained as an obstruction. In a high-load world, one permitted capability that replaces all thirteen input words by a low-load frame makes the unchanged private procedure authorize exactly as in the low-load world. Execution remains intact. That event has a thirteen-slot footprint, not one merely because it is one writer. A source admitting it must supply another common admissible protocol or restrict the positive capability topology through actual isolation; renaming the copied input cells private does not solve it. A shared transient mux produces the same obstruction without changing the external stores themselves.

The executable also retains a copied-record implementation in which input-only writes replace a bulk W buffer, a moving single writer whose whole-window support covers every slot, a wrong-physical-key case, and private-count/code-operand mutations that make the procedure lie. Those private/code mutations are explicitly inference-execution faults; the algorithm does not detect a ghost fault label or abstain because the checker calls it faulty. Working-state initialization does not repair the altered instruction operand. Physical effects of such an executor remain the parent control problem. The wrong-key case shows why Gamma membership and payload labels cannot establish actual bay binding.

## S7: Evidence and remaining source obligations

Streaming.lean checks threshold-count implications, the majority margin, private search-bound preservation, midpoint/width properties, terminal envelope, permission and row inversion arithmetic. The finite executable compares static outputs with an independent sorting specification, explores all reachable Boolean read branches of small changing-slot cases, checks every slot as a possible affected origin, verifies all read/work bounds, and executes the named countercases. Positive tests never supply a good-set map to the machine. Diagnostic traces retain raw values and physical truth only outside its runtime state.

Use `python -B streaming_model.py --check` in this directory to check the selected Lean declarations and reproduce streaming_results.json. The record binds STREAMING.md, Streaming.lean and streaming_model.py and the reused strict declaration/axiom checker. `--write` deliberately refreshes only that result file after review. Optimized Python is rejected. Full hardware compilation, physical input isolation, renewed origin/path availability, actual cache/sample ages, byte-region ownership, common read availability, startup and the global H/footprint/resource induction remain unproved suppliers. No source admission, permanent clean backup or full-program completion follows from this component.
