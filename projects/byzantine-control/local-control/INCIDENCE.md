# Local observation routes and actual target binding

Status: constructed static incidence adapter for INSTANCE's ring family. It supplies the missing physical meaning of PROGRAM's local client/target ordinals and logical origin groups. It does not establish sensor accuracy, source availability, image custody or fault-free contact interpretation. SOURCES's bounded-degree circulant assessment precedes this construction; the interval and routing calculations below are elementary applications, not a novelty claim.

Let N=mR, with even m>=72 and R>=6, and take hosts modulo N. Use the ordered displacement list S=(-20,...,-1,1,...,20). A host i has physical maintenance, direct data and target-observation neighbors M_i={i+s:s∈S}. A provider j has forty actual maintenance/functional/cell targets, indexed by its own copy of S. It also has rank-one plant heads for its own and the two adjacent regions. Even hosts supply the sum row and odd hosts the difference row; the hardware type does not make one host observe both coordinates. P can be common across these different physical heads.

For a controller i working on target t∈M_i, choose its thirteen maintenance/cell observers from C(i,t)=M_i∩M_t. If the circular displacement from i to t has absolute value k∈[1,20], then |C(i,t)|=39−k>=19: on the relevant length80 arc there is no wrap collision because N>=432, and translating the two punctured intervals gives that count. Neither i nor t belongs to the intersection. Order C(i,t) by the provider's displacement in i's local list; use the first member as the backend of the logical primary and the next twelve as auxiliaries. Thus every selected provider is both a direct data neighbor of i and a physical observer of t. There is no observation relay supplying global maintenance reach.

For each of i's two plant rows, twenty members of M_i have the required parity. Select thirteen, again reserving one primary backend and twelve distinct auxiliaries. Every such provider's region is either i's region or an adjacent one, since its distance from i is at most20<m. Its actual corresponding region head exists among the three heads. These plant groups differ from maintenance groups: maintenance does not need thirteen observers of each parity. Imposing that unnecessary restriction on the minimum nineteen-member intersection would give a false shortage; assuming all forty providers can observe every neighbor's fixture would give a false reach guarantee.

## Ordinals are local; physical objects are shared

Suppose t=i+S[a] and j∈C(i,t). Let b be the unique index with t=j+S[b]. Request delivery maps the consumer's target ordinal a to the provider's physical slot b, and the response maps b back to a. The client-host and client-bank coordinates are retained independently. PROGRAM's provider loop scans its own2d client-bank entries and d physical target entries; the2d² count is therefore still correct. Requests use the provider-local slot corresponding to the actual target, not the same integer ordinal at both ends.

The raw request payload contains the candidate side, bay and cell key. It cannot change the physical client identity or the provider-local target slot holding it. `source_capture_request(client,b)` captures that slot; `source_start_cell(b)` probes the actual target j+S[b]. The returned payload binds the captured candidate key; its fixed physical reply lane binds the target. Both are required. For example, receiver0's target+1 has ordinal20, while provider2 observes that same target at ordinal19. Copying ordinal20 probes host3. Correctly comparing a reply key from host3 does not validate host1's cell.

Fast published keys have the same translation: provider target key3+b·K+field maps to consumer target key3+a·K+field, without changing the field value. Here K is PROGRAM's number of published fields per target. The consumer's logical plant key0 or1 selects the corresponding parity group and the provider's physical region-head index0,1 or2. A published key's integer is not by itself a statement that two hosts measured the same thing.

These translations are a finite static wire/port layout. They depend on local displacement, fixed head type and object identity, not hidden world state, future fault identities, image correctness or normative permission. P need not read a global host number. They may be realized by separately bound per-origin lanes with fixed target selection; a programmable table is an alternative only with its actual integrity, renewal and cost obligations. They cannot be implemented by silently adding one writable receiver remapper that can falsify every auxiliary input while decision execution remains intact. The layout's physical selector/descriptor bits, driver power and wire travel remain in the resource and timing bills.

The baseline private writer layout is equally concrete. At target t, producer host i∈M_t and its physical bank b∈{0,1} own candidate ordinal2·index_(M_t)(i)+b in each prepared side. This is a bijection from the eighty actual producer-bank pairs to the eighty candidate bays. `write_own` and `own_equal` use that physically bound lead; their caller cannot supply another producer or bank identity. The target execution side remains an ordinary argument, subject to that side's actual clamp/power/write-enable conditions. A/B producer banks therefore cannot overwrite each other's candidates by retaining a host label through renewal. Common P need not contain the owner's ordinal. An optional seven-producer/B14 design needs its own restricted mapping and bootstrap-force/deadline proof; this eighty-bay construction does not certify it.

## The correlation bound this map actually supports

The logical primary is the receiver's shared frontend. For a given group it consumes the selected backend's A/B records; arbitrary corruption of the whole frontend may forge both and every field, but contributes one logical vote. Auxiliary records retain twelve separate backend host identities, each with A/B records ORed once. The primary backend is not an auxiliary in that same group. The receiver itself is never an auxiliary or backend in these groups.

Under the specified source-domain map, a host-domain fault may alter that host's publications/probes and its own primary frontend. For any one receiver/group, this domain reaches at most one logical slot: if it is the receiver, only the primary; if it is the selected primary backend, again only the primary; if it is an auxiliary, that one auxiliary. Both physical banks remain the same origin. Therefore q reached host domains can affect at most q slots in each group, even with arbitrary correlated values and temporal choices within the common cover. No independence probability or honest identifier assumption enters this argument. Separate channel faults need their actual endpoint footprint included in the same cover, rather than an extra uncharged budget.

This is not a claim that every one-location physical failure has that footprint. A common all-input DMA/remapper, a target-controlled read server, or a causal mechanism reaching all independent comparison paths can violate the stated map while the receiver's decision execution remains intact. Such an execution must retain its wide reach and use the corresponding information/control boundary; it cannot be renamed an execution fault or counted as one corrupted origin. The positive class has the enumerated physically separated paths. The initial-I and retired-record debt mechanisms are still needed even on those paths.

Truthful observations of one damaged switch also do not establish the physical fact for which that switch was intended. The raw contact-to-carriage or contact-to-power implication has its own source law and defect footprint. In particular, intact helpers' factual intervention duties cannot be discharged by thirteen copies of a false target status. The functional load/isolation measurements used for those duties must couple to the actual relevant quantities, with the declared shared-dependency and error map. Likewise, sequential truthful cell reads establish one image only under the actual custody/write-exclusion conditions, not by this routing lemma.

The source preservation law is an actual-object equality: the object probed at the provider equals the object named by the consumer's local target port, and the candidate key/record returns on that target's independently bound lane. The negative checks break target-ordinal transport, duplicate the primary backend into an auxiliary, and introduce an all-input remapper. The general interval/count argument covers every N in the stated family; executable checks cover several complete finite rings and the raw logical-domain map. These establish incidence, not the full joint source or the final Goal.
