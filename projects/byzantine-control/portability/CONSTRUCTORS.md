# Finite constructive interfaces and their proof boundary

Status: implemented design-time certificate algorithms, before independent review and source-family instantiation. [constructors.py](constructors.py) is an exported-candidate implementation, not yet frozen for RP6. It performs finite exact calculations and returns specific sufficient-certificate failures. It does not implement a runtime repair server, assume a secure estimator or certify the full mission. New source-local realization certificates are legitimate future inputs; an unexplained complete recovery theorem is not.

## Incident projection and separating-bundle construction

For a finite set of actual incident tokens Q and a consumer c, the design input supplies a footprint map P(e,c). `projected_support` returns the set union over e in Q. The tokens retain incident identity even when two tokens reach the same execution host; only identical affected consumer items are merged by the union. Missing maps fail explicitly. Source realization must prove that this footprint includes direct reach and retained descendants across the complete consumer window, and that the supplied joint token families are conservative for the same history. The function cannot infer those physical facts from labels.

For rational observation rows A_i in Q^n and a nonempty finite family F of admitted row supports, `separating_bundle` enumerates row subsets K up to the declared cardinality and search capacity. It returns K only if, for every S,T in F, the rows indexed by K minus (S union T) have rank n. Exact Gaussian elimination uses rational arithmetic. The output lists K, n and the number of checked support pairs/candidates. It does not output an estimate, identify actual bad rows, promise noisy precision, or claim the chosen bundle is physically available.

Soundness is the existing separation argument instantiated as follows. If x and x' explain the same exact received rows outside S and T respectively, then A_i(x-x')=0 for every retained i outside their union. Full column rank forces x=x'. Thus two compatible explanations agree. Conversely, rank loss for one pair gives a nonzero kernel vector and an algebraic ambiguous-row construction under the arbitrary-value support model: outside S union T use the common row values; on S minus T use x' and on T minus S use x. This is exact-reconstruction failure for that information model, not control impossibility or an assertion that both histories occur in a particular source. The broader bounded-error decoder remains the existing INFORMATION result and needs its actual geometry, finite computation, age and service suppliers.

All tuples in F describe simultaneous scenario alternatives. Collapsing them to the union of mutually incompatible supports before the pairwise test may introduce unnecessary conservatism; omitting an actually joint footprint may make the result unsound. The algorithm handles the given family, not arbitrary unknown common causes. The exhaustive search is finite but can be exponential. The candidate ceiling bounds only enumeration count: support-pair materialization, rank calculations, rational bit sizes and memory are additional costs, not bounded by that ceiling. It is not a total-work or runtime receiver deadline. An exhausted search returns a failure, not an optimality or impossibility result. Fixed d determines the chosen bundle before hidden scenarios; no actor is given the actual S or T.

## Ranked local-phase budgeting

`phase_budget` consumes a finite phase relation, a natural rank strictly decreasing on every edge, explicit terminals, and nonnegative rational elapsed/work bounds on every edge. Each edge names the source-local realization statement that must justify it. The checker rejects missing phases, outgoing terminal edges, nondecreasing ranks and a nonterminal with no represented successor. It computes

    T(q) = max_(q -> q') (duration(q,q') + T(q')),
    W(q) = max_(q -> q') (work(q,q') + W(q')),
    T(terminal) = W(terminal) = 0.

The proof is induction on rank. For every represented next edge, its duration plus the residual bound is at most T(q). Applying the induction to the target bounds every demonic path; strict rank decrease and the nonterminal successor condition force finite arrival at a terminal in the represented relation. Taking time and work maxima separately is conservative even when different paths realize them. A prefix path need not achieve either maximum.

Exported numeric inputs accept only exact integers/Fractions; counts and capacities require natural integers, and booleans/floats are rejected. A phase certificate carries its input ranked graph; horizon composition recomputes the graph certificate and checks equality, rather than trusting a forged dataclass or negative claimed bound. The implementation does not verify a realization name. The source adapter must map its actual local phase state and every relevant outcome to the graph, establish edge bounds from primitive operations and already justified input intervals, retain stalled/aborted branches, and prove the terminal postcondition. A phase may contain repeated raw instructions or continuous motion, but its bounded progress proof is open and counted. An edge named `complete repair` whose realization assumes H-return is not admissible. An infinite raw stall omitted by the graph invalidates the source map; syntactic acyclicity does not erase it. The source map must be timed and progressive: each actual entry leads to a bounded successor or an explicitly charged interruption with its remaining-budget/entry-state witness. An edge map only for completions is vacuously satisfied by a source that never completes anything. Actual invocation is also separate from the abstract existence of an execution window.

`phase_family_budget` adds a synthetic zero-cost demonic root for every declared interrupted entry, making the bound their maximum. The root is an analytic case split, not a runtime observation or oracle. Source coverage of all reachable entry states remains open. `initial_debt_deadline` separately checks that commissioning plus the actual initial-debt phase closure finishes strictly before that debt is removed from its initialized cover; an invented nonnegative release time cannot supply this branch.

This interface does not impose acyclicity on the whole recurrent system. Each particular attempt has a finite ranked progress/abort closure, while subsequent attempts and fresh intrusions recur. A newly acquired incident may invalidate that target attempt and remains charged; the global proof must quantify over a retrospective whole-window cover and establish the interval suppliers for the relevant attempt. It may not choose a future successful path. Whole-source flow continuation and time divergence remain separate obligations.

## Joint horizon and chronological reserve checks

`WindowEnvelope.bound` evaluates p+c+floor(sigma+lambda*(H+W))+D0 using exact rational arithmetic. It is raw token bookkeeping under the all-closed-interval acquisition envelope and occupancy/debt definition. It is not effective support. `check_horizon` requires the explicit phase bound plus commissioning and retirement tail to be strictly below H, then checks the whole-attempt W=H token budget against the realized phase's tolerated count. The phase realization must actually hold at that count. Calling the same function with an unjustified count does not discharge it. This is a simultaneous numerical witness in the H/support constraints, not the initialized causal proof.

`reservoir_margin` checks R>=d and C-b-d*T>0 for the existing chronological reservoir lemma: actual demand is at most b+dL and raw supply at least R*(L-T)^+ on all intervals. Source inventory and actual connectivity must justify those envelopes; the capacity/initial stock and spill semantics must fit the imported lemma. A last-capacity-contact argument then bounds the deficit by b+d*T. Multiple uses of one stock are included in one demand sum before invoking it. Physically failed funding paths have their separate hard bounds; this check grants no delivery through them.

## Dependency and preservation audit

The actual constructor inputs are design incidence/support data, rational rows, finite ranks/edges and source-derived cost bounds, raw acquisition envelopes and resource envelopes. Outputs are finite bundle, phase and scalar compatibility certificates. The soundness arguments preserve these exact input-level judgments. Source-to-input refinement, bounded runtime interpretation, primitive physical validation and the reusable all-history assembly are separate consumers. Negative outputs have only the stated certificate scope.

The algorithms deliberately forget source code internals and detailed physical trajectories once a named local realization establishes the consumed envelope. They do not justify that forgetting themselves. Reopen the dependent certificate on changed source reach, row geometry, phase outcomes, timing, shared debit, terminal meaning or evidence trust. A global model checker hidden behind a realization name remains global verification for RP5. The constructors count neither theorem names nor source lines as reduced proof burden.

Before RP6 freeze, independent review must check these input/output contracts, implementation alignment, all imported obligations, actual use by both positive families and change locality. These algorithms currently discharge only finite construction work. They are not substitutes for the two positive families, scaling result, recurrent theorem or independent held-out transfer.
