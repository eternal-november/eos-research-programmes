For every consumer failure in that presentation, the construction returns an incident in the applicable raw cover whose declared footprint reaches that consumer. It handles an old live capability, a missed operation that produced nothing, and a missed operation caused by an earlier failure at a different provider. ## What is fixed before the proof

An operation identifies a particular physical duty or repair episode. Its entry is the real demand, release, initial deadline trigger or source-derived scheduled start. Its cursors include the retained states needed to continue the *same* operation. Its ordinary terminal and interrupt each have a local interpretation on the run. A query about a missed seat, for example, fixes its fixture, actual seat opportunity and eligibility conditions. A classifier may examine the diagnostic history to verify that they held. It cannot start the duty retrospectively at an event already known to have succeeded. A continuing raw charge with no release may have no repair invocation. For an uncovered, expired origin the adapter must match the particular repair assigned to its source episode.

Fix the same role-local policy before choosing the scenario. Its command factors through its role's actual permitted view. A given raw run fixes the observed operation kind, endpoint, cost and actual successor-cursor relation. The proof can use a bounded list of other support queries to certify a particular step. Each such query precedes the *outer* challenge strictly and lies at or before the endpoint of the step being certified. A post-strobe read may explain an actual completion. It cannot change the pre-strobe command or select a favorable successor. The returned local step has to match the recorded operation and carry its actual successor cursor. The source must bind those declarations to its installed policy, rule, primitive outcome, read permissions and causal phase. Giving an actor a different role for different hidden states would violate that binding. ## Construction and causal induction

1. At a live adverse effect, trace actual retention edges backwards to a raw seed. If its owner has fallen outside this query's cover, instantiate its identified repair. Starting from the source entry cursor, the local job either produces its specified terminal, records an actual interrupt or advances with smaller rank on the same run within the remaining budget. Its finite provider requests can call the theorem only on smaller cuts. The deadline gives a cut strictly before the challenge. A local terminal excludes continuation of the old mark at that cut. A valid interrupt must reattribute every still-relevant path of this particular old liability or otherwise exclude that mark. An interrupted attempt that needs to retry with the same owner must consume a bounded progress step, or the certificate fails. Since any retained line to the challenge crosses the cut with its mark intact, that expired owner cannot be the traced seed. This derives coverage and returns the named witness.
2. At a missed duty, open its registered operation before an issue was required. A lawful terminal within the allowed window contradicts the supplied miss; bounded local progress gives the actual interrupt receipt. It may identify current adverse authority, in which case apply the first construction. Alternatively it identifies a specific earlier failed query. Apply that earlier answer and transport the **same token** with both time-window and physical-footprint membership into the current query. A previous funding problem at a different receiver, an expired ordinary incident or a shared host name is insufficient. The interrupt can be at the deadline, provided its actual causal cut is not later; a same-time atomic effect must be handled directly or ordered by its source.
3. Resolve all these calls by decreasing cut index. Recursion crosses roles and kinds of obligation, so the role-dependency graph itself can be cyclic. At cut zero an earlier read/referral is impossible. Initialized occurrences still need their actual seed or local physical terminal. The resulting attribution is a support inclusion; it does not claim sole causation, count a token twice or erase another contributor. For an actual classifier yielding either a positive usable receipt or the queried defect, the absence of any covered token reaching the role now yields the positive receipt. Bridge sparse availability to a complete job interval with the separate [last-loss handoff](DONOR-WINDOW.md). Take the union of actual affected roles over one common window before applying the [regional weights](SERVICE-FIBRES.md).

The finite derivation here uses the contextual-composition programme's distinction between a locally consistent completion mark and a finite completion certificate. In a silent self-loop the equation for a Boolean completion mark admits true, although no finite run reaches a terminal. A same-cut cycle of supplier referrals would admit the analogous false positive here. Strictly earlier reads and decreasing physical job rank rule it out independently of how often the same roles recur. The least-finite-certificate observation transfers directly. The present theorem separately supplies incident identity, physical footprint and coverage. The finite-cut interpretation is important. A monitor can be unsafe throughout an open interval even if both endpoint readings are safe. It needs an interval-valued bad witness and a flow/collar proof, or a removable observation cut at the actual interior time. Subdividing an interval must leave the physical flow, grants and original operation identities unchanged. Strict decrease in arbitrary real time need not terminate: the false obligation at each t>0 can refer to the same one at t/2 while the initial state at zero is fine. One sufficient finite-past certificate uses actual source events and finitely many sponsored alarms on [0,T]. When an edge does not cross one of them it must either step back by a uniform positive physical margin ε or reduce a finite local order inside the same segment/time bin. Lexicographic order on the number of preceding events, floor(t/ε) and that local order is well founded. Its purpose is to bound dependency depth, not to identify distinct physical states in a bin. Finite local branching, finite on-run job ranks, and the fixed physical choices give a finite subordinate query diagram for each particular challenge. Chronologically insert the needed observation cuts, and keep same-time dependencies in the permitted micro-order. A genuinely simultaneous physical solve is one checked block. ## Instantiation at a return seat

[SeatSupport.lean](SeatSupport.lean) instantiates the entire interface for the two orders of one due, funded sample and one permanent physical takeover at fixture 100. At the same elapsed time the hardware permits both causal orders. Strobe first actually seats NORMAL. Takeover first freezes the normal strobe and the carriage remains in RETURN. The missing-seat operation refers to the already acquired, same-site held pole at the preceding causal cut, and the exported solver returns token 100. The local policy and physical stage start are identical for both runs. Later queries in this projection concern that same historical duty. The source checker executed the two orders using the local bank and work, including the actual gate state after both operations. [Paid strobe and retained-override tests](RETURN-SEAT.md)

This instance exercises a genuine miss and cross-query recursion. The permanent physical token does not expire in this slice; the general repair branch has separate evidence. For a nonpermanent example consider the stale ordinary direction word. Under stable wrong geometry, a fully funded nominal capture replaces the inward steering level. Its possible new inward issue no longer traces to the old level. When a physical takeover happens first it can instead **copy** the old key to a held pole. A transfer is legitimate only when the new charge actually owns that continued reach. With 2047 local work a strobe spends the available amount and retains the old levels, so a funded terminal cannot be constructed. An admitted underfunding that has no covering incident must be handled by a local reserve/retry law or is an obstruction to that source adapter.
