# A bounded EXITING lease and a separate cleanup action

**Candidate B operation.** A recovered helper with old EXITING can continue sending negative MODE while helping the same target reach cleanup. The existing command packet carries signed MODE, signed CAM and a separately addressed ACTION. Only the choice of MODE depends on the old latch in the mature FULL branch of this alternative. During persistent corroborated ENTERING, the last adverse MODE issue from a continuously serving recovered bank is bounded by **2901.518q** from the start of stability. A genuinely displaced cam in an initially releasable RETURN also needs a change to the physical routing of the cleanup actuators. The existing source blocks that routing in the interior of RETURN. These are distinct program and mechanism proposals. Neither was installed in the reference B family. ## The locally implemented rule

The illustration uses the existing per-target EXITING, EXIT_OBSERVED and EXIT_WAIT fields and the original paid per-frame decrement of each positive EXIT_WAIT. Set P=POST_STAGE_FRAMES=2100. No new independently running watchdog, free elapsed-time source or nonvolatile store is added. On each old-X target visit, a signed countdown outside [0,P] is clamped to P. An unpowered processor, a stalled comparison or an unretired frame does not count down merely because physical time passed.

* **Positive NORMAL_STOP has priority in old X.** On the first positive observation enter posthold and set the countdown to P. A later normal-positive visit may clear X, ABORT, WATCH_HALF, stage and rank only after that hold has run down. That clearing visit still emits negative MODE and no ACTION. Loss of the normal observation resets EXIT_OBSERVED and sets the countdown to P once. Sustained absent NORMAL does not repeatedly buy a new lease.
* **Positive FULL in old X renews the countdown.** The helper enters the same route-26 stage-27 and post-stage wait as its non-X counterpart. While waiting, old X emits negative MODE with neutral ACTION; non-X stays neutral. After that qualification, both execute the original `abort_action` with its same anchor, side, geometry, low-energy, functional load/clearance checks and executable priority. Its ACTION with its side/index/amplitude is gated by the same retained ABORT_SIGNATURE and ABORT_WAIT. Only **after** that signature check does old X replace MODE with −FORCE. Moving the override before the original “MODE negative” signature test would allow a newly proposed CUT or other action to evade its wait. If a successful ready/entry check sets a new X, initialize its countdown to P after the original assignment; a new X cannot inherit the old zero. At a qualified FULL positive, renewing old X without complete cleanup is legitimate for this construction because old X now performs the guarded cleanup ACTION. With the old MODE-only X, that renewal could sustain a deadlock.
* **No positive FULL or NORMAL in old X.** The ordinary response remains negative MODE with no ACTION. Only when EXIT_WAIT is zero and there is a corroborated positive coherent ENTERING observation does the helper clear X and its stale abort/watch/stage/rank state and emit positive MODE on route 26. Expiry or missing data alone cannot produce that positive command. Under a fully corrupt local processor the same raw opportunities for false words and arbitrary earlier effects remain.
* **Without X**, the original FULL-first, ENTERING-second helper and its ordinary branches remain. A genuinely fresh bank starts at the existing formed BOOT defaults. START/WAIT or a packet return value is not a claim that the physical bank has been reconstructed, or that an old side has been cut off.

This choice preserves a long negative hold at a clean actual RETURN, even if another cleanup contact briefly opens: periodic corroborated FULL renews the lease. A proposal renewing only on the entire simultaneous cleanup conjunction would require a stronger continuous-contact or coverage proof. If cleanup stays false long enough in RETURN, every negative lease could instead expire before normal seating. Conversely, renewing on FULL while keeping the old X policy's silence on the ACTION channel leaves a parked cam and unready blend, shunt or cut with no available cleanup command.

## A displaced RETURN needs a physical route

Consider an unlatched cam entry, an intact keeper, carriage strictly inside RETURN, blend away from that keeper (or ISO unseated), no adverse force that moves the carriage forward, and initially no X. Once the truthful FULL and missing preconditions are received, all non-X helpers command MODE+ plus the upstream BLEND/ISO action after the required waits. They cannot ask for REWIND yet. Positive MODE does not move the one-way RETURN carriage. In the incumbent source, the ordinary abort cleanup train works at the full carriage endpoint and the B-specific rewind segment accepts travel only in phase FULL with the pre-park sample. Thus **enabling REWIND in RETURN and adding a cam-entry seating pin alone does not recover this state**: the relevant callers issue another actuator and that route is physically closed. This obstruction survives arbitrary successful donor cycling. It is conditional on admission of the displaced local product; it is not a whole-source losing trajectory. A candidate physical extension is to engage the entire existing, fixed-direction, keeper-indexed FULL cleanup train according to the **retained physical full latch**, covering the interior of RETURN until actual normal seating. Preserve its physical prerequisites, explicit permission to press CUT from the local policy, old windings/flight and one-way keeper-specific parking. Keep normal CAM disconnected. Couple actual negative return travel/normal engagement to the real cleanup contacts and keeper-entry detent, with genuine cut, continued no-rearm, stable half-off and the admitted source age bound where the existing sampler is consumed. A held predicate that sampled low E long ago is not that conjunction; real energy may be high. A switch that infallibly detects correct code or factual permission would not implement this proposal. An initially invalid RETURN need not move as a whole until real cleanup is attained, but cleanup action must remain physically possible at its current abort position. The extension forbids the exposed case of seating into normal from the displaced cam. If the receiver accepts separate actuation fields under the actual FULL latch, X cannot suppress the common warranted action by monopolizing the MODE sign.

The useful conditional progress argument is as follows. While FULL stays asserted and NORMAL unseated, after the read/visit and stage/signature wash every functioning eligible helper can contribute the same bounded cleanup job a corresponding non-X helper can perform. An old-X visit no longer omits it. This includes restoring a displaced blend to the actual retained keeper, seating isolation/shunt, obtaining factual cut permission if needed, retaining the real disconnected energy drain, bringing cold activation/clamp/reset to their endpoints, then rewinding the actual cam to the keeper entry. Each is a physical job with an actual force direction, withdrawal of earlier opposing outputs, compatible circuit, upper duration and enabled successor. Different jobs can be issued while a different helper is waiting; a single matching snapshot does not supply that whole-job interval. The fixed full-latch train must supply the same ordered, signed and guarded work down this itinerary on every required RETURN position. When cleanup is genuinely stable long enough for the original qualified confirmation, each remaining non-X can set X; existing X already maintains negative MODE, and the actual negative effort can seat RETURN. No donor election, agreement on who holds X or privileged external reset is used. An indefinitely failed fixed fixture, absent functional permission, unpowered repair stage, jam or incoherent old loading has no nominal progress guarantee. The cost/rate/continuation and achieved physical job bounds for the extended train have not been supplied.
