# Timed recovery: source and construction boundaries

The obligation-directed source assessment was performed before writing this module, using the already assessed FIFO and refinement routes. Checks below are dated 2026-10-21 and are limited to their exact stated scopes. The local contribution is a direct constructive assembly, with no novelty or exhaustive-frontier claim.

| Primary source | Checked result and consequence |
|---|---|
| [Singletary, Chen and Ames, Control Barrier Functions for Sampled-Data Systems with Input Delays, arXiv:2005.06418v1](https://arxiv.org/pdf/2005.06418), Section IV Assumptions 1–2, equation (18), Algorithm 1, Theorem 2 and Corollary 1 | [✓] Inspected the integer-multiple input delay, retained input buffer, safe initialization and accurate/covering prediction conditions. This supports retaining every pending input when predicting its effect time. Its zero-input initialization is different from the demand-preserving d FIFO here. Its theorem supplies neither Byzantine local interval agreement nor the administrative reservation and release mechanism. The local proof constructs those conditions directly. |
| [Reissig, Weber and Rungger, Feedback Refinement Relations for the Synthesis of Symbolic Controllers, arXiv:1503.03715v3](https://arxiv.org/html/1503.03715), Definition V.2, Proposition V.3, Theorems V.4 and VI.3 | [✓] Inspected input admissibility, successor inclusion, composition and specification transport. The present release must restore an actually realizable input interface and initial-state relation; trace resemblance alone cannot do that. The source does not certify separate local actor information, command ownership, normative authorization, or mode-transition roots. No theorem about those mechanisms is attributed to it. |

The closest repository premises are E-H's witnessed, delayed interval controller and the institutional distinction among credential access, power, permission and effective exclusion. Their original positive instances have different state spaces and role maps. A common global capacity bound cannot justify removing capacity below an old queued command; nor can a digital readiness label prove that a live d FIFO is safe from a boundary state. These are exhibited compatibility failures, not evidence that existing control literature lacks recovery methods.

The selected route is therefore adaptation: restrict disturbance through effective isolation, consume previously certified commands, maintain service during reduced-capacity repair, construct a local interval certificate for a protected recenter block, and return to the exact d-FIFO startup region. The read-only analytic investigation additionally checked 172 FIFO states, 18,576 report profiles and 37,152 common interval endpoints on frozen evidence commit e37ec4f408ee83c19028ad95da9f95cb8d4e88fd; those calculations supported the choice but are not substituted for the maintained runtime and proofs.

The search was bounded to the named primary FIFO/refinement constructions and their compatibility conditions. It did not survey all switched-system, hybrid recovery, reservation-protocol or administrative-law literature. Reopen source checking before an optimality claim, uncertain isolation bound, nonlinear dynamics, arbitrary time-varying input delay, membership migration, or a novelty claim. The exact initial-region comparison in TIMED-RECOVERY is independently derived for the fixed immutable d FIFO, not imported as a universal optimal-control theorem.
