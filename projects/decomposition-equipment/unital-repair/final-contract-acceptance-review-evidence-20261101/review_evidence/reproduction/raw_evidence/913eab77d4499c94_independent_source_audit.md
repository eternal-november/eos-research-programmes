## Independent mathematical checks for D2

For fixed finite f:A'→A, g:B'→B and h:C'→C, universal relational equality over every R⊆A×B and S⊆B×C holds exactly when A' is empty, C' is empty, or g is surjective. Necessity in the nonempty-endpoint case follows by choosing one primed exterior point on each side and a missing b∈B, and singleton relations through (f(a'),b,h(c')). Empty B already makes g onto. A zero target cardinality cannot be silently treated as a counterexample to this criterion.

For n≥2 the corresponding universal path criterion includes an additional vacuity: some OLD internal interface A_i is empty. If all old internal sets and both primed outer sets are nonempty, singleton relations along any selected old path prove the necessity of each internal surjectivity condition. For n=1 restriction is exact without an internal condition. For n=0 equality is diagonal=kernel(f), hence exactly injectivity, including an empty domain.

For particular fixed R,S, endpoint support equality only requires one feasible old intermediate value in im(g) for each supported exterior pair. It does not say every actual old witness lifts. An actual span comparison is bijective exactly when every feasible target witness has exactly one lift; a product fibre of cardinality zero and a product fibre of cardinality greater than one are different failures. Do not erase this distinction by quotienting witnesses.

Tree compatibility must use every ACTUAL child composite/run required by the tree. CUT's three-edge missed-value example has all adjacent primitive-pair tests vacuously bijective while the full comparison fails. Nullary instances require the diagonal test separately. Supplying primitive span-leg tables and computing finite tuple fibres is a noncircular input test; simply assuming the desired comparison is invertible is not.

## Independent mathematical checks for D3

A groupoid-equivalence theorem can legitimately start with primitive signature actions and construct the operation/refinement comparison by D1. It should not start by postulating an equivalence of completed calculi. On a Grothendieck transport/refinement category, an arrow must retain (interface arrow, actual original-slot refinement tuple). Full faithfulness uses the equivalence's bijection on interface hom sets together with the actual tuple map; essential surjectivity requires an explicit transported object. Coherence must be proved on these arrows, not just on object isoclasses.

Repeated equal components do not authorize permutation of ordered slots. A stabilizer must be a subgroup of the supplied allowed interface action actually fixing the full witness or tuple, rather than an unexplained symmetric group on repeated slots. Scalar products cannot replace retained local scalar vectors.

PROV's K_f has one arrow between lifts of the same OLD value. For a chain B'' --g→ B' --f→ B, two-stage arrows compare f(g(z)), not g(z) alone. The constant f:{0,1}→{*}, g=id example disproves independent recomputation of K_g. Nullary diagonal is an equivalence of groupoids, not a bijection of object sets, and strict endpoint set fibres cannot replace homotopy fibres.

PROV treats old cells and old refinement tuples as discrete labels. Distinct graph partitions, actual coefficient witnesses, local semantic scalars, and original occurrence data remain separate components. Original decorator placements are NOT additional retained invariants because R, UL, UR, D0, DA, DL and DR are already equations. The check of those seven equations is sound interpretation; it is not an unproved fullness/generation theorem for all extended groupoid-span objects.

ACT's active-graph intrinsic quotient automorphisms are trivial at scalar 1; its retained actual cut arrows may have product Sym(E(a,b)) isotropy. The factorial certificate bound is valid only in the declared finite equivariant marking model and is not a general computational-memory lower bound. The actual beta maps are an adequate repair only with their explicit contraction/splitting constructions and diagrams, not merely because isolated fibres are contractible.

## Scientific floor and acceptance boundary

The selected original floors can be met without claiming that every noninvertible map acts strongly on the original set-valued calculus, or that quotienting all symmetry yields the original refinement category. Those blanket statements are false. A correct acceptance must identify which bounded groupoid-valued repair is selected, show its actual original-presentation/refinement application, and preserve the set/groupoid and equality/equivalence distinctions above. Source consolidation alone is useful but must not be described as new general descent theory.
