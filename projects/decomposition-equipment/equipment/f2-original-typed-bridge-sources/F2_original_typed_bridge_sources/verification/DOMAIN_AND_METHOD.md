# F2 original graph-cut certificate: exact domain and method

## Scope and reproducibility

Run `python3 verify_f2.py` in this directory (standard library only). Assertions are mandatory: `python3 -O verify_f2.py` raises before checking anything. `results.json` is deterministic; elapsed time appears only in the separate console/run log. This is finite computational evidence (C), not a kernel certificate, an all-degree proof, or independent acceptance. The companion all-degree proof instantiation is separate. No I4 claim is made.

The tested object is precisely the original ordered induced-graph cut object times the nerve of **[2]**, not the nerve of raw refinement and not a cluster quotient. In degree n the records consist of an ordered simple graph on v vertices, an arbitrary function [v] -> {1,...,n} (empty and noncontiguous blocks allowed), and a weakly increasing sequence a0,...,an in {0,1,2}. Actual category arrows are pairs (ai,aj); [2] has exactly six arrows and three objects. The arrow (0,2) is the composite of (0,1),(1,2). Degree zero forces v=0 and has three interface records.

Exhaustive bounds: v=0,1,2,3,4 and n=0,1,2,3,4. All monotone alpha:[m]->[n] with n,m<=4 are applied to every graph/partition record and independently compared to a block-set reference implementation. All composable pairs alpha:[m]->[n], beta:[l]->[m] with l,m,n<=4 are checked on every block-label atom and every [2] path. Identities are checked separately. This includes every face and degeneracy staying in the domain, constants and endpoint repetitions. Maps leaving the degree-four domain are not claimed exhaustively checked. There are 3,6,10,15,21 category paths in degrees 0,...,4.

## Why coordinate factorization and atom reduction are exhaustive equivalents

The two simplicial coordinates have no mutual constraint: category interfaces/arrows are independent of graph edges and partition labels. Each map acts coordinatewise. Equality of product maps is equivalent to equality of both coordinate maps. The triangle target matching conditions likewise separate into graph shared-edge equality and category shared-arrow equality, so the full target is literally the Cartesian product of the two tested target sets. The unit target also separates: graph selected block empty, category selected arrow identity. Thus no omitted graph/path interaction can falsify a tested equation or pullback; repeating every product pair would repeat already verified equations.

For geometry, a vertex with block label b survives alpha exactly when alpha(0)<b<=alpha(m), with its new block the unique j satisfying alpha(j-1)<b<=alpha(j). The exhaustive atom equation compares this partial label function under alpha then beta with that under alpha beta. For any graph, the resulting vertex subset is therefore identical in both orders. Every surviving vertex is renumbered by its increasing rank. Increasing enumerations compose, since rank in a subset of an increasing subset is rank in its composite subset. An edge survives iff both endpoints survive, and is sent to the pair of their ranks. Consequently the same atom equality proves the complete graph and partition composition equation for *every* graph, not just edgeless graphs. Full graph actions are additionally checked against an implementation based on explicit block sets and direct adjacency enumeration, independent of the atom implementation.

## Independent 2-Segal target enumeration

For every graph through four vertices and each triangulation of degrees 2,3,4 (respectively 1,2,5), `targets` starts with the root triangle adjoining the polygon's long edge. It enumerates **all binary partitions of the retained root graph**. Each of the other two edges is forced to be the induced graph on its actual block, and the procedure recursively enumerates all binary triangle records above that fixed induced edge. No global n-block partition is supplied to this enumerator. The polygon triangulation dual is a rooted tree, so these are exactly all matching triangle records: at the root every target supplies one of the enumerated binary partitions, and every child target independently supplies one of the recursive matching records. Cross-block root edges remain present in each retained node graph.

`reconstruct` independently lifts the recursively reconstructed subpartitions through the root block inclusions. Checks assert (1) every enumerated target maps back to itself after comparison, (2) no two targets reconstruct the same source, (3) the reconstructed set equals the separately enumerated full n-partition set, and (4) every source compares then reconstructs to itself. Category targets are independently enumerated via all root triangles a<=c<=b and matching child arrows, with the same uniqueness and completeness checks.

Pentagon transitions in this certificate are **common-global-normalization transitions**: reconstruct a full cut from one target, then restrict to the adjacent triangulation. The flip adjacency is computed from shared diagonals; all five transitions around the cycle return every independently enumerated graph target. This is not claimed as a separate local-quadrilateral implementation. The category transition cycle follows from the checked inverse identities (the intermediate comparison/reconstruction factors cancel). The all-degree theorem supplies their compatibility with local flips.

## Units, controls and six-vertex bridge

For every n=0,...,3 and every insertion position i=0,...,n, the target unit pullback is independently enumerated in degree n+1: precisely records with block i+1 empty and category ai=ai+1. Deleting that repeated boundary is inverse to the tested degeneracy. All graph counts and all category counts are recorded separately. Arbitrary empty-graph components with nonidentity [2] arrows are not units.

The ordinary Segal map loses cross edges: the two-vertex edge/no-edge pair with singleton blocks has equal principal pieces but distinct wholes. An outer face deletes that edge. A bad target with a mismatched shared-diagonal graph is rejected. A root-edge-forgetting mutation differs from the correct reconstruction.

The exact original C1 section 8 fixture is executed from `c1_reference.py`, a verbatim copy of the existing author's source. It verifies G with edges 01,12,13,24,34,45, partition {0},{1,3},{2,4},{5}, path 0->1->1->1->2, opposite binary refinements of the equal nonempty middle components, the two original distinct parenthesizations, and G+05 with equal leaves but distinct whole. It also executes its original independent label/matrix substitution checks and mutation controls. The main F2 verifier further checks all five degree-four triangulations and all bounded map-pair geometry compositions for both G and G+05. These six-vertex checks are selected mandatory fixtures, not enumeration of all six-vertex graphs.
