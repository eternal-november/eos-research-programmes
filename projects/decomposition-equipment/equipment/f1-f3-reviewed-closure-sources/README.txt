REPLAY

Python 3 and its standard library are sufficient. No network or external
repository is used. From the extracted archive root run:

    python3 replay.py

Do not use Python -O or PYTHONOPTIMIZE. The runner and every shipped verifier
reject disabled assertions. The runner executes the scripts in an isolated
temporary copy, leaves the frozen reference JSON files untouched, checks both
ordinary and environment-controlled optimized-mode rejection, and compares
all JSON fields and the exact reference bytes. It writes replay_results.json
at the archive root and prints the same deterministic result. There is no
elapsed-time field or timing-dependent stopping condition.

DOMAIN DISCLOSURE

The cluster graph tests enumerate all ordered contiguous-clique types through
four vertices and degrees 0 through 4, with actual occurrence-indexed partitions
and empty blocks. Graph and category coordinates are factorized. C2 x [1]
grade checks retain composability and endpoints, not independent arbitrary
arrow tuples. The supplemental six-vertex (3,2,1) fixture checks 800 degree-four
orbit fibres and 56,000 monotone-map comparisons, not every six-vertex graph.
The rewrite test is terminal-grade, four-vertex/four-initial-leaf bounded and
uses R, L, UL and UR, not all graded equations or B3 path coherence. Group
classification checks every subgroup through S4, recursively against literal
R/E on all graphs and four flags; its 7,872 candidate checks concern sizes
three and four. Full-erasure verification checks 76 graphs, three/four slots
and 32,513 proper-interval fibres. Finite counts overlap and are not a proof
of all degrees, all critical templates or the original F2 certificate.
