Publication and portability notes

The delivered proof mathematics is unchanged from the reviewed source
snapshots. Changes are exact, file-specific publication/reference edits;
there were no broad identifier, symbol or mathematical-expression replacements.
SOURCE_PROVENANCE.json records original and delivered SHA-256 hashes and the
edits for each imported file.

Three Python scripts originally inserted an absolute workspace directory into
sys.path. That single insertion was removed from reference_pipeline.py,
audit_dynamic_binding.py and audit_report_permutations.py. The imported
binding_checker.py is now a sibling file and resolves through ordinary local
Python imports. No algorithm or test body was changed. All shipped scripts
were replayed after this portability edit and again after ZIP extraction.

Proof/document references were made local to the package. Publication status
wording and internal background references were updated without changing
the mathematics. The implementation note refers to the separate deadline
obstruction proof and describes its final runtime/resource boundary.

The bounded baseline comparison predates the completed construction. Its
historical candidate-status remarks are retained, with a prominent note
pointing to the final theorem and assumptions delta. This does not turn its
limited literature check into a novelty survey.

REPORT.txt, mathematical_review.txt, README.txt and reproduce.py are package
documentation and reproduction material. REPLAY_RESULTS.txt records the
complete packaged-source replay; exact model results are supplied separately
as reference_pipeline_results.json. SHA256SUMS.txt covers every other file in
this source directory. The delivery-level manifest covers the separate TXT
report and the complete ZIP.

The release contains only the selected proofs, comparison, code, finite
checks, generated fixture results and documentation. It does not include
private background notes or the earlier source archive. Simulated hidden
truth in the JSON is expressly validation-only; the controller accepts the
documented public inputs, not those hidden fields.
