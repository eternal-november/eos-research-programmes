4 G2 EXACT RETAINED INFORMATION

4.1 Side-information theorem and allowed-code boundary

G2-P1. Fix any observation r:X->Y and deterministic supplement s:X->A. There
exists a decoder d on the image of (r,s) with d(r(x),s(x))=x for all x iff s
is injective on each fibre r^-1(y). Necessity: two distinct x with equal r
and s would require one decoder value to equal both. Sufficiency: each image
record has a unique preimage, which defines d. This is a genuine iff and does
not claim effective decoding for arbitrary infinite input classes.

For a finite fibre of size L, any such A has size at least L. A uniform
fixed-length b-bit supplement therefore needs b>=ceil(log2 L); take the
maximum L across allowed observations for a uniform bound. Conversely, where
the finite fibre has an explicit ordered enumeration, send its rank and decode
by unranking. This gives exactly ceil(log2 L) fixed-length bits, with unused
codewords rejected. These are zero-error finite-alphabet bounds, not claims
about expected code length, Shannon entropy or noisy recovery. They are
standard finite counting; the concrete content is the fibre classification
and a decoder not given the hidden original object.

4.2 Graph whole and witness bounds with executable decoders

G2-P2. In S1, partition all vertex pairs into I_B (within a block) and X_B
(between different blocks). The within-block observation fixes exactly the
I_B bits and leaves every X_B bit independent. C3 Theorem 2.1 gives the
bijection of EVERY fibre with P(X_B), not only an ambiguous pair. Therefore
q=sum_(i<j)|B_i||B_j| independent binary bits are necessary and sufficient.
Encode the cross-edge bit vector in lexicographic pair order. Decode each
pair {x,y}: if in different blocks read its bit; if in the same block locate
x,y in that block's increasing order and read the corresponding observed
H_i bit. This pairwise decoder equals C3's union-of-lifts inverse, but has a
different implementation and never receives G. Removing any selected bit
identifies the two records differing only on that edge, for any fixed H.
Thus this augmentation is not merely 'add the whole': it sends EXACTLY the
missing coordinate choices and meets an unrestricted deterministic-code lower
bound within the frozen observation class. If q=0, no supplement is necessary.

G2-P3. In S2, C3 Theorem 3.1 gives the full witness fibre

 disjoint union over B with |B_i|=n_i of P(X_B),
 L = m!/(product n_i!) * 2^q,  m=sum n_i, q=sum_(i<j)n_i*n_j.

It follows that ceil(log2 L) fixed-length supplemental bits are necessary and
sufficient. An exact enumeration orders the label words of length m with n_i
copies of block i lexicographically; these words specify B. Within each word,
order the q cross pairs lexicographically and enumerate their bit vectors
in binary numeric order with those fixed pair indices.
Rank is rank(B)*2^q+rank(C). Divide by 2^q to unrank B and C, apply the S1
decoder to p's H_i, compose the full grades to get the whole grade, and return
the complete witness with the supplied B. Enumerating valid label words can
be slow; no polynomial-time or optimal-runtime claim is made. The formula
handles empty blocks; k=0 forces m=0, giving one valid empty identity-graded
witness and zero required bits. The repeated-middle six-vertex example has
L=180*8192=1,474,560 and an optimal 21-bit fixed-length code. Separate field
encodings of 8 placement bits and 13 edge bits also attain 21 here. Indeed in
EVERY S2 instance q is an integer, so q+ceil(log2 |Part(n)|)=ceil(log2 L):
the separate placement/edge fixed-length fields attain the same sharp bound.

Deleting B fails even when C is retained: the two singleton-block cuts of the
same two-vertex edge have equal p and C={{0,1}} but opposite ordered B. The
fibre counts WITNESSES. It must not be relabelled a count of distinct wholes.
If only the whole is the target and blocks are unknown, some placements can
coincide; the theorem does not assert L as that different problem's minimum.

4.3 Semantic arrow bounds without confusing them with final operations

G2-P4. SEM section 2 proves, by explicit inverse maps, that in S3

 Hom_Ref(D_M)(a,b) = disjoint union over admissible lambda
                    { n in M^k : m_a * product n_i = m_b }.

Here lambda=(l_i) is the ordered segmentation of the target path into source
occurrence runs. It is admissible iff each run's target blocks union to the
actual source block, and its full subpath has the source slot's endpoints
and composite grade. A zero run requires an empty source graph and identity
grade. The tuple entry at i has the canonical pullbacks of that run's blocks,
that ENTIRE run path, whole equal to the original component at i, and n_i.
These formulas reconstruct the genuine tuple; nothing is keyed just by
component value. Reading lengths and scalars is the inverse. SEM (2.4) gives
composition entrywise, retaining nullary values even with no descendants.

For h=number of admissible lambda and t=number of scalar solutions, the exact
fixed-endpoint fibre has L=h*t. If L=0 there is no arrow to recover. If L>0,
G2-P1 gives ceil(log2 L) bits necessary and sufficient. Enumerate weak
compositions of target arity into k parts, retain admissible ones, and pair
lexicographically with scalar solutions; unrank and apply the displayed
pullback decoder. This is effective for finite K,M at fixed endpoints.
For k=0, only l=0 and m_a=m_b gives the singleton identity arrow; a false
empty-run convention is not used.

On the four-slot six-vertex source with M=Z/2 and a fixed target obtained by
splitting the middle slots, lambda=(1,2,2,1) is forced because all target
blocks are nonempty. With source and target values 0 the four scalar values
must sum to 0. There are 2^3=8 actual arrows with those endpoints. Three bits
suffice: retain n0,n1,n2 and infer n3=n0+n1+n2. Three bits are necessary.
In particular (0,0,0,0) and (0,1,1,0) cannot be recovered from the same final
operation even though the structural slot boundaries are unambiguous. This is
parallel-arrow nonthinness, not the unrelated fact that two raw trees evaluate
to one object. Nontrivial monoids may have other multiplication fibres; no
cancellation or group formula is assumed in the general result.
