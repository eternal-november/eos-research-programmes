INDEPENDENCE AND REPRESENTATION
The independent checker was written and first run successfully BEFORE reading
the author finite source. It imports neither the author implementation nor the
inherited model evaluators. It uses symmetric adjacency matrices and
vertex-to-block label vectors, in contrast to the author's undirected edge sets,
ordered ambient block tuples and rank maps. Its internal-edge reconstruction
computes local ranks from preceding vertex labels; cross bits are separate.

After initial independent execution I inspected the author source, DOMAIN.md,
certificate, and the proof's named fixtures. The final independent checker was
strengthened to test both recursive trees and encoding inverses throughout the
entire 8,192-member family, and its named relational fixture was aligned exactly
with the stable proof. This was not a theorem change or a failed test repair.
No author evaluator was imported during that update or comparison.

evaluator are genuinely different code paths, but I do not count these as
