3 B4 CORRECTNESS AND FLOOR

R1 preserves actual source constructors, primitive labels and edge components.
The leaf formula is an ordered, component-preserving correspondence, not a
count or a multiset equality. Constant-one primitive weight gives vertex
additivity and strict growth for nonidentity forests. Unary insertion can
leave frontier length unchanged and nullary insertion can decrease it, so
leaf-count monotonicity is correctly rejected. The decreasing direction for
the well-founded rank is reverse refinement; infinite forward growth is not
incorrectly ruled out.

The fixed-source reconstruction inverse reads the subtree of U at each leaf
address of T. I checked its induction, including a nullary source root. Its
labelled-prefix condition is independently defined and sufficient; forest
uniqueness is proved rather than assumed. Every raw fixed hom is therefore
thin, but categorical faithfulness of raw evaluation is not a recovery claim.

R2 correctly classifies every possible source/forest pair over a fixed final
raw U by an ancestor ideal of its internal vertices. Pruning at the first
omitted vertex yields a well-typed identity edge at that exact component;
the inverse forest is then forced. The two inverse laws recover primitive
labels as well as shape. The polynomial recurrence 1+z times the product of
the child polynomials and its nullary value 1+z are correct. This is an exact
finite source-forgetting fibre, not the tautology that injectivity permits
recovery. A prescribed source boundary filters the actual ideal enumeration.

R3 correctly identifies atomic chronological histories with linear extensions
of the added-vertex forest. The hook-length formula N!/product s(e) follows
by interleaving the child orders, and the singleton boundary is precisely a
chain of internal events, not necessarily a tree of unary primitives. The
adjacent-swap argument preserves typed execution legality. It forgets only
independent interleaving; an arbitrary macro schedule first requires atomic
expansion, as in the imported B1 theorem.

R4 imports and correctly reconstructs SEM's exact hom fibre. A length vector
partitions the entire target path into original-source occurrence runs. Actual
set unions, intermediate interfaces and actual arrow composites constrain
those runs. Increasing enumerations force each child's partition, leaving
only the individual scalar values subject to the endpoint multiplication
equation. Empty runs require empty identity-graded components and keep their
own scalar values. Composition retains the same original slot data. This is
not an object-only quotient and needs no cancellation assumption. Its finite
cardinality claim is for fixed endpoints a,b, not all sources of one final
semantic operation.

The group and idempotent examples obey the formula, including the separate
k=0 case. The raw d_1-chain family correctly shows that a canonical semantic
normal form does not reconstruct the originally chosen raw presentation.
Raw vertex count does not descend across C5's D0 equation; the manuscript
now says exactly which equation-invariance premise is needed for a weight to
descend. No source, final tree, evaluated operation, forest and chronology
are silently identified.

R5 provides effective ideal/extension/tuple enumeration and inverse decoding,
with exact fixed-length code bounds at each declared observation. This is
direct support for G2. B4's original P-plus-L, classification, unary/nullary,
repeated-occurrence and multiple-schedule requirements are all covered.

5 G2 CORRECTNESS AND FLOOR

Targets and allowed observations are fixed before the new tests: anchored
whole graphs; total unanchored cut witnesses; fixed-endpoint semantic arrows;
and B4's separate raw-source/history records. Supplements are deterministic
finite messages, with exact zero-error and fixed-length assumptions for the
bit bounds. These are not all-context minima, Shannon entropy claims or noisy
recovery guarantees.

C3's anchored fibre is exactly the powerset of missing cross pairs, so q bits
are both sufficient and necessary. The independent pairwise decoder sees
only anchors, induced local graphs and cross bits, never the hidden whole.
The unanchored witness fibre is a disjoint union over placements and has
multinomial(n_i) times 2^q elements. It counts witnesses, not distinct wholes.
The placement/cross-bit rank decoder is valid, including empty blocks and
the unique admissible k=0 case. Because the edge factor is exactly 2^q,
separate placement and edge fields also attain the joint fixed-length bound.
The final text corrects an earlier overgeneral caveat about separate ceilings.

For semantic arrows, the SEM inverse uses full run profiles and local scalar
values, not equal component labels. The fixed six-vertex Z/2 example has eight
parallel arrows and exactly three missing scalar bits. It remains distinct
from raw object collapse and from chronology. For a finite observation fibre
of L targets, pigeonhole necessity and explicit ordered unranking prove the
ceiling(log2 L) bound. The empty fibre is an inconsistent arrow claim, not
an object awaiting recovery.

The code's encoder and decoder are different constructions. JSON roundtrips
remove object-reference channels; the decoder evaluates each ambient pair
from the record, while the encoder restricts and lifts coordinates. My own
separate implementation also verifies the graph inverse and complete small
unanchored fibre counts without importing author functions. This satisfies
the independent decoder test without pretending finite tests prove all sizes.

The original G2 classification branch and exact-family/lower-bound floor pass.
Adding the entire unknown object has not been used as a vacuous repair: the
records contain only the classified missing coordinates and achieve the sharp
number of distinguishable supplemental messages for the frozen targets.
