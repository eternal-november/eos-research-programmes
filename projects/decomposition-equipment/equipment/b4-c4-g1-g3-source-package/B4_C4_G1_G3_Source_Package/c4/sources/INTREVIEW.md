## 2. Independent reconstruction of the central proof

### 2.1 The category is genuinely syntactic

Objects remain raw trees. Directed edges are primitive insertions at current
external occurrences; only equation edges receive formal inverses. Rcat
identifies raw histories of the same forest using the inherited chronology
theorem. O, MOut and the seven bare MIn templates are specified before the
semantic functor is introduced. Their instances are decidably typed and
recursively enumerable for fixed finite parameter tables. No equality of
semantic images, arbitrary forest equivalence, or full/faithful hypothesis
occurs in the definition of the path quotient.

The distinction between zero primitive vertices and a primitive nullary is
preserved. Equation addresses and variable substitutions are actual data;
proofs transporting equal component/profile types are not new arrows.

### 2.2 Ordinary coherence really follows from the displayed basis

I manually followed both words in each of the 18 rows. Every word reaches the
stated common target. Row 6 uses commutativity to identify nm with mn; row 13
uses associativity; the rotation rows use the same lifted partitions and
full arrow strings, not cancellation or guessed factors. Unit rows can delete
only the displayed u at an empty/identity input, never an external empty leaf.

The peak classification is exhaustive: the only nonvariable nested heads are
the left cut of R, the inner decorator of DA, and the decorator children of
DL/DR. Remaining nested occurrences lie inside a once-retained variable;
disjoint occurrences commute. Degenerate parameter coincidences may make
some paths identical but introduce no additional unclassified peak.

The induction is on a genuinely decreasing contextual term measure. For two
normalization paths, each first reduct is strictly smaller than the source,
so the induction legitimately identifies its tail with the corresponding
local joining path followed by normalization. Consequently
`nu_t = e ; nu_u`; inversion and cancellation give every equation zigzag as
`nu_t ; inverse(nu_u)`. This is path coherence, not an invalid inference from
common normal-form objects alone.

### 2.3 The high-risk bare-to-general MIn step is valid

For an entry `C[l[sigma]]`, replace the redex by one identity leaf. This gives
a genuine prefix forest F0 and a distinguished descendant leaf j of T[F0].
The original insertion factors as F0, the bare l insertion at j, then sigma
at l's variable leaves. The r-side has exactly the same variable frontier.
MOut moves the bare equation past sigma; bare MIn then replaces the l
insertion followed by that equation with the r insertion. Raw composition
reassembles the desired F'. This proves the contextual instantiated law
without assuming it. It also covers RHS identity leaves, nullary substituted
variables, empty contexts, and other entries already containing arbitrary
material. An empty original frontier has no entry to change and is vacuous.

MOut extends from elementary corollas to arbitrary forests by their finite
B1 histories. A nullary insertion removes the same external position on both
sides. There is never an external position inside a primitive u. Inverse

### 2.4 Arrow normalization, fullness, and faithfulness are not circular

Scanning a finite mixed word moves its equation part past each next graft,
using MOut, and composes the resulting forests. MIn then normalizes each
original forest entry; O determines the remaining equation path uniquely.
Thus a path from T to U is represented by a full original-slot tuple of normal
terms plus the specified terminal normalization zigzag.

The functor to Ref(Q) is sound on all defining relations: equation edges have
identity tuples, MOut preserves the same insertion tuple, and MIn changes
one entry by an actual declared equation. Equality of full semantic tuples
then reflects equality of normal entries by inherited object completeness.
Conversely identical entries give identical canonical paths. No cancellation
of T or of monoid values is invoked.

For a given semantic arrow, canonical representatives of its individual
entries produce a raw forest; its endpoint equation guarantees the terminal
pure-equation path. This proves fullness rather than assumes a lifting
property. Objects are not artificially identified: Comp is equivalent to the
semantic category, while its full irreducible-object subcategory is actually
isomorphic. The section's identities, composition and natural comparison
are justified after the hom theorem; the subsequent use of faithfulness is
therefore legitimate.

The finite-word equality algorithm is also valid. Equation steps preserve
frontier order; the current descendant of an original slot is located using
entry lengths, never component lookup. Zero-length entries persist as entries
although they have no descendant to receive a later graft. Term normalization
terminates, and no unbounded equation-path search is required.

Composition sums descendant run lengths and uses

normalization; the proof correctly supplies a normalization isomorphism
instead of claiming literal preservation of normal syntax. Its naturality

For an interval factorization, equality of the final retained partition
