REPRODUCE

Use Python 3 and the standard library; this package was tested with Python
3.12. No packages, credentials,
network connection, absolute workspace paths, or other archives are needed.
Unzip into a writable directory, then run from the extracted package root:

    python3 replay.py

The runner verifies every MANIFEST.sha256 entry, runs the two finite suites,
byte-compares their generated JSON with the pinned reference results, and
runs the independent public-decoder isolation check. It writes generated
results alongside the scripts without changing the pinned reference files.
The full enriched JSON deliberately retains every finite raw fixture.

Individual scripts can also be run directly:

    python3 scripts/verify_priority_cylinder.py
    python3 scripts/verify_observable_enrichment.py
    python3 scripts/verify_observable_decoder_isolation.py

Run the enrichment script before its isolation checker, which reads the
freshly generated scripts/observable_enrichment_results.json. The three
observable_reference files are local relative imports of the prior pipeline.

to their original relative source names and SHA-256 hashes. MANIFEST.sha256
covers every shipped file other than itself. The package's outside digest is
provided separately with the deliverables; a self-digest cannot be embedded.

INTERPRETATION

Finite regression checks corroborate the stated finite instance; the general
claims depend on the supplied proofs and explicit physical premises. Timing
allowances are supplied tick bounds, not Python benchmarks or measurements
of a physical device. Harness choices of lawful bit realizations are test
oracle witnesses, never controller powers to set uncontrollable payloads.

The nonempty singleton physical preparation profile has a two-element formal
middle. Its information remains in labelled test legs; this is not a compact
encoding promise. The eight/six/eight counts concern conditional sections
and their combined-test presentation, not physical control over bit words.
