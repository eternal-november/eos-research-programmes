1  Findings and scope

The shared priority scheduler has an explicit two sided cylinder realization
when its primitive constraints retain one common assignment of jobs to ranks.
This applies the existing Boolean complete module wiring theorem; it is not a
new generic categorical result.

The bridge gives sound assurance K_E subseteq K_P, equality in a full record
fixture, and an honest same cylinder comparison X_N <- U_N ->> M_P. A nonempty
singleton K_P(b) certifies the command; existential possibility does not.

The four job example proves strict loss from splitting joint rank witnesses.
Its conditional middles have 8 exact, 6 relaxed and 8 combined elements. The
actual singleton preparation profiles instead have middles of size 2. Raw
observations do not expose latent role response y. A distinct, paid diagnostic
protocol DOES realize executable response tests under a new fixed budget; it
does not retroactively add tests to the old tight protocol.

Boolean support means possibility, not probability or causal dynamics.
Physical premises remain supplied. Full proofs accompany this report.

Empty/drained start, reliable counts and a closed horizon give one actual job

vacuous success. Work invariance, FIFO, arbitration, persistence, safe

    V_a(sigma,b)=XOR_(k:rho(sigma_k)=a) b_k,
    K_P(b,y)=1 iff some sigma in LE(P) has y=V(sigma,b).        (1)

The physical bridge identifies the required command with V(pi,b). Three
profiles must remain distinct.

3  The operational singleton certificate

For incomparable x,y set a_xy=|Pred(x) union Pred(y)|+1 and z_xy=n-|Succ(x)
union Succ(y)|-1. The operational theorem proves

    K_P(b) is singleton iff every incomparable cross role pair x,y
    has b_k=b_(k+1) for all k in [a_xy,z_xy].                  (2)

Exactly those ranks admit x,y consecutively in either order. Their swap
changes V by (b_k XOR b_(k+1))(e_(rho(x))+e_(rho(y))). Connectivity of linear
extensions by such swaps proves the criterion. A passing test evaluates any
one topological order. A failing test gives poset witnesses, not automatically
physical full record witnesses. The algorithm uses O(n^3) elementary
operations and polynomial storage, not a guaranteed hardware latency. Every
word passes exactly when all incomparable pairs have the same role.


4  Primitive joint constraints and their common witness

Introduce one hidden rank x_j in {1,...,n} per job. Equality wires copy the
SAME x_j to all occurrences. The finite Boolean primitives are

    D(x_i,x_j)=[x_i!=x_j]             for each unordered pair,
    C(x_i,x_j)=[x_i<x_j]              for each generating edge i<j of P,
    S(x_j,b,c_j)=[c_j=b_(x_j)]        for each job,

and one XOR chain per role over its c_j values, initialized at 0 and ending at
y_a. Empty role chains end at 0. Chain states, constants, terminal conditions
and all copy ports have their declared equality couplings. There is ONE shared
b vector, not separately chosen copies.

Each factor is its FULL joint relation, with explicit copy/equality couplings.
Hidden full support sources may be included. This is finite typed constraint
semantics, not controller access to latent ranks or a causal implementation.

For complete internal assignment z, including rank, selector, chain and copy
values, the contraction is

    K_N(b,y)=OR_z AND_v F_v(local values from b,y,z).           (3)

A satisfying z gives a bijection by D, sigma in LE(P) by C, and y=V(sigma,b)
by selectors/chains. Conversely sigma and b determine a satisfying assignment.
Thus K_N=K_P in both directions.

At every cut the same assignment must satisfy both sides. Eliminate a variable
only after joining ALL factors mentioning it, retaining the full remaining
joint boundary relation. Independent per port projections need not preserve
(3).

Sound local comparison records P_i and cross comparisons E_cross combine as
P=transitive_closure((union_i P_i) union E_cross), on one global rank
assignment. Regrouping records does not create independent per group
priorities or extra server capacity.


5  Explicit carrier legs and canonical comparison

Boolean complete modules are complete join semilattices with join preserving
maps; free modules are 2^A. Surjective/injective image factorization induces
the cylinder factorization system with generating/separating legs.

For phi:A x T->2, the discrete cylinder has object 2 at each preparation/test
and entry multiplication by phi(a,t). Its canonical middle is

    M_phi=image(phi_!:2^A->2^T),
    (phi_! lambda)(t)=OR_a lambda(a) AND phi(a,t),
    alpha_phi(a)=phi(a,-),       beta_phi(t)(s)=s(t).           (4)

Thus M_phi is the union closure of rows, including bottom. Alpha generates;
beta jointly separates. It is not Set's bare row set or an Isbell fixed point
lattice. Formal unions need not be physical preparations.

Let M_v be (4) for each primitive F_v, with its labelled alpha_v,beta_v.
Orient external b as input and y as output, and let Z be complete internal
assignments. The existing module theorem gives the actual carrier

    X_N=direct_sum_(z in Z) tensor_v M_v,

    e_N(b)=join_z i_z(tensor_v alpha_v(in_v(b,z))),
    q_N(y)(i_z(tensor_v m_v))
          =AND_v beta_v(out_v(y,z))(m_v).                     (5)

Separate join preservation extends the tests through tensor/coproduct. Both
legs use the SAME z summand, so

    q_N(y)(e_N(b))=OR_z AND_v F_v(...)=K_P(b,y).              (6)

This derived scalar identity makes X_N an HONEST realization of this cylinder.
Let U_N be the join submodule generated by e_N(b). Evaluation has image
M_P=image((K_P)_!:2^B->2^Y), giving

    X_N  <-- injective --  U_N  -- surjective -->  M_P.       (7)

Inclusion and evaluation both preserve all b preparation and y test labels;
the right map sends e_N(b) to K_P(b,-). The mono is left and epi right.
Existence is supplied by the established module theorem. No raw carrier is
enumerated or claimed small; the certificate tests rows without building it.

For the actual single preparation split, use the bit support sources and joint
output (b,y). Its middle is image(2->2^(B x Y)). If nonempty, it consists only
of bottom and the entire support row: size 2. Labelled tests still record
every incidence, potentially with a large description. Fibers conditioned on b
recover K_P; this does not identify the two factorizations or turn
conditioning into physical control.


6  Normalized wiring coherence

Regroup the SAME factors while retaining every exposed shared value. Expanding

subnetworks but retain each COMPLETE joint boundary kernel. Serial contraction

Identity insertion may enlarge raw X_N; only its normalized middle is

8  Rank witness splitting and the conditional middle comparison

Take jobs 0,1,2,3, roles A,B,A,B, P={0<3,1<2} and b=0011. The six extensions

    (0,1,2,3)  (0,1,3,2)  (0,3,1,2)
    (1,0,2,3)  (1,0,3,2)  (1,2,0,3)

all give 11. Their job wise rank projections are {1,2,3} for jobs 0,1 and
{2,3,4} for jobs 2,3. The product of those sets, still with distinct ranks,
admits x=(1,3,2,4), order (0,2,1,3), violating 1<2 and giving 00. There are 8
relaxed bijections and the relaxed response fiber is {00,11}.

Each false coordinate has its own legal rank witness:

    x_0=1: (1,2,3,4)       x_1=3: (1,3,4,2)
    x_2=2: (3,1,2,4)       x_3=4: (1,2,3,4).

There is no common legal witness for the tuple. This is splitting at the
INTERNAL JOB RANK boundary, not at the final role outputs: both exact role
marginals are already singleton 1. Retaining the precedence factors or an
equivalent full joint boundary relation repairs the error without new sensors.

Write u={00}, v={11}, O={01,10}, T=u union v. Exact rows are u at weights
zero/four, O at odd weights, v at 0011 and 1100, and T at other weight two
words. The relaxed rows only replace those v rows by T. Thus

    M_A={empty,u,v,T,O,u union O,v union O,T union O},
    M_B={empty,u,T,O,u union O,T union O}.                     (9)

The legs are the labelled rows and response membership tests. The join map
f:M_A->M_B defined by f(u)=u, f(v)=T, f(O)=O is surjective, preparation
preserving and extensive. It is test order lax, NOT test preserving:
evaluation at 00 changes from 0 on v to 1 on f(v).

No reverse preparation compatible function exists: relaxed T occurs where the
exact row is v and also where it is T. Inclusion M_B->M_A preserves joins and
tests but not preparation labels. No map in either direction preserves BOTH
preparations and tests, since that would equate the differing scalar entry
(0011,00).

The union closure C of paired rows is the 8 element graph of f. Its
projections give a surjective/surjective span M_A<-C->M_B, with left
projection an isomorphism. It carries TWO test families, beta_A(y) pi_A and
beta_B(y) pi_B, which disagree at the witness entry. It is not a same test
comparison and must not be identified with (7).

The 8/6/8 counts concern conditional sections only. Each nonempty actual
singleton preparation assurance or observation profile has middle size 2. The
test labels, not the small abstract carrier alone, retain their meaning.


9  Raw observation loss and universal policy variance

Let A_E:{p0}->B x Y have support K_E. The declared forgetting kernel

    F((b,y),b')=[b=b']

gives F A_E(p0,b)=OR_y K_E(b,y)=O_E(b). It discards a latent annotation; it
does not read it using an unprovided sensor. Its module direct image is

    F_!:2^(B x Y)->2^B,
    S |-> {b: some y has (b,y) in S}.                          (10)

It maps assurance onto observation. With one nonempty preparation both have
size 2; the abstract module isomorphism is NOT a decorated equivalence. The
pulled back b test is OR_y of response tests, not an individual (b,y) test.

Raw b cannot generally determine y. With local only evidence, priorities
(0,1,2,3) and (0,2,1,3), roles ABAB and word 0011 have the same productive
timing/word but responses 11 and 00. This comparison does NOT reuse the

Nor is the productive role word quotient stable under all existing contexts.
For rho(x)=rho(y)=A, rho(z)=B, priorities (x,z,y) and (y,z,x) both have role

For an admitted b, command delta(b) is justified precisely when

    K_E(b) is nonempty and K_E(b) subseteq {delta(b)}.         (11)
