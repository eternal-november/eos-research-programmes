# Independent finite verification: priority-cylinder bridge

31 October 2026. Reproduce with `python verify_priority_cylinder.py`; results are written to `verification_results.json`. All assertions passed. This is a finite check of the named example and certificate implementation, not a new general theorem or an empirical test of the physical assumptions.

## Primitive computation, not a supplied global table

The checker constructs six pairwise all-different factors on ranks r0,...,r3 in {1,2,3,4}, the factors r0<r3 and r1<r2, four selector relations ci=b[ri], and the two role XOR factors c0 XOR c2=yA, c1 XOR c3=yB. A two-input XOR is a length-two XOR chain with initial state zero; its unique internal state is substituted. Shared variable names implement equality wires, not independent existential choices.

For all 16 observed words and all four response tests, direct enumeration of all 4^4 rank tuples agrees with three relational variable-elimination orders: selector values first; reverse ranks first; and interleaved rank/selector values. Each elimination joins **every** factor mentioning its variable before projecting it. It therefore retains the exact joint relation across a cut. All 192 segmented evaluations agree with the separately enumerated six linear extensions.

The checker is allowed to condition on b as an externally supplied observation. This does not make uncontrollable productive bits an available physical preparation. A fixed preparation with external joint response (b,y) is a different cylinder and has a different image middle.

## Explicit conditional-section middles and legs

Let 0 denote response 00, 1 denote response 11, and O denote the response set {01,10}. These are response labels, not Boolean scalar zero and one. The exact middle A consists of the eight unions of the three disjoint sets {00}, {11}, O. The marginal middle B is the six-element submodule

    empty, {00}, {00,11}, O, {00} union O, {00,11} union O.

Both use union as join. For every b,

    alpha_A(b)=exact support at b,
    alpha_B(b)=marginal support at b,
    beta_A(y)(s)=[y in s],  beta_B(y)(t)=[y in t].

The JSON lists all 16 labelled rows, and all elements of both middles. These families generate their middles and coordinate membership tests separate them.

Define q:A→B by extending by unions

    {00} |-> {00},   {11} |-> {00,11},   O |-> O.

The finite checks verify bottom preservation, binary joins (hence all joins for these finite modules), surjectivity, and q alpha_A=alpha_B. Moreover s⊆q(s), so beta_A(y)(s)≤beta_B(y)(q(s)): q is order-lax on tests, **not** test-preserving. At b=0011 the exact row is {11}; the marginal row is {00,11}. The y=00 scalar changes from 0 to 1.

Inclusion i:B→A preserves all joins and all labelled tests. It fails preparation compatibility at the same b. Thus neither the existence of q nor that of i gives a map preserving both decorations. Any such map in either direction would force equality of the two scalar kernels, contradicted by this entry.

## What the combined-test E/E span does and does not say

Take the union-closure C of paired rows (alpha_A(b),alpha_B(b)) in A×B, with componentwise union. It has eight elements, precisely the graph {(s,q(s)):s∈A}. Its two projections are surjective join maps, giving A←C→B. The A-projection is an isomorphism; the B-projection is q under that identification. Both preserve their respective preparation labels and their own corresponding coordinate test family.

C carries **two** test families, beta_A(y)pi_A and beta_B(y)pi_B. They differ at the witness entry. An E/E span formed this way is not a same-cylinder decorated comparison: there is no single shared y-test family preserved by both legs. Do not identify it with the honest-realization normalization below.

## Honest comparison and its justified symbolic description

The finite factor computation establishes the scalar identity required to instantiate the already-proved witness-indexed construction:

    X = direct_sum_z tensor_v M_v,
    e(b) = join_z i_z(tensor_v alpha_v(in_v(b,z))),
    t_y(i_z(tensor_v m_v)) = AND_v beta_v(out_v(y,z))(m_v).

The SAME complete assignment z occurs in both legs. Thus t_y(e(b))=K(b,y), exactly the 64 cells checked above. Let U be the join-submodule generated by the e(b). Inclusion U→X is injective; evaluation U→A has image all of A, since it sends e(b) to alpha_A(b). The resulting honest comparison is

    X ← U ↠ A,

with mono left and epi right. The script does not enumerate the enormous raw tensor/coproduct carrier or claim to do so. Existence, linear extension, and comparison orientation come from the named Boolean-module theorem; the independently checked premise here is the actual primitive scalar contraction. Changing factor grouping preserves its common witness. Identity insertion need not preserve raw X.

For the actual singleton-preparation profile, the support is the nonempty set {(b,y):y∈alpha_A(b)}. Its row-generated module has only bottom and that entire support (two elements), not eight. Conditional sections recover the checked rows, but this does not identify the two CFS factorizations.

## Witness-splitting failure, stated at the correct cut

The marginal job-rank sets are {1,2,3}, {1,2,3}, {2,3,4}, {2,3,4}. Their independent product, still constrained by all-different, contains r=(1,3,2,4). This gives order (0,2,1,3), violates 1<2, and yields response 00 at b=0011. Each coordinate ri has a legal extension witnessing it independently; the JSON records one such legal rank vector per job. No common legal extension realizes the entire tuple. Hence replacing the joint rank relation by its unary projections creates the false scalar entry.

Do not describe this particular failure as independently choosing a witness for each final role output: the exact role marginals at 0011 are both singleton 1, and their product remains {11}. The damaging projection is at the internal job-rank boundary.

## Polynomial certificate verification

The checker implements transitive closure, cycle rejection, predecessor/successor sets, and a prefix sum of adjacent bit transitions. For each incomparable cross-role pair it tests the exact interval [|Pred(i) union Pred(j)|+1, n-|Succ(i) union Succ(j)|-1]. It uses polynomial space/time and never constructs a module to decide a row's singleton property.

Its answer agrees with exhaustive linear-extension singleton checking on all 219 labelled four-job posets, with roles ABAB, for every one of the 16 words: **3,504 comparisons**. A cyclic input returns INCONSISTENT rather than vacuous PASS. This finite regression is not a substitute for the general proof in the operational source.
