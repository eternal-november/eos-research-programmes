I5 simultaneous repair of witnessed decompositions
31 October 2026

The main finding

Fixing an abstraction for substitution can leave it wrong about cuts. Fixing its cut observations can, in turn, make it wrong about substitution again. The issue is not lost information being deleted: each repair adds distinctions. The problem is that those new distinctions create new obligations for operations that were previously adequate.

The selected I5 package identifies the least information needed to satisfy substitution, joint cuts and the permitted interface change together. For one growing family, every added branch label is necessary. For a contrasting finite-group family, substantial compression survives and one transport pass suffices. Both conclusions concern the same kind of genuinely shared-parent cut, not independently chosen marginal witnesses.

Status: independent mathematical and obligation-coverage reviews pass the selected package. The original I5 outputs are supplied for the specified graph-linked witness enrichment and Boolean joint-cut observation doctrine, relative to the precisely named original graph-spine presentation. This does not close unrestricted I1/I4 or the whole completion contract.

The precise guarantee

Fix N >= 2 and k >= 4. Start with the ordered graph-C5 calculus, with terminal original scalar and its actual full profiles. Keep every old operation, graph, ordered occurrence, interface path and old witness exactly observable. Add two-channel labels from L = M_k x M_k to nonempty input occurrences; empty inputs receive no added label. The transformation monoid M_k has 3k - 2 elements. Initially observe only whether each first local channel belongs to H = {e,b,b²}. The permitted transport is actual channel-frame exchange.

For these observations, the coarsest typed refinement complete for substitution, Boolean joint-cut experiments and that transport retains the entire ordered active-label tuple. Over each fixed old record with r nonempty inputs, it has exactly

    (3k - 2)^(2r) classes.

The optimum is taken among ALL profilewise partitions, including nonuniform partitions and partitions correlating different inputs. It is not obtained by restricting admissible abstractions to products or full-state representations. Full label retention is the conclusion of distinguishing tests.

The experiment language contains initial observations, Boolean combinations, context and transport pullbacks, and existential joint-cut tests. It preserves their truth, not witness counts, unique lifting, a chosen concrete witness, isotropy or universal endpoint recovery. Physical access to the labels is a separate requirement.

Why joint cuts matter

Under substitution, a parent label a_i multiplies into each nonempty descendant. A cut therefore solves

    x_j = a_i b_j

with ONE a_i shared across its group. Asking whether every child can separately find some parent is a different, weaker question.

A concrete M_4 example compares two-leaf labels (A_1,A_1) and (A_1,B_1). Their coordinatewise cut-repaired indices agree. Require one parent of index 1 and both children of index 0. The first source has a witness; the second does not. The eligible parent for A_1 is A_1, whereas the eligible parent for B_1 is B_1. Separate marginal tests succeed but cannot select one common parent. Finite verification likewise finds a rank-two cut partition strictly finer than the product of the unary index partitions. That computation illustrates the obstruction; the theorem does not depend on extrapolating it.

The three repairs and their interaction

S, C and T are input-relative saturated repairs: each is the coarsest refinement of its current input stable under, respectively, substitution contexts, joint cuts or declared transport. More information means a smaller equivalence relation. A one-pass composition of saturated repairs is not one elementary partition-splitting round. Separate global repairs exist even across infinitely many profiles: each fixed-skeleton cut has finitely many candidate label records, so equality of all finite experiment truths gives a stable least refinement. This existence argument alone supplies no finite global algorithm.

For S/C commutation, the structural criterion compares actual joint records after every relevant context test. One matching record must satisfy all factor tests simultaneously. A separate witness for each test is insufficient. The opposite order must also preserve the repaired cut-theory classes under actual context generators. These synchronized-witness and context gates are effective on finite systems with a certified representation; they are not a compact classification of every infinite profile system.

Three distinctions are established. S and T commute globally for the declared channel action because exchange conjugates branch contexts. C and T commute at the specified channel-product seed, using nonempty independent channel cut fibres over the same old skeleton. This is NOT global C/T commutation for arbitrary correlated partitions: equivariance alone does not provide a single compatible witness. S and C genuinely fail to commute throughout the M_k family.

The growing analytic family

Use transformation composition fg = f composed with g on {0,...,k-1}, with

    a = (k-1,1,1,2,...,k-2),    b = (1,2,1,...,1).

Writing t = k-1, the normal forms are A_i = a^i and B_i = ba^i for 0 <= i <= t, and D_i = b²a^i for 0 <= i <= t-2. Their multiplication is proved analytically from the actual transformations.

Membership in H is a multiplication congruence, so the starting observation is already S-complete, including branching grafts. Unary cut repair yields the index partition Q, where A_i, B_i and D_i have index i. But e and b have the same index, whereas ae = a has index 1 and ab = A_t has index t. Thus cut repair introduces a distinction that a legal substitution can expose. S after C differs from C after S for every k >= 4.

The simultaneous endpoint is proved, not guessed from this first failure. Cut tests force all indices. Left multiplication by a isolates A_1. The cut query “has left factor A_1” separates the constants A_t and B_t. Right multiplication by b and ab separates the remaining pairs. Every S/C-stable refinement is therefore discrete on M_k.

For the natural elementary cut splitter, the exact number of strict rounds is

    R(k) = max(2, ceil(log2(k-2))).

The residual index threshold doubles each round. This is an unbounded logarithmic necessity result for that specified algorithm, not a lower bound on all algorithms or on saturated-repair alternation. The saturated scalar schedule C, S, C, S already reaches discreteness.

Why unbounded profiles are covered

A bound on graph vertices does not bound empty inputs, profile arity or unary depth. These remain actual typed data, not erased positions. Nevertheless r <= N bounds the number of active labels. Elementary cuts have finitely many active grouping patterns: 2^(r-1) when r > 0. Each pattern retains its exact old feasibility guard. Induction covers arbitrary generated planar cut trees and contexts; it does not silently include crossing cuts or extra unrecorded cross-sibling constraints.

Finite templates alone would not establish the coarsest partition across infinitely many old profiles. The stronger coordinate argument supplies necessity at EVERY old record. Labelled unary identities implement right multiplication at an input and left multiplication above the output. The actual cut into an outer operation and unary identities exposes any chosen coordinate factorization; unit factors complete the other coordinates. Projecting the entire joint signature therefore recovers the scalar distinguishing tests without assuming the global partition is a product.

Transport makes both channels observable. Scalar discreteness then forces complete labels at every coordinate. The resulting discrete fibre is stable under every permitted guarded operation, supplying sufficiency. The same stagewise argument gives a uniform upper bound of R(k)+4 combined elementary rounds across all full profiles when every label is an allowed elementary multiplier; generator-only a,b contexts in BOTH channels give the conservative R(k)+5 convention. Neither bound is asserted exact.

A genuinely compressed positive case

Replace M_k by a finite group G with a proper nontrivial normal subgroup J and initially observe the first channel modulo J. Substitution and joint cuts already preserve this observation. Transport adds the second coset observation, after which all three requirements hold.

For a grouped cut, keep one parent representative a_i and solve every child as b'_j = a_i^(-1)x'_j. All child cosets match simultaneously. This is the shared-parent lifting argument that marginal reasoning would miss.

For G = C4 and J = {0,2}, one transport pass records both parities. At rank r it retains 4^r classes from 16^r concrete label tuples. Exact joint-cut completeness therefore does not universally demand full-state recovery.

When local repairs combine

The modular positive theorem uses actual conservative coefficient comparisons over a shared graph/interface presentation. For two channels A and B, global coefficients are A x B. Local cuts glue at a fixed global source precisely over the SAME retained old cut skeleton. Unit internal labels and the prescribed source labels at leaves provide fixed-source lifts. These facts prove global optimality, not just completeness of a candidate product.

The scoped presentation and certificate lemma additionally handles mixed coefficient interchange and occurrence-indexed refinement forests. Global retained certificates project to local ones; compatible local forests pair back to a global certificate. This remains relative to the old graph-spine presentation and its retained-certificate doctrine, not an unrestricted pushout or rewriting theorem.

Symmetric M_k observations combine successfully, including exchange. Asymmetric local observations fail: observing H on A but nothing on B identifies (e,e) and (e,a), while exchange exposes their difference. This failure occurs in the principal family for arbitrary permitted N.

A stronger shared-coefficient comparison uses A x K and K x B. Exact observation of the shared K-labelled cut record makes local matches glue. An explicit eight-element K shows why forgetting it can fail: two locally complete observations match one cut using incompatible shared factors. That stronger counterexample is proved only at N = 1. Its coordinatewise extension is not locally cut-complete at N = 2, so it is not promoted to the principal branching case.

Costs and evidence

The class count requires at least ceil(2r log2(3k-2)) bits for an injective fixed-length label encoding. A tuple representation avoids enumerating the exponentially many states; it does not eliminate their information requirement. With p = |L|, an explicit-table scalar certificate uses O(p^4) table or word-RAM accesses with O(log p)-bit indices, and O(p^3) signature bits. Charging indexed operations by their word bit length gives a conservative O(p^4 log p) accounting bound, not a hardware-independent bit-Turing theorem. Processing a concrete record also requires reading its old data, whose size is not bounded by N alone.

These are distinct quantities: necessary state count, encoding length, algorithmic work, working memory and physical information acquisition. None implies the others automatically.

Independent executable checks reconstruct transformation products, exercise finite typed label templates, verify shared-parent failures and proper-group controls, and test the modular boundary. They support the analytic proofs. They do not enumerate all old profiles or prove the all-k, arbitrary-depth results by finite sampling.
