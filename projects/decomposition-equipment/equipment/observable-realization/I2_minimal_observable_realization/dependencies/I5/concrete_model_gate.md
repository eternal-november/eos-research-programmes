# Graph-linked two-channel witness refinement scope

31 October 2026. Mathematical scope specification. The theorem and its supporting proofs supply the results at this declared scope.

## A. Data fixed independently of repair

Parameters: graph bound N>=2; finite category K for the original C5 grade/interface data; terminal original scalar monoid {1} for the principal theorem (retaining nontrivial old scalars is a separate extension); finite monoid M. For noncommutation/necessity tests choose the explicitly presented transformation monoid M_k, k>=4. Let L=M×M.

Take two copies, indexed by frame f in {0,1}, of the selected original ordered graph-C5 semantic calculus. Original interfaces are `(A,f)`; original arrows are `(u,f)` with u in K. A full operation profile retains frame, all actual ordered input components, output component, complete grade path and outer interface data, including every empty and repeated occurrence. An operation must be in one frame. The frame change `tau:(A,f)->(A,1-f)` is a specified action on the parameter/interface category, not an unannounced internal old arrow.

For an original operation with ordered graph blocks pi=(U_1,...,U_n), let `Act(pi)={i:U_i nonempty}`. Adjoin a label `ell_i=(x_i,y_i) in L` for each i in Act(pi); empty input occurrences have no additional label. Parallel operations are pairs `(old operation, ell)` with precisely these labels. The initial observation retains ALL old operation data exactly and, for each active occurrence, only the Boolean `x_i in H` for the specified H⊆M. It ignores y_i. The first coordinate means the first LOCAL channel in each frame; the observation mask is not transported to follow a named physical channel. This is a specified symbolic readout, not claimed to be physically measurable without a bridge.

The full initial partition E0 is the kernel of these readouts on each profile. For M_k use H={e,b,b²}. For other positive-control monoids/observations state H or a more general finite seed partition explicitly before testing.

## B. Operations and cuts

**Grafting.** Original graph/grade composition remains unchanged. On an active child block j inside active parent block i, put `ell_ij=ell_i ell'_ij` componentwise in L. No label is created on empty resulting blocks. Identity labels are (e,e). Empty parents have only empty descendants and hence no labels. Associativity is checked along each nonempty leaf path; independent branches do not exchange factors. This is a nonsymmetric tuple-decoration operad over the graph-cut calculus, NOT the original commutative node-scalar decoration.

**Transport.** The sole generating interface/frame change tau sends f to 1-f, acts identically on old K arrows and ordered graph data, and sends every `(x,y)` to `(y,x)`. Thus tau²=id and transport respects branchwise multiplication. No planar leaf order is changed. For transformation monoids on [k], realize the two-channel interface as B={0,1}×[k]: (x,y) acts block-diagonally and the actual interface permutation (c,z)↦(1-c,z) conjugates this action to (y,x). This makes transport a concrete channel-interface relabeling, not a renaming of algebraic closures. No arbitrary carrier map, singleton endpoint restriction or additional probe is included. The ordinary old-interface data and new two-channel frame action are explicitly separate roles. T closes under this actual declared action and its composite, not under all conceivable interface changes.

**Admissible cuts.** Use all finite planar rooted ordered cuts generated by consecutive grouping/ungrouping of actual C5 input occurrences, with induced graph intermediates and composited grade paths. Empty runs, unary vertices and legal nullary nodes retain their actual positions and original admissibility. Do not include crossings or reorderings without their own extension/comparison theorem.

At an elementary cut, let parent active block i group active descendants j. A cut witness retains an outer label a_i in L and all inner labels b_ij in L, satisfying `ell_ij=a_i b_ij` simultaneously for all j in the block. One a_i is shared across the entire group. On an empty group there is no label and only the exact old structural cut data. For a tree, retain all such nodewise labels and equations, not merely a collection of marginal factorizations. Multiplication order is root-to-leaf.

**Readout/guarantee.** C preserves Boolean existential JOINT factorization queries: for a specified permitted cut, does there exist ONE actual jointly compatible cut record whose entire outer and inner factor tuple lies in the specified quotient blocks? A quotient class for a factor may be relational across that factor's active coordinates. Counts, chosen individual witnesses, isotropy and unique lifting are not claimed. Repeated refinements of those joint queries and generated cut trees are in scope. Empty/nonempty feasibility is observable. No arbitrary fixed-endpoint lifting guarantee is selected.

The target is least typed partition refinement of E0 stable for all three operation families, with effective representation, structural commutation criterion, unbounded order-dependence family, finite-fragment upper/necessary bounds and the I1 modular controls retained. Restricting to this explicit admissible planar family is not a claim to settle unrelated crossing I4 duties.

## C. Precisely what is and is not proved by the proposed definition

The operations can be checked without invoking a shell theorem. They are actual graph-linked witnesses: grafting multiplies a parent label into each descendant and cuts require a shared parent label. Thus the additional information changes valid joint cut/refinement judgments. The proof/test package must exhibit concrete such judgments; legality of a decoration alone is not significance evidence.

Forgetting labels gives the old operation; assigning all labels e gives a section. At the semantic operation level these are candidate calculus maps. Old label-blind existential cuts forget and lift by all-e labels. There is NO cut-fibre bijection claim: units can factor e with nonidentity labels. Original presentation-level conservativity requires a separate generator/relation comparison, not merely these semantic maps.

The frame action is genuine typed interface transport. Its effectiveness on E0 must be computed: for this seed, transport observes H-membership of the second channel as well. Do not infer global C/T commutation merely from the action's equivariance.

## D. Single-vertex spine lemma — exact required statement and argument

Consider any fixed valid full profile whose output graph has exactly one vertex. Vertex conservation implies exactly one nonempty leaf and exactly one nonempty child at each nonempty internal tree vertex. Hence all nonempty vertices of any cut tree form one root-to-leaf spine; every off-spine subtree is empty and has no additional labels.

For an elementary legal cut, the only additional equation on the spine is `ell=a b` in L. Conversely any pair a,b with this product labels that old cut, since the empty off-spine factors carry no additional coordinates. Exact old operation data and profiles are unchanged. For iterated cuts the added equations are precisely a finite ordered factorization chain; every such chain labels any corresponding legal old spine shape. Old cut existence is independent of the labels.

Consequently the candidate equality between full C-repair restricted to this single-vertex sort and ordinary monoid-factorization repair requires TWO checks: (i) every ordinary binary factorization is realized by a legal original spine cut (unary insertion supplies it), and (ii) stability under binary joint factorization implies stability of all finite chains by induction without changing the retained endpoint/profile tags. Empty/off-spine queries contribute no new label distinctions because E0 retains their old data exactly and they have no labels. This is a structural proof route, not a depth-truncation argument.

The same sort's generated one-hole grafts include all left and right multiplications by L labels, and no multi-active-coordinate experiment can originate within its one-vertex graph without increasing the retained output graph. A surrounding larger-graph context CAN embed it into a larger graph; global S may therefore be stronger than bare unary congruence unless the proposed initial product observation is already stable under ALL grafts. The coordinatewise H-congruence argument is needed here. Similarly subsequent global C refinements on larger sorts must not feed back through S unnoticed when comparing a particular order of repairs.

## E. Finite schematic reduction is a theorem target, not an assumption

Bound N gives at most N active coordinates per operation, not finitely many profiles. Profile arity, empty positions, grade paths and unary depth stay unbounded. The finite representation target is a scheme indexed by reduced graph/active-block patterns with carrier subsets of `L^r`, r<=N, together with external full-profile tags. Arbitrary relational partitions of these tuple carriers are allowed; product-only partitions are not assumed complete for shared-parent cuts.

Required reduction lemma:

1. Erasing label-free empty slots from an admissible old operation/cut/graft records enough original structural information externally to recover exactly which operations exist.
2. The induced transformations/relations on added labels depend on finitely many reduced active patterns and finite K/frame data, with an effective construction.
3. Arbitrary legal empty insertions, nullary operations, repeated occurrences, and unary chains induce only composites of these finite semantic actions/relations, or are represented by a complete effective schema.
4. Elementary cuts generate all admitted finite trees while preserving the JOINT shared-parent incidence, and stability of the represented partitions implies stability for every generated unbounded context.

A shared-parent feasibility test uses intersection of candidate parent subsets of L, but a bound on one such intersection is not alone a proof of this lemma for nested cuts and multiple shared variables. The proof must account for root-class constraints and relational factor classes. Since each individual semantic carrier is finite, enumerating all its relations is an upper bound only after the finite-pattern reduction is justified. Record actual costs; exponential growth in N or |M| is acceptable for this intrinsic result if honestly charged, not relabeled compact physical discovery.

## F. Product-channel transport caution

For independent channel partitions E,F, a candidate product factorization is `C(E×F)=C(E)×C(F)`. It requires proving that every fixed cut-shape signature is a NONEMPTY Cartesian product of the two channel signatures, so equality is reflected by projections, and proving the same at every saturation stage. It is not justified by ordinary deterministic congruence folklore.

Even if this holds, swap closure sends `E×F` to `(E∩F)×(E∩F)`. Thus GLOBAL C/T commutation additionally needs compatibility with that meet; bisimulation-style relational repair does not generally preserve arbitrary intersections. A safer selected-orbit statement starts at E×top, uses `C(top)=top`, and checks C/T there directly. Do not state all-domain commutation from this restricted fact. A one-pass positive case can use a named already joint-complete base E, but the result must still include genuine nontrivial observational compression and actual transport behavior where claimed.

## G. Modular target in this same class

A nontrivial positive I1 combination test should share a component/interface and an actual witness action, not merely disjoint label alphabets. Local repaired tuple relations must agree on that shared subtheory, and the finite semantic operation basis must make mixed graft/cut/transport peaks checkable. Prove conservative comparison and that every global elementary joint test is generated by the glued local tests with coherent shared witness choice. Only then infer the global optimum from local repairs.

The matched failure should use a shared parent variable or interface identification that creates a mixed joint factorization test not determined by the local marginals. A pair of independently feasible local parent-candidate sets with empty intersection is the natural candidate. It must be realized by actual labels/gates in the selected M family and checked against full profiles; an abstract two-set example alone does not pass. This modular criterion is distinct from the imported complete-shell reduced-product identity.
