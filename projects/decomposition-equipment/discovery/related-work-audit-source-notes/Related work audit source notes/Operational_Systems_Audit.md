# Operational systems results: primary-literature audit

28 October 2026. Result-by-result assessment; no claim of exhaustive priority clearance.

## Main findings

1. **Control-oriented identification is a real close neighbor, not an unexplored motivation.** Application-relative information and obtaining a useful controller without uniquely identifying the plant are established ideas. The present operational sources mostly solve exact finite-model reconstruction, abstraction adequacy and resource-constrained implementation problems. That is a legitimate different problem, not evidence that earlier identification theory ignored the application.
2. **Most proof engines are standard.** Partition/kernel factorization, relational joins, finite constraint enumeration, rank-one tests, path/pullback interchange, simulation-based controller transfer, belief games, finite-state minimization, communication indistinguishability, and CFG/regular-language intersection cannot individually carry broad novelty claims.
3. **The potentially distinctive work is the exact bridge between these engines.** The best candidates preserve actual parallel-event records, specified crossing matchings, occurrence identities, nullary boundaries, staged observation timing, installed hardware/table sharing and one persistent physical world. A checked bridge can be a real theorem or implementation contribution even when its ingredients are standard. Priority for the particular bridges is not established by this pass.
4. **There are several different discovery claims.** The crossing theorem searches for one missing designated component relative to given parent witnesses. Persistent factorization usually receives the actual whole graph and view maps. The later completion theorem can enumerate unknown joint supports/alignments from partial charts, but only inside its generated, jointly separating finite class. Fixed-root profile recognition permits unbounded profile length, not unbounded hardware or empirical discovery of an unknown plant.
5. **No stochastic generalization follows from these operational sources.** Their principal guarantees are exact graph/span reconstruction and all-outcome nondeterministic safety, not probabilities, statistical identification, common-randomness realization, expected cost or almost-sure success.

## 1. Crossing/common-refinement reconstruction and anchored network gluing

### Actual statements and hypotheses

Sources: `crossing_delivery/Crossing reconstruction proof sources/witnesses/{Witnessed_Square_Reconstruction,Crossing_Grid_Cylinder_Reconstruction,Crossing_Grid_All_Fibres_Classification}.md`; `dynamics/Support_Abstraction_and_Witness_Lifting.md`; `network_checkpoint_20261026/fresh_extract/theory/Anchored_Network_Reconstruction.md`, Theorems 1–2 and Propositions 3–4; `Integrated_Finite_Network_Lifting.md`, Theorem 1.

* A witnessed crossing input has finite parent spans and a **specified whole-witness bijection** theta. A common middle T must supply actual factorization bijections alpha,beta making the theta square commute. Equality of endpoint supports is insufficient: cardinalities may prevent T, and an XOR-twisted theta can prevent factorization even when cardinalities fit. This is relative factorization of supplied data, not unconstrained discovery of the entire architecture.
* For fixed local chart realizations, a generated common component exists iff an equivalence relation K on their tagged disjoint union contains the identifications forced by **the same actual whole events**, is type-constant, never collapses two distinct records at one local boundary lift, and contains **exactly one representative at every lift** of each occupied global boundary type. Optional partial operations require congruence and no imported local operation domains. Arbitrary, including noninjective and nonsurjective, boundary maps matter.
* The finite partition algorithm is complete with fixed local carriers. Local invisible sectors can be unbounded. The hardware-bounded lifting theorem obtains bounds from actual compiled execution carriers: one core event set of size at most N and local pullbacks bounded by interface-fibre multiplicities times N. It then searches local factorizations, K and **one core device with exact compiled wrappers**, rather than silently using different devices in different charts.
* `Crossing_Grid_Decision_Complexity.md` proves a genuine complexity split for **explicitly listed** finite sets, maps and theta: the fully visible four-component problem is in P; the general problem is NP-complete both with and without prescribed middle support. NP membership uses a polynomial small-realization bound; hardness encodes three-dimensional matching in witness multiplicities when one exposing side is empty, while the parallel Q remains nonempty. This is not hardness of the visible test, compressed inputs or all physical grammars.
* `Relational_Grid_Reconstruction_by_Residuals.md` separately solves one unknown relation U in arbitrary-union-preserving contexts C_k: the safe-atom union U_max is the greatest solution iff every C_k(U_max)=P_k. All solutions are safe subsets covering each required behavior. This is support-level residuation, not witness-bijection reconstruction; repeated unknown occurrences can destroy union preservation and greatest solutions.
* The reconstruction is initially of one designated component. Global parent/whole assembly additionally requires genuine cover and unchanged-context-coordinate agreement. Simultaneous Cartesian base change preserves solutions; arbitrary independent chart changes do not. Carrier-surjectivity alone does not reflect operational existence.

### Closest primary comparisons

[Beeri–Fagin–Maier–Yannakakis, *On the Desirability of Acyclic Database Schemes* (1983), Theorem 3.4](https://s3.us.cloud-object-storage.appdomain.cloud/res-files/500-jacm83a.pdf) identifies acyclicity/join-tree conditions with universal pairwise-to-global consistency properties. Its relation instances and attribute projections are the immediate baseline for local consistency versus a global join. The current input has additional named execution identities, prescribed factorization maps and exact pullback coverage; an ordinary lossless support join does not automatically solve those obligations. Conversely, merely exhibiting pairwise-but-not-global consistency is not a new phenomenon.

[Abramsky–Brandenburger (2011), Theorem 8.1 and the support hierarchy](https://arxiv.org/pdf/1102.0264) relates global sections to factorizable hidden-variable realizations over measurement covers. The general local/global obstruction is established. The current forced-equality cycle is instead derived from actual shared whole records and within-chart distinctions. A global projection supplied in advance would eliminate that obstruction. No identification with a Bell/contextuality theorem is proved: measurement distributions, compatibility and global-section objects differ. Calling every gluing failure quantum contextuality would be incorrect.

[Vorob'ev (1962), *Consistent Families of Measures and Their Extensions*](https://www.mathnet.ru/php/archive.phtml?jrnid=tvp&option_lang=eng&paperid=4710&wshow=paper) is the direct classical marginal-extension baseline. Its measure-extension problem must not be replaced by mere support extension or record bijection. This pass verified bibliographic/abstract access but did not complete a theorem-by-theorem reduction to Vorob'ev's hypotheses.

The complexity proof explicitly reduces [Karp's three-dimensional matching problem (1972)](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf) to positive incidence multiplicities by writing n_b=1+x_b (or directly Boolean multiplicities without prescribed support). That proves the stated new problem-instance classification, not a new NP-completeness mechanism. No comparison against earlier complexity results for this exact witnessed schema was completed. For residual synthesis, combine the C_k into one union-preserving powerset map C: its right adjoint sends P to the safe-atom union, and C(U)=P is solvable exactly when C(C^*(P))=P. This exact mapping makes the synthesis principle a standard adjunction deduction; the grid equations and obstruction/transport cases are its specialized application.

### Verdict

**Established mechanism + explicit relative reconstruction/integration.** Union-find, partition amalgamation, finite enumeration and cover gluing are standard. The narrower candidate contribution is the derivation of exact constraints from theta/whole anchors, all-fibre treatment, symmetry retention and single-device execution comparison. Neither “first local-to-global obstruction” nor a general arbitrary-network discovery theorem is supported. The equivalence of the full anchored, arbitrary-interface theorem to an existing descent theorem remains unresolved; an exact functorial reduction would be needed before labeling it a direct corollary or a new general gluing theorem.

## 2. Information sufficiency, lost context and physical implementation

### Actual results

Source: `crossing_delivery/Crossing reconstruction proof sources/model/Finite_State_Crossing_Models.md`, §§1–5; `dynamics/Wiring_Exactness_and_Joint_Abstraction.md`; network implementation sources.

For a deterministic finite update f on a full product state space, a local block U and external observation q are sufficient exactly when `ker(local state,q) ⊆ ker(f_U)`. This is ordinary factorization through a quotient. In the encoded-sensor example, `c'=u XOR v XOR z`, with only sensors `a=v XOR z`, `b=u XOR z`, both cuts `{cu|vz}` and `{cv|uz}` are exact; their common singleton refinement is not, even using both available sensors. The states 000 and 111 agree on a,b and disagree on next c. One additional raw u, v or z repairs it, minimally **within that stated repair class**.

The parent observation-kernel join is `ker(c,u XOR v XOR z)`, whereas `ker(c,a,b)` is not contained in it. The update can factor through each parent view without factoring through the smaller component's allowed information. Raw coordinate sensors behave differently: an observation set suffices iff it includes every essential external input; the union of parent raw boundaries suffices for the intersection block. The n=2^r AND family with budget n−2 has feasible proper cut subfamilies but no full common refinement. A semantic one-bit AND message still costs n−|U| raw acquisitions to implement.

For relational wiring, the exact retained-middle lifting condition is equality between the union of actual same-middle rectangles and the apparent rectangle obtained by independently selecting middle representatives. Endpoint-safe quotients satisfy a pair-compatibility relation; a greatest safe quotient exists exactly when that relation is transitive. Individually safe interface abstractions need not remain safe after the other surrounding interface is abstracted.

### Exact comparisons and limits

[Gács–Körner, *Common Information is Far Less than Mutual Information* (1973)](https://cs-web.bu.edu/faculty/gacs/papers/commoninf.pdf) supplies the deterministic common-part baseline. In the finite deterministic specialization, functions factoring through both observations are precisely functions constant on the equivalence relation generated by their two kernels. Thus the kernel-join calculation is standard common-factor mathematics; it is not a new common-information theorem. Equivalently, assign positive mass to every allowed whole state and form the bipartite support graph of the two observations: its connected-component label is the common factor. This assertion follows directly because a common function is constant along each edge and hence along each path, and the component label is separately readable at either endpoint. [Witsenhausen (1975)](https://epubs.siam.org/doi/pdf/10.1137/0128010) further connects nontrivial agreement from repeated iid observations to decomposability under a compactness condition, including finite alphabets; only the publisher abstract was available for that stronger probabilistic statement. The current operational question additionally fixes which local state survives a cut and which sensor functions may be physically acquired. Its cardinality/resource claims are not entropy claims. The general operation-sensitive context theorem was not separately recovered in this pass; only the explicit finite source above and the wiring note were inspected.

[Brooks–Frankel–Kamenica, *Comparisons of Signals* (March 2024), Theorem 1](https://benjaminbrooks.net/downloads/bfk_comparisons.pdf) distinguishes marginal experiments from jointly specified signals and characterizes Blackwell dominance robust to every additional signal by reveal-or-refine. This is an important **neighboring** comparator for contextual information, not a demonstrated subsumption: their conclusion is decision value under probabilistic signals and arbitrary side information; ours is exact update factorization under fixed local state and a restricted sensor grammar. No implication in either direction has been proved here.

[Clarke et al., *Counterexample-guided Abstraction Refinement* (2000)](https://web.stanford.edu/class/cs357/cegar.pdf) already analyzes spurious abstract paths and refines abstractions. The wiring-prefix lift algorithm is an instance of this established abstract-path feasibility mechanism. [Giacobazzi–Ranzato–Scozzari (2000)](https://www.sci.unich.it/~scozzari/paper/JACM00.pdf) develops complete-domain extensions/restrictions for semantic operations. Their complete-shell quantifiers are not the same as safe equivalence partitions for one fixed producer/consumer; the absence of a coarsest safe partition does not refute their theorem.

`Maximal_Permitted_Interface_Equipment.md` gives a separate positive closure theorem: for the endpointwise replete semantic image H of **unbounded finite** snapshot circuits, take exactly those actual interface functions whose graph and converse spans both have circuit certificates, and all compatible ambient span cells. Restrictions compile as forward-map circuit; component; converse-map circuit, with exact preimage multiplicity. Restricting units proves this is the largest vertical base supporting all ambient restrictions with that H. Cells are semantic certificates, not necessarily physical transformations between circuits; unrestricted membership is not proved decidable. This is an operational instance of [Shulman, *Framed Bicategories and Monoidal Fibrations*, Theorem A.2 and §4.15](https://arxiv.org/pdf/0706.1286): companions/conjoints supply the restriction mechanism once the source establishes semantic-image composition closure.

### Verdict

**Explicit operational counterexamples and resource separation, not new general information theory.** Distinguish: insufficient permitted information; enough extensional information but no allowed circuit/acquisition implementation; and sufficient/implemented interfaces that lose exact cross-component record matching. A finite full-table circuit closure is complete for its declared ports/gates. A fixed acquisition or memory budget need not be closed under substitution and is not itself a complete equipment. Keeping those distinctions is substantive modeling work; broad priority remains unestablished.

## 3. Persistent exact factorization, correlation reflection, aligned records and time scale

### Actual theorem package

Source: `persistent_checkpoint_20261026/preflight/theory/Exact_Dynamic_Factorization.md`, Theorems 1–8, Proposition 9; `examples/Temporal_Cycle_Decomposition_Discovery.md`.

* At a fixed Cartesian state cut `X ≅ Z ×_B Y`, exact graph-pullback factorization through interface J exists iff each actual transition-multiplicity block has a nonnegative integral outer product `M_j=d_j c_j^T`. Nonzero rank-one blocks have primitive vectors and divisor choices; zero blocks allow arbitrary invisible records on the opposite factor unless generatedness or bounds exclude them. Counts do **not** determine the prescribed event bijections/anchors.
* For total independent row/column aggregation maps `L_i(M)=A_i M B_i^T`, let V be the zero-row/zero-column-sum interaction space and `H=V ∩ intersection ker L_i`. Every nonnegative integral M whose observed matrices are independent is independent **iff H=0**. For H≠0, integer kernel perturbations of a sufficiently positive uniform matrix give false positives. The necessity quantifies over all such finite multiplicities; structural zeros, deterministic models or a hardware bound may exclude the perturbation family. Literal restriction views have a different criterion: every 2×2 rectangle must occur in some view.
* Interface coarsening preserves the **old** synchronized factors exactly iff it introduces no new matching record pair. New count-level factors may exist even when the old witness does not descend.
* Once one state/event pullback is exact, coordinatewise path construction gives coherent factorizations at every length and under finite occurrence substitution. This is a finite-limit argument, not inference from finitely many traces.
* Proposition 9 recovers the full graph from a **known whole state carrier**, jointly injective state-view maps and actual shared event identifiers. Separate histograms can conceal H-correlations even when jointly aligned records recover them.
* For a cycle context of length m with permutation transport and d-state fibre, an unknown autonomous factor over that fixed context exists iff loop transport is conjugate to an m-th power in Sym(d). Coarse m-step products can therefore exist without a primitive-time product. Two coprime samples imply primitive product only for a reversible whole under **one common anchored cut**; incompatible separately discovered cuts do not suffice.

### Literature placement

The rank-one classification, vanishing minors, integral primitive-vector argument, linear observation kernels and preservation of limits by graph-path formation are standard algebra. The H criterion is a clearly stated derived reflection theorem, sharper than simply demanding full-table injectivity. **No exact prior theorem with the same total-aggregation, all-integral-matrices quantifiers was established in this pass.** Its priority should be left unresolved, not inferred from the elementary proof or from failed keyword searches. Algebraic statistics, discrete tomography and lossless marginal/join reconstruction deserve a targeted second comparison before a new-theorem claim.

The temporal criterion is gauge transport plus a finite permutation-root condition, and the positive coprime statement is Bézout inside a product-permutation subgroup. These are specialized deductions using standard algebra, not new permutation theory. Their useful content is a precisely scoped failure of decomposition discovery to commute with temporal coarse-graining, despite retention of path records.

Compositional control already has nontrivial local-to-global abstraction theorems. [Zamani–Arcak (2016), Theorem 4.2](https://arxiv.org/html/1608.01590) starts with subsystems, their abstractions/storage functions and an interconnection matrix; matrix inequality and compatibility conditions yield a simulation function for the interconnection. [Swikir–Zamani (2019), Theorem 2.4](https://arxiv.org/html/1805.06271) composes alternating simulation functions under cyclic small-gain conditions. Those solve quantitative approximation of supplied component networks, not classification of all exact event-record pullback factors. The present work does not replace their continuous-state/error guarantees; their existence prevents claiming that cross-component compatibility was ignored by compositional control.

[Samari–Nejati–Lavaei, *Data-Driven Control of Large-Scale Networks with Formal Guarantees*, v2, Assumptions 1–2 and Theorem 2](https://arxiv.org/pdf/2411.06743v2) is a stronger recent comparator than supplied-model composition alone: unknown subsystem dynamics and unknown interconnection maps are allowed, and data-derived local certificates compose under explicit Lipschitz/coverage-slack conditions. However, subsystem coordinates are designated and all their states measured; the symbolic-model construction initializes state/disturbance grid points. Its arbitrary-number-of-agents statement is a compositional condition uniform in network size, not recovery of latent component coordinates from mixed readouts. Neither this genuine data-driven advance nor the dossier's exact finite record classification subsumes the other as stated.

### Verdict

**Standard algebra plus narrow characterization and counterexample results; candidate theorem-level distinctness unresolved.** A legitimate description is “exact finite witnessed-factorization and observation-reflection criteria, with provenance and time-scale obstructions.” Avoid “learns arbitrary hidden subsystems from partial sensor data.” The bounded algorithm can search state cuts and components rather than assuming them, but receives a finite whole model/view maps or specially reconstructed finite completion evidence and explicit bounds.

## 4. Original Calc bridge, staged control and the gripper/fixture example

### Actual bridge

Sources: `safety_lifting_checkpoint_20261027/qa/fresh_extraction/foundations/Original_Calculus_Dynamic_Interpretation.md`; integration report; `persistent_checkpoint_20261026/preflight/control/Causal_Implementation_and_Control_Transfer.md`; later dynamic Lean report.

The target consists of graph-span assignments and operations `whole -> compatible tuples of pieces`, retaining separate states/events and occurrence maps. The empty compatible tuple is the boundary graph, not a terminal singleton. A nullary operation requires a syntactic loop and equal boundary legs; it is exact iff that common leg is a graph isomorphism. Tree.extend, Presentation.extend and SemanticRefinement.functor connect the **original** source APIs to this target; declared equations must agree on full graph maps, not just visible outcomes.

The operational enrichment separately specifies pre-action acquisition, action selection, post-action replies and commit. Gate tables use only routed phase-correct wires. Open plant matching is checked before controller insertion and includes actions the final policy never selects. A fixed controller's safety/progress transfers only with observation/action/initialization/predicate and nonblocking conditions; exact collapsed transitions alone do not grant it future observations.

The fixture example derives local gripper/fixture/object tables, then the open plant (72 states, 396 action records) and Select/Decode/Commit controller with one memory owner. The coupled comparison retains 468 records. Under HOLD retention and the stated finite response envelope, all nondeterministic seating choices safely achieve the released quarter-turn goal in at most three actions. Missing handedness memory, missing retention and independently duplicated contacts fail for distinct reasons. It is a model-checked worked instance, not friction/force certification of a physical robot or a global minimal-memory theorem.

### Close baselines, with quantifiers

[Reissig–Weber–Rungger, *Feedback Refinement Relations* (2017), Theorems V.4, V.5 and VI.3](https://arxiv.org/html/1503.03715v3) already connect refinement to feedback composability, behavioral inclusion and controller transfer, including admissible-input conditions. The local staged transfer proof is standard simulation/feedback-refinement reasoning after its own hypotheses are established. Because its staged record objects are not literally their simple systems, “direct application” requires an explicit encoding; the safe classification is a specialized reproof/bridge.

[Calbert–Girard–Jungers, v2 (2 April 2026), Theorems 3.15 and 3.19](https://arxiv.org/html/2410.06083v2) gives a two-way relation between simulation types and specified interface control architectures, through the interfaced system's feedback refinement. ASR/PSR/FAR/MCR/FRR have distinct dependency architectures; the converse requires the stated common-quantization condition for PSR/FAR. This is much closer than a generic approximation citation. It precludes claiming that implementability-sensitive abstraction relations are new as a general idea. It does not automatically supply this dossier's named-record bijections, source syntax/nullaries or restricted acquisition/store grammar.

[Willems et al., *The Canonical Controller and Its Regularity* (2003), Theorem 1](https://homes.esat.kuleuven.be/~sistawww/smc/jwillems/Articles/ConferenceArticles/2003/1.pdf) characterizes linear differential behavior implementability by `N ⊆ K ⊆ P`. This is a primary baseline for control by interconnection, not simply “a controller is an external function.” It does not imply a bounded finite driver with the prescribed causal ports and memory. The behavioral criterion and the dossier's fixed-architecture requirement have different classes and conclusions.

### Verdict and formalization boundary

**Strongest case for formal implementation/integration credit, not a new control-transfer principle.** The later `dynamic_lean_checkpoint_20261027/output/Dynamic calculus Lean formalization results.txt` records a fresh-source build of seven modules, full Calc laws, graph-map/tuple equivalence, nullary classification and the original free/presented/refinement bridge. Recorded axiom closures exclude sorryAx and use standard Lean axioms. It explicitly excludes general exact-substitution closure, paths/time, CFG lifting, interface changes, staging/controllers and the equipment/2-Segal program. Thus earlier report wording “not formalized” is superseded only for that slice; the operational guarantee is not wholly Lean-verified.

## 5. Continuation interfaces, exact witness gate and safety zoning

### Actual result split

Sources: safety-lifting `theory/Finite_Continuation_Interface_Theorem.md` (A), `Generated_Profile_Fullness_Automaton.md` (B), `example/Thermal_Zoning_AB_Instantiation.md`.

A takes finite sorted carriers, designated predicates, actual maps/action relations, demonic predecessor operators and explicit admission predicates. Boolean/operator closure produces the coarsest quotient preserving every generated continuation verdict. It preserves reached successor-class sets and enabledness when included. Physical realization requires the actual observation/history map to distinguish its classes; a mathematical quotient is not a sensor. Its exact message lower bound counts continuation atoms, not autonomous runtime memory.

B is different: with a fixed finite graph assignment, interface abstraction and original generated profile grammar, a finite Hom-map/boundary defect automaton decides whether **all new semantic operations** on those profiles lift with their same coordinate records. Context-free/regular reachability covers arbitrary finite profile length. Fullness then gives unique coherent lifts under substitution. New exact nonempty operations lift as exact; nullaries need the separate rootwise E0 check. Preserving every old exact nullary under coarsening is a different direction and can require boundary isomorphism. Testing only interpreted old source terms would make existential lifting largely trivial; B deliberately covers new semantic maps.

The combined A/B theorem enlarges probes to participating semantic occurrence maps, computed by the grammar automaton. Primitive-only probes do not suffice for arbitrary new semantic discoveries. In the thermal example, heat and one remaining cooling charge give four continuation classes; regime is redundant in the boundary because colors already retain it. Heat alone invents resource-reuse route tuples. This is a one-owner finite deterministic episode model; it is not universal geographic safety or an adversarial robot theorem.

### Comparison and verdict

The coarsest modal/continuation quotient is ordinary finite Boolean closure/bisimulation or residual behavior minimization. Complete abstract-domain machinery provides the right broad baseline, while finite automata and CFG intersection supply the decision engine. The existence of canonical A does not imply canonical B: B can realize arbitrary conflict-graph coloring, and adequate partitions need not have a greatest element. Existing incomplete-machine compatibility theory also warns against assuming all compatibility relations are equivalences.

**Classification: standard mechanisms with a nontrivial explicit source/semantic-discovery bridge.** Credit must attach to compiling the correct actual-map defects, retaining nullaries, distinguishing generated profiles from old terms, and aligning A's probe language with B's discovered maps—not to the slogan “finite automata check infinitely many profiles.” No general arbitrary semantic crossing doctrine is proved finite-state merely because individual carriers are finite. No priority claim for this exact A/B bridge is yet supported by a full comparative theorem.

## 6. Persistent-world suitability, causal capabilities and fixed-root grammar recognition

### Exact operational quantifiers

Sources: suitability `theory/{Typed_Persistent_Completion,Causal_Descent,Operational_Cut_Capability,Coupled_Target_Index_Capability,Operational_Semantic_Profile_Recognition,Typed_Causal_Presentation_Closure,Parametric_Causal_Descent}.md`.

The completion theorem enumerates supports inside finite compatible chart-tuple graphs, unknown finite alignments, generated component quotients and finite original-presentation maps/equations. It is complete only for worlds whose chart maps jointly separate whole states and events and have no invisible extra multiplicity. Optional mathematical decomposition failure must not remove a physically possible world. Pure proof-coordinate choices, physical uncertainty and installed implementation choices are separate.

The controller order is `exists one permitted architecture/tables/controller; for every persistent physical world; for every initial state and adverse execution`. The hidden world stays fixed across steps. Belief sets are analyst storage, not free runtime memory. The unrestricted belief fixed-point solver and the fixed/bounded-controller product-graph test are expressly different claims. Universal termination without fairness reduces to absence of reachable non-goal cycles/deadlocks for a fixed finite candidate.

Causal cut reconstruction uses full actual prefixes and codes e_c. The necessary-and-sufficient constraints are initialization from allowed observations, actual shared-cut anchors, **one permitted update table across all occurrences and worlds**, and common acceptable responses. For set-valued task responses all relevant intersections must be nonempty; pairwise intersection alone fails. Individual-cut coloring does not enforce successor/update closure. A nine-episode promise example has a two-code optimum at each separate cut but requires width three somewhere; its two minimal profiles are incomparable. Product amplification is only for the stated separately owned, noncommunicating registers.

The target-block family with N=mr gives `b >= 2^[r ceil(m/b)]` and a one-table upper construction, hence `Theta(max(2^r,N/log N))` persistent register states. A model allowing the final target block to change needs exactly `2^N` states despite the same two local chart images. Tags are delivered inputs, not a free hidden clock; combinational tables are unrestricted in this resource model. The sharp operational lesson is loss of an actual matching promise, not a new INDEX lower-bound technique.

Fixed-root semantic profile recognition freezes one finite physical architecture/table tuple before worlds. Finite letters carry actual graph maps, allowed memory maps, physical aliases and world-specific proof maps. An independently specified finite-state joint-support machine supplies the target—not the image of the proposed root map. Image, injectivity and subset-preimage surjectivity defect automata, plus finite physical coverage/table/ownership monitors, give an exact regular language. Its intersection with the source profile CFG decides arbitrary finite profile lengths. Unbounded repeated profiles do not allocate new stores. Recovering memory alone needs a separate memory-only comparison; a coupled inverse might otherwise use hidden environment state.

The same source's Theorem 3 also **constructs an unknown common refinement**, not merely verifies one: two exact crossing descriptions of the same fixed coupled root supply row/column parents; one cell-tagged CFG and independent regular inner-support monitors specify candidate leaves. Erasing to each row/column preserves regular recognizability, and the combined monitors recover both forests, named leaf matching and the explicit joint-target comparison `H_V ∘ H_U^(-1)`. Empty rows/columns retain their boundary data. This is not necessarily a bare permutation of every internal boundary coordinate; stronger named-boundary matching requires extra finite checks. It does not permit arbitrary independent CFG intersections, arbitrary unknown parent networks or runtime reordering of observations.

### Primary baseline mapping

[Gevers, *Identification for Control* (2005)](https://perso.uclouvain.be/michel.gevers/PublisMig/P78.pdf) treats identification criterion, experiment and controller design as a coupled application-dependent problem, including closed-loop identification and restricted-complexity models. [Hjalmarsson, *System Identification of Complex and Structured Systems* (2009)](https://www.kth.se/social/upload/525e5cdaf276545124e66218/hjalmarsson_ejc_2009.pdf) explicitly studies experimental effort versus application-relevant accuracy and deliberate concealment of irrelevant properties. These are direct motivational predecessors. Neither premise says “identify everything first”; neither paper establishes this dossier's typed witness reconstruction or hardware grammar theorem. Hjalmarsson's stated focus sets aside finding a suitable model structure, so it should not be cited as solving arbitrary architecture discovery either.

[van Waarde et al., *Data Informativity* (2020), Definition 3, Theorem 16, Example 19](https://arxiv.org/html/1908.00468v2) uses exactly the robust order `exists K, for all systems consistent with data`. Example 19 stabilizes an incompletely identified plant; Theorem 16 gives the full-row-rank/right-inverse characterization for noiseless LTI state-feedback data. Section V-B also discusses input/output data, so this literature must not be dismissed as full-state-only. The dossier instead constructs its possible-world family from explicit finite chart/operation constraints and charges causal physical implementation. To claim a new data-informativity theorem would require defining a data-to-model version space and proving the associated equivalence, not merely reusing the quantifier order.

[Diedrich–Bruns–Rauh–Niggemann, *Learning Causal Relationships to Derive Contract Architectures for Model-Based Fault Detection* (2026), §§III–IV and Algorithm 1](https://www.researchgate.net/publication/411908739_Learning_Causal_Relationships_to_Derive_Contract_Architectures_for_Model-Based_Fault_Detection) is an actual learning-to-contract integration: CODA combines time-series dependency estimation, expert component-contract templates and nominal bounds to generate monitors, using annotated component health/fault information in its demonstrated dependency learner. Its authors identify heuristic learning/confounding and expert refinement limits. That is meaningful partial structure/contract inference, not an exact witness-sensitive finite completion theorem; our supplied-chart enumeration is not a substitute for its empirical learning stage.

[Beatty–Miller (1962)](https://research.ibm.com/publications/some-theorems-for-incompletely-specified-sequential-machines-with-applications-to-state-minimization) and [Kam–Villa–Brayton–Sangiovanni-Vincentelli (1993), §§3–4](https://www2.eecs.berkeley.edu/Pubs/TechRpts/1993/Archive/ERL-93-79.pdf) already address compatible state sets and closed covers for incomplete machines. The latter explicitly requires coverage and successor closure. This is the close baseline for promise-relative code compatibility, not only Myhill–Nerode minimization of total automata. The local shared-table/physical-library translation is more constrained, but “local compatibility is not sufficient without closure” is established.

**Specialized finite completion/recognition and resource examples built on established synthesis, minimization and communication mechanisms.** A novel integration claim is possible only at the exact record-to-constraint/monitor bridge. ## Cross-cutting stochastic/common-realization boundary

The actual-record requirements are useful for distinguishing a shared invocation from two independent invocations. They nevertheless specify sets and maps, not a probability measure or transition kernel. Event multiplicities alone need not be physical probabilities. A bijection that is not measure-preserving does not transport stochastic guarantees, and support-level sure success is stronger than almost-sure success in a different sense.

[Lavaei–Soudjani–Majumdar–Zamani (2017)](https://arxiv.org/html/1709.10312) composes stochastic abstraction error certificates under small-gain conditions and explicitly considers independent abstract/concrete noises. That is a genuine probability-bearing comparator; the current operational notes explicitly exclude those guarantees. A probability-preserving common realization would additionally need normalized kernels, specified couplings/shared randomness, persistence and causal sampling/observation conditions. Neither junction-tree support gluing nor exact graph factorization supplies them automatically. The separate positive-realization audit owns stable-cone/HMM and stochastic channel-realization results.
