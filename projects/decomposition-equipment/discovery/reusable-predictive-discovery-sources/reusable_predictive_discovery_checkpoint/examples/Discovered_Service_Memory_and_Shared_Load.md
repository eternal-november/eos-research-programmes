# Discovering reusable service interfaces from joint response tables

## Abstract

Two service zones can each look predictable on their own while a controller using both receives the wrong joint prediction. This synthetic family adds three genuine requirements: a zone must remember its own earlier condition, receive a neighbor's current condition, and use a common random source rather than independently sampling the two predicted responses. The minimal local input scopes are recovered by an exhaustive search over proposed scopes. They are not supplied as the answer. The common-source mixture is then obtained from the response tables and checked across all contexts.

This is a reproducible population-table calibration of the synthesis and witness checks, not a claim of architecture identification from finite raw logs. A separate finite-data version requires bounds for full histories, or an explicitly stated finite-memory assumption. The distinction is important: averaging histories with the same short suffix does not prove that the suffix predicts every controller's future.

## 1. A genuinely coupled positive family

For N>=2 zones on an unknown directed interaction graph, let Y_i(t) be a binary busy/degraded readout and A_i(t) a binary requested load. A finite-order service family may have

    p_i(t) = b_i + u_i A_i(t) + v_i Y_i(t-1)
                 + sum_j w_ji Y_j(t),

with all p_i in a fixed subinterval of (0,1). The directed supports, lag choices and coefficients are not supplied to the scope search. Other nonlinear tables can replace this formula; the exact check does not assume additive structure. A next readout is generated by a mixture of independent uniform thresholds and one common uniform threshold. The same mixture choice and shared uniform are reused at all zones within a tick, with fresh noise at the next tick. Thus local dynamics depend on neighbors and on history, and simultaneous innovations are correlated. All joint outcomes have positive probability because the independent part has positive weight.

This particular family has no unobserved persistent mode: all persistent predictive influence is in observed history. It complements, rather than resolves, the hidden-mode example in `Interacting_Service_Zone_Family.md`. It is not legitimate to replace a genuine persistent mode by the fresh source used here.

## 2. Two-zone member and what the scope search receives

Let current readouts be (y0,y1), previous readouts (z0,z1), and actions (a0,a1). The reference process uses

    p0=(1+3a0+2z0+2y1)/10,
    p1=(1+3a1+2z1+2y0)/10.

With probability 1/2 draw two independent uniform thresholds; otherwise use one common threshold. Its joint response table is

    K11 = (p0*p1 + min(p0,p1))/2,
    K10 = p0-K11,
    K01 = p1-K11,
    K00 = 1-p0-p1+K11.

The synthesis checker receives only the 64 joint response tables indexed by the six observed binary coordinates. It does not receive the formula for which coordinates matter. It tries all 64 coordinate masks for each local response. A mask succeeds precisely when every two rows agreeing on its retained coordinates have equal marginal next-response probabilities.

The unique inclusion-minimal successful masks are:

    port0: (neighbor current y1, own previous z0, own action a0),
    port1: (neighbor current y0, own previous z1, own action a1).

Each mask has eight contexts. Omitting the neighboring readout or old local readout merges response laws differing by 1/5; omitting the action merges laws differing by 3/10. Therefore any single approximate response probability on such a merged class has worst-case error at least 1/10 or 3/20, respectively. These are same-context separation certificates, not significance tests on a guessed graph.

The search is for predictive scopes, not unique physical groups. A merged two-port component and two communicating one-port components are both implementations. The resource contract chooses between them; the evidence alone does not identify a privileged physical partition.

## 3. Recursive executable witness

At each port retain one bit m_i=Y_i(t-1). Read local Y_i(t), receive one bit Y_j(t) from the neighbor, and read its own requested action A_i(t). Use the selected table indexed by (m_i,Y_j(t),A_i(t)). At the end of the tick update m_i := Y_i(t). Initial memory is supplied by an actually observed preceding readout; an arbitrary hidden initial bit is not an executable observer initialization.

Thus the separated implementation needs one persistent local bit per port and one incoming current-readout bit per tick. The messages must arrive before the prediction deadline. A merged implementation instead has direct access to both readouts and two memory bits. No communication advantage is claimed without charging the physical placement and schedule.

These recursive state updates preserve the meaning of the mask at every tick; repeating a discovered one-step table without these updates would not establish a recurrent interface.

## 4. Recover and verify a common positive source

After obtaining the marginal response tables, compute from every joint context

    lambda = (K11-p0*p1)/(min(p0,p1)-p0*p1).

All denominators are positive in this member. All 64 contexts yield lambda=1/2. A candidate common-source implementation is therefore generated and checked, rather than inferred solely from marginal compatibility.

It has 110 context-independent response atoms:
- 10 common-threshold atoms u=0,...,9, each of weight 1/20;
- 100 independent-threshold atoms (u,v), each of weight 1/200.

The response at port i is 1 precisely when its selected threshold divided by 10 is less than its locally obtained p_i. Thus each atom specifies responses at EVERY local context, not a separately resampled coupling chosen after seeing a joint context. All atom weights are positive and sum to one. Direct enumeration verifies every full joint table. This is a valid positive local-response realization.

It is not the only possible latent realization. The discovery conclusion concerns the predictive table and an executable witness, not the identity of an actual physical common load. The context-independent source class is also substantive; some response tables will fail this realization requirement even if each separate context has a positive joint distribution.

Sampling the correct marginals independently is wrong: the largest one-step joint total-variation error over this member's contexts is 1/4. A controller depending on simultaneous conditions can therefore distinguish the product predictor from the correct joint predictor.

## 5. Finite evidence and transfer WITHOUT a hidden Markov promise

A response table conditioned only on the last two readouts is not enough to certify that older history is irrelevant. To use the all-causal-law verifier, data must instead justify, for every covered full history h and action a up to H,

    |P(Y_next=y|h,a) - K(y|suffix2(h),a)| <= epsilon

for all four outcomes y. These are empirical full-history statements with simultaneous uncertainty, not a hidden second-order-model assumption. They imply one-step TV<=2 epsilon. Any adaptive controller using the admitted action/readout history then has H-step transcript discrepancy at most min(1,2 H epsilon), provided initial laws agree and all its histories/actions are covered. The usual common-coin sequential coupling proves this: while histories agree, use identical policy randomness and a maximal coupling of next readouts.

If evidence gives only a policy-weighted residual instead of a uniform conditional bound, use the main theorem's policy-family coverage multiplier. Do not silently substitute the uniform bound above.

For independent complete episodes, fixed finite H and all-action exploration, one can use a union bound over next-outcome conditional estimates. Conditional on the visit count for a fixed (time,history,action), its next outcomes are independent with that conditional law. With M such rows, a sufficient common radius is

    epsilon = sqrt(log(8M/delta)/(2 N_min)),

where N_min is the smallest row count. A random N_min is valid through the conditional-on-count bound for each row; rows with zero count receive the trivial interval. Dependence among rows within episodes does not defeat the union bound. These statements assume independent episodes and a fixed data-generating regime; they do not establish physical regime stability.

If both initial readout pairs are allowed, four actions are available and four joint outputs are possible, then

    M = 64 * sum_(t=0)^(H-1) 16^t.

This elementary finite-data certificate is exponentially expensive. The example does NOT demonstrate a sample-efficient escape from that cost. The main theorem's weighted residual/dual certificates may use smaller evidence families, but that improvement must be established in an actual example rather than inferred from the compact predictor.

If only short-window conditional tables were measured, a process with longer memory may match them while invalidating transferred predictions. In that case either retain the ambiguity or state the finite-memory promise explicitly. The verifier must not manufacture that promise from a successful mask search.

## 6. Reproducible status

`check_service_interfaces.py` verifies all 64 joint contexts, exhaustively searches both sets of 64 masks, derives lambda, checks the 110 positive shared response atoms, checks each omitted-feature separation, and contrasts independent marginal sampling. It also checks 50 distinct posterior states in the two-state hidden-mode obstruction.

These are exact rational synthetic calculations. No finite episodes were collected, no noisy parameter estimation was performed, and no full-history discovery theorem is claimed from the table search. The family is a meaningful test of recursive and joint witness requirements, but the small two-zone member remains a calibration example rather than evidence of general practical scalability.

### Shared randomness is an explicit resource

The joint sampler is executable in centralized software, but its common noise must not be treated as free communication in a distributed implementation. A concrete driver draws a uniform integer R in {0,...,199}. For R<100 it sends floor(R/10) to both ports. Otherwise it sends floor((R-100)/10) to port0 and (R-100) mod10 to port1. Each port compares its threshold divided by10 with its selected response probability. Enumeration verifies the desired joint table.

Thus a distributed sampler requires a declared common driver with 200 equiprobable outcomes per tick and a 10-symbol threshold delivery to each port (4 fixed binary bits), in addition to the one-bit neighboring observation and one-bit recurrent memory per port. The source-to-port messages are causal model-simulation resources, not newly assumed sensors of the actual environment. Centralized sampling can avoid physical interprocessor delivery, but then the implementation is centralized. A centralized numerical forecaster can calculate the joint probabilities without drawing any random source; these random-source resources concern execution of the generative simulator. An ideal uniform200 primitive is part of that execution contract. Implementing exact uniform200 from fair bits by rejection has unbounded worst-case draws, so an exact fixed-deadline sampler is not supplied merely by declaring an eight-bit register. Counters, synchronization, delivery and random-bit generation have their own costs. No installed hardware capability is certified by this mathematical witness.
