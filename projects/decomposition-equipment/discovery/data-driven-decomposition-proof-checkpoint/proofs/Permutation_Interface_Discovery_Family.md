# Persistent permutation interfaces discovered from readouts

Status: proved isolation/calibration family and interface tradeoff, not validation of the central architecture-inference problem. The ingredients are elementary orbit algebra, positive factorization, and deterministic behavioral distinguishability. No novelty or full-target discharge is claimed. The family is globally coupled by a without-replacement assignment constraint, not independent repetition of a small example.

## 1. Universe and raw data

There are n named readout positions and n distinct labels. A hidden configuration is a bijection pi from positions to labels. Initially pi is uniform on all n! bijections. Readouts report labels at requested positions, or the label set in a requested position scope. Position-permutation commands act by

  T_g(pi) = pi composed with g^(-1).

Only actually recorded command/readout histories may be used for inference. Commands can be generated by adjacent transpositions; an arbitrary permutation is not a free oracle.

A calibration command R_P is known, by the declared universe, to uniformly reshuffle positions within each block of SOME UNKNOWN partition P of the n positions. The partition, component scopes, interfaces and their values are not supplied. A log may contain several calibration commands with different unknown, crossing partitions. The noiseless readout and block-reshuffle assumptions are part of this first test universe; arbitrary sensor noise or arbitrary unmodeled mechanisms are not covered.

## 2. Unknown partition recovery from recorded resets

Given a before/after full-position readout around an occurrence of R_P, track where each observed label moved and add an undirected edge between its old and new positions. Return connected components of the accumulated transfer graph.

No observed edge crosses a true block. If a true block has size b, each old position's label moves to each specified position of that block with probability 1/b per reset. Independent uniform reset draws, or that same conditional lower bound after every past history, imply

  P(a fixed within-block ordered transfer has not occurred in N resets)
  <= exp(-N/n).

A union bound over at most n^2 ordered pairs gives exact partition recovery with probability at least 1-delta whenever

  N >= n log(n^2/delta).

This is conservative: seeing every within-block transfer is stronger than connectivity. The instance input is the recorded readouts and reset-command label, not the partition. Several reset labels use a further union bound. More generally, a known lower bound eta on every within-block transfer replaces n by 1/eta.

No active experiment, unavailable reset, or hypothetical observation is assumed. If the required reset records are absent, this theorem does not apply. Model membership and the transfer-probability lower bound are assumptions, not facts inferred merely from failure to observe a cross-block move.

## 3. Intrinsic observable reset criterion

Let H_P be the subgroup of permutations acting separately inside the blocks of P. R_P averages the permutation operators T_h over h in H_P. It is a stochastic idempotent.

For a transposition tau=(i j),

  R_P T_tau = R_P  iff  i and j lie in the same block of P.

Indeed averaging over H_P is unchanged by a member of H_P. If tau is not in H_P, the relevant coset is disjoint from H_P, so the resulting distributions from every configuration have disjoint supports. Thus the unknown block relation can also be recovered intrinsically from learned observable command operators when the full calibration readout behavior is observationally faithful to these reset operators. An exact predictive intertwining preserves an operator identity forward, but does not by itself reflect the converse: coarse observations may identify distinct reset operators. The stated iff criterion uses the full, faithful calibration behavior. Estimation error must be handled separately.

## 4. Canonical positive reset interface

For a partition P={B_1,...,B_m}, define

  Lambda_P(pi) = (pi(B_1),...,pi(B_m)).

Its values are ordered partitions of the label set with block sizes b_i=|B_i|. Their number is

  Q_P = n! / product_i b_i!.

The rows of R_P are identical precisely when their Lambda_P values agree. Its Q_P distinct rows have disjoint supports, so

  rank(R_P) = nonnegative-rank(R_P) = Q_P.

Consequently ANY nonnegative reset factorization R_P = E D through a finite interface of q states requires q >= Q_P. For the stochastic interface interpretation, E and D are row-stochastic kernels; E may be a stochastic encoding rather than a deterministic map. The canonical factorization uses the interface value Lambda_P and prepares independent uniform bijections B_i -> Lambda_i.

At q=Q_P, with E and D both stochastic kernels, the exposed interface is canonical up to relabeling: each intermediate state must belong to exactly one disjoint support block. Hidden implementation refinements may remain inside a fiber, but cannot merge two different interface values in a minimal positive realization. Without stochastic normalization, a general nonnegative factorization also permits reciprocal rescaling of intermediate generators; canonicality is then not merely up to relabeling.

Equivalent support proof: a product distribution of the local assignments supported only on full bijections must keep each component's label set fixed. Otherwise, fixing the assignments of all other components leaves a unique complement label set, contradicting independence. Hence every positive mixture term supports at most one ordered label partition. All Q_P partitions have positive probability.

This resource statement concerns a reset/preparation interface or a conditional-product factorization. It is NOT a lower bound on an arbitrarily named current memory register if free correlated private initialization or uncharged historical communication is allowed.

## 5. Crossing interfaces and nonunique witnesses

For two candidate cuts S and T, the common refinement has the four position cells

  S intersect T, S minus T, T minus S, complement(S union T).

Write their sizes as n11,n10,n01,n00, allowing empty cells. The jointly realizable interface pair (A,B)=(pi(S),pi(T)) must satisfy

  |A|=|S|, |B|=|T|, |A intersect B|=|S intersect T|.

These conditions are also sufficient. Choose independent bijections between each position cell and the corresponding label cell. There are product_ij nij! witnesses for each accepted interface pair. They are genuinely nonunique exactly when at least one position cell has size at least two; if every cell has size zero or one, the witness is unique.

The number of possible joint interface values, and the minimal positive interface for the four-cell preparation, is

  Q_ST = n! / product_ij nij!.

When all FOUR crossing cells have size n/4+O(1), Q_S and Q_T grow as 2^n divided by polynomial factors, while Q_ST grows as 4^n divided by polynomial factors. Merely requiring the two cuts each to have size n/2 is insufficient for the latter asymptotic. The joint alternatives are not the independent Cartesian product of separately inferred cut interfaces; their intersection cardinality must be retained.

For any finite family of scopes S_1,...,S_l, a proposed family of label sets A_1,...,A_l is realizable by one bijection precisely when every membership-pattern cell has the same number of positions and labels:

  for every b in {0,1}^l,
  |{i : (1[i in S_j])_j=b}| = |{a : (1[a in A_j])_j=b}|.

The proof is constructive matching within cells. Empty cells may be omitted. A realized profile has product_b c_b! witnesses. Its canonical joint interface has n!/product_b c_b! values. This is a complete finite joint compatibility test, not pairwise agreement alone.

The refined preparation is an analysis construction; it need not be a physical reset command already present in the log. It must not be silently granted to the controller.

## 6. Dynamic obstruction without local messages

Fix a nonempty proper scope S, |S|=k. The exposed interface is Lambda_S(pi)=pi(S). With no position-change commands, its persistent readout behavior has a Q=binomial(n,k)-state positive realization and no smaller one: two repeated complete interface probes give a Q by Q diagonal probability matrix.

Now allow all position permutations, generated by recorded adjacent-transposition commands. An interface-only realization must produce BOTH its outputs and its state updates using only its own current state and the command, with NO messages from local component stores and no free external Lambda_S sensor. It must reproduce all later Lambda_S readouts; treating those readouts as an uncharged input would invalidate the lower bound.

Then at least n! positive interface states are necessary and n! suffice.

First, distinct configurations pi and sigma are distinguishable: if pi(U)=sigma(U) for every k-subset U, the permutation sigma^(-1)pi fixes every k-subset setwise and hence is the identity. Commands can move S to any such U.

To make the lower bound intrinsic to the uniform-initial observable law, not to an assumed preparation oracle, choose n cyclic k-subsets U_1,...,U_n. Their position-membership patterns are distinct. For each U_j, apply a permutation g_j with g_j^(-1)S=U_j, probe Lambda_S, and undo g_j. The finite schedule identifies pi and returns the state to pi. Its length is polynomial in n when permutations are expanded into adjacent transpositions.

Let h_pi be the resulting readout word for configuration pi. It has probability 1/n!. Let s_sigma be a repetition of the same command schedule with the outputs associated with sigma. Then

  f(h_pi s_sigma) = 1/n! if pi=sigma, and 0 otherwise.

The controlled Hankel matrix therefore has an n! by n! diagonal block. A q-state positive interface realization has Hankel rank at most q, so q>=n!. This rules out encoding the configurations as overlapping probability distributions over fewer states.

Equivalently, after the identifying histories, the positive state distributions for distinct pi must have disjoint supports: a shared state would have to emit two different deterministic responses under a distinguishing future command word.

This is a dynamic closure obstruction: the static common-information interface is not sufficient to update itself under the permitted command algebra. Bounded local alphabets alone do not eliminate it. The lower-bound mechanism is classical behavioral distinguishability; its role here is a spatial-interface test.

## 7. Exact communication repair

Retain the optimal static boundary Lambda=pi(S), with Q=binomial(n,k) states. Let the two local components retain their actual within-scope assignments.

For a crossing transposition (i j), i in S and j outside S, let a=pi(i), b=pi(j). The correct new boundary is

  Lambda' = (Lambda minus {a}) union {b}.

This is not determined by Lambda and the command. A staged port implementation is exact:

1. The S component sends the index of a in the sorted current Lambda, an alphabet of k values.
2. The complement component sends the index of b in the sorted complement, an alphabet of n-k values.
3. The boundary decodes a,b and updates Lambda. It sends the incoming label b to the S component through a return channel of conditional cardinality n-k, and sends a to the complement component through a return channel of conditional cardinality k. Each recipient uses its remembered old boundary value to decode the index. These return channels are additional charged ports. Alternatively, a broadcast of Lambda' can supply the same information, but that broadcast and its alphabet must be charged rather than treated as free.

For fixed Lambda and command, all k(n-k) pairs (a,b) occur and give distinct new boundaries. For separate, zero-error one-round encoders, the first message alphabet must have at least k values and the second at least n-k. Fixing the other input proves injectivity of each encoder. Randomness does not help exact zero-error performance on this finite domain: fix a seed on which all inputs succeed. Any free correlated side information or extra boundary state must be charged separately.

These are conditional message alphabet sizes. In the explicit relay implementation there are four directed messages: outgoing capacities k and n-k, and incoming return capacities n-k and k. Using one fixed alphabet of raw label names costs n values per directed channel. The lower bound is for the declared protocol, not arbitrary interactive protocols with extra storage or precommunication.

The same construction applies to any partition P: swapping positions in different cells requires the corresponding outgoing labels, with conditional message cardinalities equal to the two cell sizes. This realizes the common refinement of crossing cuts with one coherent persistent witness. Within-cell swaps require no boundary update.

## 8. What the family establishes and does not establish

Within its stated universe, the family gives:

- A polynomial-record route from readouts to UNKNOWN spatial partitions.
- An operator-level test for the inferred partition.
- Exact minimal positive reset-interface cardinalities.
- A complete joint witness criterion for crossing inferred interfaces.
- A factorial dynamic blow-up when local messages are forbidden.
- Exact smaller-interface realization with bounded local messages.

The global process and every local readout process have ordinary positive realizations throughout. What fails is a PARTICULAR constrained spatial interface implementation, not existence of a stochastic environment.

It does not establish a general positive-cone discovery theorem, arbitrary noisy latent representation recovery, or novelty of the combined statements. It is an isolation/calibration family for definitions and resource accounting, not validation of the central architecture-discovery difficulty. Partition recovery uses the special reset records; the genuinely interacting permutation commands enter the later maintenance/resource theorem, not that recovery argument. Classical baselines include positive factorization/nonnegative rank, common-information support components, orbit partitions, and finite-state behavioral distinguishability. No whole-target completion is claimed.

## 9. Representation and observation accounting

A full calibration record contains two arrays of n label names, so its bit length is O(n log n), not one unit. For L reset-command families, N=ceil(n log(L n^2/delta)) records per family suffice by the preceding conservative bound. Their total bit length is O(L n^2 log n log(L n^2/delta)). The readout alphabet, command labels, and any sensor noise parameters must be accounted for separately.

The primitive position-command alphabet can be the n-1 adjacent transpositions. Every permutation used in a query/undo schedule has an adjacent-transposition word of length at most n(n-1)/2. The n subset queries therefore use O(n^3) primitive commands. This constructs a finite distinguishing schedule; inference may use it ONLY when the corresponding records/coverage are actually available. It is not an authorization or assumption of a new experiment.

Full before/after calibration readouts and the projected boundary process are different observation views. Calibration can record every position; the boundary resource theorem concerns the declared Lambda_S port and its command response. It does not require the boundary alone to reproduce all local readouts. If a runtime controller lacks the Lambda_S query port, the query/undo lower bound is not automatically a claim about that controller's available observations. The decomposition certificate may still use offline calibration data; no analysis-derived set readout becomes a free runtime sensor.

The global configuration is stored succinctly as an n-label array, requiring O(n log n) bits, even though its positive finite-state realization has n! states. Similarly, a boundary label partition uses O(n log m) bits and local within-block orders use sum_i O(b_i log b_i) bits. The theorem's exact state-cardinality lower bounds are not exponential bit-storage lower bounds: log(n!) is Theta(n log n), log binomial(n,k) is Theta(n) for balanced k, and the message bounds are log k and log(n-k) bits up to rounding.

Architecture recovery operates directly on the recorded arrays and transfer graph. It never constructs an n! by n! transition or Hankel matrix. The diagonal Hankel block is an existential lower-bound witness, not a matrix the algorithm enumerates. A generic global predictive-basis method would face rank n! here; the reset-universe structure is what enables polynomial-record direct discovery.

The exact statistical guarantee relies on the declared calibration universe. It does not certify that an arbitrary outside-world model is a uniform block shuffle merely because it fits these records.
