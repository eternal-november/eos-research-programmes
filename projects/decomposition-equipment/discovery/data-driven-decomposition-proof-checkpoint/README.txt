Discovering spatial decompositions from recorded readouts

Supporting proof source archive
27 October 2026

This archive supports the accompanying research checkpoint. It is not a claim that the general positive spatial and port factorization target is solved. The main question remains whether unknown components, interfaces and correlated couplings can be discovered from recorded readouts in a declared mathematical universe, without supplying their actual decomposition.

Reading order

1. Permutation_Interface_Discovery_Family.md is an isolation/calibration example: a revealing reset makes the partition recoverable by connectivity. Its exact crossing-interface and resource theorems remain valid, but recovery is not inferred from the harder interacting dynamics used in the maintenance result. It does not validate the central architecture-inference problem.
2. Finite_Observable_Behavior_Certificate.md supplies the finite predictive-law certificate and a finite-horizon error bound. The finite Hankel realization foundation is classical, not the selected main result.
3. Calibrated_Reset_Frame_and_Coupled_Ports.md reconstructs unknown coordinate frames and a coupled staged realization within a strong calibrated sufficient class. Costs scale with the learned global representation.
4. Observable_Channel_Cones_and_Minimal_Deterministic_Ports.md constructs positive local kernels and correlated instructions under a simplicial channel-cone criterion and proves minimal deterministic outgoing-message partitions for its declared protocol. Complete process realization also needs an admissible, separately charged positive initialization certificate.
5. Positive_Channel_Retraction_Extension.md extends the fixed-frame test to redundant nonsimplicial local channels. Under explicit normalized positive retractions, the all-extreme-channel linear feasibility test is complete for the declared protocol; an infeasible test gives an obstruction, but failing to find a retraction does not. The general unknown-frame and crossing-factorization problem remains open.

The source manifest identifies each proof and test, its evidence status, assumptions and checksum. All proof notes retain their limitations and attribution to classical mechanisms. There is no novelty-priority claim or completed Lean verification claim.

The files under checks contain finite regression programs and their recorded JSON outputs. The predictive program requires Python 3 and NumPy; the permutation program requires only Python 3's standard library. The channel and retraction program requires Python 3, NumPy and SciPy; its linear programs use floating-point numerical solvers, not exact proof certificates. From the checks directory, run:

python3 check_predictive_certificate.py
python3 check_permutation_interface_family.py
python3 check_channel_port_certificates.py

These programs test small synthetic instances. A passing result is not the proof for all sizes, validation on environmental data, or certification of the declared model universe.

No external experiments or new sensors are assumed. The permutation discovery theorem needs actual full-position before/after reset logs and an explicit uniform-block-shuffle universe. Its n! state count is Theta(n log n) bits, not an exponential bit-storage bound. Analysis-only interfaces are not free runtime controller inputs.
