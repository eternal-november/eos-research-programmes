# Independent preflight review of certificate guided discovery

Reviewer note 29 October 2026. This is a scope and failure-case checklist, not approval of the developing theorem.

## Existing results which cannot be counted again

Typed_Cover_Descent already defines the exact specified-endpoint lift fibre, proves why quotient reconstruction need not fill it, retains dependent joint forest domains, and warns that individual lifts do not solve crossings. Mixed_Presentation_Criterion already supplies structural residual descent for arbitrary constructor depth. KernelPair_Provenance_Repair already keeps all original records and proves noninvertible reindexing via weak seam matching, explicitly changing from sets to groupoids.

The new burden must therefore be constructive extraction and composition of selected concrete discovery certificates after genuinely forgetting boundaries. Merely retaining the full old record or defining the fibre by its intended solution does not discharge it.

## Exact separator requirement

Suppose a partial certificate has relation R on its exposed boundary B and private variables U. Eliminating U gives the exact relation S=exists U.R. This is safe against a continuation T only when every variable T shares with R is among B. Renaming a shared variable into two fresh variables changes conjunction into independent existence and can make an impossible request succeed.

Minimal counterexample: R forces the shared source s=0 and T forces s=1. Each is satisfiable, but their conjunction is not. Forgetting s from both makes both scalar truth values true. Mapping both source values to one quotient name has the same defect if quotient equality is used as actual equality.

There is no theorem that exact marginalization is safe against arbitrary future contexts which can reopen an eliminated variable. Safe reuse needs a declared interface containing all future joins, or provenance sufficient to reintroduce the constraint.

## Noninvertible change and nullary comparison

For f:A'->A, direct images of relations along f need not preserve intersections. Let A'={0,1}, A={*}, R={0}, T={1}. Then f(R) intersects f(T), while R intersects T is empty. Joining only quotient boundary names admits a false concrete realization. A relational transport certificate must retain the equation f(x)=a and the relevant old x, or another exact coupling relation. Requiring two independently chosen new names to coincide is instead too strong when only old-value equality is intended; the doctrine must specify which equality it uses.

The nullary identity is also diagnostic. Pulling back the old diagonal along f x f gives {(x,y): f(x)=f(y)}, not the new diagonal {(x,x)}. For the constant two-to-one map it has four pairs rather than two. On-demand certificates can select valid pairs but cannot turn that comparison into a bijection. A theorem must not slide from set-valued witnesses to the previous groupoid repair without announcing the change.

## Exact compression lower limit

Let each partial witness x admit continuation boundary states R_x subset B. A summary q is sufficient to decide whether x can be completed against every set-valued continuation T subset B exactly when q(x)=q(y) implies R_x=R_y. Sufficiency is immediate. Necessity follows by taking T={b} at a boundary state in the symmetric difference. For a declared restricted family C of continuations, equality of the Boolean signatures (R_x intersects T is nonempty) for T in C is necessary and sufficient.

Thus a task-relative contract may permit substantial compression, but arbitrary future context reuse forces retention of the full residual possibility relation. This is a standard contextual-equivalence observation, not a novelty claim.

## Cost requirements

A treewidth claim must specify the primal or incidence graph of the actual certificate constraints, including shared world variables, source process choices, interface functions and occurrence aliases. Physical wiring width alone is insufficient. Finite domain sizes and their explicit encodings must be included.

Computing one satisfying assignment using a supplied width-w elimination order can have cost proportional to d^(w+1) times instance size. Exporting a flat relation on k retained boundary variables can still cost d^k even if one solution is cheap. Distinguish one witness, a factored representation of all witnesses, and an explicit list of all witnesses. Retaining backpointers proves existence and permits one reconstruction; it need not compactly enumerate all alternatives.

An unsatisfiability certificate based on elimination tables can have the same width-sensitive size as the computation. Do not claim arbitrary no-instances have polynomial certificates. Rational probabilities, unknown functions and coefficient maps do not have bounded finite domains without an explicit representation promise.

## Source calculus coverage

A valid compiler must retain actual ordered partitions, induced subgraph maps, complete input profiles, repeated occurrence identities, coefficient maps and scalar labels. Original C5 has binary cuts C, nullary U_A and unary D(W,m), with R, UL, UR, D0, DA, DL and DR. The span extension has different generators and additional maps; original soundness is not full cell generation. Nullaries retain their sole common vertical map; a genuinely singleton forest cannot adjust scalar labels.

The compiler must separately justify each crossing equation and any noninvertible interface relation. Coherence means comparing the same concrete global assignments under coordinate reassociation, not choosing unrelated local witnesses and then invoking associativity.

## Discovery and task scope

A certificate relative to a declared model or model family is not validation that an actual physical environment belongs to that family. One possible concrete explanation does not establish every consistent environment supports the discovery. Stating that ambiguity remains is acceptable; hiding an existential quantifier behind a safety conclusion is not.

A boundary-forgetting quotient is not task sound merely because its requested refinements have witnesses. Task-relevant observations, operational semantics and permitted controls need an independent preservation argument. Conversely, successful task abstraction does not imply fixed-endpoint lifting.

## Multiplicity under source equations

Compilation invariance under original equations should normally assert equality of projected exposed relations. It must not silently assert a bijection of all internal CSP assignments. Contracting a scalar-bearing tree records only the product at the root, while several local scalar vectors may have that product. Raw decorator placements are not semantic operation invariants; specified refinement child labels are retained until the arrow is evaluated. These two facts are compatible, but require explicit variable scoping.

An arbitrary concrete coefficient map is evaluated on actual composable tuples. Its table, and the size of a composite apex when explicitly constructed, may be exponential in a compact diagram. A compiler cost measured only in graph vertices or primitive arrows hides this cost unless the map representation supports a proved symbolic evaluator.
