# Finite recognition of all hardware-compatible semantic decomposition profiles

## Plain-language abstract

A controller can fit each partial description separately while the pieces, when combined, admit executions that never belonged to the actual environment/controller pair. Checking a few shallow decompositions will not rule this out. This theorem gives a finite test for every profile generated by a finite decomposition grammar, with no bound on the number of pieces. It retains the same installed hardware and the actual state/event records throughout.

The test is constructive. It scans a proposed family of component maps. One check detects actual root records that the pieces fail to distinguish. Another chooses a tuple of component records and keeps track of which root records could explain all its coordinates. If that set becomes empty, the tuple is an explicit invented execution. Importantly, permitted tuples are constrained by independently specified shared-interface, shared-memory and persistent-world rules; they are not formed by freely joining unrelated marginal descriptions.

The automata and grammar-saturation methods are established mechanisms. The result is their explicit extension to the coupled operational semantics and resource-sensitive witness problem. It does not claim efficient synthesis of unrestricted controllers, and it does not turn every arbitrary family of joint constraints into a finite automaton.

## 1. Fixed physical implementation, finite operational carriers

Fix one finite physical controller architecture and ONE selection kappa of its permitted primitive tables, stores, readouts and program-phase implementation. This selection is made before the unknown physical environment. The finite persistent physical completion family Omega is nonempty. Mathematical decomposition choices are proof data, not adversarial physical parameters; they may be bundled per world as described in Typed_Persistent_Completion.md.

For each omega and component color d, construct the actual selected coupled graph K_d^omega. Its states are actual environment-state/memory pairs and its events are actual adverse environment records coupled to the selected request and memory update. Use the actual reachable joint support or an explicitly named inductive support; do not replace it by independent marginals. Request/reply stages and available observation ports are computed from the primitive wiring. The same physical table is used wherever its identifier recurs.

The finite environment/decomposition signature supplies a context-free language L_c of allowed ordered leaf-color profiles for each root color c, by the original generator-tree profile grammar. A specified finite-state filter can demand nontrivial constituents or exclude the identity profile; that demand must be part of the requested discovery problem, not invented after a result. The theorem treats every semantic coordinate family on such a profile, not only maps obtained by interpreting old generator terms.

Fix root c. A letter ell consists of:

- a leaf color d;
- the physical alias/port identifiers of that occurrence;
- ONE permitted physical memory map eta_ell, independent of omega;
- for each omega, an actual candidate environment/proof map f_ell^omega, producing h_ell^omega(x,m)=(f_ell^omega(x),eta_ell(m)) from K_c^omega to K_d^omega.

The alphabet is finite. A memory view that merely names an existing store projection is proof bookkeeping; a view requiring a runtime adapter must use an adapter table already selected in kappa. Unbounded words may repeat names of existing physical stores, but do not allocate unbounded fresh memory. Construct the alphabet by enumerating the permitted finite map tables and checking actual graph incidence, local selected-command and update-cube conditions of Typed_Causal_Presentation_Closure.md. A single leaf need not by itself reconstruct a root request that combines several component ports. The global physical-assembly monitor below checks that additional requirement. Thus h being a coupled graph map is a CHECKED consequence of physical tables, not an assumed strategy-lifting property. If proof-carrier choices must be held fixed across letters, a finite registry in the recognizer enforces those identities. The same applies to a repeated physical alias: its map cannot be changed independently at a later occurrence.

### Finite global physical-assembly monitor

The physical implementation is a fixed finite, phase-respecting primitive DAG with named nodes, input/output ports and owned stores, or a finite explicitly bounded selection of such DAGs. A candidate letter identifies which existing nodes/ports/stores its component presents and their actual port maps. Build a finite monitor whose state records: the covered node/port/store identifiers; the selected table and ownership assignment at each identifier; and the finite request/update truth maps contributed at the covered ports. The truth maps are computed by evaluating the specified primitive tables on their permitted physical memory/observation inputs, not by exposing a hidden environment coordinate to the driver. Repeated aliases must give the SAME table, port map and writer identity.

At the end, check the required coverage and evaluate the actual supplied wiring in phase order. Its root request and memory-update truth maps must equal those of the stipulated physical implementation on the declared input domain. Explicit glue nodes may perform their permitted operations, but are part of the same counted finite architecture; no fresh operator or store is allocated per letter. Reject missing required ports, inconsistent writers, unavailable input dependencies and incorrect assembly. This is a finite-state check because the architecture, identifiers, table libraries and all table domains are finite. It is not a per-leaf request reconstruction condition or an oracle for strategy existence.

When only a semantic description of an already installed kappa is requested, coverage means the specified chart interface, not necessarily a hardware replacement by those leaves. If actual recovery of the root memory from the leaf memories is claimed, additionally test the MEMORY-ONLY tuple map against the independently specified hardware-memory joint support using the same image/injectivity/surjectivity machines on that finite carrier. Coupled state/event exactness alone is insufficient: its inverse might recover memory using hidden environmental state. An online inverse/adapter also must belong to the permitted physical implementation library; the graph inverse is not automatically such a program.

A single word therefore carries world-specific mathematical maps but the SAME physical implementation and alias choices. It may not secretly choose a different runner for each omega or each occurrence. World-specific discovery profiles instead of a common profile are a distinct quantifier variant, handled by checking the corresponding languages separately while retaining the same kappa.

## 2. Independently specified target joint records

For each omega and graph sort s=0 (state) or s=1 (actual event), the desired tuple support is specified by a finite automaton A_s^omega. It reads an augmented record word

  LEFT(b), (ell_1,z_1), ..., (ell_n,z_n), RIGHT(b'),

where z_i is an actual s-record of K_di^omega and b,b' are actual outer boundary s-records. A target record is this augmented word, NOT an accepting run of an automaton. If additional witness multiplicity is required, its identity must be added as an actual coordinate; nondeterministic accepting runs do not supply unnamed physical records.

The machine is derived from independently declared finite tuple constraints. Examples include adjacent boundary equality, equality of repeated physical store values, a shared persistent world/matching identifier, and finitely many named crossing-anchor registers. For a fixed finite registry, these machines are constructed by storing the current boundary and the previously chosen values of the named shared coordinates. An arbitrary unbounded crossing doctrine is NOT presumed regular merely because every individual carrier is finite.

The support machine must not be defined as 'the image of the candidate root map'. That would make surjectivity a tautology. Its input constraints describe which combinations the component descriptions claim are possible independently of the proposed candidate coordinate family. Its transition may use a letter's color and declared physical alias, but may not manufacture target support by consulting the image h(K_c) to evade reconstruction tests.

The empty profile is represented by LEFT(b),RIGHT(b) at its boundary type. Its target is the declared boundary support, not a singleton. Nontrivial boundaries, empty supports and parallel boundary event records are retained.

Check that every accepted target word obeys the declared typing/boundary constraints, and that the source and target of every accepted event word are accepted state words. These are finite regular-language inclusion checks: apply the coordinatewise source/target token map and compare with A_0. They can be restricted to L_c by context-free/regular emptiness if desired. Consequently every profile word ell_1...ell_n defines an actual target joint-support graph J_ell^omega, not unrelated state and event tables.

For a given candidate word, the proposed map is

  H_ell^omega(x) = LEFT(left_c(x)),
                  (ell_i,h_ell_i^omega(x))_i,
                  RIGHT(right_c(x)).

Its state and event incidence follows from the checked h maps, PROVIDED its image lies in J. That image condition is part of the recognition test below. The same definition applies at n=0 using the actual two boundary legs.

## 3. The three finite defect languages

For fixed omega and sort s, construct the following finite automata over candidate letters ell. Component record choices are hidden nondeterministic choices of the defect machine, not choices granted to the physical controller.

### Image defect

Choose an actual root record x. Feed A_s the initial token LEFT(left_c(x)); on ell feed (ell,h_ell(x)); at the end feed RIGHT(right_c(x)). Accept precisely when A_s rejects. Determinize/complete A_s first if needed. Since the root carrier is finite, this is a finite machine. If the root carrier is empty there is no image-defect witness.

### Injectivity defect

Choose distinct root records x,x' with equal left boundary values. At each letter retain this pair only if h_ell(x)=h_ell(x'). Accept at the end if their right boundary values also agree. This accepts exactly when two root records have the same complete augmented tuple. The initial/final boundary tests are essential for the nullary case.

### Surjectivity defect

Choose a permitted initial boundary value b. Start the target-support machine after LEFT(b) and set

  S = { x in K_c^omega_s : left_c(x)=b }.

On a candidate letter ell, choose an actual component record z of its indicated color, feed (ell,z) to A_s, and replace

  S by S intersect h_ell^{-1}({z}).

At the end choose an outer right boundary value b', feed RIGHT(b'), and intersect S with {x:right_c(x)=b'}. Accept exactly when the target-support machine accepts and S is empty.

The invariant is exact: after each prefix, S consists of the root records explaining every chosen coordinate and boundary value so far. Thus acceptance produces an actual admitted target tuple with NO root preimage. The state space is finite: it contains a target-machine state and a subset of the finite root carrier (plus typing/alias registers). Empty root and boundary carriers are handled literally. For an empty profile this tests the preimage of the boundary record under the retained common leg, rather than pretending that the empty tuple has one preimage.

All three languages are regular. Construct them separately for states and events; event multiplicity is not inferred from the state check.

## 4. Recognition theorem

Typing uses the ORIGINAL syntactic interface vertices and component endpoints, not equality or isomorphism of their assigned semantic boundary graphs. Each row and column recognizer retains its own root endpoints; an empty subsequence is admissible only for a syntactic loop, even if two distinct vertices happen to carry identical boundary tables. Repeated component colors remain distinct occurrences; they share a physical alias only when the supplied alias identifier says so.

Let V be the regular language of typed/alias-consistent candidates that also pass the stipulated finite global physical-assembly monitor (and memory-only recovery monitor when that stronger hardware realization is requested). Let Bad be the union of the three defect languages over BOTH graph sorts and EVERY physical omega. Define

  Exact = V minus Bad.

**Theorem 1.** A candidate word belongs to Exact precisely when its SAME physical implementation and coordinate family induce a bijective graph map

  K_c^omega -> J_ell^omega

for every physical omega, preserving the stipulated phases and physical primitive interpretation. The inverse is a genuine record reconstruction, not an independently chosen action for each hidden world.

**Proof.** The image machine accepts exactly the failure of membership of some root record in the target support. Conditional on image membership, the pair machine accepts exactly failure of injectivity. The subset invariant proves exact equivalence of the third machine with failure of surjectivity. Absence of all defects on both sorts gives state/event bijections. The checked incidence squares give a graph map, whose inverse commutes with incidence by bijectivity. The letter alphabet and global registry fix the physical memory maps and tables consistently; the finite assembly monitor checks their joint command/update realization and required coverage. The optional memory-only check is necessary for the stronger hardware-recovery claim, not inferred from environmental correlations. Conversely a claimed exact coupled map has none of the three witnesses. QED.

This theorem supplies more than separate statewise suitability tests: it detects extra compatible component EXECUTIONS and event-only loss even when every local state/command summary appears adequate.

**Theorem 2 (all generated profiles).** The following are decidable from the finite input, without a depth or leaf-count bound:

1. Whether some requested profile in L_c has a hardware-compatible exact semantic realization: emptiness of inverse_color(L_c) intersect Exact.
2. Whether every candidate in a specified regular candidate class R on L_c is exact: emptiness of inverse_color(L_c) intersect R intersect complement(Exact). Since Exact = V minus Bad, this also detects candidates outside V (invalid typing, aliases, coverage or physical assembly), not only graph defects. The simpler intersection with Bad is sufficient only when R is explicitly restricted to V.
3. Whether every coarse accepted candidate in one such presentation is also accepted after a proposed fine interface/cut comparison: intersect the coarse acceptance language with the complement of the fine acceptance language, using a common finite paired-letter alphabet carrying the actual comparison squares.

The third item does not infer that arbitrary coarse/fine descriptions have a common alphabet or physical implementation. Those maps, request/reply types and implementation constraints must be supplied and checked. It does not silently create extra sensor access.

**Proof.** Replace each terminal color of the finite profile grammar by the finite set of candidate letters of that color. This gives the inverse-image context-free language. Intersect with the finite automaton for the relevant regular property. Emptiness is decidable by saturating, for each grammar nonterminal, the relation of pairs of automaton states connected by a derived word. Each production composes these finite relations; epsilon uses identity only at the proper typed positions. There are finitely many nonterminal/state-pair facts, so saturation terminates. Induction on derivations proves soundness; induction on a finite parse tree proves completeness. Retaining predecessor facts reconstructs a finite derivation. For a rejected candidate inside V, the corresponding defect automaton supplies an exactness defect tuple or distinct root pair; for a candidate outside V, the validity monitor supplies the failing typing, alias, coverage or physical assembly check instead. An accepted existential candidate carries its successful monitor run. Thus the procedure covers arbitrary finite generated trees, including cycles/epsilon in the grammar, rather than testing a chosen depth. QED.

For bounded synthesis, enumerate only permitted physical table tuples kappa, chosen outside the universal physical-world quantifier. Each tuple receives its own finite tests. The grammar algorithm may select world-specific mathematical coordinate maps bundled in its letters but cannot alter kappa during a word. Existence of some exact decomposition is distinct from universal exactness of all semantic candidates; neither should be substituted for the other.

## 5. What is derived across time and refinement

For an accepted exact candidate, the coupled graph isomorphism yields bijections on executions of EVERY finite length, retaining the same physical omega and every actual record. These commute with truncation and concatenation. Consequently a root controller already verified against the finite safety/stopping monitor can be represented through that joint description without inventing or removing adverse executions. The reconstruction theorem alone does not prove that the root controller meets the task; the physical controller check must also pass.

The allowed source-refinement and crossing equations remain those of the presentation. When the target supports are generated by relative joint-support substitution, use the explicit blockwise inverse construction in Typed_Causal_Presentation_Closure.md: inner joint constraints plus outer recovered-parent constraints define the composite support. This proves all-tree causal compatibility and relative exactness while retaining correlations. A regular support machine used for a composite profile must agree with that generated support before one claims the same refinement diagram. A separately supplied regular machine is not automatically coherent with substitution merely because its language is finite-state.

Thus there are two complementary guarantees, not one silently conflated claim:

- Grammar recognition checks ALL semantic coordinate discoveries on the allowed profiles against independently specified finite-state joint supports.
- Finite primitive update/command/crossing tests prove all-generated refinement coherence for the declared support-substitution doctrine.

A discovery claimed to participate in that doctrine must satisfy both. This does not discharge arbitrary semantic crossing recognition or the full virtual-equipment contract.

## 6. Resources, observations and remaining limits

The subset machine is exponential in root-record count before determinization; complementing nondeterministic machines can increase the cost further. The grammar saturation is finite, not a practical complexity guarantee. Structured implementations can exploit the actual finite interfaces, but no unproved efficiency claim is made.

Memory bounds are imposed on physical kappa, including driver state and protocol phase unless an external clock is explicitly supplied. They are NOT measured by the internal memory of this offline proof-search algorithm. A finite offline recognizer does not give the robot its own hidden-world subset state.

All-outcome support semantics is used. Probabilities, expected cost and almost-sure objectives need additional kernel data and preservation theorems. Initial descriptions and their coverage are assumptions; the result does not identify a real environment from readout data alone. A failed exact-discovery certificate can coexist with a suitable controller that does not realize the requested decomposition, and a controller's inability to certify admission is not proof that the physical zone is unsafe.

## 7. Constructing an unknown common refinement of crossing descriptions

The preceding recognizers can find a common refinement rather than merely checking a supplied one. The following class is deliberately explicit about the crossing pattern and generated language.

For each physical omega, fix two witnessed exact coupled descriptions of the SAME root K with the SAME outer typed boundary maps:

  U: K -> J_U subset P(U_1,...,U_r),
  V: K -> J_V subset P(V_1,...,V_s).

Here exact means bijective on actual states and events onto the retained joint supports J_U and J_V, as in the relative-support theorem. The supports and root maps are given finite data, not independent marginal joins. Their physical memory views are part of the SAME implementation kappa. Invisible component sectors are retained if supplied; an inner refinement is tested on its stipulated entire support rather than silently discarding sectors unused by a particular root.

A prospective leaf occurrence is assigned to one cell (i,j). Its letter contains a permitted component color d, actual maps

  h_i^omega: U_i -> K_d^omega,
  k_j^omega: V_j -> K_d^omega,

and their permitted physical memory views. Retain the letter precisely when both sets of primitive causal/physical tests pass and the root composites agree on BOTH states and actual event records:

  h_i^omega composed with U_i-projection composed with U
    = k_j^omega composed with V_j-projection composed with V.

This is a finite table equality. Alias and memory maps remain globally fixed, not chosen separately for each crossing chart or world. The letter does not assert that the whole refinement already exists.

Supply ONE context-free language Gamma of complete cell-tagged candidate words, with a finite regular order/type filter. For example words can be in row-major cell order, with an unbounded grammar-generated sequence within each cell. Gamma is the independently specified simultaneous refinement doctrine. The row-i profile is obtained by erasing all letters outside row i; the column-j profile erases letters outside column j. These inherited orders are actual data. A column-major traversal of the whole leaf set uses the stable subsequence order within each column.

Do NOT impose several arbitrary independent context-free membership tests on those subsequences: intersections of context-free languages need not be decidable. If parent-specific profile restrictions are wanted, they must be encoded by the one common Gamma or by additional REGULAR monitors. This restriction is part of the theorem's class, not a hidden use of a general grammar-intersection algorithm.

For each U_i and V_j, independently specify its finite tuple-support machine for the possible inner refinement, with the same well-formedness requirements as section 2. Construct its exactness recognizer from section 3. Extend a row recognizer to the global alphabet by doing nothing on letters outside that row; similarly for each column. This is the inverse image under an erasing homomorphism, hence regular. Form the finite product of all row/column recognizers and the alias, typing, order and physical-implementation monitors. Test Gamma against this one finite product machine.

**Theorem 3 (crossing common-refinement recognition).** The intersection is nonempty if and only if there exists a finite common semantic refinement in this cell-incidence/language class such that:

- every row and column inner refinement is exact onto its specified joint support on both graph sorts;
- every leaf occurrence has the same actual root map through either parent description;
- one physical implementation supplies all memories, observations and primitive tables;
- the stated typing/order/alias constraints hold in every physical omega.

If nonempty, a word, the actual inner maps, the named LEAF occurrence bijection, both refinement forests, and an actual graph comparison of their retained joint targets are constructively recovered. The comparison includes boundary transport; it is not asserted to be a bare permutation of every retained internal boundary record. If empty, there is NO such refinement of ANY permitted finite arity, not merely none below an enumeration bound.

**Proof.** Necessity follows by reading the existing refinement's ordered leaf occurrences into a word: each row/column projection passes its exactness recognizer, the same root maps pass the letter test, and its shared physical implementation passes the global monitors. Conversely an accepted word gives exact row and column graph maps and their inverses by Theorem 1. Substitute all row maps into U using the explicitly retained joint-support rule: the global row target consists of leaf tuples whose row blocks belong to their inner supports and whose recovered parent tuple belongs to J_U. The map from K to this target is bijective. Do the same for columns and J_V.

Write H_U and H_V for the two bijections from K onto the generated row and column joint targets. Define the comparison explicitly by

  Phi = H_V composed with inverse(H_U).

It is a graph isomorphism by construction and preserves the common outer boundary. An explicit common augmented joint object is the graph of Phi, namely the pairs (u,v) with v=Phi(u). It retains the union of both boundary registries with their actual consistency relation; its projections to the two targets are bijective. It is not their unconstrained product, and it introduces no new free boundary values. For each named leaf occurrence, its projection after Phi agrees with the corresponding row-leaf projection by the letterwise root-composite equation. Thus Phi implements the stated LEAF occurrence bijection without identifying repeated colors. Every internal column-boundary coordinate is transported by the actual map obtained from H_U^{-1} followed by its column-boundary map; none is silently discarded, including boundary data of empty rows or columns.

Equality of leaf coordinates alone would NOT justify saying that Phi is a pure permutation of all retained internal boundary coordinates. The present conclusion is a common refinement in the category of retained joint-support diagrams with this explicit boundary comparison. If the application prescribes a stronger coordinatewise boundary comparison, supply a finite named boundary registry and its transport maps and add equality of their root composites to the finite checks. These comparisons cannot be inferred merely from matching leaf names. Fixed finite registries can be stored by the same regular monitors. No extra online sensor access is granted by the proof-level comparison.

This does not assume a general permutation symmetry or equality of the two profile types in the planar source. The comparison is defined ONLY on these recovered joint supports. Boundary compatibility in each traversal has already been checked by the respective support machines. Empty rows and columns are recognized by their actual boundary maps, not discarded. Finally Gamma/regular emptiness gives the unbounded existence/no-existence decision and a concrete accepting derivation. QED.

A successful comparison preserves the actual executions of the one root controller in every admitted world. It does not grant a new physical observation order: spatial regrouping of leaf coordinates and temporal reordering of reads are distinct. A temporal interface change must pass its own physical/cut-code tests and can change the required memory, as the coupled resource families demonstrate.

The output maps are semantic coupled refinements. A generated profile does not imply that every discovered map is denotable by the previously chosen source generators; such syntactic completeness is not claimed. The theorem constructs an unknown refinement for fixed crossing parents and a supplied finite simultaneous grammar. It is NOT a theorem for arbitrary crossing networks with arbitrary independent grammars, nor a globally functorial choice of refinements for every possible input diagram. It is nevertheless stronger than requiring a common refinement as an input, checking one chosen depth, or declaring arbitrary compatible marginal tuples to be actual executions.
