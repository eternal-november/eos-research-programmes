COMPLETE WITHIN THE STATED MATHEMATICAL HYPOTHESES

1. One genuine crossing four-component schema, with one unknown component:
   under the stated nonempty visibility fibres and nonempty parallel interface,
   a rectangle reconstruction followed by the actual-Q, fixed-witness, and
   cross-level cylinder tests is necessary and sufficient. Successful fixed-data
   realization groupoids are contractible. A prescribed support relation is
   handled by an additional exact support test.

   A complementary finite normal-form theorem handles all empty-fibre cases
   of this same four-component schema. It enumerates explicitly bounded typed
   matching data modulo free relabelling, together with arbitrary finite sets
   on completely invisible endpoint pairs. Those invisible sets retain their
   permutation symmetries. This is a terminating existence procedure and a
   complete groupoid presentation, not a claim of an efficient algorithm.

2. One elementary finite-span interpolation square, including empty fibres:
   the source classifies the entire realization groupoid. Fully visible sectors
   are determined by labelled rectangles; one-sided invisible sectors retain
   finite tilings; doubly invisible sectors retain arbitrary finite sets and
   their permutation symmetries. Its structural classification is separate from
   the bounded-matching normal form for the full four-component schema.

3. Specified context transport and fully visible internal-interface retyping:
   the explicit transport laws preserve the given realizations under their
   stated hypotheses. They do not identify every new solution after arbitrary
   context changes, nor grant arbitrary changes of internal interfaces.

4. One-unknown relational synthesis in union-preserving contexts, support
   abstraction, finite conservative-refinement counterexamples, and concrete
   finite-state observation obstructions and repairs.

5. Decision complexity for explicitly listed finite inputs: the fully visible
   four-component problem is in P; the general problem is NP-complete, both
   with and without prescribed middle support. The hardness construction loses
   one side's exposing witnesses. This does not make the visible structural
   test NP-hard, and does not classify compressed input representations.

CENTRAL EXAMPLE

The four-component bit-grid has nonidentity R, T, Q and S behavior. The positive
and negative instances have identical supports, event counts and component
behaviors. Both even have an ordinary witnessed-square completion. Only the
untwisted prescribed whole-event matching admits the required cylindrical
four-component realization. The negative proof permits arbitrary names for
the missing component's events, not just a failed preferred construction.

REPRODUCTION

Use Python 3 and its standard library; no external packages are required.
From the extracted package directory run:

  python3 checks/run_checks.py

The runner executes copies in a temporary directory and compares each resulting
JSON object with the bundled result. It does not modify these source files.
SHA256SUMS records the exact delivered bytes, excluding itself. Original and
delivered source hashes, with editorial-change notes, are recorded in
SourcesAndVerification.txt. Runtime regression evidence supports the proofs;
it is not a substitute for them.
