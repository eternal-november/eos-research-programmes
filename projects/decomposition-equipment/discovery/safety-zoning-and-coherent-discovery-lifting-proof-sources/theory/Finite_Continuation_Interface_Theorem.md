# Finite continuation interfaces and the separate witness-lifting test

Scope: a continuation-interface and conditional-certificate theorem for the explicitly declared finite class. Finite Boolean-algebra minimization and relational bisimulation are standard mechanisms. Sections 7–9 establish their specified integration with interpreted typed occurrence/refinement probes and the generated-profile witness-lifting test. This is not a novelty claim for the standard quotient construction, nor an integration theorem for undeclared cut operations or arbitrary physical models.

## 1. Explicit finite class
Fix a finite many-sorted carrier family S_t. A sort can be an owner resource state, a controller information state, an entry/exit boundary record, or an actual cut-witness record. Every sort is finite. Fix a finite typed probe signature containing:

* designated predicates (unsafe, nonblocking admission, zone membership, required exit condition, observable outcome tests, as appropriate);
* designated total maps, interpreted contravariantly on predicates by inverse image;
* designated relations R:S_t -> P(S_u), interpreted by the demonic operator [R]P={x:R(x) subset P};
* designated enabledness predicates En_R={x:R(x) nonempty} whenever nonblocking matters.

Relations are ACTUAL model relations. Nondeterministic alternatives remain separate outcomes; a controller does not choose them. Action-labelled relations R_a are kept separate. The alphabet may include the already interpreted finite generator-level cut/restriction probes, but they must be supplied as actual maps/relations with their equations checked. A theorem does not follow by writing the word 'cut' on an arbitrary relation.

For control, use an actual finite information-state carrier I, for example a specified finite belief update model. Its elements encode exactly what the controller knows at decision time. A safe information state B satisfies B subset Good_X. R_a(B) is the set of all possible next information states under that SAME action a, including all allowed adverse outcomes. Add the separate designated predicate Adm_a(B) iff action a is enabled at EVERY concrete state compatible with B. This need not equal En_Ra(B): an aggregate successor relation can be nonempty even when another compatible concrete state blocks. Alternatively define R_a(B) to be empty whenever Adm_a(B) fails, and document that convention. Admission checks use Adm_a, not merely nonemptiness of an aggregate relation. This information-state model, its initial states, and observation update are part of the input evidence. Alternatively one may work on actual owner states, but then every selected action/predicate must separately pass the physical-observation test in section 5.

## 2. Construction and theorem A
For each t begin with the Boolean algebra generated by its designated predicates. Repeatedly close the family under every designated inverse-image and demonic operator and under Boolean operations. Because each P(S_t) is finite, the ascending construction stabilizes. Denote the least closed family A_t.

Define x equiv_t y iff all P in A_t have the same truth value at x and y. Let Q_t=S_t/equiv_t and q_t:S_t -> Q_t. Every A_t is precisely the algebra of unions of equiv_t classes (finite Boolean algebras are their atom algebras).

**Theorem A.**
1. Every finite formula/context generated by the declared predicates, Boolean operations and typed probe operators denotes an element of A. Thus its verdict is exactly determined by q.
2. q is the coarsest sorted state summary with that property: if h determines every generated verdict, ker(h_t) subset equiv_t. The quotient q is unique up to unique isomorphism as a partition, not as arbitrary physical hardware.
3. Each map f descends to a well-defined map fbar. Each relation R descends to Rbar by successor classes, and for all x,y with qx=qy,

   {q(z):z in R(x)} = {q(z):z in R(y)}.             (1)

   Consequently q^{-1}([Rbar]Pbar)=[R](q^{-1}Pbar), including empty successor sets; enabledness is preserved when included as specified. This is exact demonic permission transfer for the generated probe language.
4. These comparisons commute with every finite well-typed composition of the designated operators, including arbitrary finite repetitions and generator-tree substitutions. Any actual operator equation between such contexts that holds before quotient also holds after quotient. This is not an assertion that a missing mixed-cut equation holds before quotient.

**Proof.** (1) Structural induction and closure. (2) Every element of the least closure is represented by a finite generated expression: the fixed point is the union of finite stages and each finite Boolean combination/operator application is a finite term. Thus all adequate h separate every pair separated by A. Conversely q determines all A predicates. (3) For f, inverse-image closure of every target atom implies equal source classes map into equal target classes. For R, if an atom C is reached from x but not y, [R](S_u minus C) distinguishes x,y, contradicting equivalence. Conversely equal reachable atom sets determine the universal condition. (4) Substitute the inverse-image equalities inductively. Surjectivity of q reflects equality of quotient predicates, so actual operator equations descend. QED.

A finite stabilization bound is sum_t max(|S_t|-1,0) strict partition refinements after the initial partition: every genuine enlargement of a finite Boolean algebra splits at least one atom. This is not a polynomial algorithm claim; representing whole predicate algebras naively is exponential. Standard partition refinement avoids explicitly listing every predicate in many signatures.

## 3. Uniform actions, not a quantifier swap
A quotient policy chooses a single action a at a quotient information state. Pull it back to that information state, with the same action for all represented concrete possibilities. If its action-specific demonic successor condition is safe and nonblocking, the pulled-back policy preserves that condition. Arbitrary finite safety certificates and finite rank certificates formed using the declared predicates/probes transfer by theorem A. An existential choice of an action separately for each hidden concrete state is NOT admitted by this argument.

For reachability, a finite ranking or an explicitly defined fixed-point construction is needed; safety alone is not task completion. The finite quotient exactly preserves fixed points built from its closed operators, since its predicate inverse-image is a Boolean-algebra isomorphism onto A. This is model-relative, not a claim that the robot's world model is empirically complete.

## 4. Conditional zoning and refinement
A zone certificate is an implication or operator inequality involving its ENTRY information/resource predicate, action-specific protocol, and EXIT predicate. Refinement may move a cut past a cooling/calibration action. The subzone then receives the appropriate transformed entry predicate; it does not inherit an unconditional 'safe' label. If the concrete cut/restriction/protocol maps used in that transformation are among the generators (or their interpreted composites), theorem A preserves the entire conditional certificate and every finite re-expression by the verified source equations.

For a finite original typed generator presentation, generator trees are unbounded in size but the semantics of all generated probe terms is covered by the structural induction. To claim an original source refinement is represented, one must explicitly define its predicate operation from the actual record map and prove the required mixed restriction/substitution identity in the concrete model. Naming all possible refinements in the generator signature would evade the finite-basis obligation and is not allowed.

## 5. Physical implementability and exact information lower bounds
Suppose the permitted physical observation/history map at sort t is o_t:S_t -> O_t. An exact implementation of q_t from that information exists iff ker(o_t) subset equiv_t. Necessity: any implementation is constant on observation fibres. Sufficiency: send [s] for any s with observation o(s); the inclusion makes this well-defined. If the receiver lacks the permitted communication channel, abstract computability does not supply one.

If the inclusion fails, no function of the allowed observation can exactly provide all generated verdicts. This is an impossibility witness: two physically indistinguishable states and one finite generated context with different verdicts. Conservative certification remains possible by universally checking the observation/history fibre; its failed verdict means uncertified, not necessarily unsafe.

If k atoms of A_t intersect the declared reachable state set, every exact adequate summary has at least k distinct messages on that reachable set. This lower bound concerns message values; dynamic memory and channel timing require their own implementation model.

Unbounded elementary family: resource r in {0,...,H}; a unit-cost action decrements r when positive and is disabled at zero; all states are intrinsically safe but completion requires every step enabled. For r<s, the continuation of r+1 unit-cost steps is infeasible at r and feasible at s. Hence every state is a distinct continuation atom and exact admission of all finite resource-cost continuations requires H+1 messages (at least ceil(log2(H+1)) bits). One-step enabledness alone distinguishes only zero from positive. This demonstrates why closing under ALL continuations matters. It is the familiar automaton/residual-language mechanism, not a new complexity result.

## 6. The separate exact-witness gate B
Theorem A preserves all generated permission verdicts, not actual decomposition or execution witnesses. Independent successor marginals can agree while joint outcomes differ; Boolean probe closure does not magically reconstruct omitted record correlations. For exact semantic decomposition discovery lifting, apply the necessary-and-sufficient finite Hom-map/grammar criterion in Generated_Profile_Fullness_Automaton.md to the same declared graph assignment and physical summary. For newly discovered exact nullary operations use its additional rootwise E0 test, not an unconditional requirement that q be an isomorphism. Preserving OLD exact nullary operations is a distinct direction.

Thus the two tests have different answers and repair meanings:

* A fails: the summary cannot decide the requested continuation permissions exactly; either retain an implementable distinguishing observation/history, weaken to conservative permission, or reduce the declared context class.
* A holds but B fails: permissions can still be sound/exact for the declared language, while an apparent route/refinement witness may be invented by summary matching. Preserve original boundary witness identities or a sufficient permitted interface; do not claim witness reconstruction merely from permission adequacy.
* A and B hold: the generated conditional permission certificates and generated structural witness/refinement family both lift, with arbitrary finite tree coherence as established by their respective inductions. An actual source-to-probe interpretation is still required to identify the SAME certificates on both sides.

In general there is no canonical coarsest interface meeting B (conflict-coloring counterexample); the canonical quotient of A must not be advertised as the universal minimum for all mixed exact reconstruction obligations.

## 7. An explicit finite source-to-probe bridge
Here is a bounded semantic class for the missing interpretation, rather than an assertion that every possible cut is already covered. For every primitive generator witness

  w_g:W_c -> P_B(e_1,...,e_k)

include, on both graph sorts, the actual occurrence maps f_g,i=projection_i composed with w_g in the finite probe signature. Include graph source and target maps between event/state sorts. For each declared primitive temporal/zone certificate, include its actual action relation and designated conditional entry/exit predicates as in section 1. Nullary generators have no leaf projections; their declared boundary probes, if relevant, are separate finite maps.

For any finite original generator tree t, every leaf projection of its interpreted witness is a composite of the corresponding f_g,i along the root-to-leaf path. This follows by induction using the original strict substitution/flattening formula, not from a new coherence axiom. Consequently all Boolean combinations of allowed leaf predicates, transported to the whole along ANY finite tree/refinement, belong to A. Original equalities of actual tree maps give equal inverse-image probes.

The concrete mixed restriction identity is explicit. If leaves have predicates P_1,...,P_n, then

  w_t^{-1}({compatible tuples with component_i in P_i for all i})
     = intersection_i (projection_i composed with w_t)^{-1}(P_i).

Refining one leaf substitutes its composite occurrence maps; associativity of inverse image makes the two computations equal. Apply this on states and events. When the selected predicates define subgraphs (event predicates imply both endpoint predicates), the restrictions remain graph restrictions. Thus this supplies all-tree mixed restriction/substitution coherence for these actual rectangular leaf restrictions and their Boolean combinations as WHOLE predicates. The theorem does not claim a Boolean combination of rectangular restrictions remains a product decomposition.

To handle a genuinely correlated/crossing cut predicate, include its actual finite joint probe in the signature, or prove it is generated by existing probes. Merely specifying individual projections does not preserve arbitrary untested joint correlations. The probe closure supplies all generated contexts of the given finite signature; it is not a proof that an independently proposed infinite cut doctrine has a finite generating presentation.

## 8. Closing the A/B gap for NEW semantic discoveries
Section 7 covers old source-generator expressions. B deliberately covers MORE operations: every semantic operation on a grammar-generated profile. Their component graph maps need not be composites of old primitive occurrence maps. Therefore primitive-probe closure alone is insufficient for a combined all-discoveries theorem.

An exact finite enlargement is available. Fix the interface abstraction q and the original finite profile grammar. For each pair of component colors c,e, enumerate the finite graph-map set Hom(W_c,W_e). Call f a PARTICIPATING occurrence map if some coarse operation on some p in L_c has an occurrence of color e whose component map is f. Participation is decidable by the B grammar automaton: retain its coarse-matching transitions, accept any coarse outer-matching final state (ignore the defect bit), and add one bit that records whether a transition tagged (e,f) has occurred. Grammar reachability with final seen=1 is equivalent to participation. Thus the map family is computed from finite data, without assuming a lift or bounding the number of leaves.

Add every participating f (on states and events) as an inverse-image probe before constructing A. Add all separately declared temporal, admission, observation and joint-cut probes as before. If B passes, every participating family lifts with exactly these same record maps. Hence any Boolean certificate built from allowed leaf predicates along ANY newly discovered semantic decomposition is represented in A, not only certificates coming from old syntax. Arbitrary finite substitutions among discoveries are covered because the resulting profile is grammar-generated, and the inverse-image induction applies to the participating maps. Actual source equations still require their interpreted equalities; no syntactic completeness is inferred.

This enlarged A is canonical and coarsest for this ENLARGED semantic-discovery probe language at the fixed q, not necessarily for the old primitive-only language or uniformly over every possible q. A is an induced permission view evaluated at this fixed q, not a self-consistent replacement for q. Changing q requires rerunning B and the participation computation; its physical-observer feasibility test must then also be rerun. The enlargement may remove all useful compression: that is a real obstruction to uniform adequacy, not a reason to pretend old A already covered every new discovery. Conditional entry/exit permissions still require action admission and observation-uniform implementation, and actual correlated joint predicates remain part of the explicit probe specification.

Small gap counterexample: a single three-state discrete component with terminal boundary, only identity source behavior, and predicate {0}. Primitive-only A has atoms {0},{1,2}. Boundary abstraction is identity, so B is trivially full, but a new semantic permutation exchanging 0 and 1 pulls {0} back to {1}, outside A. The participating-map enlargement includes that permutation and repairs the gap. This example also warns that 'all semantic discoveries' may be a much more demanding adequacy language than physically permitted discoveries.

## 9. Combined conditional-certificate theorem (fixed finite discovery doctrine)
Fix the finite typed graph assignment, record-retaining boundary abstraction q, and profile grammar of B. Compute the participating occurrence-map family of section 8. Form A from those maps together with the declared action-specific relations, universal-admission predicates, information-state/observation probes, source/target maps, and explicitly supplied zone/entry/exit/joint predicates. Suppose:

1. B's necessary-and-sufficient fullness test passes (and E0 passes if exact discovered nullary witnesses are demanded).
2. The physical observer/history factorization test for the required A summaries passes at the appropriate decision/communication phases. Any proposed controller is a single policy on the actual information-state carrier, not a hidden-state-dependent selector.
3. The supplied coarse discovery is a finite family of semantic operations/refinement arrows on grammar-generated profiles, with its stated equations genuinely satisfied. Its conditional certificate is an expression/inequality in the declared probe language, using those operations' actual occurrence maps.
4. The concrete information-state model soundly represents the declared initial possibilities and all allowed adverse outcomes; admission uses universal Adm_a. These are assumptions about the world model and controller implementation, not conclusions from category structure.

Then the same family of specified record maps has a unique coherent fine lift; all its original occurrence-level refinement equations remain valid; and its conditional certificate is exactly expressible through the A summaries. Truth of that certificate for the declared initial condition is the same when evaluated on the retained records before or after the lift. It is also the same on the induced A permission view. A nonblocking universal safety certificate therefore yields the corresponding model-relative pre-execution permission for the lifted family and physically implemented policy. A task-completion claim additionally requires its stated reachability/ranking certificate.

Proof: B supplies unique lifts and coherence without changing any component occurrence map. Section 8 placed each such map in the finite probe closure, so A's commuting inverse-image identities apply to the VERY SAME certificate, rather than a separately chosen certificate. Induction on the certificate expression preserves every action-specific demonic step, admission predicate, conditional entry/exit transformation and allowed Boolean operation. Physical factorization implements the resulting summary at the declared stage; uniform policy selection and the information-state model give the stated adverse-outcome quantification. For nullary discoveries there are no leaf occurrence maps: any boundary certificate is covered only through its separately declared finite leg/boundary probes, not by the participation construction alone. No independent product decomposition of an arbitrary safe set is inferred. QED.

The theorem does not claim that B is necessary for all safe permissions. If B fails, its extracted coarse operation is an unliftable SPECIFIED witness; other fine witnesses may still exist on that profile (indeed, the original generator interpretation can supply one). Some or all permission predicates may remain exactly decidable by A, and conservative permission may remain useful. Nor does the theorem create a common crossing refinement not present in the supplied family. It lifts existing compatible diagrams in the selected generated doctrine; it is not a complete recognition theorem for arbitrary mutually compatible decompositions.
