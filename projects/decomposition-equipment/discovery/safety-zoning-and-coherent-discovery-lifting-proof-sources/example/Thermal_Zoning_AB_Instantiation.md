# One thermal owner, conditional zones, and all generated route profiles

## Plain-language abstract
Before an inspection robot enters a hot aisle, it must know whether it can complete the requested inspection and leave safely. A map that remembers heat but forgets the remaining cooling charge can reuse the same charge in two different pieces of a proposed route. The pieces are individually real; their supposed connection is not.

This example checks two distinct obligations on the SAME finite thermal model. First, it calculates the least boundary information needed to answer every task made from the declared moves. Second, it checks whether every newly discovered decomposition witness on every profile generated by the route grammar really corresponds to the original resource owner. The second check covers arbitrarily many inserted waiting segments, using a finite fixed-point computation rather than a chosen route-length bound.

Retaining heat and reserve passes both checks. A redundant route-regime label can safely be omitted from the boundary because the component types already retain it. Heat alone fails both. These are model-relative proofs, not a certificate for an empirical robot environment or a claim that resource accounting itself is novel.

## 1. Actual owner and episode types
The finite boundary carrier is

`B = {(h,c,n) : h,c,n in {0,1}}`.

Here h is heat (0 cool, 1 hot), c is the remaining single cooling charge, and n is one of two fixed inspection regimes. The regime is ALREADY specified by each component color; forgetting its duplicate boundary coordinate does not discover an unknown regime or add a sensor. It remains constant throughout an episode. For each n write:

- a_n=(0,1,n), b_n=(1,1,n), c_n=(0,0,n), d_n=(1,0,n).

Use one interface vertex with boundary graph the discrete graph B. Its graph has no edges. Each component graph below is likewise a discrete graph of finite ONE-SHOT EPISODE RECORDS. Its left and right legs give the owner state at entry and exit. A graph state here is an episode record, NOT a simultaneous physical state at an intermediate instant.

| Color | Actual episode records (index order) |
|---|---|
| H_n, hot aisle | H_n[0]: a_n→b_n; H_n[1]: c_n→d_n |
| C_n, cooling | C_n[0]: b_n→c_n |
| I_n, waiting | one s→s for each s=(h,c,n), in lexicographic order |
| R_n, two-aisle inspection | R_n[0]: a_n→d_n |

R_n is backed by the genuine route H_n[0], C_n[0], H_n[1]. It is NOT a record pretending that three aisles were traversed. All heating/cooling changes belong to the one shared owner. Serial profile matching requires equality of the actual exit and next entry owner states. It does not independently reset resource state in each factor.

There is no asserted identification of an unknown physical world with this graph, no continuous dynamics, and no adversarial branch in this first example. An invalid action is unavailable; a completed-task permission requires enabledness at every step. Entering a hot aisle while already hot can instead be represented by a separate failure transition with the same safety verdict; it is deliberately excluded from the safe episode colors.

## 2. Actual source interpretation and unbounded grammar
For each n use two nonidentity generators:

1. R_n → [H_n,C_n,H_n], sending its unique record to `(H_n[0],C_n[0],H_n[1])`.
2. H_n → [I_n,H_n], sending each hot-aisle record to its input-state waiting record followed by itself.

These are actual fine operations: their adjacent and outer boundary states agree. Identities give the stopping production e→[e]. No nontrivial source equation or nullary generator is asserted. Ordinary strict substitution supplies the existing tree/refinement calculus.

The generated profile language is explicit:

- L(I_n)={[I_n]}, L(C_n)={[C_n]};
- L(H_n)={I_n^k H_n : k≥0};
- L(R_n)={[R_n]} union {I_n^k H_n C_n I_n^l H_n : k,l≥0}.

There are unbounded refinement trees/profiles despite finitely many component record sets. The root record does not encode the elapsed number of waits. A decomposition witness specifies the inserted waiting records. No claim is made that a fixed finite event set stores every distinct unbounded execution transcript.

## 3. A: exact minimum for the declared continuation permissions
On owner states use the actual partial deterministic action relations:

- H(h,c,n)=(1,c,n), defined iff h=0;
- C(h,c,n)=(0,0,n), defined iff h=1,c=1;
- I(s)=s.

The initial probes are enabledness of H,C,I (equivalently, the admitted one-step tasks), the terminal acceptance predicate B, Boolean operations, and action-specific demonic preimages. Completion of a fixed word additionally intersects enabledness at every step. No existential choice is made separately for hidden states.

**Claim A1.** The continuation closure has exactly four atoms, determined by `(h,c)`; n is irrelevant.

Proof: all initial predicates and transitions depend on h,c only, and transitions preserve n, so no generated expression distinguishes the two regimes at fixed h,c. Conversely En_H separates cool from hot; En_C separates b_n from d_n; and En_H intersect [H]En_C separates a_n from c_n. Thus all four thermal/reserve combinations are distinct. This proves both sufficiency and the exact four-message lower bound for this declared permission language.

Consequently q_plus(h,c,n)=(h,c) is its coarsest exact summary. The code computes this by finite partition refinement, including successor-class tests, and obtains four two-element classes after one strict refinement of the initial three-class partition.

Concrete task predicates:

- Pre(H)={a_n,c_n}: one aisle can be crossed from either cool state.
- Pre(H C H)={a_n}: two aisles require the fresh charge at entry; exit is d_n.
- Pre(H C H C H)=empty: three aisles cannot be completed with the single charge and these operations.
- Inserting any number of I steps changes none of these conditions.

These are conditional state-space permissions. A geographic region is not unconditionally 'safe' merely because one task can be completed there. The task, entry resource state, available actions, and required exit condition are part of the certificate. Cutting the two-aisle macrozone after its cooling step gives entry condition c_n for the final aisle; that subzone does not inherit the parent's fresh-charge entry requirement or an unconditional label.

The code currently checks completion at any safe exit. The named R_n macroepisode additionally fixes exit d_n, and the successful two-aisle route has exactly that exit. More selective terminal tests can be explicitly added to the probe signature; they are not implicit.

## 4. B: fullness of every source-generated profile
Keep all component record graphs unchanged. Compare two boundary maps:

- q_plus(h,c,n)=(h,c), forgetting redundant regime;
- q_minus(h,c,n)=h, additionally forgetting reserve.

**Claim B1.** q_plus passes the all-generated-profile fullness test for every color.

Proof independent of enumeration: every generated profile of an n-colored output contains only n-colored leaves. Every graph map into a leaf component therefore has all its boundary values in B_n. q_plus restricted to B_n is injective. Hence equality after q_plus of any two participating adjacent/outer boundary maps implies their actual equality. Every coarse family of component maps therefore lifts, uniquely, with the same record maps. The same argument covers any number of inserted I leaves, identities, and substitution. There are no nullary profiles, so E0 is vacuous.

This is genuinely noninjective boundary compression on active data: both n values occur in component records. It is deliberately modest compression; its adequacy follows because the grammar/types retain n elsewhere. It does not show that physically essential owner information can be discarded.

**Claim B2.** q_minus fails, including on the nontrivial source profile `[H_n,C_n,H_n]`.

Consider the new coarse operation from the unique record R_n[0] to

`(H_n[0], C_n[0], H_n[0])`.

Its heat sequence is `0→1, 1→0, 0→1`, agreeing at adjacent boundaries and with the heat of the root a_n→d_n. But C_n[0] exits at c_n, whereas its proposed second H_n[0] enters at a_n. It resets the reserve. Its final state b_n also differs from the root's actual d_n. No lift preserving these actual records exists. The source derivation tree is simply the root generator R_n→H_n C_n H_n, with stopping identities at the leaves; the newly discovered MAP is not the old generator's map.

The valid source map selects H_n[1] for the final aisle. Thus B's failure rejects a particular new witness, NOT physical existence of the two-aisle task. This distinction is essential: every generated profile already has its old fine source interpretation. Separately, A rejects the three-aisle task from all entry states. The impossible three-aisle route is not falsely claimed to be an old source-generated profile of R_n.

Additional q_minus failures can already occur on stopping profiles, e.g. a coarse H_n endomap exchanging its two records. B intentionally quantifies over all semantic operations on generated profiles, not just interpreted old source terms.

## 5. Same-system participating-map bridge
The finite participating maps for q_plus can be read directly from the languages and injectivity proof:

- each stopping component contributes its identity;
- H_n→I_n selects each hot episode's actual entry state;
- R_n→H_n may select H_n[0] (first occurrence) or H_n[1] (last occurrence);
- R_n→C_n selects its sole record;
- R_n→I_n may select waiting at a_n (before the first aisle) or c_n (before the last).

No cross-regime map participates. Pulling back the four owner classes along entry/exit legs distinguishes every local episode record within H_n and I_n; C_n and R_n are singleton. Thus adding all participating occurrence maps yields no further owner-state distinctions: q_plus still has four owner classes. Every generated refinement transports these actual record predicates by inverse image, so the mixed rectangular restriction/substitution equality follows directly from composition of occurrence maps. This does NOT establish arbitrary correlated crossing cuts outside the supplied signature.

## 6. Physical observation, belief, and scope of safe admission
For the deterministic proof assume `(h,c)` is available before action selection, either from permitted sensors or reliable initialized memory with observed cooling commits and no silent charge loss. This is a physical assumption, not a consequence of q_plus being a function. The n coordinate is already in the chosen route type and need not be measured again at the boundary.

With only heat observable, entry information `{a_n,c_n}` cannot decide the two-aisle permission exactly. The universal safe admission verdict is negative because c_n cannot complete it; the actual a_n state remains feasible. Label the proposed entry **uncertified under that information**, not 'the physical region is intrinsically unsafe'. If actual state is known to be c_n, the specified two-aisle task is certified impossible under the declared operations. For all entry states, three aisles are certified impossible under these operations.

These classifications depend on the modeled alternatives. To handle adversarial outcomes, information-state updates, or controller choices, use action admission at every represented state and one common observation-uniform policy. A factorization witness alone proves none of those facts. For example, two observationally identical junction states may require opposite safe branches: each has a safe action, but no single action is safe for the combined information state. Thus statewise existence of a safe route does not establish an observation-uniform controller. No nondeterministic theorem is claimed from the present deterministic calculation.

## 7. Reproducible checks and limitations
Run `python check_thermal_zoning.py`; output is `thermal_zoning_results.json`.

The checker:
1. builds the eight actual owner states and eight component colors;
2. computes the least stable permission partition;
3. checks the two- and three-aisle task predicates;
4. enumerates actual maps between discrete episode graphs;
5. constructs the defect-bit boundary-map automaton and saturates the finite grammar relations to a fixed point for every root color;
6. reports all q_plus roots full and a q_minus failure for R_0 (also other roots), recording actual component-map indices;
7. separately checks the explicit reset-charge counterexample on the source profile H_0 C_0 H_0.

This is an unbounded grammar check, not testing words only up to a selected length. It uses discrete episode graphs, so no untested source/target graph-edge constraints are hidden. No claim is made about efficiency, optimal continuous zoning, global world identification, stochastic guarantees, arbitrary crossing cuts, or solving the original research contract in full. The standard resource facts are an integrated test of the new A/B family formulation, not independently novel mathematics.
