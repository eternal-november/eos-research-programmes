DISCOVERING A COMPENSATED TOOL
2 November 2026

Result

A robot need not learn every hidden interaction to use an unfamiliar machine
reliably. In this finite example, one paid dummy trial identifies the combined
effect of two required jobs while leaving each individual effect unknown. The
robot then performs both real jobs, compensates their combined disturbance,
and routes a connector correctly by time 10. Four of eight possible machines
remain after calibration. If interrupted after only one job, the pair's
certificate does not authorize release; the remaining job can repair the
interface only if its real token and three remaining ticks are available.

For this bounded application, the existing joint-witness and typed-context
machinery, elementary linear algebra, and explicit local instance proofs
suffice. No new generic categorical gap or need for a new research contract
has been demonstrated. The result is an application and synthesis, not a
claim of a new learning algorithm or a physical robot demonstration.

Important boundary

The exact criterion is conditional on a nonempty, stationary binary-linear
model and truthful safe probes. Physical ownership, a closed gate with a
bounded retention horizon, a correction actuator, complete event accounting,
and exclusion through final route capture are supplied. The mission deadline
is T=10; the distinct retention/disposal horizon is H=11. Every accepted
Commit routes correctly, but refusal, abort, or expiration is not mission
completion. No safety is promised after the holding horizon. Learning does
not create capabilities, undo physical work, verify the model class, detect
silent drift, or extend exact abstraction to arbitrary future probes.
