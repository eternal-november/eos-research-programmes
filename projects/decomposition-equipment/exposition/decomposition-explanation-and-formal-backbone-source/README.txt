SCOPE
This is a checked foundational extension, not formalization of all 36 earlier
obligations. General equipment, descent, incidence, the full minimality and
repair hierarchy remain separate mathematical results unless named explicitly
in the formal coverage report. The old core is reused, not relabelled as new.
The new positive decoder uses actual setoid quotients of source labels and whole
decoration records for each fixed typed tree, with graft congruence. It does not
construct a new full quotient multicategory or prove its universal property or
original-seed minimality.
All TeX is intentionally source-only; compilation and rendered layout are not
claimed. Motivating illustrations are not empirical application validations.

DOCUMENTATION REVISION
Only the explanatory narrative, its motivating source material, README and
documentation evidence were revised. All 54 formal-backbone payloads are
byte-identical to the previously delivered package, including every Lean proof,
coverage report, dependency pin and build/axiom receipt. The earlier fresh

The motivating studies concern distinct models: uncertain coupling, shared
scheduler constraints, anonymous reports and controller reorganization. They
are not combined into an unstated general robot theorem.

DEPENDENCIES AND REPRODUCTION
Python 3 standard library verifies the package identities. Lean reproduction
requires official Lean 4.35.0 and the exact nine third-party revisions recorded
in the supplied lake-manifest.json. No toolchain, mathlib object cache, compiled
project objects or downloaded paper PDFs are bundled.

From this directory:
  python3 verify_delivery.py
  python3 verify_delivery.py --lean --report ../decomposition_replay.json

Put Lean 4.35.0's bin directory on PATH first. For a new dependency installation,
run formal_backbone/project/restore_dependencies.sh. It retrieves only the pinned
official repositories and their matching precompiled mathlib cache; it needs
network access and standard git/curl support. Alternatively set
DECOMPOSITION_PACKAGE_CACHE to an existing .lake/packages directory at the exact
pinned commits. The replay wrapper checks every dependency revision before use.
Dependency caches are external inputs; all project proofs compile anew in a
disposable copy. No existing project .olean files are reused.

The axiom audit reports Lean's standard logical axioms where used. The intended
criterion is no sorryAx, no added axioms and successful kernel checking, not a
claim that every theorem is constructive or axiom-free. Finite examples and
counts supplement but do not replace universal Lean statements.

The manifest verifies byte identity, not mathematical significance. The public
verification summary states what was actually compiled and reviewed. Private
working reviews, scratch notes, caches and executable binaries are excluded.
