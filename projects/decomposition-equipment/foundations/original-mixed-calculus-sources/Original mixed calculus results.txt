Original mixed calculus results
29 October 2026

Abstract

The original mixed calculus gives a sharper result than the affine example, but not a complete recovery theorem. Requiring refinement lifting with actual endpoints and replacement profiles fixed forces a quotient to retain every ordered graph partition. For the graph-indexed scalar quotients, the allowable identifications are exactly multiplication by one common subgroup of invertible scalars on nonempty graphs. Empty graphs retain every scalar, because nullary operations leave no child for repairing a missing value.

These equations extend conservatively through the free equipment construction: adding arbitrary interface restrictions, units, and universal composites introduces no additional equalities between original witnesses. This conclusion uses the original seven rules and a separating model, not an assumption that the larger span presentation was already generated.

The ordinary horizontal image has an exact criterion: for a nonempty graph word, the span multiplicity matrix must factor through a fixed interface bound over the nonnegative integers. A factorization compiles into an original-envelope expression. Larger identity carriers fail; extra carriers remove this object obstruction, but cell generation and complete equations remain open.

Cut witnesses require more memory than the lifting criterion alone supplies. We calculate their exact unit-scalar markings and comparison arrows. Separately, a provenance-preserving groupoid construction handles duplicated interface names, including nullaries, while missing interface values remain obstructed. This changes the transport doctrine; it does not establish the original strict assertion.

The advance combines an exact original-calculus criterion, conservative completion, and a constructive generation boundary. Remaining cell-level obligations are explicit; the programme is not claimed to be finished.

1 What changed from the affine test

The earlier affine work supplied useful infrastructure, but its model was too accommodating to test the difficult part of the proposal. This pass returns to the actual mixed calculus and asks what survives when the original witnesses, nullaries, and noninvertible interface changes are taken seriously. The main answer is restrictive. Universal lifting does not license arbitrary forgetting, and the enlarged span model cannot simply be substituted for the original syntax.

There are three distinct results. First, fixed-endpoint lifting forces partition rigidity and sharply classifies a natural scalar-kernel family. Second, those particular equations survive free equipment completion without introducing unintended old equalities. Third, an exact integer-factorization criterion describes the ordinary horizontal image, compiles successful factorizations into expressions, and proves that some finite-span objects are absent. This turns a missing generation proof into a constructive boundary.

Two companion constructions explain what a repair would have to remember. Original cuts need actual intermediate scalar markings; interface duplication can instead be handled by retaining all lift names and arrows between names for the same old value. Neither construction erases the distinction between original syntax and an enlarged semantic setting.

These results address the chosen whole and its supplied decomposition witnesses. They do not discover a graph, infer a decomposition tree, establish semantic adequacy for a physical application, or certify a system as safe. The work remains about what the calculus represents, what its quotients retain, and which exact recovery assertions its rules support.

2 The actual original presentation

The starting parameters are a nonempty finite category K, a commutative scalar monoid M, and a graph-size bound N at least one. The frozen programme uses finite M; the scalar classification itself does not require finiteness. There is no arity or tree-depth bound in the proof.

A component is an ordered graph together with a typed arrow in K. An operation retains its whole output graph, the complete ordered path of input arrows, an actual ordered partition of the whole vertex set, and a scalar. Equal-looking input components are still different occurrences. The whole graph includes cross-edges between blocks. The input graphs alone do not reconstruct it.

The generators are binary graph cuts C, genuine nullary operations U_A at the empty graph with identity arrow on A, and unary scalar operations D(W,m). The seven original equation schemes are R, UL, UR, D0, DA, DL, and DR: reassociation, the two designated unit laws, scalar identity and multiplication, and transport of scalars through either side of a binary cut.

The previously proved original normal form is a complete flat witness. Substitution replaces each actual block by its ordered subpartition, retains the full resulting arrow path, and multiplies the scalar labels. These normal forms are a dependency, not a new result claimed here.

Nullary means zero input occurrences, not an empty-graph input occurrence. A nullary original operation exists only at an empty graph with identity arrow and has an arbitrary scalar m. A leaf carrying that same component is a one-input expression. Unit laws cannot delete it merely because its graph is empty, and they cannot discard a decorated nullary scalar.

Original parameter changes, such as functors on K, are also different from arbitrary cartesian interface restrictions. The latter require the separate free chosen equipment envelope. That envelope adds new formal horizontal objects and universal factorization constructors; the old normal form is not a classification of all its new cells.

3 The exact lifting criterion

Fix an actual outer operation a, an actual target b, and the complete replacement-profile skeleton. Suppose a forest u composes with a to the same quotient class as b. Fixed-endpoint lifting requires an actual forest v in the same quotient class as u for which a[v] equals b literally. The outer operation is not allowed to move to another representative. Occurrences, interfaces, and replacement profiles stay fixed.

Partition rigidity holds for every parallel substitution congruence satisfying this requirement, not just scalar quotients. Suppose two parallel operations with different ordered partitions were identified. Choose the identity unary replacement at each input occurrence of the first. This gives a quotient refinement to the second. But any actual replacement with that unary skeleton assigns the entire child graph to its sole block. It cannot move vertices between the outer slots. Hence no actual lift exists. Repeated equal components do not help, because the slots are occurrence-indexed.

The complete classification is more limited. Consider kernels retaining partitions and allowing scalar equivalence R_G to depend only on the output graph G, not on the arrow path or input profile. They are substitution congruences exactly when every R_G is a monoid congruence and the relation on an induced subgraph is contained in the relation on its whole graph.

Within this family, universal fixed-endpoint lifting holds exactly when there is one subgroup H of the unit group of M such that

    empty output graph       m is equivalent to n exactly when m = n
    nonempty output graph    m is equivalent to n exactly when n = mh
                             for some h in H

The same H must work for every nonempty graph. This is not a classification of arbitrary profile-dependent or coefficient-map kernels.

Three tests force the answer. A nullary outer operation has only the empty forest, so nothing can adjust its scalar; equality on the empty graph is mandatory. On a singleton graph, a scalar h equivalent to one must lift back to one under outer multiplication by h. The resulting child scalar supplies its inverse, forcing the class of one to be a subgroup of units. Finally, cutting any whole into its actual singleton vertices forces every scalar class on that whole to be the corresponding H-orbit. This works even when the whole has cross-edges.

Conversely, when the whole is nonempty, at least one input block is nonempty. Any missing factor h can be inserted at that child without changing its quotient class, partition, grade, or replacement profile. When the whole is empty, every scalar is already exact. No cancellation by an arbitrary element of M is used.

The quotient has explicit original equations: D(W,h) equals the identity for nonempty W and h in H. No such equation is imposed on empty W. DA, DL, and DR derive the required scalar movements through the original cuts, and the existing normal form proves completeness on original operations. If M has no nontrivial units, equality is the only quotient in this family passing the test.

In the concrete graph-span extension, the same quotient retains the complete coefficient map as well as the partition. Scalar adjustment therefore does not pretend to solve a coefficient-lifting problem. It respects the chosen restriction and contextual-unit factorization bijections for arbitrary finite interface maps. The entire shared substitution boundary-map family remains fixed, including its single map in a nullary substitution. This concrete result must still be distinguished from generation by the original syntax.

4 What an original cut must remember

Lifting a refinement is weaker than retaining a prescribed normalized factorization unchanged. For example, take a two-element group of scalars and quotient by the whole group on nonempty graphs. A normalized binary cut with all actual factor scalars equal to one evaluates to one, not to the other group element, although the two results agree in the quotient. Recovering that specified target requires changing a real factor.

For a fixed finite planar original cut tree, we can describe exactly the missing memory. Fix the actual flattened operation with scalar m, the entire tree, every induced intermediate graph, and every occurrence and grade path. Consider lifts of the normalized quotient factorization: the root factor belongs to the class of m, and every nonroot internal factor belongs to the class of one.

Let r count nonroot internal vertices with nonempty output graph. Their scalar labels can be chosen independently in H. Every nonroot empty-graph label must be one, while the root label is forced to be m times the inverse of the product of the chosen labels. Thus the actual lift set is H^r; for finite H it has |H|^r elements. An empty root retains its supplied scalar m and has no positive-graph descendants.

Here the flattened actual witness is fixed, but the outermost factor scalar is allowed to vary. If that outermost scalar must additionally stay equal to m, the product of the internal markings must lie in the stabilizer of m under H. It need not equal one. An absorbing scalar can be fixed by every unit. This distinction avoids an invalid cancellation assumption.

The original invertible unary D(W,h) operations provide comparison arrows between these marked factorizations. Their nodewise equations follow from DA, DL, and DR. There is exactly one such gauge arrow between any two marked lifts, so the resulting groupoid is contractible even when its object set is large. Collapsing all objects while retaining all gauges as automorphisms would be a different construction.

Contraction multiplies actual scalar labels; normalized expansion inserts a label one. They are inverse up to the unique comparison, with coherent rotations and unit insertions. Grafting is restricted to lifts of the normalized quotient factorization. Arbitrary scalar factorizations are not covered: in the additive cyclic group of order four with H={0,2}, zero can factor as 1+3, whose entries lie outside H.

This is an exact original-C5 memory calculation. It does not make a noninvertible interface comparison of coefficient witnesses invertible, nor establish a new unrestricted cut or 2-Segal theorem.

5 Completion without extra old equalities

The free virtual envelope adds arbitrary chosen restrictions and contextual units. The ordinary envelope also adds universal composites. The scalar quotient can be imposed before or after either completion, yielding canonically the same presented equipment. The congruence must close under the inverse factorization constructors as well as substitution; otherwise the chosen universal bijections need not survive.

Commutation of free construction with added equations is standard presentation reasoning. The more substantive point here is conservativity: after all these constructors are added, two original parallel witnesses become equal exactly when the original scalar quotient already equates them. Arbitrary noninjective and nonsurjective interface maps introduce no further old equality for this family.

The proof uses the existing graph-word and span separating equipment. A horizontal carries a finite ordered word of graphs and an actual span. Restriction retains the word; universal composition concatenates words. Its scalar relation forgets H only at positive total vertex grade and retains scalars exactly at grade zero. Graph-forest substitution conserves total vertex number, so a scalar change at a positive child can occur only under a positive output. Every universal factorization bijection and its inverse preserve this relation.

On an original full profile, the graph forest is exactly the original ordered partition and the coefficient map is forced by the faithfully realized interface arrows. This detects precisely the claimed old quotient kernel. The model separates old witnesses; it is not asserted to be the free envelope itself.

Consequently original scalar-bearing nullaries remain distinct whenever their scalars differ, even after arbitrary restriction closure. Supplied tuples of old refinement cells are also controlled occurrence by occurrence. But the result does not classify all newly available refinement arrows, prove fullness, or provide a global scalar normal form for every new envelope cell. Fresh equipment units remain distinct from old empty-graph components.

6 The exact ordinary horizontal image

The passage from the original envelope to the enlarged finite-span presentation now has an exact object-level answer. Let b be the largest size of an interface in the fixed faithful finite-set realization of K. For a finite span S, form the matrix n_S whose entry at endpoints (a,c) counts the actual witnesses with those endpoints. Define its nonnegative integer factor rank as the least k for which n_S=P Q with nonnegative integer matrices P and Q and k intermediate coordinates.

A horizontal consisting of graph word L and span S is isomorphic to the interpretation of an original ordinary-envelope expression exactly when

    L is the empty word, or the integer factor rank of n_S is at most b.

This is the complete semantic horizontal-image criterion for the ordinary envelope. A nonempty word includes a one-letter word containing the empty graph. It is not the same as a graph with positive vertex count. The converse is not claimed for the smaller virtual grammar, which lacks ordinary composites.

For necessity, span composition multiplies witness-count matrices over the nonnegative integers. Restriction reindexes rows and columns. Neither operation increases a supplied factorization width. Every original graph-arrow primitive factors through its finite apex, whose size is at most b. An expression with a nonempty graph word must contain an old graph-bearing leaf. Following any such leaf through all restrictions and composites therefore propagates a width-at-most-b factorization to the whole expression. Other branches may have arbitrary graphs and witness multiplicities; they cannot remove this intermediate bound.

Sufficiency is constructive. Every empty-word span is already available as a standard conjoint followed by a companion. Given n_S=P Q of width at most b, pad the factors to an old interface attaining b and realize P and Q as empty-word spans with exactly their prescribed witness counts. Between them place the original components (G_j,id) for the successive graphs of L, all at that old interface. Their span matrices are identities. The resulting expression has exactly word L and matrix P Q, hence is isomorphic to the desired span by fibrewise bijections.

This supplies both directions of a certificate: a generated term yields a bounded factorization, while a supplied factorization compiles into an original expression. Verifying the supplied factors uses exact integer multiplication. No efficiency claim is made for finding them, expanding large witness multiplicities, or deciding equality of arbitrary cell terms.

Boolean support rank gives a simpler but weaker obstruction. It counts rectangles covering the endpoint relation, ignoring multiplicity. The diagonal of a finite interface E has Boolean and integer rank |E|, so its graph-bearing identity carrier is absent exactly when |E| exceeds b. For |E| at most b, restrict an old identity graph span along an injection into a maximal old interface; this already works in the virtual envelope.

Multiplicity genuinely strengthens the criterion. With terminal K, b=1. The matrix [[1,1],[1,2]] has full rectangular support but integer factor rank two. Its five-witness span cannot accompany a nonempty graph word, although removing the duplicate witness gives a generated rank-one span. Merely counting apex size would also be wrong: noninjective restriction can enlarge an apex without increasing factor width.

Adding a carrier D_G(E) for every allowed graph and finite interface removes the horizontal obstruction. Any finite span can surround its graph-bearing carrier by a conjoint and companion, and further carriers supply longer words. This is one sufficient object-level extension, not a uniquely minimal repair. No uniformly bounded-support primitive family suffices.

The criterion concerns isomorphism classes in the semantic target. It is not a normal form for syntactic horizontal expressions, a claim that every semantic isomorphism lifts, or a proof of cell generation and complete equations. The larger presentation remains genuinely larger, despite conservativity on original witnesses.

7 A limited repair for duplicated interface names

The original discrete transport obstruction remains. For f:A' to A, the nullary comparison is the diagonal from A' to A' times_A A'. If f is noninjective, that is not a bijection. Scalar quotienting cannot manufacture the missing off-diagonal support.

The optional repair changes the doctrine. Replace the discrete lifted interface by the groupoid K_f: its objects are the new names, with exactly one arrow between two names having the same old value. Lifted span witnesses retain the actual old coefficient witness as a separate coordinate. Arrows may change lift names, never the old witness. Composition matches seams weakly through these arrows.

Over a complete old feasible tuple, the lift groupoid is empty if a required old value has no lift, and contractible otherwise. Projection is fully faithful with precisely that supported essential image. It is an equivalence for every tuple when the interface maps are surjective, including arbitrarily unbalanced, noninjective fibres. Missing values remain genuine obstructions.

The nullary diagonal is now an equivalence of groupoids, not a bijection of the original sets. Trees retain complete provenance records: occurrences, actual partitions, coefficient equations, boundary values, and the supplied local scalar data. After contraction, dropping hidden values and then admitting new records would invalidate the support criterion.

Successive changes must preserve this old-value provenance. Recomputing an independent kernel pair at each stage is wrong: a constant map from two names to one old value followed by an identity change must still retain the arrow between those names. The corrected construction compares names by their common original value and composes by forgetting only the specified intermediate coordinates.

On the normalized marked domain, scalar gauges and boundary-name changes act independently and combine as a product of groupoids. Here the fixed base is the nonscalar old record and actual root scalar m; local scalar labels may change under the marked gauge. This does not turn distinct original refinement forests into equalities. The construction respects the seven original equations as an interpretation, but supplies neither generation of its new objects from C5 nor the original strict set-valued recovery theorem.

8 Verification and the remaining target

Independent AI proof review found no remaining proof-breaking gap within the stated scopes. The review prompted explicit corrections to nullary boundary bookkeeping, the distinction between old and new-horizontal equations, successive-change provenance, and the restricted grafting domain. This is not external human verification or Lean formalization.

The independent bounded checks cover all 106 labelled commutative monoids with fixed identity through order four and all 577 congruences, plus 243 hereditary graph-indexed families. Additional checks cover 16,886 boundary-groupoid comparisons and 6,191 scalar-tree assignments. Independent matrix tests add 22,032 factor-preservation and 81 witness-count checks. The author's rank checker verifies 4,096 composition cases, 256 restriction cases, diagonal ranks through four, 88 injective carrier restrictions, and all 81 two-by-two integer matrices with entries zero through two. Author regressions and their reproducible scripts accompany the proofs. These checks test finite instances; the general claims rest on the written arguments.

The mechanisms are established mathematics: unit-group orbits, matrix factorization and Boolean rank, free presentations, companion/conjoint factorizations, and kernel-pair descent. Their application here yields a sharper diagnosis of this particular original calculus, not a claim to have invented those tools. The contribution audit records primary references and separates inherited results from this pass.

The remaining substantial target is a relative presentation theorem for a precisely chosen carrier extension. It needs cell generators, equations for carrier maps and graph/scalar interactions, compatibility with every chosen universal constructor, and proofs of cell generation and equality completeness. Classification beyond graph-indexed scalar kernels is also open. These cannot be replaced by object generation or old equality reflection.

The justified conclusion is narrower, but harder, than the affine test: we now have an exact original-calculus family, explicit witness-memory requirements, and a constructive horizontal-image classification proving that the unextended generation bridge is impossible. The original reconstruction and strict noninvertible cut-recovery obligations are not all discharged.
