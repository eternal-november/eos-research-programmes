1. WHAT THE FORMALIZATION ACTUALLY PROVES

T1 / semantic domain. Interface I X retains a label in arbitrary I; its arrow
family is ALL predicates X(i) -> X(j) -> Prop. No Fintype, nonempty, decidability,
or cardinality bound occurs. Thus all frozen finite families, including empty
I and empty carriers, are covered. evaluate recursively composes relations
existentially and maps nil to the diagonal, not to an empty relation. A total
operation stores an actual public Quiver.Path, with fixed Component output and
its validity proof. ContainmentOp uses inclusion; ExactOp uses equality. The
whole is independent, not definitionally the path composite.

T2 / actual calculus laws. containmentData and exactData are the public A
CalcData. Their substitution fields use Path.Slot and componentAt, and build
Path.expand from one independently supplied child at every occurrence.
evaluate_expand_le proves existence by composition monotonicity; its exact
counterpart separately proves equality. A proof-irrelevant validity field does
not make an invalid operation exist. It is used only after these validity
proofs and the entire profile equality have been established.

containmentCalc and exactCalc fill the public Calc fields, not a similar private
record. The units use expand_edges and nil_comp. Associativity uses the public
CalcData.composeAt_profile. That lemma was inspected: it is derived from the
data's profile law and Path.expand_assoc/expandFamily, not by assuming the
operation associativity being proved. The latter transports the third-level
occurrences correctly. Thus the short Subtype.ext arguments are meaningful
operation equalities, not a shortcut proving only equality of relation values.

exactInclusion is a genuine same-base Calc.Hom. Its structure preservation is
literal; the word strict does not assert properness for every degenerate family.
The generic diagonal_containment_nonexact theorem and finite named witness
establish properness where advertised. IndependentSemanticChecks additionally
proves that a strict Boolean diagonal-to-top cell has an empty exact fibre and
that different full profiles remain distinct total containment operations.

T3 / actual restriction maps. restrictionQuiver maps each relation by membership
R(f(x),g(y)) between the two generally different relation quivers. Its component
map retains endpoints and its path map retains order. The source never claims
this is a same-base Calc.Hom. restriction_path_comparison recursively maps the
actual existential intermediate values through f; it covers nil as equality
transport. restrictContainment applies that comparison and the original cell's
validity to the independently restricted whole. It is not an assertion that
pull-of-composite equals composite-of-pulls.

Identity/composite quiver and path restrictions are checked. The positive-arity
equality theorem has a cons-path conclusion and requires surjectivity exactly
at targets of prefix edges: internal occurrences. It does not demand endpoint
surjectivity/injectivity as extra assumptions. A global map reused at an internal
occurrence of an endpoint label naturally has to satisfy that internal condition.
There is no unsound universal converse about arbitrary relations or empty sets.

The nullary theorem explicitly identifies the pulled diagonal with the kernel
pair. Its equality with the primed diagonal is equivalent to injectivity.
IndependentSemanticChecks constructs a surjective constant Bool -> Unit map:
its nullary exactness fails, although the actual containment operation restricts
successfully. This also checks that onto and injective have not been conflated.

IMPORTANT L BOUNDARY: the source gives global per-label maps and existential
comparison proofs. A separate first-class map of realization SETS, arbitrary
locally chosen incidence-compatible vertex maps, and restriction/substitution
commutation for every forest are P, with finite C checks. They are not exported
L theorems. This is honestly stated, and the frozen target permits the P route.
The P diagram condition uses the same primed set and map on each glued vertex
class; a nullary child identifies its two endpoint classes. This is sufficient:
restricted child wholes then equal the actual restricted parent slots, and both
orders have the same restricted leaf path and whole. Without that agreement
the alleged substitution diagram is not available. No map/law adequacy is waived
because the two Calcs compile.

T4 / public bridge and syntax loss. containmentFiberEquiv and exactFiberEquiv
are actual two-sided equivalences from prescribed public operation fibres to
empty/singleton Unit subtypes. Their inverse sends validity to the prescribed
path, and their inverse laws eliminate the profile equality. The model therefore
has the promised fibres, not merely an untyped relation evaluator.

primitiveAssignment has the public Signature.Assignment type and requires the
complete declared profile/output condition for each label. presentationExtension
uses the actual A2 Tree.extend; uniqueness quantifies over public strict
Calc.Hom maps agreeing on primitive assignments. Source FreeExtension and the
relevant Calculus/PathOccurrences API were inspected. same_frontier_same_semantics
fixes the same Component output and full frontier; it concludes equality of
relational values only, never equality of raw trees or primitive labels.
The finite certificates independently exhibit both semantic collisions. There
is no hidden quotient by all equalities of this selected model.

The principal 2,3,2 example has composite {(0,0),(1,1)} and independent strict
whole adding (0,1). Its nonsurjective middle inclusion deletes the realizer
through 2 and outer pair (1,1), while retaining (0,0). The pulled exact whole
still contains both pairs; the resulting containment cell is NONEXACT. The
surjective (0,1,2,2) example restores endpoint-relation equality yet maps two
realizers to one. Noninjective endpoints and empty-set cases are retained.
Thus comparisons concern actual maps and witness loss, not merely a boolean
assertion that some inclusion exists.

Four actual in-memory source mutations were inspected and rerun: reverse
containment; conflate the two composites; merge repeated component occurrences;
replace nullary diagonal by empty relation. All were detected, and replay JSON
matched the frozen mutation certificate. The independent syntax example also
makes an occurrence-collapse mutation change the composite itself, not just
the profile. Wrong order/endpoints, false equality and nullary failures are
not accepted as legal instances.

Additional reviewer BoundaryGuards.py deliberately imports the author API
(so it is NOT advertised as a no-import oracle). For arities 0–8 it checks

maps at nonglued occurrences remain allowed. These are bounded executable

from testing nine arities.

Four independent Lean negative files must FAIL by a specific type mismatch:
