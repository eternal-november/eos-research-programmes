Method and exact finite coverage
--------------------------------
The standalone Python checker imports only standard-library modules, never the
author model. It independently implements Boolean matrix multiplication and a
second evaluator which enumerates all global vertex assignments satisfying all
edge predicates, then projects to endpoints. The latter is used for F3 source
and segmented compositions. The occurrence-typed syntax and validity checks
are independently authored dataclasses. None calls the author's functions.

F1: all six carrier sizes in {0,1,2}; every f,g,h and every R,S.
  113,171 actual boundary-map/relation tuples.
   33,821 tuples with surjective internal g; equality holds in every one.
   17,424 strict comparisons; these are not silently replaced by equality.
   75,547 mapped realizing triples checked edge-by-edge.
  661,613 choices of containing whole W, all restrictions remain containment.
  297,272 of those restricted cells are nonexact.
   46,707 tuples have at least one empty interface.
The W choices exceed the explicitly minimal F1 tuple domain; all are visited.

F2: every relation triple on four carrier sizes in {0,1,2}.
  8,507 relation triples; both bracketings and whole-path evaluator agree.
  62 unit equalities, checked by both evaluators, including size zero.

F3: every path of arity 0--3 on canonical carrier sizes in {0,1,2}, every
relation, every weak cut sequence for outer arity 0--3, every tuple R_i
containing its block composite, and every W containing the outer composite.
       9,040 source profiles.
     132,793 profile/segmentation pairs and exact substitution cases.
   8,162,514 intermediate-whole tuples.
  25,619,591 full containment substitution cells.
  By source arity, the numbers of full cells are
    0:127; 1:10,664; 2:591,190; 3:25,017,610.
  By outer arity, they are
    0:6; 1:195,322; 2:2,621,014; 3:22,803,249.
No F3 cell is skipped by weighting, sampling or semantic-class factorization.
The inner loop visits every W explicitly. A weak cut sequence
0=t0<=...<=tk=m corresponds bijectively to contiguous blocks [t_i,t_{i+1}].
An empty block keeps the SAME positional interface at both ends. The code does
not use equal cardinality as a license to contract distinct interface labels.

All finite carriers are represented canonically as [n]. Membership computations
are independent of the spelling of an interface label; F1--F3 test the numeric
matrix domain, not an infinite enumeration of arbitrary names. F5 separately
uses actual repeated labels and rejects distinct labels of equal cardinality.
No unrestricted assertion about names, arbitrary finite sizes or unbounded
arities is inferred from these finite tests; that belongs to P/the API bridge.

Additional coherence coverage:
  31 relation identity-restriction cases.
  23,015 iterated relation-restriction cases for all involved sizes 0--2.
  All 11 functions [a'] -> [a] with a,a' in {0,1,2} as nullary restrictions.

Named certificates and source inspection
---------------------------------------
The independently constructed principal example has A,B,C of sizes 2,3,2,
R={(0,0),(1,2)}, S={(0,0),(2,1)}, composite={(0,0),(1,1)}, and strict whole
{(0,0),(0,1),(1,1)}. The map [2]->[3] with values (0,1) leaves composite
{(0,0)} but restricts the original exact whole to {(0,0),(1,1)}. Containment
survives; exactness fails. A surjective map (0,1,2,2) restores equality, while
its map of realizing tuples is not injective. Noninjective endpoint maps are
also tested. A nullary exact singleton diagonal pulled along (0,0):[2]->[1]
becomes the whole kernel pair, while the new empty composite is only Delta[2].

Every one of the author's 15 serialized named cells was independently parsed
with its actual labels/sizes/relations and recomputed by whole-path assignment
enumeration. Pair lists and masks are checked against each other. The principal
boundary maps and old/new/mapped realizer lists were recomputed, not trusted as
booleans. The author's two four-leaf grouping shapes and its two different
substitutions at literally identical loop components were rebuilt in the
independent syntax. Its refined cell, repeated-colour mutation and an exact
nullary bottom graft were independently reconstructed. All match.

The independent additional repeated-component example uses nonexact unary
substitutions P={(0,1)} and Q={(1,2)} into the universal three-element loop.
Its correct refined composite is {(0,0)}; copying P to both occurrences or
swapping the occurrences yields the empty composite. This detects occurrence
collapse even without relying only on differing profiles. Two differently named
primitive nodes and two binary groupings remain different raw syntax while
their selected semantic cells agree. No syntax quotient is introduced.

Restriction/evaluation is compared on ten independently built typed trees.
Actual restriction/grafting equality is checked under one global map per
interface, including a nullary child. The same global B map is used wherever
nullary contraction identifies B boundaries. The suite rejects wrong ordered
profiles, a wrong repeated occurrence output, a nonloop nullary despite equal
endpoint cardinalities, false containment, and mismatched node children.

Mutations: reverse the containment direction; replace composite-of-pulls by
pull-of-composite; merge repeated-component occurrences; use empty relation
instead of diagonal at arity zero; infer nullary exactness from vacuous internal
surjectivity. Each has an explicit independently computed distinguishing case.
The author's key mutation payloads were recomputed, not merely read as PASS.

Reproduction and trust boundary
-------------------------------
At the source checkpoint root, with Python 3 on PATH:
  python research/workstream_C2/review/IndependentFinite.py \
    --output /tmp/C2-independent.json
  cmp research/workstream_C2/review/IndependentFinite.json /tmp/C2-independent.json

It reads only its own source, the frozen target/contract, and the author's
source-hashed JSON fixture; it imports no local model module. The evidence JSON
is deterministic (timings are printed only into the run log). A run took about
9.5 seconds here. IndependentFiniteRun.log records that full run. A second run
from a fresh temporary directory containing only these required source/data
files produced byte-identical JSON; IndependentFiniteCleanRun.log records it.
Python lru_cache only memoizes this process's explicit computations; no prior
proof/test cache is consumed. This does not claim to bootstrap Lean or reproduce
the entire inherited A/B/C1 implementation; the owner's separate clean driver
and formalization audit cover those tasks.

No test failure or counterexample to the frozen C2 finite targets was found.
Finite success cannot establish all-parameter P, justify an omitted hypothesis,
or prove a Calc adapter merely by resemblance. The public A correspondence,
all-arity mathematical substitution and all-arity restriction laws require
separate review. Full C2's later D2/E use is still OPEN. Correct familiar baseline
implementation is useful infrastructure, not a new mathematical contribution
or satisfaction of the broader scientific-scope acceptance gate.
