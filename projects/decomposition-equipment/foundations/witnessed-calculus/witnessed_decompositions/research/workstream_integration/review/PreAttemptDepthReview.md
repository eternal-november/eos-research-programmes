## 2. Cheapest technically compliant positive construction

The cheapest plausible construction is elementary but materially stronger
than object normalization. Fix every finite bound N, finite interface category
K, and finite commutative monoid M from the inherited presentation. Let raw
terms remain the objects. Generate arrows by elementary leaf corolla grafts
and invertible instances of the seven declared equations in typed contexts.
Composite raw forests may be convenient abbreviations, but their expansion
into elementary grafts must be proved using the accepted B1 chronology result.

Impose these independently specified syntactic relations:

1. The actual raw category relations, including interchange of independent
   graft events, with no artificial chronological multiplicity.
2. Inverse cancellation for equation steps; the eighteen inherited ordinary
   overlap diagrams; disjoint-redex interchange; and the variable-overlap
   diagrams justified by occurrence linearity. The endpoints, joins, contexts,
   and typing of these diagrams must be explicit. Their sufficiency for all
   equation paths is a theorem, not the definition of the relation.
3. **Outer mixed naturality:** an equation step followed by a graft of a
   forest at its unchanged external slots equals the same forest graft before
   the appropriately grafted equation step.
4. **Inner mixed compatibility:** changing one forest entry by a declared
   contextual equation equals the original graft followed by that equation
   in the corresponding output context. Original slot indices, not component
   labels, determine the changed entry.

Each scheme is finite syntactic data with decidable typing/matching; all typed
contexts and finite forests are effectively enumerable. This is an effective
basis for unbounded arity and depth, not a claim that a fixed finite object set
has been enumerated. Empty blocks and decorators make syntax unbounded even
at fixed N,K,M.

The plausible proof is a normal-form argument on arrows. Outer mixed
naturality moves equation steps to the right of raw grafts, raw composition
merges the grafts, and inner compatibility normalizes each forest entry.
Ordinary coherence makes the remaining equation path between its fixed
endpoints unique. Thus every arrow has a forest-then-equation representative.
Equality of its *complete normalized entry tuple* should characterize its
arrow class. This must be derived syntactically, not stipulated.

The comparison then evaluates each forest entry and sends every equation step
to the identity occurrence tuple. Completeness of the inherited object
presentation supplies the terminal equation path for any given semantic
tuple. Faithfulness follows from entrywise presented equality, inner mixed
compatibility, and ordinary path coherence. This proves fullness rather than
assuming it. The raw-object category is equivalent to the semantic refinement
category; an object-bijective isomorphism requires an explicitly defined
normal-form object subcategory or a justified further object quotient.

This is mathematically plausible across the whole frozen family. It has no
apparent dependence on cancellation of M, injectivity of substitution, or
recovering a whole from isolated pieces. Those assumptions must not be added
after encountering difficulties. An obstruction in this approach could use
B3's permitted repair branch, but cannot discharge positive A4 or C5 by itself.

### 6.1 Adversarial audit of the scalar enrichment

The user's concern that “decoration” could disguise a cheap enrichment is
mathematically well-founded. This family IS a scalar extension. Let P be the
accepted full-profile calculus: P(c,p) is a singleton for every well-typed
path p with the endpoints of c. Let P_M(c,p)=M with the same profiles, identity
value 1 and substitution multiplying the outer and child values. Commutativity
makes this a lawful calculus. Forget values P_M→P and retain the full profile
Cut→P. The enriched calculus has the direct fibrewise description

    D = Cut ×_P P_M.

This is not a new graph mechanism: every operation is exactly an ordinary cut
and a freely attached scalar. The input profile is shared, not weakened.
The corresponding refinement construction has the equally direct description

    Ref(D) ≅ Ref(Cut) ×_{Ref(P)} Ref(P_M).

On objects, a pair with a common image is an ordinary cut and a value m on its
same full profile. On arrows, equality of their images in Ref(P) requires the
SAME original-slot replacement profiles/segmentation. A Cut tuple supplies the
local retained cuts and a P_M tuple supplies each n_i with
`m * product_i n_i = m'`. These are exactly the full D tuples, and entrywise
substitution gives the same composition. Thus the description is automatic
once the accepted category-of-substitutions construction is available.

It is not a plain Cartesian product of refinement categories: the occurrence
segmentation is shared and the number of local values varies. That qualification
does not make the pullback result intrinsically novel or scientifically deep.
Likewise the fixed-interval multiplication fibre is exact bookkeeping of the
scalar extension, not a new unique-factorization theory.

What remains technically missing is an independently specified, effective
LOCAL syntax/coherence presentation of these full arrows with the declared
interfaces, units and mixed rules. That is useful and can be a nonvacuous
library integration result. Its generic proof strategy is nevertheless
standard coherent-presentation/category-of-operators mathematics. The target
must explicitly make the above product/pullback translation and assess whether
the remaining theorem is merely a standard theorem with checked hypotheses.
If so, merge its credit into that baseline and report the scientific-scope
shortfall. Do not manufacture a distinction by withholding profile or witness
data from the comparator.
