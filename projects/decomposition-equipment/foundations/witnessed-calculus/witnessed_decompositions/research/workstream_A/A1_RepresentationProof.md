# A1 representation and admissible-color comparison

Status: complete author proof submitted for independent mathematical review, not acceptance. The canonical contract and A1_TargetFreeze.md govern its scope. This is background free-multicategory infrastructure, not a novelty claim.

## 1. Independent abstract representation

Fix arbitrary interfaces I, a directed component family J, and signature S. Let C be the type of triples (A,B,j) with j in J(A,B). No decidability, inhabitedness, or finiteness of I, J, or S is assumed. Each particular signature input is a finite path.

An abstract witnessed planar rooted tree consists of the following finite sets and maps, before any recursive tree encoding is chosen.

- A nonempty finite edge set E and distinguished root edge r.
- A finite vertex set N and an injective output map out:N→E.
- For each vertex v, a finite linearly ordered set In(v), and a bijection inc from the disjoint union of In(v) to E\{r}. Thus every nonroot edge is incoming to exactly one vertex, the root is incoming to none, and an edge cannot be shared by two parents.
- For a nonroot edge e, define parent(e)=out(v), where v is its unique incident vertex. Require that repeated parent steps from e reach r after finitely many steps. In particular there is no cycle. This is a condition on finite incidence data, not a recursively generated datatype.
- An edge label λ:E→C and a vertex label ν:N→S.Generator. Require λ(out(v))=S.result(ν(v)). Require an order-preserving bijection between In(v) and the slots of S.input(ν(v)), under which every incoming edge label equals S.argument(ν(v),i).

A leaf is an edge outside the image of out. In particular, the output edge of a nullary vertex is NOT a leaf. The identity tree has one edge and no vertices; a primitive unary vertex is NOT an identity. An isomorphism is a pair of edge/vertex bijections preserving root, out, inc, each incoming order, and all labels. Abstract operations are isomorphism classes with specified root label and specified ordered leaf path. The path is obtained by reading leaves from left to right; the typing proof below shows it exists and has the root endpoints.

These data rule out cycles, disconnected components, copying/sharing, implicit exchange, and infinite trees, while permitting both unary and nullary vertices. They do not infer a whole from its leaves: λ(r) is retained data.

## 2. Decomposition lemma for incidence trees

If r is not in the image of out, N is empty and E={r}. Indeed, an element v of N would have output e. If e=r this contradicts the assumption. Otherwise its parent chain ends at r, and its last parent step has value out(w)=r for some w, again a contradiction. Similarly any nonroot edge has a final parent step into r, so none exists.

Otherwise injectivity of out gives a unique root vertex v with out(v)=r. For every incoming edge e of v, let E_e consist of e and those edges whose parent chain first reaches an incoming edge of v at e. Uniqueness of the parent function implies these sets are disjoint. Every edge except r lies in exactly one E_e: take the final nonroot edge on its chain to r. Let N_e consist of vertices whose output lies in E_e. Every vertex except v belongs to exactly one N_e; out is injective and no other vertex has output r. Incidence is closed within each piece, except that e becomes its root and loses its parent incidence at v. Restricted out remains injective, every nonroot edge has its original unique incoming incidence, and restricted parent chains end at e. Thus every piece is an abstract tree. Its vertex count is strictly smaller than |N|. The incoming pieces are ordered by In(v).

Conversely, take a label g and one tree rooted at S.argument(g,i) for every slot i. Form their disjoint union indexed by i, add a fresh root edge and a fresh root vertex labelled g, and attach the child root edges in the slot order. The displayed conditions follow directly: the new root has no parent, each child root gains exactly its new parent, other parent incidences are unchanged, and parent chains gain at most one final step. Outputs remain injective. Decomposing the constructed tree recovers its children exactly up to the canonical disjoint-union bijections. For empty input this construction still has a root vertex but no children.

## 3. Reconstruction and extraction

Define D from abstract trees to the Lean representation by induction on |N|. If there is no root vertex, use Tree.leaf λ(r). Otherwise use Tree.node ν(v), with the children obtained by applying D to the ordered subtrees from the lemma. The matching-label equalities transport child output indices to S.argument(ν(v),i), and transport the resulting node output from S.result(ν(v)) to λ(r). The strict decrease proved above justifies every recursive call. Isomorphic incidence trees have equal D images: an isomorphism sends the unique root vertex to the unique root vertex, restricts to isomorphisms of the correspondingly ordered subtrees, and preserves witness labels. Induction gives equality of every child, then function extensionality gives equality of the Tree.node values. Hence D is well-defined on isomorphism classes.

Define E from Lean trees to incidence data by structural recursion, using the one-edge graph for a leaf and the disjoint-union construction for a node. All sets are finite: a path has finitely many slots, each child is finite by induction, and finite disjoint unions with one added vertex/edge are finite. The fresh root carries the existing output index. Every vertex carries its actual generator, not its profile alone. This construction is independent of chosen representatives because replacing any child by an isomorphic incidence tree extends that isomorphism by the identity on the fresh root and vertex.

For every implementation tree t, D(E(t))=t. For a leaf the equality is immediate. For a node, the root decomposition of E(t) is its original generator with its original ordered children. The induction hypothesis gives equality of every reconstructed child; dependent function extensionality and constructor congruence give equality of the node. Equality transports in the edge labels do not create a second operation: they are eliminated by equality induction, and their proofs are irrelevant in Lean.

For every abstract tree T, E(D(T)) is isomorphic to T. In the identity case the unique-edge bijection is the required isomorphism. Otherwise the root decomposition partitions all nonroot edges and all nonroot vertices into the disjoint child pieces proved above. The induction isomorphisms on those pieces combine by disjoint union, and the fresh root edge/vertex map to r/v. These maps are bijective because the partition is disjoint and exhaustive. They preserve out/inc within children by induction and at the root by construction; they preserve incoming order and every label. This proves the second inverse, not merely equality of frontiers or semantic values.

Together these statements give a bijection between abstract isomorphism classes and implementation trees, for every signature and every output component. There is no assumption that vertices with the same witness or leaves with the same color become identified: the disjoint-union index is a position, not a label.

## 4. Boundaries, occurrences, and grafting

Define the left-to-right leaves of an abstract tree by the root decomposition: the one-edge identity contributes its root; a vertex contributes the ordered concatenation of its children's leaves. Each actual leaf occurs exactly once because the child edge sets are disjoint and exhaustive and the root output is not a leaf. For a nullary vertex this concatenation is empty. By induction each child's leaf sequence is a composable path with its root's endpoints. The generator input is itself a composable path, so concatenation produces a path with the root endpoints. This proves the boundary assertion needed in the definition of abstract operation.

E and D preserve this ordered leaf sequence by their very root decompositions. Thus the preceding bijection restricts, in both directions, to each prescribed output/profile fibre. It also preserves individual occurrences: the root-decomposition address of a leaf is its ordered sequence of child slots. Two equal labels at different addresses remain different leaves. The required Lean Path.Slot/frontier-to-Tree.Leaf correspondence will supply the formally checked occurrence implementation of this same order; that declaration is pending at the time of this proof draft.

Abstract grafting attaches an independently chosen tree at each actual leaf of T. Take disjoint copies indexed by leaf occurrences, identify each replacement root edge with that leaf edge, and retain all replacement vertices and all original vertices. Only the glued edge is identified; no vertices or distinct occurrences are merged. Labels agree by the stipulated output typing. Each nonroot edge still has exactly one parent incidence, and a parent chain follows its replacement to the glued edge then its original chain to the root. Therefore this is again a finite incidence tree. Its leaves are precisely the pairs (original leaf, replacement leaf), in lexicographic planar order; a nullary replacement contributes no such pairs.

D(T[grafts])=Tree.graft(D(T),the corresponding occurrence-indexed substitution). Prove this by root decomposition of T. For an identity tree it says that gluing at its sole edge returns the replacement, which is the one-edge identification. For a node, grafting affects only leaves inside the disjoint child pieces, leaving the root vertex and its incidence order fixed. Apply induction separately to every child and constructor congruence. This proves compatibility with the actual graft operation, not only with flattened boundaries. Applying E and the two inverse statements gives compatibility in the other direction. Both abstract unit laws and associativity therefore agree with the same laws on implementation trees and their explicit prescribed fibres.

## 5. Restricted ordinary nonsymmetric colored multicategories

Take colors C=Σ A,B,J(A,B). An input list [c₁,…,cₙ] with output c is admissible when neighboring endpoints agree, its outer endpoints agree with c, and all colors are retained in order. For n=0 admissibility means c.source=c.target. No distinguished unit color is added. The equalities are conditions, not additional operation witnesses.

For fixed output c, the map p↦Path.components(p) is a bijection from paths c.source→c.target to admissible color lists. Existence follows by constructing the path from left to right using the adjacency equalities and then transporting its start/end to c's endpoints. For uniqueness, remove the last edge: equality of the lists gives equality of the last full component, hence its two endpoints and edge, and gives equality of the preceding component lists; induction identifies the prefixes. For the empty list, a path has length zero, so is the unique empty path after the required endpoint equality. Equality proofs do not give extra paths, by equality induction/proof irrelevance. This also proves independence of choices made in constructing the path.

Given a path-profile calculus M, put its operation fibre at an admissible list/output equal to the M fibre of the uniquely reconstructed path; put the empty type at every inadmissible list/output. The ordinary colored identity belongs to the singleton list [c]. Colored substitution is the M substitution via the slot/list-position correspondence. Its flattened list is admissible: replacing cᵢ by a path with the same endpoints preserves adjacent endpoint matches and outer endpoints. A zero-length replacement is possible only at a loop cᵢ and merely removes that loop from the list, so adjacency is still preserved, including removal of every slot. The canonical reconstructed concatenation path is Path.expand by the uniqueness just proved. Thus the colored unit and associativity laws are precisely the M laws transported along this unique boundary reconstruction. All cases with an inadmissible input operation have empty domain and introduce no new operation.

Conversely, given an ordinary nonsymmetric C-colored multicategory whose inadmissible list/output fibres are empty, define M(c,p) to be its fibre at Path.components(p), with the same identities and substitution. The preceding substitution-closure argument ensures the result has the expanded path profile. Ordinary units and associativity give the path-profile laws under the same position correspondence. These constructions are inverse up to the displayed fibre bijections: paths reconstruct from their lists and admissible lists are unchanged; the empty fibres stay empty. Each bijection preserves identities and substitution. A strict map fixing the colors restricts/extends by the same bijections, uniquely on empty fibres, so the comparison also gives inverse hom-set bijections and respects identity/composition of maps.

## 6. Default positive subcalculus and explicitly enabled nullaries

If every generator input has positive length, every tree frontier has positive length. For a leaf the length is one. For a node its input has a last slot; that child's frontier is nonempty by induction, and the ordered concatenation has length at least that positive length. Substitution of nonempty frontiers is therefore closed in the nonempty-profile subcalculus. Neither the construction nor the proof requires a uniform arity bound. In the nullary extension, zero-input vertices are permitted exactly when their output is a loop; the preceding incidence, inverse, boundary, and substitution proofs already include them. This is an extension of the positive case, not the assertion that every loop carries a zero-input witness.
