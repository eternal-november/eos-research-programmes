The principal six-vertex example has four ordered leaves with interface path
0→1→1→1→2. Its two middle leaves are literally the same nonempty two-vertex
one-edge graph with identity grade, but their occurrence-indexed refinements
are opposite proper binary cuts. Two distinct binary groupings evaluate to
the same full cut. Adding a cross-block edge changes the retained whole while
leaving all induced leaf graphs unchanged.

The complete mathematical model retains the whole graph, ordered partition,
and full typed arrow string. Vertex bound N=6 is closed under all substitutions;
arity and tree depth are not truncated. Empty blocks and true nullaries are
checked separately, never substituted for the principal nonempty example.

The model uses established graph-restriction and multicategory infrastructure;
no novelty claim is made for this local construction. Required downstream
C5/F2 use remains OPEN. Gate 1 addresses foundational viability only.
