# Concurrent reconstruction: a constructive protocol bridge and its exact boundary

Independent challenge, 2026-10-31. This is a theorem about a specified asynchronous open-system language, not a theorem about every physically possible concurrency semantics. The probability-kernel and contextual-equivalence ingredients are standard. No novelty claim is made.

## 1. A sharp failure of the completed-invocation interface

There are two exclusive resources L and R and two modules A and B. A module executes five successful commands: acquire its first resource; acquire its second; release its second; release its first; return `done`. An unsuccessful acquisition returns `busy`, consumes a scheduling tick, and retries while retaining any already acquired resource. No other transition occurs while blocked.

Compare two networks:

* Ordered: A and B both acquire L before R.
* Opposed: A acquires L before R; B acquires R before L.

In isolation with both resources initially free, every module in both networks has exactly the same completed-invocation interface: duration five, output `done`, probability one. Its local duration tails, expected duration, and terminal-output probabilities are identical. Resource commands are not part of this coarse interface.

Use the same deterministic scheduler in both networks: cyclically select A,B, skipping returned modules; the manager grants a request exactly when the resource is free and implements release immediately.

In the opposed network, the first two ticks grant L to A and R to B. Every subsequent request is busy. Neither returns. The failure is resource deadlock, not scheduler unfairness: both modules are selected infinitely often.

In the ordered network, after A acquires L, B cannot acquire anything. A acquires R, releases R and L, and returns; B then completes. Thus this fixed admitted context distinguishes networks whose local duration/exit cylinders coincide exactly.

Consequently no reconstruction depending only on those serial cylinders can preserve behavior under all these resource contexts. At least resource effects during the invocation must become observable to the interface. This is an information-loss impossibility, not a limitation of one termination checker or canonical implementation.

## 2. Local controlled-prefix data

For each module i fix countable input alphabet U_i and output alphabet O_i. Inputs are the entire information received at a selected transition: resource-manager replies, externally admitted interventions, and any shared-state observations affecting its next law. Outputs include resource requests/releases, ordinary observations and a distinguished terminal output. Termination is made absorbing for bookkeeping. A finite local history h=(u_1,o_1,...,u_n,o_n) is countable data; when multiple initial preparations or entry states are admitted, prepend their declared local preparation/entry label to h and index p_i,K_i accordingly; it need not reveal the module's hidden physical state.

The local cylinder supplies exact probabilities

    p_i(o_1,...,o_n || u_1,...,u_n)

for each deterministic, sequentially imposed input word. Double bars emphasize intervention rather than conditioning on inputs generated by a policy. Causality means the probability of a prefix does not depend on future inputs. Normalization means summing over o_n gives the length-(n-1) prefix probability, including terminal/idle bookkeeping. We allow countable hidden state and arbitrary real probabilities; effective access or sampling is not asserted.

For an attainable prefix h, define

    K_i(o | h,u) = p_i(h,(u,o)) / p_i(h).

For p_i(h)=0, choose any normalized distribution consistent with absorbing termination; such values will never be used from the specified initial preparation. The denominator is the controlled-prefix probability for the input sequence recorded in h, not a probability of observing that input sequence under a particular scheduler. Causality and normalization make K_i a probability kernel.

A local operational realization has state h, receives u, samples o from K_i, emits o and updates h to h,(u,o). It is a countable-state positive realization built solely from that module's controlled cylinders. It is not the full global process repackaged as a local interface. It may be infinitely larger than a hidden implementation and is not claimed minimal.

**Identification proviso.** The cylinders must include the relevant intervention prefixes and initial preparations. Ordinary observational distributions under one policy generally do not identify these kernels. Missing interventions are an identification obstruction, not permission to fill in an arbitrary kernel and claim contextual equivalence.

## 3. Admitted contexts and the closure obligation

A context consists of a resource manager, scheduler and intervention controller, with their own countable state (full finite history is permitted). On each global tick it selects an unfinished module i, supplies input u determined from context state and prior events, receives o, and updates its state. Its transition rules can be probabilistic and adaptive. Each primitive tick is an atomic sequential interaction, with resource-request resolution represented either by explicit request/reply phases or by a manager-provided response for the pending command; these presentations must not be mixed when counting durations. In the five-tick example each acquisition command and its grant/busy response count as one atomic transaction. There is no unrecorded infinitely long computation inside a single normalized tick. For the ordered-lock companion, the concrete boundary exposes the pending action, its requested resource (if any), and held-resource ownership; each selected attempt receives grant/busy. A busy visit changes no intrinsic worker state, ownership or pending action; a grant performs one successful intrinsic transition, reports releases and its next pending action, and reports completion/reentry or offspring with their entry marks. Releases and fresh entries have the explicit manager timing convention of the companion. All these events and the one-tick attempt cost belong to the controlled trace. A reconstructed history state may append a busy event rather than literally stutter; the required invariance is that erasing busy visits preserves the successful-grant path law and resource effects. The resource manager enforces the chosen acquire/release discipline. Idle, refused, deadlocked and terminal configurations have explicit distinct observable transitions; none is silently called success.

The decisive operational closure property is

    Law(O_next | interaction history, retained context-state history, selected i, supplied u)
      = K_i(- | h_i,u).

Here the conditioning includes the context's actual CURRENT operational state immediately before the worker transition, including private context memory, and the retained past context/interaction record and declared entry values. It is not restricted to information visible to an external observer. It does NOT include unrevealed worker hidden states or future private innovation tapes. The scheduler/manager's next transition law must itself be its specified kernel conditional on this record, with no unmodeled worker-state dependence. This is not a fairness or termination assumption. It is a conditional-interface sufficiency statement, and cannot be inferred from isolated marginals. A concrete sufficient implementation discipline derives it: every module has private initial randomness and private random innovations independent of other modules and the context, and all effects from outside enter through its input stream. A module's hidden state may depend arbitrarily on its own previous inputs and private randomness. Conditioning on the external history supplies no extra information about that randomness beyond its own local input/output history, because the context only obtained information about that module through this boundary. This standard conditional-independence argument establishes closure. Shared initial randomness violates this discipline unless retained as common state/preparation or handled by joint kernels.

Equivalently, a more general physically correlated implementation may provide a direct proof of the displayed conditional equation. It is the equation, not independence as an aesthetic requirement, that is needed. If a context reads unreported internal state, performs unmodeled mid-step interventions, or uses correlated secret noise, it is outside the interface language until the missing information/coupling is exposed.

This is an essential compatibility obligation, not something reconstruction creates. Its necessity is witnessed by shared-bit modules: each emits a fair bit on its first call; independent bits and one reused common bit have identical isolated cylinders but different joint outputs. Rich local history tests alone cannot recover an unrecorded shared coupling.

**Why visible-only conditioning is insufficient even for visible traces.** Give the context a private fair bit Z. Its first input is fixed. The original worker emits Z on its first transition and emits a constant thereafter. The context's next visible input is Z. At the first worker transition the conditional output law given only the visible history is fair, and later it is constant. A history reconstruction using those visible-only kernels emits an independent fair first bit; its next context input is still Z. Thus the original visible pair (first output,next input) is perfectly correlated, while the reconstructed pair is independent. The failed induction would have assumed the context's posterior state law agreed after observing the first output. Requiring closure conditional on its actual current private state rules out this example: given Z, the original first output is not fair. A context restricted to visible-history policies with fresh independent randomness avoids this obstruction, but arbitrary private-state contexts require the stronger condition used in our theorem.

## 4. Exact asynchronous reconstruction theorem

**Theorem.** Let finitely many modules satisfy the controlled-prefix consistency and conditional closure conditions above. Replace each module by its local history realization. For every admitted adaptive scheduler/manager/intervention context, the original and reconstructed networks have the same law on the complete marked global trace. In particular they have equal probabilities of successful completion, resource violation, deadlock and infinite execution, and equal distributions of any measurable trace-defined duration/cost. No fairness, almost-sure termination, finite expected duration or finite state space is required.

**Proof.** The empty global prefix laws agree. Suppose a finite marked global prefix has the same probability in both networks. The induction prefix includes the retained context-state record. Given that augmented prefix, the specified context kernel has the same law of its next state/selection/input in both networks; equality of its posterior private-state law is therefore established jointly rather than assumed from visible traces. Conditional on selecting i and input u, the next output has K_i(-|h_i,u) in the original by closure and in the reconstructed network by definition. Thus the next joint context/output prefix law agrees by multiplying conditional kernels and summing over countable states. Induction proves equality of every finite cylinder. Zero-probability local histories cannot arise along a positive-probability global prefix: its first allegedly impossible extension would have K_i probability zero. Therefore arbitrary kernel choices on zero cylinders are immaterial.

Probability measures on countable-alphabet infinite sequence spaces are determined by finite cylinders. Add absorbing symbols after finite termination so every run is a sequence. The two full trace measures coincide, proving all measurable-event assertions. Completion is a countable union of finite-prefix events; its complement records noncompletion, not necessarily one designated kind of divergence. No interchange of an Isbell construction with an infinite limit is used. QED.

**Coherent wiring.** The global step kernel is assembled from local K_i and the actual manager/context transition kernels. The theorem keeps EXACTLY THE SAME primitive scheduler and resource-manager transition law while replacing worker kernels. Regrouping means only rebracketing/tagging state products and transporting that same global scheduler, manager and tick granularity. Associativity and Tonelli then reassociate the same nonnegative finite-prefix sums. Replacing a flat round-robin scheduler by nested round-robin is generally a different context with different traces, and is not a coherence claim here. Feedback and interventions are covered only through the fixed explicit context protocol. A genuinely simultaneous shared-resource language needs its own joint step rule; multiplying marginals is not legitimate by default. No compact tensor preservation is asserted.

This result is stronger than matching final exit distributions and weaker than an isomorphism of internal physical realizations. It allows arbitrary admitted contexts, including deliberately starving ones. It preserves their nontermination rather than disguising it.

## 5. Connection to the actual two-sided cylinder comparison

Use an ambient matrix doctrine with a distinct preparation column for each finite controlled input word u of length n. Its normalized distribution is over tagged output words (n,o_1,...,o_n), so probabilities from different lengths are not incorrectly summed into one column. Indicator tests select these tagged output words; include the unit/mass test. Marginalization identities across columns encode causality and prefix consistency. Controlled input words label distinct preparation experiments, not random inputs subsequently conditioned on a favorable outcome. Exact two-sided factorization of this same cylinder preserves the entries p_i(h).

Hence any actual canonical comparison for that cylinder preserves all attainable ratios K_i(o|h,u), and section 4's operational history realization can be extracted from the preserved entries on either side. This supplies a route

    local controlled cylinder -> positive local history realization
                              -> actual asynchronous network semantics.

It does NOT assert that the canonical Isbell apex itself is a stochastic state space or that arbitrary CFS legs intertwine one-step kernels. Semantic extraction and the formal canonical comparison must remain distinguished. The comparison has the required concurrent consequence because the chosen cylinder tests are contextually sufficient and the separately verified physical closure property licenses their reuse.

A full general cylinder theorem would still have to construct these controlled test families and the context action functorially in each admitted doctrine, prove their compatibility with the selected mixed-variance comparison, and say which physical gluing operations they represent. The above proves a concrete asynchronous doctrine instance, not that general theorem by renaming its premises.

### 5A. An actual joint realization map and its canonical comparison

The following supplies honest factorization data for this asynchronous doctrine, rather than merely asserting that a generic cylinder theorem applies. Fix finitely many countable-state hidden workers, the SAME countable-state scheduler/manager, a countable family A of initial preparations, and countable intervention/event alphabets. Primitive steps are normalized. Padding with distinguished absorbing symbols is used only after an actual terminal/halted outcome (success, failure or abort) declared by the SAME context. A blocked or apparently deadlocked configuration remains subject to its real busy/idle/intervention transitions whenever later release, cancellation or recovery is admitted; reconstruction never inserts deadlock absorption. Each initial preparation in A must satisfy the stated conditional closure requirement. Include finite horizon n in each experiment; no distribution over infinite hidden paths is being claimed to have countable support.

**Filtration qualification.** In this construction retain the context's operational state c at each step in BOTH path carriers. The local closure equation of section 3 must therefore hold conditional on the past of this retained context record and the interaction history, but still NOT on hidden worker states or future private tapes. The private-innovation implementation discipline proves this stronger conditional statement, provided all information the context obtains about workers passes through the specified interface. Merely knowing equality of externally visible trace laws does not by itself prove equality jointly with arbitrary private context state. Moreover, visible-history-only local closure does not generally prove EVEN visible trace equality, as the shared-bit counterexample in section 3 shows. A weaker-filtration variant is valid only if the context itself is a specified visible-history policy using fresh independent coins, or if visible trace equality has been established separately. In that restricted or separately proved case, an observed-prefix carrier quotient is legitimate; it is not a fallback theorem for arbitrary private-state contexts.

For experiment e=(a,n,w), where a is an initial preparation and w an externally fixed intervention word of length n, let X be the disjoint union of tagged finite global paths of the original network. A path records every original worker state, all primitive event/input/output marks, and the context state c through horizon n. Allow syntactically well-typed zero-probability paths, so no support-dependent partial function is needed. Countability follows from finite products and countable unions of countable sets. Let H be the analogous tagged finite paths for the history-realized workers and the SAME context. A history-worker state is its accumulated local input/output history, not an original hidden state.

There is a deterministic total path map

    q : X -> H

which retains the experiment tag, context states and event marks, forgets hidden worker states, and calculates each history-worker state by appending that worker's recorded interactions. If necessary take H to include all well-typed accumulated-history records; records inconsistent with its transition law simply receive probability zero.

Let p_X^e:1->X and p_H^e:1->H be the actual length-n path distributions obtained by multiplying their primitive transition kernels. Their columns have total mass one, including absorbed paths. The finite-prefix induction of section 4, performed jointly with the retained context record under the qualified closure equation, proves

    q_* p_X^e = p_H^e                       for every e.       (F1)

Indeed, summing original hidden worker states after each one-step extension gives exactly the history worker's conditional kernel; the common context factor is unchanged. Countable summations can be regrouped by Tonelli. Zero-prefix choices are immaterial by the same support induction as before. This is a derived pushforward identity, not an assumed joint interface.

For every visible marked-global-prefix test t, let b_H^t:H->1 be its 0/1 indicator row, and define b_X^t by the same visible test on original paths. Include the constant-one row. Since q retains all visible marks,

    b_H^t q = b_X^t.                                      (F2)

Work in a small skeleton of the category of countable [0,infinity]-valued matrices (or a small subcategory containing these objects and maps), with nonnegative countable-sum composition and 0*infinity=0. Regard q as its deterministic matrix. Let D be the discrete family of singleton preparation objects indexed by e, and T the discrete family of singleton test objects indexed by t. Equations (F1)-(F2) show that

    r_(t,e) = b_X^t p_X^e = b_H^t p_H^e

is ONE ACTUAL JOINT CYLINDER, with two honest realizations X and H, and that q is an arrow X->H in Fact(r). The preparation/test families are fixed actual probability columns and actual indicator rows, not formal independent products of local marginals. Their joint values were derived from local controlled kernels and the declared context.

Embed this small matrix category by J into its free Isbell envelope. Applying the established source-changing normalization naturality theorem to Jq gives the diagram of canonical spans

    JX <-[M_0] G_X ->[E_0] R_r
     | Jq         | G(q)         | identity
    JH <-[M_0] G_H ->[E_0] R_r.

Writing their legs as b_X,h_X and b_H,h_H, the actual middle map satisfies

    b_H G(q)=Jq b_X,       h_H G(q)=h_X,
    G(q) a_X=a_H.

These equations are the legitimate comparison-of-spans cell with changing source boundary. They follow from the actual Fact(r) arrow and the previously proved CFS orthogonality argument. This is not an isomorphism assertion, not a fixed-source span 2-cell, and not a claim that G_X,G_H or G(q) are stochastic implementations. The concrete deterministic operational map is q between finite-path realizations; the canonical cell is its formal image/normalization consequence.

**Coherence actually obtained.** Rebracketing/tagging finite worker-state products, while transporting the identical global scheduler and manager, commutes exactly with q: both routes forget the same hidden coordinates and accumulate the same marked histories. Restriction to a shorter finite prefix also commutes with q. Appending a finite continuation commutes with history accumulation when its incoming history/context is the one supplied by the prefix. Thus for actual composable path segments, q sends their concatenation to concatenation with that inherited history. It need not reflect endpoint matching or lift every concatenation of abstract records; no pullback-preservation claim follows. The resulting commuting realization arrows have coherent canonical cells by identity/composition uniqueness of normalizer naturality. This establishes a concrete joint-cylinder reconstruction comparison for asynchronous composition without manufacturing an unspecified monoidal/trace action on a new doctrine.

Infinite completion and tail events are still handled by the finite-prefix measure argument, not by treating infinite hidden paths as a countable matrix object or asserting that Isbell completion preserves infinite probabilistic limits.

## 6. Progress is a second theorem, not a corollary of reconstruction

The exact theorem transports any independently derived trace-defined completion result. It does not derive completion from rich observation data alone. The deadlock example remains deadlocked after faithful reconstruction.

One elementary non-fairness-as-assumption progress rule is the following restrictive protocol:

1. Finitely many agents/resources, resources totally ordered.
2. Each agent has a finite fixed ordered list of locks; acquisition follows strictly increasing order, retaining all previously acquired locks. There are no acquisitions after entering its service phase.
3. After obtaining its list, an agent's service terminates almost surely as a function of its own selected transitions, conditional on the complete past at service entry. It releases all locks in finitely many further selected transitions and returns. No reactivation occurs.
4. The executable scheduler cyclically selects every unfinished agent, including blocked agents. Each selected transition takes one global tick.

Then all agents return almost surely. For an unfinished finite system, if no agent can currently take an unblocked step, follow a wait edge from each blocked requester to the holder of its requested resource. Along a directed wait cycle, each holder is waiting for a strictly larger resource than the one it holds for its predecessor. Strict increase around a cycle is impossible. Thus a holder chain ends at an agent able to acquire an available resource, or already servicing/releasing. Under cyclic scheduling an available acquisition or release occurs in finitely many ticks. There are only finitely many acquisitions before some agent enters service, and its infinitely repeated service opportunities imply almost-sure completion by its conditional local service guarantee. Its finite release sequence completes. Remove that agent and induct on the finite number of agents. The conditional guarantee ensures this argument remains valid after random preceding histories. No finite expectation follows from almost-sure service alone.

The rank rule alone does not imply scheduler progress; the concrete cyclic policy supplies it. Conversely cyclic scheduling alone does not eliminate resource deadlock, as section 1 shows. Repeated arrivals, release/reacquire loops, changing lock lists, reactivation and arbitrary scheduler replacement require a stronger protocol/progress theorem. Rejection by this restricted rule is not an impossibility result.

This elementary lock theorem is included as a constructive baseline, not as the ambitious final contribution. The companion derivation should supply broader quantitative local-progress/interference rules and preserve their actual conditions through the controlled interface.
