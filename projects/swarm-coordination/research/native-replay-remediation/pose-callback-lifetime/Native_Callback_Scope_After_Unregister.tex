\section*{The temporary pose-remediation scope must also close in native code}
A subsequent replay failed in later radio work after the local
scope used for pose failure injection had returned. Reinspection
showed a lifetime error in the harness. The temporary native
pose callback captured by reference a local copy of the original
callback. After the scoped unused-member removal, leaving the
temporary callback installed allowed a later dispatch to
dereference a dead stack object. Earlier runs returning expected
outputs had not established that this was safe. The affected
source witnesses are PRs 898, 899, 900, 902 and 904.

Restore the saved stable pose callback immediately after the
actual authorized \texttt{Unregister} and before the retained
FIFO is dispatched again. The mapping of registered roles and
physical pose fields is otherwise unchanged. The one explicitly
failed nonparticipant has been removed, so the restored native
observer is the original live observer for every remaining
registered participant. No credited packet, modeled event order,
decision rule, body or final route is changed. Verify each
actual recompiled native transcript against its previously
pinned exact expected output under the same source assets.
On a matched PR 904 case, AddressSanitizer reproduces a
stack-use-after-scope in the original source; the corrected version
returns its exact expected body/dock result in that probe. All five
complete alternate native replays retain their pinned output. The separate Python transaction or proof modules are not
the location of this issue.

This is a correction to the native witness harness, not support
for any more general physical source, consensus or fault
theorem. It records the source and observation boundary explicitly:
successfully restoring the semantic role alone does not prove that
the native observation function has survived the implementation
scope that introduced the remediation.
