# Scoped requests after an actual amendment

A limited-trust R5 lift-bay benchmark with two compliant owners. The two-way lawful request can use actual release evidence after the recipient's authority changes. A one-way public path cannot attain both privacy and exact service, with a tight quantitative trade-off under relaxed privacy.
