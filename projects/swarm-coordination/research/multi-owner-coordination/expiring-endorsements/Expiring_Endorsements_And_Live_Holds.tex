\paragraph{Service law.}
Endorsements for a release may expire with an appointment. A release already executed does not disappear when an endorsement expires. Conversely, endorsements seen at different cuts cannot be pooled to authorize an effect requiring their simultaneous presence. The question is how much of an old ledger must survive an amendment that permits more recognized coalitions to act in succession.

Fix $m\geq1$ named roles. At each modeled cut the fixture gate has a set $C\subseteq[m]$ of simultaneously recognized endorsements for a physical release operation. A live unit claim has a monotone release policy: $D\subset 2^{[m]}$ is the downset of coalitions that leave it occupied, with $\varnothing\in D$ and $[m]\notin D$. At an admitted cut with $C\notin D$, a pre-staged physical release executes before the next probe. Signing and recognizing are not by themselves evidence of release; the abstraction requires the actual deterministic effect at that cut and excludes interruption between recognition and release. There are no new claims, policy changes on live claims, or per-owner probes during the episode. There are $M$ integer units initially, fixed and known across the ledgers being compared.

The bench consumer queries physical occupancy after permitted histories; it is not an assumed globally informed controller. An on-fixture controller can realize the test if it actually recognizes the specified simultaneous scopes, has a lawful ledger or summary, and admits a new use only if the requisite units are free. A different release timetable, disclosure charter, or enforcement mechanism may narrow the query family or make that data unavailable.

\paragraph{Exact continuing state.}
Write $L$ for the poset of proper downsets containing the empty coalition, and $J_0=\{\varnothing\}$ for the initial cut. A sequence $C_1,\ldots,C_s$ reaches
\[
 J=J_0\cup\bigcup_i\mathord{\downarrow}C_i,
 \qquad F(J)=\sum_{D\in L:\ J\subseteq D}W_D,
\]
where $W_D$ is the initial unit count of type $D$. If $J$ is the full ideal the answer is zero. From prefix $J_*$, every continuation test $J$ gives $F(J_*\cup J)$; no row can be retired twice. Histories with the same down-closure are equivalent for this test; histories with the same last coalition need not be. Nor is $J$ generally the principal ideal of the union of endorsements ever seen.

Let $w(J)$ count the nonempty maximal coalitions of $J$. If the gate can recognize any coalition once per window and let it expire before the next, exactly the $J$ with $w(J)\le r$ are testable in at most $r$ windows, apart from the constant-zero outcome. Each maximal nonempty coalition must itself have occurred. Conversely present the maximal elements one at a time. Nested recognition alone tests only principal ideals. With unrestricted windows, $W\mapsto F$ on $L$ is unit triangular in reverse inclusion order. For four roles there are 166 claim policies; a single window tests 15 rows including the initial mass. Neither number is a claim about minimal bit encodings or permitted coalitions in a particular installation.

\begin{proposition}[Sharp mass threshold]
Let $J\in L$ have $t=w(J)\ge1$. Two ledgers each of mass $M$ can agree on all $K\in L$ except $J$ and differ at $J$ if and only if $M\ge 2^{t-1}$. Below that threshold, the proper subqueries obtained by retaining subsets of the $t$ maximal coalitions already determine $F(J)$.
\end{proposition}
For the witness let $A$ be the set of maximal coalitions of $J$. For each $S\subseteq A$ give type $J\setminus S$ coefficient $(-1)^{|S|}$, and split positive and negative terms into two ledgers. Removing these maxima preserves membership in $L$. Each ledger has exactly $2^{t-1}$ units. If $K\subseteq J$, their difference at $K$ is $\sum_{S\subseteq A\setminus K}(-1)^{|S|}$, which vanishes unless $A\subseteq K$, equivalent to $K=J$. If $K\nsubseteq J$ all terms vanish. Pad both ledgers identically to reach $M$.

For necessity, project each ledger onto the subset $B\subseteq A$ its type contains. Its count $N_B$ is nonnegative and the sum of counts containing $S$ equals $F(J_S)$, where $J_S=J_0\cup\bigcup_{a\in S}\mathord{\downarrow}a$. If all strict subqueries agree and $F(J)$ differs by nonzero integer $\delta$, subset inversion gives projected differences $(-1)^{t-|B|}\delta$. Each ledger has at least half the cells with mass at least $|\delta|$, so $M\ge 2^{t-1}|\delta|$. To decode $x=F(J)$, write each inverse subset count as $a_B+(-1)^{t-|B|}x$ with $a_B$ determined by the proper subqueries. Intersect the nonnegativity bounds with $0\le x\le M$. Below the threshold the interval contains exactly one integer: existence follows from the source ledger and two distinct integers would violate the same mass argument.

For $M>0$, equality on all $r$-window responses is equivalent to equality on the queries with $w(J)\le\min(r,1+\lfloor\log_2 M\rfloor)$. Induct on width using the decoder. No retained positive-width query in this table can simply be dropped; its signed witness changes that answer alone. For $M=0$ all responses are zero. This is not a bound for fractional loads, a minimal-bit claim, or a computational advantage over re-evaluating a small known ledger. Taking the union of a prefix with a future query adds at most the number of windows in the prefix. The compiled response table therefore updates exactly within the remaining window budget. A later permission expansion beyond that budget can require new old-ledger evidence. The decoder presumes the specified lower-width answers may be recorded. If the charter only permits a final readout, do not impute unavailable subqueries or conclude that a narrow record is sufficient. Conversely, equal answers on every permitted prefix force identical behavior of an adaptive controller that uses only those answers and the same recognized coalition history.

\paragraph{A service discriminator.}
With two roles $a,b$, compare unit claims with survival policies $\{\varnothing\}$ and $\{\varnothing,a,b\}$ against claims with policies $\{\varnothing,a\}$ and $\{\varnothing,b\}$; here $a,b$ represent singleton coalitions. All single-window responses agree. After an $a$-only window followed by a $b$-only window, the first ledger still holds one unit while the second has none. A new job requiring both of two slots is admissible in the second but not the first. Simultaneous recognition would clear both ledgers and cannot be inferred from two disjoint windows. Two compliant owners with identical recognized reports suffice for the separation. If a prior charter permits only one of the two windows, permitting the second changes service in one ledger. Only after admitting the needed old-ledger distinction does this give an implementable new admission rule.

\paragraph{Provenance and comparison.}
\href{https://arxiv.org/abs/1512.06404}{Combi, Vigano and Zavatteri} connect workflow constraints and temporal role availability to compute who can act when. Here the test concerns physical occupancy after such lawful operations. The underlying algebra is \href{https://math.mit.edu/~rstan/pubs/pubfiles/Stanley_y2000_p203X-XXGian-CarloXRota.pdf}{Rota's finite-poset inversion}. The prior scope-retirement model is recovered for policies where any single endorsement from a fixed nonempty signature clears a claim. The \href{https://github.com/eternal-november/eos-research-programmes/blob/b20c2c1bfebaeb3031e4079a552359fa67933183/projects/contextual-composition/feedback-and-concurrency/observable-covers/Residual_Profiles_and_Admission_Reflection.tex}{Contextual Composition residual-profile criterion} supplies the quotient by response equality; the new calculation gives its probe widths and sharp finite-mass threshold. For \href{https://github.com/eternal-november/eos-research-programmes/blob/b20c2c1bfebaeb3031e4079a552359fa67933183/projects/byzantine-control/exclusive-service/RULE.md}{Byzantine Control's exclusive-service rule}, a sufficient recognizing coalition may be a route, but whole-window coverage, local evidence, and bounded actual settlement still need fixture proofs. The profile does not supply those premises.

A matched direct raw ledger executes the same lawful operations and gets the same outcomes. Replay checks raw execution, signed witnesses, decoding, and prefix updates. Lean checks filtering, down-closure invariance, and the exact two-window mass minimum. The general threshold is a written proof. This is a scoped R5/R2 result, not independent transfer, a priority claim, or full contract acceptance.
