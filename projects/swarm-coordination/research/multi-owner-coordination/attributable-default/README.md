# Attributable refusal after a role change

A confirmed successor role and actual clearance can make a rescue lawful
without making its costly grant voluntary. If refusal and lawful
inability give the same enforceable record, collateral cannot
distinguish them. [Timing, exact bound and controls](Default_And_Authority.tex).

Use the pinned archived #657 replay listed in [SOURCE.tsv](SOURCE.tsv)
as `source.json`. It checks an entitlement seam, not strategic
behavior or audit probabilities. Verify its Git blob hash in the last
column and run:

    python replay.py source.json | cmp expected.json -
