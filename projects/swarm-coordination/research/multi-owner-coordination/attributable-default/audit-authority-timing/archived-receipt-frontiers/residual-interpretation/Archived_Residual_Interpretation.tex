{Contextual Composition result}. The consumer is a read-only scheduler
that has already accepted work but may learn the available verifier
slots late. It must recover a named committed result, not execute again
or infer a different duty from the visible outcome.
One slot provides one read. Qualified access to a sealed archive,

the exporter does not grant these permissions or perform an audit of a
physical world. This is a bounded constructed interface, not an
independently selected instance.

\paragraph{Native and target witnesses.}
The archived RWARE journal has actual SQLite effect commits and
name-indexed receipts. Let \(W\) be the eight tested source archive
witnesses. Each independently commits the same selected finite plant
trace. For each subset of three named receipts use the earlier native
bundled transaction when retained and a split write with actual process
death after effect commit when not retained. Back up each source file
with SQLite's backup operation. All selected runs have the same
final reconstructed plant state, but different receipt sets.
The named witnesses are first delivery acceptance, its later unload,
and second delivery acceptance at ticks \(8,13,27\).

Let \(W'\) consist of the independently specified finite returned-data
schema: for each of the three exact outcomes, present or absent,
with one of three irrelevant destination labels. The exact outcomes are
computed from a separate nominal native run, not inferred from
the outputs of the eight archives. Receipt identity, payload and result
are part of the returned value. The native map \(r:W\to W'\) is the
implemented export: from a single transaction on a read-only archive,
read the requested keys and verify present rows against the corresponding
effect entries, then materialize the rows with the specified fixed schema label.

\paragraph{Primitive reflection and attained coverage.}
For each allowed key/payload/cut query \(d\), the source primitive
\(F(w,d)\) reads the native receipt in the same snapshot, and returns
its named tuple if the payload matches and its commit tick is no later
than the query cut; otherwise it returns undefined.
The target primitive \(F'(r(w),d)\) performs the same supported lookup
from materialized data. Think of this as one two-input test with an
identity witness map on the query carrier. For authorized queries,
export reads exactly the relevant record, including its payload and
effect result; for the tested absent key it never invents a record.
The epoch and payload comparisons are unpaid mathematical tests of
allowed already supplied inputs, not ways to create an observation.
Consequently
\[
                   F= F'\circ(r,\operatorname{id})
\]
on the stated domains, with the independent 27-query suite also
checking wrong payload, unknown key and early/equal/late cuts.
There are \(216\) checked primitive equalities. The exact, sufficiently
late query for each genuine key distinguishes its presence or absence;
the other test outputs are determined by those presences and the fixed
associated outcomes. Thus the target residual quotient has eight
classes. Every class has an actual source representative among the
archived runs, despite different target labels not all being images
of the native map. The fixed query carrier has attained coverage
by its identity map.

\paragraph{Reused consumer and controls.}
Each query has an evidence value that both encodings return identically;
absence and a physical completion are not collapsed. The declared
capacity factor is independent of the encoding. Reflection and
coverage therefore justify using the same
\href{https://github.com/eternal-november/eos-research-programmes/pull/692}
{previous exact slot matcher} without changing its tests.
It determines which actual slots can serve the committed verification
set. All \(512\) assignments-as-existence queries agree across the
small tested carrier; for the declared three-role support (a full slot
and one separately selected sparse slot), the valid early choices stay
exactly the empty set and the three singletons. A controller can consume
the materialized packet only after it actually has the authorized data;
the test assumes same available data on the two sides and establishes
no transmission or delivery bound. Common history restrictions are
kept in the role support, not inferred from independently reachable
per-slot states.

Two obstructions diagnose different repairs. A native projection
keeping only ordinary final state and tick has the same image for all
eight carriers but produces opposite results for an allowed exact
named query. Reflection is impossible for that fixed projection and
primitive, regardless of how finely one profiles its target. If the
source is restricted instead to complete-prefix availability, the
actual export still reflects every test but covers only four of eight
target classes once sparse archives are admitted. To use the old
positive theorem, either restrict the successor to the certified
scope or change the attained-witness support. Stating a new finer
profile for the old restricted source cannot supply the missing classes.

\paragraph{Limits.}
A direct matcher over the same qualified keyed reports gives the same
admission. The benefit here is an explicit condition for preservation,
not lower end-to-end time or higher operating capacity. No uncontrolled
independence assumption, new verifier permission, durable cryptographic
transport, native measurement of actual wear/clearance, or full
programme acceptance is inferred. The finite relation cannot be reused
for a changed query, an unguarded concurrent export, or a new physical
consumer without checking the corresponding primitive and coverage
again.
