# A timely outage report before an irreversible port choice

[Proof and model](Ports_Before_Outage_Notice.tex). Checking pairs of possible outages is not enough when several ports are acceptable. The replay tests when an encoder and a receiver can agree on one physically usable port, and when a truthful report comes too late.

```sh
python3 -B replay.py | cmp - results.json
```

The standard-library replay compares 360 alphabet queries to a separate raw encoder/decoder enumeration. It checks 1,042 three-uniform hypergraphs against the staged simulator across 53,498 code partitions, plus 15 deadline and reserve controls. Lean 4.35.0 with Mathlib checks the cell criterion, the size bound for an obstruction and the sharp three-port example. The general layout realization is a written proof. These are authored civil development cases, not independent held-out validation.
