\paragraph{Joined distinction.}
The earlier lift trace ended at a per-payload velocity command
write; the separate physics trace began with a chosen lift write.
This replay joins those selected source bodies in one serial
fixture. A successor request goes through the native supervisor
and simulated lift admission and status construction. The same
synthetic entities are then in the selected lift payload box and
receive the native writes. Finally the pinned Gazebo 9 model
dispatch and cleanup bodies execute against the same component
fixture. The fixture authors poses, candidate body capabilities,
phase cuts, a nonzero cabin velocity, and all non-extracted
interfaces. No real scheduling or physics step is run.

\paragraph{Matched impairment.}
The declared role needs the successor lift's requested world setter
to be invoked for this payload, not merely for the session to exist.
Compare full fixture \texttt{LiftState} outputs for the prior
request and identical entity pose and command writes. Test four
modeled missing prerequisites: recipient unavailable in the
physics model map, non-top-level model, unavailable free group,
or absent engine command feature. One payload never receives the
setter in any impaired case; a second compatible payload in the
same box receives it as before. Component cleanup removes both
commands whether or not both setters were invoked.

Each impairment is applied before admission and in a separate
comparison after a healthy admission and modeled capability check.
The same report admits both despite the impairment; in the second
group even a healthy earlier private check cannot replace a
current capability warrant. There are eight paired comparisons.
The modeled capability query reads exactly the missing prerequisites
in these admitted cases; we do not attribute it to stock reports.
The test witnesses a split between the session, slot write,
compatible recipient and actual invocation.

\paragraph{Use and limits.}
These same-report cases show a scoped latent-entry problem for an
external policy that uses session admission as confirmation of
recipient capability. It is not the native meaning of a session,
nor a finding that healthy Gazebo models lose a feature on an
ordinary transition. An independent recipient check at the actual
cut, or a source-qualified guarantee maintained until consumption,
could rule out these failure cases. Neither would establish physical
motion or completion of a real ride. The still-compatible payload
only establishes a preserved selected setter invocation, not an
authorization to run despite missing mandatory effects.
This is scoped F01 evidence and no architecture disposition.
