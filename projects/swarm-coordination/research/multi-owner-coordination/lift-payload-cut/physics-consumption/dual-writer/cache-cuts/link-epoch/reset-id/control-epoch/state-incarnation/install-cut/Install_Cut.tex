\paragraph{Claim and scope.}
A cached monotone credential is not a fence if the resource can change incarnation without the checker's knowing it. The new source check extends the \href{https://github.com/eternal-november/eos-research-programmes/pull/761}{Gazebo state-restore extraction}. Native authorized state application can either coalesce deletion and restoration, leaving the original address live, or apply them across two iterations, creating a new object under the same numeric identifier and world time. The two paths share accepted service replies and have no remaining birth flag after the source clears it. The replay exercises actual application, removal and explicit-ID creation through extracted C++20 functions on a graph-only fixture. Authority issuance, delivery offsets, binding, and one-shot write eligibility are authored; no motor, full simulator transport, hardware or security boundary is tested.

\paragraph{Matched experiment.}
Use the same survivor on another address, one request pinned to an assertion about the watched body, and five writer opportunities after the second state cut. The actual incarnation starts at one. A scoped source hook captures the native birth bit before it clears and advances the local incarnation index for that address only. Qualified installation of the active incarnation may be delayed or miss all five opportunities. A duplicate of the old installation may arrive before, with, or after the active one; within a tick the active installation is processed first. The old binding is still legitimate in the coalesced case. At the writer use cut test the request's incarnation, the installed credential and the source-local active incarnation for equality; absence of a current installation closes that particular effect path. A qualified installation for the active incarnation can reopen it, without changing unrelated authority. This experiment starts {\em after} the second state cut, not in the mid-cut gap; an affected write during absence would also require a liveness test. Incarnation storage and the writer's access to it are fixture premises, not hooks shipped by Gazebo.

\paragraph{Exact service and obstruction.}
An affected request can issue at the first opportunity at or after its own arrival and the active binding's readiness. Coalescing needs no new installation; split recreation needs it. A missing current install never legalizes the old one. In the two-history example the writer's remote views before timely installation can be identical even though a requested old-incarnation write is due in one history and invalid in the other. A checker restricted to that view cannot satisfy both obligations. A max-of-observed-epochs cache stops rollback after seeing the new epoch but cannot rule out a new birth before seeing it. A global freeze suppresses stale effects at the expense of unrelated work. Lean checks equality safety, install and scope laws, the missing-view obstruction, and the exact timing gate. The timing law requires continuously valid authority for the modeled uninterrupted interval; a new lifecycle event would have to be checked again. The predicates establish authorized target eligibility, not evidence the write happened, stopped, or was physically settled.

\paragraph{Comparators.}
The executable reference evaluates the native incarnation plus actual qualification delivery, and independently computes the first valid tick. In 540 episodes per arm, last-delivered credential agrees on both timing and independent service in 350 episodes and executes 145 wrong-incarnation modeled effects. Max-observed agrees in 450 and executes 90 wrong-incarnation effects. Checking the source epoch directly at the writer with the same qualifying deliveries and the scoped install mechanism both match 540/540, settle the same 330 current requests, and take all 2,700 independent opportunities. Global freeze gets the same 330 affected completions without a wrong-incarnation write, but preserves only 1,800 independent opportunities and matches both duties in 240 episodes. These are grid counts, not measured rates. The equivalent strongest scoped effect-side validator ties; naive cache controls diagnose necessity, not architectural superiority. There is no independent confirmation, whole-mission result or I1 closure.

\paragraph{What would extend this result.}
Neither a one-off birth event nor a remote positive acknowledgment alone establishes a fail-safe writer binding. A deployment needs ordered delivery to or synchronous acquisition at every targeted write, idempotent application of matching installations, nonreused identity across all admitted reset or restore paths, and a means to observe or bound old command effects that already passed the writer. The next discriminating test attaches this lifecycle cut to the separate cached-actuation and physics consumption cuts, checking whether local retirement can remove only the stale side of an already sampled command. Do not promote these fixtures to closure or select a held-out case before pinning the complete source and joint operating envelope.
