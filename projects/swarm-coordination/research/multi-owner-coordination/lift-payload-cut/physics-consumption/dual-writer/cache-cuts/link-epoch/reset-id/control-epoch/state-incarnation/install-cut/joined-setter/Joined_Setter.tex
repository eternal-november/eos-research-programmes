\title{Retiring a sampled contribution can disable an independent lift request}

\maketitle
\paragraph{Claim and scope.}
A native lift request affects a payload only if the payload already has a velocity command component. In the pinned sources, the velocity producer can create that component from its sampled command and the lift then changes the vertical coordinate. Hence a valid lift grant and current payload do not imply a usable vertical writer. Dropping a stale horizontal sample may remove the only component supplier. One lawful repair in the declared model is to seed a current component with a separately authorized zero horizontal target, then let the native lift write its contribution. Zero is a target write, not an absence of power or a proof that a payload stops.

\paragraph{One causal replay, exact cut.}
The single serial fixture first runs real velocity mailbox and latch bodies, then real Gazebo graph-state apply/remove/re-create bodies, then selected source producer, lift and physics setter-dispatch bodies. Graph-state inputs may coalesce (old allocation remains) or split (same numeric body ID, new allocation and unchanged time). An authored sideband attaches the generation to the exact latch at capture and binds the same numeric subject across the stub contexts. Mailbox delivery and relatching need not coincide. Updating the mailbox early, or relatching after physics dispatch, cannot qualify the old sampled command. The comparison uses both old nonzero and old zero values. The selected bodies run with stub data stores, a separately granted current lift permission, axis-aligned poses, and an inert physics engine stand-in that records setter calls. There is no full ROS/Gazebo scheduler, hardware, physical clearance or real authority-provider claim.

\paragraph{Reused rule and its conservative boundary.}
Given current allocation \(g\), sampled generation \(e\), and a grant \(n\) to write the neutral target, the eligible input is the latched sample if \(e=g\), otherwise the neutral seed if \(n\), otherwise no component. The exact lawful vertical opportunity further requires lift payload membership, nonzero lift target, and a current supported setter. Lean checks the soundness and exact existence of a horizontal seed, the vertical condition, and the distinction between old zero and authorized zero and between mailbox and latch. The predicate does not promote either updater to a new source of authority. No valid horizontal seed means the native full-vector interface cannot deliver the vertical request under these specified suppliers. One must negotiate the separate grant, acquire a current sample or change the effect interface. Clearing the command component after setter dispatch does not retract the call. The replay does not yet exercise an allocation change after component staging but before dispatch, or a physical carryover.

\paragraph{Comparison and attribution.}
The same inputs (current generation, sample generation at the capture cut, neutral permission, and live payload plus setter checks) are available to both implementations. The source-seeded arm invokes the selected native set-or-create path with a permitted neutral target; the direct arm materializes the same qualified value explicitly and invokes the same native lift and setter. Both match the analytical schedule and authorization criterion on all 384 cases per arm, reaching 78 lawful vertical calls each. Merely skipping stale horizontal samples gives 60 lawful vertical calls and no unauthorized effects. The difference of 18 comes only from the newly supplied lawful component; it does not separate two methods with access to that component. Neutral without authorization gives 36 invalid setter calls. Fresh mailbox alone gives 48 invalid setter calls. There is no architectural advance over an equally informed direct fencing-plus-materialization rule. This establishes a precise cross-layer dependency and positive fallback in a development fixture, not independent transfer or I1 acceptance.

\paragraph{Next discriminating cut.}
A policy that labels an output when it was constructed still needs scoped authority and lifecycle at consumption, or a valid hold across both cuts. Test a post-staging recreation with an authorized current vertical effect and a stale sampled horizontal effect. Distinguish recomputation, preservation of separately attributable portions, and a scalar aggregate from which no valid portion can be recovered. If downstream application is already irrevocable, separately verify the residual effect rather than inferring it from state or publication.
