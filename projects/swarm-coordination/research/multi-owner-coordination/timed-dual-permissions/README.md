# Two live permissions, one timed admission

[Proof and separation examples](Timed_Dual_Consent.tex). In one recipient
view the minimum notice is interval stabbing. With private receiver views,
a shared sender encoding needs the chromatic number of the conflict graph.
The same-sized message can be too coarse or too late to support the handoff.

Replay with Python 3.10+, standard library:

    python3 -B replay.py | cmp expected.json -

Timed_Permissions.lean checks the integer timing and intersection kernel.
This is authored development evidence, not an independent or physical test.
