\paragraph{Which square?}
A civil service acceptance can reserve a physical staging lane before it has authorized a shared launch, before performance, and before any credit settles. A scope amendment can set the default lane for future acceptances without affecting an already-reserved lane. The two orderings can therefore produce the same quote, acceptance and settled-credit amount while leaving different lanes free. The consumed interface is the authority to rely on actual timed capacity, not a record of money moved.

There is a documented analogue, not an equivalence of domains. \href{https://support.authorize.net/knowledgebase/article/000001346/}{Authorize.net} distinguishes a void of capture from when the issuer actually makes held funds available; a settled payment instead requires a separate refund. \href{https://arxiv.org/abs/2610.14419}{Sharma's HoldSpec} tests acceptance, outward status and actual hold release separately using synchronized product search. Its offline implementation at commit \texttt{5874e9d7c6055fa8deff6a0dcc68c10f6f952eaa} was run here on two profiles with the same clock horizon that differ only in modeled release delay. The first witness was authorization, void, one tick of waiting: both closed without a capture but one hold released first. This is an actual run of the public reference simulator, not a live payment or a claim about every issuer.

\paragraph{An explicit double category for the test.}
Horizontal arrows are legal state-transition relations whose boundaries carry the data that admissible continuations can consume. Vertical arrows are functions on those boundary states. A square with relations $H,H'$ and boundary functions $f,g$ exists if $xHy$ entails $f(x)H'g(y)$; thus a square is a forward simulation. Identity and pasting follow by function composition and using the same intermediate witness in relational composition. Interchange holds since there is at most one such verification cell per boundary in this construction. Equivalence or a preservation-and-reflection promise needs both directions on the stated attained domain; forward preservation alone does not imply it. This is an ordinary relations-and-functions construction, not a new double category of games. It is useful only when the chosen states and comparisons retain the intervention semantics.

For the sibling #382 physical model, configure a default lane for new attempts and accept a timed hold. Amending the default after acceptance does not remove the active hold. If a different lane is actually acquired first, the staged transfer can occupy both lanes until the previous effect is physically drained. Only a comparison scoped from the true drain cut onward then has equal capacity data. An admissible earlier capacity query still distinguishes the orders, or already affected which work could have started. The model does not permit retrospective deletion of time, reinterpretation of authorization as release, or a transfer without its extra capacity. The fixture is a pasting test for an allowed vertical function only, not a promise that arbitrary state migration is a function or available at runtime.

\paragraph{Exact residual profile for a fixed retirement consumer.}
Fix a finite set $K$ of lawful-to-test retirement scopes and a finite vector of resource/time coordinates. A raw current ledger associates each live claim $i$ with nonnegative footprint $w_i$ and signature $A_i\subseteq K$. In the declared class, a valid certified settlement in scope $j$ retires exactly the old rows with $j\in A_i$. Certification denotes an admitted effect-side event: it is not a requester command that can release a live physical effect, and a void request alone changes no footprint. For this theorem the modeled observer may test every sequence of valid scope retirements, and all signatures are fixed until such retirement. No named per-row query, minting, side-effect-conditioned payment, or selective reclassification is in the test language. The full bench test language need not be granted to a single running robot. If the real law permits only some settlement sequences, the conclusion is limited to their attained tests; it may then need less information. If effects or authorities change during a retirement, this model does not supply a reduction.

For each exact signature $A$ save $W_A=\sum_{i:A_i=A}w_i$. After applying all scopes in $S$ the occupied footprint is
\[
 F(S)=\sum_{A\cap S=\varnothing}W_A .
\]
Thus the grouped profile suffices for arbitrary adaptive finite sequences of certified scope operations with capacity probes. On the declared interface equality of all continuation responses is exact: $G(B)=F(K\setminus B)=\sum_{A\subseteq B}W_A$; solve recursively by subtracting the terms of proper subsets. Equal initial capacities and equal one-step releases are not enough. Put one unit each in signatures $\varnothing,\{a,b\}$, or one each in $\{a\},\{b\}$. Both start at two and retain one after either scope alone. After both scopes the first retains one but the second retains none. Released amounts visible in a narrower controller may still need receipt evidence; the formula concerns actual effect and a declared query, not a guarantee it is visible by the deadline.

For up to $m$ available distinct scopes the shortest distinguishing continuation can need all $m$. On the same footprint coordinate compare the one-unit ledger of even-cardinality signatures with that of odd-cardinality signatures. For every proper set $S$ of applied scopes pick an unexercised $j$; toggling it pairs surviving signatures across parity. With all scopes applied only the empty signature survives and belongs to the even ledger. Repeated scope operations are idempotent here; this is a sharp distinguishing length within the language, not a universal lower bound on messages or field controls. Direct synchronized-product search reproduces the finite witnesses and the profile algebra recovers the full family without enumerating every ordered word.

\paragraph{A scoped interpretation using Contextual Composition.}
The fixed-interface membership of each coordinate after a permitted continuation is a declared primitive family for \href{https://github.com/eternal-november/eos-research-programmes/blob/main/projects/contextual-composition/feedback-and-concurrency/observable-covers/Residual_Profiles_and_Admission_Reflection.tex}{Residual Profiles and Admission Reflection}. Equality of all of its sections on two raw ledgers is exactly equality of the signature-group sums; recursive subset subtraction proves the necessary direction on attained inputs. An interface change that acts by one known function $\phi$ on old signatures induces pushforward of the group sums. A named retirement $j$ transports to $j'$ exactly when membership is reflected on every potentially positive source signature: $j\in A$ if and only if $j'\in\phi(A)$. This is sufficient by filtering each row, necessary for universally valid transport by the single-row test. For matching attained profiles, require a preimage ledger for each target profile in addition to reflection. The replay's constructive positive control bijectively relabels scopes and preserves all weights, so inverse relabeling supplies that preimage. No such assumption is made for a general amendment. A replacement that can single out an old owner within an otherwise equal group cannot be evaluated from the old quotient. In that case the rule either needs new source evidence before declaring the square, or must retain the owner distinction beforehand.

\paragraph{A strategic condition is separate.}
\href{https://arxiv.org/abs/1711.07059}{Hedges' double category of open games} uses horizontal games, vertical lenses and morphisms that also preserve responses under transported contexts. A physical square neither proves such a morphism nor reduces its definition. A narrow economic test can already fail. With the #382 notation, positive performance probability lets one normalize incremental utility on a menu $(x,z)$ to $xP_i-z$, for attempt probability $x$ and expected fee weight $z$. A common affine transport $z'=\alpha z+\beta x$, $\alpha>0$, preserves all menu comparisons for each retained type exactly when $P_i'=\alpha P_i+\beta$, provided the old indifference menu at its cap is admitted and transported. Necessity tests indifference to refusal, sufficiency is positive scaling. This applies only to a common affine fee change leaving attempts and types fixed. Starting caps $(18,12,6)$ and changed caps $(18,15,6)$ hold the first and last fixed and change the middle type's decision at price 14. The latter can be modeled as recovery of only the middle type's failed-attempt fallback, holding physical success probability at one half. No common affine map transports all responses. The obstruction does not rule out a more expressive lawful menu, different strategic types, or other vertical lenses.

\paragraph{Disposition.}
A scope-only ledger, its direct product comparison, and the relation model are matched accounts on the same capacities and observations. Their agreement is not a planner improvement. This scoped study makes precise which resource distinctions survive a particular test language and when a graph square fails after amendment. It does not claim priority for subset inversion, transition-system equivalence, or double categories; no live provider or full strategic morphism is verified. Lean checks two pasting implications, filtered transport and the two-scope example. Separate scripts reproduce 3,020 ledger checks, 17,487 layout and scope controls, 4,180 live-timing comparisons, parity depth controls, and 11,760 affine menu comparison checks. No full contract obligation is discharged.
