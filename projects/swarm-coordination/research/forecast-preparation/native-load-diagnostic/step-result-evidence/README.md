# Recover the forecast from an earlier native observation

[Exact comparison and scope](Step_Result_Evidence.tex). The stock
RWARE call's default self location, read immediately after a named
attempt with a known launch point, fits in the ordinary radio window
and preserves the optional report. A success acknowledgement does
not supply the same information. The whole stock next-step result
can match for a move and a boundary-clipped no-move if the launch
premise is missing.

Materialize `SOURCE.tsv` and use Python 3.10+, NumPy and C++17:

    set -o pipefail
    sh replay.sh /path/to/materialized-sources | cmp expected.json -

This tests a stronger selected-code fixture and an authored continuation
change, not factory telemetry, measured rates or independent acceptance.

The [reserve-commitment replay](../reserve-commitment/) applies this
calibration to a different, later native mission with real staging costs.
