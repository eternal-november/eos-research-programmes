\paragraph{What is strengthened.}
The preceding loaded calibration only exposed one of two named lane
observations in the ordinary receive window. Its alternative paid for
an additional receiver slot. The new test permits access instead to
an existing native source observation at an earlier execution cut,
not to an evaluator's latent pallet condition, a hidden
\verb|req_action| value, a precomputed parity or an extra radio.
The exact stock default dictionary observation path (including
\verb|_make_obs| and \verb|_get_info|) is executed with unnormalized
coordinates. The carrier starts at known $x=1$ and tries one
identified forward step while carrying the required load. A selected
SubT replay checks the actual capacity and callback in the same
execution. Sources are pinned in \verb|SOURCE.tsv|; position
uncertainty, operating rates, rewards for preparation, transport
links and archive availability are not field measurements.

\paragraph{Native effect and retained context.}
The returned self location immediately after the step is $x=1$
if the pallet prevented movement, or $x=2$ if the move succeeded.
The action return is nonterminal in both cases and contains
identical rewards, done flags and empty info. The diagnostic
adapter may therefore either report the same two-byte acknowledgement
for all successful API calls (uninformative) or encode the older
qualified location as a two-byte bit report. In either arm the
old work's three-byte debit and this reading fit exactly in the
same five-byte first receiver window; the trial's other independent
callback and the optional four-byte report at the second receiver
both still run. The paired arm of the earlier study had to
forego one actual optional callback to obtain both observations.
This new access is a capability of the plant-side interface at a
particular time, not free data assumed available in the original
archive. Erased reports are charged as attempted native sends.

A matched control changes the launch position. One actual carrier
moves from $x=3$ to the edge $x=4$; another requests the identical
forward step already at $x=4$, where its request location is clipped.
The whole selected stock next-step result (both self observations,
sensor neighborhoods, rewards, flags, and info) is equal, and
both commands remain labeled forward internally. Their displacements
are one and zero respectively. Thus even an exact position or a
retained command name is not an execution certificate without
the ordered pre-state/launch contract. A detected lack of motion
also does not establish its cause outside the fixture's declared
alternatives.

\paragraph{A second boundary: measuring a physical block is not measuring
the counterfactual route law.}
In the first regime, an actually blocked native movement triggers a
route to the opposite lane. In another lawful route adapter, it
takes a detour and returns to the old lane. Both continuations are
physically executed using selected stock moves and carry the same
load. The immediate return, delivery of the early bit and
optional work are unchanged. The actual eventual lane outcome
changes from $Y=X\mathbin{\mathrm{xor}} M$ to $Y=X$.
This is a real distinction between evidence of the same native
event and evidence for a forecast of a future authorized policy.
No number of immediate bits identifies which downstream outcome
law holds if receivers may mis-specify which route commitment
survives. Actual route policy or later linked evidence is then
a separate input.

\paragraph{Exact finite comparison.}
With the switch rule fixed, count the same underlying loaded
pallet laws $p=1/4,3/4$. The observer with the named native state
report has classification error $1/4$, or $3/8$ under the sampled
independent half-erasure case. These are the same minimax errors
as a paid paired measurement under its matched erasure process,
but preserve the formerly lost optional callback. Wrong-reserve
regret per episode is respectively $1/8$ or $3/16$ in the
declared utility units. The arrival-only control is
indistinguishable under both laws and remains at minimax
error $1/2$. Exact decoder enumeration, including randomized ties,
and the equally informed direct likelihood lower bound agree.
The campaign runs 256 synthetic native configurations plus
the two clipping controls. Preparation remains a decision for a
different subsequent episode, not a response to the actual pallet
when forming the forecast. This bounds the benefit of changing
the experiment interface at the stated resolution, not a generic
claim against paired acquisition or
\href{https://arxiv.org/abs/1205.0858}{controlled sensing}.
No real telemetry, independent mission, calibrated risk or
full R3b acceptance is inferred.
