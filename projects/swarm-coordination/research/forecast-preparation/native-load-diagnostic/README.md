# Loaded and unloaded experiments identify different forecasts

[Scope, exact decision bounds and replay](Native_Load_Diagnostic.tex).
A loaded carrier is blocked by a pallet in the stock RWARE fragment,
while the same unloaded route is not. The stock SubT fragment
charges concurrent receiver work and erasures. An independently
provisioned diagnostic receiver recovers the loaded pair at the
cost of a real foregone optional callback.

Materialize `SOURCE.tsv` and use Python 3.10+, NumPy, and C++17:

    set -o pipefail
    sh replay.sh /path/to/materialized-sources | cmp expected.json -

The two laws, route choice, exact archive interface and normalized
forecast payoff are authored. This is not a calibrated warehouse law
or an independently selected mission.
