# Forecast evidence with live commitments

A finite exact R3b model: ordinary logs do not identify the future reserve placement when an existing job excludes a same-run scan window. A new diagnostic run has an exact preparation error versus foregone job-cost frontier; a direct likelihood-ratio baseline ties. Same sensor error marginals can support different preparation policies when there is common-mode error.
