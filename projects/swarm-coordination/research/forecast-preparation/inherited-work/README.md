# Forecast preparation around inherited work

This finite maintenance study obtains preparation clearance from the actual two-handoff scheduler, not from the forecast. It compares warning-guided preparation and diversion against optimized restricted menus. A late certificate leaves some physical opportunities intact but prevents the incumbent controller from using them. A different gate can handle a conditional request, and an independent control shows how sharing the detour's worker slot removes diversion.
