# When a diagnostic changes the forecast law

Unlimited complete unloaded experiments can agree while two possible loaded
laws call for opposite preparations. A calibrated transport bound gives an
exact regret frontier. A separate protected loaded probe restores information,
and adaptive stopping can beat the best fixed sample count after charging
every probe. The matched controlled-sensing calculation ties.
