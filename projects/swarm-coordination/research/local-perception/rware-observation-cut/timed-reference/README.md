# A late binding can make an earlier local flag useful again

[Proof and audit](Timed_Reference.tex). In the pinned two-lane warehouse
case, the receiver's local shelf flag is truthful but does not identify
its lane unless it is bound to the correct producer assignment.
A held-in observation-selected plan can finish in five steps if the
binding arrives by step 1, six if it arrives at step 4 and the earlier
evidence is retained, or eight without a usable binding.
For one frozen six-step prefix, the local shelf flag is out of view
when the binding arrives. One retained logical bit from the named
probe is necessary and sufficient, in addition to the timing and
source calibration.

Motion and observations use the selected native source. The arrival
schedule for the binding is a declared input, not a measured radio or
actual retirement/certificate protocol. Materialize the files in
`TIMED_INPUTS.tsv` or use the [source-complete Space
archive](https://chatgpt.com/space/page_f5a09a52f6b881919b10d91ecf2caa80).
Run `sh run.sh | cmp expected.json -` (archive names:
`run-timed.sh` and `timed.json`). Requires Python 3, NumPy and Git.
