\title{Exact supplements for an amended motion-audit interface}
\maketitle

\paragraph{Interface.}
Use the previous native RWARE family, which realizes every binary word $x$
of length $n$ of actual named body effects. The old exact audit $y$ answers
the OR query at each placement of a window of $r$ rounds.
Freeze body, lifecycle, exact operation semantics and cutoff. No recent
pose, reset flag, numeric entity identifier or message timestamp supplies
omitted effects. This is zero-error fixed-width communication between a
source retaining qualified outcomes and a receiver, not a measured
protocol. Count payload bits, not identity, authorization, archive storage,
CPU or framing.

\paragraph{Keep the old export unchanged.}
For a fixed old answer $y$, let $Z_y$ be the union of windows answered
zero. All compatible $x$ are zero on $Z_y$. Setting these coordinates
to one while leaving other coordinates alone injects the class into the
all-positive class: an old positive stays positive and a negative
becomes positive. The original class can be recovered from the image
and $y$ by putting zeros back on $Z_y$. The all-positive class consists
of words with no $r$ consecutive zeros. Write $A(l,r)$ for their number
on length $l$. A trailing-zero recurrence counts and ranks these words.
The worst old answer therefore needs exactly
$\lceil\log_2 A(n,r)\rceil$ further bits to answer all singleton queries.
At $n=100,r=5$ the old interface used 54 bits and the supplement can need
98, not $100-54$; its largest class has
$240714680556315819945145376976$ members.

If the amendment instead names a known subset $S$ of the singleton
positions before the supplement is sent, set off-$S$ coordinates to
one as well. This maps projections of the old class injectively into
projections of the all-positive class. If the consecutive runs of $S$
have lengths $L_1,\ldots,L_j$, such projections have exactly
$\prod_i A(L_i,r)$ possibilities: assign one off $S$, then the only
forbidden assignments are all-zero $r$-windows entirely within a run.
Mixed-radix ranks of these runs give an encoder and decoder.
At $r=5$, 50 alternating positions need 50 bits; 50 adjacent ones need
49. If any position can be requested after the supplement must already
be sent, all singleton answers must descend through the supplement again.
These results presume the source can still read the qualified causal
archive. If the old summary is the only surviving data, no supplement
or renaming can recover a split in its history class.

\paragraph{Redesign the first export.}
Consider a different interface where an amended reader is known to need
the full word and the receiver is already allowed to distinguish some
histories within an old answer class. Let $F_y$ be the number of source
words producing $y$. An $a$-bit first export and $b$-bit supplement are
possible exactly when
\[
 \sum_y\left\lceil\frac{F_y}{2^b}\right\rceil\le 2^a.
\]
The first codeword must decode $y$; at least the indicated number of
distinct first codewords within its class is necessary because any one
can name at most $2^b$ histories after the supplement. Conversely,
rank within the class and split the rank into a bucket and a residue
modulo $2^b$. Index the bucket jointly with $y$, allocating each $y$
just its necessary number of buckets, then send the residue at the
amended cut. This is constructive. If the original law forbids the
receiver learning anything beyond $y$, this redesign is not admissible:
an early bucket can reveal an extra history distinction even when its
message length is unchanged. Randomized first encodings with no added
information per $y$ are not a substitute for that distinction.

\paragraph{Exact measurement without enumerating all histories.}
For a given $y$, positive runs have disjoint sets of source coordinates
available, since an entry cannot touch a negative window. One run filling
all $y$ gives $A(n,r)$. A run of length $L$ meeting exactly one boundary
has $L$ eligible source coordinates, with the coordinate next to the
negative side forced to one. Its factor is $A(L-1,r)$. An interior run
has $L-r+1$ eligible coordinates, both outer coordinates forced to one
(coinciding if there is just one coordinate), giving
$A(\max(0,L-r-1),r)$. The source positions outside runs are fixed zero.
Each uncovered positive window would leave $r$ consecutive zeros in the
free interior; truncated edge windows contain the forced one. Thus the
total class size factors. A run-length recurrence counts classes by that
product, independently of a trailing-zero constraint recurrence used to
decode an individual class.

For $n=100,r=5$ the 54-bit capacity is $18014398509481984$ first
codewords. With $b=52$ the exact required number is $18148649035734681$;
with $b=53$ it is $18007974586498170$. Thus 53 is sharp with the redesigned
54-bit first phase, down from 98 when the existing export is fixed.
This is distinct from simply sending all 100 bits early, which exceeds
that phase's cap. No reduction against an equally informed direct rank
coder is claimed. The first message's permission to reveal more than
$y$ and the producer's access to complete history at the initial cut
are indispensable changes to the interface.

\paragraph{Checks and limits.}
The replay tests the projected bound and executable decoder, compares
the product-derived history histograms to brute source enumeration,
and checks both payloads end-to-end. A compact early export is not a
way to retain unavailable source history. These exact analytic costs
do not price any fault in retrieving, transferring or interpreting
qualified body evidence. No independent mission or architecture
acceptance is claimed.
