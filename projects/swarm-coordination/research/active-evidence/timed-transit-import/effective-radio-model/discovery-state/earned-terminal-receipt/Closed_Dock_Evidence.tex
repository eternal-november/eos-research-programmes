\paragraph{Audit.}
Reading the exact terminal ledger can avoid a duplicate recovery trip,
but getting to the ledger and reading it can consume the only early
crossing of a gate. The test joins an actual native radio receive or
failure, a subsequent route change, a local exact-key read, the
recovery of that same old inspection report, and the courier's
second inspection and egress. Allowing earlier egress when the old
report was already paid is a declared performance objective, not a
waiver of the remaining report or inspection duties. This is an I2/R3a
development cut, not an independent mission, field claim, or an
advance over a fully informed same-interface planner.

\paragraph{Sources and omissions.}
Use the published Cave Circuit 01 visibility graph and positions
imported by the parent replay (all 158 vertices; independent shortest
visibility-cost computations). On the projected 3--2--39 RF link,
at configured hard range 25.51 the two native breadcrumb orders with
the same final set differ in actual delivery. The pinned SubT dispatch
attempt sends the literal current key, and the bound callback exports
only the actual resulting body. The sender's nine-byte debit is
observed in both histories, but the receiver's is present only with
the delivered body. Cut the link after that attempt as an explicit
fixture intervention; no later RF feedback is available. The dock
replays the resulting sealed ledger in SQLite and also retains a
different earlier key. That older exact key is not evidence of current
delivery. The positive or qualified negative lookup arises only after
a local read while at tile 39, costs one tick, and concerns this
closed archive prefix. Do not use SQLite absence to infer that a fresh
radio writer outside the scope was inactive. Copy acquisition at 3
and manual deposit at 39, each costing one tick, use the preauthorized
retained copy and repeated deposit is idempotent by key.

The graph adjacency is used as an authored travel projection, not as
a claim that the visibility edges certify geometric clearance. Local
interlocks and equal travel ticks are explicit idealizations. The
cut on physical edge 2--3 activates before issuing a move at tick 3.
A crossing already issued at 2 can finish at 3; no new traversal
begins in either direction while closed. The courier sees this
interlock only at an endpoint. It receives neither the true gate status
at a distance nor a native first-breadcrumb or reference world label.
No new reserve, radio slot, or telemetry is added between policy arms.
Dispatch of separate native traffic is checked independently; it
does not certify the authored courier's egress.

\paragraph{Service and information scopes.}
The mobile reserve starts at 43. The additional inspection is a
local unit operation at tile 1, due by 12 in the frontier experiment,
and egress is at 0. The original old report must be actually at 39 by
$D_R$, and the reserve must reach 0 by $D_E$ in every history. The
earlier promise $F$ applies only to histories in which the desk's
initial old report is already present; it is not given as a history
tag to the mover. Comparators use the same motion, copy, clock and
local interlock. The passive comparator does not query the archived
key; the exact active comparator can choose any physical visit,
read or available movement. Hold fixed native midpoint range and
cross the two ingress outcomes with each of the two gate outcomes.
Also run nominal, contact-only, gate-only and joint singleton controls
against a separate known-plant reachability search. A singleton is
an oracle bound for the hidden problem, not a deployable comparator.
Test the exact sealed read, unavailable or positive-only read, and
temporary or persistent omission. A missing read is never interpreted
as a certified negative.

\paragraph{Sharp deadline staircase.}
For the reported closed-cut split, the shortest committed route
without a read reaches 3 at tick 3 across the last admissible near
crossing, takes the retained copy, and comes back through the longer
route, doing the additional inspection along the way. It deposits
by 14 and exits by 17. The long route from 3 to 39 when 2--3 is
closed has eight moves
\[
       3,8,6,16,42,13,1,43,39 .
\]
It is shortest on the complete imported travel projection. The
shortest motion in the closed/undelivered world either uses that
return after an outbound crossing by 3, or takes the detour both
ways; neither gives egress before 17 with the two operations and
inspection. Without terminal information, the same closed gate
worlds with different radio outcomes expose identical local histories
prior to deposit, so the earliest promise in the already-paid
branch is also 17.

An exact read after collecting the copy cannot improve the bound:
at the dock it takes the same one tick as the idempotent deposit.
Any read that can help must occur without an acquired copy at the
dock. That first read is no earlier than 2, making the near crossing
unavailable before the potential retry. After the read the absent
branch then needs eight moves out, one collect, eight back, and one
deposit, plus its inspection if still owed. A fastest desk-first
route reads at 2, includes the inspection along the detour, deposits
by 21 and exits by 24. On the present branch it must backtrack to
inspect, and exits at 10. If inspection instead precedes the first
read, completing inspection and traveling to the dock cannot finish
the read before 5. This gives a faster present-branch egress of 8,
but the closed/absent branch cannot deposit before 23 or exit before
26. These cases yield the exact frontier in the declared sweep:
\[
F^*=\begin{cases}
8 & D_R\ge 23,\ D_E\ge 26,\\
10 & D_R\ge 21,\ D_E\ge 24\ \text{and the previous line does not apply},\\
17 & \text{otherwise in the checked envelope.}
\end{cases}
\]
The no-gate case allows $F=8$ with much tighter report and egress
budgets. A temporarily unavailable desk can move the desk-first result
from 10 to 11, even though a retry is eventually readable. If
persistent omission is an admitted possibility for both outcomes,
the fastest guaranteed present-branch egress is back to 17. There
is no free estimate of archive state in those cells.

\paragraph{Procedure and comparator.}
Synthesize an action only if every partition of its successor plant
states by actual local feedback has a winning continuation. Belief
membership uses only the motion state, local interlock observation and
return value of the consuming read; absolute time is the mover's
own elapsed ticks. The finite recursion is by decreasing remaining
horizon. It picks one first action for each local belief; no private
world identifier can select different pre-observation actions. The
known-world search bounds the local solution; executable replays of
the selected policies use the native-derived ledger and check exact
keys, authorized movement, inspection and egress. An unmodified
contingent planner with this exact same action/sensing process can
make the same choice and is represented here by the direct
synthesis, not a claimed performance opponent. The passive/known
world comparisons isolate the marginal value and cost of actually
acquiring terminal information. They do not spend the independent
enclosed mission or establish an I2 advancement over an existing
full system.
