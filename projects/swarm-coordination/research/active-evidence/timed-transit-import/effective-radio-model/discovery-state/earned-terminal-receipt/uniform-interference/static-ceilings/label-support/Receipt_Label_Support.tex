\paragraph{Audit.}
The fixed-cap comparison identified a key distinction that a byte
ceiling cannot make. Here the proposed gate instead tracks a compact,
fixed label and asks exactly when that label is sufficient. Which
reports can be owed in the \emph{same retained receipt window} matters
more than the maximum count owed in a single mission. Compact labels
may be reused only after checking the surviving writers and receipts.
This is a calibrated representation and force-of-scope result,
not a new packet elimination primitive or an independent mission.

\paragraph{Declared seam.}
The pinned native cave RF source and broker still perform actual
dispatch and admission for every unfiltered frame. All A-class
frames have nine bytes, identical fixed label encoding cost across
arms, and a literal distinct key as consumed in the exact comparator.
The fixture exposes either the configured label or the actual scoped
key to its authorized pre-enqueue owner. It retains successful
receipts but never promotes failed attempts to receipts. No scope is
asserted in which stock SubT can recover an application key before
charging the native resource. This experiment treats metadata access
and authority as explicit fixture capabilities, not a wire encoding
claim. Two independent A-class owed keys plus a ten-byte B fit
within 28 native bytes; an extra uncontrolled duplicate can leave
B unpaid. The separate side stream has its own native receive path.
There is no movement or field accuracy claim in this follow-up.

\paragraph{Static label law.}
Let $K$ be a finite set of exact named report types including
the epoch or other distinction used to separate duties. The
source declares supported sets of keys that can both incur a
qualified first receipt in a single retained window. More
precisely the pair $(u,v)$ needs separation if a legal continuation
can use $v$ after a receipt for $u$, with positive service still
requiring $v$ and neither retirement nor forgetting between the
events. The normative exact gate drops a copy only if its own key
already has a qualified receipt.
For the experiment each admitted pair has both orders and there is
no ageing or authority change inside a window. Make an edge between
every distinct pair that can coexist in an admitted list. A label
function is exact on all such lists if and only if it separates
the ends of every edge:
\[
             \mathrm{exact}(\ell)\quad\Longleftrightarrow\quad
             \forall\{u,v\}\in E,\ \ell(u)\ne\ell(v).
\]
Necessity follows because an alias makes the gate reject a still-owed
second key in a tested order. For sufficiency retain a seen label
only on an actual receipt. Within any admitted list, any seen label
that matches the candidate must be that candidate's key. The actual
prefix gate then agrees stepwise with the exact-key gate.
Thus the minimum number of static labels in the declared family
is the chromatic number of the coexistence graph. The graph is
indexed by an admissible history law, not the number of live
objects in a log. If every two keys can coexist then all $n$ keys
need distinct static labels even though no history has more than
two. In a narrower disjoint support reuse can be sound.

The Lean kernel proves the exact separation law and the complete
pair-support cardinal lower bound. Native replays test 52 canonical
label partitions, both orders for each pair, and compare the
resulting minima on all 1,024 five-key undirected supports.
The graph-coloring result is a familiar mathematical structure;
the contribution here is the exact mapping from finite source
admission support and charged receipt windows to what the guard
can safely forget.

\paragraph{Why simply resetting a label is not an alternative.}
Start with a real nine-byte receipt for old key A. Reassign its
single label to new, still-owed key C before the native RX credit
expires. Keeping the old seen bit refuses C even when no old
writer sends again. Clearing it permits C when the old writer has
really retired, but a delayed A can set the bit first and prevent
C. Admitting both distinct or duplicate attempts by default spends
27 on A, delayed A and C, then blocks the ten-byte old B at 28.
A fixture with access to exact still-current key/generation and
with control over all relevant enqueues eliminates the duplicate
and preserves both remaining obligations under either arrival
order. The guard cannot derive the requisite distinction from an
otherwise identical tag and local state representing the delayed
old request and the newly owed request. The Lean impossibility
is at that information interface; physical retirement before
reuse, a fresh binding with sufficient tags, qualified older-key
evidence, or genuinely separate reservations are different
architectures. Native logical reset does not cancel an RF debit.

\paragraph{Strong comparison and remaining work.}
Established
\href{https://www.rfc-editor.org/rfc/rfc8938.html#section-4.3}{DetNet
packet replication, elimination and ordering} is the conceptual
baseline. An equally provisioned elimination point that sees the
same flow and generation identity before the constrained resource
can make the same decisions. A later application receipt cannot
undo a prior native debit. Dynamic assignment needs actual
negotiation costs, checked generation lifetime and closed old
authority; the present experiment supplies none of those free
to the native controller. The evidence is 1052 matching
native/reference rows and three Lean lemmas. All scopes including
hard range, usable accounting window and receive thresholds are fixed by
the held-in native seam, not inferred for an independent site.
