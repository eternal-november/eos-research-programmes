\section*{Idempotent content is not compensation for prior resource use}
Use the qualified local gate sample and its single immutable closure,
alongside the actual native courier clearance, pose outage and broker
recovery. The gate's past installation record and the radio's present
credit are two independent contextual exports. Returning an existing
exact Q result does not mean no new native physical resources were
spent on delivering the redundant request; it is only idempotent in
the specified effect dimension. Conversely, a cached gate receipt has
no power to refund a radio's actual charged bytes.

In one arm the courier has handed its genuine three-byte clearance
to the actual native queue before recovery of the pose-stalled
broker. It is rescued and delivered later, but the authoritative Q
worker reads an already committed installation; its interval and
number of ledger effects do not change. The true Q state enables a
separate typed acknowledgement from gate to courier. Its payload
reports committed status for the known gate/era/duty, not the exact
historical interval on the wire. The independent gate diagnostic still
has its native receipt. A later-four-byte audit in the courier-to-gate
direction now faces real TX and RX debits of three already paid bytes.
The audited next task fails at the same cut and at debit age exactly
one second. The original charge survives unchanged. At the tested
1.125 s retry it has expired and the separate native audit succeeds.

Compare retaining the courier request before it enters the broker
and waiting for that same native historical acknowledgement. In
the declared scope and trials the local gate has already completed:
the courier need not send its duplicate, and its same audit now
fits at the repair cut. Delay is saved only with that genuinely
observable prior committed state; an unchecked assumption that the
local gate works would drop required work under another history.
The contrast gives a concrete boundary for compensation: preserve
or recover semantic authority/results as justified, and compare
actual event-produced resource context separately. Native mode,
geometry/pose rounding, gate and dock crashes and independent
diagnostic remain tested in both arms. The projected native
accounting is not a field latency bound or an independent mission.
