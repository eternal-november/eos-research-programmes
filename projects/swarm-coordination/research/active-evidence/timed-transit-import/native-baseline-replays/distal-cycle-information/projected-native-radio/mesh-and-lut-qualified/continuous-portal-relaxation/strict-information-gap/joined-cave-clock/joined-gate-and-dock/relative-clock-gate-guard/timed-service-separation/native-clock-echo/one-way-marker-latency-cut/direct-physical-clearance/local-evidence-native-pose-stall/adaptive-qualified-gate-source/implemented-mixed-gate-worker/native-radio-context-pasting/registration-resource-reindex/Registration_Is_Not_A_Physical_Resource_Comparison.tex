\section*{Reindex the physical resource, not the native address}
Under a declared physical-credit contract the effect of an accepted
native transmitting debit lasts through its accounting window, even
when its packet is not delivered. A simulated authority transition
may keep the same physical radio or legitimately bind a fresh
independent one. These are separate source-certified interpretations,
not choices inferred from an address or record reset.

Execute the actual native registration and removal bodies in the
pinned replay. A repeat registration on a present name retains the
actual node and its debit. An authorized remove and new registration
installs a different native state. If this is the same physical
radio under the declared external contract, a compatibility witness
must carry its earlier unexpired debit across the transition.
If it is a genuinely independent qualified sending resource,
the old transmitter's debit need not bind it. The recipient's
independently held credit may still bind the replacement.
No source comparison equates a renamed actor with a verified
new physical resource by construction.

The small executable checks both interpretations and the stable
duplicate registration using actual directed attempts. The source
fault fixture has an earlier charged but undelivered frame and
an optional separate live receive debit. Keeping the charged
time/source profile when the hardware resource is the same
enforces the declared physical cap. Treating a new native node as
proof of fresh physical capacity produces one violation in the
negative comparison. A qualified different transmitter can
send when the actual receiver still has room; native receive
credit rejections, including send-side charging, remain visible
even after the scope change.

The source-level distinction does not say that the SubT's declared
software accounting should itself adopt that external persistence
contract. It is a typed implementation obligation for any enclosing
architecture that claims the physical resource invariant. No fresh
binding authority, actual hardware transition, network attack or
independent mission claim is supplied.
