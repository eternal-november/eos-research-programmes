\section*{From the mixed comparison obligations to an actual gate worker}
This is a first implemented slice of an integration mechanism, not
an inventory of handlers. The pure interface fixes the gate, closure
duty and observation era. Its context concerns who can install that
effect now. Its content retains qualified whole-body exit facts and
the original durable result, if any. A source substitution on the
physical side and an authority change on the context side induce
different comparisons. The small request grammar and output sum
are specified in the independent context/content kernel.
The native worker does not implement the general Interactad
construction; its direct transition is the evaluator of the
particular mixed contract used here.

\paragraph{Actual adapters, comparisons and repair.}
At an irreversible effect transaction, read the current operator
from its administrative row. Independently select physical facts
scoped to the actual gate, mission and evidence era. Separately
read the prior exact effect result. This is the source comparison,
not an equality inferred from a generic ready bit. The independent
kernel chooses one of three branches:
\begin{enumerate}
\item A committed result is a historical answer within the specified
read scope. Return the exact existing settlement and do not renew it.
The historical replay proof has no current write-permission premise.
\item A pending request from a retired operator fails the live
context check. Record the attempt as stale without settling
the semantic duty key. A later authorized actor may still do it.
\item A new effect requires both the live actor and the separately
qualified physical content. Bind the actual effect and exact
receipt in the same native transaction.
\end{enumerate}
Only the fresh authorization needs the new owner; a transfer
does not erase source facts about an unchanged physical crossing.
The optical and radio source labels are both retained for audit,
although they denote the same qualified body predicate for this
effect. The late radio receipt is obtained through the actual
stalled and recovered native queue; it changes the witness archive,
not the returned duration or installed interval. Independence of later
diagnostic and dock work holds in this fixture under their own valid
radio and authority preconditions, not for arbitrary shared resources.

\paragraph{Measured slice and boundaries.}
The independently specified finite kernel is now called by the
positive native gate worker, within the effect commit transaction.
Its contextual handoff tests compare directly with the ordinary
SQL implementation on the same geometry, actor schedule and work.
Their output counts agree. A valid successor yields all 24 timely
authorized closures. The negative cached-permit arm still
installs 12 unauthorized effects when the old commit had not
happened. With explicit withdrawal and no successor, the 12
already committed historical outcomes are retained and the 12
pending acts are not installed. All arms preserve the unrelated
diagnostic and later exact native dock/audit/egress work.
This is no dominance claim over an ordinary direct proof of
the same factored obligations.

The reusable design point is to make changes compare the actual
contexts and effects those proofs read, rather than invalidating
everything or considering every cached result a new permission.
The present comparison is grounded in one fixed semantic key,
an unchanged geometry/evidence era, exact scoped trusted source
labels and one serialized simulated gate authority. More concurrent
duties, advancing resource versions, invalidation of a physically
stale observation, independent authority trust, and source-grounded
distributed refinements need separate hypotheses and a coherent
pasting argument. The full layer and independent mission
remain open.
