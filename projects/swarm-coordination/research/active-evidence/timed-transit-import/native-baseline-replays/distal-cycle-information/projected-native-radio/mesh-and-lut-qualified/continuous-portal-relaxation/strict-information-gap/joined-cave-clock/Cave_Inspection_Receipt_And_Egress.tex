\section*{A single-clock cave inspection, receiver crash and exact return}

\paragraph{Mission and comparison scope.}
Two mutually exclusive installed passage closures in the published Cave
Circuit 01 geometry change the traversable route. The inputs comprise the
signed-off collision and time certificates of PRs 874--876, checked
again before execution. Analytic ray tracing generates the actual byte
sent by each stationary observer. The native SubT broker runs on the same
event clock as the motion; only its received byte selects the round-trip
schedule. One or both observers can send. Neither knows the future of
the dock. The courier rests at all prescribed stops, under the fixed
orientation, speed $1$ m/s and acceleration $5$ m/s$^2$ law. The model
starts timing before the early evidence and requires actual visit to the
inspection pose and rest at home. Fixed actors are excluded from the
whole swept path by exact inflated-cube intersection checks. A stationary
dispatch counterfactual establishes that neither dock can receive the
report from the inspection pose in the tested native radio. The courier
carries its five-byte report to the reserved return stop instead.
No continuous RF inference is made from these sampled dispatch cuts.

\paragraph{Second interruption.}
The first dock receives the named report from the native callback. A
real worker exits immediately before or immediately after a SQLite
transaction records the simulated settlement effect and its keyed
result, in both cases before replying. A second worker at the named
reserve dock can run only after the first has exited and in the arm that
provides promotion. It consumes the actual retry callback and can
retrieve the shared, surviving record. The acknowledged result comes
from that worker and is transmitted back through the native broker.
Completion requires exactly one matching effect and the exact returned
bytes, not merely a radio callback, plus delivery of two separate
one-byte pose samples to an audit endpoint as independent duties
sharing the courier's transmit budget. The sample payloads come from
the return stop's coordinate and are stored in a separate audit table.
The reservation and authorization, trustworthy binding, and surviving
common database are provisions of the fixture; this is not a quorum or
remote storage proof. In particular commit and physical actuation have
not been made atomic.

\paragraph{Checked results.}
At six bytes per rolling second, a retry at exactly one second after the
first send fails (the first debit is still live). One eighth of a second
later, both the retry and the second audit sample fit, and the courier
gets the framed result on the next eighth. Both gate cases, both primary
crash cuts, and three observer-availability cases pass (12/12).
A five-byte cap recovers the named result but misses the two-sample
audit criterion. Blind credit on retry duplicates the effect in 6/12
runs despite returning exact bytes. Without the authorized reserve,
delivery of the backup request never proves settlement.

With a registered old dock whose pose source fails, the native
dispatch never reaches the reserve contact or the later audit
message. In the paired test using native membership removal of that
dock before retry, both proceed in 12/12. The removal is an explicit
locally available control in the fixture, not a claim of automatic pose
failure detection, timely removal, or fail-safe behavior of a deployed
system. A direct guarded SQL baseline with the same removal,
same named records, and same native timing matches all checked results.

The worst positive egress including the round-up of the radio cut and
both late operations is 453.847823 s in the model. The independent
geometric lower bound from PR 876 applies to motion with the same
six-meter local observation envelope but no early source, without charging it
any late radio delay: at least 456.4981695 s. Thus 454 s distinguishes
the modeled information regimes, not equally informed algorithms.
All cuts are serial, staging is already in place, worker wall times are
not measured, and the early analytic beam is not a calibrated sensor.
Both closures, fault cuts, bounds and data flow are development inputs,
not a frozen independent I1 or I2 test.
