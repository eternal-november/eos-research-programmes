# Native historical clock receipts across a gate authority handoff

Civilian held-in extension of native clock acquisition. Exact official
cave assets under `up` as in Space 666, exact included `parent` sources,
Python 3 with NumPy/NetworkX, Git, SQLite and a C++17 compiler.

```sh
bash replay.sh up parent | cmp - EXPECTED.jsonl
```

The gate authority transfer and clock phases are simulated. The gate
worker commits and exits, and the SubT broker runs for the clock
frames and original later dock handoff. No adversarial frame
authentication, independently chosen geometry, or field behavior is
claimed.
