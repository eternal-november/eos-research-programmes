\section*{Stable contents and resource credits across an opaque rebinding}
The stakeholder constraint in this civilian test is to return the
exact old result without exceeding either the physical transmitter
cap or the native receiver cap. A separate diagnostic should not
wait for uncertainty about the return. The early accounting window
has one remaining dispatch opportunity for the return. Both replicas
actually receive the same named result on the pinned native broker
before that window. After one accepted transmission fails to arrive,
its physical source still has a live debit. The native effect of
the authorized handle transition is real removal and re-registration
for both entries. Physical identities, the authority of the binding
driver, transfer integrity, and seriality at the dispatch cut are
part of the enclosing simulator contract, not capabilities attributed
to stock SubT or to field hardware.

\paragraph{A mixed preservation law.}
Let \(p\) be a physical transmitter principal, \(k\) the named immutable
receipt and \(d\) the receiving principal (stable in this case).
At the dispatch cut \(t\), the executable admission test requires:
the named local value and authorized scope of \((p,k,d)\); the current
binding generation; and
\[
   U_{\rm tx}(p,t)+|k|\leq 6,\qquad
   U_{\rm rx}(d,t)+|k|\leq 6.
\]
Here \(|k|\) means the bytes of its stored value and \(U\) is the sum
of nonexpired debits, including an earlier transmit that did not
deliver. An entry at exactly one second remains live. Local
preflight, conversion to handle \(b(p)\), and dispatch are serialized
in this fixture. With two complementary bijections \(b\) and \(b'\)
on the affected aliases, the physical result after decoding the
sender is equal under either binding. The equations follow because
all four predicates (name/scope, liveness of the newly selected
binding, sender credit and receiver credit) have the same value
after rebinding and resolving again, and the native link behavior
in this fixture is invariant under the change of handle. The same
reasoning works for successive such changes: the current map is
applied once to each checked physical plan, not once per old map.
It does not apply to reusing a previously prepared binding
generation without resolution. Receiver debits do not transport
with the transmitter. These are typed crossing obligations
between content and changes of context, not a construction of
the general Interactad.

\paragraph{Obstruction and control surface.}
In the core pair, both native handles have clean records and both
physical replicas hold the same result. The hidden mapping
assigns the charged physical transmitter to opposite handles in
the two continuations. At the early cut its prior 4 bytes plus the
3-byte return fail the cap, while the other transmitter fits.
No fixed handle gives an admissible guaranteed return at that cut;
randomizing among them cannot give a probability-one guarantee.
The choice can nevertheless be constant at the physical interface:
request a return from the independently qualified replica and resolve
only at the effect-owning driver. This does not give the planner
future knowledge or require it to learn the mapping. The direct
equally informed reference uses the same admission predicates and
matches the replay. A missing qualified identity would not justify
that choice. If the recipient has independent live credit of 4
bytes, neither sender can return at that cut. The separate
diagnostic has a disjoint stable sender and receiver and still
fits; this disjointness is a proven fact of the fixture, not a
default inference from distinct names.

\paragraph{Execution and kernel.}
The replay uses actual broker callbacks, member replacement,
dispatch and byte accounting, with a deterministic link fixture
and a declared serial physical wrapper. It evaluates 320 fixture
invocations (a Cartesian sweep; not independent evidence) over both
bindings, optional second rebind, exact/expired boundary cuts,
receiver debit and request scope. Forty initial returns complete;
160 stale and 160 wrong-scope cases are rejected (overlapping
classes), and all 320 independent diagnostics arrive. A fresh
resolution agrees with the direct physical reference in all 160
second-rebind cases, including refusal when credit or scope fails.
No claim is made about concurrent remote binding, link invariance
for moving radios, issuer discovery, credential authenticity in
deployment, exactly-once remote delivery or mission acceptance. If
an observer asks for the raw routing address, the legitimate
reindex changes that observation; preservation is for decoded
physical sender, exact returned value and resource transitions,
not the raw dispatcher transcript.
