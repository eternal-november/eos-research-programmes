\section*{A small context/content contract that generates direct gate proofs}
Use the context/content separation of the
\href{https://github.com/eternal-november/eos-research-programmes/blob/4359a8a1484498b9c46d8e58a0112448a1fba06b/projects/contextual-composition/publications/interactads/Interactads.tex}{Interactads presentation}
to specify the worker before comparing its traces. Use the
\href{https://github.com/eternal-november/eos-research-programmes/blob/4359a8a1484498b9c46d8e58a0112448a1fba06b/projects/contextual-composition/feedback-and-concurrency/observable-covers/Residual_Profiles_and_Admission_Reflection.tex}{residual-profile criterion}
to test which observations can be merged. The target here is a
finite, independently specified mixed body and certain comparison
squares, not a construction of all contextad/contentad pastings.

\paragraph{Pure boundary, context, content.}
The pure interface fixes an actual named gate, mission, evidence
era and immutable closure duty key. The holder of a future
effect permission lives on the context side. Physical clearance,
the qualified source port that attested it, and any past exact
result live on the content side. A source port's fact is scoped and
authenticated by the previous modeled acquisition; replacing the
actuation principal does not rename the physical gate or evidence
era. A historical read capability is separately granted to both
modeled principals. A transfer is an actual ordered policy
event, never an equality of actor names.

The mixed body at an effect cut takes a typed request occurrence
with its actual context and legitimate content facts to three
disjoint output branches:
\[
 \begin{aligned}
 &\text{exact historical result} &&\text{if this duty is already settled},\\
 &\text{stale attempt, no settlement}&&\text{if the current context forbids this new actor},\\
 &\text{fresh terminal result}&&\text{if this actor is current}.
 \end{aligned}
\]
The fresh branch checks physical clearance and either installs the
effect or settles a qualified refusal. The raw allowance to visit a
port is distinct from the authority to create a closure at it.
A denied attempt cannot consume the stable semantic duty key.
The exact immutable response contains status, event serial and
the actual installing principal if any. A context-change comparison
held to the same operation occurrence does not create future rights
by transporting a historical receipt.

\paragraph{Comparison obligations before code comparison.}
At fixed pure endpoints, the mixed comparison of authority
replacement with the content-side read must preserve the effect
response and leave the record unchanged. This is the concrete
commuting read square, for the stipulated read access. A new
effect square need not commute: with a qualified body witness and
no committed result, placing old installation before withdrawal
commits an effect, whereas placing it after withdrawal returns a
stale attempt and leaves no committed result. Both orderings start
with the same physical fact. The input ports and content evidence
remain in the same typing scope, so an observational capture can
commute with this context change: transferring authority does not
modify the newly observed physical fact. This is a conditional
interchange, not a general interchange theorem. Geometry, clock
era or evidence expiry changes would require their own checks.

As a residual-cover test, compare possible summaries against
the declared primitive observations: exact historical result and
fresh permission for either actor. Forgetting live authority
identifies matched facts and histories for which the fresh test
differs. The owner/qualified-body/result profile permits each
primitive and successor transition to descend. Replacing either
physical source with the other preserves that effect-only
profile. Adding an audit client for the actual source port
distinguishes the two, so requires a finer profile even though
both still suffice for closure. Repeated finite transition
partitioning (test output then every successor class) finds
the coarsest operational partition of the displayed machine:
36 reachable states at a fixed symbolic clock, 10 effect
classes, 29 with the additional source audit. This count neither
erases native serials nor claims a minimal profile over arbitrary
future operations or a newly allowed motion.

\paragraph{Direct native proof obligations.}
The separate persistent-store checker exercises all 120 orderings
of the two attestations, one transfer, and two attempted acts,
with exact history reads, for each of two target authority outcomes
(successor or vacant). It checks each intermediate response and
the final authority, source archive, exact event order, and
installed interval against the independent small semantics.
Transfer is a real committed subprocess followed by recovery.
Late dock and RF physics are not used to construct this proof
specification; those are separately pinned integrated replay
obligations. A different worker may implement the same checks with
SQL or other direct proofs. It must preserve these particular
interfaces, not merely produce equivalent egress on one trace.
