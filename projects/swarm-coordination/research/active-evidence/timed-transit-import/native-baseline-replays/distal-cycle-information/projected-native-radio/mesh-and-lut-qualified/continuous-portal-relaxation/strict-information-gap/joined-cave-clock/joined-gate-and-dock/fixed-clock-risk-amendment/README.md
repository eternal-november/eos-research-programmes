# Shared clock uncertainty and a mid-mission risk amendment

Finite civilian planning fixture using translated copies of the pinned
#881 occupation geometry. Python 3 and Git; the small exact input is
included under `up` in the Space bundle.

```sh
bash replay.sh up | cmp - EXPECTED.jsonl
```

No probabilities are estimated from the simulator. The ambiguity laws,
authority to revise, lack of distinguishing feedback at the cut, and
irreversibility of earlier commitments are declared assumptions.
