\section*{Historical clock evidence is not an active gate permission}
Keep the native clock exchange, gate overlap witness and exact dock
replay, and distinguish the former gate clock era from the current one.
The old authority holder transitions from era 6 to era 7 in a single
authorized SQLite transaction that records the handoff; its process
exits after commit. The later gate actuator reads the actual durable
era. Both possible observer identities have the exact physically
matched gate binding. No malicious sender or forged era is needed.

A delivery receipt may contain a current short echo, or a separate
short calibration reading from the retired instrument. Both readings
can arrive from the same enrolled observer address; its clock
measurements are specifically requested and correctly labeled. No
historical value or request-purpose interpretation is forged. The wide
echo is for the active era. The retired short echo is a truthful
narrow interval for a clock with the opposite offset. Consequently its
interval has a nonempty intersection with the active wide interval
but excludes the actual active offset. Testing consistency alone does
not find the error. The collector retains both packets for audit.

Inside the actuator decision transaction the valid comparison selects
echo payloads typed by the actually active era. Without a verified
cross-era clock bridge, an old echo cannot tighten the bound on the
current actuator. A comparison that erases that index authorizes the
wrong closure in half the matched worlds and misses timely work in
the other half. The latter may wait more, but waiting does not make
the old calibration about the current clock. When the old result is
excluded the wide active record still yields safe egress, exact dock
recovery and independent maintenance, although half the timed
closure jobs are missed. The matched arm with a genuinely new
active short echo completes all 48 full bundles. Both arms use the
same packet budget, so the effect of usable clock authority has not
been confounded with merely receiving more bytes.

The clock phases, authorized transition and actual effect owner are
part of the simulated source. The positive route assumes static
registered sender identities and truthful epoch labeling, not
cryptographic frame authentication or physical restart qualification.
The gate/dock process exits and native packet carrier execute source
code, but the oscillator model is authored. A real certified
cross-era bridge could retain some historical evidence; none is
assumed here. This is an authority/evidence handoff fixture, not
independent mission, R5 closure, or a gate hardware proposal.
