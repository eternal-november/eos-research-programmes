# Two qualified source paths, one immutable closure duty

Civilian held-in replay on the same native geometry and radio assets
(Space 666 under `up`). The pinned smaller `parent` files are included.
Use Python 3 with NumPy/NetworkX, C++17, Git and SQLite.

```sh
bash replay.sh up parent | cmp - EXPECTED.jsonl
```

Sensor, outage and repair clocks are supplied model inputs. No field
claim, fresh held-out test, or defense against forged sources is made.
