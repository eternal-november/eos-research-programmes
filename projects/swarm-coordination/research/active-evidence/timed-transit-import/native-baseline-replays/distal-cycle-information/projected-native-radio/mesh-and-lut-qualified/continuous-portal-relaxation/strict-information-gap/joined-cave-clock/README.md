# One-clock cave inspection, crash, exact receipt and egress

This is a held-in civilian simulation, not independent I2 acceptance.
Relocated replay requires the exact assets under `up` from PR 872
(Space checkpoint 666), the small `parent` directory from the associated
Space supplement (or fetched as pinned in `PARENT_INPUTS.tsv`), Python
3 with NumPy, SQLite and NetworkX, Git, and a C++17 compiler.

```sh
bash replay.sh up parent | cmp - EXPECTED.json
```

The role swap, its authorization, and the shared surviving journal are
explicit test provisions. Both docks are static. The two audit samples
are separately owed with separate immutable records, but share courier
radio capacity; they are not a second motion mission. Replay cuts are
measured in simulation time, not CPU or physical sensor wall time.
