\title{Cave contact support and collision clearance are distinct source predicates}
\maketitle

\paragraph{Pinned inputs.}
The two placed instances are Cave01 tiles 13 and 42 in SubT
commit \texttt{083c6a8}. The snapshot uses OpenRobotics
\href{https://fuel.gazebosim.org/1.0/OpenRobotics/models/Cave\%20Straight\%2005\%20Type\%20B}{Cave Straight 05 Type B}
version 6 and its
\href{https://fuel.gazebosim.org/1.0/OpenRobotics/models/Cave\%20Straight\%2005\%20Lights\%20Type\%20B}{Lights wrapper}
version 8. The wrapper declares a nested unversioned basic
model; that model is explicitly taken at version 6 here.
Exact file digests are supplied. These model files are by
OpenRobotics under CC BY 4.0. Neither the world include
nor the wrapper version independently identifies a historical
Fuel cache or simulator collision-engine import.
The collision DAE contains three identity-transformed
Z-up parts with centimeter units, and both world placements
are applied from the pinned SDF. This is only a check against
the two specified meshes, not other collision sources of the world.

\paragraph{Geometry result.}
The modeled ground-size probe tube about the nominal center
line contains a nondegenerate triangle vertex from tile 13
at about \((99.69847,59.78485,0.77981)\).
Thus the earlier authored clear ground tube does not
transport to this asset pair. However, an elevated axis at
\(x=100,z=8\), between the two sampled centers, admits the
selected swept box \(x\in[99.7,100.3]\),
\(y\in[49.6,75.4]\), \(z\in[7.7,8.3]\).
For each of 27,224 triangles, the verifier uses an integer
separating-plane certificate on exact decimal input.
The second pose's printed yaw is compared to half a turn,
and the certified box is inflated by 0.1 mm in each coordinate
to dominate the coordinate error of the angular approximation.
A separate narrow beam tube from the previous read station
to an authored side-of-path optical target also has strictly
positive certified separation. The listed conservative bounds
for the inflated body and beam boxes are 0.16814 and 0.33946 m,
with values rounded for reporting. The output gives a geometric
option for an already positioned small elevated body, not
ground robot clearance, a path up to the elevated start,
neighboring-tile clearance, real image production, or a
dynamically executed flight. The target panel and closed gate
are development additions rather than observations of this map.

\paragraph{Radio result on the actual lookup data.}
The same SubT revision stores Cave01's native binary spatial
lookup, with Git blob \texttt{5d53ca3aefec299168a1b49f6d2900bf51b42774}.
Execute the pinned loader for its 1,533,365 declared records;
a strict independent parser checks the sampled mappings.
The file has 18 additional complete-record lengths past
the header count, which the pinned loader ignores. The
transformed collision geometry is not the lookup.
The sample at the proposed read site \((100,58,z)\) remains
in tile 13 for the queried altitudes. In the selected
3,146-position box the native broker delivers the addressed
installer-to-courier bit in the deterministic no-fade 72 m
fixture, including ground positions without any certified body
clearance. The original old report is separately accepted.
Actual selected registration at \(z=8\) at either relay site
also opens its branch's named new report; at the near site it
loses the old route after registration, so the ordering
requirement remains. No extra endpoint capacity, clock bound,
drop-to-static operation or physical relay placement is inferred.
The fixture uses a projected weighted visibility graph for the
named labels and actual native spatial data (not whole-world physics).

These checks replace two separate assumptions: local clear
space where there is a certificate, and receiver path where
there is a pinned communication result. They do not turn a
representative radio success into a physical-in-the-world reachability
or safety result. The old motion timing comparison still requires
the physical capability bounds, actual detection and receiver
phase budget. No independent full mission or new established
baselines have been evaluated.
