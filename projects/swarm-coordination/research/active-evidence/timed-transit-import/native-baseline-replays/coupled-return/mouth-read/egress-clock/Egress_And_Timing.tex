\title{Delivering the report is not enough: a geometry-backed timed egress comparison}
\maketitle

\paragraph{Mission and admissible history.}
Use the pinned Cave01 source and actual binary radio lookup
previously tested in \#786--787. A fixed old report must be
received and acknowledged before the installer is allowed
to activate its relay. The installer and courier must both
return to their separate staging points. The courier has to
deliver a new report by 35 seconds and get a positive reply
before egress; both actors must be staged by 200 seconds.
They start already positioned at designated elevated poses.
The two authored gate schedules are fixed and exclusive:
the \(13\)--\(42\) mouth or the \(2\)--\(3\) mouth contains
a specified solid panel. The targeted observation sees the
former panel or a farther positive marker; inference about
the second panel requires exclusivity. No later geometry
change, moving obstacle, or physics-driven dropout is assumed.
There may instead be one additional omitted submission to the
simulated broker: either the first branch bit or the first new
report. This is absence before enqueue, not lost acknowledgement
after possible delivery, and the actual source is exercised at
the next allotted retry. Neither a dropped bit nor an attempted
new send establishes any settlement.

\paragraph{Geometry and time law.}
A route library was discovered on an authored rectilinear
lattice and every selected swept box was verified on the
original decimal triangles of 13 placed tiles
(233,868 triangles, plus four solid staging fences).
Use the pinned asset snapshot of the \#786--787 straight,
corner and tee pieces, also OpenRobotics Cave Corner 02
Type B v7 with Lights v8, Straight 02 Type B v6 with Lights
v8, Straight 03 Type B v6, and Starting Area Type B v9.
All Fuel assets are OpenRobotics, CC BY 4.0;
\href{https://fuel.gazebosim.org/1.0/OpenRobotics/models}{source collection}.
Meshes use the declared scales. The staging mesh's link
rotation and fence link offsets are applied rather than
deduced from visual appearance. The scene is the named
subset, not every object in the Cave01 world, and
unversioned historical wrapper caches are not inferred.

Exact integer separation checks each triangle against each
inflated swept box: axis bounds first, other separating
directions checked with integer coefficients where needed.
Printed rotations are replaced by cardinal angles inside a
0.5 mm allowance; the resulting box stays strictly separated.
The proposed probe, two first routes, egress routes,
parked-body exclusions, elevated resident relay and beam
boxes are checked. The marker, gates and relay mounting
arrangement are authored experimental additions. This is a
triangle/box geometric proof for the selected input,
not a safe flight, full imported scene, or calibration guarantee.

Each actor follows rectilinear legs with rest at every
corner, the stated scalar bounds \(a=1,V=3\), and a small
body covered by the boxes. The installer first performs the
common-prefix \(d=8,v=2\) probe of \#785 in an elevated
tube, returns past the same start position, stops and departs
at \(14\) seconds. The raw observation, processing times,
source delivery clocks, controlled stops and bounded motion
law are model inputs, not measured simulator scheduling.
For actor separation the verifier rejects overlap of whole
spatial leg boxes at concurrent time intervals. This is
sufficient, stronger than clearance of exact moving centers.
The chosen near and far schedules have strictly positive
time gap even between spatially intersecting boxes.

\paragraph{Actual selected radio events on that clock.}
At zero the earlier source report arrives at the base.
A separate addressed base reply reaches the installer.
In the authored gate scene the selected branch signal is
decoded from a positive range reading, before offering it
to the pinned SubT broker. The actual binary lookup and
selected graph costs, 72 m no-fade RF configuration and
receiving callbacks run in each arm on the common nominal
clock. The courier selects an approach using the received
bit, not a private fixture copy of which gate was closed.
It moves at 5 seconds on this envelope; the retry of an
omitted cue is also decoded before this choice.
Use the actual near registration at the already mounted
relay position only in the near branch and only after the old
receipt. The new report and addressed acknowledgement both
execute, with room for the modeled omission and retry.
The radio uses the pinned static lookup and does not infer
extra physical RF shadow from the authored panel. The same
new-report bit is not assumed safe across changed sender
identity, late queue readiness, or unbounded retry latency.

\paragraph{Results and comparator.}
The far branch uses no relay and reaches the reported/egress
cuts by 32.287 and 188.646 seconds, respectively. The near
branch uses the one retained relay, reports by 16.834,
and stages by 164.637. The installer reaches its separately
reserved staging pose by 152.986 in both. A signal late
enough to cross the branch cutoff cannot be folded into
these outputs without another temporal test.

Compare fixed-first policies in the same explicit path
library, allowing all macro reversals supplied by that
library. Give the blind baselines zero packet and queue
delay, immediate departure and no inter-actor collision
delays. Starting far still sends in either gate state, but
in the near world the short exit is blocked. Its best
listed detour, including the alternative of retracing the
first path and using the near exit, takes over 205.409
seconds even under those relaxations. Starting near takes
over 205.812 in the far world; the near exit is blocked and
the first path must be retraced. Both inequalities follow
from the rest-at-turn durations of the named legs. This is
a strictly conditional route-library distinction about
delivery plus egress. It does not exclude shorter unknown
paths or stopping partway with new early sensing, and is
not a claim that a different communication algorithm
cannot realize these same schedules.

It is consequently stronger than a report-only replay
while remaining a development test. The offsets and gate
conditions were not independently selected, the full
physics/transport timeline was not executed, and no
independent mission or contract I2 acceptance is asserted.
