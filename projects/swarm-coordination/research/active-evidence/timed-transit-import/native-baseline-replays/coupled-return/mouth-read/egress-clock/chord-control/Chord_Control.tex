\title{Verified ordinary chord shortcuts remove the broad staged-route advantage}
\maketitle

\paragraph{Changed control surface.}
Keep the \#788 source snapshot, collider bounds, gate panels,
original concrete approach paths, reports, and actor separation
law. Within each egress path's existing waypoint sequence,
consider earlier-to-later straight chords. For a candidate
chord, its axis-aligned fully swept box provides a sufficient
certificate against all selected triangle and fence inputs and
the relevant authored gate. This overapproximates true diagonal
sweep, so a rejected chord need not be physically impossible.
The proof accepts only fixed selected paths with exact integer
certificate checks. Path discovery enumerates the acyclic graph
of forward waypoint skips with time weights. Both the comparison
and directed policy may use this upgraded repertoire; there is
no claim of unrestricted optimality.

For a chord of Euclidean length \(\ell\), each actor again has
scalar acceleration at most \(1\), speed at most \(3\), and rest
at bends; time is \(2\sqrt{\ell}\) for \(\ell\le9\) and
\(\ell/3+3\) otherwise. Chord motion does not gain any higher
axis velocity or parallel-clock artifact. The actual motion
scheduling exclusion uses both actors' swept boxes and keeps
strict time separation. It is not a full simulator integration.

\paragraph{Stronger ordinary positive policy.}
Commit to the far first approach at time zero in both worlds.
The courier does not use the gate bit for that choice. It does
still learn the gate before egress, and branches for the
return path. Replay the actual pinned broker, lookup, gate
observation and positive new-report reply with the same
conducted fault arms as in \#788. Because the courier is now
moving at the time of the cue, the native replay uses its
position on the first far-approach leg at that dispatch cut.
No relay is installed in either world. The earlier report and
addressed reply are preserved; the new report and reply occur
before 35 seconds in every tested omission arm. The two staged
egresses complete by about 167.126 and 190.293 seconds.
Thus this competitor meets the original 200-second envelope
and uses no relay, with equal sensing access for the later
return choice. A claim that early addressed branch choice is
necessary for the original envelope does not survive this
ordinary comparator.

\paragraph{A narrower scoped distinction, not closure.}
With these egress shortcuts for both policies, the recorded
directed-first schedules finish the two branches by
approximately 167.126 and 124.535 seconds. In the same explicit
first-approach macro library, grant a fixed-first competitor
instantaneous communication and no inter-actor waiting.
Even allowing the specified retrace-and-rejoin alternatives,
its adverse-world durations are about 167.892
(fixed near first) and 172.609 (fixed far first).
This leaves a small conditional gap at 167.5 seconds.
It is a diagnostic, not a validated engineering limit: shortcut
selection over the original approach, curved dynamics,
replanning before the endpoint, broader route control,
and timing/clearance disturbance can all alter it.
The original independent I2 and whole-programme completion
remain open.
