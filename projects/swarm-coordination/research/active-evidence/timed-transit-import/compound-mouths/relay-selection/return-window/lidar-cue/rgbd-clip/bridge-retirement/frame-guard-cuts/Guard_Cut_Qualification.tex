\title{What Does a Pair of Clip-Mode Polls Establish About an Earlier Frame?}

\paragraph{Audit.}
The query concerns the selected publisher's source-side clipping guard
at its evaluation for a named frame. It is not camera geometry,
horizon-wide safety, duration spent in a mode, or reading availability
by a robot's movement deadline. The source law is one valid publisher
and one matching remote depth bridge, with no local competing reader,
serial completed callback cuts, and no publisher reset. Add and named
end can change the bit in either direction, whereas the selected
process-only expiry may stutter; the new token, sampling cuts and
maximum number of flips are proposed instrumentation and assumptions.
Named frame identity, configuration, clock alignment and no-reset
provenance are separate from the token.

\paragraph{Indistinguishable polls.}
An initially absent bridge can stay absent through a frame or register
before the frame and complete a named end afterward. Both polls then
see no native connection; the frame can respectively export a supplied
far return or clip it. Scope of the outside reader: poll endpoints
and trusted bounds on what fits between; it does not read the hidden
callback or renderer outcomes. A positive reading on a different frame
does not alter this counterexample. In the unchanged native observer,
if every such event path is possible, two polls do not certify that the
frame used the endpoint's clip policy.

\paragraph{Sharp bounded certificate.}
Let the bit \(b\) be observable at each poll. At every actual guard
flip, serialize an auxiliary tag \(q\) in \(\mathbb Z_M\) with the
update. Advance \(q\) on \(1\to 0\) only. Then \(2q+b\) advances by one
in \(\mathbb Z_{2M}\) at every flip, independently of the starting
phase. Let an independently justified \(H\) bound the number of flips
between any pair of polls at issue. If \(2M>H\), their combined
residue difference identifies the exact count, so equality certifies
no flip. For minimality, consider an alternating history of length
\(H\) and its even cuts. If two of those cuts had the same tag,
their observed bit and tag at both ends would fit a stuttering history
of the same duration that starts at the same cut. Such starts and
stutters are legal in the declared class. Thus a token that only
changes on guard transitions needs at least
\(\lfloor H/2\rfloor+1\) states; the proposed token attains the bound.
The observed guard bit is not charged again. This is a lower bound for
a per-scope, stutter-invariant observer of these two snapshots, not
against an additional authenticated operation log, more poll cuts,
or an on-frame stamp. At \(2M\) flips the combined value repeats.
A silent reset can alias even sooner; a verified incarnation or
appropriate invalidation action is required separately.

This is related to the alternate-signer counting argument of
\href{https://github.com/eternal-november/eos-research-programmes/pull/388}{the
bounded custody freshness study}. It is not a new general freshness
bound. Here the anchor is a serial native point-mode guard, and the
consumer gets uncertainty on an interior evaluation, not authority
to make an irreversible custody move. An ordinary version-and-retry
discipline is the appropriate baseline (see the
\href{https://docs.kernel.org/locking/seqlock.html}{Linux sequence
counter documentation}). The half-counter is a typed optimization
for existing observable parity. It does not implement a lock, detect
an in-progress write, or remove the need to serialize writers and
supply a non-perturbing diagnostic.

\paragraph{Exact interpreter for an interior cut.}
Let \(m,n\) bound the number of available one-flip slots before and
after a named frame evaluation, with independent stutter slots.
Write \(x,z\) for the endpoint bits, \(y\) for a proposed frame bit,
and \(d\) for the combined endpoint token difference. The counts
left and right have parities \(a=x\mathbin{\mathrm{xor}}y\) and
\(c=y\mathbin{\mathrm{xor}}z\). Define
\[
u=m-((m-a)\bmod 2),\qquad v=n-((n-c)\bmod 2).
\]
If \(u<a\) or \(v<c\), there is no such path. Otherwise the sums of
feasible left/right flip counts fill the step-two interval from
\(a+c\) to \(u+v\). This follows by adding the independently
attainable intervals of integer half-counts. The cut is possible iff
\(d\) has parity \(x\mathbin{\mathrm{xor}}z\) and the interval
\([a+c,\min(H,u+v)]\) contains a number congruent to \(d\pmod{2M}\).
Membership is checked by rounding up its lower bound to that
residue. This handles wrap without treating equal endpoints as
automatic no-change. If it yields both bits the receiver cannot use
a mode-dependent interpretation from these polls. This constructive
formula assumes the stated support of flip/stutter choices, not
arbitrary coupled distributions over callback counts.

\paragraph{Replayed scope and failure path.}
The selected #740 state machine produces 4096 callback schedules with
64 distinct length-six projected guard words from zero.
The four primitives in the sweep are stutter, valid typed registration,
matched named end and selected process-only timeout. The decoder
agrees with 47,880 exact brute-force queries across short histories;
Lean independently checks the cardinality and wrap arithmetic.
No advantage over a same-information exact direct computation is
claimed. Retaining equal polling bits without a qualified version is
a negative control. A consumer that can receive a provenance-bound
bit from the actual named frame's clipping branch may avoid waiting
for a later poll, at the cost of changing that source interface. If
the later poll arrives too late for a robot's decision, a retrospectively
successful inference is not a lawful runtime observation. In the
declared evidence gap, a controller must use a rule sound under both
modes or refuse the mode-dependent continuation; this replay neither
establishes a route fallback nor demonstrates live repair, an
independent cave mission or an improvement over established control.
