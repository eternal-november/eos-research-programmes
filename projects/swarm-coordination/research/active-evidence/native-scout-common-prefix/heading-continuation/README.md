# Heading cue under a changing movement rule

An exact local position read can miss an already visible turn. Heading lets the other carrier choose the right branch in the stable program. If withdrawal is allowed after the read, the same heading is no longer enough.

- [Scope and indistinguishability argument](Heading_Continuation_Cut.tex)
- `HeadingCut.lean`: finite observation argument, Lean 4.35.0 + Mathlib.
- Materialize exact `SOURCE.tsv` paths under INPUT. Run `sh replay.sh INPUT > actual.json`, then `cmp expected.json actual.json`. Requires C++17, Git, Python 3 and NumPy.

96 native selected simulator comparisons. No field observation, forecast accuracy, or independent mission claim.
