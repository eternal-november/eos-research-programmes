\paragraph{Scope.}
Compare a separate active probe with actual early mandatory payment
under the same shared transmitter, timing and allowed resources.
Early payload availability and authority are given. This is not
the fixed late-release regime of the preceding preflight. The
first old and disjoint reports pay in every native case.

\paragraph{Native threshold.}
Let $B$ be remaining headroom after first old debit, $p$ useful
primary bytes, $q$ fallback bytes, $d$ diagnostic expenditure and
$f$ actual failed primary debit. Before expiry, the constant-cost
diagnostic family requires $B\ge d+\max(p,q)$, and productive first
requires $B\ge \max(p,f+q)$. Both depend on receipt and authorization
arriving at the stated branch cut. The healthy test world requires
primary; the other needs the physically available fallback.

At $(p,q,d)=(3,2,1)$ the pinned native physical path erasure charges
$f=3$. The required robust headroom is 4 for diagnostic first and
5 for productive first. But a missing native endpoint suppresses
the TX debit before an actual attempt; $f=0$. Productive first
then needs only 3 whereas the healthy diagnostic branch still
needs 4. The diagnostic byte can also avoid a charge at the missing
endpoint; it does not change the healthy bound here. These are
different source laws, not an advantage over a comparator given
additional registry evidence or an earlier payload release.

\paragraph{Erased observer receipt.}
In a separate control the early primary has physically settled in
one world and terminated unpaid in the other; neither gives the
remote actor a reply. Fallback can physically work in both and
exactly one actual settlement is required. Blind retry duplicates
the first, withholding misses the second. An authorized local
consumer in the fixture observes the actual synchronized terminal
callback and conditionally commits only if unpaid. The same
request pays once in both without disclosing the branch. This is
not inferred from a timeout. Pending late effects, missing contact,
authority or insufficient fallback capacity would invalidate the
conclusion. Separate negative cases are explicit simulator controls.
