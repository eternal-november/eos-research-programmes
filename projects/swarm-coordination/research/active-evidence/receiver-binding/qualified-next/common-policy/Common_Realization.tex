\paragraph{Decision and lawful inputs.}
At a single authorized actor and decision cut, each complete reachable
history $h$ has a local key $k(h)$ and a prescribed action $a(h)$.
The key includes the actual matched locally delivered receipt or its
absence by the cutoff; the operator does not see the model's binding
or RF-drop bit. For histories reachable across multiple admitted
installations, a \emph{single} deterministic local policy reproduces
the prescriptions exactly iff
\[
          k(h)=k(h')\quad\Longrightarrow\quad a(h)=a(h').
\]
Necessity is single-valuedness. For sufficiency assign the common action
on each occupied key and any permitted default on an unused key; the
Lean theorem is for an inhabited action type with a supplied default.
Availability/authority for the prescribed actions and the scope of
unmodeled keys are separate checks. This is not synthesis of a global
controller or a proof that a safe conservative action is impossible.

\paragraph{Native-derived example.}
Use the exact recorded complete histories of the charged two-due
probe fixture. All selected old deliveries actually complete.
The per-installation prescription admits the optional next action
if it actually can complete, otherwise withholds. This is a formed
requirement to reproduce full-information progress, not a rule
whose action may read held-out evaluator outcomes.

At next size two and locally complete positive RF, actual absence
requires withholding and receipt allows admitting. If drop is allowed,
same absence arises in a distinct-receiver dropped world that can
deliver, and a shared world that cannot. They each have an implementable
one-world prescription but there is no common implementation of
both from that key. The conflicting paths have different roots
and never splice edges between worlds. A good positive receipt for
another history does not solve that absence class. At next size three
and no drop, both histories withhold, so a common action exists even
without a probe distinction for that prescription. With a drop,
the corresponding successful distinct branch again shares absence with
the failing branch. This distinction separates action consistency
from identifiability of every latent fact.

\paragraph{Controls.}
A hypothetical timely qualified binding release plus receipt
distinguishes those absent histories; this control does not prove
such a source is physically available. Under the same real receipt
law a conservative rule authorizes only when all compatible
worlds pay; this is a common inference rule but does not necessarily
reproduce full-information useful work. Its refusals keep the
old obligation clear but do not themselves complete the optional one.
Probability- or cost-dependent alternatives are separate doctrines.
The pinned local bucket checker agrees with direct truth-table
enumeration on the selected fixture and 256 exact key/action tables.
No independent selection, new authority, or end-to-end implementation
advantage follows.
