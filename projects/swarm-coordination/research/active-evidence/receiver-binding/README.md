# Actively distinguish a shared receiver while carrying an old duty

Actual native charged probes, a fixed two-binding uncertainty,
and direct same-information adaptive enumeration. The positive
example uses an already available lower-ceiling transmitter,
not unseen information about the receiver or a weaker comparator.

Place the exact paths in SOURCE.tsv in the upstream directory just as
in the earlier projected-dispatch replay. Requires Python 3 and C++17:

    sh replay.sh /path/to/upstream | cmp results.json -

ProbeCost.lean is checked with Lean 4.35 and Mathlib. This executes a
headless simulated broker fixture, not a live network.

[Qualified next-service update](qualified-next/README.md): actual probe receipt can identify a separated receiver while spending the very credit that a larger next duty needs. The pinned checker keeps compatible whole histories.

[Risk-limited acquisition](risk-choice/README.md): for the same native receipt effects, a whole-plan cap and an observation-conditional cap select different exact probe fractions. Stipulated fixed laws, not probabilities measured from the simulator.

[Runtime observation fibers](observation-fibers/README.md) separates a fixed installed binding from the realized probe effect. A qualified negative can permit the next send that a positive disproves even under one law. Lost status and failed physical reception are distinct. Exact direct conditional checking ties.
