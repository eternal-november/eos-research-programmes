\title{A truthful formation bit can be lost before it reaches the radio}
\maketitle

\paragraph{Operands and tested boundary.}
In the preceding formation model, a stationary capture must produce
one bit before a braking deadline. An older two-byte radio report
retains its deadline and receive debit. Add an independent obligation:
emit the ordinary depth image for this capture, retaining its valid
near pixel. Test the actual depth publish branch, point masking and
packing, and selected transport membership and broker receive paths.
The old image obligation ends at the source publish call in the
fixture; it is not a guarantee of delivery to a named ROS peer.
The radio obligation, separately, reaches its actual selected
application callback. All decisions and that old radio obligation
are on the same declared chronology.

The two worlds supply a common near pixel at 5 and a target pixel
at 7 or 8 for the near site, or 37 or 38 for the far site.
These are injected post-texture samples, modeling two known
witnesses, not measurements of a rendered cave. The sensor pin
requests rendering far plane 300 and software depth clamp 10 for
the configured camera. A corresponding separately pinned
ignition-rendering3 Ogre2 reference provides the selected
\texttt{PostRender} body. It builds the depth callback's $x$
from the same texture copy that supplies point $x,y,z$ and runs
both sensor callback bodies. The GPU copy is a fixture from an
authored buffer. The shader and upstream integration test are
inspected, not executed. This neither pins a particular installed
CoSTAR image nor supplies the physical target, geometry, GPU,
or transport schedule.

\paragraph{Incompatible outputs under the stock path.}
With a matching depth subscription at the native depth stage,
the far pixel is clipped to positive infinity. The old image
emits with pixels $(5,+\infty)$, and the stock point message
sets all three selected coordinates of the far pixel to infinity.
The near pixel remains valid in both streams. Consequently
the far-world class cannot be inferred from either delivered
stock view, irrespective of spare radio capacity. The two
physical branches in the declared model are not both realizable
with that common view and no other timely evidence.

A matching named end before the depth stage leaves the finite
point values, but no ordinary depth image is emitted at that
cut. Ending the subscription between depth emission and point
packing also does not help: membership can be absent at pack
while the previous in-place mutation still masks the point.
For the same selected traces, process timeout or BYE alone
does not remove that native membership, and a new matching
registration keeps the old mode-dependent behavior even if the
old membership is removed. These are serialized source events
around one frame; no notification, peer crash or concurrent
wire performance guarantee is implied.

\paragraph{Authored qualified source read.}
With permission, an extra producer-local read of that pixel's
raw value after its native copy and before the depth mutation
classifies the witness. The proposal retains one bit for this
fixed named capture until the deadline, and preserves the
ordinary image and point output byte values tested. It sends
the same one-byte cue through the same receiving budget, with
the same producer/capture binding assumed in the earlier study.
This adds source access, classification and qualified retention.
No privacy, codec, storage-availability or CPU latency claim
is made. A direct raw-hook implementation can do the same.
No ordinary stock point consumer with only the shown outputs
has that distinguishing input.

The producer must preserve the capture reference as well as
the raw bit. A second supplied view at time $.55$ maps the
same pixel to a different witness after the stationary capture;
the actual selected renderer/callback sequence overwrites the
raw buffer. A latest-only tap now carries the wrong bit for
the original task if radio contention defers its send past
that view. It would select a branch failing the actual
terminal requirement even if that report reaches the receiver
before the physical decision cut. This is a changed pixel
referent, not a world change or a claim of measured reprojection.

\paragraph{Joint service and remaining assumptions.}
The native driver supplies 60 first frames and 60 follow-up
views, crosses five membership modes and three source event
positions. The joined replay checks 1,080 radio cases under
the old obligation, 608 timely correct cues and 90 timely
wrong latest-only bits. On the tested cases, raw retention
allows far-site success with retained image emission whenever
the earlier receive resource bounds admit the cue. It cannot
make a genuinely late packet actionable. Four rational motion
paths are checked at all relevant extrema. An exact direct
calendar agrees, and the stronger direct raw-source arm ties.
Actual scene correspondence and reliable, lawful capture
binding, read/processing latency and transport of old imagery
remain separate obligations. No independent mission or full
architecture/contract acceptance follows.
