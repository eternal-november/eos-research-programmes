# Qualified local RGB when the new RF cue cannot arrive

[Local_Optical_Cue.tex](Local_Optical_Cue.tex) joins actual native warehouse
dispatch, rendered controlled sign materials, selected stock RGB/depth
processing, broker receipt and the modeled physical deadline. The qualified
RGB image can carry a bit even when XYZ is nonfinite; it cannot confer a
pose or a clearance guarantee. A physical visibility loss still matters.

Run from the parent raster-validation root using the inherited source
manifests; stage this directory as optical/. Use optical/run-optical.sh
after materializing INPUTS.tsv and the parent's inherited inputs.
The Space backup contains the exact prior ZIP and the warehouse inputs.
The SDF/formation correspondence and the modeled timing are declared.
