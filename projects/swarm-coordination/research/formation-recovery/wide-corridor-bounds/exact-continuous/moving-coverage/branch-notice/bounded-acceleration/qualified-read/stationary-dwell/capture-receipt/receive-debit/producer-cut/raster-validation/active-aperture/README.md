# An acquisition aperture with a charged camera move

[Visible_Aperture.tex](Visible_Aperture.tex) derives the fixed-ray interval,
travel budget and pose error limit for the same rendered covered scene. The
slower modeled slider cannot reveal either world; the faster one can retain
both old outputs and provide the useful bit when the native receive window
admits it.

Run the parent run.sh with pinned inputs to build the two source drivers.
Stage aperture.py at the parent validation root, run it there, and compare
stdout with aperture.json. The Space archive includes the exact parent.
This is authored diagnostic geometry and a modeled independent actuator.
