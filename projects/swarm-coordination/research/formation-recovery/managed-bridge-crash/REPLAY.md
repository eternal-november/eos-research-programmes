# Planned bridge activation and an abrupt stop

[Statement and scope](Managed_And_Crash.tex). Cut-derived stress test of the original default point-mass formations from the pinned KTH-DHSG/constrained_omrs companion source. Authored counterfactual abrupt loss and a separate exact speed-only geometry, not full Gazebo, a field result or an independent mission.

Reproduce with Python 3 and NumPy: **PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python3 -B audit.py**. The upstream repository is pinned in UPSTREAM.txt. Copy the exact paths in PINNED.tsv or use the full source archive in Space. Run the original source without replacing its dynamics. Numerical outputs use floating point and are not platform-independent last-digit claims. Original source license included in the archive.

The [qualification-window study](qualification-window/) checks the actual
published bridge/departure overlap and a separate acceleration-limited
example where good geometry does not guarantee enough time for a handshake.

The [warm-start recovery study](warm-start-recovery/) uses the actual
velocities at the four request cuts under declared acceleration limits.

The [local-sensing deadline study](local-sensing-deadline/) keeps the
warm planar fault cut and tests an authored hidden remote offset.
