# Cohort randomization after an erased braking report

A robust binary decoder with one shared seed is not equivalent to independently randomized groups. The no-report stopping obstruction makes group agreement necessary, and the optimal guarantee degrades with the number of separate seeds.

[Exact proof](Randomness_Across_Braking_Crews.tex) · [Rational replay](replay.py) · [Recorded results](results.json)

Run python3 replay.py and compare its output to results.json. The erased information history is identical and leaves no other coordination channel.
