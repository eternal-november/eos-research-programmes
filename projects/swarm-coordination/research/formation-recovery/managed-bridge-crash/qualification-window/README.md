# Connectivity is not a qualified handoff

[Source comparison, proof and scope](Qualification_Window.tex).
The pinned KTH managed-removal replay has one time unit when the retiring
edges and the activated bridges coexist. A new acceleration-limited
track example shows why meeting the geometric constraints throughout
can still be insufficient for even a short handshake.

Materialize the hashes in `PINNED.tsv` from the repository and revision
named in `UPSTREAM.txt`. Use Python 3.10+, NumPy and SciPy:

    set -o pipefail
    sh replay.sh /path/to/pinned-source-root | cmp expected.json -

`Dwell.lean` checks the exact braking arithmetic. The recorded source
overlap is a conservative floating-point chord check on the published
point-mass simulator, not a radio measurement or crash-controller replay.
