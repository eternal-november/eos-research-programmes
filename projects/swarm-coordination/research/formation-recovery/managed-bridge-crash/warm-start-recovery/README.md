# Bounded recovery at the original warm crash cuts

[Construction, unconditional lower bound and scope](Warm_Start.tex).
The actual velocities at all four pinned managed-departure request cuts
are retained. A separate bounded post-crash controller brakes, then
moves the two surviving components to a new bridge at rest. Its
continuous check retains original internal edges and avoids the failed
body. A directional reachability bound supplies matched infeasible
deadlines without appealing to any particular controller.

Materialize the hashes in `PINNED.tsv` from `UPSTREAM.txt`.
Use Python 3.10+, NumPy and SciPy:

    set -o pipefail
    sh replay.sh /path/to/pinned-source-root | cmp expected.json -

The post-crash limits and optional receipt duration are specified by the
experiment, not measured or attributed to the source controller. The
source-state extraction is numerical; the proofs and reproduced
finite bracket do not implement an independent mission.
