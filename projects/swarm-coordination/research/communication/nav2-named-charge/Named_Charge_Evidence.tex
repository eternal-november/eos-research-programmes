\paragraph{Source and consumer.}
The source is the \href{https://github.com/ros-navigation/navigation2/tree/346bd05f40b62ae60b96ba86e02eb491c8dba444/nav2_docking}{pinned Nav2 docking framework}. The proposed downstream consumer settles a job only when its robot is receiving power at a named station at the decision cut. This is a stronger task than the \texttt{DockRobot} action's result. Nothing here suggests the source claims to settle that stronger task. The \href{https://api.nav2.org/nav2-rolling/html/md_nav2_docking_README.html}{framework documentation} already explains that the simple plugin can use proximity as a charging proxy. No tests were conducted on a robot, network, or running ROS stack.
\paragraph{Two further source distinctions.}
The database maps dock instances to plugin objects by type. For two distinct dock names with one configured type, the selected early-return check after goal selection reads the shared object's \texttt{isDocked} or \texttt{isCharging} before following the new approach. The expression takes no named station input. Its result can therefore carry information about the retained pose or battery state without identifying which physical dock the robot occupies. In the pose path, \texttt{isDocked} compares available current base pose with the retained dock pose. The approach's detection freshness check is a separate operation. In battery mode, the subscription stores whether the last observed current exceeds a threshold; the selected \texttt{isCharging} accessor does not itself validate a timestamp. Both charging modes are useful to their own callers. Even retaining the current request name with the result does not make it a measured name or an electrical measurement at the decision cut.
\paragraph{Exact observation judgment in the fixture.}
Two disjoint certified charging stations are modeled. No other power source is admitted, and one station at most can power the robot. A site reading can certify actual occupancy of a named station through the decision cut; a separate electrical reading can certify actual current through that same cut. Neither is assumed available in every branch. A certificate from a reading is only valid through later changes for which its maker verifies that occupancy or current did not change. The model admits cached readings and missing witnesses; observational absence is not physical absence.
\par
With only the stock result, a single observation class includes physically settled and unsettled cases for the same request. Even giving the consumer the two stock predicates and the configured mode, no positive guarantee follows just from them over this declared family. With both current witnesses, a local consumer admits exactly when the certified site equals the requested site and the electrical witness says current is present. The site witness alone leaves a charging/noncharging pair; the electrical witness alone leaves a right-site/wrong-site pair. A single trustworthy named current witness covering the same cut would suffice instead. A fresh site or electrical record factored out of an old action is not a fresh certificate unless its validity survives the source change. This is a statement about identifiability and a causal admission action, not a substitute for contact, voltage or collision guards.
\paragraph{Replay.}
Unmodified four plugin predicates, the current threshold expression and the selected early-return Boolean are compiled against a test seam. Dock type aliasing and the response schema are checked against the originating source. Pose transformation, perception, propulsion and feedback scheduling are not emulated. Over 1,440 authored combinations, the source branch passed 400 times; 224 passes lacked actual current and 88 had current at the other station. These counts are coverage of a constructed family, not failure frequencies. The typed two-witness consumer admits 72 instances. An exact direct comparison partitions the same observation vectors and checks all compatible physical states, agreeing in all 120 observation classes. It has the same evidence and authority. No superiority over that direct baseline, independent non-radio holdout, or full R1 acceptance follows.
