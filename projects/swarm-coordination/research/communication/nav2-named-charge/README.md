# Docking result versus named charging evidence

This development audit checks the selected Nav2 docking predicates and first success branch. A higher-level job that requires current at a particular station cannot use the generic result as its sole certificate. A paired fixture tests what happens when current and station identity come from different observations.

The proof and scope are in the TeX note. Put the four original files at the paths in the first column of SOURCE.tsv and run `sh replay.sh`. The script verifies the pinned Git blob hashes before extracting any method. The exact original files and license notices are included in the Space replay archive; the repository study does not need to vendor them.
