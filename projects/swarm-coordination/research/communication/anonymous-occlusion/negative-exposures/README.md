# Qualified negative camera frames across a passage

A true empty camera exposure can prohibit a hidden swap. A missing or
masked frame cannot, even when a masked frame decodes to the same all-zero
pixels as a true empty view. The exact cutoff charges time gaps, coverage,
clock linkage and bounded loss.
