# Settlement frontiers across rejoins

Run `python3 -B pilot.py --json | cmp results.json` with Python 3.12 and no optimization. See [proof and scope](Settlement_Frontiers_Across_Rejoins.tex).

For one fixed issuer with consecutive immutable IDs, an observed settled prefix and the received receipts above it exactly preserve successor admission under delayed, reordered and repeated delivery. Merge is exactly union of learned facts followed by prefix compression; it does not move a physical effect or license reordering an actual handoff.

A width cap B requires exactly B−1 further bits at the fixed worst-case frontier and issued counters. A cap of three unresolved documentary duties alone still admits 2n−2 distinguishable states with the same counters after n issues. The replay checks these counts, union/merge, and a recurring trace with physical support retained into each rejoin. An indefinitely stalled old receipt can still block new issuance. The result is conditional on the declared authority, facts and recurrence envelope, not a proof-reuse advantage or full C2 acceptance.
