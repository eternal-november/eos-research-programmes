\title{An elapsed-time receipt bound is a phase-dependent reuse budget}
\begin{document}\maketitle
\paragraph{Task and kernel.}
A scoped old physical clearance authorizes one current custody
handoff. A delayed authentic copy from an earlier handoff must
not authorize the new one. Retain the scope, recognized current
signer, shared local gate, qualifying receipt and actual
settlement as distinct events. Both endpoints advance a finite
tag policy only on the actual shared boundary advancement.
The receiver can inspect the packet's signer and tag, and
its current relative gate time, but has no independent
observation of the current clearance or trustworthy absolute
issue epoch. There is no credential forgery or source attack.
Copies can be retained up to an enforced age measured from
the original qualified emission, not from a relay's latest
republication. The model does not establish that an actual
transport enforces this age. Extra challenges, true purge, or
a newer physically qualified witness change the interface.

\paragraph{Admitted timing and phase.}
For a single edge, local activation times have gap at least
\(P>0\), with the saturated trace included. A locally known
periodic phase determines the actual authorized signer \(s_i\),
earliest acceptable singleton receipt \(F_i\), and latest
original emission \(B_i\), relative to activation \(i\).
Assume \(0\le F_i\le B_i\le P\), and that the matched proof
arms can realize the earliest current receipt and latest old
emission with saturated starts. For instance the fixture uses
a direct fresh arrival while a copy remains admissibly aged
up to \(U\) inclusive. Each phase has a configured later
acceptance deadline and a positive branch with a qualified
receipt before that deadline. A further finite transfer-and-
fence time must still fit the pipeline's budget \(g\); this
is a separate premise. The finite comparisons use integer
slots and same-phase interval supports. For necessity the
negative branch may withhold the current clearance entirely
and deliver a single old duplicate, so waiting after observing
it cannot reveal a second distinguishing event by the due cut.
The positive service theorem only covers those histories
with the stipulated live evidence and bounded settlement.

\paragraph{Sharp edge relation.}
For \(i<j\), read the signer as part of the observable
wire type. A tag equality matters exactly when the signers
agree and the age budget can reach the new observation.
The necessary and under the admitted matched extremes
sufficient inequality is
\[
       (j-i)P+F_j\le B_i+U .
\]
Indeed the left minus the old emission bound is the least
possible age at the current earliest qualifying receipt.
The saturated trace with old emission at \(B_i\) and
current decision at \(F_j\) attains it. With exclusive
expiry, replace the inequality by a strict one. One old
retained copy is sufficient for any separating test; no
arbitrary accumulated queue or armed behavior is assumed.
Any earlier latest emission, later earliest accepted arrival, or
longer activation separation can only make this specific
collision harder. Correlation that forbids the extrema
can invalidate sharpness; any actual shorter gap can
invalidate soundness.

\paragraph{Exact finite tags, including nonuniform phases.}
For each signer separately, put interval start \(iP+F_i\)
and expiry \(iP+B_i+U\) on the proof-side axis. Starts
are ordered by use; in the exact fixture phase and age
cuts are part of the admitted clock law. An earlier same-
signer interval conflicts with the current one exactly
if it still covers the current start (up to the chosen
equality convention). Any two currently conflicting
earlier intervals already conflict with one another.
Therefore a fixed palette needs at least one plus the
maximum number of still-live earlier intervals of the
current signer. Greedy allocation using an absent color
achieves this bound, and is locally implementable from
finite phase and at most the last
\(\max(0,\lfloor(U+\max B-\min F)/P\rfloor)\) entries.
The positive bound needs only this conservative index
window; eligibility within it tests the directional
phase law. Zero-error alternate schedules of tags cannot
evade the clique: along a clean saturated execution one
pair in any undercolored clique shares a tag, and its
late-copy/no-current counterpart has the same receiver
history and input. Applicability needs the matched
copy to be retainable without revealing its presence earlier.
Different signers share the same palette because the
actual signer is independently authenticated and checked.

\paragraph{Changed timing can invalidate a frozen profile.}
With \(P=4,U=6\) and alternating signers, both phases
admitting first receipt at 1 and last emission at 3
need two tags. A same-signer copy from two handoffs ago
can meet the new cut at age exactly 6. Either enforcing
strict expiry or moving the first observation from 1 to
2 makes one tag sufficient in that model. Faster evidence
can therefore require more tag memory, even with unchanged
ports and service rate. Increasing the minimum offer gap from 4 to 5 is a
separate way to remove this particular collision, at lower offered capacity.
Moreover the phased case
\((F_A,B_A)=(1,1)\), \((F_B,B_B)=(3,3)\) also needs
only one tag: both same-signer repeats are too far apart,
despite matching the first case's earliest-overall and
latest-overall bounds. The phase-qualified design permits
one commissioned two-link corridor: the first link uses
a two-value alphabet, the second has only one possible
tag value and can use two hardware-compatible modes.
Only the phased mode passes. Change its timing to the
coarse-equivalent first case and neither mode passes.
The retained port compiler is unchanged. Receipt and
transfer windows are allocated before deployment, with
independently verified local duration at most four inclusive;
the Python filter does not certify this physical premise.
An endpoint reading actual current effect or a distinct
fresh hardware latch can remove the ambiguity by adding
information, not by guessing the old age.

\paragraph{Comparison and verification.}
The older receipt-epoch result assumed age was bounded
in completed advances. This derivation supplies the
conservative conversion and exact per-phase adapter from
a different elapsed-time source. Reuse follows only if
phase selection, lower separation and retention support
hold under overlapping neighbors. Fixed ports alone
do not guarantee reliable messaging or RTC alignment.
A direct time-aware interval colorer gives the same palette.
\href{https://www.rfc-editor.org/rfc/rfc9293.html\#section-3.4.2}{TCP's sequence reuse discussion}
and \href{https://arxiv.org/abs/1011.3632}{bounded-channel stabilizing links}
offer different guard mechanisms; this is not a new
general link protocol. The replay compares 2,200 exact
arrival-support tables and finite color minima, and 2,200
steady profiles, then calls the pinned commissioning
checker for the distinguishing case. Lean checks timing
attainment and the interval ordering step. This is a
scoped extension to the constructive recurrent subclass,
not the full action-dependent synthesis result or an
independent mission test.
