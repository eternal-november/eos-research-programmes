# A receipt's elapsed age and its handoff generation are different

An exact per-phase test says when an authentic old receipt can still match
a new handoff. Earlier accepted evidence can demand a larger tag alphabet,
and two systems with the same aggregate early/late bounds can disagree.
The same fixed-port commissioning checker is reused after filtering
its menus by this finite receipt adapter.

[Proof, timers and scope](Timed_Receipt_Re-use.tex).
Put the prior pinned file from [SOURCE.tsv](SOURCE.tsv) into an input
directory as `paced.py`, then:

    sh replay.sh /path/to/inputs | cmp expected.json -

`TimedReceipt.lean` checks the timing witnesses and ordering implication,
not actual delivery or actuation. No full moonshot or independent result.
