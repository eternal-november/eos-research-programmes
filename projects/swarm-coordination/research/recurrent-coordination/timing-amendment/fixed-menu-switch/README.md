# Custody proof reuse across a mid-run amendment

The existing #390 and #391 rules are exact when held fixed. This study keeps both complete fixed-law languages equal and exhibits the shortest two-transfer word that separates histories once a lawful switch is added. It gives the exact prefix test for a known switch calendar, and a minimal evidence distinction for the example.

Run `python -B replay.py | diff -u replay.txt -` with the original #390 `port-expiry/model.py` copied as `port_source.py`. The replay checks the original Git blob ID. The exact source is included in the Space proof archive. Three small Lean checks were tested with Lean 4.35.0 and Mathlib.
