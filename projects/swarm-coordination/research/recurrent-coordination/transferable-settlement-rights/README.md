# Transferable issue rights across settlement rejoins

A shared issue cap at the allocator need not bound what separated replicas learn when they rejoin. Per-right history and cumulative per-issuer evidence repair two distinct failures while retaining all disclosed settlement identities.

Read Transferable_Settlement_Rights.tex for the proof, interface and direct comparison. Run python3 -B replay.py and compare standard output byte for byte with results.json. Run sha256sum -c SHA256SUMS to verify the delivered files.

The model assumes trusted single-spender ownership, stable issuer IDs and authentic settlement only on physical acceptance. One missing first receipt can block every right despite free supports. This is a finite civil warehouse check with a parametric width proof, not field validation or full contract acceptance.
