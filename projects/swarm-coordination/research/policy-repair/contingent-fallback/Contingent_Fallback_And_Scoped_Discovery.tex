Two admitted inspection continuations still require a fallback at the
same future cut. Meanwhile, an old unrelated operation has actually
occupied a helper, and another job could use one specific helper while
recovery runs. The first live repair may replace the source of the next
fallback with a newly mated relay. A command, a preparation message and
a completed mate are three different events. Commit needs two continuous
supported physical ticks; a failed attempt leaves the original source
in place. Even a successful commit does not discharge earlier effects
already in flight. Timings, feed behavior and trust in local source
hardware are stipulated source laws in this fixture.

\paragraph{Which extra work can be admitted?}
Each future observation class at the fallback cut gives an eligibility
set for every still-needed job in each possible actual history. An
edge represents an available helper, actual effect-side readiness, and
authority to use it. Physically held earlier effects and a proposed
noninterruptible job are removed prior to choosing. One dispatcher is
lawfully able to choose the matching for both fallback jobs once the
declared observations arrive. This is an explicit policy class; it is
not distributed matching with independent authority.

An extra job is safe exactly when, for every reachable future
observation class, the graph obtained by intersecting legal edges
over its source histories still has a matching for all fallback jobs.
Such a matching gives a causal dispatcher: select its class only
when the actual observations arrive. Conversely the same local
view in the class forces one assignment, and each of its edges has
to work on every admitted history. Future knowledge can be used only
if the earlier decision proves it will be available in time in the
admitted family. If a late second fault still may remove a needed
helper in that family, it must be retained even when the first mate
is already certified.

For a single helper's release, compute one complete matching in each
class and start at its unmatched helpers. Reach a currently matched
helper by using an edge from a reachable helper to the latter's
assigned job. Switching along such a path moves the vacant slot,
so every reachable helper can be excluded from a matching. Conversely
the symmetric difference with a complete matching that excludes a
given helper contains an alternating path from an initially unmatched
helper to it, unless it was already unmatched. Intersect the safe
sets across classes, and separately check the optional job's physical
eligibility. This is ordinary alternating matching. After a matching,
one linear edge scan per class gives all single exclusions; finding the
matching and assembling actual legal-class edges are separate costs.
A strongest fixed-resource matching reference can use the same scan.

\paragraph{Actual effects and a changed receiver dependency.}
In the authored source, mounting the new relay moves the physical
shared fallback supplier from helper 2 to helper 4. Two authored readout adapters over the same dwell witness
can emit the same correctly interpreted
mate/decline observation. A slower measured result that reaches the
same next cut still works; a result reaching after the cut, or an
on-time update request with no actual receipt, does not. A reader
checking a fast response but accepting a queued command as the
corresponding physical completion would be taking an unsupported
replacement. A further loss of the new helper 4 invalidates the
optional job's release even with timely knowledge. In the joined
test that loss may still be admitted at launch, so a good earlier
receipt alone cannot authorize the extra work.

The integrated replay actually schedules the promised earlier work
on held resources, the fallback pair, and the additional job on
helper 0. It counts completion at the ends of physical occupancy,
not at admission. With timely and legally sufficient source knowledge
four obligations complete. With a late receipt or admitted late
second loss, the preinstalled safe fallback protects three and
refuses the extra job. It does not halt unaffected existing work.
There is also a separate certification deadline at the real optional
launch (tick two). If proof checking has not returned then, the
installed fallback still completes the three obligations. Later
computation cannot be credited with an optional effect that had to
start earlier. Certification-finish time is a supplied simulation
event, not a measured solver runtime. A cached direct witness with
the same evidence and valid scope matches that control.
In a separate calibration, a timely failure signal means silence
is enough logically to infer physical success in the other branch.
The new relay is still unusable if the role law requires a current
visible grant and that grant did not arrive. Physical prediction,
authority and holding a real available slot are distinct checks.

\paragraph{Discovery of changed dependencies.}
The plant emits a source mutation on the actual commit, not on
preparation. Each role has its current physical read and a collection
of old outstanding source claims that retain their own tokens. The
index counts role/source edges with multiplicity. Adding a current
source only inserts its edge, since the earlier edge now denotes
a retained claim, and a physically verified retirement removes only
the named predecessor. Returning to a previous source before its
old tail retires cannot make the later retirement delete the new
current edge. A full effect-ledger scan is the direct functional
reference, not the only efficient baseline.

An accepted local query needs both a source-issued, helper-specific
scope certificate and its complete epoch prefix. The certificate
states that no new committed dependency can join the indicated
helper during this future interval. The plant actually enforces
the local fence at the effect, and conservative retirement of tracked
responsibilities may be deferred. The index neither invents the
current watermark from silence nor reads the evaluator's truth.
If a relevant record is missing, the new work is withheld. A
separate valid source is unaffected, and actual movement onto it can
continue. The fence is not free: the fence control
delays the next mount on that helper for two ticks. External physical
failures are not prevented and must still enter the feasible edges.
An accepted footprint certifies a registered conservative set, not
universal free physical capacity.

In the declared complete notification model, each actual commit or
retirement produces one delivered reverse-index edit. Return all
affected registered roles in time proportional to the output after
a scoped epoch and lease check (assuming ordinary indexed lookups).
This bound counts primitive source monitoring, validation and fence
checking separately, and does not bound unmodeled network retry or
the cost of learning an unreported dependency. With a bounded number
of retained tails and buffered but not yet consumed events, memory
is proportional to those and the current roles; unbounded missing
settlement can violate that assumption. Epoch bit width also grows
with the number of distinct events unless a separate safe reclamation
protocol is supplied. A cached direct monitor with the same event
law can realize the same state and cost.

\paragraph{Evidence and disposition.}
The closest primary starting points are
\href{https://pmc.ncbi.nlm.nih.gov/articles/PMC9468080/}{LiveLTL obligation monitors},
\href{https://conf.researchr.org/details/icse-2022/icse-2022-papers/18/Dynamic-Update-for-Synthesized-GR-1-Controllers}{GR(1) bridge controllers}, and retained commit-cut dependencies in
\href{https://whoenig.github.io/publications/2019_RA-L_Hoenig.pdf}{action dependency graphs}.
Tracking prior obligations during a live transition is established;
the illustrative contribution here is obtaining scoped inputs
from actual simulated source changes and respecting their physical
cost. The pilot does not reproduce those complete implementations.
Finite replays give 24,947 exact single-release comparisons on
5,000 models, 12 resource occupancy controls, 8,000 indexed source
checks, 7,000 scope checks with explicit local refusal and 14
end-to-end cases. Four supporting kernel statements are checked in Lean.
Same-information scheduling and indexed direct mechanisms tie in
the represented envelope. This is not a proof of historical novelty,
independent field transfer, bounded universal synthesis or full R2
or I2 acceptance.
