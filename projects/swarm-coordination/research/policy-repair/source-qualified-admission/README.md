# A start-time fence only constrains failures it can prevent

An exact recovery-admission test for a simulated inspection station. Five Lean
lemmas check the arithmetic, not the source plant. The trace replay checks
649,872 parameter cells across three comparisons, including complete search
over the two actions available on each warning branch. Total combines distinct
tests, not unique physical incidents. No hardware, measured speedup, baseline
advantage over a matched planner, or contract acceptance is claimed.

Run `python3 replay.py`. Lean file checks with Mathlib in Lean 4.35.0.
