# Live latch policy synthesis

An old load keeps its support while a controller compiles a new Boolean dispatch rule. The analysis compares catalogue selection, bounded scalar replanning and validated policy installation. It charges the staging support held open during computation and preserves conservative service on timeout or invalidation.

Read [the statement and proof](Live_Latch_Policy_Synthesis.tex). Run `python3 -B replay.py | cmp results.json` (Python standard library only). The exact finite reference tests inverse responses by enumerating hidden latch vectors. The replay is not a hardware benchmark.
