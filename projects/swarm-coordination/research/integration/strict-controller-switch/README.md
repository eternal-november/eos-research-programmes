# Scope of a failed strict controller switch

[Source audit and proof boundary](Strict_Switch_And_Old_Service.tex). In the executed manager slice, strict activation failure removes the attempted replacements without restoring the earlier controller. The evaluated failure response cannot substitute for mode evidence.

Run `python3 -B replay.py | cmp replay.txt -` with Python 3 and a C++17 compiler. Supply [the manager implementation](https://github.com/ros-controls/ros2_control/blob/0c94b008a82731967ba89e2e7379ec6d2f07580b/controller_manager/src/controller_manager.cpp) and [the service definition](https://github.com/ros-controls/ros2_control/blob/0c94b008a82731967ba89e2e7379ec6d2f07580b/controller_manager_msgs/srv/SwitchController.srv) under their original basenames. Both files are Blob-ID-checked and archived with the evaluator. The physical modes in the replay are stub state, not measured hardware state.
