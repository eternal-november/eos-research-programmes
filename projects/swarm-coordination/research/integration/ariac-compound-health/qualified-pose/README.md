# Public blackout, internal camera cache, and one-use read

Run `python3 run.py && python3 guard.py`. Compiles selected exact Gazebo Classic and ARIAC paths in one deterministic C++ fixture. The Python program checks an explicitly proposed defensive service and performs real SQLite worker exits around the service commit. It does not provide any way for a mission controller to subscribe to internal or privileged state. No full Gazebo/ROS build or physical clock bound is claimed.
