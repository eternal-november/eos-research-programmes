\title{Scope admission belongs before the latest-frame reduction}
\maketitle

\paragraph{Joined interface.}
The prior service study assumed a trusted emitter for a capture
generation. This replay connects the proposed ledger adapter to
the selected native Gazebo Classic production and ARIAC public
camera wrapper, on one deterministic run per case. The evidence
adapter adds a named capture cut at the actual selected capture
call, parking episode and authorization generation. It exports
these only on a successful public wrapper publication. Captures
only visible in the scoring-side cache never become controller
inputs. The raw transport can be delivered or deferred without
changing the candidate input. The time of wrapper publication
and the earlier capture time are deliberately separate inputs in
the serial fixture, not measures of a Gazebo installation.
A single visible part prevents needing an unestablished association
or an enhanced logical-camera interface. An independently
prequalified old duty has its own retained result and slot.
The source modifications and time guarantees are not attributed
to stock ARIAC.

\paragraph{Two distinct losses.}
First, a publication made at the same late clock time can carry
either a capture before the order's lower bound or one after it.
A policy which admits by the wrapper timestamp alone would spend
the single read on the old sample in the former case. Constancy of
the epoch does not settle this problem. Second, a published frame
can be valid in its source scope yet irrelevant for the receiving
order's authority. The earlier single-frontier adapter sorts by
generation then time. An early frame for generation one, delivered
while the order still expects zero, can replace the only cache
entry, so that a later valid generation-zero frame cannot enter.
Checking the old entry on use avoids a false acceptance but cannot
recover the lost live observation.

In the new interpretation the ledger verifies the active source,
parking episode and corresponding authorization before applying
the maximum reduction, in the same transaction as storing the
qualified latest frame. The guard at consumption is still necessary
since the scope can change after arrival. If an early frame is
ineligible, the duty stays unspent; if committed under a named key,
later evidence cannot change that result. If no usable frame ever
arrives the replay reports noncompletion. The correct reference is
a per-scope ordered cache plus the same earlier idempotent duty
transaction. It agrees; the result is a preservation condition for
composing the two optimizations, not a speed claim.

\paragraph{Scope of the replay.}
There are 128 native-to-ledger histories including capture-time
aliases, differing delivery, blackout and scope, and missing
replacement. Four keep a qualified first result, 62 qualify the
later one, and 62 have no resulting authorized pose. The old duty
can always complete in this test. An observer indexing only current
scope can refuse unqualified future-epoch arrivals, as the policy
here does. An observer that promises to retain samples from scopes
not yet active needs separate bounded per-scope retention,
authorization and eviction rules; a global maximum does not suffice.
No bounded-data guarantee for an unbounded number of scopes follows.
The source adapter has additional metadata and a local transaction.
There is no new independent mission or claim of authority on
unmodified competition infrastructure.
