# A replaced schedule is not a progress receipt

[Statement and scope](Schedule_Deprecation.tex). The replay compiles selected exact Open-RMF dependency tracking and waiting code against controlled schedule and adapter state. It is not a full ROS run or a claim of a deployed failure. The source package in Space contains the pinned files. Alternatively place the exact files listed in `native_sources.tsv` beside the harness under the listed names. Python verifies every Git blob ID. Then run `sh replay.sh | cmp replay.txt -` with Python 3 and a C++17 compiler.

A monitor that saw progress before a plan was replaced and a monitor registering afterward can both report that waiting has finished, while only the former records the earlier progress. A plan-scoped wait result cannot by itself verify that a physical duty ended. The model keeps unrelated work and independent waiting conditions separate.
