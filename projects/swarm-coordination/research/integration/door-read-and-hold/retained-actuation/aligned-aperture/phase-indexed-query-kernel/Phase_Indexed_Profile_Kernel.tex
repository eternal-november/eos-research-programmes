\section*{A phase change splits an exact actuator-profile quotient}
\paragraph{Query and kernel.}
Freeze the plant, the independent leaf-issue rule, the 24-update
horizon and the 203 native-backed source profiles of PR 864. Each
profile includes the retained command depth and one permitted
pulse, or no pulse. The consumer asks whether a constant integer
cap on joint aperture deficit is met for every permitted issuance.
For a left profile $x$ and right profile $y$, let
$C(x,y)=\max_t(P_x(t)+P_y(t))$ for their two pointwise
envelopes. Define the full query set prospectively: every right
profile in the declared release band and every aperture budget,
not the one right continuation that later happens. It assumes
physically independent leaf writers known at the action cut, a
separate premise in the parent-alias study PR 865.
This quotient is scoped to the aperture test; no other consumer of
the underlying trace is intentionally merged by this result.

For a fixed allowed right menu $Y$, two left histories are
interchangeable for all these queries iff the vectors
$(C(x,y))_{y\in Y}$ are identical. Sufficiency is substitution.
For necessity, if the values on one coordinate differ, the smaller
integer value is an allowed budget that separates the two query
answers. Equality of these vectors is therefore the coarsest exact
equivalence for that fixed downstream interface. The representation
does not require observing any future realized pulse, but it does
require an independently declared model of which substitutions
are allowed.

\paragraph{Exact source-catalogue split.}
There are 203 source keys and 164 distinct pointwise envelopes.
With right requests limited to start at or before tick 5, the
exact query quotient has 158 classes. Extending the same shaped
menu through tick 11 gives 159, and the remaining admitted
extension through tick 13 does not increase it further.
Only one old class splits: left profiles $(3,3,3)$ and $(5,5,2)$,
indexed by retained closing depth, pulse start and pulse duration.
They agree against every old right query. Against the newly
admissible right profile $(0,11,4)$, the first peaks at 38
and the second at 36. Thus at budget 36 the obsolete summary
cannot distinguish a valid continued admission from a refusal.

If the old class identifier must remain, a single additional bit on
that split class is necessary and sufficient to recover all new
threshold answers. The fixture can retain whether the staged native
command depth exceeds four, known at the cut before any future
right pulse occurs. The ordinary factored direct index gives the
same result. This is an exact refinement of a fixed old interface,
not a claim that the new standalone encoding takes an extra bit
globally, that command depth is available in the stock OPEN message,
or that these 203 profiles exhaust physical environments.
