\section*{A restarted door writer and a migrating named duty}
\paragraph{Test and kernel.}
Exercise the same two-cut controller used in the warehouse--radio fixture
with a different live resource: a five-update crossing through selected
door leaves. This is a development transfer, chosen with knowledge of
previous failures and not an independent selection. The four doors are
two shared candidates numbered $0$ and $1$, a prepositioned isolated
alternative numbered $2$, and a distinct continuing actuator workload.
The plant uses pinned Open-RMF C++ for the paired joint writes, reported
door modes, and phase and session check. It uses an authored serial
authority adapter and stipulated velocity following, not Gazebo physics,
ROS transport or Open-RMF's deployed ownership semantics. Resetting the
modeled command cache does not establish which actuator command persists
on real hardware.

\paragraph{Actual cut and admissible observation.}
Two reopened SQLite views share the same unqualified CLOSE latches and
the same fresh OPEN/phase reports and prefix writers. The named OLD row may
or may not exist. A qualified read at the decision cut exposes only which
gate, if any, currently owes OLD. It does not expose the later appointment.
The evaluation family separately admits either steady authority or one
switch to the other shared gate after the first update. That future support
is authored and tested, not inferred from the first read. One scoped
writer consumes the active named appointment at each update. Service
requires all owed CLOSE targets to be lawfully issued and write a negative
velocity, the other gate's independent workload to continue, and the
selected, prepared crossing to stay within the strict $8/512$ dip bound.
This counts dispatch for OLD, not completion of its physical motion.

\paragraph{Exact scoped check.}
Initial writes are zero on either candidate. In $1/512$ units the native
writer followed by the chosen integrator gives successive CLOSE dips
$1,3,6,10,15$ after up to five consecutive ticks. A single first CLOSE then
OPEN gives dip $1$, because the subsequent OPEN write is already zero; no
faster crossing or compensating actuator is admitted. For either prepared
shared gate, the lawful scoped writer permits service precisely if the
OLD authority at the four later ticks does not name that gate. This
includes the case where OLD was assigned there for the first tick and
then left. The isolated path always preserves the same duties if staged.
Checking the scoped and local-hold per-row formulas against native outputs
does not have to infer them from the winning plan matrix.

\paragraph{Matched failure and positive service.}
If authority stays fixed, an early qualified snapshot permits routing
between the two prepared shared gates. Without that snapshot neither
shared gate can be guaranteed and the isolated path must be staged. With
migration allowed, even a qualified snapshot leaves two continuations
with opposed later assignments. In a matched pair the report names gate
$1$ in both traces. Gate $0$ remains usable if OLD stays on $1$; if it
moves to $0$, the modeled leaves dip $10/512$. Holding the crossing
writer on OPEN avoids the dip but suppresses OLD's due write. Using the
isolated prepared path allows the new crossing and both old services to
continue. A late read is not offered at the frozen decision cut: before
claiming a design limit beyond it, test whether waiting would still meet
the physical deadline. Repeating either unqualified CLOSE or a single
snapshot at every writer update does not preserve lawful service across
this family.

\paragraph{Reuse and comparator.}
The same pinned chooser and importer compute one common action per
reached local view, not one per hidden future. An independent factored
schedule given the same native outcomes, qualifications, declared future
support, effect-side fence and staging options ties in all 20
configuration arms. The causal counterexample is not just another
permission label: when the shared resource is physical leaf clearance,
a valid late writer can consume it even though the earlier read is true;
suppressing the writer violates a distinct continuing duty. No advance
over fencing plus equal timed routing is established. This does not
resolve I1, source coverage, or the independent missions. In particular,
a production adapter still needs a nonreused writer installation,
receiver-side enforcement without alternate paths, a separately justified
motion bound, and source-supported inclusion of every possible joint
continuation. Representative observed branches alone do not prove that
inclusion.
