\section*{Development bridge: a paid observation and a retained result on one cut}

\paragraph{Evidence scope.}
This is an authored serial model, executed over a finite support.
It is not a replay of native RWARE, SubT or SQLite, a freeze for
confirmatory evaluation, or any part of an independent mission.
The anchors for adapter conformance are
\href{https://github.com/eternal-november/eos-research-programmes/pull/813}{the keyed restart},
\href{https://github.com/eternal-november/eos-research-programmes/pull/818}{the scope-expansion audit}, and
\href{https://github.com/eternal-november/eos-research-programmes/pull/825}{the paid observation}.
The final adapter integration is an open obligation; no row from
one source run is combined with a row from another and counted
as a native trajectory.

\paragraph{Interface and model.}
The same executable solver sees a plan menu, a declared family of
histories, a local observation boundary and a service predicate.
For each reachable observation it intersects the candidate actions
that realize the predicate. The resulting decision uses only the
local view; the world is private to the reference execution.
Each chosen policy is replayed. A separate exhaustive search
over local functions checks the feasible-plan set.
Inspection consumes access to a currently free lane; a late bit
tests one lane and never identifies the full blockage.
The already-settled named audit consumes disclosure permission
and exact old key-to-row provenance. A two-row basis is local and
preinstalled; a qualified ordinal or the full record supplies the
missing binding, not permission to repeat the old motion.
The joined interpreter checks both before updating its modeled plant
and refuses stale provenance or missing permission. Its serialized
local commit is not a physical atomicity claim.
An unrelated move and separate four-byte report continue.

\paragraph{One interaction the separate checks miss.}
On the quiet dock at request cap five, the inspection with its one-byte
live observation and the audit with its one-byte live ordinal each
admit the same four-byte request when tested alone.
Require the same live debits at the same dock and cut, and both cannot
succeed: \(1+1+4=6\). A budget of six suffices, or if the old
association is already sealed, sending the same ordinal before the
rolling debit window suffices at five. The audit record survives debit
expiry; the occupancy evidence does not survive an intervening
blockage. When a declared outage can cut all late routes to the old
record, a larger late budget alone does not restore it.
The return at the joint cut is separately charged: one move identifier
and the four-byte old result, not a four-byte stand-in.

At five with early staging, the ordinal plan sends 15 bytes including
the unrelated report and return; the early full-record plan sends 18.
A stale ordinal invalidates only the ordinal branch; the qualified
full path still works. The claim is marginal packet bytes with a trusted
preinstalled basis, routes and grants. Setup, discovery, and validation
are not measured as free: if ordinal staging incurs more than three
additional bytes per use it does not save total bytes, and this model
does not supply that overhead. No measured computational or source
effort advantage follows. Direct same-view enumeration finds exactly
the same feasible plans in 27 configurations (3,042 world/plan pairs).
