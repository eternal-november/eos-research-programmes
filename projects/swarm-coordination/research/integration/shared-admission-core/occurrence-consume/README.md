# A shared named-effect check on two selected source paths

Read Occurrence_Replay_And_Consume_Cuts.tex. The role-chain checker is
hash-checked separately from its adapters. The Gazebo case executes selected
Gazebo/Open-RMF source bodies with an authored scheduler, not a Gazebo build.
The warehouse case reuses a pinned previously executed native radio trace
and reruns the native station behind the consumer.

Materialize SOURCE.tsv (destination, repository, commit, path and Git blob
hash) under up/. Requires Git, Python 3, SQLite, NumPy, NetworkX and C++20.
Run from this directory:

    sh run.sh up | cmp expected.txt -

No actuation, physical clearance, architecture advance, or independent
acceptance is claimed.

The replay checks 64 selected actuator cases, 16 native station reruns,
and 320 independent finite rank cases (41,858 candidate action words).
The rank theorem is a condition on the serial stage chain, not a claim
about what scheduling APIs the original runtime makes available.
