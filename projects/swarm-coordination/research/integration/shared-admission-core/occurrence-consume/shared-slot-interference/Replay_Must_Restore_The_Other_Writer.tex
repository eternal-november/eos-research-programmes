\section*{A late local repair can owe a replay to the other writer}
The earlier serial rank says which stages must run again to deliver
a named new effect. That rank is not sufficient when an operation
also writes a field needed by an unrelated duty. This fixture holds
an independent vertical lift effect while retiring the named
horizontal motor intent at one selected update. Neither field is
a measurement of physical motion or payload clearance.

\paragraph{Interface.}
In the identity-frame fixture, the native horizontal producer
sets the whole linear velocity command to $(x,0,0)$ from its most
recent sampled command. The selected lift write afterward preserves
the horizontal field and sets $z=5/8$. Then one selected Gazebo
physics setter consumes that common component. The new named
request asks for zero horizontal effect. The vertical writer owes the
same $5/8$ effect at that setter. An old numeric zero does not
provide evidence that the actual named new request reached the
setter. The provenance counters are tapped at the modeled cuts;
they are not fields in the stock protocol.

\paragraph{Exact frontier in the declared action class.}
The policy can rerun the sample, the horizontal writer, and, if
available with authorization, the original vertical writer before the
setter. A native write is distinct from executing the setter. No
scope-aware partial write, reassignment, physical bypass, or extra
time before the deadline is granted. With phase-indexed receipt and
the declared order:
\[
\begin{array}{lll}
\text{receipt before normal sample} & &0\\
\text{after sample, before horizontal write} &&1\\
\text{after horizontal write, before lift write} &&2\\
\text{after lift write, before setter} &&3\text{ if lift repeat is allowed, else infeasible}\\
\text{after setter} &&\text{infeasible for that cut.}
\end{array}
\]
Here zero, one, two, and three count extra calls, not time.
Necessity of each horizontal call follows from its older parent
occurrence; a later latch alone cannot replace an older command
already in the component. In the fourth case the mandatory
horizontal replay erases the old vertical command. Any satisfying
sequence must legally replay the vertical writer afterward too.
These calls in dependency order attain the counts; at earlier cuts
the scheduled lift write already supplies the vertical effect.
If repeat authority is absent, dropping the vertical duty or
calling a different writer is not a solution within this class.
A scoped read-modify-write could change the frontier only if its
authority, frame, freshness and command semantics were established.

\paragraph{Common effect cut.}
A separate two-cut native trace has zero horizontal value at one
setter and required vertical value at the next, but neither
setter has both. Independent reports of success somewhere in the
horizon do not establish a joint requirement at one effect
occurrence. The replay pins the original native setters and
source bodies, explicitly samples and compares both coordinates,
and checks 160 cases against the exact direct condition above.
A direct scheduler with the same abilities can make the same choices.
Neither availability of the extra calls on a real scheduler nor a
positive physical or independent mission result is established.
