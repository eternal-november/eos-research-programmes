\section*{A shared-slot repair requires a usable continuation, not a free-slot report}
The selected Gazebo/Open-RMF source fixture has a late horizontal
repair while an independent vertical command is already staged.
Rerunning the native horizontal writer clears the staged vertical
component. The only offered restoration is another call to the
native lift writer before the selected setter. The scope is the
value passed to that setter, not motion or payload clearance.

\paragraph{Causal interface.}
The controller can re-sample the named new horizontal command
without writing the shared slot. It must then decide whether to
issue the full-vector rewrite. A scheduler row represents one
remaining lift-call opportunity; a distinct optional job can claim
the same opportunity. A read-only view can truthfully report that
the row is free while leaving it claimable. In the reserve arm a
real local SQLite conditional update commits a cut-bound one-use
grant before the irreversible rewrite. An independent connection
can obtain it otherwise. Claims for another cut and duplicate
consumption fail. The ledger governs cooperative contenders, not
independent loss of a writer. Its use to gate procedure invocation
is authored; no stock scheduler or end-to-end atomic plant write
is asserted.

\paragraph{Two obstructions with different remedies.}
With no intervening contention, the rule that reads the free row,
rewrites, and only then claims can complete both named effects.
On the identical free-row observation, an optional claimant can
take the row after that rewrite. A continuing policy has no way
within the offered late-stage operations to restore the vertical
value once the required call is lost. The reserve arm excludes
this particular legal contention after commitment. On that same
case it satisfies both setter values, but defers the optional job.
If the optional job has already taken the row at the decision cut,
the policy does not erase the independent vertical command; the
horizontal request remains unresolved. If the competing claim comes between the preview and the
reserve attempt, the conditional transaction loses despite the
unchanged earlier preview; it still refuses the rewrite.
Claim timing changes actual
service rather than just the wording of a certificate.

There is a different negative case where the writer becomes
unavailable after a valid reservation. The row can be acquired and
used, yet the source cannot execute the restore. A resource token
does not prove the promised action completed or was physically
possible. If this loss is in the admitted class and there is no
backup or effect-preserving narrow write, the robust controller
cannot justify the irreversible broad write on the same preview.
It keeps the earlier vertical value and openly loses the horizontal
request. For this fixed action interface the obstruction is exact:
one history permits the restore, a history with the same available
prefix does not, and the only horizontal route erases the existing
vertical value first. Merely trading away that existing duty would
change the contract. A jointly guarded actuator operation or a
qualified independent restoring source might change the interface;
neither is assumed here.

\paragraph{Compared behaviors.}
The native source bodies are run interactively at the individual
cuts. The scheduler experiment independently changes when the
optional claimant runs and whether the source is unavailable.
There are 48 cases. The robust arm uses only the declared
availability class plus the committed local grant, never the
realized fault parameter, for its rewrite decision. Among its twelve
cases admitted by the specified environment law it preserved the
existing vertical duty in all twelve, including when the horizontal
request could not be retained. A direct scheduling rule consuming
the same grant and fault support can select exactly the same actions.
No timing advantage over it is claimed. Holding a conflicting
optional job is an explicit cost, not a free global pause or loss
under an independent route. No physical, holdout, inventory, or
architecture acceptance follows.
