\section*{Named evidence across a late source cut}
This development test isolates a small check: did a requested source
occurrence yield the required terminal effect, through the permitted
intermediate roles and within the declared deadline? The effect is
typed by the consumer. The same terminating number, the last mailbox
value, or a transport acceptance is not automatically evidence of
the named effect. The archived tests use two established source
fixtures, not independently selected missions.

\paragraph{Frozen predicate and semantic boundary.}
The hash-checked predicate consumes an ordered prefix of scoped
occurrences. It checks terminal value, deadline, and a chain of
parent occurrences with the declared roles, qualification and exact
named origin. The two adapters supply role names and establish their
own source facts; the core was frozen before running either adapter.
It does not authenticate a tape, infer missing observations, enforce
actuator control, or certify a horizon after the terminal occurrence.
The adapters may not promote a command to a physical state report.
The direct rules below get the same authority and occurrence
information. The exercise is about transporting a check, not proving
that the two systems have the same dynamics.

\paragraph{Serial chain and exact repair rank.}
Let stages $1,\ldots,m$ normally execute once in that order, passing
the current occurrence of stage $j-1$ to stage $j$ at execution.
Stage 0 is the source. The new named occurrence arrives after the
first $k$ scheduled operations. Before the remaining scheduled suffix,
a subset of the passed stages can be legally re-executed. At deadline
the final stage must descend from the new occurrence, even if the
old value happened to equal the requested one.

Every previously executed stage must run again after the named
receipt: if the final output descends from it, backtracking the
parent at every stage places a subsequent use in every slot. No
other stage can fake that use. Thus, if any required passed stage
cannot be re-executed, no policy in this interface can establish the
law by this deadline. Otherwise, re-executing precisely the first
$k$ in order suffices. For unit re-execution cost the optimum is
$k$; with fixed nonnegative per-stage costs it is their sum, with
zero-cost passes not affecting necessity. This result assumes serial
copy lineage and a suffix still scheduled in order; competing
overwrites, additional parent dependencies, availability changes
during the inserted passes and physical effects of those calls are
outside the theorem. Exhaustive ordered search is a direct baseline
for the finite cases, not a deployed scheduler.

\paragraph{Actuator front.}
In the selected Gazebo fixtures the actual bodies sample the mailbox,
write the component, and consume a mixed velocity command. From
a named zero-horizontal receipt, the exact cut frontier is:
before the usual sample, no extra call; after the sample but before
the write, one re-sample; after the write but before the selected
physics setter, repeat both the sample and the horizontal writer;
after that setter, no authorization of this elapsed cut. A re-sample
without rewriting cannot change the pending slot. The vertical
writer completes at its original $0.625$ in all tested cases.
Old numeric zero and an unqualified request are explicit controls.
The reordering interventions and phase opportunities are authored
and not granted by the stock scheduler. The setter is not a stop
certificate or a sampled trajectory. Monotonically ordered phase
indices in the replay are not wall time.

\paragraph{Station front.}
In the earlier selected SubT native tapes, the adapter retains
the named fenced result's actual charged-send ancestry, application
arrival and exact destination. Here it reruns the native warehouse
worker and reads the new station's local authority, named permit
and snapshot tag in one read-only transaction before deciding
whether to install. The same radio tape can yield a qualified
receipt on a fresh fenced copy or an unqualified result on a
pre-fence copy. A matching effect is qualified packet availability
and permission to try; the later actual cached return is checked
separately. The radio source was replayed when creating the pinned
tape, not recompiled as part of this package. This port consumes a
different role chain than the actuator port, and reuses the same
predicate bytes. It does not instantiate the actuator's scheduling
rank theorem in the radio plant.

The development results leave the independent transfer, resource
advancement, non-speaking source guarantees, and architecture-level
inventory dispositions open. In particular no version is frozen
for confirmatory I1/I2 acceptance.
