\section*{A past opportunity is not current service evidence}
An old audit has two actual qualified radio opportunities.
The proposed new calibration would make an observer
unavailable at the second. The application owns an amendment
deadline strictly between them. It must not free the second
opportunity unless the old audit already has a qualified
durable receipt. Either the audit is owed or its qualified
settlement crosses into the new scheduling context.

The executable gate retains the elapsed cut and calculates the
remaining eligible set \(W_{>t}\). It approves a valid amendment
only if either a current scoped receipt establishes old service,
or the actual proposed source constraints leave a member of
\(W_{>t}\) unblocked. Recomputing the full original \(W\) against
live appointments is not the same test. If the earlier cut
failed because calibration was active, purging that completed
appointment is correct for future work but cannot produce a
new opportunity at an old time. The false rule accepts a late
calibration and the native broker then loses the old audit.
The Lean invariant separates qualified receipts from actual
settlement, and proves retention across both edits and elapsed
qualified cuts, with an exact two-cut counterexample to expiry
forgetting. The modeled owned dispatcher actually schedules an
available cut to justify the transition premise.

\paragraph{Native evidence.}
A one-byte exact callback to the requester comes from the
actual audit receiver on the pinned native path. Its nominal
early receipt is 7.8125 ms after the first audit. An independent
six-byte result can instead fill the requester's receive
credit, while the audit itself still arrives at its own
destination. The real return attempt uses a native transmit
byte without reaching the actor responsible for the amendment.
Do not infer the old receipt from a known sent audit. The timing
control delivers the same valid return at 23.4375 ms, after
the 15.625 ms amendment deadline and before the next audit
opportunity at 31.25 ms. The authority's stored clock is twice
integer microseconds, so neither arrival is conflated with the
decision cut. It accepts the later record as truthful evidence
of that old audit, but a retry returns the exact previous
decision and a genuinely new edit is outside the closed scope.
Arrival of evidence cannot rewrite either historical policy.

\paragraph{Checked consequence and kernel.}
The four cases are: actual first cut blocked; returned receipt
on time; actual audit accepted with its return blocked by real
radio credit; and identical valid receipt returned too late.
Both mapped routes and paired real gate/dock failure phase
orders are crossed with worker exits before/after the durable
amendment cut. The causal and direct same-input arms agree
on all 32 cases each, preserve all 32 old audits and install 8
timely changes. The stale calendar installs 32 changes but loses
8 old audits. Existing egress and dock settlement still hold,
and the independently owed competing result actually arrives
when present. The actor intentionally foregoes the new
calibration when the proof is unavailable; this is conservative
about a possibly already delivered old audit, not a claim that
the old audit did not arrive. Clock ownership, serial admission,
the precise evidence scope and calibration control are declared
parts of this civil model. No field clock bounds, stock receiver
authorization API, independent mission or new theorem about
unbounded clocks are inferred.
