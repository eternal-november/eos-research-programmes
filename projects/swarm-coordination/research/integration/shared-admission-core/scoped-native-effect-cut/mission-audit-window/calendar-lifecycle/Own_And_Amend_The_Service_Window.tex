\section*{Derive service support from controlled source work}
The earlier cave replay took proposed observer outage supports
as declared inputs. This replay makes the overlapping part of
those supports a consequence of a durable, versioned source
operation. It is still the civil held-in cave and a deliberately
controlled calibration lifecycle, not discovery of unrestricted
physical outages.

\paragraph{Source and consumer.}
At the actually reached rest station the existing source derives
the two eligible native audit opportunities, including preserving
room for the old five-byte dock attempt. The modeled source
owns narrow calibration intervals indexed by the same clock.
Its projected outage mask is exactly which eligible cuts lie
in the half-open interval of an active calibration. The deployed
broker code uses the corresponding current pose callback, not
a future outcome selected by the optimizer. Actual calibration
starts are separately committed in the source journal as each
cut arrives. An independent instrument has its own local
calibration but is not a member of the radio cohort.

\paragraph{Prospective approval must survive revision.}
The two early observers start aligned on the first cut. Their
old audit is still due and the second cut is protected.
Authentic scope for the enrolled sources is a precondition of
this fixture, with a joint request permitted only in the
designated controlled source. A singleton shift to the second
cut would remove the remaining valid shared opportunity,
although each resulting observer schedule alone still leaves
one. Do not commit that shift. A two-observer atomic change
that shifts both to the second cut leaves the first free and
is legal. A sequence of single shifts to the target times
cannot realize that change while preserving the invariant at
each step. Changes to the third instrument do not affect it.
The exact shared cut classifier and the direct enumerating
calendar agree. The independently checked count and freeze
arms distinguish respectively an unsafe local test and an
unnecessarily conservative global immutable test.

New appointments and a typed exact edit result commit in
one SQLite transaction. The worker actually exits before or
after this cut on matched runs. Retrying a committed key
returns the old decision without performing the appointment
again; a before-commit exit leaves the previous plan visible.
The pose source then enacts whichever appointment actually
committed. The separate observer reports, old dock settlement
and physical cave egress still use the pinned native and
worker replays on the same histories.

\paragraph{Bounded consequence.}
In the declared four change types, two route geometries, and
paired failure phases, each correct policy preserves all 32
old audits. It installs 16 amendments, including safe joint
and unrelated edits. Freeze installs only 8; the local-only
test installs every edit but loses 16 owed audits. Lean checks
the scoped edit and elapsed-cut invariant in the idealized
transition system; the native adapters establish the relevant
actual effect/forwarding correspondence for this fixture.
This does not promise a valid certificate when an
uncontrolled sensor part fails, authenticate an external
clock or owner, cover arbitrary serializations across remote
sites, or claim independent mission acceptance.
