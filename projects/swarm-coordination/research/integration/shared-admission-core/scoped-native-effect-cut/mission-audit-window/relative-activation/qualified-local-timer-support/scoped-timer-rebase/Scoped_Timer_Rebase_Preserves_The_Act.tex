\section*{Change the timer representation without changing its act}
An already armed act is determined by whether its current
reading reaches a threshold, not by the numeric value abstracted
from the source that reads it. Let the durable local timer carry
\(h\) in its old clock \(C\). If an authorized replacement clock
satisfies \(C'=C+k\) for the entire relevant timer phase, then
the correct threshold is \(h'=h+k\). Each comparison gives the
same answer, hence the first true local activation cut is
unchanged. Equality of one timestamp would not establish this
premise if the rate or drift law can change. The controlled
test owns the fixed additive relation as a prospective
clock-configuration fact, not a field calibration from one
unqualified sample.

Both timed observers first actually receive the old command.
The authoritative source issues the exact relation for the
reconfigured observer; a native typed callback can deliver it
before the clock switch. That observer rebases its read and
threshold together if the qualified relation arrived. If
earlier native data (five bytes plus the old arm byte) leaves
no receive room for the new relation, the test can lawfully
retain the old physical read and original threshold. The
attempted new relation actually spends one byte at its sender.
Both the preserved old action and the optional coordinate
migration are recorded separately. Holding an old clock through
a compulsory loss or physical replacement is not assumed.

Across the eight paired native scenarios, four install the
proposed replacement coordinate without changing either
activation cut and four safely retain the qualified source.
A direct implementation pinned to the same old physical clock
ties in all old audit and required new-effect outcomes.
Keeping the old numeric threshold in the new coordinate
instead loses four old audits and acts before the permitted
earliest cut in two other scenarios. These are actual changes
to effect time at the controlled held-in native cuts, not
claims about clock synchronization, external authorization,
independent mission acceptance, or novelty over direct
qualified coordinate comparison.
