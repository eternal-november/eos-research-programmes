\section*{Recovering early service by retaining allowed outage locations}
One old diagnostic remains due, but admitting a new observer can
block native radio dispatch whenever that observer has no pose.
A membership controller may defer observers with no earlier
registration obligation. Each observer also has an independent
one-byte result; the stakeholders prefer earlier receipt when it
does not jeopardize the old result or any mandatory obligation.
No authority to delay an existing obligation is assumed.

Let \(W\) denote the genuinely eligible cuts for the old send
after fixing resource, authority, route and deadline conditions,
before testing the added observers. For each active observer
\(i\), the qualification contract specifies a permitted
disruption set \(S_i\subseteq W\) and a count limit \(b_i\).
The fault support is exactly every combination \(M_i\subseteq S_i\)
with \(|M_i|\le b_i\), on the same time domain.
These sets restrict \emph{where} missing poses are allowed. They
are not the actual future reads. A common-cause law that excludes
combinations cannot be replaced by this product for an exact
impossibility claim. No such support is inferred from arrival logs.

\paragraph{Sharp finite cut composition.}
Create a bipartite graph with one vertex per eligible cut and
\(b_i\) unit slots for observer \(i\); connect a cut to each slot
of \(i\) iff it lies in \(S_i\). If the observers jointly block
\(k\) distinct cuts, assign each blocked cut to one observer
missing it. At most \(b_i\) of these assignments use observer
\(i\), giving a matching of size \(k\). Conversely a matching
assigns an outage to each matched cut; group them by observer.
This is in declared support and blocks exactly the matched cuts.
Hence with maximum matching size \(\nu\), the exact minimum
available count is \(|W|-\nu\). The live controller dispatches
at the first currently ready eligible cut, without knowing
the chosen outages. The code uses augmenting paths for a fixed
subset; the search over early subsets is explicit.

\paragraph{Actual source consequence.}
Each of two observers can miss at most one cut.
An old native receive debit leaves cuts 1.375 and 1.5 s eligible
for the three-byte diagnostic; age one second is still charged.
The count-only policy stages one observer before the old deadline.
If both are unable to miss outside the same cut, no matching
covers the whole window. Admit both early. When their support
allows them to cover opposite cuts, retain the count policy.
The earlier observer results send at 0.75 s on a distinct resource
path with no permitted pose outage at that earlier cut. Others send
the same result at 1.625 s after qualified enrollment. Both policies
deliver the old diagnostic in all 49 paired native schedules.
Eight move one more observer result earlier without dropping
or delaying another obligation. Direct enumeration with the same
supports and control powers agrees. The 430,080 matching checks
vary eligible subsets and overlapping supports; the native replay
separately executes real native credit, dispatch and exact callbacks
with the unchanged effect-cut interpreter.

This is an advance over the count-only guarantee, not over a
same-information direct scheduler. Nothing here establishes
how to qualify the support on hardware, a stock broker API,
or an independent mission. Disturbances that change allowed
windows or resource histories require a renewed qualification.
