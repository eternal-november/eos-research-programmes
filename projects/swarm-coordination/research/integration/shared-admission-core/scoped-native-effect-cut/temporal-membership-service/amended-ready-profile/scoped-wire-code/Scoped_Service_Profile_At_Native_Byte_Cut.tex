\section*{One-byte transport of the exact deadline query, and when it breaks}
Two controllers share an outstanding audit before the end of a
nine-cut service window. The broker needs every registered
observer's pose. Absent activation of the optional observer, the
already required observer can miss at most the declared cap and
cannot fill the whole window. If the optional observer activates
early, it can send its own report immediately, but can interfere
with the pending audit. Each controller owns a local scheduled
availability or blackout, not a read of its partner's future
physical fault realization. This fixture explicitly implements
the declared calendars as pose-source policies, with current
readiness rechecked at each real native dispatch opportunity.

\paragraph{Typed consultation.}
On the cut set \(W\), let \(S\subseteq W\) be the source's reserved
ready support and let \(U\subseteq W\) be the receiver-side
observer's known planned omissions, with \(|U|\le b\).
Under the fixed room and link assumptions of this fixture,
an activated optional observer still leaves old service iff
\(S\not\subseteq U\). The exact profile from the previously
proved ready-support criterion retains \(S\) when it fits the cap;
otherwise the receiver only needs the large-set class that
cannot be covered. The finite number of distinguishable
signals is
\[
    1+\sum_{k=0}^{b}{9\choose k}\quad (b<9).
\]
It is 131 when \(b=3\), versus 512 for the raw nine-bit set.
A deterministic canonical index carries the decision in one
byte. For necessity, distinct classes have a separating query.
A one-shot exact encoder with fewer possible payloads merges two
such classes, making their differing answer undecodable for
the same partner query. The communication lower bound assumes
fixed source and receiver/context slot, no additional signals
(e.g.\ timing, suppressing the slot or other traffic), and zero
error over all admitted source and query pairs. It is not a
lower bound for protocols with independently supplied side
information. An equally factored optimal codec reaches the
same bound.

\paragraph{Effect on actual budgets and old service.}
An actual five-byte older receipt occupies the destination's
six-byte native rolling receive credit at the profile cut.
The one-byte value arrives; the two-byte raw exact set is
charged at its transmitter but rejected at the receiver.
Both policies protect the old audit. The condensed route
admits the optional observer exactly when the receiver's
local query allows it. In the 512 paired schedule cases,
this completes 504 additional independent reports at
the early cut. Activation is not harmless: in the checked
negative control, an unjustified activation leaves no cut
with all poses ready and prevents the old native audit.
The optional report and old audit both use the actual receiving
credit at the same independent receiver (three bytes each);
conditional availability is not inferred from transmitting
metadata alone. The source, typed version and cut grid are
bound by the preexisting fixed slot. Encoding and sending a
separate source or generation header is not included.

\paragraph{Cap amendment.}
At \(b=4\) exactly 257 classes are reachable. Therefore the
same fixed one-byte interface cannot answer every admitted
query. Two stored old saturated supports of sizes four and
five are tested against the same newly allowed four omissions:
one misses the audit under activation, and the other delivers it.
Retaining the old class is insufficient after this change.
The newly required two-byte canonical value hits the native
RX cap, and truncation cannot repair the interface. Valid
alternatives require a qualified smaller workload or support,
a larger budget, an additional communication opportunity, or
a conservative fallback. The 197,632 reference query checks
confirm exact classes and the native controlled replay checks
the one-byte and failure consequences. No claims about unknown
field availability, cost of creating the calendars, independent
mission acceptance, or novelty over a direct exact codec.
