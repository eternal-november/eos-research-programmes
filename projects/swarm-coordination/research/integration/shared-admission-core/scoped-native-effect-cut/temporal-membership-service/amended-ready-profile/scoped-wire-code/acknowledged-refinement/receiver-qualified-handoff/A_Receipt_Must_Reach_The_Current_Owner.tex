\section*{A retained profile is scoped to its actual receiver}
The one-byte conditional amendment uses a prior cache class.
A confirmation from a former receiver at the same native address
does not establish that the replacement possesses that class.
A replacement can even have a valid earlier value for a
different subject. Its one-byte indices have a different
interpretation.

The civilian native replay first sends the prior profile both to
its receiving owner and to a separately qualified archive. An
actual report replies with the old class. An authorized membership
change removes and re-adds the same address, proving an actual
different native allocation at that address. In the positive
case the archive sends the exact prior class into the new
receiver's cache, and a new native acknowledgment establishes
its value and modeled receiver scope. An unconfirmed new delivery
is not enough for the sender. The control plane gives the fixture
a trustworthy current allocation comparison; no claim is made
that an ordinary remote SubT datagram exports this scope.
The initial exchange, archive transfer and re-acknowledgment
are real sends before the later credit window. They are not
charged as though they occurred in the later one-byte window.

Only a qualified matching current cache authorizes the supplement
with the unchanged relative codec. Both the original source and
target remain in the declared subject/window of the amended
query. The reference is direct comparison of the actual ready
set and local blackout when this witness exists, and old-duty-first
deferral when it does not. Importing the old acknowledgment by
address alone is a diagnostic ablation rather than an equally
informed alternative. In the negative comparator the same
payload index is evaluated against a different prior class
which also arrived natively. This can falsely admit a new
observer, and its missing poses actually exhaust the old audit's
whole eligible window. The good policy defers that activation
when the old receiver changed but has not requalified.
Separation between reporting the historical receipt and
authorizing further physical work is essential.

This is a finite held-in source replay; the application cache and
authorized binding/copy interface are controlled and serialized.
No cryptographic authentication, unconstrained authority migration,
field availability or independent mission result is claimed.
