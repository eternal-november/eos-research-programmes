\section*{Recover the larger query interface without retransmitting the old profile}
A change from three allowed partner omissions to four admits
257 exact query classes on nine fixed eligible cuts. A stateless
one-byte exact replacement cannot cover all of them. Suppose
the receiver already has a qualified, scoped cap-three profile
and the sender has an actual acknowledgment of that profile.
This is an existing historical fact, not additional assumed
bandwidth at the later constrained cut.

\paragraph{The comparison and its kernel.}
The cap-four profile refines the cap-three profile; the older
payload is the coarser class containing the current value.
The cap-three small classes retain the exact readiness set and
have a unique refinement, so no new byte is needed there.
Its large class splits into the 126 exact sets of size four and
the one class for all larger sets. The sender supplies a local
index in that retained class. The controller uses the same old
profile and the in-class index to recover the full exact query
answer. Among zero-error one-shot supplements with the same
known old class, 127 possible payloads are necessary in that
class: any two split classes differ on an admitted partner
query. Thus seven bits suffice and fewer do not. The fixed
one-byte native payload can hold those bits. This is relative
information, not compression of 257 stateless classes into 256
labels.

\paragraph{Actual context carriage and invalidation.}
A native dispatch sends the original profile and a native
reply confirms its precise scope-bound value while the old
window is open. Its cost is real and precedes the later budget
window. An old frame that was not confirmed to the source
does not qualify for this protocol. The acknowledgment has a
fixed existing identity and slot in the replay, and no fresh
epoch header is added. When the cap changes, the current
source must still lie in the acknowledged parent class, and
the interpreting receiver retains the corresponding original
profile. If the scope changes or the subject no longer has
that class, the index does not travel with it. The tested
missing-confirmation and changed-parent controls defer early
activation rather than invent a fresh message or a working
old certificate. The conditional construction would permit
a changed finer value inside the same verified parent, but
the positive sweep pins the source support through the change.
General source adoption needs verified typed receipt lifetime
and cannot infer coherence from the address alone.

\paragraph{Native consequence.}
At the later cut the receiving broker has one byte left after
an actual five-byte delivery. The replacement that resends
the full two-byte absolute profile cannot deliver it in any
of 512 paired cases. The qualified cache policy needs no
frame in 130 cases and delivers a one-byte supplement in
382. Both preserve all 512 old audits per arm; the qualified
cached policy executes 496 additional early native reports
without dropping one of those old audits. The same direct
conditional code ties. All 131,072 pairs of exact input and
admissible query agree independently with the decoded result.
This is a design with a qualified prior receipt, declared
controlled calendars and a serial current effect check, not
evidence for unknown pose availability or independent mission
acceptance.
