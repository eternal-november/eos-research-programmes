\section*{Carry the receipt, not the power to create a warehouse effect}
A named warehouse duty remains live across an actual worker exit.
A later authorized change can leave either station, both stations,
or neither able to create that duty's motion. Both still have
separate standing permission to return the exact historical
receipt. This transfer compares the same scoped cut kernel used
for the cave gate and native broker with a distinct warehouse
motion and recipient-owned journal interface. It is held-in
source development, not independent acceptance.

\paragraph{Same-history native inputs.}
The pinned warehouse simulator and SQLite continue to own
motion and keyed receipts. The first worker really exits
after commit and before a reply. A matched pair has identical
actual native motion logs with and without the named duty
settled: the physical result alone cannot answer the key query.
The additional control executes a distinct ambient committed
step prior to the exit, leaving both principal destinations
physically available. The revision runs in a separate durable
transaction at the broker's interposition point, after its
ordinary side traffic and before the first charged retry.
The role mask is read again after reopening the database; the
native motion history and any old receipt have not changed.
The declared fixture serializes the qualified read, callback,
and effect; neither simulator is claimed to provide this
coordination API outside the wrapper.

\paragraph{Interpret and assemble.}
An available radio resource represents one possible recipient;
neither an old radio address nor a new one grants warehouse
motion. Before committing the first charged attempt, an exact
historical return uses its read permission and immutable named
value. A pending duty requires an actual candidate whose
receiver is available to this send, whose cell is free, and
who has the current scoped power. The shared kernel makes
that local inspection-versus-effect distinction, while the
older first-admissible selector combines it with the native
radio filter. The actual warehouse writer rechecks current
authority and occupancy. Its refusal is not an effect and cannot
refund a packet that already used native airtime. The old
journal result returns through the local callback, not a modeled
over-radio acknowledgment.

\paragraph{Consequences on the matched actual effects.}
With both cells free and a pending duty, ordinary radio
competition can leave only B receiving. That alone leaves a path
when either actor is authorized. An authorized change
leaving only A also leaves a path when the radio is free.
Together these leave no recipient who can complete the duty:
the separate success claims do not compose. Giving lawful
power to B instead restores a same-cut settlement in the
declared B-only-radio branch. Conversely if both can receive
but only B can act, the live check selects B. The stale check
sends to A, is correctly refused by the actual warehouse
writer, and still pays the whole four-byte budget. It cannot
repair the error by another charged send at the cut.

Across 768 checked native cases, the shared and ordinary
factored direct checks agree: each credits 63 old duties,
including 40 historical returns, with zero charged attempts
that fail to produce an eligible result. Each can return
20 old records through a recipient who lacks fresh action
power. The recorded-old-power ablation pays for 22 attempts
without an effect or return; it settles one fewer old duty.
Side traffic, 432 successful native deliveries per arm, is
unchanged. All results are exhaustive over the fixture's
declared finite choices, not estimates for real operations.

The imported comparison applies at this serialized source
boundary with stable read permission and same-history
resources. It does not authorize cross-owner grants, prove live
remote atomicity, or imply field motion, service beyond the
scoped admitted cases, or operational improvement over a
direct check with the same inputs.
