# Shared mixed cut contract: exact inspection versus fresh effect

Civilian simulation only. The common check is executed by both the
native cave gate SQLite worker and the source-exact SubT broker
fixture. It is not merely a postprocess over their traces. The two
source adapters have different qualified evidence and resources;
the direct baseline transcript is preserved in each.

From a clean extracted Space supplement, provide the existing pinned
cave assets directory (including the visibility table and collision
meshes) to run the two complete replays:

    sha256sum -c MANIFEST.sha256
    bash replay.sh /path/to/cave-rehydration gate/parent | cmp - EXPECTED.txt

The included gate source checks the original parent source digests and
exact cave asset pins. The radio test includes its exact inputs in the
Space supplement. Git contains changed files, required source pointers,
and expected outputs. No geometry/held-out acceptance test is run.
Lean proof was checked on Lean 4.28.0. The C++ refinement check enumerates
the declared finite profile family separately.
