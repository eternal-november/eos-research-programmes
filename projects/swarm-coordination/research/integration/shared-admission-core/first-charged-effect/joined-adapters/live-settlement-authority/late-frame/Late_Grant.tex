\section*{Reject stale authority without refunding spent airtime}
\paragraph{Fixed conditions.}
Extend the \href{https://github.com/eternal-november/eos-research-programmes/pull/819}{native authority replay}
with an old one-byte grant frame, sent to the prior owner. The old
frame may arrive before the current frame, immediately after it at
the same timestamp, or at the decision cut. The valid new frame
may arrive or be lost in the actual extracted radio calculation.
Native warehouse states decide which route is physically open,
and the trusted fixture identifies the source and current lease
between the decision and the actual move. The independently due
report is preserved in every arm. Only diagnostics or safe decisions
change; the test does not model a forged authenticated grant.

\paragraph{Separate semantic admission from resource effect.}
A receiver matching the known current scope does not replace
a valid record with a later old record. Lean checks that order
independence for a fixed scope and that an old frame cannot
install a current grant. A last-arriving-value ablation can lose
settlement even when both old and new radio debits have aged
out. If the valid frame was lost, old receipt alone cannot
authorize a move. This is a known-current-scope rule, not a
proof that observing a numerically greatest epoch discovers
which one is actually current.

The receiver filter still incurs every native delivery debit.
With one valid one-byte grant and an old one-byte grant
on the same recipient ledger, a four-byte request fails a
five-byte cap until one debit expires. Even a syntactically
rejected old frame has already used the receiver ledger.
A separate comparator with permission and current authority
at the sender may discard the old frame before dispatch,
so neither end pays for it; this removes the extra debit.
It is not the same interface as a receiver-only filter.
Source-side rejection is not inferred from the source being
reachable or from eventual receipt.

\paragraph{Matched checks.}
Across the same 2,304 cases per arm, the scope-aware receiver
and same-information direct comparator each settle 432.
Last-arriving-value settles 320; predispatch suppression
with the extra upstream permission settles 480. These are
exhaustive counts for the authored grid and not probabilistic
estimates or a new fleet control solution. Both comparators
retain the physical recheck and final authority guard.
Old send and receive debit use the unmodified native broker
and RF routines, including the strict one-second boundary.
The logged H counter is its native, lazily maintained ledger,
not independently expired by later Q traffic. No independent
mission or distributed source authority claim.
