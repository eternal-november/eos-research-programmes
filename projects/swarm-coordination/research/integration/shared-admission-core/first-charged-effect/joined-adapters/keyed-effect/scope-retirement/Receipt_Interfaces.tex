\section*{Retirement preserves a scoped retry interface, not arbitrary history}
\paragraph{Contract and witness.}
A durably acknowledged result may answer a later duplicate with a
terminal no-redo notice; an unacknowledged completion must still return
its exact result. A stale epoch is outside the admitted receive interface.
This permits forgetting an acknowledged result only for a consumer
which no longer needs to read it from this server. It does not waive
a separate historical audit or an open client obligation.
Two named native RWARE effects commit in the journal. A separate
unrelated motion is preserved. The client durably records neither,
either or both exact responses. The notification transport, client
failure prior to this commitment, and no-execution class for newly
issued keys are not under test. The replacement installs its decoded
map in a new SQLite store, reopens it and queries both keys with no
donor or client read. Both old keys remain associated with the original
physical state; neither continuation issues another movement.

The anchor comparator is the first-incomplete acknowledgement in
\href{https://web.stanford.edu/~ouster/cgi-bin/papers/rifl.pdf}{RIFL, section 4.2},
not largest observed receipt. With receipt two durable and receipt one
missing, incorrectly using the maximum retires result one and loses
its exact answer. A contiguous frontier preserves both; the selective
interface preserves one and returns a terminal status for two. RIFL
already discusses finer reclamation. This is a measured conditional
comparison to its contiguous representation, not novelty of selective
acknowledgement or an architectural advance over an equivalently
typed selective implementation.

\paragraph{Preservation and its boundary.}
Fix the permitted questions and the result interpretation. For a live
unacknowledged key ask for its exact result; for an acknowledged key
ask whether this retry can safely terminate without a new effect. Under
the latter question a retained exact result and a qualified terminal
record have the same interpretation in this fixture. There is no
such equality for a consumer that still asks the server for the exact
acknowledged payload. Lean constructs identity/composition for
interfaces with a fixed allowed family of partial queries. It proves
that every certified map and any composite reflect those answers, and
that erasure cannot reflect an allowed exact query on which it changes
the answer to undefined. This is the fixed-query part of the
\href{https://github.com/eternal-november/eos-research-programmes/pull/693}{archived residual-profile application};
it does not obtain the receipt authority, field dynamics, or a lift
for changing observers or rights. The SQLite trace checks the concrete
answer equivalences under the stated, fixed premises.

\paragraph{Matched size calculation.}
With the horizon, identity and basis preinstalled, charge a one-byte
frontier, $w$ bytes per live outcome, and $b$ additional mask bytes.
If $s$ of the $n$ nonprefix positions have independently qualified
retirements, the corresponding migration representations use
$1+wn$ and $1+b+w(n-s)$. Selective retirement is strictly smaller
exactly when $ws>b$. With only receipt two retired and one-byte mask,
four-byte results make the checked sizes nine and six. With the
existing scope-qualified one-byte row references the checked sizes are
three and three: the mask uses the entire saving. For $k$ independent
observable retirement bits beyond a fixed frontier there are $2^k$
answer profiles. A one-byte exact fixed-width summary can represent
eight such bits but not nine. The proof is by querying the individual
memberships; the small enumeration checks both boundaries.
The experiment counts the migration status bytes only. It shares
the immutable physical prefix (including the row catalog) across
arms and does not charge transmission of the incoming acknowledgements.
Different availability, wire latency or audit rights require a new comparison.
