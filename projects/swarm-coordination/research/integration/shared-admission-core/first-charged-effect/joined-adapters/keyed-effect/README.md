# Keyed physical effect under a changed recipient

Run the offline bundle with Python 3, NumPy, SQLite, Git and C++17:

    python3 -B journal_effect.py | cmp - REPLAY_JOURNAL_FINAL2.txt

From a checkout use `--source`, `--warehouse`, and `--support` as in the
[shared selector](../../README.md) and [joined adapter](../README.md).
The worker is intentionally terminated after committing one native
step. There is no live network activity. The columns distinguish
credit for a historical result, native receipt, sender bytes and
the exact returned record. Policy 0 is the scoped common selector,
1 the exact direct selector, 2 the position-only admission guard,
and 3 the radio-only admission guard.
