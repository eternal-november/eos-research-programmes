# Effect-owned guarded append

The adapter revalidates the live debit and exact FIFO prefix under the native dispatch mutex before publishing the old report. It admits all 360 feasible cases in the declared envelope. A stale snapshot and the assumption of one charge per queued datagram each fail controls. Future appends do not affect the prefix; endpoint expansion and arbitrary insertions are not covered.

- [Statement, guards, costs and comparison](Guarded_Append.tex)
- `Append.lean`: arithmetic and finite-prefix transport; audited with Lean 4.35.0 and Mathlib.
- Pin source files from `SOURCE.tsv` (path, repository, ref, source path, Git blob) into INPUT. Run `sh replay.sh INPUT > actual.json`, then `cmp expected.json actual.json`. Requires C++17, Python 3 and Git. The output commits to the entire trace table by SHA-256.

The receipt is actual selected simulator output; the appointment, fallback, endpoint envelope and workload are authored. Same-information direct formula ties. No field or independent mission result.
