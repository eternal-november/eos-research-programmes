\paragraph{Audit.}
This is an executable development result for the finite I1 admission stack,
with one fixed receiving cut, action menu, and set of deadlines and carried
duties. It supplies the \emph{affected history fibers} to the named-fiber checker
from the preceding result. It does not certify the physical completeness of
a source fragment or trust a self-reported timestamp. A civil actor still
needs a qualified edit by the receiving cut; no result authorizes changing
an act already issued. Native packet and warehouse sources remain pinned.
The rule combining them, the alternatives, and the revision authority are
authored for this model, not recorded simultaneous field faults.

\paragraph{Source law.}
Let $R_r$ and $D_d$ be finite complete sets of projected radio and ongoing-duty
states for identifiers $r$ and $d$. For a stable history name $i$, a link
relation $L_i$ lists exactly the identifier pairs which the declared model
allows together. This is where shared causes, aliases, or route changes can
rule combinations in or out. The present kernel assumes there is no additional
dependence \emph{inside} a listed pair:
\[
H_i= \bigcup_{(r,d)\in L_i} R_r\times D_d .
\]
If there is such dependence, give it its own key or an additional joining
condition; composing the marginals alone would fail. Fragment values must
include every distinction read by the receiving interpreter; here, those
include sender/receiver resource sharing, receipt loss/freshness, the
exact old lane clearance outcomes, and the need for an early consumer.
Multiple links yielding identical projected rows are immaterial to a fixed
recipient's universal test, but links themselves are retained for later
revision. Authoritative deletion is typed separately from an empty or
missing fragment, which cannot certify that an active joint history vanished.

\paragraph{Exact impact enumeration.}
For a batch with changed radio keys $E_R$, duty keys $E_D$, and link names
$E_L$, take
\[
C=E_L\ \cup\ \{i: L_i\text{ mentions a key in }E_R\text{ or }E_D\}.
\]
The reverse incidence lookup uses the old links. It is complete even for
new incidence: a newly incident name must already lie in $E_L$.
Outside $C$, both the links and every used source set are unchanged.
Inside $C$, rebuild the complete old and new projected sets together with
their compatible endpoints, then compare. Thus the resulting patch has
the exact names with changed projected supports. Missing endpoints for
live links reject the whole batch. On install, revise incidence links even
when the outgoing recipient patch is empty. Otherwise a later source edit
can be missed. Versions are strictly increasing; the offline compiler,
the receiving-cut check, and commit must be serialized by the caller.
The compiler alone neither verifies edit credentials nor implements an
atomic distributed protocol.

The candidate stage visits edited keys and their old posting lists.
Exact projection comparison additionally visits each changed link candidate
and the products of possible variants in its old and proposed links.
There is no locality claim when a common cause has wide incidence.
The verifier downstream checks only rows in changed projected fibers.
These costs do not include deriving the complete leaf edit or communication.

\paragraph{Two discriminating replays.}
In the first, a new pair joins the old feasible histories rather than
replacing them. It combines common airtime with a still-live old job that
needs an early receipt. Late packing misses the old clearance deadline;
ordinary split breaks the shared budget. The old support and old favorable
witnesses persist. Yet the receiver, with no new branch-distinguishing
observation, must narrow \texttt{pack, split, spare} to \texttt{spare}.
A check that only verifies its old successful witnesses approves both
unsafe ordinary choices. Here the old #603 plant handles native message
and physical clearance effects; the support edit does not rewrite
physical history.

In the second, a route switches between equal radio fragments. The supported
projected rows and all current decisions remain identical, so the outgoing
patch is correctly empty. A later edit to the new route source now makes
\texttt{split} infeasible. Keeping the old incidence map would miss it.
A separate duplicate-link test drops one equal source and then widens the
other; neither deduplication at the receiver nor old successful witnesses
are an adequate source dependency index.

\paragraph{Evidence and baseline.}
The run verifies 3072 pinned radio cases and obtains 20 warehouse source
traces. The local compiler matches a full rerun of the join and fresh
same-information admission for all 3600 enumerated two-by-two batch edits.
A 2048-name fixture with one incident history touches one instead of 2048
names and makes four downstream row/action checks. A direct indexed
incremental join given the same complete factorization and old incidence
can do the same work; this comparison does not establish a speed advantage
over such a planner. The structural gain is a justified locality boundary
and a runnable way to obtain the complete patch required by the previous
checker. No claim of independent mission acceptance or architecture-wide
fault coverage is made.
