\paragraph{Outcome.}
One unchanged admission checker can consume both a native radio
prefix whose earlier message never arrives and a native warehouse
prefix that has unloaded but not yet cleared a bay. For the radio
case, no callback does not mean no debit; for the warehouse case,
no load does not mean space is released. Collapsing either
distinction can approve the wrong \emph{locally chosen} next
operation, even if the other layer is modeled exactly. One
authored positive recovery shifts a previously owed report to
an authorized backup and retains both required side effects.
The precise interface is scoped to the source formats below, not
evidence of independent mission or whole-stack acceptance.

\paragraph{Boundary and inputs.}
Reuse the \href{https://github.com/eternal-november/eos-research-programmes/pull/595}{shared
all-pay kernel}, pinned byte-for-byte. It checks every use of
an event before depositing the uses of that event. That is a
fine strict prospective guard for a required operation that must
complete. It would be wrong to summarize the \emph{past} failed
attempt as a transaction whose no-delivery result implies no
changes. The new compiler does not change the interpreter to
pretend that it models partial commit automatically.

In each held-in world a known finite episode can contain no earlier
probe, an erased probe, an actually delivered probe, or a probe
whose actual receiver rejects it after a different sender filled
that receive row. The optional earlier attempts are authorized
by the fixture, not counted as required paid work. The native
broker and exact rolling-window code run in the selected
headless source tree with common capacity and fixed order.
Record the actual seed receive debit, the delta in the probe's
sender ledger, the actual receiver delta and a separately
counted native callback. The matched upstream native prefix
is literally replayed for each alternative; its outputs
are verified to agree before the later option.
The adapter emits the seed debit, actual transmit debit and
actual receive debit as separate ordered events when present.
It does not invent a reception from a debit and does not emit
a rejecting prospective resource check to stand in for past
partial progress. All native source hashes and this kernel
hash are recorded in the manifest.

The second source uses actual RWARE grid coordinates and load flag
on each step. The projected clearance flag is valid exactly after
the named old carrier unloads and reaches the named exit; the
unload fact can precede that event and is retained separately.
The source interpretation removes facts when their represented
physical condition ceases to apply. A second carrier has a disjoint
actual movement through tick 4. The receiver or sender catalogue,
clock, authority conditional on clearance, and compatibility keys
between the two plants are authored; they are not upstream
contracts inferred from the native runs. Space/time/authority keys
are stipulated through the fixed short horizon.
An audited complete set of paired fragments is required; the
existing join rejects missing family labels rather than treating
them as unreachable. It is not a license to join independent
successful histories on loose outcome equality.

\paragraph{Joint choices and locally available evidence.}
The dispatcher can choose the old needed report on its existing
sender at tick 4, the authorized backup at tick 4, or the old
sender at tick 6. The old report can use either separate or
shared physical receive identity depending on the declared
case, held fixed within it. The three choices independently
pay only if the \emph{same} old physical clearance and role
hold for that operation and the native callback occurs by due.
Time within the radio source is a quarter-second per integer tick;
a tick-0 debit is still active at 4. The positive envelope
permits a true record of initial heading before decision tick 1.
The optional early radio observation is only whether a callback
has arrived, not why it has not or how much was consumed.
Stutter, when allowed by the stated deployment, remains hidden.
A no-stutter variant narrows the installed command tape before
selection; it is not advance knowledge of random failure.
Proof-side explicit joint histories are not inputs given to the
implemented policy. Two independent obligations are measured:
actual radio callback on a separate endpoint and actual warehouse
movement to the separate cell.

The core folds each paired row with its normal all-pay test.
A prefix ledger entry carries exactly the spending the native source
made before the selected action, including authorized unsuccessful
attempts. This is exact at the option cut because ledger keys, event
order, expiry convention and actual phase deltas match; no option
moves an earlier debit. Warehouse applicability is an ordinary
dependent fact, not a success code substituting for position.
The event projection may decline a future option, but past
effectful failure remains in its prefix. Under the stable
and reliable option routes selected here, all required option
debits pass the strict check iff the corresponding native effect
can be received. In this particular trace family, the exact
native-capacity and warehouse test agree with the core in
every world and with the intersection for each reported local
view. Unknown or unmatched future branches are not left out
as a means to prove progress.

\paragraph{Two independent obstructions to coarse composition.}
Use cap five, three-byte reports, the separate result receiver
and prior observable silence. If the early tape actually
clears the bay before the tight deadline, the earlier probe
could have been absent, erased after a send, or receive-rejected.
The isolated world of no attempt would allow the primary
sender, but at least one compatible world has an active
three-byte send. The scoped backup has its own admissible
sender and the separate receiver and remains available across
all these compatible worlds. The exact robust menu is only
the backup for this local evidence cell. A negative control
that treats every no-callback prefix as zero transmit effect
instead also approves the primary sender. On the native
erased history that extra choice fails to deliver the old duty;
the earlier transmitter's real debit persists. This control
already uses the real positive physical clearance and
does not get the result by confusing clocks.

Conversely hold the raw radio interpretation exact and use a
valid absence-of-contention case with the later departure.
Unloading at tick 3 leaves the space occupied at the proposed
early cut. A second negative control turning set-down into
clearance authorizes the early operation, although its native
warehouse premise is false. The radio \emph{could} deliver if
forced in that model, but it is then not the lawful required
effect. A truly infeasible view at the tight deadline is
explicitly left without any qualifying option, not reported as
an architecture success. In the looser horizon a late slot
can be selected without canceling the independent side duties.
The one-source reductions are tested with the other layer
unmodified.

\paragraph{Audit and comparison.}
The clean replay produces 648 native radio tests, 15,552
joint world/option checks, and 1,728 local cells. Actual native
terminal outcomes, deadline and physical guard membership form a
separate direct factored oracle, not an implementation of the
core's event interpreter; all exact decisions agree.
Suppressing unsuccessful-arrival transmit debits falsely approves
312 world-level choices and 52 local-view choices. Collapsing
physical clearance falsely approves 3,392 world-level and 912
local-view choices. These are finite counts, not risk probabilities.
Three Lean checks cover the failed-callback quotient and the
independent necessary source premises, not code extraction.
The processed earlier failed source branch is not a virtual
dropped obligation; it was never a required delivery.
This is a held-in producer/consumer fit for the declared trace
language with an unchanged reusable kernel. Strongest operational
architectural advantage, a process that certifies all allowed native
future alternatives under later faults, physical motion parameters,
independently selected compound transfer, and 110 inventory
dispositions remain separate.
