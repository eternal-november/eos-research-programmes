# Consuming-cut admission under an intervening native writer

[Scope, result and boundary](Consuming_Cut.tex). This follow-up to the live
clearance replay distinguishes an honest preflight from an admission check
serialized with its effect. The warehouse return, broker debits and callbacks
are executed by the already-pinned simulator fixtures, not supplied as a
possible-futures table. The wrapper supplies the joint cut.

Materialize the destination column in `SOURCE.tsv` from the recorded
repository, revision and source path. Then run:

    sh replay.sh /path/to/materialized-sources | cmp expected.json -

Use a shell with pipefail, Python 3.10+, NumPy and C++17. The replay verifies
each input's Git blob hash. `Commit_Footprint.lean` uses Mathlib with Lean
4.35.0.
