# Source-held clearance pledge with explicit terminal evidence

[Scope, proof, and results](Release_On_Terminal.tex). A source-side
guard protects the bay across a blackout while independent work continues.
An authenticated terminal result, not merely requesting cancellation,
allows the old motion to resume. The interface is an authored adapter over
the pinned native warehouse and broker fixtures.

Materialize the exact inputs in `SOURCE.tsv`, then run with a shell with
pipefail, Python 3.10+, NumPy and C++17:

    sh replay.sh /path/to/materialized-sources | cmp expected.json -

`Pledge_Cut.lean` checks the Boolean protection invariant and failure
witnesses in Lean 4.35.0 with Mathlib.
