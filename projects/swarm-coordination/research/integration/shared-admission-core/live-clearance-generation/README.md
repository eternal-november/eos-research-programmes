# Live admission across reentry and scope renewal

[Proof and comparison](Live_Clearance_And_Epoch.tex). A running wrapper
reads current native motion and the radio's real active rows, then
executes the chosen old candidate. Actual clearance, delivered permission
and scope lifetime are independently checked. The unchanged core and
the matched direct local controller tie.

Materialize SOURCE.tsv, then run:

    sh replay.sh /path/to/upstream | cmp expected.json -

Python 3.10+, NumPy, C++17. Guarded_Reuse.lean checks the small proof
kernel. Authored control/fault envelope and bridge; not an independent
or field result.

The [consuming-cut follow-up](consuming-cut/) tests a real return or
broker debit interposed between preflight and send.

The [source-step lease follow-up](source-step-lease/) checks when a remote
consuming cut does not need a fresh warehouse read.

The [source-held pledge follow-up](terminal-pledge/) trades the remote
clock bound for an effect guard, terminal evidence, and a possible wait.

The [recurring-request replay](native-recurring-request/) checks when a
current native observation cannot certify closure of the old order.

The [restartable native commit](native-atomic-commit/) implements the keyed
publication boundary for a wholly replayable simulator.
