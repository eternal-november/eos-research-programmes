# Joint closure, failover, and reuse of the backup window

[Scope, finite service proof and comparison](Joint_Closure.tex).
One continuous civil logistics execution combines an actual process
restart, an unresolved old authority, source motion and native shared
radio debits. A shared interruption can mask receipt of a completed
old job while making the primary route unusable; the backup then
retries the same intent. A genuine matching receipt is necessary
before the controller gives the backup window to an optional job.

Materialize `SOURCE.tsv`, then use Python 3.10+, NumPy, SQLite WAL and
C++17:

    set -o pipefail
    sh replay.sh /path/to/materialized-sources | cmp expected.json -

`Joint_Admission.lean` checks the robust capacity law in Lean
4.35.0 with Mathlib. Comparison is tied with the same-information direct
rule. There is no independent mission, hardware, strongest-prior
advancement or inventory acceptance claim.
