# Durable remote effect, delivered terminal evidence, and guarded return

[Proof, comparative replay, and limits](Durable_Release.tex).
Freshly restarted native warehouse workers issue a keyed committed
result. Real broker callbacks carry the named paid result to release
a protected return in a second warehouse fixture. A failed delivery
still spends its sender budget; the other traffic and motion continue.

Materialize the exact pinned paths in `SOURCE.tsv`, then run with
Python 3.10+, NumPy, SQLite WAL and C++17 using a shell with pipefail:

    sh replay.sh /path/to/materialized-sources | cmp expected.json -
