# Charged receipt, hidden application feedback

[Native source test and limits](Hidden_Receipt.tex). If the scout's native receive window already paid for a current result, retransmitting it on application silence can starve the independent old result. A typed local mailbox recovers the arrived result without repeating radio work. A stale receipt with identical charge is not enough.

Materialize the parent competing-receipt replay inputs, then place this extension alongside them. Run `sh replay_hidden.sh | cmp expected_hidden.txt -`. The verified Space archive contains exact sources and both benchmark packages. The ingress/application split and timing are authored controls, not evidence of a particular stock middleware defect or independent mission.
