\paragraph{Audit.}
The joined native replay of PR~719 initially required a
maintenance notice identifying the current forwarding relay.
That is a stronger authority condition than the old result
query needs when the consumer only wants a confirmed
historical outcome. This follow-up compares that condition with
two named read-only delegates. It changes forwarding permission,
not the registered writer or current ownership of physical work.
The simulator has a preinstalled trusted identity and result
scope; this is not a network authentication mechanism.

\paragraph{Scoped alternative.}
The same actual scorer return produces the old exact archive,
and the same native callbacks create each relay's copy before
unrelated scoring closes the old lookup. Each named relay may
forward that exact historical result if it still holds it.
The scout accepts the first matching record and treats a
second matching receipt as redundant, not as a second scoring
operation. Scope, delivered bytes, source label, and actual
copy remain distinct. The final release in this fixture
requires that old result and a separately modeled safe exit.
The forwarded archive cannot supply present custody or the
right to apply a missing effect. If another action needs
a true current delegate notice, it may not omit it merely
because this historical query can.

\paragraph{Matched cuts.}
With two actual copies staged and the primary removed, a dropped
designation prevents the current-supplier policy from finishing
by 8, even though a valid reserve copy exists. The
preauthorized read-only reserve confirms at 5 and egresses
at 8. No designation arrives in this arm. This also frees
the three receive bytes that used to block a three-byte
result. Before primary loss, both short read-only replies
can arrive, spending four receipt bytes at the scout
instead of the selected policy's five total bytes including
the notice. The wider read set may cost an extra sender
attempt. It pays the same preparation cost; it does not
recreate a lost copy, an invalid record, or missing sender
airtime. A previously charged reserve still cannot send
its result at the required cut after the primary is removed.

\paragraph{Comparison and residual.}
The explicit read-only authority is allowed in the corresponding
direct reference and cannot be silently attributed to a
stock current-supplier policy. The direct accounting and native
producer/controller execution agree on 576 paired case inputs
across modes and controls, with independent native scorer work
and the separate native radio work retained. These are authored
control counts, not measured reliability. The read-only
optimization is common in scope, with no advantage asserted
over typed replication given the same evidence and rights.
No physical custody, actual exit trajectory, independent
mission, or broader contract closure is established.
