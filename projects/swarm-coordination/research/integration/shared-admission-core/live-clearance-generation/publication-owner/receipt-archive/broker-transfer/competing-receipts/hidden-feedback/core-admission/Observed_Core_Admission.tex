\paragraph{Audit.}
The two-receipt fixture supplies a useful check on the
common one-cut admission interpreter. The unchanged
interpreter selects a real next action before the native
broker executes it. The source includes the actual selected
scorer and its result-producing sequence, actual staged
relay copies, original lookup closure and a receive/app
visibility split. All topology, deadline and source
certification seams are authored. This is held-in development.

\paragraph{What the controller can see.}
At the cut the controller receives one of three typed
observations. A previously deposited current result can
have reached the application, or been recovered from
the scoped mailbox. A distinct certificate can confirm
that the primary was actually removed before its first
send: only that earlier membership event certifies no
prior charge in this fixture, not merely seeing that
the primary is absent now. The remaining observation
is silence with no such certificate. It is shared by
histories with zero prior charge and histories with an
already charged but unconfirmed result. The controller
does not read the evaluator's raw receive ledger or
the hidden world label to choose its action. Positive
mail is recovered from the actual inbound record; the
early removal certificate uses the recorded native member
removal in this test and an explicit delivery switch.

\paragraph{Shared rule and actual execution.}
Export the declared admissible histories to the common
event interpreter with inclusive send and receive use,
separate old duties and observation-based grouping.
A blocked receiver can still charge sender capacity.
An old result adds its application duty only when
qualified. The adapter does not identify the actual
history for the checker. The same rule admits finishing
only \(B\) as a continuation of the full objective when
\(A\) is already positively known. It admits \(Q\) then
\(B\) after a genuine pre-attempt removal certificate.
In the silence cell no uniform full-service continuation
satisfies the declared envelope. Checking the explicit
reduced safety/service objective separately permits \(B\)
alone; that is recorded as loss of \(A\)'s timely
confirmation, not counted as a full pass.
The resulting selected order is passed to the still
waiting native broker, which executes those actual
operations and observes independent work.

\paragraph{Scope of the verification.}
In the fixture \(B\) succeeds in all 16 executions.
The full service result succeeds only in the
admitted cells. The stripped case where no actual charge
was made can still deliver both under hindsight, but
that does not license it from the ambiguous view.
Control authors explicitly restrict the available copy
and authority/time horizon. The adapter uses a declared
finite history support, not inferred exhaustiveness
of stock ROS or real radio networks. The unchanged core
checks candidate effect traces rather than producing a
complete synthesis from raw source. This is an
executed connection between a shared rule and the
selected source, not complete independent I1 or I2
acceptance, nor an advantage over the same typed direct rule.
