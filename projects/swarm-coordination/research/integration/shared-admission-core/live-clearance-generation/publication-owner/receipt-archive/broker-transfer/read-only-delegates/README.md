# Historical read-only delegates

[Argument and controls](Read_Only_Delegates.tex). Either preauthorized holder can deliver the same exact archived result after a relay failure, without needing to know the current writer. This changes neither the writer permit nor evidence of current physical work.

The verified Space archive contains the complete parent plus this package. For a Git replay, materialize the parent broker-transfer inputs and `expected.txt` as `expected_joined.txt`; place this package alongside them. Run `sh replay_readonly.sh | cmp expected_readonly.txt -`. The native pipeline keeps the old source and real broker callbacks; the delegated read scope and exit timing are explicitly authored controls.
