Fetch each row of SOURCE.tsv as a Git blob and write it to the first-column path under up/. Columns are destination, repository, commit, source path and Git blob hash. Requires Python 3, NumPy, NetworkX, SQLite, patch, Git and a C++17 compiler. Verify with:

    sh run.sh up | cmp expected.json -

The side count and old return value are simulator outcomes. The audit probability is policy feasibility on source-backed reader views, not an observed financial or audit result. The radio tape fields are tick, sender, destination, bytes attempted, bytes charged, and callback received. Simultaneous success requires the old application as well as the timely qualified cue.

Across 90 cases, each run in both arms: four bytes of spare budget suffice for either framing; three leave the separate cue undelivered if the old duty is protected; two cannot fit the old preparation even with a valid packed decode. A late but delivered separate cue at four bytes does not revise the audit cut. Erasure is imposed on the cue-bearing frame, not claimed to be an invariant physical failure across encodings.
