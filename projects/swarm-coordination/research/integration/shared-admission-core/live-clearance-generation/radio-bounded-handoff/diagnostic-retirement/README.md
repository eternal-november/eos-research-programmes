# Retire a diagnostic receiver before the attempt is charged

Read Retirement_Before_Charge.tex for the source scope, proof, and comparisons. This tests a normal, authorized receiver exit in a pinned civil simulator fixture. The vehicle's old operation remains independently keyed and fenced.

Fetch the exact blobs in SOURCE.tsv under up/. Each row gives destination, repository, commit, Git source path and blob SHA. Requires Git, Python 3, NumPy, NetworkX, SQLite, and a C++17 compiler. Verify from this directory:

    sh run.sh up | cmp expected.json -

The broker tape is paired with the station's actual cached result or refusal. The optional second report is significant only when comparing the two-copy arms (1 fixed backup, 2 qualified choice, 3 fixed primary, 4 attempt primary then react, 5 queue both old sends before one dispatch); arm 0 is the single-copy transport boundary. A received callback, successful old result, and ordinary unrelated job remain separate outputs.

Case tapes list primary prior and post-probe debit, primary final meter, old receiver meter, pending and side counts, old delivery, remaining binding, selected/actual sender, optional report, backup meter, and old attempts. A meter sampled without a new attempt can still carry expired rows; the oracle purges only the meter actually consumed by a send.
