\title{Recurring warehouse requests do not certify closure of a named obligation}

\maketitle

\paragraph{Scope.}
The previous terminal pledge needs an application closure result that
outlives restart. The earlier
\href{https://github.com/eternal-november/eos-research-programmes/pull/606}{station-gate replay}
used a durable effect-local key. This probe asks whether the physical source
already provides equivalent evidence. The effect counted is a native
first-stage station acceptance credit for the requested shelf, rather
than an acknowledgment, total reward, irreversible parcel delivery, or
receipt at a different application. A scoped old order should get one
credit, and a separately authorized later order for the same shelf should
not be suppressed. The old request's receipt is lost and prior reward
and command histories are unavailable to the restarting actor. The
fixture supplies the application keys; the stock warehouse takes no key.

\paragraph{Observed obstruction.}
The pinned step replaces the requested shelf on a native station arrival.
Returning it home and setting it down resets the carrier's
\texttt{has\_delivered} flag. With two shelves and one active request, the
new request choice is unique, so two completed deliveries take the queue
from A through B back to A. Both shelves and the carrier then return to
their original positions and headings. In the paired execution the
carrier waits instead of doing those deliveries. Pad both histories to
the same tick, with zero last reward. Across twenty pairs, the exact
stock dictionary observations from both robots agree (four sensor
radii), even when augmented with the global occupancy grid, all shelf
identities and poses, the ordered native request IDs, both agents'
current and previous poses/actions and delivery flags, and the common
tick. In a witness the two stations credits happen at ticks 5 and 27
and the set-down credits at ticks 10 and 33; the restart is at tick 80.
The full native past or privileged inactivity counter could distinguish
these particular histories: the reported counter values differ. This is
not a claim that the entire internal state or logged history agrees.

Separately, the identical native prefix including its rewards can be
lifted into two legally assigned application histories. The first
acceptance of A may belong to key 7 or to an independently authorized
key 6; B belongs to key 9 in both. The current recovered intent is
key 7. Those are authored assignment histories with different old
authorizations, not additional information present in RWARE. Native
observations, reward trace and inactive tick agree because the input
commands agree. The exact application key, once discarded, is not
recoverable even from that native trace in this lifted setting.

\paragraph{Decision and positive control.}
The admitted old retry must be issued in the unpaid history and withheld
in the paid one. Any decision of the common view takes the same branch;
if a retry has probability $p$, the failure probabilities are $1-p$
in the unpaid history and $p$ in the paid history. A durable keyed
completion fact before the decision allows exact service; it must
distinguish two authorized uses of A. In the positive control the replay
supplies the correct keyed fact from the completed history. The
alternative actions then execute real native moves and station events.
Across forty runs per arm, this gives exactly one old credit and one
new credit in all cases. Blind replay duplicates the old credit in
twenty cases. Permanently withholding A to avoid a duplicate misses all
forty new orders and twenty old ones. A direct calculation on the
same keyed fact makes the same binary decision. The replay does not
establish how a native application atomically records the fact or
makes it available; it confirms why a current-state reconstruction or
shelf-identity tombstone is not a substitute. Lean checks the decision
obstruction and separate-key update, not the simulator code.

\paragraph{Next discriminating check.}
For a concrete implementation, include the crash after the native station
effect but before an external adapter can durably record its key.
If a passive reporter neither controls admission nor can join a
recoverable event with the key, it cannot provide the required fence.
RIFL-style keyed terminality remains the same-information positive
baseline when that atomic interface is available. No independent test,
end-to-end architecture disposition, comparative stack win or field
robot result is claimed.
