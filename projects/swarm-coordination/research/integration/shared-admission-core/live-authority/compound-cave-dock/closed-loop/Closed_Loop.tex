\paragraph{What changed.}
The parent replay executes the direct algorithm and checks its outcome
against the common admission checker. This variant instead stops at
the next native transmission cut and sends the local inputs to that
checker. The actual later native transmission uses its reply.
The exact parent program is verified by Git blob hash and a marked
execution hook is inserted. No native broker or radio source body is
edited. The same admissible timing, available observation, and trusted
lease premise from the parent study apply.

\paragraph{What reaches the controller.}
The interface exports Q's actual addressed receipt tape, modeled payload
length and known cap, plus an instrumented read of Q's own still-live
native transmit debit. This is an explicit host read, not a claim that
an uninstrumented robot or protocol already exposes it.
The two worlds of receiving authority are not passed as the actual
branch. They are represented inside the checker under the declared
grant law. No remote occupancy, remote route outcome, fault flag, or
inspection receiver result is supplied to the controller. The side
transmission's completion is an earlier proof obligation from the
pinned radio run and bounds, not something inferred from a debit.
The native trace records its callback after the fact for evaluation.

\paragraph{Check.}
The C++ wrapper synchronizes with an isolated Python process at the
declared cut. Python invokes the exact unchanged admission core and
returns one authorized destination or refusal. The independently
written local rule, with the same tape and own debit, returns the same
choice in all 1,632 closed-loop checks. In 576 cases both owed reports
are credited; where the new sender action is refused the independent
report still pays. Sixteen exact-cap switched cases with a late
historical receipt use S and settle both. Subject to the same terminal
hold premise, this makes the checker causal in the executable fixture
rather than just a trace adjudicator.
Wall-clock process latency, hardware timing and the independent
mission are not evaluated. The actual outcome here is the expected
application callback, not physical arrival or field settlement.

\paragraph{Replay.}
Run \texttt{python3 online.py} in the complete offline bundle. From
a checkout pass the parent study's geometry and native source
directories to \texttt{--geom} and \texttt{--source}.
