\paragraph{Scope and result.}
This is a held-in I1/L1--L3 extension of the
\href{https://github.com/eternal-november/eos-research-programmes/pull/799}{compound cave family}.
A live logical dock can be bound to its actual recipient after the
courier's last local grant. Doing so does not by itself preserve
exactly-once settlement across a restart. Carrying the old keyed
settlement fact restores the safety condition but creates a new
destination debit. In the pinned simulator, that debit can cause
the otherwise lawful retry to fail. A one-byte scoped format
restores the earlier capacity envelope for a single pre-established
report key. The direct implementation using the same directory,
scope, journal and encoding has the same decisions; the tested
controls are not a comparison with a full deployed recovery stack.

\paragraph{Matched cold journals and actual effect.}
The pinned native SubT broker has two historical paths for the
same named old report. An older send at \(t=-2\) reaches R in
one and not in the other, because its physical receiving pose
differs at that cut. The same later direct attempt at time zero
is charged and fails in both. Q retains the archival copy, not the
old completion fact; the old callback does not send it a completion
acknowledgment. Q's authorizing receipt tape and own debit are
identical across that initial pair.
The reference credit is a SQLite insertion for a key,
not a counter of radio callbacks. The hosted station opens and
closes its named file on each operation. R and S have separate
files. This tests reconstruction from disk-backed commits, not a
power failure, independent scheduler, or crash at every commit point.
It reuses the named-effect distinction from
\href{https://github.com/eternal-november/eos-research-programmes/pull/640}{the prior restart study};
the actual SQLite and radio operations in this replay are new.

\paragraph{What is bound by whom.}
R initially owns the logical \texttt{Dock} endpoint. In the early
or late move arm it leaves the modeled dock scope while remaining
within native radio range. Its local cut retires its binding
and snapshots the keyed fact after the last permitted R credit.
It sends that fact to S using the actual R-to-S broker on the same
timeline. Only the real S receive callback can import the result
and install its singleton binding. There is no independent read
of R's database from S. If transfer was omitted, the endpoint
has no route, and no second credit or fabricated recovery appears.
The control host explicitly has authority to update the directory,
co-located with S's transfer callback. This is a declared serial
fixture adapter, not a claim about atomic stock membership
updates across a network or multiple writers. The old
site stays departed through consumption; a later re-entry or
unfenced writer could invalidate an export.

The courier uses its earlier grant for the logical dock and
later sends the same request once, without learning whether
R or S ultimately accepts it. The selected native dispatch resolves
the endpoint after installation and charges the actual link.
R or S returns the first effect or a replay result \emph{locally}
at the application boundary. No return acknowledgment to Q
is claimed in this window. A comparator pinning the grant to
the physical destination sends to old R after a late move,
whereas the logical address can use S without a new Q message.
This differs from the hand-authored alias change in
\href{https://github.com/eternal-november/eos-research-programmes/pull/624}{the earlier queue replay}:
the late binding here is caused by R's local predicate and a
real transfer callback, and the binding also consumes a keyed
settlement fact.

\paragraph{Same-history resource and safety law.}
Q has already sent the side report of size \(b\), still live in
its transmit window. The old retry costs \(a\). When S takes over,
its receive window also contains \(h\) bytes from the ownership
and settlement transfer. By the pinned implementation, it is
the consuming sender Q's cap \(c\) against which both the
Q transmit and S receive totals are tested. The two necessary
and sufficient byte inequalities for arrival, conditional on
the adopted scope, link and no other live debits, are therefore
\[
           b+a\le c,\qquad h+a\le c,
   \qquad\text{equivalently } a+\max\{b,h\}\le c.
\]
The previous one-byte handoff remains a one-byte handoff
when two symbols jointly select the permitted transfer and
the old paid/unpaid Boolean. An explicit transfer opcode followed
by the Boolean uses two transmitted bytes instead.
At \(a=3,b=1,c=4\) the uncompressed proof reaches S and installs
the rightful binding, but the later report cannot reach it.
The compact form restores service without increasing either
budget. It assumes one prebound report key, role and handoff
epoch. It is not a compression claim for arbitrary logs,
identities or key counts. If the proof debit has already expired,
this particular byte obstruction is absent.

Precisely one global credit follows from importing the true
old fact and rerunning the same key; an imported paid fact is
a replay, an imported unpaid fact allows one new credit.
Marking the key paid by default loses the pending history;
marking it unpaid duplicates the settled one. More generally,
correctly answering the first-or-replay operation at every
permitted key requires agreement of the two profiles at all
those keys, not equality of values outside the consumer scope.
The receipt and the fixed bound authorizing its reuse are
both load-bearing.

\paragraph{Checks and benchmark boundary.}
The native replay includes 17,280 traces, with 8,640
matched Q tapes across the two prior-settlement histories.
Of 960 predeclared positive fixtures per arm, the packed
scheme preserves one credit and actual local reconciliation
in all 960; the two-byte mode yields 928 local reconciliations
and 944 net one-credit outcomes. Some old work had already
paid before a later failed retry, so these counts are not
the same outcome. An arm ignoring the imported fact
creates duplicate credits. The independent report pays
in every tested case. The frozen previous Python admission
checker does not yet drive this new binding adapter; this
artifact tests native effects against a separately checked
exact law. Lean checks the byte inequality and keyed
settlement abstraction, not SQLite, C++ or field conditions.
No I1 acceptance, I2 egress proof, independent mission or
global computational advantage is asserted.
