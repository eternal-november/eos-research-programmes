\paragraph{Declared resources and observation.}
The parent gate-queue development fixture installs a mode
appointment only when the certified source history bounds the
courier's actual last contact and prevents late re-entry. This
variant tests a different release interface: wait for a received
one-byte physical-clearance notice from Q before changing the
interlock, as a completion-driven dependency would. Q also owes
a distinct indivisible four-byte follow-up inspection report to
a separate receiving application at that cut. Both sends originate
at Q. These fixed sizes, authorized recipients, and the exact
slot law are the comparison scope. This is not a test of all
communication or report compression schemes.

To obtain the positions at the qualifying cut and the two later
opportunities, first run the actual native acquisition and reply
from the enlarged-envelope parent, then sample the tested
stop-to-stop egress at its positioned time on that same clock.
No received notice is synthesized from a global source label.
Compile the selected pinned SubT broker and actual visibility
lookup and use Q's sampled positions as pose supplier. The late
radio window is reconstructed empty because all earlier native
radio uses ended more than one second before this cut. This
would be unsound if earlier report traffic survived in the new
window. The resulting calculation is still a staged native
radio replay wrapped around modeled geometry and a specified
clearance observer, not a dynamics trace.

Two fixed programs at separate named radio endpoints in the
connected hub receive the notice and report, respectively. The
local gate desk's access to the interlock is an assumed actuator
interface, not demonstrated wiring. We separately keep the
original more remote placements as a negative RF control. The
mesh and route evidence alone does not prove transmission
eligibility to either program.

\paragraph{Two obligations and exact slots under the radio-only gate.}
Both messages can physically arrive in the confirmed endpoint
placement. With cap four bytes per trailing one-second window,
they cannot both be sent at the qualifying slot \(t\).
Sending the four-byte report first credits it at \(t\),
but the desk receives the clearance notice only at
\(t+17/16\) on the chosen lattice. The opposite order delays
the report by the same amount. At \(t+1\) the first debit is
still present in both native cases. In particular, checking
nominal time without the strict expiration semantics changes
the service frontier. At cap five, both callbacks are delivered
at \(t\), with the same physical routes and distinct receive rows.

If the gate desk instead holds the valid last-contact appointment,
it can use \(t\) without an extra outgoing byte from Q. The
independent report can then still arrive at \(t\) at cap four.
The improvement is conditional on having that independently
justified appointment, a trusted clock and an interlock; using
a guessed timer in place of a required receipt is not a safe
repair. If the hold is unavailable, use the actual notice and
retain the delay or buy enough capacity. A direct controller
given the same timing proof, scope and resources ties. This
does not compare all published systems: completion-notified
execution is one applicable baseline from
\href{https://whoenig.github.io/publications/2019_RA-L_Hoenig.pdf}{H\"onig et al.},
not a claim that their implementation lacks other sensors or
all time bounds.

\paragraph{Receiver placement is a separate failure.}
With the original more remote endpoint placement, raising
the cap to five does not make both messages arrive.
For closure A both fail despite an actual Q transmit charge.
For closure B the independent report can arrive but the
clearance notice cannot reach that desk. Sending the failed
notice first under cap four still delays the independent report
by \(17/16\). This particular bad policy consumes capacity
without producing the authority it needed. Rescoping the
desk to a demonstrated contact is an actual placement
change with its own effects and cost, not an equivalence
derived from receiving a completion notice in another layout.

\paragraph{Bounded conclusion.}
The 48 native cases cover both enlarged-envelope routes,
the two earlier receipt schedules, two capacities, two endpoint
placements and three first-send rules. The finite result is a
service tradeoff at a certified physical cut, not an independent
mission, an advantage against a same-information direct design,
or performance measured on robots. Replay with
\texttt{python3 gate\_radio.py} and the pinned parent sources.
