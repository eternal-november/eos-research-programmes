\title{Checking a declared history envelope before admission}
\maketitle
\paragraph{Claim and scope.}
A reliable finite admission check needs two different premises: the export
has one accepted record for each declared history, and the record derives
the effects the original duty requires. This audit checks the existing
radio suffix-supplier and MRWS retained-class development sweeps against
separately encoded input domains and effect rules. It checks archived
selected-source execution, not fresh physical execution, independent mission
selection, completeness of either fault model, or I1 acceptance.

\paragraph{Interface.}
A versioned envelope enumerates the admitted input domain \(D\) before
execution. A certificate exporter supplies \((h,r)\) pairs, where \(h\)
names one full tested history and \(r\) carries local availability and
effect evidence. Accept an export only if the map from record occurrences
to \(D\) is bijective, then check the source-qualified effect predicate
for each record. A missing or conflicting record means unresolved
assurance, not a proof that an action is impossible, not an unreachable
history, and not necessarily a reason to stop separately justified work.
The controller still uses the old view projection: full history names
are audit inputs, never a new sensor.

\paragraph{Why the extra premise matters.}
The existing join checks equality of binding \emph{sets}. Where a binding
has several alternatives, that establishes only a nonempty fiber on
each side. With a fixed menu and local view, admission for an action is
universal over the fiber. Deleting one history preserves the binding
set if another remains, yet can turn a rejecting universal into an
accepting one: let the omitted row be the sole failing row for that
action. Conversely, if acceptance is true for every lawful history, an
exact export with source-faithful action verdicts preserves it, because
its bijection carries the universal in both directions. Completeness
but not exactness can support conservative admission when extra rows
are validated as a sound overapproximation; that requires a separately
declared rule and cannot claim exact rejection. Counts alone do not
exclude substitution. Even exact domain matching does not identify
false evidence under a sound name. Thus this complement to the
named-fiber cache does not replace its source impact premise.

\paragraph{Two source boundaries.}
In the radio sweep the producer has a mode, a delivered-or-erased
notice at its own cut, legal supplier set and a charged debit. The
consumer can prepare only on the actually received cut-local notice.
The acceptance witness is a sender-matched suffix and the cached
warehouse result at the promised tick, not a send or delivery flag
alone. Two unrelated moves remain separate. When the notice is absent
and both suppliers are licensed, dropping P makes the fixed Q action
appear admissible without changing the surviving binding label.

In MRWS the native state distinguishes initially retained carriers and
a second critical fault during the old job. The dispatcher sees the
sample only if delivered by its cut; the claimed success requires
native ordered class acceptance and exactly one order completion with
the side return still intact. Removing the B-loss row from the
no-notice cap-four decision makes the prescription to reconstruct C
but not B appear admissible. That decision fails in the omitted row.
The controls start from the original model functions; no change to
the core, predicate, receipt projection, or action is made between
complete and mutated exports.

\paragraph{Checks and residual.}
The audit checks all 48 radio and 90 warehouse history keys and their
recorded outcomes. It rejects every single-row deletion, single-row
duplication, foreign insertion and equal-count foreign substitution
(552 checks), and separately rejects four effect corruptions on valid
keys. The effect tests compare to independent algebraic rules at the
same inputs, not improved planning. In both replays all declared side
work persists, including outside the old-duty positive domain.
These mechanisms are scoped F50 examples, not dispositions of that
entry. Radio notice truth, MRWS supervisor availability, and both
fixture timing rules remain stipulated. This does not discover
reachable histories, demonstrate a common-cause generator, certify
arbitrary object identity, establish continuous robot motion, or
change the architecture ledger. A new fault class that changes \(D\)
must supply and justify a new domain version, retain evidence for
projection through the action cut, and recheck affected proofs under
that new version.
