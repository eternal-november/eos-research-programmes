# Timed reserve release guard
Run `python3 run.py` with Python 3 and a C++17 compiler. Source is pinned in the two INPUTS.tsv manifests. The camera runner reproduces the stock native-gate checks with its added filter disabled, then executes the same selected methods with the explicitly indicated per-target optional filter. The radio runner executes the previously pinned selected broker, receiver debit and callback functions. The exact guard checks are compared with direct enumeration for every support; neither learns the chosen future time before deciding. No binary, external package, simulator service, credential or network access is required.
