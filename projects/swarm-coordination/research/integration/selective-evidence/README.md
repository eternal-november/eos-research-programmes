# Selective evidence at a custody transfer

Finite model of bounded domain-level unreliable evidence. It separates a
three-history decision obstruction from whether any pair of histories has a
shared lawful action. It checks a binary radius theorem and counterexamples
outside its scope. No intrusion, source-code weakness, live access, or
deployment is modeled. Run python3 -B replay.py | cmp results.txt -.

Witness.lean checks the binary triple arithmetic and explicit tapes with Lean
4.35.0 and Mathlib.
