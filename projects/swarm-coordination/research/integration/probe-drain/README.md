# Recovery traffic can sustain the fault

Scoped I07 / R1 / R2 development result. A controlled diagnostic reopens the same
fixture whose settling progress is required to exit degraded mode. Ordinary
read-only telemetry is not treated as an intrusive probe. The finite model
charges probe requests to a shared service budget before updating the fixture.
The cross-crew law is a rolling evidence deadline, not a recommendation to
unconditionally wait longer.

- `ProbeDrain.tex`: exact boundary and the contract of the fixture and probes.
- `ProbeDrain.lean`: arithmetic cut and repeated-reset invariance.
- `replay.py`: direct finite-state schedule search, separate periodic construction,
  and feedback traces. Run with Python 3 standard library.
