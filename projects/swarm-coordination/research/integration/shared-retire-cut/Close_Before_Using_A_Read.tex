\maketitle

\paragraph{Result.}
One controller runs unchanged against selected native RWARE and SubT
backends. It rescues a delivery while retaining an earlier
unsettled obligation and making an unrelated delivery. A produced
local read is useful only if an old queued attempt cannot
invalidate it before the rescue. Retiring that attempt before
admission can help; retiring it after execution cannot undo its effect.

\paragraph{Workload and authority.}
The original cases were frozen before either plant ran. There is
one rescue authorization that can use either of two sites, but
cannot be spent twice. Another authorization covers a separate
delivery. The worlds differ in which site the old attempt can
affect. The common controller sees only a produced resource read
or its absence and the state of its own submission gate. It
does not see the hidden site. A completed call exhausts that
particular authorization to attempt, not the prior separate duty.
The model has no external source of delayed duplicates.

\paragraph{Native effects.}
The warehouse uses pinned RWARE steps on a finite grid. The old
carrier still owes a shelf return and moves into one of the delivery
berths. The chosen rescue carrier must actually enter the other
berth carrying an interchangeable requested shelf; original native
reward, carrier position and shelf identity are checked. The same
step delivers a separate shelf. New requests after scoring choose
dummy spares so the old shelf is not immediately requested as new
work. This is fixture workload, not a changed reward rule. A retired
old move consumes an empty native step instead. The local read uses
the native occupancy grid, not continuous clearance or field sensing.

The radio fixture uses selected pinned SubT broker, accounting and
callback code. The first attempt on an unavailable path leaves no
receipt but charges three of the chosen sender's five bytes in the
window. The old payload remains buffered. The alternate rescue
sender actually obtained its copy from an earlier broker callback.
Live path inputs allow the final rescue to be received subject to
the sender window. Another sender and sink deliver the separate
payload through a native callback. The local read uses the
real debit ledger; this is a colocated fixture interface, not a
claimed feature of a field radio.

\paragraph{Comparison.}
If the old effect occurred before a produced read, the controller
chooses the other site. If the read is omitted, the two worlds
have identical information and opposite sole successful choices.
In the race case, the controller truthfully sees both sites clear
while the old call is still queued. The call can then occupy or
charge either site before the rescue. Each fixed choice loses one
world. Retiring the old queued call at its submission gate prevents
that late effect and either site works. The same gate rejects a
retirement after the native call, leaving the effect intact; a
current read still identifies the available choice. This gate is
adapter code, not a stock RWARE or SubT cancellation API.

The matched direct comparison enumerates all deterministic policies
at the same information and one-grant limit, evaluated on the
native outcome table. Both methods obtain worst-case rescue one
in the produced-read, pre-admission retirement, and
late-retirement-with-current-read cases, and zero in the skipped
and racing cases. The separate delivery succeeds and the original
obligation stays unsettled in every replay. Two Lean facts check
the finite choice criterion, not the plant or distributed fencing.

\paragraph{Where the analogy stops.}
A separate later-cut diagnostic restricts the grant to the
previously blocked site. The radio debit ages out by the later
read and the actual callback succeeds. In the warehouse an idle
step has not cleared the berth, and the sole permitted move fails.
The common decision rule transfers through the current resource
interpretation, not through a common expiration law.

This is an executable development transfer on authored examples.
It shows neither an advantage over the matched direct policy nor
settlement of the older duty, a real sensor or actuator guarantee,
or independently selected I1 or I2 acceptance.
