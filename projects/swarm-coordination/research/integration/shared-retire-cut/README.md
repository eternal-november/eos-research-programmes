# Close before using a resource read

[Proof and scope](Close_Before_Using_A_Read.tex) · [Frozen
workload](FREEZE.txt). One controller uses selected RWARE and SubT
backends. A current reading cannot justify rescue if an older queued
effect can still change the resource before commitment. A later-cut
control shows why occupancy and debit do not expire alike.

Place the pinned inputs in [SOURCE.tsv](SOURCE.tsv) under their short
names in an upstream directory. Run:

    sh replay.sh /path/to/upstream | cmp results.json -

The script checks all input blobs. It requires Python 3 with NumPy and
a C++17 compiler. The Space archive includes exact inputs and licenses.
These are selected native functions, not full Gym or Gazebo. Lean
checks the two-site choice law. The matched direct policy ties.
