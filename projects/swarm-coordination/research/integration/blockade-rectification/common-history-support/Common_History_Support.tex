\section*{Generating common-history reservation continuations}
\paragraph{Interface, scope, and kernel.}
This controlled civil crossing uses the same pinned native Open-RMF
moderator and conflict calculation as the moderator-replacement test,
with a different question: which coupled continuations can a local
representation safely supply to a recovery chooser? The native fixture
permutes serial calls over an admitted partial order. Before the incumbent
exits, two candidates can request the same exclusive crossing; A can
withdraw, and an already held callback for A can arrive. A fourth
participant performs unrelated work on a geometrically disjoint path.
Publishing a grant is not physical motion of either contender. The only
scored reach events are the incumbent's exit and the disjoint work.
The model omits arbitrary routes, further send and failure recurrence,
ROS, sensor uncertainty and physical actuation.

\paragraph{Generate before looking at source outcomes.}
An event has a name, predecessor condition and state-dependent step.
A shared cause or resource change occurs once in the joint order, not
once per participant marginal. Both withdrawal and delayed delivery need
A's initial issue. The model holds ordered waiters and exclusive span;
the independent route marks its own progress. A live-source guard on
late forwarding is an intervention that can change the successor support.
The unguarded control applies the native call when the held notification
arrives. A separate C++ reference enumerates all admitted orders of flat
native calls, exercising native range, ready and reach state at every
cut. The Python traversal of enabled events does not read reference
outputs to build states. Both implementations match all 480 full traces,
including their intermediate observer fields (and recorded evaluator
fields, explicitly not a shared runtime view).

A and B in opposite request orders give identical ready/range outputs
before the common exit, yet disagree on who receives the next grant.
Allowing the unqualified late callback after A withdraws can change
the next eligible recipient when B has not yet requested the route.
A per-actor Cartesian product invents a simultaneous grant never
produced on any source execution in the tested envelope. Placement of
the disjoint step can be quotiented for the crossing transcript with
its own progress retained separately (480 to 80 orders), but not if
the consumer needs the timing of that step.

\paragraph{Exact reusable quotient under bounded deletion.}
Consider a separate boundary family of \(n\) named contenders all
pending for one exclusive span. Before an unambiguous release of the
incumbent, an authorized context can delete at most \(k<n\) waiting
names, and asks who becomes the first grant. No new entry, repeated
clear or reissue is in this query algebra. For FIFO, the ordered first
\(k+1\) names are sufficient: at least one of those names survives, and
the first survivor is exactly the grant. The summary is minimal for a
representation required to serve all allowed future deletions without
knowing which one will occur. If two such prefixes differ, delete the
\(j\) shared leading names before their first disagreement, for
\(j\le k\). Both first differing names survive and are distinct answers
under the same lawful query. The exact quotient has \(n!/(n-k-1)!\)
classes, not merely the set of ready participants or the current
preferred name. At \(k=0\) only the head matters. For \(k=n-1\)
the entire ordering matters. If all names can be deleted, that
additional query has a common empty answer and needs no extra class.
This is a finite summary lower bound at the specified interface, not a
claim about other schedulers or every possible repair.

The native reference checks every permutation and deletion mask for
\(n=2,\ldots,5\) on intersecting straight paths, 4,280 executions.
An independent enumeration checks 10,448 bounded-deletion queries.
The proof applies to any FIFO single-exclusive-span abstraction;
application to a new source family requires establishing that abstraction.
In particular this does not demonstrate native geometry of mutually
conflicting routes for arbitrary \(n\), nor a general online
strategy selector or support model on unobserved ROS state.

\paragraph{Residual.}
The strongest reference runs the same native paths and yields the same
answers; no service or resource advantage over established dispatch
or model-checking algorithms is claimed. The reusable gain is knowing
which distinction the query requires before generating or discarding
histories. Outputs here are grants, not committed effects including
physical actuation, and the finite emitted support is exact only for
the declared test grammar. No independent test was selected, and no
I1, L2, or moonshot closure is claimed.
