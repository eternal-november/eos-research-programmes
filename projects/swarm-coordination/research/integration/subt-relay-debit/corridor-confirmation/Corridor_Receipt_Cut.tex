\paragraph{Audit.}
This is a held-in corridor fixture with the pinned SubT broker,
radio ledger and ROS callback. The blocked former shortcut, gate
geometry, loss monitor, alternative bays, exterior upload and
keyed sink are authored plant controls. It is not full Gazebo
or physical motion. Actual report copies, application settlement,
scout confirmation, and egress are separate outputs. A different
report continues on a declared independent path.
\paragraph{Information and transport.}
The original scout installs both candidate copies through actual
bound callbacks. The east bay sends a gate request at tick $-1$
or 0. Its sender is debited before propagation, even if the
gate never sees it. The scout reads its actual local east face
at tick 1 only if the request arrived; exactly one open exit
is the authored geometry law. An actual maintenance callback
names the unavailable bay. A mechanical inspection and carry
fallback remain if the gate request fails. A forwarded copy
must actually reach the Base callback to be processed and
acknowledged. One processing tick and a direct Base-to-Scout
ACK are authored; the stock artifact scorer has a separate
reply-to-submitter and forward path (PR~707). One quarter
second per tick and inclusion of the one-second endpoint make
the first feasible send after the request tick 4 or 5
respectively, for three-byte packets on a five-byte sender.
\paragraph{Confirmation interference.}
With the west exit needed, east active and request at $-1$,
the old report is delivered and processed by tick 5.
A three-byte confirmation is blocked: the earlier three-byte
maintenance notice at tick 1 is still present in the scout's
receive ledger. The source applies the current Base sender's
five-byte limit to that ledger, not the scout's larger
advertised limit. Base still pays its transmit debit.
A two-byte code for the one preinstalled current request
fits exactly, reaches the scout at 5 and permits egress at 8.
A stale two-byte code also reaches the callback, but does
not clear the old duty. This is not a general receipt
compression format or authentication protocol. The larger
confirmation fits at 6 after expiry, but then egress is at 9.
Actual old report settlement is unchanged, which is why
report-arrival-only scoring misses the distinction.
\paragraph{Negative and matched controls.}
The same maintenance notice and local timeout can result
from erasure of the subsequent report or from successful
settlement and blocked confirmation. Reply-only erasure
also preserves the effect. The scout does not read the
actual settlement directly. With no confirmation it keeps
the copy; the specified west carry reaches egress at 8
and the exterior keyed upload at 12 when the report had
not previously arrived. This fallback loses the original
report deadline and does not count in the positive envelope.
Eight scoped route/report cases and 192 matched
native-versus-direct confirmation histories exercise exit,
failed bay, request cut, code form, waiting, report erasure
and reply erasure. The independently written arithmetic rule
with the same resources and qualified source agrees.
A route plan alone cannot establish the continuation here.
This does not beat an equally informed direct planner,
certify real sensing, or close I2 or the independent mission.
