\title{A source can recheck an amendment against a timed native footprint}
\date{}
\begin{document}\maketitle

\paragraph{Scope.}
In the pinned civil network simulator, qualify the scope from actual
radio ledgers and the queue under the evaluator's local control.
A changed old report can be compatible with an accepted overlapping
new send if its debit will expire. A physically failed optional send
can still defeat a required rebind. A cancellation before dispatch
removes only the planned optional effect, not an already incurred
debit. The fixed same-information reference agrees. This does not
establish a field sensor, network transaction or independent test.

\paragraph{Source producer.}
Use the same selected native broker and radio functions as
\href{https://github.com/eternal-november/eos-research-programmes/pull/587}
{the rolling-scope test}. Model a broker owner that controls the
pending old route, its actual endpoint registry, the acceptance
of one optional report, and the dispatch of the scoped jobs.
The evaluator is local to this owner. It reads the selected native
state for physical TX and RX histories, site identity and sender
configuration; it uses the complete modeled remaining committed
queue and reliable nominal candidate paths. It checks both budgets
against the sender's configured capacity for the current attempt,
not the recipient's own setting. Untested outside writers, alternate
paths, loss of clock or read access, or unmodeled senders invalidate
source completeness. An owner unable to read the actual receipt
or ledger has a different information interface.

Before accepting the optional report, forecast its pending effects
together with the later old duty under the inclusive one-second
window. Before installing a route change, use the same check with
the actual source ledgers, and include the optional effect only if
it has not yet attempted. Qualify the read by a source revision;
a substantive actual attempt or route change invalidates an earlier
snapshot. These events are ordered locally without simulated
network-round-trip latency. An old destination can be amended while
a new reservation is live if the exact timed duties can coexist.
A coarse prohibition of every overlap would remove this legal
capability. The comparator checks the same nominal scope and does
not validate arbitrary fault recovery.

\paragraph{Source controls and physical residue.}
With capacity 5, the first actual old report uses 2 bytes at time
zero, a 2-byte tail must arrive at time 0.75, and the optional
packet uses 3. Independent work has its own nodes and callback.
If a conflicting amendment wins before acquisition, the prior
read is stale and a fresh early forecast will still refuse.
If that amendment follows an early acquisition while optional
and old are both owed, it is refused. If the optional report can
wait until 1.25, the same sharing is allowed: the earliest old
debit has expired and the two remaining charges fit.

If the optional report has actually arrived at 0.5, its source
TX and destination RX ledgers both contain 5 bytes in this fixture.
A sender-only or receiver-only overlap now prevents the old rebind.
If the optional path instead fails, native TX still contains 5
bytes while RX contains only 2. The same old permission can permit
the receiver-only change but not the sender-only change. This is
actual ledger access, not an inference from a missing acknowledgement.
The Lean lemmas check monotonicity under a decrease of qualified
ledger loads and the distinguishing arithmetic, not authority or
the native abstraction.

\paragraph{Forced rebind and optional cancellation.}
As a separate controlled loss, the original disjoint old route
becomes unavailable. The lawful replacement is the staged rebind,
not an invented alternate. If the optional send is still planned
and the two cannot both fit, it can be cancelled under the declared
optional authority. Both mandatory source receipts are then restored.
A policy that keeps its earlier reservation misses the old tail
under the same physical loss. If the exact timed amendment is
already compatible, no cancellation is necessary and both reports
still pay. If the optional attempt has physically occurred, this
operation cannot cancel it. A failed transmit with retained sender
debit then still prevents the mandatory sender-sharing rebind.
Receiver-only recovery after a failed optional arrival remains
possible in the checked model. Some post-attempt cases therefore
have no feasible recovery at the given deadline and authority;
the trace records the miss rather than silently changing it.

\paragraph{Boundary and costs.}
Twenty-four native source/edit checks read 204 ledger entries
and inspect 80 pending attempt forecasts. A further twenty-four
forced rebind controls compare the policy outcomes to the exact
same-information decision tree. The conditional cancellation is
an improvement over keeping an optional reservation in this
prescribed fault scenario; it is not claimed superior to an
equally informed transactional scheduler that can cancel planned
optional work. Unlike the standing shelf case, overlap can
resolve by actual expiry rather than permanent footprint
disjointness. These authored mechanisms do not spend the
independent transfer or establish contract acceptance.
