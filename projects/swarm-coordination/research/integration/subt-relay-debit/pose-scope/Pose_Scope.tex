\paragraph{Lift and source scope.}
An already owed report is offered at a cut during the available
geometric dwell from the pinned planar brake-and-connect witness.
The original geometric timing is retained, but the radio fixture
supplies a matched direct-path power law; the KTH simulation does
not measure or produce this packet channel. The source under test
is the pinned OSRF SubT pose cache, broker dispatch, capacity checks
and ROS callback, executed as selected code against a local simulation
fixture. There is no live network, field claim, independent mission,
or application settlement beyond the named body reaching its callback.
The separate side stream uses disjoint endpoints unless explicitly
indicated. Registration status, position availability, indicated
time and actual current geometric state are not interchangeable.

\paragraph{What the pinned broker checks.}
For a nonempty queue, the broker samples the pose function for every
registered member before consuming any datagram. One unsuccessful
lookup returns with the existing queue intact and no new TX debit.
A newly registered member that has not yet produced its first pose
can therefore defer both unrelated streams. Mere omission of a
\emph{previously recorded} member does not imply that behavior.
The pinned plugin retains old per-name entries when a later message
omits the name, and its callback returns the cached pose with the
current global simulation time. In two paired synthetic histories,
an old far position produces an erased attempted send even when
the actual pair is now within range, whereas an old near position
can make a simulated callback fire even when the actual pair is
no longer within the declared path threshold. These paths establish
a version/pose qualification problem in the selected interface;
they do not estimate how often real frames omit a member.

\paragraph{Scoped interpreter and resource envelope.}
For each datagram, retain the dependencies of its path model, the
sending and receiving ledgers, identity and custody, registration,
and the task's deadline. Require fresh qualified observations only
of dependencies that can affect it; missing unrelated observations
cannot establish a fault or revoke a registered member. In the
declared direct unicast model the only required poses are those of
its endpoints, and without shared charge, manual ordering or RF
dependencies, an independent stream cannot consume its rights,
debits or callback. In that case the local branch executes the
same pinned path and ledger function with the same dependencies
as in a fully available snapshot. It keeps blocked messages in a
separate pending queue rather than treating refusal as delivery.
The fixture confines this scoped projection to a serial wrapper;
temporary isolation of a mock map is not a production concurrency
or authorization mechanism. Freshly sampling endpoints is only a
sufficient acceptance guard: a separately justified uncertainty
tube could preserve the needed predicate without a fresh point.

With 173 report bytes, a capacity limit of 200, and zero or 20
unexpired sender bytes, a missing first pose of the unrelated
registered member blocks on-time receipt in the stock dispatch.
Scoped dispatch on the same current samples delivers it and the
side message at time 1. Forty carried bytes make even scoped
dispatch unable to send the report at that cut. Later lookup
availability at 1.5 can restore the stock queue, but cannot meet
the time-1 deadline. The due date is a fixture choice, not the
stop time after braking.

\paragraph{Why pose dependencies are not enough.}
Let an earlier held report need 173 bytes at the shared receiver
and a different sender's currently available side job need 60.
The old report has a qualified pose at 1.5, half a second after
the side job can be sent. The pinned received-byte window includes
both cuts (one second, left boundary inclusive). At cap 200,
bypassing on endpoint poses alone lets the side use 60 at time 1;
the later report has no receiver space and still incurs 173
sender bytes before being rejected. The stock ordered batch at
1.5 instead gives the old report its space but loses the side
opportunity. To preserve the old report, reserve the 173 in the
same receiver ledger before allowing bypass; it adds a buffer
delay, not physical capacity. At cap 233 both fit, and the
reserve check allows the side to finish early. The check is
necessary and sufficient for this two-job receiver/cut family:
the earlier side debit remains live at the old reserved due
time, and there are no other competing debits. If side service
is mandatory at time 1, cap 200 cannot provide both under
these placements; giving up that service is explicitly accounted
for. If the capacity producer counts different times, if a moving
relay also controls RF, or if additional live debits are possible,
neither the two-node scope nor the two-debit proof suffices.

\paragraph{Attribution.}
There are 156 matched principal cases varying fresh/missing/stale
state, carried debit, cap and later recovery, and six actual
shared-receiver executions. The same qualified-pose and ledger
planner can implement the guard and ties in this envelope.
A native callback covers neither physical continuous contact
nor qualified duty settlement in an application. The result is a
scoped mechanism and a concrete incompatibility of independently
reasonable controls, not a production patch, full simulator
integration or architecture acceptance.
