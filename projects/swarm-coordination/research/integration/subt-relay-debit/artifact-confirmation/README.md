# SubT artifact confirmation

[Source analysis, exact cuts, and limits](Artifact_Confirmation.tex). The scorer uses a global counter in the returned report ID. A tutorial relay can return the request itself; its reporter does not distinguish an echo from a score confirmation. This package reconstructs source behavior in two bounded models, not an executed Gazebo/ROS mission. No upstream behavior is changed.

See `SOURCE.tsv` for all examined implementation pins. Reproduce with `node scoring.js` and `node echo.js` (no dependencies). Expected counts are 1,085 cap/goal state pairs and 210 queue schedules, and 86,480 capacity/path cases plus three typed response controls. Check the two Lean files with Lean 4.35 and Mathlib; their eight declarations were audited with no `sorryAx`.

The [score log follow-up](log-projection/README.md) tests whether the native event projection can substitute for the lost result. It separates native-key identity from displayed geometry and the event-write cut from the score update.
