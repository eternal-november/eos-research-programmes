# Retire an old footprint without discarding its return duty

The native warehouse replay tests actual reward and occupancy, still-live
old return, and authority over a later entry. The disjoint true return
can progress in the same native wave as rescue; its advertised scope
can become stale unless rebinding is closed. Runs the unchanged
incremental cut checker on an explicit product of the native controls.

Put the exact SOURCE.tsv inputs in an upstream directory. Requires
Python 3 and NumPy. Run:

    python3 -B replay.py /path/to/upstream | cmp results.json -

Twenty-four native rows, one checked explicit recompilation comparison.
Read Footprint_Closure.tex for limitations. This is a development test.
