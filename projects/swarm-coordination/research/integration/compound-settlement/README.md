# Compound settlement cut across warehouse and radio

The frozen core uses local evidence to preserve an old delivery, try rescue,
and continue a disjoint service. The TeX note distinguishes an old effect
from its acknowledgement and the cost a retry leaves behind. A separate
fragmentation test changes authorized command granularity; it is not a
planner win over a matched scheduler.

Copy the entries listed in SOURCE.tsv to the named paths in an upstream
directory. Run from this directory:

    sh replay.sh /absolute/path/to/upstream | cmp results.json -

Requires Python 3 with NumPy and a C++17 compiler. SOURCE.tsv and the
script verify Git blob identities before running. The archived copy has
exact sources and licenses; repo files do not include those vendor sources.
No new inbound or outbound network access is run by the fixtures.
There are 24 compared cutoff rows, 6 native forced controls, 12 separate
placement and 12 fragmented cases, and 4,000 split arithmetic comparisons.
Split.lean contains two Lean 4.35 plus Mathlib checks. FREEZE.txt and
core.py were fixed before constructing either new backend.
