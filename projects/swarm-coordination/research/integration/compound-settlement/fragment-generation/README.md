# Coexisting fragment generations

A controlled replay of ordinary callback arrivals, paired on all
receiver information. The two-generation control tests whether an
extra byte of framing invalidates the early split from the compound
settlement study. The TeX distinguishes settled generation from
parseable content and states a scoped equality-code coloring rule.

Materialize the pinned SOURCE.tsv paths as in the compound settlement
study. Requires Python 3 and C++17. Run sh replay.sh /path/to/upstream
and compare to results.txt. This does not run a real network.

[Development closure witness](closure/README.md): an old send fence, actual old settlement, and a downstream completion cut restore the untagged branch without buying more payload credit.
