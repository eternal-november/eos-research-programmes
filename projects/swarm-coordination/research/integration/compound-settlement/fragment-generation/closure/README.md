# Qualify the end of an untagged generation

A before-dispatch fence, after-dispatch completion check, and actual
old receipt qualify retirement of a partial receiver buffer. The
simple policy was frozen before the shared-cut replay. The comparator
ties at the same local read. A separate publication control visibly
combines the fresh left half with old work.

Use the pinned SOURCE.tsv inputs of the parent studies, then run
sh replay.sh /path/to/upstream and compare stdout to results.json.
Requires Python 3 and C++17. Epoch.lean uses Lean 4.35 and Mathlib.
The downstream delayed callback and source-owner authority are
authored fixtures. Nothing executable here addresses a deployed network.
