\title{A source cut for retiring an implicit packet generation}

\paragraph{Decision.}
Open a new two-part receiver cohort without allocating generation bytes.
Each accepted pair must discharge the new inspection rather than mix its
fragments with older work. The receiver knows positions from origins.
This is a simulated installation with one declared owner for the old
source, a lawful retract-before-dispatch operation on its redundant
pending fragment, and a receiver that can continue unrelated work.
Do not infer those authorities from a displayed status or apply this
test to a live network.

\paragraph{Actual source obligations.}
Separate the old dispatch queue, already handed downstream work, and
any already delivered incomplete part in the receiver. The source owner
must first stop being able to enqueue this old generation. The guard
requires zero old effects still queued and zero still in flight at the
relevant receive boundary. This is a witness of a stable cut only under
the stated source law: dispatch moves work between the first two stages,
completion removes handed work, and the only source transition that adds
new work is disabled. Idle or publication does not create a source fact.
The Lean development proves stability for the explicit transition law.
If future source names or ownership can be rebound, a complete projected
registry, or a sound horizon that covers all reachable sources, is an
additional premise. Topology names are not a proof of that registry.

Separately, the prior mandatory service must actually be paid (or be
otherwise transferred under an explicitly authorized old-duty proof,
not exercised here). The partial buffer may then be cleared as old,
not passed forward as the first accepted fragment of the new cohort.
That clearing is neither a late delivery nor old settlement. In the
fixture the zero predicate is direct state at one colocated source
cut. A distributed certification must account for messages in flight,
as in the underlying distinction of Chandy--Lamport
(\url{https://lamport.azurewebsites.net/pubs/chandy.pdf});
the classical snapshot algorithm is not claimed to work over an
unreliable or unauthenticated control boundary here.

\paragraph{Native selected-body replay.}
The fixture uses exact selected SubT dispatch, radio and callback bodies
with authored local ownership and an explicit optional downstream work
queue. The source state in front of dispatch is the actual simulator queue.
The handed-work stage records data already accepted at the gateway's
native callback, but not yet processed at the final application callback;
this pending last step is authored, not claimed to describe stock
middleware. The terminal old receipt is the actual authorized application
delivery to its separate old destination. Cancelling the optional repeat
only removes a correctly fenced entry still in front of dispatch.
Source expiry in one cut does not cancel an already emitted fragment or
delete one buffered at the receiver. A deferred old part that debited
earlier than the active radio interval can still carry a live downstream
effect. Both continued source availability and rate accounting use the
same test clock; a timestamp alone is not the documented order between
same-tick delivery and commitment.

Fifteen histories cover the old effect still queued, handed downstream,
already buffered, allowed to enqueue late, or awaiting unpaid old service.
Publication-only control admits the new action in four paid branches and
accepts a pair containing the stale right half. Actual sealing with
scoped queue retraction closes the unissued or future-issue branch.
The handed-work branch must wait until the old callback is processed
and then clear the old partial before admission; merely seeing a now empty
source queue is insufficient. If the old duty is unpaid, the old
permission cannot be abandoned to install the new cohort; the distinct
independent service is still delivered. The ready and burned-credit
conditions come from pins: after the two old charges at time zero each
sender has two bytes left exactly at time one. The untagged two-plus-one
fresh transmission succeeds once the cut is qualified. The tagged
alternative from the preceding study requires five bytes and cannot fit
this envelope.

\paragraph{Comparison and kernel.}
The direct check at the same observed cut ties. Exclusion of stale work
is the concrete reason the previous zero-overhead branch is restored,
not a general advantage over designs that already perform safe drain
or carry admissible generation metadata. This combines one actual
source of closure, a terminal old receipt, and useful disjoint execution
in a selected simulator, but does not establish a physically distributed
closure service, liveness under an unbounded tail, independent transfer,
or overall I1 advancement. An older frame retained elsewhere, a missed
route in the source registry, or an expired right reopened by another
actor requires another argument. Clearing via audit-state unavailable to
the acting layer would change the interface, rather than solve the same
problem.
