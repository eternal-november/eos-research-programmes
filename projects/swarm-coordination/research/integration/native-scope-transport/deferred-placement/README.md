# Defer warehouse placement without dropping the old deadline

A prior native return occupies one bay. The live old return can choose
a bay only after a local route designation or by a deadline fallback.
The result separates true motion, qualified observation time, later
authority changes, due service and unrelated work.

[Proof, comparison, source and limits](Deferred_Placement.tex).
Stage the three named pinned blobs from the earlier
`integration/compound-settlement/SOURCE.tsv` manifest. Run:

    python3 -B replay.py /path/to/upstream | cmp expected.json -

Requires NumPy. `Timing.lean` was verified with AXLE Lean 4.35.0.
The two controller modules and their respective freeze files precede
their native checks. A changed source with late motion preserves the
matched result; permitting later reassignment defeats the original
guarantee. No independent contract milestone is claimed.

[Designation lifetime](designation-lifetime/README.md) moves the authority change past actual unload and holder clearance. The same final job is feasible with a different earlier shelf position; settlement did not retire the standing footprint.
