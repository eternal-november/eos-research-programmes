# Contextual Composition: residual profiles on native recovery sources

Apply the pinned **Existence and construction of common profiles** theorem
to specified warehouse and radio replay witnesses. Reflection, coverage
and full raw surjectivity are separately tested. The common profile uses
both status branches and all declared off-policy test arguments.
[Application, witness maps and limits](Native_Residual_Profile_Application.tex).

`SOURCE.tsv` gives Git blob digests, revisions and repository paths.
Fetch the pinned `native-scope-transport/expected.json` (or produce it with
that study's native replayer) and pinned Contextual Composition TeX source,
then run:

    python3 -B replay.py /path/to/native/expected.json /path/to/pinned/theorem.tex | cmp expected.json -

This checks the imported theorem's hypotheses on the recorded finite
source interface. It does not re-verify the general theorem or replace the
source fixture's own replay. No held-out transfer or operational
superiority is claimed.
