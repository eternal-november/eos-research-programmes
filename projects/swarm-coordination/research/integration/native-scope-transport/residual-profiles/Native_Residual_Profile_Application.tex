\title{A native application of Residual Profiles and Admission Reflection}
\date{}
\begin{document}\maketitle

\paragraph{Claim.}
In the two-source development fixture, one cached admission and effect
evaluator serves both a warehouse and a radio receiver on a specified
recovery interface. This is an application of the named theorem in the
pinned Contextual Composition note, not an assertion of complete
mission transport. The positive case covers two native witness sorts,
both settlement branches, and off-policy checks in the declared
product. It does not assume surjectivity of either raw witness map.
The earlier scoped comparison proved preservation on the unchanged
receiver's actions only; it did not prove a common presentation for
all primitive tests on this product.

\paragraph{Imported criterion.}
Use the
\href{https://github.com/eternal-november/eos-research-programmes/blob/4359a8a1484498b9c46d8e58a0112448a1fba06b/projects/contextual-composition/feedback-and-concurrency/observable-covers/Residual_Profiles_and_Admission_Reflection.tex}
{pinned \emph{Residual Profiles and Admission Reflection}, theorem labelled \texttt{thm:criterion}}.
Its hypotheses are (T), reflection of each declared primitive on
\emph{all} source tuples along the given coordinate maps, and (C),
coverage of every residual target class in each sort. Target
equivalence is equality of all incident sections, testing against
all other target arguments in the declared domain. Under (T) and
(C), one evaluator on the attained profile products implements
every declared primitive on both sides. This conclusion is stronger
than the mere existence of matching outcome pairs and weaker than
lifting arbitrary native continuations or full effect histories.

\paragraph{Native witness maps and primitive authority.}
The first sort consists of precommit source runs of the pinned
\href{https://github.com/eternal-november/eos-research-programmes/pull/579}
{native replay}, indexed here by time cut and whether the old
operation's first attempt worked. Each source witness is a warehouse
run at 0.75 or 1. Each target witness is a radio run at the next
representable cut above 1 or at 1.25. Map each source run to the
radio run at the first of those late cuts with the same prescribed
success or failure of the initial actual attempt. This map is
defined on reproducible native input identifiers, not by finding
matching outputs after replay. The old status used by the receiver
is separately checked from each actual native run. Both sides have
staged copies and the same stipulated branch-level dispatch rule.

The second sort consists of command tokens: the warehouse offers an
old retry on the right with rescue on the left, or no old retry
with rescue on the right. Map either token to the corresponding
radio command under the inherited site/sender interfaces. The radio
catalogue can also offer no retry and rescue on the left, which is
not in the source catalogue. For each token, test issuer eligibility
(no retry if already settled). This is an explicit policy restriction,
not a claim that a robot or broker rejects all duplicates on its own.
On eligible inputs test actual old delivery, actual rescue, and
separate independent service; unavailable composite actions have an
undefined output rather than false physical receipts. The read is
a unary primitive; each eligibility or service test is binary in
run and command. Run and command identities and measured effects
are retained in the replay store; quotient identifiers are not
asserted equal native arrows.

Only the qualified settlement label is read by the executing
receiver at this cut. Whole-run witnesses, all alternate commands,
and the exact physical-effect outcomes are available to the
mathematical auditor, not revealed early to the running vehicles.
Nothing here settles the warehouse return duty, which is separately
owed, or equates travel to radio capacity. Any future consumer
reading return, radio debit, timing beyond the modeled wave, or
different party permissions needs a fresh interface check.

\paragraph{Construction and results.}
At the late radio cuts, both time-indexed witnesses at each
settlement status give equal sections. In the command sort the two
no-retry rescue destinations give equal target sections. The old
retry/rescue command is distinguishable, including by issuer
eligibility. Thus the target quotient has two classes per sort.
Both source images miss raw target witnesses, yet both cover the
attained classes. All 36 source factor calls reflect; in particular
the crossed no-retry command on the live branch is mechanically
available but does not pay the old duty on either plant, while
the settled branch with a retry has an undefined effect on both.
The theorem therefore supplies the same exact product evaluator,
and using it on the two frozen chosen commands preserves all three
service results. Eight native context/receiver checks agree with
the cached answer. A direct result table under the same status,
authority and commands agrees; no speed or operational advantage
over it follows.

The early radio cut fails (T): with old service live, retry on the
right and rescue on the left still pays old service, but cannot
pay rescue from the sender with carried debit. (C) still holds.
Expanding the source catalogue with the unused no-retry/left
command also fails (T), but in the settled branch: the warehouse
has physical occupancy at that goal, while late radio can deliver.
This does not invalidate the narrower certificate. Finally, adding
no retry and no rescue to the target only leaves (T) true and
fails (C): the command's lack of rescue makes a third target class
unrepresented in the source. No finer common profile fixes that
failure for the fixed maps and catalogue. The controls exercise
both directions of interface error without claiming two distinct
physical mechanisms are interchangeable in general.

\paragraph{Verification boundary.}
The implementation constructs all sections and scans all declared
factor tuples, then cross-checks adequacy and coverage against 405
enumerated candidate pairs of partitions (160 source factor calls
across the four interfaces). Counted calls do not represent
statistically independent trials. This is a scoped application of
the named preservation law using exact source replays and an
unchanged receiver. It is not an independent holdout, a recurrent
proof, a comparison to a stronger established operational
architecture, or an inventory disposition.
