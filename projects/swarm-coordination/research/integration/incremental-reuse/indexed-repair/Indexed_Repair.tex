\paragraph{Scope.}
The previous two prototypes either traversed a conservative dirty cone or
reconstructed a rooted witness index and copied graph maps on each edit.
This comparison holds the finite product and verdict exactly fixed and
maintains the adjacency, reverse, parent and child indexes under their
owner. It is single-installation, sequential and requires a complete edit.
A saved old version, a speculative branch, or concurrent external mutation
would require separate snapshot and consistency work.

\paragraph{Sparse repair.}
Only removed roots that serve as actual witness roots and deleted edges
that serve as actual parents invalidate existing proofs. Invalidate their
descendants in the old witness forest. The remaining nodes have actual
rooted paths in the new graph. For all other nodes, find a new root or
an entrance from retained nodes. Every entrance from a retained node
is either a new edge, or already had an old reachable destination by
the old reachability closure. Thus in the latter case an entrance into
the still-unknown set must enter an invalidated witness node, for which
the edited reverse incidence is available. There is no need to scan
all outgoing edges of retained nodes. The Lean lemma checks that
entrance characterization. The earlier inside-first-entry result applies
to arbitrary regions: each new path to an otherwise unknown node
uses a last entrance from the retained region or starts at a new root.
All found paths are rooted; a disconnected self-supporting cycle
does not authorize any certificate.

On repair, maintain the monitors for states actually removed and
added, plus every independently edited fact at a reachable node.
An unchanged witness proof need not transport an altered observation
name. This result assumes immutable state identity, correct labels and a
well-defined finite product. There is no simulation theorem for a
changing representation or a generic policy optimizer.

\paragraph{Exact comparisons and work.}
Across $7{,}125$ deterministic chained patches the rebuilt full oracle,
previous rooted-witness worklist and indexed implementation agree on
reachable sets, separate verdicts, and valid paths. Reverse and child
indexes are checked. The composed input producer has $4{,}096$ unrelated
lease rows and an 80-state timed cancellation model. A changed branch
with identical output renews source dependencies but gives the receiver
no edit. An inactive-pool input needs no re-evaluation. Rebinding the
active cancellation reserve is a real edit: eight recipes and eight
rows change, the receiver reads twelve outgoing rows and six reverse
members and visits three old witness children, with no scan of the
unaffected forest. The old copying worklist indexes the $4{,}101$
initially reachable nodes for that comparison. The same work certifies
a rooted re-entry trace only in the new binding. A separate lateness
edit produces the deadline violation, and restoring the reserve removes
the safety violation without erasing that remaining deadline failure.

Five alternating trials on the available CPython 3.12.14 workspace
timed the entire warm supplier--receiver--verdict pipeline for 120 edits
per trial, with the same supplier and exact verdict assertions and no
shadow full run inside either measured interval. Medians were 670.313
ms with the older copying worklist and 4.101 ms with the indexed
implementation, and roughly 21.8 and 19.9 ms respectively for setup.
The archived timing sample is observational, not part of the deterministic
replay. It is evidence for removing whole-graph Python copying and
reindexing on this sparse workload, not a claim against optimized
incremental reachability, an architectural speed guarantee, or an
independent field comparison. Dense edits and invalidation of deep
witnesses can still touch most of the model; explicit root replacement
may require reading the whole root set.

\paragraph{Next proof duty.}
A correct versioned sparse data structure can preserve much irrelevant
work, but neither fast processing nor a local message proves that a
transition edit is complete. A qualified producer with a persistent
source or receipt law must supply the actual change. The explicit
simulated plant and pinned trace producer establish only the declared
instrumented interface. No independent fixture selection or contract
acceptance follows.
