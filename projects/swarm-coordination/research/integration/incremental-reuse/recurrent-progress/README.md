# Fixed-policy recurrent recovery at stable ports

One reusable progress summary per sealed module. A live change can produce
a fair unpaid cycle with unchanged reachable vertices. A reachable unfair
trap is reported separately rather than being hidden by the fairness filter.

[Proof and limits](Recurring_Recovery_Reuse.tex). The four verdicts are for
one named duty and fixed generalized Buchi edge justice in a complete finite
installed graph, not timing, source validation or controller synthesis.
The compiled masks match an exact factored direct check with the same ports.

Python 3.10+, no third-party dependency:

    python3 -B replay.py | cmp expected.json -

RecurringMasks.lean: three Lean-checked lemmas about joining reusable tours.
The exact graph and extension arguments are given in the TeX note.
Development freeze and authored controls only; no independently selected
test has been opened.

[Native source check: transient and persistent eligibility](native-eligibility/README.md). Real simulated dispatch resolves eligibility at two cuts; a typed budget hold can preserve it if the route and gate authority survive, but does not prove scheduling fairness or a deadline.
