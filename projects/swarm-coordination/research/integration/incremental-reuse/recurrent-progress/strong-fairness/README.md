# Strong-fairness boundary of sealed recovery summaries

[Proof and scope](Streett_Recovery_Interface.tex). An exact suffix adapter
can reuse positive justice charts after filtering, not a single union of
opportunities. Even two ports can need a middle-binomial number of bits
for all members of the declared neighbor family. This does not make an
ordinary explicit Streett solver exponential or imply that a simulator
scheduler owes strong fairness.

Put the original pinned recurrence.py at the SOURCE.tsv destination in
an upstream directory. Run with Python 3.10+:

    sh replay.sh /path/to/upstream | cmp expected.json -

Three Lean 4.35.0 algebra/counting lemmas are separate from the graph
refinement proof. No independent test or acceptance is claimed.
