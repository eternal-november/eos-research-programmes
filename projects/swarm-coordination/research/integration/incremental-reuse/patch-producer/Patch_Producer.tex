\paragraph{Interface.}
The earlier reachability checker accepts a complete explicit edit. This
development supplies an edit without regenerating every semantic row.
A row recipe is deterministic, side-effect-free and reads a typed,
versioned binding of named cells. The supplier declares the complete
changes of those cells and any changes of recipe code. Immutable
row meaning and correct supplier updates remain requirements. No
separation of real resources follows merely from different parameter names,
and no absence of an event is inferred from a frozen planner report.

\paragraph{Read-trace condition.}
An interpretation returns a value together with the cells actually read.
A constant has empty support; a named read records its input; a strict
operation combines its inputs' supports. A conditional records every
test read and only the selected branch's reads. If the recipe is unchanged
and the new cell environment agrees on that old support, evaluation gives
both the same value and the same support. Induction proves this: condition
evaluation agrees by the induction hypothesis, chooses the same branch,
and then the branch's inputs agree as well. The Lean theorem checks the
conditional/read kernel over natural-valued cells; strict equality and
pair construction use the union case in the Python model. This is not a
verified compiler relation on arbitrary Python behavior.

Invalidate every altered recipe, even if its previous support was empty.
For each changed cell, re-evaluate its active consumers. The inverse
support index must be refreshed whenever support changes, including when
the output happens to stay identical. Otherwise the next input edit
can be missed. The delta passed to reachability contains only actual
output changes; refreshing provenance is a distinct operation.
Adaptive functional programming already supplies this general change
propagation principle (\url{https://www.cs.cmu.edu/~rwh/papers/afp/toplas06.pdf}).
No advantage over a matched ordinary dynamic dependence updater is claimed.

\paragraph{Composed experiment.}
The finite timed cancellation fixture is exactly matched to the pinned
previous direct compiler. It also has $4{,}096$ independent retained
lease rows. Switch to another diagnostic pool with the same effective
binding: eight recipes are read again and emit no edit. Alter the old
inactive pool: zero actual recipe re-evaluations (eight under a strong
syntactic-dependency index). Alias the active pool: eight rows change;
an old move is newly reachable because the diagnostic now consumes the
only cancellation reserve. Safety is refuted while the deadline still
holds. Change a separate timing cell: both claims are then refuted.
The recipe counts for active traces are $8,0,8,8$, for the indexed
syntactic comparator $8,8,8,8$, and for cold $4{,}176$ each time.
The separate pinned reachability checker consumes each exact edit; both
of its original incremental methods and the full direct full-graph
reachability checks give the same outcomes and valid concrete witnesses.
The guarded source update with identical output is also tested against
an intentionally broken output-only cache: it later falsely carries
the safety verdict.

If active pool equality is unknown, the matched complete installations
give a safe law and a counterhistory; the checker reports undecided
and the separating supplier fact. This does not create a trusted
procedure to observe the resource binding. Never mix rows from distinct
admissible installations. A direct code edit changing a row formerly
reading no altered cell still invalidates that row and can expose a
reachable violation. The replay covers $512$ fixed-seed chained changes
in addition to the named cases.

\paragraph{Cost and residual.}
Recipe evaluations and subsequent graph reads are counted separately
from index maintenance and materialization. The current receiver
still copies graphs and builds indexes; no end-to-end runtime gain
is established even when almost no rows change. This is authored
post-freeze model evidence, not an independently selected transfer,
unbounded-horizon guarantee, or a deployed authority detector.
