# Risk messages before a query

[Proof and two exact bounds](Risk_Bits_Before_The_Query.tex) · [model freeze](FREEZE.txt).
All labeled pair diagnostic laws can agree while the exact admission answers
over ten candidate bundles range independently. A fixed-length sender that
does not yet know which query will be asked needs ten bits on that family.
The direct full-state replay also tests a nested menu with variable caps.

    python3 -B replay.py | cmp results.json -

The checker requires Python 3.10+. This is a model of exact admission
and one-way communication, not a field measurement or a claim about
approximate reports.

The [calibration follow-up](calibration/README.md) gives matching-order sample bounds when the sender must learn the menu from full observations rather than receiving the law.

An [episode-linkage follow-up](episode-linkage/README.md) distinguishes hidden linking, verified labels, and outcome-dependent selection before fitting the menu.
