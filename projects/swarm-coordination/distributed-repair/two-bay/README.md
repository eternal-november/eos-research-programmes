# Two crews, two bays

Run `python3 -B pilot.py` with Python 3.12, without optimization. For byte-for-byte replay, run `python3 -B pilot.py --json | cmp results.json`.

Crews A and B already support two independent loads. Both are owed delivery to distinct capacity-one bays by tick 3. Each crew sees its own local state before committing a lever at tick 2. In two reached fixture alignments, A sees the same history (its own load remains held), whereas B sees the alignment indicator. A passive keyed guide maps A's chosen lever to an actual bay. B's guide is straight. Both moves are simultaneous, before either has evidence of the other's choice. A fail-closed gate retains the old supports if the requested bays conflict; this is safe but does not meet delivery. Waiting also misses delivery. The admitted base repertoire excludes spare supports, a third bay, and a late second choice.

The original guide is straight in both alignments. Reversing A's guide in both alignments changes A's required lever when B keeps the incumbent two-entry policy (0,0), but leaves the exact set of B policies that have a compatible A policy unchanged: {(0,0),(1,1)}. Reversing A's guide only in alignment 1 leaves A's observation unchanged and changes the exact B relation to {(0,1),(1,0)}. No upstream policy preserves the old complete B table. Either B entry separately can nevertheless stay at 0 for some repair. One entry change suffices, and keeping A's old lever is feasible with one of these repairs. Giving B a genuine reserve bay makes the constant reserve policy compatible across all three layouts, but changes the resource and action interfaces.

The checker replays physical requests and acceptance, enumerates both complete local policies, and independently joins the direct physical no-overlap factors on A's **single shared policy entry** before elimination. Exact contextual-style projection over the reached worlds retains that same entry until the conjunction and gives the same result. Dropping A's entry separately within each world would permit any B continuation in either world and incorrectly preserve the old B table. The cache equality test can stop at B for the uniform reversal only after verifying the same exact policy relation; an equality of entrywise marginals would also pass the coupled edit and would be unsound. This is a fair tie, not a proof-work advantage.

The same factor model with m B observations and keyed reversal mask g has two feasible B tables: g and its complement. It therefore has 2^(m−1) distinct exact separator behaviours, all with the same one-entry marginals. The distance from a constant zero incumbent is min(weight(g),m−weight(g)). The executable enumerates every mask through m=6. This is a family of finite models, not evidence about reachability of arbitrary physical guides, distributed online synthesis, or v0.5 cascade acceptance.
