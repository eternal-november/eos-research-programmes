# Native finite-witness wiring and double-operadic systems

This package constructs an independently specified finite-span interaction doctrine acting on retained native finite-measure writer systems. It also separates that compatibility theorem from the formal regular-module application of Libkind and Myers.

## Results and exact scope

Read [Finite witness wiring on native finite-measure systems](Finite_Witness_Wiring_Module.tex). Finite sets are interfaces, finite spans are wiring interactions, and comparison squares have a pullback input square. The native action retains each original witness and each compatible wiring witness, preserves actual coefficient maps and the entire global writer grade, and counts wiring multiplicity without normalization. The input-pullback condition is necessary and sufficient for this canonical witness-map action to preserve every native finite measure.

The action is a symmetric monoidal loose right module in the sense of [Libkind and Myers](https://arxiv.org/html/2505.18329v2), with pseudo action coherence. Typed variable-sharing cospans supply a specialization. The established span/module pattern is not claimed as new; the contribution here is its explicit native compatibility and exact comparison boundary.

Fixed-endpoint process categories are recovered by compact naming. Original dependent bind and finite-wire trace are recovered by equality wiring. Arbitrary changing-input process squares require the proved relative pullback/replication interface: direct naming does not preserve them, since collapsing input rows changes total mass.

With finite limits in both coefficient categories and all small families, each fixed-interface fibre has universal finite all-law assemblies. Wiring gives a coherent directed map from wiring a shared-boundary assembly to assembling its wired images. This is not an isomorphism in general. Raw zero-weight witnesses, alternative couplings and hidden-state identifications independently matter. A common retained boundary is part of this theorem, not a silent reduction of arbitrary distinct-interface marginal assembly.

[Regular module application check](Regular_Module_Check.tex) establishes the simpler formal bridge for the original relative quintet double category: hom followed by collapse gives an ordinary loose right module. Symmetric monoidality requires separately verified structure; joint assembly and feedback do not follow from that application alone. This note preserves the attribution and the rejected overstrong inference.

## Exact preservation boundary

[The limit-preservation classification](Wiring_Limit_Preservation.tex) sharpens the counterexamples. For this counting-witness action on all-law fixed-interface families, every binary product is preserved if and only if the span input leg is bijective and its output leg is injective. This is also exactly the class preserving every nonempty finite limit. Terminal preservation, and hence preservation of all finite limits, requires both legs bijective. This is a classification of the stated action, not a claim about all wiring semantics.

The proof retains actual family indices, raw zero-weight points and the common-boundary interface, including empty interfaces. Run `python3 check_limit_preservation.py` for bounded diagnostics: 43 small labelled spans, 1,600 pair checks on the stated finite weight grids, and a terminal-law grid. These do not replace the universal proof.
