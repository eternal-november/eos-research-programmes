# Relative synchronization by enriched completion

A source-led construction that retains the original tagged pure interface and directed native cells while adding selected synchronization objects.

## Main result

[Relative synchronization](Relative_Synchronization_by_Enriched_Completion.tex) constructs an incoming lax-cone object as an enriched category of diagram-arrow components. Completing the pure and process bicategories separately, then retaining pure-object tags, gives an identity-on-objects relative interface that preserves these selected pure-diagram limits. No framed companion/conjoint hypothesis is imposed on the original interface.

Original native hom categories are recovered as full subcategories of representables. The enlarged hom categories contain new arrows; the enlarged pure base is a bicategory. This does not claim limits for every process diagram.

## Construction and boundary

- [Local cocompletion](Local_Cocompletion_for_Relative_Directed_Processes.tex): reuses Kelly–Labella–Schmitt–Street to extend genuinely lax operations by homwise density. Old pure representable layers remain exact.
- [Module exactness](Module_Extension_and_Pure_Boundary_Exactness.tex): reuses Shulman's module construction, identifies a composition-closed class of exact pure algebra maps, and shows why new pure maps are not automatically exact, even for a strong monoidal functor.

## Remaining integration

Directed parallel need not preserve the new pure projections or pseudodiagrams. Tensor/state operations must separately preserve the chosen cone objects. This is not a complete feedback/concurrency unifier or a novelty claim about enriched completion. The earlier [bicategorical synchronization criterion](../bicategorical-synchronization/README.md) supplies the conditional assembly framework, not an automatic discharge of these remaining obligations.
