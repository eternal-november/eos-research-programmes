\section{Explicit provisional interface}
Let $\mathcal W$ be a category of world states and actual world arrows. For each invocation input label $u$, let $M_u(w)$ be its local-state set at world $w$, equipped with covariant passive rebase maps $a_*:M_u(w)\to M_u(w')$ for $a:w\to w'$. Input labels and invocation addresses are frozen occurrence data; changing the common world is not reinitializing an invocation. An invocation state includes finite ordered emitted slots, divided into persistent external leaves and persistent child ports. Rebase preserves their identities, all labels, relative order and incidence. Existing children cannot be silently deleted or retagged. Completion status and the entire completed local content body must also be fixed by passive rebase; command readiness need not be fixed. No naturality of initialization under rebase is assumed: new children are initialized at the actual post-world, whereas old children are rebased.

A finite configuration consists of one common world $w$ and a finite rooted invocation tree $T$, with local state $m_v\in M_{u_v}(w)$ at each node. Every existing child port has exactly one child. No terminal shape is asserted for an unfinished invocation. If a final polynomial body is wanted, local terminal bodies and their tree rendering must be supplied independently on all complete terminal configurations and all formal unused grades.

A legal paid scope $c$ at this configuration supplies a finite participant set $A\subseteq V(T)$, finite normalized raw row $(Z_c,q_c)$, actual augmented coefficient $K_{c,z}$ and, for every raw outcome $z$, one common world arrow $a_z:w\to w_z$. At each active node $v\in A$, it supplies a local successor $d_{v,c}(z)\in M_{u_v}(w_z)$ and finitely many new child ports. Every active successor preserves all old port identities, labels and relative order; only fresh ports may be added. All active successor data are evaluated from the prescope configuration and the retained outcome. Passive nodes use $(a_z)_*m_v$. New children are initialized at the post-world $w_z$, once only. The full scope may be jointly sampled across different invocation subtrees; $q_c$ is supplied data, not a product law.

Assume initialization is port-free, or more generally that its all-raw silent child relation is well founded and finitely branching with finite raw rows, so each requested initialization expands to finitely many raw possibilities. Initialization witnesses and actual coefficient factors must then be retained in the paid scope row. A probabilistic zero branch cannot be removed to obtain this guard. For simplicity the proof below uses deterministic port-free initialization; the guarded finite expansion has the same finite combinatorics with additional retained initializer factors.

\begin{proposition}[Finite operational closure]
Under the preceding conditions, one scope step sends a finite compatible invocation configuration to a finite compatible invocation configuration. Repeated finite paid execution is defined without a commutation or serializability axiom. At each fixed paid horizon from a fixed seed there are finitely many raw histories under a fixed deterministic controller, including zero histories.
\end{proposition}
\begin{proof}
A finite tree has finitely many active and passive nodes. Every old local successor lies at the same post-world $w_z$: active successors by their specified type, passive successors by rebase. Stable old slots retain the existing edges and their frozen input labels. Each active node creates finitely many fresh addressed child slots, and their finite initial states are also at $w_z$. Attaching those children creates no cycle and preserves the unique parent of each old or new node. Thus the result is another finite compatible tree. The raw row at each selected scope is finite. Inducting on paid horizon proves finite branching of histories. This proof never interchanges two scopes or claims that a simultaneous scope has a serial execution with the same post-state.
\end{proof}

\paragraph{Meaning of closure.} This is a state-construction theorem, not a law of categorical feedback. The theorem requires the actual scope availability and active successor data, including compatibility of slots with rebase. Finite trees alone do not supply them. If an active scope replaces its ancestor subtree, or rebase invalidates an existing port, a new cancellation/reconciliation interface is required. If silent initialization can have an infinite raw chain, the claimed finite state space is not closed. If a scope has infinitely many raw outcomes, the fixed-horizon finiteness claim no longer follows.

\section{Actual native comparison requirements}
For a comparison with world functor $H:\mathcal W\to\mathcal W'$, local state maps $h_u$ must be natural for passive rebase:
\[
 h_u(a_*m)=(Ha)_*h_u(m).
\]
A retained tree map must preserve incidence and match active occurrences and old/new slots. For each source scope command there must be a selected target scope command, an actual raw function $r_c$ and augmented coefficient arrows $K_{c,z}\to K'_{c',r_cz}$ satisfying
\[
 (r_c)_*q_c=q'_{c'},\qquad a'_{r_cz}=H(a_z),\qquad
 h_u(d_{v,c}(z))=d'_{v',c'}(r_cz).
\]
Seed and birth initialization maps must satisfy their actual selected-state and coefficient equations. Any full writer or formal terminal grade must have one supplied global map on every shape, including unused shapes; a witness-dependent grade choice is not allowed.

These equations suffice for a one-step tree post-square: active nodes use the active equation, passive nodes use rebase naturality, and fresh children use initialization comparison at the matched post-world. Seed comparisons relate corresponding source and target seeds, but are not a requirement that rebasing an old seed equal freshly initializing at a new world. Tensor regrouping of initializer factors is legitimate only for the declared coefficient construction; an arbitrary supplied scope coefficient is mapped by its supplied arrow, not reconstructed from primitive marginals. Conditional fibre induction then gives actual native finite-history comparisons for compatible controllers, exactly as in the reviewed command-system theorem. Context augmentation gives context/history truncation; content truncation requires separate content augmentations.

\section{Why nodewise algebra folds do not settle shared scopes}
\begin{proposition}[Primitive maps do not determine a shared-row map]
Even for two one-event invocations over a trivial world, identical primitive laws, state transitions and primitive native maps do not entail a native map between their supplied shared scopes.
\end{proposition}
\begin{proof}
Each invocation draws a fair raw bit, with unit coefficient and its bit retained in the full successor. Use full raw pair carrier $\{0,1\}^2$ for the two-participant scope, including its zero atoms. In the source put weight $1/2$ at $(0,0),(1,1)$ and zero elsewhere. In the target put weight $1/2$ at $(0,1),(1,0)$ and zero elsewhere. Both primitive marginals are fair. Require the identity primitive raw maps and the identity retained bit-state maps. Any joint raw map compatible with both primitive projections is identity on pairs, so it does not push the diagonal law to the antidiagonal law. Equivalently, the retained successor-pair square prevents changing either bit. Thus no actual scope comparison over these primitive maps exists, despite identical marginal equations and unit coefficients.
\end{proof}

The example is an obstruction to inferring a whole-scope arrow from invocation-local folds, not a proof that every strengthened shared-scope algebra category lacks initial objects. A map that changes retained bits or replaces the target joint is a changed comparison. A quotient forgetting those bits is a changed observer. Neither repairs the specified claim.

\paragraph{A second missing obligation: coefficient assembly.} Even after exact raw joint transport is supplied, local coefficient arrows do not automatically assemble to the required scope coefficient arrow. A joint scope may use a boundary pullback coefficient rather than the tensor of its active primitive factors. The reviewed augmented $k^2$ example distinguishes dimensions three and four. For a construction by joint limits, a natural comparison is obtained from the actual compatible cone; for a merely supplied joint coefficient, an actual arrow must be supplied. An independent tensor regrouping theorem cannot stand in for either requirement.

\section{New lift-uniqueness test for whole-scope maps}
\begin{proposition}[Supplied joint coefficients can hide native-map freedom]
Restriction from whole-scope native maps to their primitive row and coefficient maps need not be faithful, even with identical raw laws, world arrows, post-states and full writer maps.
\end{proposition}
\begin{proof}
Work over a field $k$ with augmented vector spaces. Both primitive raw rows are singleton Dirac rows with unit coefficient $k$. The joint raw carrier is also singleton with mass one. Supply the joint coefficient $J=(k^2,\operatorname{pr}_1)$ and both cone legs $p_1=p_2=\operatorname{pr}_1:J\to k$. Use trivial world and state transitions and full singleton writer grade with unit coefficient. For each $\lambda\in k$, the actual augmented arrow
\[
 A_\lambda(x,y)=(x,\lambda y)
\]
is a whole-scope endomorphism over the identity primitive arrows: $p_iA_\lambda=p_i$ and its augmentation is unchanged. In particular $A_0\ne A_1$. Raw pushforward, world, post-state and writer-body equations coincide for these maps. The native maps themselves differ on the retained joint coefficient. This coefficient is supplied cone data, not the categorical limit of the two unit legs. No quotient by primitive projections is permitted.
\end{proof}

This is a nonuniqueness witness for extensions of a specified primitive fold. It is not, without a separately defined endofunctor and algebra equation, a claim that two algebra morphisms exist. An algebra's whole-scope arrow may fix the missing coordinate. A proof that only checks primitive fold equations, however, has not fixed it. The familiar diagonal/antidiagonal law example detects failure of existence; this coefficient example independently detects failure of uniqueness after all scalar law equations already hold.

\paragraph{Scope-lift criterion.}
Fix the world functor, state maps, occurrence matching and target scope command, as well as matched finite participant diagrams, primitive raw maps, primitive actual coefficient arrows and full primitive writer maps. Uniqueness below concerns the local raw/coefficient/full-grade lift over these fixed data, not unrelated world functors, menu functions or entire system maps. Suppose the following independently supplied doctrine holds.
\begin{enumerate}
\item The raw joint carrier is the actual limit of its matching diagram, with retained projections, and primitive maps are a compatible map of diagrams. Participant occurrence matching is specified; merging two active occurrences is not silently used as a bijection of diagrams.
\item At each raw joint atom, the joint context coefficient is the actual limit of its coefficient diagram. Scope coefficient arrows are required to commute with every retained projection. The required limits exist in the admitted augmented category.
\item The entire writer family, including every unused shape and its actual coefficient, is constructed by the corresponding full-family limit or another specified assembler that is an actual functor defined on every admitted matched diagram map and whose action is projection-detecting. Thus the alternative supplies the assembled arrow, not merely faithfulness if one exists. Its maps are likewise required to preserve the primitive projections. Merely checking realized bodies is insufficient.
\item The intended full scope post-state/body factors through the assembled interface, and the supplied active/rebase maps give its actual commuting square. Matching actual world arrows, not only endpoints, is part of the diagram.
\end{enumerate}
Then there is at most one scope native map extending the specified primitive maps and the prescribed assembler constraints. There is exactly one if the induced raw map pushes the source joint law to the selected target law and its constructed full body square holds. The raw map is forced by raw-limit projections; the actual coefficient arrows and full-grade arrows are forced by their respective limiting cones or the specified projection-detecting assembler. Conversely these unique maps satisfy all native fields precisely under the effect and full-body conditions. This is an explicit local existence/uniqueness criterion, not an assumption that marginal probabilities determine a joint.

For an all-admitted-joints menu, the target command can instead be the induced pushed joint, provided it is admitted. For a fixed target joint, the equation must be checked. For supplied nonlimit coefficients, the same criterion replaces uniqueness by the actual fibre of augmented hom-sets over the primitive cone maps; the preceding example makes that fibre non-singleton. No amount of scalar verification can shrink it.

\paragraph{Composition and regrouping obligation.}
With actual limits and projection-preserving maps, identities and composition of the unique lifts follow by testing every primitive projection. This proves functoriality of scope-map assembly on the specified diagrams. Root decomposition can use this result only when it preserves the full flat participant diagram, its complete chosen joint law, and its complete coefficient/content cone. Grouping a diagram into child blocks and retaining only their marginal laws loses cross-block correlations; grouping only some cone legs can lose uniqueness of coefficient maps. Canonical rebracketing is justified when both presentations retain the same flat diagram and joint datum, or when an actual limit-of-limits comparison retaining all cross-boundary constraints is proved. It is not a generic tensor-factorization law.

\section{What an initial-algebra claim would have to prove}
A root constructor for invocation trees is a configuration-level bijection between a root local state with its child configurations and the grafted tree, provided all components share the same world and slot incidence is retained. That bijection is not yet an isomorphism of controlled transition systems. A scope may include the root and several descendants or cross two different children. To transport it across root decomposition, the constructor must retain that entire scope command, its complete raw joint carrier and law, world-arrow data, actual scope coefficient, and full body.

An independently defined endofunctor $T_P$ on proposed native systems would need the following concrete operations, not just the configuration formula.
\begin{enumerate}
\item Restrict each legal global scope to the blocks determined by root and immediate child subtrees. The resulting block scopes, with their actual raw marginals and retained world-event coordinates, must be legal in those child systems. This is an admission condition; an arbitrary selected set of joints need not satisfy it.
\item Retain the remaining cross-block coupling as global data in $T_P$, rather than replace it by a product of block laws. Root grafting must preserve its raw witnesses and weights bijectively, including zeros.
\item Given child native maps, construct the whole-scope raw map by the actual compatible block maps and push forward the global law to an admitted target command. The target law must equal that pushforward. Fixed target choices need their own descent/equality law.
\item Construct the actual global coefficient arrow naturally from the specified joint assembler, or supply it as structure with composition laws. Root decomposition and reassembly must agree on this arrow, not only on primitive projections unless those projections are jointly faithful in the relevant coefficient interface.
\item Prove scope post-squares for active descendants, passive rebase and newly born children simultaneously. A root action can change child readiness; it cannot be treated as leaving child configurations fixed.
\item Prove constructor and fold equations on menu functions, whole-scope raw maps, coefficient arrows and the entire unused terminal grade. Uniqueness on configurations alone does not imply uniqueness of native cells.
\end{enumerate}

These are tests for a proposed endofunctor, not axioms being asserted to hold for arbitrary shared worlds. Once such a functor is independently defined, finite structural recursion is a possible method for constructing a fold: first fold child configurations; obtain the actual block scope maps recursively; use the global scope assembler; then apply the proposed algebra's native whole-scope map. This is a valid proof strategy only if each block recursion has smaller finite invocation height and the listed operations really exist. The present note does not assert a general initiality theorem from this strategy.

\paragraph{Decisive interface choice.} The all-admitted-joints menu can make forward transport easier by naming the pushed joint as the target command, provided admission is closed under the actual compatible maps. It does not solve fixed-controller descent, joint coefficient functoriality, scope restriction, or resumption naturality. Conversely an algebra morphism that is already required to preserve whole-scope rows must satisfy these stronger equations; primitive marginal conservation cannot be used as a proof that it exists. Retained coupling parameters are control data and cannot be silently promoted to the controller's observable history.

\paragraph{Current conclusion.} Finite labelled invocation configurations can be closed under genuine multi-active shared scopes and passive rebasing on the stated interface, without serializing them. The control-sensitive native feedback algebra remains a separate construction. The fair-bit joint obstruction rules out a nodewise-marginal proof of it. A candidate satisfying the explicit whole-scope functor and constructor obligations may survive, but neither initiality nor a complete open polynomial assembly has been established here.
