This defines an operational ambient of arbitrary locally finite incremental causal implementations, rather than merely rebracketing one supplied global schedule. Its open composition is proved before any strategy is selected. Selected strategies do not form a horizontally closed category by taking pairs of standalone policies. \section{Intrinsic operational objects}
\begin{definition}[Locally finite incremental causal arena]
An arena $P:A\rightsquigarrow B$ consists of the following data.
\begin{enumerate}
\item A set of configurations $S_P$ with an input anchor $S_P\to A$, an initial configuration $i_P(a)$ over each $a\in A$, and stable identifiers for possible events and output ports. All transitions preserve the anchor. Configurations outside the raw reach of the designated initial configurations remain part of the arena and all native maps; none are quotiented away. Event and port identifier sets are exactly their occurrence unions over all configurations, including those unreachable from designated initials. There are no additional never-occurring namespace coordinates carrying unconstrained map data. Raw reachability, when used, includes all zero-probability outcomes.
\item At each configuration $s$, a finite set $E_P(s)$ of enabled event identifiers. An enabled event $e$ has a normalized finite native row
\[
 (W_{s,e},\mu_{s,e},K_{s,e,w})
\]
and a deterministic transition $s[e,w]$ for every $w\in W_{s,e}$. An event identifier occurs at most once in a raw execution. After firing, $e$ is no longer enabled; its executed occurrence remains in the raw history.
\item Persistence, row stability and the diamond equation: for distinct $e,f\in E_P(s)$, firing either leaves the other enabled with literally the same native row, and
\[
 s[e,w][f,z]=s[f,z][e,w].\tag{D}
\]
The identities of surviving and newly enabled events and ports, and every port inclusion, agree in this equality. Row stability here is literal equality of raw sets, weights, augmented coefficient objects and their structural identity maps. Hence the raw/coefficient diamonds are actual identity isomorphisms, not noninvertible pushforward comparisons. For any finite simultaneously enabled set the higher cubes are the same tuples and these same identities; tensor reorderings satisfy symmetric-monoidal coherence. An alternative presentation with chosen row isomorphisms would have to supply the corresponding cube coherence explicitly. These conditions are structural, independent of any selected coupling or strategy.
\item A finite linearly ordered set $O_P(s)$ of already emitted output ports, labelled by $\ell_s:O_P(s)\to B$. Each transition preserves existing ports, their labels and relative order, and may add fresh ports. New ports have unique births, so two independent events create disjoint new ports. Port inclusions compose under (D); new ports may occur between previously emitted ports in the final order. Configurations with $E_P(s)=\varnothing$ are terminal. No global execution bound or termination hypothesis is imposed. Call an arena bounded when from every configuration there is a finite bound on all raw execution lengths. That optional bound is a finiteness property, not chosen data that associators must preserve.
\item One full weighted polynomial collection $C_P=(C_n,R_c)$, including unused shapes. At every terminal configuration $s$ a shape $c_P(s)\in(C_P)_{|O_P(s)|}$ is supplied. Together with the ordered port labels this is the terminal body in $F_{C_P}B$. This content grade is independent of the context-row coefficients. It is not reconstructed from positive support or inferred from an unlabelled transition graph.
\end{enumerate}
\end{definition}
Initial configurations may already emit ports; this is necessary for genuine pure identities. Outputs are incremental, not a batch returned only when the whole arena becomes terminal. A primitive original process emits all its ports at its single event, but a composite will generally emit some ports while other calls remain pending.

A raw history records the initial input, every selected event scope, and every raw event outcome. It does not replace the configuration: different histories may reach the same configuration and a strategy may distinguish them. Scheduler decisions and coupling choices are external control-table entries, not additional probabilistic raw draws. Stable identifiers may be taken in a fixed universe. At every fixed number of selected scopes there are finitely many raw histories from a given configuration, so all finite histories are countable. In a bounded arena there are only finitely many such histories. No finiteness is imposed on the entire global configuration set or shape collection.

\begin{definition}[Native arena map]
A fixed-endpoint map $P\to P'$ consists of a configuration map $h$, global event and output-port identifier functions on those occurrence unions, one full weighted-content map $\gamma:C_P\to C_{P'}$, and actual native maps of all enabled rows. It preserves input anchors and initial configurations, and is specified on every configuration, not only initially reachable ones. At each $s$ its event map gives a bijection $E_P(s)\to E_{P'}(h(s))$, its port map gives an order-preserving bijection $O_P(s)\to O_{P'}(h(s))$ preserving labels, and its raw maps satisfy
\[
 h(s[e,w])=h(s)[e',r_{s,e}(w)].\tag{M}
\]
The row maps, their actual coefficient arrows and identifier maps are coherent under persistence squares. Since row persistence here is literal identity, this requires equality of the raw row functions and of their actual coefficient arrows before and after an unrelated enabled event; a configuration diamond alone does not suffice. At terminal states the full content/body square holds, including the actual $\mathcal R$ maps in $\gamma$ on all shapes. Identifier maps need only be bijective on the active/emitted sets in each compared configuration; mutually exclusive raw branches may be merged. Native maps compose by these actual data. Pure input reindexing and pointwise output transport are defined separately in the usual way.
\end{definition}
No policy descent is included in this definition. In particular a map can identify raw histories with different selected continuation controls.

\section{Arbitrary open horizontal composition}
Let $P:A\rightsquigarrow B$ and $Q:B\rightsquigarrow Z$. A configuration of $Q\circ P$ is
\[
 \bigl(s,\ (t_p)_{p\in O_P(s)}\bigr),\qquad s\in S_P,
\]
where $t_p$ is any configuration in the input fibre of $Q$ over $\ell_s(p)$. Include every such configuration family, including initially unreachable ones. During execution a new copy starts at its initial configuration immediately when its port $p$ is emitted; it does not wait for $P$ to become terminal. The enabled set is the disjoint union
\[
 E_P(s)\ +\ \coprod_{p\in O_P(s)}E_Q(t_p).
\]
A $P$ event updates $s$, retains all existing copies, and initializes a new $Q$ copy at each newly emitted port. A $Q$ event updates only its own copy. The enabled native row is the corresponding original row. Output ports are pairs $(p,q)$ with $p\in O_P(s)$ and $q\in O_Q(t_p)$, ordered lexicographically; their label is the $Q$ label. The initial configuration contains the $Q$ initial copies at every initially emitted $P$ port.

The full global grade is $C_P\circ C_Q$, the original weighted polynomial substitution. At a terminal configuration the shape is
\[
 \bigl(c_P(s),(c_Q(t_p))_{p\in O_P(s)}\bigr),\tag{G}
\]
with content coefficient $R_{c_P(s)}\otimes\bigotimes_p R_{c_Q(t_p)}$. This grade is the full substitution collection, not the subset of shapes attained by any configurations.

\begin{theorem}[Open arena assembly]
The construction is an arena for every pair of well-typed arenas. It is functorial on all native arena maps. Together with the pure identity arena it defines a bicategory of interfaces, incremental causal arenas and native maps. Its associators and units preserve the complete open coupling-port interface, actual context-row maps, full unused content grades, and terminal bodies.
\end{theorem}
\begin{proof}
For two enabled $P$ events, the structural diamond and port inclusions of $P$ agree; the same newly emitted ports initialize the same copies. For two $Q$ events in one copy use its diamond, and for different copies their updates are disjoint. A $P$ event cannot alter the label or configuration of an existing $Q$ copy; its update therefore commutes with a $Q$ event already enabled there. In every case surviving rows are unchanged. Output-port persistence and order preservation follow from the corresponding two component properties. Fresh births remain distinct under tagged pairing.

At each composite configuration there are finitely many component copies, enabled events, emitted ports and raw outcomes per event, so local finiteness is preserved without a termination assumption. If both components are bounded, then from a fixed composite configuration there are finitely many raw-reachable $P$ configurations and therefore finitely many newly emittable labels/ports. Adding the remaining $P$ bound, all existing-copy bounds and every possibly newly initialized-copy bound proves that bounded arenas form a composition-closed sub-bicategory. Finite raw branching is essential for this optional boundedness argument. Terminality is exactly terminality of $P$ and every initialized $Q$ copy. Thus (G) is a correctly typed body. Native maps act componentwise, indexing target copies by the supplied port bijection. Equations (M), actual coefficient-map functoriality and the full weighted substitution map prove functoriality and the body square.

A triple composite in either parenthesization consists of exactly one $P$ configuration, a $Q$ configuration for each emitted $P$ port, and an $R$ configuration for each emitted pair $(p,q)$. Its enabled events are precisely the same tagged $P$, $Q$, and $R$ events, with the same native rows. Rebracketing the configuration and identifiers is therefore an operational isomorphism, not a rescheduling. Output ports identify $((p,q),r)$ with $(p,(q,r))$. Full grade readdressing is the original polynomial substitution associator; its actual $\mathcal R$ map reassociates/permutates the same full tree factors, including unused trees. The terminal body (G) commutes with that map. All pentagon paths flatten the same four-level configuration family, event identifiers, port identifiers and complete weighted shape tree; hence they agree. Naturality and interchange follow componentwise on actual maps.

The identity arena on $B$ has no events, initial and terminal state labelled by $b$, one immediately emitted port with a single fixed identifier $*$ shared by all input configurations and label $b$, and unary unit content. The identifier is not the input value $b$. Zero-event pure-map arenas use this same fixed singleton identifier. Composing on either side inserts only trivial copies or singleton port tags. Removing them gives the operational unitors and the original grade unitors. Their triangles agree on every configuration, enabled row and full content factor. Importantly this pure unit is not an additional sampled singleton event.\end{proof}

This is an intrinsic closure theorem for arbitrary arenas satisfying the stated operational axioms. No admission condition says that the desired associator must already exist. Persistence and incremental ports are precisely the hypotheses used in the construction. Opaque batch processes without incremental continuation ports need not admit this composition: a global wait-for-all barrier would change the right-parenthesized enabled sets.

\section{Pure interfaces and relative assembly}
Work in the same nested-universe convention as the original category-valued modules. For $u:A'\to A$, reindex the arena configurations to $A'\times_A S_P$, retaining the same rows, transitions and full grade. Event and port identifiers are the same original identifiers occurring in these pulled-back configurations, not pairs with the new input label; their sets are restricted to the resulting occurrence unions. This convention makes the pure-middle balance below global on identifier functions even when a port identifier occurs in different input fibres. For $v:B\to B'$, retain configurations, events and grade and apply $v$ pointwise to every emitted port label. These operations give the category-valued module
\[
 \mathsf{Arena}:\mathrm{Set}^{\mathrm{op}}\times\mathrm{Set}\longrightarrow\mathrm{Cat}.
\]
They are genuine pure operations, not additional singleton sampled events.

For $P:A\rightsquigarrow B$, $v:B\to B'$, and $Q:B'\rightsquigarrow Z$, the two balanced composites $(v_!P);Q$ and $P;(v^*Q)$ have configurations
\[
 (s,(t_p)_{p\in O_P(s)})\quad\hbox{and}\quad
 (s,((\ell_s(p),t_p))_{p\in O_P(s)}),
\]
where $t_p$ lies over $v\ell_s(p)$. Forgetting or restoring the redundant label is an operational native isomorphism. It preserves all enabled rows and actual arrows, full content grades and every emitted port. These isomorphisms are natural on native maps and satisfy identity/composite balance relations by equality of the same tags and configurations. Their compatibility with horizontal associativity follows by flattening the same component family. Consequently horizontal composition descends through the original relative pseudocoend on pure-middle maps. The zero-event unary pure arenas provide the unit module. Thus the intrinsic arenas supply an actual relative pseudopromonad on these independent pure interfaces, not just a fixed-schedule interpretation.

The independent evaluator below respects these pure actions and balances: its complete traces are unchanged by pointwise relabelling or input reindexing, and its full grade/body maps are the original ones. Its multiplication/unit comparisons therefore constitute a strong map of the resulting relative structures into $H_{\leq}$. This is a conservation theorem for the independent interpretation, not an invertible source inclusion.

There is also a direct zero-event realization of the original pure content module $N(A,B)$: a representative $(C,f:A\to F_CB)$ has one terminal initial state per input, emits exactly $f(a)$, and retains the whole weighted $C$. Native cells are exactly its full content maps and body squares. This realization is locally fully faithful on each native hom category. No strong realization of content composition is asserted in the global-identifier map doctrine. Indeed choose position-rank identifiers for the zero-event realization. If an outer output has two slots and the first inner output has arity one at one input but arity two at another, while the second inner output always has arity one, the composite tuple identifier $(2,1)$ must flatten to rank two in the first configuration and rank three in the second. No single global port-identifier function can realize that ordered flattening. Input-tagging identifiers is not silently substituted: it can obstruct pure unit/balance comparisons at noninjective input maps. The intrinsic tuple-identifier arena composition remains coherent, but the source's flattened-position content realization is not thereby a strong content functor. Allowing configuration-indexed identifier maps coherent along transitions would be a separately enlarged map doctrine, not a notation change.

The original pure context module $M$ has the one-event realization with unary unit content; all original row and coefficient maps survive. As in the original mixed source, additional endomorphisms of the content unit can prevent local fullness unless they are trivial. That realization does not preserve context multiplication or its unit by native comparison maps: the event-count obstruction below applies already to deterministic contexts. No opposite claim is hidden in the relative assembly theorem.

\section{Open coupling ports and selected control cells}
At a nonterminal raw history $h$ ending at $s$, a port offers every pair
\[
 \varnothing\ne J\subseteq E_P(s),\qquad
 q\in\mathsf{Coup}(\mu_{s,e}:e\in J).
\]
The set is independently nonempty: select any enabled event, or any finite nonempty subset with its product law. The parallel update by $J$ is well-defined by repeated (D). Its context coefficient is $\bigotimes_{e\in J}K_{s,e,w_e}$. A complete deterministic strategy specifies a scheduler subset and a coupling at every structurally valid raw history rooted at every configuration, including zero histories, histories outside the designated initial reach, and histories using earlier scheduler choices different from this table. Evaluation admits only histories following the selected scheduler choices (while retaining every raw outcome including zeros); alternate scheduler plans are not inserted as fictitious zero-weight raw witnesses. The additional off-policy tables remain explicit control data. A history records the selected subsets, but their probabilities are not counted: their selection is deterministic control.

Operational arena isomorphisms transport all ports bijectively, therefore all complete strategy tables. The associator in the theorem consequently transports the same full history table; it neither averages policies nor resamples a block. At a general native map $h:P\to P'$, define $R_h(\sigma,\sigma')$ by the conditions at every source raw history: the target selected subset is the event-bijection image of the source subset, and the product raw map pushes the selected source $q$ exactly to the target $q'$. These conditions include zero histories and all actual native row maps.

\begin{proposition}[Lax native control action]
$R_1$ is equality, and $R_kR_h\subseteq R_{kh}$. These inclusions are unital and associative. Objects $(P,\sigma)$ and native maps $h$ satisfying $R_h$ form an ordinary category. Every such map induces an exact native map between the evaluated terminal rows, with its actual tensor coefficient arrows and full grade map. The arena associators/unitors induce compatible isomorphisms of these control relations.
\end{proposition}
\begin{proof}
The scheduler equations compose via the event bijections, and the conditional pushforward equations compose by ordinary function pushforward. Hence the inclusion. For three maps, both inclusion paths assert exactly the composite conditional equation and scheduler equation; this proves coherence, not equality in the reverse direction. Induction at each finite scheduled horizon gives exact prefix pushforward. Terminality is reflected by the enabled-event bijection, so restriction to each exact terminal-step stratum preserves the fibre equations. Summing those disjoint strata by nonnegative countable Fubini gives terminal raw pushforward, since matching selected scopes have normalized rows and the same conditional target law on every source-prefix fibre. Tensoring the supplied coefficient arrows and applying the full terminal body square gives the actual native cell. Associator compatibility follows from its operational identification of event subsets, rows and histories.\end{proof}

The reverse inclusion can fail: an intermediate native map can merge source histories having different pushed choices, while a later raw collapse makes them identical. Thus the relation assignment is not a functor to relations with equality of composites, and its selected category is not automatically a fibration. More importantly, a pair of standalone selected strategies is not the input to open horizontal assembly. The composite arena has new global-history ports, including joint scopes crossing component boundaries. Such a strategy need not restrict to a local-history strategy on either component. The theorem gives composition of open arenas and a coherent semantic control interface, not an unjustified horizontal category of local selected policies.

\section{The independent evaluator and original-source recovery}
A strategy is independent when every chosen-scope law is the product of its primitive event rows. Its scheduler may be any deterministic nonstalling table. Write $H_{\leq}(A,B)$ for the explicitly enlarged category of countable subprobability raw rows, actual augmented $\mathcal E$ coefficient arrows, full weighted collection $C$ and body in $F_CB$, with exact native fibre pushforward. Composition uses the ordinary independent product of subprobability rows and tensor coefficients. Countable nonnegative Fubini and tensor/coefficient coherence give its mixed composition. Products of subprobability rows are not claimed to be couplings having those rows as their original marginals. Here the original finite normalized $H$ is explicitly taken with coefficient rig $\mathcal A=\mathrm{Vect}_k$: ``finite'' refers to raw rows, not vector-space dimension. It is the full corresponding subcategory, and bounded arenas evaluate there. Recovery of a smaller coefficient subdoctrine such as $\mathrm{FinVect}_k/k$ additionally requires all primitive coefficient objects and maps to lie in it; finite tensor closure then preserves that restriction.

A complete raw event trace is a sequential terminal event/outcome history modulo exchanges of adjacent simultaneously enabled events using (D). Its outcome data, including zero-probability assignments, are retained.

\begin{theorem}[Independent scheduler invariance and evaluation]
For every arena and initial input, every deterministic nonstalling independent strategy has terminal raw histories canonically bijective with complete raw event traces. Under that bijection the weight is the product of all primitive row weights, the context coefficient is the tensor of their actual coefficient objects, and the terminal body is unchanged. Consequently there is a well-defined native evaluator
\[
 \mathsf{Eval}_{\rm ind}:\mathsf{Arena}(A,B)\longrightarrow H_{\leq}(A,B)
\]
independent of a selected scheduler up to the stated actual native isomorphisms. It preserves horizontal composition and units by invertible native comparisons, at the original full substituted grades.
\end{theorem}
\begin{proof}
First split a selected finite scope into any sequential order. Persistence and (D) show this is a valid history with identical final configuration; independence gives the same product weight, and symmetry supplies the actual coefficient map. Different orders are precisely the permitted exchanges.

For a complete trace, a deterministic scheduler reconstructs a unique history: at each prefix select its prescribed subset and read the corresponding event outcomes in the trace. To justify that these events can be moved to the front, use persistence. Any event currently enabled must occur in every terminal extension, since no other event disables it and a terminal configuration has no enabled events. It can be exchanged leftward past every preceding event because it was enabled throughout; the row-stability and diamond hypotheses make each exchange valid and preserve its raw value. Repeat for the selected subset and then the residual trace. A given complete trace has finitely many events; every selected nonempty scope removes at least one of them, so this reconstruction terminates within that finite event count, without a fairness assumption on infinite executions. This proof does not exclude zero outcomes. Conversely splitting the scheduler history gives its unique trace, proving the bijection.

Finite-horizon mass conservation, with terminal histories absorbed only for bookkeeping, shows that the countable union of disjoint first-terminal strata has total mass at most one. A bounded arena has no infinite executions, so its total is one and its raw terminal set is finite. Every individual terminal coefficient remains a finite tensor. The product formula and actual tensor permutation are invariant under the same exchanges. Native arena maps preserve those exchanges by their coherence requirements, so they induce maps of traces. To prove the native fibre equation without assuming policy descent, choose a deterministic target scheduler and pull its chosen subset back at each source history through the enabled-event bijection. The raw history map is defined recursively, so this pullback scheduler is well-defined even when different source histories merge. Both laws are independent products, and the component row maps push the source product to the target product at each such history. Finite prefix induction and subsequent nonnegative summation over exact terminal-step strata therefore give exact terminal-history pushforward. Passing through the trace bijections gives the asserted native trace map; its raw map and actual coefficient arrows are the same componentwise ones for every scheduler choice. No forward descent of an arbitrary source scheduler is used. Actual tensor arrows and the full grade/body square are retained.

In a composite $Q\circ P$, move all $P$ events before all $Q$ events by the exchange argument: every $Q$ event before a remaining $P$ event belongs to a previously emitted port and commutes with that $P$ event. Then group the $Q$ copies in port order. Thus complete traces are bijective with a complete $P$ trace followed by one complete $Q$ trace for each emitted port. Their weights are precisely the independent dependent product (countable subprobability in the unbounded case); nonnegative Fubini justifies its summation. Their coefficient is the original tensor of the outer coefficient with the occurrence tensor of inner coefficients. The full grade and body are (G), exactly original mixed composition. Three composites give the same addressed primitive trace, so the comparison pentagon and units hold on actual native maps.\end{proof}

\begin{theorem}[Faithful atomic source and its precise limitation]
Each original finite process $F=(P,C,f)\in H(A,B)$ defines a one-event arena $I(F)$: at input $a$ its event has row $P_a$, and after raw outcome $w$ it terminates and emits exactly the ordered labels and shape in $f(a,w)$. All raw outcomes, including zeros, are terminal configurations. This gives a fully faithful functor on each native hom category, and $\mathsf{Eval}_{\rm ind}I\cong1_H$.

It does not give a lax or oplax composition/unit functor of the original interaction into this strict native-map arena bicategory, and in particular not a strong inclusion. An atomic $I(GF)$ has one indivisible event while $I(G)\circ I(F)$ exposes intermediate events and joint-control ports. Similarly $I(1)$ has a singleton event, whereas the arena identity has none. Those differences can affect later shared policies and cannot be removed by an operational scope isomorphism. More strongly, two successive deterministic singleton events admit no native arena map in either direction to one deterministic singleton event: after the first transition one side still has an enabled event and the other is terminal, contradicting the required enabled-event bijection. The zero-event unit likewise has no native map in either direction to the atomic identity. Thus even lax or oplax source comparisons require an explicitly enlarged cell class.
\end{theorem}
\begin{proof}
An original native cell supplies exactly the event row map, terminal raw configuration map, ordered port bijections and full content map of the atomic arena. Conversely the transition square forces every terminal configuration map from its raw row map, and the terminal body square is the original comma equation. The actual context and global-content arrows are independently stored, so equality is reflected. There is only one nonempty event subset and its coupling law is the prescribed row law; evaluation returns the original process with canonical unitors. Any proposed comparison in the strict native-map class would require the enabled-event bijections at the intermediate configurations, which fail in the stated deterministic examples. The result is a section only at the family of native hom categories, not a source bicategory functor or an internal adjunction.\end{proof}

\paragraph{Material source separation.} The independently defined $M,N,H$ remain those of the original source. Pure endpoint actions on arenas are genuine reindexing/output transport, not sampled calls. Atomic inclusion retains every original native $H$ cell, but it does not identify atomic pure processes with zero-event structural maps. The strong independent evaluator supplies conservation of original composition; a stronger faithful scope-preserving embedding is obstructed. This is a causal implementation resolution with an exact semantic retraction, not a claim that all E1 interaction coherences have been solved by changing the meaning of pure maps.

\section{Contraction and feedback boundary}
A semantic contraction of an entire selected finite execution can keep its complete terminal raw transcript, law and tensor coefficient. That does not make arbitrary local contractions stable under open horizontal contexts. For example, let one branch have two successive fair draws $Y_1,Y_2$ and a sibling have $X_1,X_2$. Jointly sample $Y_1=X_1$ in the first scope and $Y_2=X_2$ in the second. Both branch-local two-bit laws are independent fair. Replacing only the first branch by one atomic product row $(Y_1,Y_2)$ cannot preserve this shared law: if sampled before/with $X_1$, later $X_2$ must remain fresh fair conditional on known $Y_2$; if sampled after/with $X_2$, the earlier known $X_1$ prevents its first marginal from remaining fresh fair. Contracting both complete branches as one global scope is a different operation.

A sound restricted contraction must therefore seal a whole-scope block between stopping barriers, forbid outside calls/scopes inside it, retain the full incoming prefix as an actual dependent input, keep the complete internal transcript including zeros, and decode it for every later control. Even then descent to a smaller endpoint requires a separate law/body/grade factorization. No arbitrary contraction-whiskering theorem is asserted here.

The locally finite arena definition already permits unbounded execution; its bounded sub-bicategory is the finite source resolution. The event/port interface is designed for the tensor event-ideal clock construction: selected finite scopes are enabled antichains; cuts retain a downward-closed executed event set and its entire paid history. The present manuscript does not yet construct guarded recursive spawning, prove fairness/liveness invariance, or identify different step-count clocks. Any feedback comparison must use the separately proved actual event-ideal/tensor maps, not merely an analogy with a trace.
