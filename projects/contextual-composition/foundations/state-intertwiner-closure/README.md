# State intertwiners and instantaneous closure

[The manuscript](State_Intertwiners_and_Instantaneous_Closure.tex) compares [finite-measure native feedback](../finite-measure-native-feedback/README.md) with [retained-state native intertwiners](../native-intertwiner-feedback/README.md). Its finite-state weighted-writer hypotheses retain raw witnesses, directed coefficient maps and entire global content grades.

An exact deficit formula characterizes when the canonical closed-witness map preserves the state-fibre-weighted target measure. The criterion is loop-reflection on positive-weight witnesses, not deletion of zero-weight data. Bijective state maps give ordinary native closure comparisons; reflecting constant-degree covers give degree-scaled ones. Arbitrary state intertwiners do not preserve instantaneous trace.

A second construction equips states with declared finite seeds and changes the target cells to mass-subpreserving native maps. It accommodates all seed-preserving state comparisons and disjoint once-updated machine assembly. The normalized probability fragment remains locally fully embedded, but arbitrary finite-measure processes acquire new comparison cells. Seeded closure is not JSV trace or recurrent execution semantics; its directed cells certify upper bounds, not equal behavior.

The written arguments were independently reviewed. No novelty, proof-assistant certification or TeX-compilation claim is made. General shared-register interaction, branching, infinite execution and the broader [v0.2 completion question](../../contracts/Native_Feedback_and_Interaction_Extension_Contract_v0_2.tex) remain open.
