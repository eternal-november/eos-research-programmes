# Native state assembly in the relative module completion

This general categorical tranche joins the previously constructed relative module completion to native state assembly. Its inputs include a specified pure interface, coherent strong pure actions, and the separately stated normal-lax parallel/exactness assumptions. It does not manufacture these from a bare relative pseudopromonad.

## Reading order

1. [Pure-strand action transfer](Pure_Strand_Actions_in_Module_Completion.tex): strong pure actions survive homwise density and paired module balancing. Pure-strand exactness is distinct from pure-time-layer exactness.
2. [Horizontal native-state assembly](Horizontal_Assembly_of_Native_State_Bicategories.tex): the resulting hom bicategories assemble into a tricategory under the stated action package, with native three-cells retained.
3. [Derived fixed-interface synchronization](Derived_State_Synchronization_in_Module_Completion.tex): explicit diagram-cone presentations are preserved by fixed-interface actions, giving created native dialgebra lax limits.
4. [Finite-depth joining](Finite_Depth_Native_Flattening.tex): finite retained state lists flatten by a native pseudofunctor; block joining includes explicit body conjugation across reassociation equivalences.

## Exact boundary

These are written, independently checked categorical proofs, not a mechanization. Finite-depth joining is not yet an unrestricted higher state pseudomonad. General tricategorical process inputs carry additional process three-cell witnesses; they cannot be erased by the earlier faithful-projection argument. Arbitrary shared-diagonal synchronization, instantaneous trace and a general feedback evaluation theorem are not established here. Product-index preservation is not arbitrary joint-limit preservation.

The earlier relative completion and native-synchronization foundations remain prerequisites. Original pure-interface tags and directed native maps are retained; no assumption that the original relative factory already has all framed-equipment companions/conjoints is added. Concrete language implementations are not premises of these results.
