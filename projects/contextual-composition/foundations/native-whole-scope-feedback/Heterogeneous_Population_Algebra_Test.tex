\title{A shared-world non-hierarchical algebra for heterogeneous random-birth feedback, v2}\date{16 November 2026}\begin{document}\maketitle
\paragraph{Scope.} Shared-world extension of the independently reviewed v1 semantic test for \emph{Heterogeneous Owner Request Feedback}, v1, SHA256 \texttt{86f8067dbf108833d52678c8c399e6f8a5ea6e5f359d7717469083d74cf0cf1d}. Context and writer coefficients are units; the example tests non-rigidity and genuine whole-law behavior, not general coefficient coherence. Use the free chain world category on objects $w\in\mathbb N$, generated by $a_w:w\to w+1$, and singleton input types in each tagged branch. At world $w$, every primitive paid command uses the single boundary witness with actual arrow $a_w$. Rebase along any chain arrow changes the world fibre and leaves every mode unchanged. Initializers are world-inert at their requested world. All grades and coefficient libraries are constant over worlds. No external $Z$ port is ever emitted.

A $P$ mode is $(b_U,b_B,d,k)\in\{0,1\}^4$, with one persistent recursive port iff $b_U=1$ and one persistent continuation port iff $b_B=1$. Initialize to $(0,0,0,k)$ with a fair cached bit $k$. An unfinished mode has a fair draw command updating $k$, a deterministic finish command setting $d=1$, a spawn-$U$ command when $b_U=0$, and a spawn-$B$ command when $b_B=0$. Spawning sets the respective flag, retains the cache and creates that port. A $Q$ mode is $(d,k)\in\{0,1\}^2$, initialized with $d=0$ and fair $k$, with fair draw and deterministic finish commands when unfinished. It has no output ports. Finished modes have no paid commands. All raw atoms are retained. Initializers are port-free, so the silent guard is empty, while paid commands create nontrivial recursive and continuation populations.

Define $X$ independently as finite nonempty multisets of tagged $P$ and $Q$ modes. They have no parent relation, invocation addresses or external ports. Its initializer is the singleton $P$ population with a fair initial cache; its law family is that singleton law. Completion means all members finished. Enumerate each multiset by mode and multiplicity index. A command selects a nonempty subset of unfinished occurrences and a primitive command at each. An active $P$ spawn-$U$ occurrence adjoins a fresh fair $P$ seed, and spawn-$B$ adjoins a fresh fair $Q$ seed. The complete expanded local row retains both the selected paid atom and any seed witness; the seed must be fair conditional on that occurrence's paid atom. Other local rows are the stated primitive commands. The command then chooses any whole joint law with these complete local marginals. All zero tuples and the selected-state update are part of the row. No seed is sampled outside that law, and no new seed acts in the same event. This is an independently declared menu, not the image of a free tree fold.

Give $X$ one unit terminal shape $e_n$ in every ordered arity $n\geq0$. Completed populations use $e_0$. Give $P$ and $Q$ the same full one-unit-shape-per-arity collections, with actual completed $P$ bodies using arity $b_U+b_B$ and $Q$ bodies arity zero. These full collections keep unused positive-arity shapes. There is an actual arity-preserving terminal algebra map
\[
 (C_P\circ(C_Q+I))\circ(I+U\cdot E)\longrightarrow E
\]
sending every formal shape to the unique $e_n$ of its arity and every coefficient by the unique unit arrow. It is defined on all formal cases, not only actual nullary population bodies. Paid command writers use unit full families and their actual unit maps.

Define $a:T_{P;Q}X\to X$ by multiset union of the root $P$ mode, the fixed $Q$ copy when its $B$ port exists, and the child population when its $U$ port exists. This loses both the parent relation and the designation of an occurrence as a fixed continuation rather than a member of a variable child population. It is not injective on states. To map a command, tag the root occurrence, fixed $Q$ occurrence and each canonically enumerated child population occurrence; then biject them to the canonical enumeration of the multiset union. Send the full raw joint law under this coordinate bijection. Each target selected occurrence has precisely its original complete local expanded marginal: source child commands already have such marginals, and the source root expanded command creates the same kind of fair $P$ or $Q$ seed. Hence it is an admitted target command, even for correlated simultaneous births and draws. Coefficient and writer arrows are the actual unit arrows on every raw atom.

The post-square is equality of multisets. Existing selected modes change by the same primitive raw outcome; existing passive modes are unchanged; spawns adjoin the same selected seed mode. Re-enumeration changes no population state. Initialization sends the two root cache atoms to the corresponding singleton populations, with the common raw identity and fair-law equality. The union map is defined in every world fibre and commutes with the mode-preserving rebase; completion and the empty external-port squares hold. A whole selected scope moves its common world once along $a_w$, independently of the number of selected primitive occurrences. The full terminal arrow just specified sends every completed body to $e_0$ and therefore commutes with actual bodies. These checks prove that $a$ is a native algebra at this signature.

The model does not collapse whole laws to their marginals: two simultaneously selected fair draws, or a fair newborn seed coupled with a remote fair draw, may have diagonal or antidiagonal joint laws; these remain distinct commands and can yield different cache multisets. Nevertheless invocation ancestry is absent from the semantic state. This gives an independently defined non-free target for the constructor's fold theorem, with actual request slots supplied by selected population occurrences. It does not justify arbitrary hidden-coordinate initializer maps: the displayed birth raw maps are occurrencewise and common across all laws. No claim about the full common-schema enrichment, nonunit coefficients, or arbitrary opaque parameter maps is made by this test.

\paragraph{A precise shared-update obstruction to serialization.}
Choose a population at world $w$ with two unfinished occurrences and select a paid command at each in one common scope, for example two fair draws with the diagonal whole joint. The shared boundary has one witness $a_w$ and the successor belongs to the fibre at $w+1$. If both primitive commands are instead executed as two actual successive paid events, the first ends at $w+1$ and the second ends at $w+2$; their world arrow is $a_{w+1}a_w$. These endpoints differ in the free chain. Thus no comparison which preserves the given world fibre, actual paid boundary arrow, and the requirement to execute each selected primitive command as its own successive paid event can identify this shared scope with that two-event serialization. The successor/world square already fails, regardless of whether the two cache distributions could be coupled or reproduced by additional memory. More generally $m>1$ such sequential paid events end at $w+m$, not $w+1$.

This is a bounded obstruction, not a claim of arbitrary simulation nondefinability. Forgetting the world, changing the clock, replacing the second paid event by a free operation, or inventing a compound primitive event changes the declared comparison class. The population algebra keeps its branching, random initialization, arbitrary admitted correlated whole laws, and hierarchy-forgetting union map while witnessing a nontrivial shared world update that ordinary paid serialization does not preserve.
