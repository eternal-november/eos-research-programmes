\paragraph{Scope.} An independent algebra test for \emph{Dependent Core Entry Feedback and Native Fold}, rather than an alternative feedback constructor. The target retains the strict actor/request/material provenance required by that category, but its semantic states are finite populations, not root/child constructor expressions. No arbitrary raw/support collapse is inferred.

\section{Concrete primitive data}
Take worlds $w\in\mathbb N$, with the free forward-step category. Every primitive paid command below advances $w$ by one; a shared scope of any positive number of actors uses that SAME one-step boundary. Passive rebase changes only the world index, not the stored local mode, raw record, port list or immutable birth environment. Initializers are world-inert. Let external input $A=\{a\}$, recursive inputs $U=\{r,\ell\}$, and external output labels $B=\{0,1,2\}$.

The primitive at $a$ has a singleton initializer selecting a completed actor with two $r$ ports. At $r$ the initializer witness $z\in\{0,1,2\}$ has law $p=(1/2,1/2,0)$, selects an active actor with one external port labeled $z$, and also exposes an $\ell$ port exactly when $z\in\{1,2\}$. At $\ell$ the initializer witness $t$ has the same carrier/law, selects a completed actor with one external port labeled $t$, and has no recursive ports. Every initializer is one COMPLETE primitive row, with its own selected-state map on every atom.

An old active $r$ actor has two commands. \emph{Spawn} draws $x\in\{0,1,2\}$ with law $p$, retains all existing ports, emits one new $r$ port and completes that actor, keeping $x$ as a private record. \emph{Stop} is a singleton paid row which completes it without a new port. Completed actors have no active command. Newborn actors never act in the event that installs them. Thus the silent relation is $a\to r\to\ell$, including the real zero branch $z=2$, whereas paid $r$ spawning can recur indefinitely.

Give each $r$ or $\ell$ initializer a genuine augmented context factor, for instance $\mathbb R^2$ with first-coordinate augmentation; the $a$ initializer has the unit factor. Give spawn and stop their genuine paid factors, for instance $\mathbb R^2$ each, including singleton stop. Every occurrence remains distinct, including a real unit-factor initial occurrence. A paid owner has its own paid head tensored with all fresh silent factors it causes, before the global slice product. All full terminal collections of primitive actors use one UNIT-coefficient shape in each finite arity. Their actual completed bodies use the arity of the persistent $B+U$ port list.

Birth environments contain the typed input and inherited producer/binder record. Their semantic law tables are the above fixed tables, independent of the numerical choice of a whole incoming law. Native environment comparisons may change retained binder values only through supplied common input/presence and selected-state maps; their action on local modes/ports is the explicitly corresponding relabeling. They do not execute an environment change inside a paid step. This is a nonempty immutable-value input branch of the main category.

\section{Independent population states and rows}
Fix the same actual primitive occurrence namespace and its stable planar port-path order. A population state is a finite named registry of local primitive actors, each with one of the local states above, its immutable input/environment, and all persistent port slots. A $U$ slot has a designated addressed REGION of the registry interpreted as its child implementation. Regions may be empty or contain several independent root components. Region names and occurrence ownership are supplied by the static slot/address dictionary, not recomputed from current flattened ranks. Regions form a FINITE rooted planar forest with acyclic descendant allocation. Each actor belongs to exactly one immediate region; each non-root region belongs to exactly one actual parent $U$ slot; sibling regions and their actor ownership are disjoint. Empty regions are allowed. Each region has a fixed order of its immediate actor components, and traversal expands each actor's ordered local slots, recursively traversing its $U$ regions. This supplies a unique planar external-port order independently of set enumeration. All internal region/birth incidence is well typed; unrelated top-level components are allowed. This definition does not require the state to be a rooted invocation-tree expression.

The actual external port registry is the ordered list of the actors' $B$ ports in the supplied planar region order. A root/child presentation determines this order by slot substitution, and its flattening is the same list. An empty region contributes no ports and no actor. The signature envelope retains every actual primitive declaration, binder/reference incidence and no-reader material record. Region/group bookkeeping contributes no primitive actor or factor. Completed means EVERY actual actor is completed; an empty region is the empty implementation, not a missing paid response. The world and exact output mark are the population's actual global fields.

Initial raw witnesses at input $(e,s)$ are finite named primitive initializer forests generated by the displayed finite silent schema from that input, with all individual raw alternatives and actual occurrence names. Their family imposes the complete primitive/ancestral tests at the declared binder chains, with arbitrary correlations allowed by those tests. Selected state is the union of the named primitive records and their region/port incidence. This is an independent finite schema evaluation; no semantic state is defined to be an element of an already constructed free algebra.

At ANY such population state, including populations not initially generated, choose an arbitrary finite compatible subset of old active actors and their displayed commands at the common world/boundary. For a CLOSED paid command the chosen active subset must be NONEMPTY. An empty local selection is only an open passive response supported by an externally active boundary, with no local paid actor or factor; it is not an extra paid wait loop. Nonselected actors rebase passively. Expand every newly emitted $U$ slot by the finite silent initializer schema, at the actual postworld, with its primitive producing owner and full inherited binder chain. Admit all whole joints satisfying the selected complete row and entry tests. Actual contexts are the same expanded-owner tensors and scope product. Input reserve is handled by the full shared-row construction: a plan retains the whole incoming carrier/correlation, local tests use only the supplied original driver/own records, and the exporter unions input and own fields once. Noninjective reserve maps act on reserve with identity own witnesses; environment/native maps use their supplied selected-state/presence equations. Thus the target includes genuine correlated paid behavior and the prescribed strong incoming interface.

The full terminal grade of this population target $X$ is $D_n=\{d_n\}$ with unit coefficient for EVERY $n\geq0$. Its actual completed body is $d_n$ with the ordered labels of its $n$ external ports. Unused positive-arity shapes are retained even at inputs whose generated states happen to have fewer ports. The target does not use a singleton nullary collection as a substitute for this full grade.

\section{An actual algebra, not merely an interpretation of a scalar law}
Define $\alpha:T_PX\to X$ by union of the root actor registry with the child population registries at their supplied root $U$ slots. Use their actual disjoint occurrence copies and slot-region maps; no fresh actor is invented by taking the union. The root's $B$ ports and child-region ports give exactly the target planar external list. The map retains the same common world, primitive supports, completion, all raw records and the one envelope/owner dictionary. On symbolic catalogues $\alpha_{\rm sym}$ is the union of the root and child primitive proposal DAGs, retaining EACH primitive tag, constraint and supplied partial-domain field. It introduces no whole-law choice and is defined before testing feasibility. Disjoint copies and the root slot graft preserve the finite laminar region forest, so this union cannot create a cycle or duplicate ownership.

\begin{proposition}
This union is an independently specified algebra on the population target, with the actual native initial/paid/response and full terminal-grade fields of the main constructor. It is not the root-bit erasure map, which would violate strict support/port preservation.
\end{proposition}
\begin{proof}
The symbolic union first gives an actual map on ALL attempts. A rejected $\mathsf{reject}$ component remains a contradictory union symbol with empty admitted fibre. Missing fields are the same missing fields; they are not extended. The primitive proposal tags and formal marginal equations are unchanged, so incoming naturality and all symbolic schema equations hold before choosing $Q$. Restricting this map to an admitted fibre is precisely the whole-law map below; thus it supplies the additional full-symbolic algebra field required by the main theorem.

On initial raw witnesses union keeps every named primitive initializer record. Root decomposition is the separation of that registry into the root and its addressed regions. Conditional on each actual producing binder, the tests of a child forest are exactly the complete child initial-family tests. Thus union maps every admitted whole law into the target family, including correlations and zero atoms. Initial factors are the same labeled tensor factors; the actual coefficient map is their symmetric/associative tensor readdressing.

An old population component can have active actors even when the new root is completed or blocked. Both algebra presentations select the same old actors at the same ticket and boundary. Their whole law is retained, including its incoming reserve correlations. Each fresh forest uses the same producer/binder tests and same original owner, so union adds no full-root conditioning. Old actors act once or passively rebase; new actors only initialize. Hence the poststate/port equations commute on every raw atom. The current material dictionary contains the same paid heads and newly installed factors; persistent historical coefficients in $\Gamma$ are not charged again. Tensor within each whole owner and product-cone readdressing give the actual native coefficient map.

The incoming view maps are the component's fixed historical/environment views of the same original driver, so union and signature transport commute. Export forwards every identical incoming occurrence once. The state/response square is equality of the same registry update, not merely equality of marginals. Completion of the union is equivalent to completion of the root and all child populations, so the strict output mark and support equations hold. Empty regions cause no phantom material.

On FULL terminal grades define $C\circ(I+U\cdot D)\to D$ by sending each formal shape to the unique target shape of the SAME arity. All coefficients are unit, so the actual full coefficient map is supplied at every shape. The realized completed body square holds because union has exactly the same ordered external port list. This map is defined on unused/off-case shapes too. Thus all algebra fields, including the signature and strict operational ones, are specified independently of a free fold.\end{proof}

A population with several unrelated root components is a legitimate target state and need not be a one-root generated state. Nevertheless ancestry encoded in primitive names or explicit binder/region incidence is RETAINED, not claimed erased. Only the semantic root/child constructor bracketing is unnecessary. The example demonstrates that the algebra category can contain a non-tree semantic carrier without discarding the material/provenance fields which make the core fold meaningful.

Two old active actors in one scope advance the shared world once. Serializing their two paid commands advances it twice. A comparison preserving the world and paid-event observation cannot identify these executions. This is a concrete nonserializable shared-update effect in the stated comparison class, not a blanket claim of nondefinability by every possible encoding.
