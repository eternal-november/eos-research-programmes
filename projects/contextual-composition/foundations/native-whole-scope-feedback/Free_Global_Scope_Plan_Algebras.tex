\section{Sorts and formal frames, before realizations}
Fix the world category, recursive input set $U$, external output set $B$, and the full boundary library. A boundary schema $e$ at $w$ has finite raw boundary carrier $D_e$, actual arrows out of $w$, context boundary coefficients $L_{e,d}$, full writer boundary $H_e$, and body $\beta_e:D_e\to |H_e|$. This schema is fixed data, not chosen from the support of a probability distribution. A command can use any admitted law on its full carrier; zero atoms are never deleted. Write $a=(w,u,e)$ for the sort of an active scope schema anchored at input $u$ and world $w$.

Specify a set $\Xi_P(w,u)$ of formal root frames. Each frame $\xi$ carries a finite ordered mixed slot profile: each slot is either an external $B$-label or a recursive $U$-label. In particular its ordered recursive profile is $\rho(\xi)=(u_1,\ldots,u_n)$. A frame can retain stable slot identifiers and any additional root control information required by the interface. The primitive has a frame map from every root configuration, including unreachable ones, preserving this exact profile. Taking all root configurations as distinct frames is permitted but not required. No frame is indexed by a supplied joint law $q$ or boundary marginal $\nu$.

Independently supply primitive active schema names $A_P(w,u,e)$ and full families $Q^P_s\to H_e$. Every root active command at $p$ has a label in $A_P(w,u,e)$ and a body in that labeled family. The formal grammar below includes a label whether or not a command with that label is enabled at $p$. Extra formal frames with no realizing state are permitted. This is the explicit distinction between typing and dynamic admission.

An enriched system $X$ has sets $A_X(w,u,e)$ and full families $Q^X_s\to H_e$ for every name, including names not realized by any command. Its active commands have labels $\ell_X(c)\in A_X(w,u,e)$ and the declared full writer family is exactly $Q^X_{\ell_X(c)}$. Native arrows carry sort-preserving global functions $\phi:A_X\to A_Y$ and actual full-family maps $g_s:Q^X_s\to Q^Y_{\phi(s)}$ over $H_e$ for every name. The mandatory label and writer equations are
\[
\ell_Y(f(c))=\phi(\ell_X(c)),\qquad
 \text{writer arrow of }f\text{ at }c=g_{\ell_X(c)}.
\]
In particular $g_s$ cannot depend on which state or joint law realizes $s$. All other native state, raw, context, boundary, post-state and terminal-grade data are the whole-row data of the independently defined operational category.

\section{The independently typed schema functor}
For a sorted family $A$, define $(S_PA)(w,u,e)$ as the following set of formal tuples:
\[
 (\xi,r,t_1,\ldots,t_n),\quad
 \xi\in\Xi_P(w,u),\quad
 r\in\{\bot\}\amalg A_P(w,u,e),\quad
 t_j\in\{\bot\}\amalg A(w,u_j,e),
\]
where $\rho(\xi)=(u_1,\ldots,u_n)$ and not all $r,t_1,\ldots,t_n$ are $\bot$. The external part of the frame's slot profile remains present even though it is not a recursive argument. An active schema has at least one active descendant or root; $\bot$ denotes a boundary-driven passive response, never an active command or an independent sample. All well-typed tuples occur. There is no condition concerning state reachability, command enabledness, positive law support, or realization of a child name.

The full family at such a tuple is the actual finite slice product over $H_e$: the root factor is $Q^P_r$ if active and $H_e$ if passive; child factor $j$ is $Q^X_{t_j}$ if active and $H_e$ if passive. A map of sorted family data induces the actual limiting arrow, with identity root and boundary factors. Identities and composition hold by the limit universal property. Full families, rather than only realized bodies, are the arguments to this construction.

Operational $T_PX$ has a root state and one child state at each emitted recursive port, as before. A paid command retains the whole joint law across its active/passive root and child choices. Its global schema label is the displayed tuple using the root's frame and the selected child/root labels. Changing only the admitted joint law or its boundary marginal does not change that schema label. The actual full body is induced by the selected row bodies and the fixed $\beta_e$. Native label preservation makes the action on writer schemas precisely $S_P(\phi)$, independent of realizing configurations. This supplies the global schema component of $T_P$.

\begin{theorem}[Conditional free-global enrichment]
Assume the command-indexed operational root construction and finite-carrier fold theorem, including their all-configurations successor and all-raw body equations. Replacing its writer data by the enriched category above gives an initial native $T_P$-algebra on the same finite operational carrier, with the entire formal-plan writer library $(A_F,Q)$ and the separate full terminal collection $C_F$.
\end{theorem}
\begin{proof}
An algebra $\alpha:T_PX\to X$ has a global schema function $S_P(A_X)\to A_X$ and an actual full-family arrow from each product family, on every formal tuple, realized or not. Finite term recursion defines the only possible $A_F\to A_X$. Recursively composing the child family arrows, the actual product arrow and the corresponding global family arrow of $\alpha$ defines a map on every $Q_t$. The definition uses only $t$, never a realizing state, command, $q$, or $\nu$.

On an actual command, induction on its active-prefix plan shows that this arrow is exactly the writer arrow used by the whole-row fold: the child arrows coincide inductively, passive factors are the boundary identities, and the final arrow is the globally fixed arrow of $\alpha$. The native label square follows by the same induction. Thus the all-configurations operational fold is an enriched native morphism. Its successor proof uses smaller prescope child trees, passive rebase equivariance and the seed equation at the actual post-world; successor height need not decrease. Deterministic port-free seeds are still the standing restriction.

The algebra equation on global schemas forces the finite-term recursion even at terms with no realizing command. Its family-arrow component forces the actual product-composite arrow on every full family. This proves uniqueness on unused plans and unused coefficient shapes, not just on realized bodies. Operational field uniqueness follows from the whole-row proof, while full terminal grade uniqueness remains the independent colored polynomial-tree recursion. No writer-to-terminal comparison has been inserted.
\end{proof}

\section{A population algebra that forgets invocation hierarchy}
The following supplies an algebra target not defined as the finite-tree carrier, and allows genuinely correlated multi-active commands. Let worlds be nonnegative integers with a named generating arrow $a_w:w\to w+1$ and their free composites. At $w$ use a boundary schema with singleton $D_e=\{a_w\}$ and unit context and writer boundary objects. All primitive context and writer coefficients are units. Take one recursive input color and no external output ports.

A primitive root mode is $(b,d,k)\in\{0,1\}^3$, recording whether its single recursive port has been born, whether the root is completed, and a cached bit. The root has a recursive port exactly when $b=1$. Seeds are $(0,0,0)$, with no ports, at every world. Rebase preserves the mode and port while changing the world fiber. An unfinished root may draw a fair bit, leaving $b,d$ unchanged and storing the result; may spawn if $b=0$, setting $b=1$ and creating one seed child; or may finish, setting $d=1$. Every command uses the actual arrow $a_w$, with singleton raw rows for spawn/finish and the full two-element fair row for draw. Completed roots have empty menus. Completed modes have full terminal shapes of recursive arity $b$, with unit coefficients.

Let $X(w)$ be the set of finite nonempty multisets of these eight modes. This is a population state, with no parent relation, invocation addresses or external ports. Its seed is the singleton seed mode; rebase preserves the multiset. Completion means every member has $d=1$. To define menus, enumerate each multiset canonically by lexicographic mode and multiplicity index. Choose a nonempty subset of unfinished population occurrences, a primitive command for each, and any full joint law with the primitive marginals. Every chosen occurrence receives its own active outcome; every spawn adds a new seed mode. The post-state is the resulting multiset at $w+1$. Thus correlated fair draws are admitted, not just independent laws. The diagonal and antidiagonal fair-bit couplings can yield different successor multisets and remain different commands. All zero tuples remain.

Give $X$ one global active schema name per boundary sort, with unit full writer family, and give it one nullary unit terminal shape. These are independent global collections. They admit the unique unit-family maps from all formal schema tuples and the full terminal map from all root terminal shapes with recursively substituted nullary children.

Define $\alpha:T_PX\to X$ by taking the multiset union of the root mode and the child population when the root has a recursive port; when it has none, take just the root mode. On a selected command, temporarily tag root and child population occurrences, then biject them to the canonical enumeration of the union, ordering the root before equal-mode child occurrences. The selected target population scope uses the corresponding active occurrences and commands, and the pushed whole joint law under this coordinate bijection. Passive coordinates are the forced singleton boundary witness and add no draw. Slice-unit coefficients and whole families have their actual unique unit maps. Global schema maps are constant to the single target name at the relevant sort, on all unused formal tuples too.

The post-square is equality of multisets: active draws replace the same modes, active finishes change the same flags, and root or child spawns add the same seed modes. Re-enumeration after the step does not change the state multiset. Seed, rebase, completion and empty external-port squares hold. The terminal collection map is globally defined on all shapes, not only completed populations. Hence $\alpha$ is a native algebra in the enriched category. Its induced fold forgets invocation hierarchy and population identities but preserves actual whole scope laws by supplied raw maps. This is excluded by a rigid word/occurrence-preserving map category, yet does not forget the difference between diagonal and antidiagonal bit correlations. Its simplicity in coefficients is declared; it witnesses a non-rigid shared-world algebra, not a counterexample to the independent content obstruction.

\section{Alias descent is an additional congruence law}
Suppose a desired source library identifies distinct free plans. Specify this as an equivalence relation $\sim$ on each sort of $A_F$, together with chosen whole-family isomorphisms $\theta_{t,t'}:Q_t\to Q_{t'}$ for $t\sim t'$, satisfying identity and cocycle equations. More general noninvertible library quotients require a different descent definition; no such quotient is assumed here. The relation must be a congruence for the formal root constructor: replacing child terms by equivalent ones produces equivalent parent terms, and its $\theta$ must be the declared product-compatible comparison. Equality of evaluated family objects alone is not this data.

For a particular target algebra with recursively obtained name map $h$ and family arrows $g_t$, descent requires
\[
 t\sim t'\ \Longrightarrow\ h(t)=h(t'),\qquad
 g_{t'}\theta_{t,t'}=g_t.
\]
The second equation compares actual arrows on complete families, including unused coefficient directions. Both equations are necessary and sufficient for this fold to descend along the declared quotient with its coherent family identifications. For a theorem uniform over a class of algebras, require that class's schema algebras respect the generating relations as equations, and prove closure under arbitrary substitution contexts. Ordinary term induction then extends the generator equations to the generated congruence. Restricting to this equational algebra class changes the theorem's target category explicitly.

No theorem says arbitrary enriched native algebras respect arbitrary aliases. The population algebra above does respect every unit-family alias because its schema map and family arrows are constant. In contrast an algebra retaining free schema names can distinguish two aliased plans while realizing identical bodies. Thus a nontrivial alias cannot be imposed universally without restricting algebras or changing the observer. This identifies the exact promotion obligation: determine the source library's actual relation and comparisons, then test algebra compatibility. It is not repaired by marginal laws, by equality of realized bodies, or by merely knowing the coefficient limits exist.
