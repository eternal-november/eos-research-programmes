\section{Shape-blind contexts and the independently defined observation base}
For the obstruction it suffices to use terminal world and command-indexed data; the definitions also allow a fixed world category with the specified passive action. A \emph{shape-blind paid context} $X$ contains states, completed-state predicate, input-indexed common finite initializer carriers with convex law families/distinguished members and selected states, paid menus with complete finite raw laws, actual augmented coefficients and successor states, and passive rebase. It does not contain output ports, output labels or terminal content shapes. Raw zero atoms remain; actual context arrows are retained. A context morphism has the common initial/state/whole-command/raw/coefficient maps and their selected-state/successor/rebase squares, preserving completion. It need not reflect completion. These data are independently definable without a content object or port observation. Any additional admission diagrams or whole writer fields are retained as independent context data, not inferred from the observation functor below.

Let $e_AX$ be the small category generated by these states and, for each paid command/raw atom, its directed successor edge; include passive rebase edges with their action relations and make all passive edges invertible. Paid path words are not identified merely because they have the same endpoints. The subcollection of completed objects is marked. Completion is invariant under passive rebase in both directions, so that marking extends across the inverted passive arrows. Port lists and completed bodies are assumed passive-invariant in this representation branch, as in the pinned ordered-port doctrine; this is not a claim about arbitrary world actions. A context morphism induces a functor on these generated categories. The symbol $e_A$ forgets laws and actual coefficient arrows; it is not faithful, and those fields remain part of every native context morphism. The index $A$ refers to the initializer inputs, not an identification of every state with an input or initial raw atom.

For a set $B$ and a full weighted ordered collection $C$, independently define the category $\mathcal D_C(B)$ as follows. Its unfinished objects are finite ordered $B$ lists, denoted $u(\mathbf b)$. Its completed objects are
\[
 d(c,\mathbf b),\qquad c\in C_n,\quad \mathbf b\in B^n.
\]
An arrow between unfinished objects is an order-preserving injection of positions preserving labels. An arrow from unfinished to completed is the same kind of injection into the completed object's list. An arrow between completed objects exists only when the shape and full list agree, and is then the identity. No arrow goes from completed to unfinished. Composition is composition of actual injections, so repeated equal labels do not collapse distinct old-port embeddings. Only completed objects are marked.

A full arity-preserving grade map $\gamma:C\to C'$ induces $\mathcal D_\gamma(B)$: it is identity on unfinished lists and injections, and sends $d(c,\mathbf b)$ to $d(\gamma c,\mathbf b)$. It retains the independent coefficient arrow at every $c$ as part of the grade map, though this raw category functor forgets it. Relabeling $B\to B'$ acts on every list without identifying its occurrence positions. These actions commute. Every unused shape of $C$ is an object of this observation category.

A progressive body is a functor
\[
 b:e_AX\longrightarrow\mathcal D_C(B)                         \tag{1}
\]
which sends a state to a completed object exactly when that state is completed. All passive rebase edges necessarily map to identities, since all isomorphisms in $\mathcal D_C(B)$ are identities. Thus ports and terminal bodies are passive-invariant after canonical ordered-rank normalization. The image of a paid edge records the precise old-port inclusion; the complement gives the newly born positions and their labels. At a completed state, (1) links the arity of its full terminal shape to the actual ordered port list, not to a separately chosen observed cardinality.

If an operational doctrine permits paid moves out of completed states, restrict here to the completed-inert branch used by the feedback systems: completed actors have only passive behavior. Otherwise (1) would impose an extra restriction and cannot be silently claimed to represent that broader doctrine.

\section{Native maps are not merely carrier squares}
Define $\mathcal H_{\mathrm{prog}}(A,B)$ to have $(X,C,b)$ as objects. An arrow consists of a full shape-blind context map $f:X\to Y$, an entire grade map $\gamma:C\to D$, and a natural transformation
\[
 \eta:\mathcal D_\gamma(B)\,b\Longrightarrow b' e_Af          \tag{2}
\]
whose underlying port injections at every state are bijections. With canonical ordered ranks these position maps are identities; the transformation can still send an unfinished list to a completed object with that same list. Hence (2) permits a completion-preserving native map to send an unfinished source state to a completed target state. It does not falsely impose completion reflection on all native arrows. At a completed source state (2) exists only when the actual whole terminal shape/body equation holds. Naturality at each raw paid edge is the old-port inclusion square, and naturality at passive edges is the rebase port square. Composition is composition of the actual context and grade maps and the pasted natural transformations; its port components are again bijective.

\begin{lemma}[Exact progressive representation at the declared interface]
Opaque native systems with persistent ordered ports, completed-inert states, completion-preserving maps with order-preserving port bijections, and passive-invariant completed whole-grade bodies are equivalent to $\mathcal H_{\mathrm{prog}}$ after ordered-rank normalization, provided the independently retained law/coefficient/writer fields are the same on both sides. No claim about paid multiplication or relative crossing follows from this representation.
\end{lemma}
\begin{proof}
Forget ports and terminal labels to obtain $X$. At each unfinished state assign its ordered live labels; at each completed state assign its original full terminal shape and ordered live labels. Paid edges have the original old-port inclusions. The operational port functoriality and passive invariance give (1), including the localization of passive edges. All raw edges, including zero atoms and unreachable states, are included. Conversely (1) supplies the port sets, label lists, inclusions and completed shape/body with the required arity equality. Actual initial/paid laws and coefficients were already in $X$ and the independent grade. No context-to-content coefficient arrow is introduced.

Native port bijections and full body squares give precisely (2); its naturality gives the required raw old-port squares. Conversely (2) reconstructs those fields, including completion collapse when allowed. These operations are inverse with rank ports, and use the unique order-preserving renaming isomorphisms for stable named ports. Neither direction discards an actual coefficient arrow or an unused grade shape. This proves a representation theorem only.\end{proof}

Over the terminal world category, in the event-free identity-decoder subcategory with all states completed, $e_AX$ is discrete on the completed initial raw witnesses. A functor (1) is just the original raw body $W\to\coprod_n C_n\times B^n$. A transformation (2) between completed objects is exactly the original body equality; actual context and full content arrows remain independent. Thus the original $H_{\mathsf F}$ is recovered on this precise intersection. The shape-blind context category itself has many unfinished objects with no corresponding original mixed body; no projection of those objects to $H_{\mathsf F}$ is asserted.

\section{A delayed unary interface and separate candidate modules}
For a set $S$, let $jS$ be the marked category with objects
\[
 \bot,\qquad u_s,\qquad d_s\quad(s\in S),
\]
with nonidentity arrows $\bot\to u_s\to d_s$ and their composites $\bot\to d_s$. Only $d_s$ is completed. This is a progressive \emph{unary} interface: no result yet, one revealed result, then completed with that same result. A function $S\to S'$ induces $jS\to jS'$. Repeated transitions can stay at a node but cannot change a revealed result.

Independently define $M_{\mathrm{un}}(A,S)$ as shape-blind paid contexts equipped with an exact-marking functor $m:e_AX\to jS$. Native arrows retain context data and a natural transformation whose components are only identities or $u_s\to d_s$. In particular $\bot\to u_s$ and $\bot\to d_s$ components are forbidden: they are not unary-port bijections. Source completed labels must agree. Over terminal world, in the event-free identity-decoder restriction with all states completed, this is exactly $M_{\mathsf F}(A,S)$.

Retain the static content module $N(S,B)$ of the original source: an object is an entire weighted collection $C$ and a function
\[
 n:S\longrightarrow F_CB,\qquad n(s)=(c_s,\mathbf b_s).
\]
It has a canonical progressive extension
\[
 \overline n:jS\longrightarrow\mathcal D_C(B),\quad
 \bot\mapsto u(\varnothing),\quad u_s\mapsto u(\mathbf b_s),\quad
 d_s\mapsto d(c_s,\mathbf b_s),                         \tag{3}
\]
using the unique empty injection and the identity-position completion arrow. The full $C$ and all coefficient maps are unchanged. Thus this is a genuine separate content module, not an arbitrary state-dependent choice of output shapes. Native maps and pure Set reindexings extend by the same formulas.

There is an actual binary interpretation on these independently defined objects:
\[
 (X,m)\text{ followed by }(C,n)\longmapsto (X,C,\overline n m)
              \quad\text{in }\mathcal H_{\mathrm{prog}}(A,B).       \tag{4}
\]
Its context fields are exactly those of $X$ and its independent grade is $C$. It is functorial on the stated native maps by whiskering the body transformations and retaining their full coefficient fields. It respects pure middle balance: for $r:S\to S'$, the two functors $\overline{n'}\,jr$ and $\overline{n' r}$ are identical on every object and arrow. Consequently (4) is the candidate normal-form interpretation from Set-balanced representatives $M_{\mathrm{un}}\odot N$. This assertion neither supplies $M_{\mathrm{un}}$ multiplication on arbitrary paid contexts nor proves a crossing.

\section{Exact non-surjectivity of the candidate normal form}
Call a directed unfinished path a \emph{strict two-revelation path} if its images in the live-port observation have two strictly increasing positive arities, before any state on the path is completed.

\begin{lemma}[One-revelation invariant]
Every body of the form (4) has no strict two-revelation path. The property is preserved under native isomorphism in $\mathcal H_{\mathrm{prog}}$.
\end{lemma}
\begin{proof}
Along a path of unfinished states, exact marking requires the $jS$ image to remain among $\bot$ and the $u_s$. Such a path can stay at $\bot$, move once to a particular $u_s$, and then stay there. It cannot move between different $u_s$. Under (3), its lists are therefore empty until one fixed whole list is revealed, and are that same list thereafter. There cannot be two different positive arities in increasing order. A native isomorphism has inverse state/raw maps and bijective port components; it preserves both the path and its port arities and completion status. Hence it cannot turn a counterexample path into one satisfying this invariant.\end{proof}

Take $A=B=\{*\}$ and terminal world. A shape-blind context has states $q_0,q_1,q_2,q_3$, with $q_3$ completed, a deterministic singleton initializer selecting $q_0$, and one deterministic unit-coefficient command $q_i\to q_{i+1}$ for $i=0,1,2$. There are no other active commands. Let its full terminal collection $C$ have one binary shape $c$ with unit coefficient. Define its progressive body by
\[
 q_0\mapsto u(()),\quad q_1\mapsto u((*)),\quad
 q_2\mapsto u((*,*)),\quad q_3\mapsto d(c,(*,*)),             \tag{5}
\]
with the obvious empty/first-position inclusions and final identity-position completion. This is an all-raw finite deterministic system, with no silent recursive requests and no coefficient or probabilistic obstruction. The live ports are persistent. It terminates after three paid events, so the failure does not depend on divergent behavior.

\begin{theorem}[Failure of unary Set-mediated normal forms]
The object (5) is not isomorphic in $\mathcal H_{\mathrm{prog}}$ to any interpretation (4), for any set $S$, context $m$ or static full content object $n$. Therefore the canonical Set-balanced interpretation cannot be a normal-form equivalence onto the declared progressive paid category, although it recovers the original relative normal form exactly on the event-free intersection.
\end{theorem}
\begin{proof}
The unfinished path $q_0\to q_1\to q_2$ in (5) reveals a positive unary list and then a strictly larger positive binary list. This contradicts the invariant for every (4), including after native isomorphism. Pure middle balance only changes the name of the revealed unary result; it cannot remove that invariant. The event-free restriction has no unfinished path at all and reduces to the original context-body/content-body composition, so its old normal-form theorem is not contradicted.\end{proof}

\paragraph{Strength and alternatives.} This rules out the specified delayed-unary Set interface with static canonical content extension. It does not rule out a different $j$, arbitrary stateful content functors, non-Set intermediate interfaces, non-isomorphic directed encodings, or an observation forgetting intermediate port revelation. A completed-terminal observer alone would miss the obstruction; the native port/body interface detects it on an actually terminating process.

Enlarging the intermediate interfaces to arbitrary progressive categories would allow the object-level factorization through $e_AX$ and its identity, followed by (1). That is not yet a source-compatible relative doctrine: its native coend maps, pure embedding, paid context multiplication, content multiplication and crossing over moving intermediate interfaces must still be constructed. In particular an identity factorization of a comma object is not a proof that two independently defined operations compose correctly. Alternatively allowing $n$ to reveal different proper prefixes of $\mathbf b_s$ at multiple intermediate stages changes the static content module and demands explicit grade/port linkage on all unused shapes. Neither repair is silently asserted here.

\paragraph{Consumed obligation.} The probe advances the paid-crossing residual beyond an absent terminal body. A two-observation raw base can represent the full progressive native interface and its event-free source exactly, yet the most direct unary relative factorization still fails at a named normal-form obligation. Any next candidate must pass the strict two-revelation test while retaining source pure balance, independently full grade maps and the real whole-law/owner-coefficient crossing. The conditional-mixture and owner-normalization results from the structured family remain available only after those new interfaces are specified.
