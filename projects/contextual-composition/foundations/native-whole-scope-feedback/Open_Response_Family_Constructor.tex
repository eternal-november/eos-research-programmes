\paragraph{Audit and changed input interface.}
Open response-family construction. The new input is an \emph{open response family}, not a selected autonomous scheduler. It retains every admitted response command and every complete scope extension. An environment may broadcast a common observation after a sampled global outcome. That observation is an external input, not an independently sampled random variable or an extra paid event. This explicit input permits controllers to retain passive boundary observations and sibling/global information. The theorem supplies a constructor and native mapping theorem in this interface, with an opaque algebra example. It does not manufacture a broadcast rule, coupling, scheduler, or selected-controller fold.

\section{Independently typed shared-observation responses}
Fix the command-indexed boundary doctrine of the native feedback theorem: worlds $\mathcal W$, boundary schemas $e$ with finite carriers $D_e$, actual world arrows, augmented context boundaries $L_{e,d}$, full writer boundaries $H_e$ and their all-raw bodies. Required context and writer slice limits exist. Fix also a set $G$ of external observation symbols and the free monoid $G^*$. A common observation register is a word $h\in G^*$; a new symbol $g$ changes it to $hg$. Maps in the present category preserve the observation alphabet/register literally. This is a declared restriction on comparisons, not an automatic property of opaque native maps that forget observations.

An open response object $X$ has configuration fibres $S_X(w,h,u)$, deterministic port-free seeds $i_X(w,h,u)$, stable ordered external ports, completion and full terminal grade as in the command-indexed doctrine. Passive responses form a functorial action of the following independently defined response-path category $\mathcal R$. Its objects are $(w,h)$. Pure-world arrows $[v,\varnothing]:(w,h)\to(w',h)$ obey the original identity/composition laws of $\mathcal W$. For every actual world arrow $v:w\to w'$ and symbol $g\in G$, there is a generator $[v,g]:(w,h)\to(w',hg)$. Apart from the pure-world laws, take the free category on these generators. In particular there is no equation commuting a world move past an observation, nor an equation identifying a one-event observation with two events. An arrow $\pi$ retains its full aligned response path, its projected actual world arrow and its concatenated observation word. Supply
\[
 R^X_\pi:S_X(w,h,u)\longrightarrow S_X(w',h',u),\qquad
 R_1=1,\quad R_{\pi'\pi}=R_{\pi'}R_\pi.               \tag{1}
\]
They preserve ports and completed terminal bodies. Passive response may change private controller memory and readiness. No equation compares a rebased seed with a freshly initialized seed.

At each configuration the active-response family consists of any supplied set of whole commands $c$ over $e$, with the original finite raw row $(Z_c,q_c)$, boundary map $b_c$, actual context and full writer/body data. Unlike an ordinary closed transition, its successor is input-parametric:
\[
 \delta_c(z,g)\in S_X(w_{b_cz},hg,u),\qquad z\in Z_c,\ g\in G. \tag{2}
\]
Old ports persist for every $(z,g)$. The law $q_c$ and body at $z$ are chosen before the next $g$ and do not secretly depend on that future input. Allowing dependence on the already recorded $h$ is intended. All $z$, including zero atoms, and every $g$ have successors. Active controller updates may use both their own outcome and the common observation. Passive actors receive $R_{[d,g]}$.

A native response morphism preserves states, seeds, ports, completion, the full terminal grade and every passive action (1); at every active command it supplies a whole target command, exact native row map $r_c$, actual context/full-family maps and
\[
       f(\delta_c(z,g))=\delta_{f(c)}(r_cz,g)
                  \quad\text{for every }z,g.           \tag{3}
\]
All source commands are mapped. No target command or history coverage is assumed. Identities and composition are fieldwise. A map need not retain an invocation decomposition or participant count. It must retain the declared observation input interface.

This is independently meaningful as a controller interface. Given a process and controller memory, configurations can be pairs $(s,m)$; the family contains commands permitted by the response controller at $(s,m,h)$, and (1)--(2) update that memory on actual boundaries and observations. A singleton permitted family gives a local prescribed response when asked to act; several commands retain alternatives. A controller may block an otherwise ready process. This is not yet a choice of which actor acts in a global network.

The environment supplies $g$ after seeing a global outcome. For example $G$ can encode the full chosen scope/law/raw tuple in a set-sized presented library, so $h$ retains complete global control history. A source law label is not erased merely because a target command has a coarser raw image: both sides of (3) receive the same externally retained symbol. If the environment itself must transform under a comparison, that is a separate input-protocol map with its own compatibility equation. Treating this provenance-preserving open comparison as a closed autonomous comparison would change the interface.

No probability measure on $G$ is required. A concrete driver can provide a deterministic symbol from the sampled tuple; alternatively an explicitly supplied probabilistic driver must retain its own raw witnesses, law and coefficient factors. Neither is silently selected here.

\section{Source inclusion and protocol closure, not general forgetting}
There is no asserted forgetful functor from arbitrary response objects to ordinary closed systems. Erasing $g$ can leave several posts for the same raw $z$, and erasing controller memory can alter the permitted command family. The target of the present construction is the independently defined two-phase open category: first a command draws its ordinary finite row, then one unsampled observation input is consumed.

There is instead a faithful constant-observation inclusion $J$ of ordinary command-indexed systems. Set $(JX)(w,h,u)=X(w,u)$ as a labelled copy for each $h$, copy its full menus/grades, use $R^{JX}_\pi=R^X_{\operatorname{world}(\pi)}$ on the process coordinate, and $\delta^{JX}_c(z,g)=\delta^X_c(z)$. Native arrows are copied independently of $h$. These formulas preserve all ordinary native fields. The inclusion need not be full: general open maps may depend on $h$. This is an actual inclusion of the old interface, not identification of all new open maps with old maps.

For a \emph{global} response object, supply an explicit deterministic protocol $B(c,z,h)\in G$ on every whole command and every raw atom, including zeros. Fix a starting register $h_0$. Its closed interpretation has state $(h,s)$, ordinary command row $(Z_c,q_c)$ unchanged, successor
\[
 (h,s)\xrightarrow{c,z}\bigl(hB(c,z,h),\delta_c(z,B(c,z,h))\bigr),
\]
seed $(h_0,i(w,h_0,u))$, and passive physical-world rebase $(h,s)\mapsto(h,R_{[v,\varnothing]}s)$. All grades and coefficient arrows remain unchanged. This is an ordinary closed command-indexed system: the protocol selects a deterministic post from the open response family after the global tuple has been drawn. It introduces no extra probability weight or coefficient. If $B$ encodes the chosen law and complete tuple, that metadata is received only at this postscope stage.

Protocol-equipped morphisms additionally satisfy
\[
 B_Y(f(c),r_cz,h)=B_X(c,z,h)
\]
on every raw atom. The existing open successor square then proves a closed native successor square, so closure is a functor on that explicitly protocol-compatible category. There is no general claim that closure commutes with assembling independently closed primitives: their local raw outcomes need not determine the global protocol symbol. A random protocol requires an enlarged raw row with its full joint law and coefficients, not a use of this deterministic formula.

\section{The all-extension response constructor}
Fix a primitive root response object $P$ with recursive and external slots, port-free seeds and the same observation input. Define $\widehat T_PX$ by root-and-child configurations at the same $(w,h)$, with the full terminal grade $G_P(C_X)$. Its seed is the root seed with no children. Passive action is componentwise.

Its active-response family at a configuration contains \emph{every} compatible selection of an active root command or passive response, and an active child command or passive response for every existing child, with at least one active selection. For each selection retain every normalized whole joint $\lambda$ on the full boundary-matching carrier with the prescribed active marginals. Passive marginals are induced by this one joint. Retain its actual context slice product and full command-indexed writer-family slice product, with all unused shapes and boundary-body equations. This is a family of complete response commands; it is not a selected joint or a product of independently chosen marginals.

After raw joint outcome $z$ and input $g$, every old active actor uses its (2), every old passive actor uses $R_{[d,g]}$, and all use the same actual boundary witness and same $g$. New recursive children are initialized at the \emph{post} pair $(w_d,hg)$ using their actual seeds. They do not participate in the birth scope. No random initialization is admitted by this statement; incorporating it requires complete initializer witnesses, joint laws and actual coefficient comparisons, not fresh independent sampling. Each newborn starts with the history register $hg$, but its own seed memory is its declared seed, not an old seed rebased through the preceding history.

\begin{theorem}[Family-valued controller construction and native mapping]
The preceding formulas define an endofunctor $\widehat T_P$ on the category of open response objects. It is family-valued at the control interface: its output retains all schedule selections and all whole-joint extensions of the input response families. A native response map acts on active child commands and raw coordinates, pushes the whole joint law, and uses the induced actual slice-limit arrows. It preserves the open successor square for every observation input. No extension to untested target controller histories is chosen or needed.
\end{theorem}
\begin{proof}
Exact primitive pushforwards make the transported joint have the target selected-command marginals. It is therefore among the target's generated all-extension commands. Boundary-preserving raw maps induce actual context and whole-family arrows by their limiting cones. For an old active child use (3), for a passive child use (1), and for a new child use seed preservation at the exact post pair $(w_d,hg)$. The same port bijections match persistent old slots and the fresh complements. These arguments are uniform in $g$, and the current law has no dependence on future $g$. Terminal grades use the original full polynomial map. Identity/composition follow from pushforward, product-limit uniqueness and componentwise passive laws.\end{proof}

For ordinary $P,X$, the constant-observation inclusion satisfies the actual canonical comparison
\[
        \widehat T_{JP}(JX)\cong J(T_PX).
\]
Both sides have the same root/child process states at each $h$, the same complete extension menus and raw laws, the same slice coefficients/full writer families and terminal grades. Their posts agree for every $g$ because all old process responses ignore $g$, and their newborn seeds are the same process seeds copied to $hg$. The comparison is natural in old native maps. This is the commuting source-inclusion square; it is not a forgetful square for arbitrary memory-dependent response objects.

The theorem's codomain is not $\operatorname{Fam}$ of autonomous selected policies with uniquely completed target tables. It is the explicitly defined category of response-family objects. Its generated command family is exactly a dependent union over active/passive selections of the marginal-coupling sets. At any finite horizon, the product of complete command menus over decision nodes of the universal command/raw/input tree parametrizes scheduler response tables only. A deterministic driver separately chooses a $G$-valued coordinate at every post-command/raw-outcome node, or obeys an explicitly supplied restricted protocol $B$. Joint scheduler-and-driver data is the product of these two independently indexed tables; execution follows the chosen command, its sampled raw outcome and then the chosen driver input. All off-policy branches in both phases remain in the universal tree. No driver field is inferred from the scheduler-menu product. A native map still gives the companion compatibility relation on selected tables, not an automatic chosen table. This keeps the word ``family'' tied to an actual interface rather than using it to conceal missing target extensions.

Whole-scope restriction and the all-extension assembly theorem apply pointwise in $(h,g)$. They therefore give coherent nested composition of these response families: every regrouping keeps the same full extension and the same observation symbol, including entirely passive internal subtrees. Passive blocks retain their boundary response, not a fresh draw. All unselected command/law/input histories are matched by induction. A global-history-dependent response need not descend to an autonomous child's shorter local history; this construction does not require that descent.

\section{Finite feedback object and opaque algebra interface}
Define $\widehat F_P$ by all finite invocation trees at a common $(w,h)$, with all nonempty simultaneous primitive selections, all admitted whole joints, and post-response (2) at active nodes, passive (1) at others, and post-pair seeds at births. Its full terminal grade remains the full formal finite-tree polynomial grade, separate from scope writers. Root splitting uses exact marginals and the whole outer coupling, never conditional disintegration.

\begin{theorem}[Open response-family initiality, command-indexed doctrine]
Root grafting gives an isomorphism $\widehat T_P\widehat F_P\cong\widehat F_P$. For every native open response algebra $\alpha:\widehat T_PX\to X$ there is a unique native response-algebra morphism $\widehat F_P\to X$, on states, whole commands, raw rows, actual context arrows, full command-indexed writer families and full terminal grades. This is initiality of response \emph{families}; it does not assert compatibility with arbitrarily selected global controllers or environment drivers.
\end{theorem}
\begin{proof}
Root splitting and complete joint restriction yield the same actual menu/limit isomorphisms as the underlying command-indexed proof. The additional observation field does not alter its raw matching carrier or law. Every post-state square now has an extra universally quantified input $g$. Define the fold on prescope finite trees by the existing state/terminal recursion and whole-command split--recursive-map--joint-pushforward--algebra composite. At each induction step, active successor equations hold by the smaller child's (3) for every $z,g$, passive equations by (1), and newborn equations by the seed condition at $(w_d,hg)$. A prescope child is smaller even when its successor grows. This proves the native fold uniformly in the observation parameter without inducting on successor size. Its passive path equation follows from the same componentwise argument on every generator and then every composite path $\pi$ of $\mathcal R$. Uniqueness is forced by the algebra equation on each field, with $g$ merely an additional input of the required equation. This is precisely the pinned proof with its formerly closed successor square replaced by the explicit input-parametric square, not an appeal to selected-controller descent.\end{proof}

\section{A genuinely opaque response algebra}
A concrete non-rigid example uses trivial physical world and boundary, unit context/writer coefficients, and $G=\{0,1\}$. Each primitive root has $r$ persistent recursive ports, no external ports, and private integer memory $m\geq0$. Seeds have $r=m=0$. No state is complete. Its sole active command has a fair raw bit $z$; it creates one new recursive port iff $z=1$. Under broadcast $g$, every old primitive memory increases by $g$, whether active or passive. New children are seed memories zero at the new shared register $hg$. Full unused terminal shapes of every recursive arity, each with unit terminal coefficient, are retained; no completion body is demanded at these unfinished states.

Define an opaque response system $X$ with state $(n,c)$, $n\geq1,c\geq0$, no external ports and no completed states. Its seed is $(1,0)$. Passive observation changes $(n,c)$ to $(n,c+ng)$. Its commands are all pairs $(k,q)$ with $1\leq k\leq n$ and $q$ any joint law on all $k$ bits with fair marginals. Its post after tuple $z$ and observation $g$ is
\[
             (n,c)\longmapsto(n+\textstyle\sum_i z_i,\ c+ng). \tag{4}
\]
All raw tuples, including zero-mass ones, remain. Its entire terminal collection is a singleton nullary unit-coefficient shape; the full unused root-tree terminal grade maps to it. These are full grade maps, not an identification of a joint writer with a terminal tensor.

The algebra sends a root $(r,m)$ with $r$ opaque children $(n_j,c_j)$ to
\[
                     n=1+\sum_jn_j,\qquad c=m+\sum_jc_j. \tag{5}
\]
A selected active root contributes one fair coordinate; an active child command contributes its $k_j$ coordinates. Their whole outer joint flattens to a law on $k$ fair coordinates, yielding the target command $(k,q)$. The bound $k\leq n$ follows from $k_j\leq n_j$ and the at-most-one active root. The raw flattening, exact joint pushforward and unit full-family maps are actual native fields. Summing active births gives $n+\sum z_i$, including fresh child seeds; summing the observation increments of all old nodes gives $c+ng$. Thus (4)--(5) prove the successor square for every raw tuple and every $g$. Passive response-path compatibility and seed preservation follow from the same sums, with pure-world generators contributing no observation increment. The fold forgets tree shape and individual memories but retains population size and total observed memory. A deterministic closure protocol can, for example, broadcast the parity of the complete active bit tuple. The flattening raw map preserves that parity, so the displayed algebra/fold comparison also satisfies the protocol square and yields an actual closed native comparison after this explicitly chosen global closure. Broadcasting source-only actor addresses instead need not descend through this opaque fold; the open theorem does not claim that it does. It is not a rigid occurrence readdressing and it executes genuine correlated multi-active birth scopes.

\paragraph{What has changed and what remains.}
The positive construction admits shared observations through an explicit external input protocol and retains all response/schedule/joint extensions. It does not make a target observe discarded source information for free: comparisons preserve the declared input stream, and any concrete driver must supply it. Closing the input stream by a chosen feedback rule, randomizing it, promoting command-indexed writers to an aliased global library, or adding correlated random initializers requires the corresponding new native equations. The existing controlled-fold fibre theorem applies to selected command/raw/input tables once their driver and start/horizon interface are specified; its existence conditions have not vanished. The result inherits the command-indexed two-grade doctrine: no aliased global writer descent or single-content compiler is automatically supplied. For a Cartesian single-content refinement, the typed production invariant must hold for every $(z,g)$ with its actual writer/schema interface; if $g$ changes content production, that input must be represented there rather than omitted. The new result is an independently typed open response-family constructor and non-rigid family algebra, rather than a declaration that the absence of an autonomous controller interface makes construction impossible.
