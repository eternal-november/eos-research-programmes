\paragraph{Exact interface.} These tests accompany the concrete ABC/J population, not a separate alternative calculus. They use controller/export v10, SHA256 \texttt{7ed9166b3d839888084cadb97710b5da3332441d1442f1efd2ac88ac9361fd69}. Available read view $v$, actual selection rule and commitment index $c$ are different fields. For a selected full label $\ell$, write
\[
 b_{c,\ell}(r)=\alpha_c(r)\kappa(\ell\mid v(r),c),\quad
 p_c(\ell)=\sum_r b_{c,\ell}(r),\quad
 \beta_{c,\ell}=b_{c,\ell}/p_c(\ell).
\]
The selected whole plan must have incoming marginal $\beta_{c,\ell}$; any independently fixed incoming-signature marginal is an ADDITIONAL obligation. The original model's coarse-selection example is a sufficient instance, not a necessary ban on reading extra information.

\paragraph{Available information without selection bias.}
Let retained $R$ be fair and expose its actual value to the controller. Use one constant selected label with full diagonal plan $q(R,W)=1/2$ at $(0,0),(1,1)$. Then $\kappa=1$, $p=1$, and $\beta=\alpha$ is fair, despite the available full read. The conditional service returns $W=R$ using the already retained reserve. The selected joint is exactly q and the past is not redrawn. In the ABC/J realization the fresh pair can instead be $(a,c)=(R,1-R)$; its projection onto $(R,a)$ is this same test, while the full fresh pair has the required antidiagonal head law. This is legal with full available R as long as ACTUAL selection remains constant. The stronger claim that full readability forces a point-mass commitment would be false.

\paragraph{A genuinely biased selection.}
Let label zero promise the fair diagonal q and label one promise the fair antidiagonal q. Choose label $\ell=R$. Now $p(\ell)=1/2$ and $\beta_\ell=\delta_\ell$, not the promised fair input marginal. The naive conditional services produce $W=0$ with probability one, realizing neither advertised selected whole plan. This fails the stated calibration/input commitment, not merely a syntactic information restriction. Renaming the selected input signature to its posterior would change the commitment and would need an actual new signature; it cannot rescue the original fair-input claim silently.

\paragraph{Why the all-zero fields change the map category.}
Use one action and fresh carrier $\{0,1\}$, with full binary-simplex admission and identity context/content maps (or tensor these identities with the population's unchanged nonunit fields). Let source reserve have masses $(s_0,s_1,s_2)=(0,1/2,1/2)$, fresh tables $(\delta_0,\delta_0,\delta_1)$. Its positive whole plan has mass $1/2$ on $(s_1,0),(s_2,1)$. Map $s_0,s_1$ to $t_0$ and $s_2$ to $t_1$. At T the reserve is fair and tables are $\delta_0,\delta_1$. This is a STRONG pointwise service map even at $s_0$, and exactly pushes the complete plan.

Now collapse T to a singleton U whose fresh table is fair. This pushes the whole plan and satisfies positive-fibre averaging; T has no zero incoming atom, so zero-source table preservation is vacuous. But the composite sends the source-zero table $\delta_0$ to the fair table at U and fails the all-raw zero-table equation. Thus arbitrary averaged comparisons plus exact source-zero tables are NOT a category. This is not a probability-admission counterexample; all rows are admitted.

The strong category excludes the second map. The support-exact weak category excludes the FIRST map because it sends zero $s_0$ to positive $t_0$. Neither repair may be advertised as their unrestricted union, which still contains the displayed noncomposable pair. Their independently stated arrows remain usable with their correct scope. The population temporal-to-owner comparison and the matched common-cut controller comparison are strong: they readdress the same reserve and keep exactly the same actual service table at every atom, so neither depends on the invalid union.
