\section*{Moving binary comparison: proof-review checkpoint}
Base: repository \texttt{eternal-november/eos-research-programmes}, main at
\texttt{c0aed552b2027a3602e46fd9554b674c140ccb35} (PR 217).
In the pinned Lean package, the source is the weighted total of the actual tagged
pair span; its arrows can move the exterior base. The target is the weighted
total of the twice-free presheaf over the identity base functor. The two
endpoint actions are given by conjugating independently specified total
reference functors with explicit chart identifications. The reference comparison
is the all-arrow equality of the ordered-cut trace evaluations. Neither the
endpoint actions nor their gauges are defined using the published compositor.
The moving readout is selected using the existing strict-fibre native decoder
on objects, with the arrow action determined via the fully faithful total chart.

\paragraph{Checked laws.}
\texttt{ChartTotalCell.restriction} compares the published fixed-cut cell after
inclusion with the restriction of the reference comparison, transporting the
two endpoints by full functor equalities. \texttt{MovingCell.component}
identifies the actual included fibre component at every total object with
the specified total comparison. \texttt{MovingCell.moving} is its naturality
equation for arbitrary total arrows; it is not limited to fibre arrows.
The equality is before the packed multiplication. The intermediate charts use
actual units/counits, not identity replacements.

\paragraph{Boundary for independent review.} The total endpoint functors are
these particular chart realizations. Their strict equality over the base
and identification of their entire fibre-arrow restrictions with the original
fibre functors have not been proved by this checkpoint. A fortiori this is
not an intrinsic globally tagged three-block associativity equation, a
pentagon, or closure of issue 105. Moving components alone would not imply
those stronger claims. The finite check tests the generic transport mechanism,
not a constructed instance of the project's split data.
