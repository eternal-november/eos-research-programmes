\section*{Finite iterates under joint base change: author boundary}
The input is a split endpoint system over an arbitrary category and one fixed ordinary category-valued payload presheaf. The output is the length-graded presheaf of objects and arrows in its iterated extension. At each head the target of the recursive tail arrow is the entire remaining target pulled back along the map of extended bases; the zero case is an arrow in the payload category. Induction using the dependent one-step hom equivalence proves decoding bijective at every depth. Reindexing each summand retains its native functor laws. A two-grade dependent-sum calculation separates the selected base bit at the final leaf while both grade functions actually act. The test does not establish the general result; the induction and presheaf construction do.
