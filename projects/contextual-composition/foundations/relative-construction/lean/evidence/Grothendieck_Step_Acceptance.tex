\section*{Joint base and native-arrow action for one Grothendieck extension}
At a single fibre the hom type is equivalent to the dependent pair of a native grade arrow and a payload arrow into the target pulled back along the induced successor map. Composition is computed on these native maps. For one base change the reindex grade functor and its endpoint natural transformation induce a functor on the full extension category. Its payload component applies the actual source-side endpoint restriction to the old payload arrow and corrects the target by the image of the endpoint naturality square. No endpoint lift, grade map or payload arrow is required invertible. A dependent-sum example with point selection along a map without section detects both the noninvertible grade and the selected payload value.

No global base functor or all-length joint telescope theorem is claimed from this one-arrow result. The endpoint interface lacks coherence of endpoint lifts for composable base arrows. Nor is there a pseudomonad, strict-algebra or representable Kleisli recovery claim. Forty selected exports are audited; the author’s fresh own-source build reused pinned dependencies, with previously missing mathlib prerequisites built from the pinned checkout.
