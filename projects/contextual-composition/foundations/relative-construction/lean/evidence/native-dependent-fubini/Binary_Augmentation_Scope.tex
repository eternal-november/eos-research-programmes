\section*{The global augmentation of binary dependent Fubini}
The separate augmentation first tensors the entire augmented dependent
occurrences and then collapses the right unit. The joint augmentation is
defined independently. It uses the independent continuation augmentation
at each joint parent branch, removes the continuation unit while that
branch is still retained, then applies the independent tensor of the two
whole global parent augmentations. There is no augmentation assumed for
an individual parent coefficient. The proof keeps actual maps from each
possibly empty whole sum, and chooses neither a map out of zero nor
a component augmentation canonically.

The joint augmentation is proved equal to the joint native coefficient
route followed by terminal unit collapses. The local unit diagram for
the braided middle-four is proved for mathlib's actual comparison and
right unitor, not added as a structural coherence axiom to that model.
The flat theorem descends to the same computed raw address rearrangement
as the binary coefficient theorem, using independently grouped entries.

This is a global augmentation equality for each fixed binary input,
not an equality of native functors. The existing coefficient comparison
and these augmentation equations are separate theorems in a pinned
ordered presentation. To package a natural augmented isomorphism requires
identifying the presented raw fibres, aggregate compositions, and chosen
augmentations with the actual global finite direct-image category and
checking variation of the native arrows there. Arity zero and all-arity
occurrence assembly, as well as dependent associativity, unit and
permutation coherence, remain separate. No initiality or additive
coproduct hypothesis is used.
