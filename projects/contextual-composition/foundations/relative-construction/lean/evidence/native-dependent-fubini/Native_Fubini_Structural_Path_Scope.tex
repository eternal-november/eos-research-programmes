\section*{Actual Fubini along mixed independent structural paths}
At a root, a swap exchanges two arbitrary child trees. Right
unit deletion removes the single unit address from an arbitrary
child tree; its coefficient proof cancels the actual nullary
comparison. Left unit deletion is the actual swap followed by
right deletion. Both routes are constructed independently:
the separate path applies structural comparisons on the actual
native independent tensors; the joint path constructs the
ordered parent and continuation comparisons and then accumulates.
The actual coefficient cells on nested raw addresses are checked.

Whiskering extends the root moves through any encompassing
tree; inverse forms use the already established native augmented
isomorphisms. A finite path can mix all kinds of moves at any
depth. The resulting Fubini square uses actual native compositions.
The only additional coefficient interchange equations are the
local medial regrouping, swap and right unit laws, derived by
the standard symmetric multiplication. The proof does not
postulate a native square.

This theorem concerns the two interpretations of the same
specified structural path. It does not identify different paths
by their induced permutation, formalize arbitrary additive
presentation descent for the dependent calculus, or package
the admissible context restriction.
