\section*{All-length simultaneous Fubini in the admissible native context category}
The base is an arbitrary type, with no finiteness or inhabitedness
condition on the base. Each of finitely many inputs supplies an
admissible parent display and an admissible continuation display
over its extension. Canonical ordered views use the actual native
input coefficient arrows and the original finite positions. No
extra admissibility condition is placed on the input carrier maps.

Both routes form objects in the same literal full subcategory.
Separate display admissibility uses dependent accumulation and
same-base independent products. Joint parent admissibility is
an independent product. The joint continuation at each actual
parent pair is the product of the original continuations after
reindexing along the two parent reads. Admissibility of the
joint continuation therefore follows from pullbacks and product
closure, and the final dependent display follows from composition.
The nullary route uses the singleton unit display. The actual
indexed augmented isomorphism and its naturality on arbitrary
aggregated parent and continuation arrows are both checked.

The finite indexing uses the native canonical ordered enumeration.
Independent permutations, units and regrouping were checked in
the preceding native tree work; changes to alternative additive
enumerations of the full dependent calculus and later contentad
layers remain outside this theorem.
