# Planned causal cuts and independent commands

`Planned_Causal_Cut_Command_Module.tex` constructs a symmetric monoidal loose right module over an independently specified command double category. Pure profiles remain `(A,U,B)`; histories and complete stopping plans stay internal to systems. A command consumes the next specified barriers. Zero commands add no marks, whereas an actual cut at time zero adds a mark and is not an identity.

The carrier retains primitive-induced native strategy comparisons, complete causal tables, local lumpability, all future plan compatibility, and the full marked recursive grade, including unused shapes. Canonical round plans give a fully faithful section of that declared source strategy category. Evaluated outputs are rowwise countable subprobability processes, not necessarily finite-support or normalized writer objects. Exact decomposition semantics uses the stopping theorem in [Causal Frontier Strategies](../causal-joint-polynomial-feedback/Causal_Frontier_Strategies.tex).

A separate exact criterion classifies marker insertion and invertibility at a fixed evaluated terminal-process interface. It does not replace all-history causal control compatibility. The zero-time counterexample rules out an invertible unitor even when the raw-witness map is allowed to vary.

The module construction is a direct use of the carrier/action format in [Libkind–Myers](https://arxiv.org/html/2505.18329v2), not a novelty claim. List tensor retains separate atomic scopes; no scope merging, arbitrary polynomial dependent-substitution compiler, general source completion, or full category of arbitrary expanded-grade native arrows is claimed.

`check_planned_cuts.py` supplies bounded exact diagnostics for marker fibres, partial bijections, cursor laws, and counterexamples. These are not a formal certificate of the universal theorem. Lean and Lake were not available on PATH during this checkpoint. Written proofs require the stated source assumptions and independent review.
