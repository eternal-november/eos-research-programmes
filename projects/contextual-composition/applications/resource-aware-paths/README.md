# Resource-aware graph witnesses

An exact Pareto-profile quotient for finite resource-consuming paths under existential availability and budget tests. Composition retains one-use resource compatibility; witnesses, counts and probabilities are not interchangeable observations. An explicit family requires exponentially many profiles.

Read the [manuscript](resource_paths.tex). Run the finite diagnostics using standard Python 3:

```sh
python3 check_resource_paths.py
```

The scope is finite witness families, a finite resource universe and nonnegative rational costs. This is not a full contextad construction or a novelty claim about Pareto dynamic programming. No Lean replay or physical validation is claimed.
