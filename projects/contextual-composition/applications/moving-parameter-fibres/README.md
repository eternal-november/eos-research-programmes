# Moving parameter fibres and reverse differentiation

A scoped worked example for the differential-contextad catalogue direction. Read [the manuscript](Moving_Parameter_Fibres_and_Reverse_Differentiation.tex) first. Run `python3 check.py` with standard Python 3 to reproduce seven exact-rational regression checks.

The written proofs establish the stated finite-dimensional smooth-bundle claims; no Lean proof or full differential-contextad construction is provided. Spherical holonomy obstructs endpoint-only transport for the chosen projection connection, not all imaginable transports. The derivative cross term is necessary for arbitrary covectors. No novelty claim is made for standard differential geometry or reverse-mode differentiation.

TeX compilation was attempted but the installed pdflatex format was unavailable; the editable source is the deliverable.
