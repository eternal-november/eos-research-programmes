Scoped contextual-composition example. Main text: `Robot_Transactions_and_Interference.tex`.

Run `python3 check_robot_transactions.py` (standard library only). No physical execution or Lean replay is claimed.

New relative to the earlier robot/deployment examples: interruption factorization; exact independently selectable interference boundary; observation-adapted atomic comparison with interference during compensation. Not new claims about sagas or a general robot safety framework.
