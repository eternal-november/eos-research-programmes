# Structural, Synthesized and Efficient SLAM

How can the structure of a SLAM problem guide the choice of representation, inference and acquisition under a resource budget?

Start with the [research contract (draft v0.3)](contracts/Structural_Synthesized_and_Efficient_SLAM_v0_3.tex). The first milestone is R1: compare concrete targets in structural theory, architecture synthesis and efficiency to the closest existing methods before fixing the evaluation. The frontier seed ledger links to the relevant results from [Contextual Composition](../contextual-composition/) and [Decomposition equipment](../decomposition-equipment/) and identifies hypotheses to check before reuse.

The contract requires a contribution in each track and an integrated CPU evaluation. These are research obligations, not established results.
