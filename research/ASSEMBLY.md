## A-D: the actual digital protocol in the common core

The source state is the operational Prefix from digital_model.py: fixed fault index, leader input, epoch and the complete admitted event prefix. The local-history map is local_view, and the correct policy is local_action. The transition is successors, whose guards admit signing, delivery and cutoff choices independently of the agreement or certificate conclusion. A fixed fault index selects which actor components must follow the correct policy. The source action domains are finite tagged proposal, echo, terminal, wait, retain and observe commands; faulty commands are represented by the admissible normalized signature/delivery choices. Invalid-byte traffic and processing-resource limits remain the digital module's declared channel boundary.

The source is a fixed-policy closed loop, not a synthesis oracle. Its action-indexed next relation is now explicit: command_successors validates correct components and normalizes each Byzantine request before selecting its possible event successors. Wrong-phase or malformed requests become no-ops; requested echoes are intersected with leader signatures actually available; terminal requests may create additional signatures even after the selective-delivery point. Rejection is an admitted transition, not an empty winning run set. The finite request classes cover all valid tags/masks and one class for all other decoded requests. Normalization is checked surjective onto the admitted adversarial event branches, so it cannot establish nonblocking by silently deleting attacks. The common-core embedding gives each participant its actual local policy and regards the generator's remaining choices as adversarial transitions. The issued command is extracted independently from each generated edge: proposal masks from raw events, each follower's actual outgoing echo from its routed echo event, terminal masks from actual signature events, and the explicit wait/retain/observe actions in the remaining phases. The adapter checks every correct issued command against the policy applied to that actor's previous local history. No fault index or future event is supplied to that policy.

The target state is DigitalState in assembly_model.py. It carries the current fault/input/epoch/phase context, raw/echo/signature/decision/receipt facts and the persistent local records. Its enabled events and factual updates are implemented independently by abstract_digital_events and abstract_digital_step; neither calls the source successors or filters outcomes by agreement. The projection alpha reads the corresponding facts and local records from the source prefix.

For actor i, the history map h_i and action lift are identity on the preserved local records and tagged commands. The analytic action projection is likewise identity. The fault index is unchanged. The common-core refinement obligations are instantiated as follows.

| Obligation | Witness |
|---|---|
| Initiality | The seven source initial contexts project to the same fault/input/empty-event target contexts. |
| Observation correspondence | Each target local-record component equals local_view(source,i). The adapter checks this at every generated point. |
| Local implementation | Equal correct local views across all fault contexts yield the same local_action; the adapter constructs 586 local policy classes. It also compares actual edge-issued commands, rather than merely calling the policy twice. |

| Execution existence | Every joint requested-command profile following the correct components has a normalized source and target successor at every nonterminal point. The sole one-slot terminal phase is explicitly successful and is not used to certify recurring service through an empty run set. |

The complete finite audit covers 117,017 source states, 117,010 guarded edges, 468,300 correct action occurrences and 1,868,342 following command profiles. For every normalized profile, source successor images equal the target action-indexed successors and are nonempty before successful termination. Alpha is bijective on this generated fragment, and successor images agree. This is stronger than one-way trace inclusion for this particular representation, but does not establish equivalence with another Byzantine protocol or with unmodeled network behavior. The kernel is the earlier validated-batch normalization, not a newly invented state-only projection.

The generic theorem local_policy_factorization explains why the checked finite action classes yield a single local policy table. The explicit local_action function is already a compact realization of that table. refinement_maps_run and refinement_transports_property then apply to the constructed local/transition correspondence; their application is a derived mathematical adapter justified by the exhaustive finite certificate and source-level guard inspection. The Python source generator and target updater are not themselves mechanically extracted from Lean, and no such stronger implementation-verification claim is made.

### Termination, repetition and time

One slot has a successful finite verdict at its terminal cutoff. On both source and target use the paired clock state and the projection alpha_hat(prefix,tick)=(alpha(prefix),tick). ClockedDigitalPoint additionally implements the optional terminal embedding as (prefix,tick) advancing to (prefix,tick+1), with an actor-visible clock and no new service; every following command profile has this successor. It can either be embedded into the common core with a marked clocked terminal stutter for that finite mission, or be followed by a new epoch. Unexpected earlier termination receives a failure verdict; ordinary prefixes are not maximal executions.

Sequential repetition retains the same fault identity and immutable committed history, advances the epoch tag, and provides a fresh leader input. The local history adapter to the per-slot policy takes the suffix beginning with the newest epoch marker. This is essential: applying the per-slot phase computation to an unsliced concatenation of old and new records would confuse old phase markers with the current phase. The suffix operation is actor-local; it supplies no information about faulty identities. Old messages cannot re-enter the new slot because epoch validation is part of admission.

The preserved service claim is one completed entry per three logical rounds, with decision at round two and public evidence at round three. The extra inside-round delivery observation is an event point, not an additional elapsed round. An event-counter safety/refinement theorem alone is therefore not a proof of that rate: the source and target retain the same round-clock annotation and cutoff schedule. There is no assertion of a physical seconds-per-round bound or an overlapping-slot throughput improvement.

For arbitrary repetition, induction uses D2 agreement and correct-leader validity on each legal fresh slot; the append operation preserves earlier entries. Digital.lean proves the corresponding unbounded ledger equalities. The finite same-fault two-slot checks supplement that induction. No new independent faulty set is selected on each epoch.

### Epistemic versus strategic transport

Because the target retains the same event alternatives and local records, the digital module's event-product comparison preserves Boolean/nested-knowledge queries over tracked facts. Complete guarded histories also preserve fixed-protocol temporal statements and branching historical-slot finality. These judgments use the same source executions, not the former independent delivery example.

This adapter does not infer strategic equivalence from epistemic equivalence. Its policy is fixed and independently checked. Replacing the protocol or synthesizing different actor commands activates the whole-prefix prescription and local-refinement obligations again. The distinction is material: the earlier hidden-state continuation example fails despite its one-step safe state projection.

## Contexts and fault reindexing

The common carrier is parameterized; identical vocabulary does not identify the following contexts. Their fault maps are part of the assembly, not assumptions of stochastic independence.

| Context | Joint fault index and role map | Consumer and restriction |
|---|---|---|
| Digital D2/D3 | One fixed faulty participant or none among identities 0–2; observers 3–4 are protected verifier roles. | Broadcast signing/forwarding and terminal evidence. Physical scalar state is not a ledger input validity premise. |
| Original integer control | Six identities: three sensors and three authorizers, with at most one faulty identity in each role triple; 16 joint coalitions. | The same B controls reports and endorsements through the corresponding role projections. The bounded physical bypass is a separate admitted influence even when B is empty. |
| Institutional replacement | Twelve identities across two configurations, with the four role-triple caps; 256 global coalitions. | Installation checks both role maps against every admitted B. Moving to the second configuration retains B; it does not resample faults or certify cleaned old keys. Each installed six-role projection recovers the integer control interface. |
| Evidence/timed runtime | Three identities each holding both sensor and authorizer roles; none or one is faulty. | Co-location couples the two corruption channels. It is a restriction of the more general separate-role fault relation, not a declaration that independent role faults are impossible in every implementation. |
| Physical role adapter | For each institutional configuration, map its sensor triple and authorizer triple separately to local indices 0–2. | The two projected faulty sets may differ, but both come from the same global B. The source-hypothesis and authorization conditions are checked under those projections; the global label is retained. Both configurations over all 256 B yield 512 checks. |
| Ordinary quorum alignment | General F in Lean; four identities with at most one fixed fault in the finite specialization. | Q3 plus an exclusive fixed-slot signing guard yields ordinary certificate exclusion. This context is not substituted for D3's protocol-derived two-share exclusion or for permissive physical authorization. |

These are views of a parameterized family. Where one module is actually composed with another, the specific reindexing and judgment preservation are exhibited. No theorem asserts that every context above is behaviorally equivalent or that one coalition cardinality can replace the effect and evidence contracts.

## A-P: physical local implementation and continuous decoding

[PHYSICAL-ASSEMBLY](PHYSICAL-ASSEMBLY.md) and [physical_adapter.py](physical_adapter.py) connect actual signed reports, locally computed fault-labelled inference, interval endorsements, authenticated support selection, the pending FIFO and realized flow. The history map exposes attributed received messages and public current context; the action lift reattaches those same public timestamps, target slots and schedule bindings. It does not read inventory, actual B or future disturbance.

The concrete model includes explicit input-selection and administrative boundary events as well as the four ordered communication/control phases. Every event advances the locally observable event tick and retains the existing actor histories; continuations do not restart their Frame. Administrative events take zero modeled physical time and consume bounded retry credit, so physical_time is separate from the event count. At most seventeen events elapse per T-duration physical round. Its abstraction projects completed communication effects to the typed Evidence operations and its full-period plant effect to the held-input recurrence. Positive-delay operation allows continuous flow while communication proceeds; the old committed FIFO determines that flow. A source command is ready before its declared target effect time, under the round-processing premise. The separate instantaneous zero-delay interpretation does not acquire a positive-time communication deadline by this map.

Command normalization supplies an outcome for every decoded finite request, including malformed, stale and forged data. The all-request nonblocking proof uses the honest observation/overlap/common-interval/availability argument, not a claim that a finite selection of hostile numeric values exhausts arbitrary values. A typed authentication API is only invoked after ingress validation, so an unhashable forged object cannot turn a rejected request into an exception/deadlock.

Two preservation laws are needed. At a fixed event scale the local history/action and communication-image maps preserve following profiles and actual successor effects. For the physical time scale, every decoded held-input execution has the affine integral trajectory, and the established tube bounds cover every intermediate instant. This is a one-way control/property refinement with an analytic time decode; a contraction to completed physical rounds is not claimed to be the same-index Lean refinement theorem. Input-selection and administrative events remain in the full event correspondence, and the separate elapsed-time decoder identifies the round boundaries. The same trajectory realizes service continuously at the specified positive rate.

The adapter also carries the same fixed global coalition through separate sensing/authorization role projections and checks current-context maps into the institutional configurations. This supplies a meaningful compatibility law beyond separately counting sensors and authorizers. The physical and institutional scalar policies need not be identical: each implements the relevant common inference/support/effect contracts at its declared state, command and time scale.

## A-I: institutional phases and actual effects

[INSTITUTION-ASSEMBLY](INSTITUTION-ASSEMBLY.md) and [institution_adapter.py](institution_adapter.py) stage each epoch as administration, sensing, endorsement and effect. At most one administrative attempt occurs before sampling; the installed configuration and institution remain fixed during the subsequent collection. The result prevents policies from reading a post-administration norm while their commands are incorrectly modeled as simultaneous with the preceding administrative choice.

Actor-local histories contain only the actor's actual received packets and their public authentication verdicts, together with public configuration/mode/epoch information and its own actions. A local verifier checks those snapshots; it does not provide the policy with the global authentication event log or actual coalition. Correct sensors receive only their own sampling input. The projected effect keeps inventory, actual delivered service, mode, current scope and historical breach.

Invalid or unavailable commands have explicit successors. In particular, a live state with insufficient normative capacity does not disappear because control_epoch cannot produce a certificate: the adapter admits the actual failing effect and a clocked failure verdict. Within the certified mission invariant, honest certificate availability makes that failure branch unreachable under every admitted Byzantine traffic profile. Thus nonblocking is a property of the operational transition, and successful service is a stronger invariant theorem under its stated premises.

The institutional transition policy preserves the same B through configuration replacement, distinguishes recognized status from physical isolation, and checks power/permission/access separately. The four-event schedule gives one actual service event per epoch; its observer clock and duty monitor retain that meaning. Unexpected failure is not converted into a completed mission, and indefinite administrative attempts cannot replace the required effect phase.

## Timed recovery compatibility

[TIMED-RECOVERY](TIMED-RECOVERY.md) uses a different, explicit administrative interface for the continuous FIFO. Existing finite commitments survive new-admission suspension as slot-specific leases; old signatures cannot authorize fresh commands. Effective isolation precedes capacity reduction, and the queue drains before repair. A protected reservation can recenter an arbitrary safe ready state and retain the d warmup tail before release.

The two entry contracts matter. For a certified live FIFO, robust pending endpoint safety gives [z−rδ,z+rδ]⊆S. Perfect isolation makes the drained endpoint exactly z, so z∈J already, and constant-d repair preserves it. Recentring is optional on that ordinary cycle. For arbitrary safe isolated-ready states, J need not hold; the recenter certificate supplies the missing restart condition. The boundary-release failure belongs to this larger entry class. Treating the latter witness as an unavoidable failure of certified drain would overstate the mechanism's necessity.

The map from released timed recovery back to E-H retains state, time, fixed coalition and nominal history, with fresh current scope and a live-safe d FIFO. The actual protected administrative observation is constrained to the authentication provider's output and physical/recognition acknowledgments; a manually forged positive Boolean is outside that environmental interface. Explicit boundary transitions and their independently calculated target updates retain the full run. No physical reset or queue retiming is hidden. This transports continuous safety and actual service, while finite reinstatement still depends on eventual clean/administrative readiness. It does not equate fixed-membership key refresh with the separate twelve-identity replacement protocol.
