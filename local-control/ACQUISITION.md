# Maintained acquisition from physical origins

Status: derived supplier construction and executable first-pass checks; source admission, the effective-domain bound, full runtime compilation and the recurrent mission remain open. The construction replaces the successful-reader premise for a specified finite apparatus. It does not replace the cyclic restoration of that apparatus. [INSTANCE](INSTANCE.md), [INFORMATION](INFORMATION.md), [STREAMING](STREAMING.md), [CONTINUITY](CONTINUITY.md) and [BOOTSTRAP](BOOTSTRAP.md) retain their separate responsibilities. No novelty or repository acceptance is claimed.

The selected source uses the separately repeated three-head plant block and incremental state/functional maintenance publisher in §10, plus the fixed-slot on-demand code supplier in §8. The periodic all-code supplier in §3–6 remains an explicit cost/latency comparison.

The result is conditional on primitive sensor, wire, clock, instruction and contact laws, and on the same-window causal support supplied by the parent. Its outputs are a bounded-age value comparison, a bounded complete read opportunity and, after a physically justified freeze/wait, a common first matching bay. It deliberately forgets exact simultaneous snapshots, attribution, packet order and agreement-round identity. Those are not preserved by periodic observation. It retains the physical key, bank, origin, every raw copy, power pauses and old effects because their removal can invalidate these outputs.

## 2. Finite apparatus and physical key map

Take the radius20 ring in INSTANCE, with72 hosts per region and R≥6. A physical origin is one host, not one bank or one cartridge. A/B source banks have separate source caches, egress gates and paths, but share that origin's logical vote. The primary frontend supplies one reserved logical origin per group, represented by two source-bank records inside the same forgeable primary frame and may overwrite the entire received primary frame while the receiving execution continues intact. That reserved origin never reappears among the twelve auxiliaries. The twenty neighbors of each alternating rank contain thirteen distinct possible origins per rank. The receiver-owned primary frontend may affect the primary pair, but cannot write auxiliary records. For another receiver, a physical source is either its reserved primary backend or one auxiliary, never both; packet labels cannot grant access to its frontend. These actual incidence conditions, not the logical record labels, justify at most one affected origin per relevant host domain. Auxiliary origins are chosen distinct from the receiving host as well; omitting a participating inspector from forty possible code origins leaves enough choices, and omitting its rank from twenty leaves nineteen. This avoids treating a receiver-owned publication cache as an external independent auxiliary. Each rank-one plant head sees its origin's own or an adjacent region, as already specified; no head sees a full two-coordinate state.

For passive inspection, every origin o has its own read head and selection lead to each of its40 maintainable targets j. A head's selected address terminates at the actual cell in the retained body/bay, or at the actual specified load/pose transducer. The target's mutable program is not invoked. A nominal cell head returns the symbol of that actual cell when physically eligible, and unavailable otherwise. Below-separation measurement error is already included in this raw discrete-symbol law. Selection state and calibration belong to o's mutable bank; an altered selector affects that origin's observation, not a fictitious independent cell supplier. A target write changes the cell actually observed by all heads; it does not make each head report an attacker-selected substitute cell. A target-owned programmable mux in all thirteen routes is a different source with a thirteen-slot dependency.

A finite key is the tuple (physical target, retained body/bay, quantity or cell address, encoding). Physical seating/custody maintains body identity across the consumed interval; label equality cannot substitute for it. Keys and addressing have finite encodings fixed by design information. Each origin bank's intended routine walks its actual head table, acquires that selected head and emits its corresponding key/value. A receiver-side record is selected by physical ingress origin/bank and the bounded address decoder for that ingress. There is no payload origin credential and no shared programmable decoder that can exchange origins. A false key from a corrupted source can overwrite that source's key record, so every such downstream use retains that source's affected footprint. A nominal emitted key refers to the sampled physical head by the explicit program/head-table correspondence, not by trusting received text.

A preparatory publication lead can fill the finite per-origin records while a separate physical observation-enable contact masks their value outputs. The masked receipt circuits remain powered and keep aging. The contact is driven by actual travel/startup geometry, not by a READY assertion. Before a new bank opens that contact, old queue traffic is drained and the complete first required head-table sweep has overwritten its records; only then can any of those words be consumed. This adds an actual contact/path to the candidate source. A layout whose only report contact disables all preparatory transmission cannot claim this entry argument: opening it before a fresh sweep exposes arbitrary I, while waiting behind it cannot populate remote records. Off circuitry and masked output are distinct states.

A source broadcasts a completed sample to the finite set of participating receivers of that target, at most d=80 receiver execution banks (two banks for each of forty inspector hosts). For any target, every participating inspector has an actual branch of every selected source's fixed local route. Those routes span at most forty host spacings; they confer no write reach beyond the radius20 maintenance edges. A branch has a per-origin/bank bounded raw queue and decoder; traffic on another origin cannot fill or remap it. Source fanout is charged d times, even where the physical fanout could be cheaper. Clients do not compete for a query lock. Every client receives the periodic stream whether or not it asks for a scan.

All data words in source caches, queued packets, receive records, DMA locations and temporary raw operands remain I surfaces relative to their consumers. A receiver C/W write lead cannot address the auxiliary records or an all-origin remapper. Source-side C/W may direct its own physical publications, thereby affecting one origin in each receiving group. The receiver retains only comparison flags, counts, search bounds and control state in W. Altering those derived fields is a separately typed inference-execution fault. An input-only write that can reach all raw observations is still an input fault and has all thirteen slots in its support.

## 3. Actual cyclic publication and finite work

There are two finite, disjoint head tables. The fast table has K_f keys for plant rows and all continuously consumed load/pose variables. The slow table has K_s keys for code readback. These receiver record and processor budgets are per execution bank; a host running both banks pays both. One concrete inventory bound is K_f=3+40h with h the number of fast apparatus scalars per target, and K_s=40·2·80·L for L cells per candidate image. The three plant entries all have the source's one rank. The two slow sides and eighty bays are the actual finite cartridge layout, not copies of one target RPC response. Unused entries can return unavailable in bounded time. The head/table size, circuit count and work do not grow with the execution horizon or R.

An intended origin program has two modulo cursors. Every bounded cyclic frame executes b_f fast acquisitions and b_s slow acquisitions, with b_f,b_s>0. A visit starts an ordinary raw conversion, waits its bounded completion time s, applies its mutable calibration/encoding code, writes the source cache, emits to the d destination branches, clears the cache's publication validity, and advances the cursor. It does not wait for an acknowledgment or another actor. Ineligible heads return unavailable through the same finite conversion. A false primary field does not control the cyclic table or suppress its traversal. The prefix initializes both cursors, but no common initial phase is needed.

Let F bound a whole frame in real hardware quanta. Then every head is acquired within

P_f=(ceil(K_f/b_f)+1)F,   P_s=(ceil(K_s/b_s)+1)F

of persistent eligibility or a previous acquisition, including arbitrary cursor phase. This is a loop bound: at most ceil(K/b) complete frames visit every entry after an initial partial frame. A sharper bound requires a per-position cyclic-work argument. It is not an assumed successful callback. Bounded conversion, finite instructions and an explicit allocation establish F. A suspended frame must either finish within its stated bound or lose reporting validity under the pause rule below.

For example, allow c_head=22+4d bounded-word operations per completed sample, including calibration, key formation, cache operations, all d queue offers and cursor bookkeeping; conversion contributes s separately. Let C_control reserve the complete plant inference, C_maintenance the bounded scan/copy visits and C_schedule the remaining finite administration. Every raw offered packet, including malformed, duplicate and rejected packets, is charged c_adm work in the lane circuitry or the processor actually handling it. If A_raw bounds all offered packets in one frame, the conservative sequential budget is

W_frame=(b_f+b_s)c_head+C_control+C_maintenance+C_schedule+c_adm A_raw,
F ≥ (b_f+b_s)s + W_frame/μ_- + J,

where μ_->0 is the actual nominal elementary-operation rate and J accounts for any allowed invocation/interruption time. Combining circuitry work into this sequential upper bound is conservative; a parallel realization must additionally pay its actual peak power. The controller image must implement these blocks; c_head and the reserved blocks are capacity envelopes, not a claim that a particular8192-cell image has been compiled.

Raw arrivals are limited before filtering. A concrete local lane design has a physical per-(bank,receiver)-lane egress limit of64 fixed-size records per quantum and burst64, per-lane queue capacity128, and a dedicated finite lane service that examines at most128 records each interval of length at most1. Every offered record is examined at admission, including drops; the service retires each dequeued item rather than retaining it for replay. An intact lane that was just drained receives at most128 new items before its next visit, so it cannot overflow in that interval. Initial arbitrary entries are drained before this guarantee is used. Each record's wire and queue residence is bounded by D=2 in the example, including its latest possible next service. Nominal sources must respect the physical egress rate; shaping delay belongs in D or the source-cache bound. Bad sources may use their full rate. A shared FIFO without reserved per-origin service does not implement this construction.

A receiver execution bank serving every target within twenty spacings sees origins at distance at most forty, at most eighty hosts and160 banks. Thus a conservative raw allowance in any unit interval is A_raw=160(64+64)=20480 offered records. This is a pre-parser bound from physical line limits, not a claim that only valid frames arrive. There are finite independent lane state machines; a raw lane state-machine defect belongs to that lane's dependency. No single trusted lane scheduler is required. Its finite fixed circuitry and any physical defects retain their actual domain reach. Multiple receivers have their own lanes, and d fanout writes were charged at each source.

The numerical example uses h=16, K_f=643, b_f=16, b_s=1, d=80, s=1/64, μ_-=262144, J=0, C_control=3114, C_maintenance=584, C_schedule=256 and c_adm=4. W_frame=91688 and conversion plus work takes less than1, so F=1 is a strict upper allocation. Explicit positive minimum operation/conversion times and finite maximum clock rate exclude infinitely many frames in finite time. The nominal per-source/per-receiver-branch offered rate also fits64: a frame must spend its deliberately executed20480 admission-slot examinations, even if empty, so its minimum duration at μ_+=1.01μ_- exceeds0.309 and seventeen samples require less than55 records per quantum. A physical shaper with burst64 covers the intra-frame burst. The model records these exact rational inequalities. This is a nonempty raw timing/capacity allocation, not proof of the parent's complete runtime or energy reserve. The parent may replace these rates/inventories only with the same inequalities rechecked.

## 4. Cache, queue, receipt and actual age

A source cache contains one acquired fixed-width sample and a saturating remaining lifetime. Only completion of a real acquisition installs a sample and starts that lifetime. Repeated requests, CLEAR, acknowledgments, claimed timestamps and equal payloads do not extend it. This publication policy accepts no requests that trigger retransmission; if an implementation uses bounded retransmission it may emit only while this same nonrefreshing cache is live. Completion occurs within S of the actual sample, and emission occurs within C_s more real time. The periodic implementation clears its cache validity after fanout and fits C_s=2; it does not keep an old code value eligible for retransmission until the next slow sweep. Arbitrary copies left in I cannot be emitted by a nominal restarted publisher before its explicit invalidation/fresh-acquisition prefix.

Every receive record contains a fixed-width value or unavailable sentinel and a finite saturating receipt countdown. A physical receipt installs the value and sets that countdown to E local ticks. Nominal local elapsed clocks have rates in [a,b], 0<a≤b, with arbitrary offsets and varying rates. The actual record is unavailable when its countdown reaches zero. It never wraps. Countdown/validity is derived from the local receipt transition, not a timestamp inside the payload. At most E/a real time elapses before expiry; at least E/b elapses before a newly received record expires. The stated nominal minimum uses a receipt-armed relative timer whose phase begins at receipt; its finite counter plus raw oscillator phase implements the elapsed-time model. A free-running integer-tick implementation instead has a conservative minimum(E-1)/b, so its guard/lifetime calculation must include that tick-quantization allowance. PROGRAM’s wider ceil(b·gap)+2 variant can supply it. Neither a packet timestamp nor reading a record resets the timer. A fixed bounded per-origin circuit can implement the counter, data word and decoder. A w-bit counter admits arbitrary values up to Ehat=2^w−1, even when nominal receipt sets a smaller E. After the last possible input write/receipt, saturation decrements this arbitrary value to zero within Ehat/a. Ending intrusion does not reset it to E or make its payload genuine. A stuck timer, ongoing write capability or broken clock-rate law remains an affected path/physical defect until actually removed; release is not a timer-repair transition. Its state and every raw latch remain I. Corrupting a circuit, its rate or its retained word is a path/origin observation fault. A circuit that is powered off exposes unavailable; it must actually set its countdown to zero before reconnecting after a pause. A merely frozen countdown is not elapsed time.

For a nominal record sampled at t_s, emitted at t_e, received at t_r and read at t_c,

t_e−t_s≤S+C_s,   t_r−t_e≤D,   t_c−t_r≤E/a,

so A_read=S+C_s+D+E/a bounds its actual age. A caller using the result for another T_use quanta must include that interval and all command/effect delay. No global phase, source timestamp, unique epoch or successful CLEAR is used. Equal samples from different acquisitions are harmless because the actual recent sample supplies the same bound. A replay reaching through a damaged path is charged to that path; a nominal queue never reintroduces a dequeued record.

For continued availability of a persistently eligible head, successive nominal acquisitions are at most P apart and deliveries at most P+D apart. Therefore E/b>P+D is sufficient for the old receipt to remain valid until the next, once the first genuine record has arrived. This inequality is a service conclusion of the cyclic schedule plus bounded raw transport. It is not a freshness inference from the mere presence of a record. It applies separately to every receiver and every key. Different legitimate sampling phases do not split the guarantee.

Use E_f=64, a=1 and b=1.01 in the example: P_f≤42, and64/1.01>44. Then A_fast=1+2+2+64=69. With T_use=2 for the two row searches and three more quanta through effect, A_effect≤74. The plant allowance is .005+3.316·74/250000=.005981536, below .02. This example has room below the old provisional1000-quanta age, but the concrete controller's complete shared schedule must fit T_use; the inequality does not silently cover another long scan. Slow publication uses E_s=ceil(b(P_s+D+1)) local ticks and its own A_slow. Arbitrary old timer state uses Ehat_s rather than E_s for clearance. It consumes a large finite counter and record inventory. Fast work never waits for the slow table.

A powered-off old bank can leave packets and live records. If its last possible source transmission is at c, queues drain by c+D and every nominal old record expires by c+D+E/a. For arbitrary retained data/counter state the safe residual is c+D+Ehat/a, after the last possible counter write as well as receipt. A good sibling does not shorten this interval. If the old source can continue transmitting, there is no such bound. Reconnecting a physical bank after repair reuses the same bounded counters, keys and A/B records; no unbounded epoch counter is needed. Before reconnection its stored prefix and explicit latch-entry sequence invalidate source caches, drain queued old transmissions, acquire fresh data and install new records. Report contacts stay physically disconnected until that sequence has actually had time to execute. CYCLE must supply that contact travel and the all-path cut; a READY message is not a supplier.

**Initial incoming debt is different from a fault footprint.** INSTANCE permits arbitrary incoming I even on an otherwise nominal selected host. In particular, an inactive sibling record can initially contain a false word and counter Ehat. It has no legitimate sample prehistory. Neither A_read nor the same-window six-origin bound proves it sound, and it is not six-or-fewer new Byzantine origins. The entry policy withholds precise estimates/common selection until all initial records of that class have either been overwritten by genuine post-entry publications or have expired after the last possible arbitrary prehistory input. If T_entry bounds completion of the actual source cache/publisher entry and D drains initial queues, the conservative independent quarantine is T_entry+D+Ehat/a from the source's declared initialization boundary. Local waits must use their minimum elapsed-time bound, not common phase. During this interval the parent's actual startup fallback supplies plant service; this component does not grant an initial estimator. Fast and slow classes have distinct debt and gates. A later new bank likewise invalidates its source cache, drains stale packets and overwrites its whole code publication table before its code driver joins; an old sibling's poisoned records retain their separate tail. Power-off receipt outputs are invalid, and actual counter-zero writes precede their reconnection; leaving a frozen counter connected is the retained failure case.

**Storage and timer work are explicit.** No code-key array is placed in receiver-private W. One source I conversion cache can be reused, with actual invalidation; private source state needs finite cursors, scratch/count state and its instruction layout. The per-key receive/publication arrays are external I. A conservative upper inventory is160(K_f+K_s) records per receiver; unselected routes may be omitted only after the physical slot map is checked. For L=8192 this upper bound is8,388,710,880 records, each with its value width and, for slow records, a26-bit counter. These large bounds are deliberately unoptimized and require a real finite storage/circuit allocation. If timers tick separately at rate at most b, their aggregate circuit work is at most b times that record count elementary timer updates per quantum, in addition to W_frame and receipts. The frame calculation does not pay this array through262144 serial CPU operations. A parallel timer realization pays its full circuit/peak-energy cost; a serial implementation must enlarge its frame/age bounds accordingly. Root must include this inventory in the stock/peak-power source account or replace the supplier with a proved cheaper physical route. Finite memory alone is not evidence that the existing numerical resource budget fits. Corrupted counter state expires by the bit-width bound; corrupted programmable counter code would instead need actual renewal. This raw-circuit choice supplies no privileged clean observer or global coordinator.

## 5. One origin, two records, one vote

Encode an unavailable record above the largest admissible data word M. An elementary direct comparison `record≤p`, p≤M, is then false when unavailable. A lower-bound guard uses the fixed reversed encoding M−value as its key type, so it also uses an upper comparison; no separate validity read followed by a racy data read is needed. Code matching uses one fixed-word equality, for which unavailable never matches an image symbol. These are ordinary single-word comparisons, not atomic multi-origin reads. Every addressable retained operand is I; the only retained result of a comparison is its derived Boolean flag.

For each auxiliary physical origin i, read A and B sequentially and count exactly

vote_i(p) = (valid_A AND value_A≤p) OR (valid_B AND value_B≤p).

The displayed valid notation abbreviates the same-word sentinel encoding. It does not authorize reading validity separately. The primary also ORs its two source-bank fields and contributes one logical vote. Both fields can be replaced together by one whole-primary-frame input fault; neither is a clean selection service. Neither both bank successes nor repeated deliveries add votes. The common source set F for the whole consumed window contains an origin if either bank, any still-live record, source cache, selector, calibration or path of that origin can affect the job. A bad sibling remains in F until its actual cut/drain/expiry, even while another bank is good.

Two properties suffice for an origin outside F: every valid read in either bank belongs to the same current/key-bound envelope [L,U], and at least one of the actual A/B reads is valid. Under them a successful vote implies L≤p. If p≥U, every valid reading succeeds and the availability property makes the vote true. With thirteen distinct origins and |F|≤6, the exact same two count implications as STREAMING hold: seven successful votes imply L≤p, and a failed majority implies p<U. Its search therefore returns an envelope representative in [L,U], including changing values between passes; it need not return a simultaneous-snapshot median. The parent derives |F|≤6 from the common full window. This construction does not assume or derive global H-return.

The read-availability property is stronger than coverage at every instant. With A read at0 and B read at2, let B be valid until1 and A become valid at1. There is always a valid bank, yet both actual reads are unavailable. A sufficient remedy is a complete-pair interval cover: if consecutive actual per-key valid-bank intervals overlap by at least R_pair, then one bank interval covers every [t,t+R_pair], by CONTINUITY's interval-cover proof. If the two reads occur inside that interval, one necessarily succeeds. It is enough for nominal report contacts to retain the old continuously published stream until the new continuously published stream has been established at every receiver, and then for at least R_pair more. Publication start, full first sweep and last delivery belong before this overlap begins. The example reserves R_pair=1; any interrupt or paused comparison that can exceed it must be included or restart the job.

The private algorithm expands each origin step to two direct comparisons, a Boolean OR and the original count/index advance. It uses at most10 word operations per logical origin per pass instead of6. With z=7 initialization fields and K=ceil(log2(M+1)), the bound is2z+K(10n+10)+3; for n=13,M=2000 this is1557 per row,3114 for two. The actual maximum number of raw comparisons is 2·13K=286 per row,572 for two. A fixed13-symbol code match costs at most2z+10·13+2=146 operations in the conservative scan allocation. These replace the old143-read/985-operation single-record row bounds when A/B merging is used. Shared plant/control work and a complete image scan cannot each spend the same reserved operations.

Missing nominal reads cannot be freely padded and still preserve the two-sided envelope. Unavailable-as-high fails safely for an upper-threshold permission test: seven successes still require a valid nominal low witness. It can bias the search above U or make progress fail, so it does not certify precise feedback or common selection without the availability proof. An all-input overwrite can make the intact procedure return arbitrary low values and authorize a high-load cut; its thirteen-slot support violates the positive condition. Altering the private count is a different execution fault, not a reclassification of that input case.

## 6. Frozen code and common first-bay availability

Let f be the actual writer-exclusion time, with retained physical body identity and every inspected C cell immutable from f through activation. A final scan that merely uses cached pre-freeze reports can accept an old good image of a now bad body. It must also occur after the independent initial-I debt clearance above; a freeze-age wait cannot retroactively give an arbitrary initial word a real sample prehistory. One valid branch is to wait strictly more than A_slow after a locally justified freeze entry at t0≥f. A local wait W ticks must satisfy W/b>A_slow; its completion is bounded above by W/a plus the actual polling allowance. This wait is not refreshed by incoming timestamp claims. Every nominal valid read afterward was sampled after f, so it refers to the very frozen image to be used. The other permitted branch would explicitly schedule new post-freeze acquisitions; this construction uses the full-age branch.

A persistently eligible cell is visited every P_s, and all client branches receive the sample within D. With the slow lifetime inequality, every connected nominal bank is continuously readable after its first such visit/delivery. The A/B overlap supplies an actual valid read on each logical origin. Therefore every participating inspector, at every symbol test of the least eligible matching bay j*, obtains at least seven exact matches to its actual intended reference, assuming the common support bound. A different symbol in any earlier eligible bay obtains at most six false matches and is rejected. Ineligible bays have only unavailable nominal inputs and cannot pass. Every inspector accordingly selects the same j*, regardless of unrelated truthful errors or primary forgeries. This establishes OPERATIONS' common-first-bay condition from the periodic head, route, age and overlap construction; it does not assume an RPC was successful.

A complete receiver scan costs at most146BL bounded-word operations plus finite choice bookkeeping, or B·L bounded per-cell visits in the actual schedule. With four visits per frame shared round-robin over forty target tasks, one target receives at least one cell visit every10F and a conservative scan bound is10F(BL+2). Concurrent inspectors consume their separately provisioned receiver resources and the d fanout cost already charged; their requests do not increase source sampling work. The parent must hold the physical no-write/body-custody interval through freeze recognition, the full-age wait, the latest inspector's complete scan and activation. Its pre-power geometry must cover that complete bound. Current code equality alone, or an early inspector's completed scan, is insufficient.

For L=8192, B=80, b_s=1 and F=1, K_s=52,428,800 and the generic P_s=52,428,801. The example slow receipt lifetime is52,953,093 and A_slow=52,953,098. A safe integer local wait is53,482,630 ticks, with a real minimum exceeding A_slow. The conservative target scan bound is6,553,620. These replace a1000-quanta code-read freshness allowance and the old assumed callback scan bound. Larger b_s, faster justified frames or a constructed on-demand route can reduce the cost; simply keeping the old feasibility numbers cannot. Fast and code report drivers have separately timed entry. Fast publication needs up to P_f+D after correct prefix/head entry; code publication needs up to P_s+D, plus actual old-queue clearing and latch application. The code driver stays physically disconnected through that complete first slow sweep. Each completed fresh acquisition overwrites the corresponding record while disconnected; no counter generation tag is used. Entry overwrites the complete actual table, including unavailable entries, rather than merely setting a software READY field. The fast driver can enter earlier, but a common contact that connects both must pay the larger bound. That readiness cost must enter CYCLE's overlap geometry. This is the consequential remaining supplier boundary, not a claim that the old B_ready already fits.

## 8. Selected code supplier: fixed on-demand client slots

The periodic all-code table above is retained as a checked comparison. Its memory and parallel-timer cost are material, not an innocuous consequence of finiteness. The selected main candidate keeps periodic fast plant/pose/load publication and replaces only slow code publication with the following fixed-slot demand service. Both retain the actual passive heads, physical origin/path separation, same-word comparisons, full consumed-window support, old-effect accounting and all-client common-selection theorem. This is a source refinement with a smaller memory requirement and a larger per-cell scan time; it is not universal dominance or a change to the mission.

### Request, sample and reply state

For each source origin bank o, enumerate the finite slots (inspector host c,inspector bank h,target j) for which c and o both maintain j. There are at most40·40·2=3200. The physical ingress determines c,h and j; a payload cannot allocate another slot, impersonate another client or redirect a target lead. Each slot has one fixed-width request word, one bounded reply queue and one external reply record at that client execution bank. Two nominal banks of one host can hold different keys concurrently, so their request slots are distinct. A host-only slot can be overwritten indefinitely by the other healthy bank and does not satisfy both stabilization obligations. Source A/B votes still count once; requester-bank state is never merged by that rule. A source uses one reusable conversion/cache object and a modulo slot cursor. Private desired keys, scan cursors and elapsed waits are policy state; request words, raw selected keys, conversions, packets, reply records and all their copies remain I. The number of active slots is independent of L; only key width depends on L.

A nominal client sets its desired (side,bay,cell) key in the actual per-origin/bank outgoing slot and holds it unchanged through the bounded attempt. The chosen request transport is a fixed held-word physical lead with bounded settling D_req: after the source driver holds a word for D_req, the actual nominal destination word is that word until it changes again. This is an ordinary delayed electrical/register relation with its real physical binding and bandwidth; it gives neither an acknowledgment nor a sensor answer. Raw changes still have a physical rate/burst limit and admission cost. Every request copy, transmit latch and selector has its actual path incidence. An input-only capability that rewrites or suppresses all thirteen outgoing request paths can defeat all-client availability while the consumer execution remains intact; it is a thirteen-slot influence, not a faulty executor by definition. The selected topology has separate per-origin request slots/paths and no such shared programmable request remapper. A packet transport may replace this lead only after deriving the same stabilization, for example repeated current emission and a J_req+2D_req drainage argument; a one-time write followed by reordered old packets does not suffice.

On each source visit, ordinary instructions read that slot's actual request word, check its bounded key range, select the corresponding passive cell head on fixed target j, complete one real conversion, encode the captured key with the returned symbol, emit the reply to that fixed client/target slot, invalidate the source publication cache and advance the cursor. Invalid requests receive the unavailable word through the same bounded visit. The sampled key is captured at head selection and is not reread from a request that might change before publication. An attacker-addressable captured raw key remains I; altering it or the selector is an affected source/path, not a free correct binding. All these programmable actions are in the bank's renewed C/W. The target's program is still never asked to report its own cells.

Let V be the finite code-symbol alphabet size and K=2·80·L the number of per-target cell keys. A valid reply word is encode(k,v)=kV+v, with 0≤k<K and 0≤v<V, in a word width w satisfying KV<2^w−1. The remaining top word is unavailable. The complete runtime now instantiates a C cell as192 bits and its symbol alphabet as V=2^192, including arbitrary bad cells; private and raw reply words are256 bits. For L=8192, K=160L<2^21 and every valid encoded reply is below2^213, leaving the256-bit top sentinel separate. Instruction-cell storage/transfers pay three64-bit limbs, and a reply pays four. This is a new concrete ABI, not evidence that the prior word-rate, serialization or energy allocation transports unchanged. The provisional native-wide-operation budget below must be replaced by the actual runtime expansion.

A nominal reply lane assembles all four64-bit limbs in an origin-separated I staging buffer, then publishes the completed256-bit word atomically to its current record. A direct comparison consumes that one complete word. It does not perform four separately changing limb reads. Current and staging buffers, their pointers and every retained operand are raw I with the same path incidence; no shared all-origin assembly/remapping stage is added. The minimum data storage is thus two256-bit buffers per record, plus its counter and finite assembly state, not just one256-bit payload. Wire bandwidth of64 records per quantum per branch means256 serialized64-bit limbs per quantum, with the full frame cost, and aggregate egress is up to eighty branches. A malformed or incomplete frame never publishes its partially assembled payload as a nominal complete word. The model retains two genuine nonmatching frames whose torn limbs form an exact false key/symbol match, and shows that complete-record publication blocks it. This is a single fixed-width record boundary, not an atomic frame across origins.

 The consumer tests exactly `reply_word == encode(current_key, actual_reference_symbol)` in one direct word comparison. A wrong key, malformed record or expired reply cannot satisfy that equality. There is no separately sampled key/validity check and no raw record copied into private W. Corrupt metadata cannot turn thirteen copies through one target server into independent heads. Finite public keys can be reused indefinitely because equality is accompanied by actual sample-age control; no fresh nonce, unbounded generation or wraparound ordering argument is used.

### Constructed response bound and concurrency

Each complete cyclic frame serves b_q>0 of the fixed slots. A malicious client's changes may make its own answer obsolete, but cannot add slots, extend a conversion, restart the global cursor or block another client's visit. Therefore P_q=(ceil(3200/b_q)+1)F bounds a visit to any slot after its request has stabilized, including a possible initial partial frame. One completed sample is emitted within C_s and a nominal reply arrives within D_rep. If a client holds key k from t, a nominal bank interval containing the whole attempt supplies a genuine k reply by

T_reply=D_req+P_q+S+C_s+D_rep.

That conclusion is derived in order: held-word settling, a complete finite cursor cycle, a bounded raw conversion, ordinary bounded cache/publication instructions and bounded raw queue residence. It is not a successful-RPC premise. Old packets can still arrive during the attempt; after the request settles, the source never again samples another key until this client changes it, and the last prior-key reply is gone within the same delivery bound. A current-key reply may also predate this attempt, but its nonrefreshing source/receipt age remains bounded. Cached reply equality does not claim sampling after this particular request.

Set the nominal receipt lifetime so E_q/b>P_q+S+C_s+D_rep+1. Once the first current reply has arrived, repeated visits keep a valid current-key record available through the fixed read deadline and later repetitions. With cyclic source service maintained through the whole consumer attempt, bridging successive completed publications is sufficient: the earliest reply may expire after a newer current-key reply has replaced it. Here the frame-based P_q denotes a completed visit/publication; the extra S+C_s in the displayed first-response bound is a conservative allowance. If continued publication after that first response is not supplied, a stronger single-reply condition is required: the earliest possible genuine reply must survive the latest prescribed read, for example E_q/b>T_reply+R_pair. The standalone numerical example takes the stronger bound; PROGRAM may use the continuous-publication variant only with its complete ready-window proof. A conservative client waits T_local ticks with T_local/b≥T_reply+R_pair and then reads its A/B replies within the reserved pair span, retaining the same desired key. The local wait's upper duration and actual scheduling lag belong in its cell-attempt bound. All participant clients can do this simultaneously: each already has its fixed slot, source service cost does not depend on which clients are polite, and a bad client cannot consume another client's lane queue.

For two-bank continuity, use the complete-attempt interval, not just instantaneous report availability. If every consecutive actual nominal code-bank interval overlaps by at least T_reply+R_pair plus the caller's proved polling/read allowance, CONTINUITY supplies one bank that covers the whole held-request attempt. That bank sees the settled key, services it and leaves its response live for the actual read. A/B still contribute one logical-origin OR. The other bank may have unavailable or different-key data; a compromised sibling with a matching false reply still makes the whole origin affected until its actual cut/tail/expiry. This condition is stronger than a one-quantum overlap because it is now also constructing the response, rather than reading an already continuously published per-key value.

The source's3200 requester-bank reply slots are a finite active-job structure, not3200 protected observers. New source entry invalidates its reusable cache and initializes its slot cursor. While the observation gate remains physically closed, one full bounded slot cycle overwrites every reply record with a genuinely sampled key/value or unavailable, after old packets have drained. Initial incoming requests may be arbitrary; sampling the actual selected in-range head still creates a real sample, and malformed requests produce unavailable. The gate can open after this entry cycle and last delivery. If a participating client's held request is nominal, its exact current key is served within the response bound thereafter. Source and receiver pauses retain the explicit invalidation/gating rules in §4; no raw array becomes private W and no counter state becomes good merely on release.

### Freshness, freeze, initial debt and first choice

Same-key reuse after arbitrarily many cycles is therefore harmless only within this actual-age law. Forwarding an old reply as a new source sample, resetting its cache lifetime from a request, or accepting a paused timer defeats the proof and is explicitly outside a nominal source/path, not excused at an intact receiver.

## 9. Mutable producer readback after one entry wait

The producer can establish current cell equality without recognizing an acknowledgment of its latest write. This section supplies the cached mutable-copy adapter for §8; the runtime may instead use a separately justified direct-current own-lead acquisition. Its costs must not be silently mixed with this cached route, and final frozen scans still use their separate freeze/quiet-tail wait. The retained OPERATIONS/CLAMP first-closing argument already uses exclusive expected-value copying. The added obligation is its temporal bridge from bounded-age A/B input to the current mutable cell. The result is an elementary preservation argument, not a new storage or acknowledgment protocol.

### Entry law and actor-visible gate

Fix a candidate body b, a physical address set0,…,L−1 and one fixed intended image P over that set. Let e be an actual entry boundary after all pre-entry wrong write/CPU/command tails capable of reaching b have finished, the body-to-bay/address binding is retained, the target CPU and every other ordinary writer are excluded, and the producer-bank-private ordinary lead is the only admitted ordinary writing path. From e onward, every successful ordinary write at physical address j installs P[j]; a failed, disconnected or dropped write leaves the cell unchanged. Writes to another physical address do not change j. These are actual transition properties, not a promise inferred from the current command string. In particular, a logical address alias or a late wrong packet violates this entry law. No direct exceptional corruption or body substitution may occur in the claimed preservation interval. Such events remain consequential in the parent's fault/cycle analysis; this lemma does not silently convert them into observational faults or newly counted acquisitions.

CYCLE/HYBRID owns the physical supplier for e: actual cut/exclusion, bounded funded write/instruction tails, reset/drain travel and retained body custody. The present policy does not read e or a successful-drain flag. It starts its existing finite local relative timer on a justified local entry cue at t0≥e. If the available cue is an earlier physical cutoff with an additional wrong-tail bound T_dirty, the timer must instead cover T_dirty+A_q. A reported phase label, arbitrary new epoch or released intrusion is insufficient. Until that supplier is proved, the entry law is the precise remaining CYCLE interface, not a new-acquisition count.

For the selected A_q=824, a834-localtick wait has actual minimum834/1.01>824. The producer may issue expected-value writes during this wait, but a read match cannot advance its copy cursor, set its copied/completed flag or supply first-closing effort before the wait has elapsed. Independent arbitrary initial-I debt must also have been cleared by the §4/§8 overwrite/expiry mechanism; a real-age wait does not give an arbitrary initial word a sample prehistory. Timer/flag/cursor state is actually initialized on entry. ### Equality preservation and cursor advancement

For a fixed physical cell j, each ordinary transition after e is either `value := P[j]` or no change; writes to other cells and failed writes are in the second case. Thus `value=P[j]` is forward invariant after e. The proof is by induction on the actual finite sequence of intervening writes: a successful expected write establishes the predicate, and an unchanged transition preserves it. Positive minimum instruction/transport time and finite offered-rate bounds exclude infinitely many writes before a finite decision. The same reasoning applies pointwise to the complete image. It does not require writes to succeed, nor does it require the image to remain globally immutable while future cells are being prepared.

Suppose a producer reads a matching reply at time r after its entry gate. The bounded-age/key-bound nominal relation supplies an actual sample time s with r−s≤A_q and the sampled physical value P[j]. Because r>t0+A_q and t0≥e, s>e. With thirteen logical origin votes and at most six affected origins over the full consumed window, seven matching votes supply at least one such nominal witness. A/B is still an OR within one origin; a valid pre-entry matching sibling would otherwise defeat the inference. The forward invariant transports equality from s to the decision time, through later expected writes and failures. The match therefore proves that the CURRENT actual cell equals P[j], although the last attempted write may have failed and the witness may precede that attempt.

Maintain the ordinary copy invariant that every address below cursor k currently equals its P symbol. At entry k=0. Expected-value-only transitions preserve every established prior cell. A successful match for the held current key k supplies current equality at k by the preceding argument; advancing to k+1 preserves the invariant. At k=L the whole retained body equals P. The producer then stops its ordinary writes and may contribute first-closing effort. This is actual accumulated cell equality, not an opcode called successful-copy. The freeze mechanism subsequently excludes all ordinary writers; the final post-freeze scan remains required for common candidate selection.

Changing the requested cell or returning to the same finite key does not invalidate this argument: each match compares the single encoded current key/reference symbol, and every admitted nominal witness after the entry gate refers to the same retained physical body after e. A reply for a different key cannot match; a same-key reply from an earlier post-entry equality is sufficient precisely because equality is preserved. Changing the intended image or rebinding the body/address map reopens entry rather than inheriting this invariant. This is why the guarantee is stronger than an acknowledgment convention for this particular copying task, but does not implement a general mutable register: later writes of another legitimate value are excluded by the copying law.

### Completion, failed writes and work

Sound advancement requires no successful-write premise. If every attempted write to a wrong cell fails, current genuine replies keep that cursor at the wrong cell; the procedure does not report completion. A cell already equal to P may be accepted even if every attempted write failed, because current equality is the required result. Bounded completion needs an actual nominal writable opportunity in addition: from an issued expected write, the connected permitted lead and ordinary storage transition apply that value within D_write, with bounded queue/admission work. This is the raw connected-write law plus the actual source connection, not a successful-write return value. If a reconstructed body/lead is unavailable, that candidate may fail to finish; the parent's first-closing proof needs at least one actual usable producer candidate, not a success oracle for all candidates.

For the displayed cached-route completion bound, starting a cell offers its expected-value write and installs/holds the same current request key; the program then waits for both its entry gate and its cell response gate before comparing. It may start the first pair during the entry wait, but cannot advance early. Expected writes are idempotent under the source law and each attempt is charged. A different compare-first/only-write-on-mismatch program must add its actual extra read/offer round rather than borrow this completion bound. The direct-current own-lead runtime is a distinct route.

Let J_visit=10F be the established maximum per-target visit gap. After a cell's request and expected write are actually issued, a sufficient bound for a new matching nominal response is

T_mut=max(D_req,D_write)+P_q+S+C_s+D_rep.

Indeed the requested key has settled and the actual cell has become P by the maximum of the first two times; a subsequent cyclic source visit samples P, and the bounded cache/reply path delivers it. Expected writes retain it. Use a local response wait with minimum at least T_mut+R_pair, and allow the caller's next target visit and comparison span. This may be slightly longer than the frozen-cell response wait, although older post-entry matches can legitimately finish sooner. Ongoing repeated failed writes do not extend any source cache's freshness lifetime, allocate extra source request slots or add votes.

Projection onto[0,cap] cannot increase error when the actual quantity lies in that interval: the three cases yhat<0,0≤yhat≤cap,yhat>cap give the claim directly. Thus all allowed error signs preserve availability at load0/isolation1. An invalid status or truly out-of-band datum is never clipped into a safe value; it makes the group unavailable. Failed insulation with a true value such as.6 stays far below.8 after bounded clipping/noise. The declared load cap is a source measurement-range premise, not an attenuation theorem.

### Actual bounded source procedure and ABI

Publish the three existing plant projections in their own bounded three-visit block each frame. Their provenance remains those three rank-one heads of the source's one sensing type; this creates no additional vote or trusted state observer. Give maintenance its own expanded raw cursor. Let H_state denote all existing raw state words per target, including retained endpoint/anchor contacts. In the current PROGRAM layout there are16+4B pose words and22+4B contact/state bits (including NORMAL_STOP and ABORT_FULL), so H_state=38+8B=678 at B80; the earlier336 pose-only count is not the complete inventory. Published maintenance words are H_pub=H_state+4, with appended offsets

    H_state+0: max sampled load, side A
    H_state+1: max sampled load, side B
    H_state+2: max sampled isolation deficit, side A
    H_state+3: max sampled isolation deficit, side B.

The public key space is therefore3+dH_pub, not3+d(H_state+2(P_A+P_B)). The latter expression counts RAW acquisition visits: each target contributes H_state+2(P_A+P_B) maintenance steps. There are two functional quantities for each side's every connector. For a symmetric count P, R_maint=d(H_state+4P). Distinguish these counts in the compiler and source-resource account; four aggregate outputs do not mean four raw sensors.

For symmetric P, raw cursor r decodes target t=r//(H_state+4P), u=r%(H_state+4P). A state step u<H_state samples its actual pose or retained-contact head and publishes key3+tH_pub+u. Otherwise let g=(u−H_state)//P and p=(u−H_state)%P. Then side=g%2, kind=g//2, with kind0 meaning actual load and kind1 actual functional isolation. A heterogeneous catalogue uses the four group lengths P_A,P_B,P_A,P_B and their stored constant prefix offsets. It may not pad away a real connector or call an unknown physical state an empty group.

Each maintenance microvisit performs the following finite ordinary body. The sole raw sensing operation is start_functional(t,side,p,kind), followed by the actual bounded conversion/wait and one current-result word. That primitive measures one selected head only.

```
if p == 0:
    I_AGG := 0
    W_failed := false
start one physical functional-head conversion
wait/check its bounded actual completion; preserve the captured physical key
if unavailable, outside the full encoded numeric band, or not the requested completed head:
    W_failed := true
else:
    decode BIAS and clip I_CURRENT to [0, physical cap] by compare/assign/subtract
    if kind == isolation:
        I_CURRENT := Q - I_CURRENT
    W_compare := (I_AGG < I_CURRENT)
    if W_compare:
        I_AGG := I_CURRENT
if p is the last connector of this group:
    if W_failed:
        send unavailable on this group's public key to every receiver bank
    else:
        I_SEND := I_AGG
        send that word on this group's public key to every receiver bank
invalidate only the current conversion/cache; advance raw cursor
```

The comparisons, conditional branches, subtraction, assignments and sends are ordinary small steps fetched from the same mutable image as the other source routines. There is no `max`, `functional_safe` or permission opcode. Raw observations, the selected-value accumulator I_AGG, I_SEND, packet assembly and all copies remain I. The accumulator is kept in I precisely because it retains a selected raw value. W holds only the derived cursor, failed flag and comparison/control flags. Changing I_AGG alone is an input fault affecting that origin's reported aggregate, not corrupted receiver execution. Source-program or flag corruption remains a separately typed execution fault. The program's I_AGG must be physically separate from reusable query/current operands; PROGRAM's proposed I6 is separate from query I0…5. Interleaved cell-query work cannot overwrite a partial functional fold. An ordinary current-cache invalidation must not clear I_AGG between connectors.

The first connector initializes the actual accumulator and failure flag before any sample. The failure flag is sticky through that group and resets only at the next group's beginning. Every connector is still visited in bounded work after a failure; the final unavailable publication overwrites the prior result instead of falsely refreshing its value. Reset/boot starts the raw cursor at a valid beginning and keeps reporting masked through the needed full first publication cycle, preserving the existing arbitrary-I quarantine and actual overwrite rules. A partially accumulated old group is not a fresh result after bank reuse.

A completed single-head conversion latches one coherent raw word in I_CURRENT until the program consumes/invalidates it or launches the next job. The passive quantity may keep changing; its completed sample does not auto-refresh between the comparison and conditional copy. This is a finite raw sample-and-hold operation with its real sampling time and faultable I storage, not protected truth. Without that local stability, an ordinary comparison can see a large value but its following copy a smaller one, losing even the prior maximum. An input fault can still overwrite the latch and is charged to that origin. Nominal query work is serialized after the microvisit and uses different raw operands from the partial accumulator.

A fixed count of rapid readiness polls is insufficient by itself. The compiled wait must last through the nominal conversion deadline at the maximum instruction/clock rate, or use a proved matched asynchronous completion/drain protocol. Outstanding conversions survive a rejected busy request and cannot be silently reassigned to its new key. A nominal completed result belongs to the head captured at launch. Missing/defective jobs take their bounded unavailable branch. Source and queue tails, pauses, field invalidation and power gates retain their earlier explicit interfaces. Completed256-bit records are published coherently after their per-origin limb assembly; partial word publication does not implement a functional aggregate.

### Fold invariant and the future envelope

After k valid connectors have been processed, I_AGG is the maximum of exactly their calibrated, clipped readings; a missing earlier connector makes W_failed true regardless of later small readings. The invariant follows from the compare/conditional-copy instruction: retain the prior accumulator when it is at least the new word, otherwise copy the new word. Initialization at zero is correct for the nonnegative load/deficit encodings. Thus a completed nonmissing record G_o is the maximum of one actual reading for every connector in that source's catalogue. Those readings may have different sampling times s_(o,p). It is not necessarily the maximum at any simultaneous snapshot.

Suppose the physical one-sided variation/jump bounds hold for every connector through the consumed horizon:

    x_p(t) - x_p(s) ≤ v_p (t-s) + j_p,

where j_p bounds cumulative directional jumps over the full interval, not one jump per event. Rates here are per hardware quantum; a physical-time rate must be multiplied by the common conversion tau. These are the actual functional bounds under admitted failures, not rates of carriage motion or an attenuation law. Let every contributing sample be at most A_G old at comparison, and let T_emit+H cover later computation/issue and HYBRID's complete refresh/reordering/withdrawal/retirement interval. Put

    beta_L = epsilon_L,max + v_L,max (A_G+T_emit+H) + j_L,max,
    beta_D = epsilon_z,max + v_z,max (A_G+T_emit+H) + j_z,max.

For every connector and every consequential time in that interval, x_p(t)≤G_o/Q+beta, since its own raw reading is no larger than G_o and its own error/rate/jump allowances are bounded by these maxima. This transports an ordinary staggered fold to one common future certificate. It does not certify a current snapshot median or discard the early samples. In particular, using only the last head's age is unsound. Using the rate of the scalar true maximum is also unsound: different connectors can take turns being high so the true maximum is constant while a staggered scan samples each one low. The per-connector variation data survive aggregation because they are consumed by this inequality.

At a receiver, let m=ceil(Q beta), computed from the admitted timing/physical bounds. If m exceeds the corresponding integer limit Q or floor(Q/5) (200 at Q1000), the predicate returns false BEFORE subtracting; unsigned underflow must not turn an impossible margin into a huge permissive threshold. Values above the limit may be encoded conservatively as limit+1 when forming finite constants. Otherwise count the13 logical-origin same-word tests `G_o≤limit−m`, merging source A/B by OR once per origin and retaining the whole causal-window support. Seven successes include one nominal source aggregate; that one aggregate certifies every connector for the relevant conjunct. The two conjuncts may have different nominal source witnesses. They still cover the same actual side, physical cut set and future interval. A forged whole primary frame remains genuinely consumed but has only its one actual vote. Unavailable is the existing top sentinel and fails the upper comparison.

The safety implication tolerates missing sources because a missing record never supplies a positive vote. Positive availability is separate: at least seven origins must actually finish every required head, their A/B read opportunity must hold, and the physical connectors must enter sufficient margin. If all samples have actual load≤ell_star and deficit≤d_star through a full refresh window, their encoded aggregate is at most the corresponding value plus its measurement error. Sufficient uniform positive conditions are ell_star+2epsilon_L,max+v_L,max(A_G+T_emit+H)+j_L,max≤1 and d_star+2epsilon_z,max+v_z,max(A_G+T_emit+H)+j_z,max≤.2. Failure of those sufficient inequalities can require more sensing service, smaller actual physical slew/jump envelopes or safe abstention; it is not a universal impossibility result or permission to substitute position for function.

### Full multi-read age, service and finite work

Let b_m maintenance raw visits complete per frame and F bound that frame. For a side group of P_S consecutive raw visits, a conservative oldest-sample-to-completed-group bound is

    T_fold,S ≤ (1 + ceil((P_S-1)/b_m)) F.

The extra frame covers the first/last partial frame; every raw conversion, comparison and final aggregate preparation is included in the frame's actual instruction/I/O bound. Any later cache/fanout delay C_s is added, not identified with the last head's age. With bounded residence D and nominal receipt lifetime E_G under local clock rates[a,b],

    A_G,S = T_fold,S + C_s + D + E_G/a.

For generic frame timing, use publication interval P_maint≤(ceil(R_maint/b_m)+1)F and plant interval P_plant≤2F. A tighter per-position cyclic-work proof can remove a partial-frame term, but a frame bound alone cannot: a sample may occur early in one frame and late in a later one. Choose E_G/b>P_maint+D for continuous nominal availability after first receipt, for example E_G=ceil(b(P_maint+D+1)). Separate plant lifetimes use their shorter period and raw single-head age. This prevents connector inventory from needlessly stretching the essential plant-row feedback clock. The code-query cycle has the analogous generic partial-frame allowance; earlier ceil(N/b)F numbers are valid only after their stronger cyclic-position bound is supplied.

All source code/flag/cache/path dependencies over the entire fold, later records, comparisons and effect horizon enter the same causal union F. An instantaneous good-origin count does not replace this interval support. Initial unknown records have no genuine fold history and still require actual masking/overwrite or bit-cap expiry before the age theorem is applied. A source with an unbounded pause cannot emit a half-old aggregate after resumption as if it were a new single-head sample.

The frame's actual operation inventory is three plant acquisitions/publications, b_m one-head maintenance microvisits, b_q keyed-query visits, the complete consumer/control/helper work, all raw admissions/rejections, timer work and any deliberate padding. There are at most3+b_m+b_q publisher/query raw conversions and at most2d(3+b_m)+b_q sample-publication/reply offers per frame; an intermediate functional head usually emits none, but the upper bound allows every maintenance visit to publish. Consumer request updates, ordinary writes, commands and any other output/capture attempts are additional actual traffic; the publisher subtotal is not a whole-bank I/O bound. For d40,b_m16,b_q4 these counts are23 conversions and1524 actual offers, not23 total offers. A particular receiver branch gets at most23 records/frame. Its publication/reply64-record rate envelope therefore needs F_min≥23/64 before additional same-branch traffic is added (or a proved shaper with its delay/cost included); aggregate source egress and four serialized64-bit limbs per record are separately paid.

Let c_decode, c_start, c_wait, c_range, c_reverse, c_compare, c_copy, c_flag, c_advance and c_offer be the actual emitted instruction/word-operation costs. A functional microvisit is bounded by their displayed body: decode plus initialization when first, one start/wait/range check, at most one reversal and compare/copy pair, failure/update and cursor work, and at most2d actual offers when last. Its bound uses the same primitive costs as PROGRAM's compiler; it is not the former c_head=22+4d. A failed visit pays its start/wait/range/failure work. Define C_func from that explicit sum and C_pose from the actual pose visit. A sufficient instruction capacity law is

    I_frame ≤ I_other + 3 C_plant + b_m max(C_pose,C_func) + b_q C_query + c_admit A_raw + I_timer + I_padding.

If the wait is compiled as retiring poll instructions, their time is already in I_frame/mu_-; do not charge the same elapsed conversion again. If sensing waits while the processor is otherwise idle, add the uncovered serialized wait. Use the measured/derived maximum instruction duration, actual concurrent raw-resource capacities and the entire fixed source body to derive F. This construction provides the procedure and finite cost polynomial; it does not silently retain the old h16/F1 numbers. The public added fields save receiver-side per-connector scans, but the physical head, fold-time, calibration and energy obligations remain proportional to the real catalogue.

## 11. Pre-parser limbs, partial frames and held requests

A completed-record bound does not bound malformed input work. The256-bit transport is therefore accounted before parsing, in fixed-width physical symbols: each carries at most64 payload bits and a fixed bounded control/ordinal field (at most32 further routing/framing/control bits in this instance). A nominal record uses four symbols; start/end indications occupy those symbols. A reset, duplicate ordinal, malformed start, invalid continuation or non-data control offer is also a symbol and is charged even if no complete record ever appears. Variable-length headers or an unbounded interrupt on every analogue edge are not this interface.

For each physical origin-bank/receiver-bank branch, impose a raw symbol envelope N_sym(I)≤sigma_sym+rho_sym|I| before validation. One concrete raw-circuit point uses sigma_sym=4 and rho_sym=1040 symbols per quantum, covering a four-limb serializer with nominal record rate256 and maximum clock factor1.01. The sender's intended accepted-record envelope64+64|I| is a different, stronger traffic condition used for nominal no-drop delivery; malicious partial/control symbols are still charged at the larger physical symbol bound. A finite receiver lane FIFO with512 symbol slots and fixed minimum service2048 symbols/quanta prevents one bad lane from consuming another lane's service. Payload bits do not change that circuit's finite transition count. Initial FIFO data is included in drainage. Actual line/clock power is charged also when the bit pattern produces no accepted symbol/record.

The actual assembly machine stores one partial four-limb I buffer, an expected ordinal, a bounded partial-frame timer and the existing coherent current-record storage. A valid start at ordinal0 resets partial assembly unconditionally; ordered continuations copy one limb and advance the finite ordinal; the fourth correct limb commits the complete word. A malformed continuation resets/discards the partial frame. A partial timeout discards it. Neither a reset/drop nor a timeout refreshes the current observation's receipt timer or commits a partial payload. This machine uses fixed state and constant work per offered symbol. A programmable implementation belongs to the renewed endpoint C/W; the selected fixed raw circuit still has its data/clock/path fault footprint. Its staging bytes are I, not private verified evidence.

Let c_sym bound the actual admission/assembly work per raw symbol, c_commit the complete-word decode/commit work, and c_tick the partial/current timer work. With n_lane receiver lanes, the real bound is c_sym n_lane(sigma_sym+rho_sym F)+c_commit N_commit+I_timer, plus fixed line/circuit energy. It is not c_commit times the number of accepted payloads alone. At n_lane160,F1, the illustrative raw allowance is167040 symbols, including malformed offers. Initially staged data and queued complete words must be charged once at entry; an arbitrary-state circuit is not silently empty. Current-record double buffers and partial assembly retain their explicit storage cost.

A corresponding concrete delivery bound can be supplied entirely by raw queues/clocks: with source FIFO capacity Q_TX128 complete records, minimum serializer service r_TX256 records/quanta, propagation at most1/4 quantum, receiver FIFO Q_RX512 symbols and service r_RX2048 symbols/quanta,

    D_raw ≤ (Q_TX+1)/r_TX + 1/4 + (Q_RX+1)/r_RX = 2057/2048 < 2.

This bounds an admitted nominal frame through the physical pipeline, including complete assembly, when the fixed service is actually allocated. It is not an RPC truth/success oracle. Nominal no-drop admission additionally needs the sender's complete offered-traffic envelope and actual queue capacity; a full shared FIFO or a stalled programmable forwarder invalidates the bound. All outgoing traffic counts: the1524 figure in §10 is only sample-publication/reply offers. Consumer request updates, command records, ordinary writes and rejected transmitter attempts add their own source/branch load. If they share a conduit, its aggregate bandwidth and peak power must pay their sum. A source whose nominal load exceeds an acceptance shaper must add the actual shaping/queue delay rather than retain D=2.

An old record can commit after source cutoff only if an already launched old symbol still arrives; the last such reception is bounded by the actual raw pipeline tail. Partial timeout itself cannot generate another record. After that tail, the first fresh start resets stale partial assembly before the new complete frame is published. If new traffic can begin before old symbols drain, their possible interleaving stays in the affected origin until actual clearing; no generation label cures it. The old-current-record tail then retains the existing last-receipt plus corrupted-counter-cap bound. A raw queue design with corruptible non-draining pointers or a clock that can remain halted is not repaired by release; it needs actual reinitialization or remains affected.

The held-request interface has a separate law. Its1+u sampling/accepted-update bound is a physical bounded-rate sample-and-hold/ingress circuit, with arbitrary phase, not a bound on how often a Byzantine source changes or attempts to change its driver. A nominal stable held word propagates and is sampled within D_req only after the actual outgoing write/settling and sampler-period bounds have been added. Nominal request updates are sparse enough, or are actually queued/repeated, to meet that construction. Unacknowledged rejected writes cannot be presumed to have changed the remote word.

Every sender-side MMIO/driver/transmit attempt is paid, including a rejected attempt. If a processor can issue at most r_attempt attempts per quantum and each costs c_attempt/energy e_attempt, that demand is charged independently of accepted line symbols. Any autonomous driver also needs its actual physical toggle/strobe and peak-power bound; the circuit cannot inherit one from P(d)'s nominal frame pacing. Receiver sampling at a capped rate bounds its examination work, while the driver's transitions, line power and analogue-front-end/timer power remain in the physical source account even when no record commits. The executable exhibits thousands of partial starts with zero commits, charges every one, and keeps the old receipt timer aging; it separately distinguishes many sender attempts/toggles from few receiver samples. These are required resource distinctions, not extra successful-read services.

## 12. Finite storage allocation for the source bill

Count physical records and their real fields, not only accepted messages. One conservative record allocation is: two coherent256-bit data buffers (512 bits), one retained256-bit raw operand/snapshot latch when needed by the chosen comparison realization, two receipt counters of actual width w, one64-bit local routing/key descriptor, and16 selector/validity/commit/status bits. Its digital total is848+2w bits, at most976 for w≤64; a1024-bit allocation covers this layout, and the parent's2048-bit record_bits is conservative. Raw operand/staging copies remain I. The descriptor is not an authenticated origin or permission credential; physical ingress/slot binding determines the vote. There is no unbounded generation or timestamp field.

The counter's effective width is w=ceil(log2(E+1)), or a separately proved masking implementation with that exact state range. Padding a record or allocating a64-bit container does NOT change that semantic width silently. If all64 counter bits actually affect expiry, its arbitrary-state cap is2^64−1 and the earlier short initial/old-record clearance is invalid. The illustrated code/maintenance/plant classes need their own actual widths. Local oscillator/phase circuits, counter-update work, voltage/power sensing and their fault domains are physical costs beyond these stored bits. Any shared timing/remapping component keeps its actual multi-record reach; the storage count does not prove independence.

A source branch has finite retained transport state. At the raw point in §11, its source FIFO has128 slots of384 bits (256 payload,32 local route/control bits, validity/status and padding), or49152 bits. Its receiver FIFO has512 slots of128 bits (one64-bit payload limb,32 route/framing/control bits, validity/status and padding), or65536 bits. Add384 bits for the current serializer,512 for partial-frame assembly and its bounded timer, and128 for queue indices/counts/control. The bound is115712 digital bits per directed origin-bank/receiver-bank branch, before clock/driver/wiring energy. A received symbol is at most96 bits, so four payload limbs can cost384 physical wire bits including repeated fixed-width routing/framing fields. This corrects any use of256 payload bits alone as wire energy/bandwidth. Metadata does not create an origin; its physical branch identity remains external to that claimed label.

Per fixed held-request slot, a1024-bit receiving allocation covers two256-bit held-word buffers plus bounded key/status/control. The sender's corresponding held-word driver can be budgeted at512 bits. One shared source conversion/query/aggregate scratch allocation per execution bank can use4096 bits: the current/query raw I words, separate I6 aggregate, a coherent capture/send word, finite captured-head/key fields and validity/status are all included. Its exact implementation must remain separate from the completed record arrays and from PROGRAM's private W allocation. The record value latch, source scratch, request slot and partial framer are different retained objects; naming all of them a cache does not authorize counting one of them once.

For the actually consumed logical ABI, every one of13 origins has two source-bank records, including the two fields inside the same forgeable primary frame. Thus26 raw record locations per public fast key and26 per active code target give26(K_fast+d) locations per receiver execution bank, if the fixed incidence map drops unselected-source traffic without storing an extra copy. With K_fast27283,d40 this is710398 records. A deliberately denser implementation retaining every one of160 possible physical-bank streams for every key instead needs160K_fast+26d=4366320 records. Both banks of one host pay their own consumer allocation; a bank-level array shared among its candidate cartridge processors is counted once only if the physical access/gating/refinement really supplies that sharing.

PROGRAM's currently used private allocation is separate from I: the measured private footprint does not equal the8192-cell code image. The parent's32768-word-plus-metadata private bound and actual prefix work must be used. RUNTIME-PORTS owns that exact retained-operation/precharge inventory. The digital allocation above is a finite upper design basis, not a statement that bits alone pay peak power, heat, physical clocking or old authority.
