# Constructive recurrent closure from local operations

Status: P1 candidate theorem and written proof architecture; not yet an exported verified core or a completed baseline adapter. The finite constructors have independent bounded checks; [RankedJobs.lean](RankedJobs.lean) checks selected path/footprint arithmetic only. The full source-to-certificate and continuous/event assembly obligations below remain open until independently discharged. This file cannot by itself close RP1 or RP5.

## Source and certificate interface

Fix design d before the hidden scenario. It contains finite domains, execution roles, local observation interfaces, effect consumers, stores, primitive operation kinds and their typed causal incidence. A scenario is one actual initial state, causal acquisition/release/persistent history, faulty actions, nominal uncertainty, supply and retained effects. A finite local program is chosen uniformly from d. The theorem does not synthesize a controller for every hybrid plant and never supplies runtime participants with a proof's global fault cover.

The core retains the actual actor index separately from contributor/support groups. For the baseline it includes(host,bank,body) with80 bodies per bank; the candidate threshold source has(host,bank) with one body. A ready incarnation identifies one actual processor/body and its formed local state, not a bank-wide union of private observations. A host-level force or support bound is an aggregation certificate over actual channels; it supplies no new policy with pooled knowledge. Each family instantiates the same parametric core on its own actual actor set, with its own uniform local programme and explicit port/observation map. No direct policy transport between differently indexed actor sets is inferred from the old same-index Execution lemma. The common comparison retains protected quantities, service and response duties rather than a Boolean success label.

Real elapsed time and source causal micro-order remain in the interface. The untimed interpreter's retirement count supports instruction bounds; the rate, blocking and physical-effect maps supply actual duration. An infinite physical wait with no instruction retirements is not deleted by projecting to a finite instruction trace. Ghost incarnation/debt indices are proof data and do not create unbounded runtime names or memory.

The candidate restricted class consists of finite rule/phase protocols over timed sources whose local source operations, flow laws and event rules admit the checks below. The source may lose or stall; those branches are represented. A productive instance earns its certificate rather than belonging to a raw class defined as already winning. Reference mathematics/program meanings may be fixed; all consumed runtime copies, inference and renewal roles remain faultable under the source's incidence.

The adapter supplies local realization statements at explicit dependency supports. A statement names the actual source rules, read/write footprint, antecedent local relations and consequent relations. Unaffected relations have a frame proof. A bounded job additionally gives a finite local program, real worst-case duration/work, complete outcomes including unavailable/malformed input, and the actual effect postcondition. Its timing is from persistent eligibility/required input availability to actual invocation and application, uniformly over every permitted ready local scheduler state; it is not only a bound conditional on someone having called the routine. An attempted renewal is decomposed into phase/rank steps, not assumed to finish within H. A source-specific plant certificate supplies one-step or collar flow inequalities and quantitative service at that prefix; it is not an all-history mission theorem.

The separate required certificates are initial physical formation/commissioning; raw token incidence and whole-window projection; realized information/response jobs; primitive progress/custody and all-emitter reset; actual ready-interval overlap; disabled old-authority paths and pending tails; owned work/stock/conservation laws; local mode/event continuation; and one joint finite quantitative calculation. Grouping these fields is revisable, but their consumers cannot be dropped. A certificate that expands into ready-within-H, factive aggregate input, successful bounded access or the global target conclusion is inadmissible as a leaf.

## Raw covers and conditional usable helpers

For an analytic horizon H and time t, set a(t)=max(0,t-H). E_H(t) contains persistent tokens, direct tokens held across a(t), acquisitions from a(t) through t, and explicitly initialized debt still within its certified lifetime. Releases clear none of their effects. For I=[s,s+W], define F_H(I) by the same persistent/initial terms, direct occupancy at max(0,s-H), and acquisitions through s+W. RETURN's order argument gives union_(t in I) E_H(t) subset F_H(I). With a global raw envelope, its count is at most p+c+floor(sigma+lambda*(H+W))+D0. A spatial instance instead evaluates jointly consistent neighborhood constraints on the same token history; it cannot spend separate copies of a global budget.

Project tokens separately to execution, recipient/group observation slots, maintenance, resources and physical consumers. A token's several projections need not name the same role. Footprints contain admitted retained reach and common dependencies. `projected_support` and a finite compatible-profile calculation supply this bookkeeping; they do not infer recovery from age.

Suppose the assembled invariant is established strictly before T. Over a candidate bounded job interval [u,v] with v<T, a helper outside the execution projection of a retrospective F_H cover is unaffected during that interval and any earlier relevant debt has its return deadline in the established prefix. Hence its maintained execution relation holds throughout. Corresponding raw-slot and effect conclusions use their own projections. The finite local operation must work uniformly for every permitted hidden cover, rather than ask which helpers are honest. This implication is used only while proving the next prefix; it is not an all-time clean-helper premise. Bounded jobs are applied prospectively: their entire certified input interval ends before T, so the shorter-prefix relation holds there and forces actual completion. One cannot assume a job completed in order to obtain the premises that are meant to prove its completion.

A debt item is a retained state/authority dependency together with the consumers it can still affect, not merely an execution-host name. Each raw interference transition must have a local charge-transport certificate: it preserves the old deadline obligation, retires that debt, or moves every surviving consequential path into an antecedently declared footprint of the new still-charged event. If it delays an elimination rank, the corresponding continuing reach must be included, including other raw recipients and pending destinations. Equal host names do not prove this inclusion. The certificate is checked on the actual transition and finite reach relation; it is not the all-history support conclusion. Its witness retains an analytic owner, expiry (or currently held status), continuing effect footprint, actual phase/entry/elapsed state, and a locally derived remaining progress/tail budget R. Preserving an old owner requires the post-transition remaining-budget inequality t+R<old_expiry and continued effect containment; elapsed time within an edge is included in R rather than charging the entire entry budget again. A phase reset that loses this strict margin cannot be called deadline preserving. Equality is insufficient: at time7 a remaining bound3 with expiry10 permits completion only at10, outside the strict-prefix proof. An internal completion deadline may instead be retained strictly below the cover expiry. Transferring to a new counted owner additionally requires that the accumulated old/new source state lies in the new owner's declared interrupted-entry relation, not only that destination names agree. Held owners stay charged; their expiry is fixed from actual last release. These are ghost proof data, not runtime taint detection. Each R derives from primitive local progress and the ranked future path calculation, not a proof of the whole future return theorem. A fresh event whose execution projection covers A but whose effect projection omits B cannot justify keeping an old A-to-B command live after its original debt expires. The baseline's fixed-sink/no-spread and old-tail rules must be exhibited as an instance; this mapping remains open.

## Fibrewise debt and parallel closure

A common raw event can leave several independently realized debts. Preserve that distinction rather than assigning all residue to the next event at the same host. Let its finite debt family be D_e. For each i in D_e retain its actual state/authority path, destination footprint F_i, old deadline d_e and current local progress witness. The event's consequential reach is contained in the union of the F_i; the family is a proof decomposition, not new runtime state or additional raw tokens. At every actual transition, each member is preserved with its strict remaining-budget margin, actually retired, or transferred to a currently charged owner e' with F_i contained in that owner's antecedently declared projection. Every fibre transfer also inherits the preceding accumulated-state obligation: its actual retained state, including already elapsed phase work and old commitments, must satisfy the new owner's declared interrupted-entry relation. Footprint inclusion alone is insufficient. A transfer of one member gives no license to transfer the others. Taking unions proves the charge-transport law for the original event. Conversely, finding one surviving destination outside the proposed new owner's projection refutes that proposed transfer even if every host name is unchanged.

Parallel closure uses a maximum only when these local jobs really coexist in the same source history. If each member's actual local itinerary starts by s and has remaining duration B_i, and the shared schedules, ports, resource envelopes and overlapping actions satisfy the existing compatibility certificates, every untransferred member closes by s+max_i B_i. The proof applies each itinerary to that same interval and takes the finite maximum; it does not concatenate isolated favorable runs. Without the compatibility premise, a single exclusive server would instead admit a sum of durations and refute the maximum claim. A member's deadline is not extended when another member needs more work. The strict prefix condition is s+max_i B_i<d_e, or the corresponding separately retained deadlines when they differ. The B_i are supplied by local phase/rank and real retirement arguments, never by a terminal assumption that those debts eventually disappear.

The source-row input construction gives a concrete consumer for this distinction. Its candidate debt fibre is(region, source origin o, source bank, receiver r, receiver bank, installed key, retained operation). A whole-primary acquisition at r may affect backend rows from several origins because the primary origin depends on the consumed group. A paired acquisition has its two fixed origins. Neither is a single fictitious receiver-wide record. A shared capture has the distinct physical index(region,o,r,receiver bank,primary/auxiliary kind), not a separate cell for each source bank/key. Row-indexed obligations refer to that one object and its captured operation; they do not duplicate its work, stock or snapshot, and shared reset actions require their own compatibility law. Each raw arrival path, staged record, shared capture and pending operation retains its actual origin/destination binding; a payload header cannot choose a new physical origin. The source-bank cycle at o reforms its own outgoing rows, not all of r's inputs. A new source/root event at o may therefore contain the old o-row reach at every affected consumer; a lane event at(r,o) contains only that endpoint's o rows; a fixed pair contains only its installed two origins. Other old rows keep their old obligations. Private inference and the source's other physical exports require their own projections and are not silently included in this raw-row argument.

One specific self-dependency is absent in the threshold incidence construction: for helper r and target t, its maintenance providers satisfy G_r(t) subset N(r) intersection N(t), and neither neighborhood contains its own center. Hence r and t are both excluded from G_r(t). Repair observations for t therefore do not use t's own execution/publication as one of those fifteen producers. The literal maintenance_group constructor was checked on10080 complete/seam/interior group cases in addition to this set-theoretic argument. This does not remove the measured target's actual physical influence or a common failed sensing connection. Using the exclusion to break a source-level availability cycle still requires LEGACY-REALIZATION's actual observer-owned passive head/conversion funding and the source/receiver footprint map: a provider's sample of t must not secretly require t's CPU, outgoing queue or U. Other providers' formation and input support remain prefix obligations, not permanent-clean assumptions.

This is a derived debt bookkeeping rule and a conditional source-row application, not a completed input-retirement theorem. The actual field/reset/contact map must prove that all relevant rows, capture normalization and already emitted tails are included; complete source cycles must provide the local itineraries from the real interrupted state; source-affine funding must cover all concurrently installed rows; and the jointly admitted raw history must satisfy every consumed neighborhood envelope. In particular, the input construction's source-local TX/ADC field correspondence and temporal sibling-publication interval remain open. The mathematical projection here forgets bit values only for the containment/deadline query; truth, age, coherent reads, actual force, energy and useful service keep their separate source obligations. A new shared selector or alternate exit reopens the fibre/footprint map.

## Whole-job continuity and all emitters

Let successive actually formed intervals of a helper be [a_k,b_k], initialized with a_0=0, and let w bound a complete nontransferable job through actual application. Ordinary handover establishes a_(k+1)+w<=b_k. Raw disruption instead enters the cover. Given a job [u,v] in the established prefix with v-u<=w, choose the first available interval with b_k>=v. If k>0, b_(k-1)<v implies a_k<=b_(k-1)-w<v-w<=u. Therefore one actual bank contains the entire job. Existence of the interval reaching v comes from the current prefix's formation/coverage relation, not a future infinite sequence.

Interval containment alone does not schedule a job. For every covering ready bank, the same installed local policy must poll persistent eligibility, from every permitted local scheduler position, and reach the required actual application within w. Its bound includes residual current work, target selection, computation, transport/application and compatible duplicate invocations by the other bank. A round-robin discipline over d targets with bounded visits can construct the invocation term; unavailable/malformed targets cannot starve that rotation. This is the explicit CONTINUITY polling supplier. A request delivered only to an outgoing bank would be a counterexample: another bank might contain the whole interval while never receiving or starting the job. The core does not retrospectively assign work to its existential witness bank.

A proof need not keep one fixed bank throughout a complete renewal attempt. Physical candidate custody/progress may persist while different jobs use different formed banks. Conversely, a private stateful operation that cannot transfer between incarnations must be included in w at its full duration.

Job coverage alone does not remove other stale emitters. An all-emitter reset/custody certificate must show that every bank capable of contributing to the next transaction has cleared old state, lost/drained its old effect path, or remains physically unable to contribute until genuine formation. The baseline's phase-4 clearing stroke is one supplier. Selecting one good bank per job cannot excuse a second active stale bank.

## A derived phase and retirement horizon

A local phase supplier can derive an edge duration from finite instructions and bounded retries, or from physical progress: after settling delta, a monotone coordinate advances at least v>0 over remaining distance L, so delta+L/v bounds its duration. A computational rank of at most K decremented by each job of duration w has a corresponding finite bound. A partial contaminated phase can use finite progress bins plus an actual abort deadline, but not a watchdog that is refreshed forever without a decreasing rank. Every relevant failed/abort branch is retained.

Expand bounded counters into a finite strictly-ranked phase graph. For each phase q, the constructor computes T(q)=max_(q->q') (b(q,q')+T(q')), with zero at terminals, and similarly W(q) for work. Induction on rank gives the bound for every represented path. Source realization is a timed forward simulation with progress: from each admitted actual phase-entry relation, every admitted continuation satisfying the specified local input intervals either reaches a represented successor within its edge duration/work bound or incurs an explicitly charged interruption satisfying the debt-progress/transport rule. It retains intermediate waiting states and their elapsed budgets. Merely mapping completed edges would admit an infinite stall before the first completion and is insufficient. The terminal relation must be the one the core consumes. A terminal marked abort is insufficient if useful return needs later recovery: those later steps belong in the graph. Numerical acyclicity alone does not prove the source cannot remain stalled before an edge.

Let B be the largest T(q) over all permitted post-release partial states. `phase_family_budget` constructs this maximum through a fresh zero-cost demonic root pointing to every declared entry; that root is an analytic case split and grants no runtime information. That entry family must include the actual interrupted states, not only a fresh ideal start. Include actual retirement in those paths or add its tail once, never neither or twice. Choose H>t0+B, where t0 is commissioning. If phase costs depend on a support profile b(H), enumerate or solve the finite candidate profiles, derive B for each realized profile, then check the original raw envelope at H against that same profile. Mission, raw rates and capacities do not change to make the numerical test pass. A failed sufficient fixed-point certificate is not universal impossibility.

Relative retirement is constructed from actual launch/replenishment disabling or actual consumer rejection, together with a finite ranked graph of pending physical effects. Edges represent completion, dissipation, rejection or physical disconnection, with actual destination binding. Its bound accounts for all stored work and queues. A path ending at an already charged failed consumer may leave residue only if every later consequential exit remains within that consumer's antecedent projection; restoration of that consumer must dispose of its residue before it becomes uncharged. Ghost lineage identifiers are analytic data, not an infinite runtime namespace.

In an energy-cut instantiation, Z must include all retained power capable of rearming. A comparison Z'<=rho-kappa*Z with an appropriate trip margin gives a finite cutoff, followed by a real no-rearm law and paid effect tails. Convergence to zero alone gives no finite exact retirement. In a recipient-incarnation instantiation, actual rejection and already committed operations replace that local supplier; a new epoch label is not enough. These alternatives are open interface cases, not a theorem dispatching to separate whole-system proofs.

### Bounded jobs on one physical execution

[ContextualJobs.lean](ContextualJobs.lean) supplies a constructive composition rule for the step from bounded local jobs to a timed itinerary. Use it with a particular universally chosen maximal execution. Points are positions on that execution, including any proof cursor or pending authority needed to interpret the stage. The intended clock relation within(i,j,n) means j follows i in the actual causal/microstep order and t(j)−t(i)≤nδ. Choose a common unit δ clearing the denominators of the finite edge upper bounds. The times t(i) themselves may be arbitrary reals. Both required clock laws follow from reflexive order and elapsed-time addition on that execution. A first-defect argument can restrict points to the certified prefix only if all requested local edges have the required remaining strict margin. The caller must establish that entry, local service and physical continuability hold there.

The step certificate returns one of three things: evidence of closure at the current position, a named charged interruption at a later position inside budget, or a successor at an actual bounded time with smaller phase rank and the retained remaining budget. The successor certificate applies to the continuation actually taken. It needs to cover a blocked, delayed or partially executing source via its true response or an actual interference witness. A stuck intact source with no next edge cannot instantiate it. The theorem closeOnRun constructs the endpoint, budget, same-run clock evidence and either the closure or the charged-interruption certificate by recursion on rank. This strengthens the previously checked existence of a terminal *represented* path at precisely the source progress boundary. Neither a path in an analyst's graph nor a successful execution sampled elsewhere supplies the local step on this execution. Independent interface review checked that the point domain must consist of actual relevant entries, the clock/order must concern this same run, and the interruption result must carry real old-debt/owner data; an unconstrained unit-valued interruption would be vacuous. A source wrapper taking the whole goal as its single step would purchase no reduction.

The constructor bindOrCharge runs the second job only after receiving the first job's actual capability at its real endpoint. If the first job instead returned a charge, the same interruption is propagated with its own evidence. The type of a charge must include all continuing destinations, owner, deadline and accepted-entry evidence needed by the outer obligation. This rule does not automatically settle or extend the old debt. stagesOnRun composes any finite list indexed by its number of remaining stages; it constructs an arrival at stage zero under the sum of the per-stage budgets, or returns the earlier interruption. Stage entry data may retain the prior custodies and completed cuts. For example, instantiate the 26 rotated ordinary donor stages from [emitter turnover](ABORT-EMITTER-TURNOVER.md). The fixed remaining-stage cursor records which bank cuts have been witnessed, their surviving descendants and the relevant remaining phase time. An ordinary step consumes the old stage receipt and exhibits the actual next physical endpoint and retained cut evidence. The already checked cyclic sum is twice the healthy-half allocation. Completing that induction per rotated start is removed from the adapter. Actual progression, contact retention and the two issuers' loss of effective fields must be supplied by the local source map. The spatial calendar can consume a derived bound to the next actual phase2 on the same trace under the appropriate entry/cut hypotheses.

For parallel obligations, distinguish individual occurrences of closure by a deadline from simultaneously possessing all their results at one comparison point. joinPersistent takes two actual arrivals on the same ordered trace and transports the earlier result to the later position, using a source-specific persistence certificate on the interval. The resulting time bound is the maximum. The comparison of positions is causal order including same-time event order; equal real timestamps alone cannot order two observable updates. Repeated binary joins extend to a finite fibre family. Without persistence a row can reopen after its first clear and before another row clears. Both completed traces and both elapsed bounds are then true, while the desired pair of simultaneously closed powers is false. For a transferred fault debt, the object preserved may be old-lineage containment under a continuing named charge rather than a fresh-data predicate; each choice has a different continuation law. This lemma only combines arrivals that already coexist; matching one shared stock/field/order for their source histories remains an independent compatibility check.

The transmitter supplies a concrete decreasing measure, the sum of the remaining symbol counts of the old active claim and the old FIFO prefix. On a conforming service opportunity the active record emits its next symbol, emits its last symbol with a paid terminal strobe, or is rejected and its source capability is actually consumed. In each case oldTxDecrease decreases the measure by at least one. A newly appended record stays behind the old prefix. oldQueueDrain instantiates closeOnRun with those actual per-edge witnesses; it yields an emptied old prefix by the measured number of service intervals or the actual charged interruption. An attempted operation returning busy while keeping the same head is outside this decrease proof. The source must show an opportunity within each interval, valid physical cell/claim/selector bindings, and adequate reserved work even when the lead is full. Under those conditions 128 old queued records and one old active record give at most 516 symbol intervals. ## Resource and continuation composition

Establish nominal funding independently of repair success. Each real stock has one inventory and one supply/demand interpretation. Demand curves include arbitrary code, rejected traffic, duplicate overlap and pending reservations. Actual internal transfers have both endpoints and cancel in the combined energy balance. For an intact funding boundary with all-interval demand beta and supply alpha, let Delta bound sup_(L>=0)(beta(L)-alpha(L)). ## Candidate initialized assembly theorem

Assume the foregoing local rules, initialized relations and joint compatibility certificate at H. Assume source structural defects have a first finite event when any discrete formation/debt relation fails: event streams and debt deadlines are locally finite, same-time events have the specified causal order, and continuous protected boundaries use closed domains with suitable strict inward/comparison laws. These are source-class conditions requiring the above local continuation realization, not a convenient deletion of difficult runs.

Closed endpoint conventions in the raw covers need not produce a first point of an open uncharged-failure set. Introduce locally finite analytic deadline events at release+H and the initialized debt deadlines; at each such boundary establish that the relevant effect debt already closed strictly earlier, before discarding its charge on the following interval. These ghost events do not change runtime state or time. Continuous world/stock first exits remain their separate closed-boundary argument.

The candidate conclusion is that the fixed local program, on every admitted maximal run, has actual effective support within the E_H projections; every released reconstructible dependency without intervening relevant reacquisition returns usefully and loses uncharged old reach before its release+H; the actual safety, service and factual-response laws hold; resources remain viable; and time continues. Persistent/continuously occupied sites need not themselves return, and their hostile effects stay in the mission calculation.

Proof architecture: independent reservoir comparison supplies the funding needed to run bounded operations. The actual initial family and commissioning tube establish the first formed intervals and world bounds. Rule-local read/write certificates and their frame laws preserve every unaffected local relation; a finite conjunction assembles them on the same actual state. Raw events are charged immediately with all their projections. Continuous first exits are excluded by the finite inward/stock/thermal certificates while their shorter-prefix hypotheses hold. The same derivative bound used in an information-age certificate is justified on that protected prefix, with entry initialized separately.

At a first old-debt aging defect T, let r be the last relevant release and start at s=max(r,t0). Use one retrospective cover for the entire attempted closure; the joint calculation supplies its helper and observation margins. Every phase job required by the constructed bound completes by s+B<=r+t0+B<r+H<=T. Its premises therefore concern a strictly earlier prefix. The bounded local job/progress theorems apply to the actual causal choices and force every represented phase path to its required terminal, including all abort recovery branches. For an ordinary released debt with no relevant interruption this gives formed execution and relative retirement before T, a contradiction. If a later raw event interrupts that obligation, apply the local charge-transport rule: either the old bound still applies, it has already retired, or its entire remaining consequential reach belongs to a newer current charge. Local finiteness prevents infinitely many such transfers before T. The first uncharged defect must therefore have an outstanding deadline owner to which the argument applies; arbitrary token/host relabeling cannot establish that fact. It does not select a future successful attempt. Initialized debts are a separate branch. Each has an actual entry family and a declared deadline d_e; require t0+B_e<d_e with all relevant retirement included. `initial_debt_deadline` checks that strict inequality. Use the same prospective job argument starting at t0, without inventing a nonnegative release time for debt acquired before initialization. Such debt stays in D0 until its declared deadline or earlier actual closure. Without this premise, t0=1, B=2, H=4 and an initial deadline1/2 defeat the claimed sufficiency. The baseline has D0 empty, but the general interface retains the branch.

The interval lemma permits bank changes; the all-emitter certificate rules out remaining stale effects. Combining this support result with the same actual plant rows establishes recurrent mission preservation. The separate flow/event composition supplies continuing runs instead of inferring success from a nonempty set of good endpoints.

The simultaneous invariant must explicitly conjoin local execution/formation relations, recipient-specific information/response conditions, phase/debt progress witnesses, old-effect containment, and world/service/stock/thermal relations. Its defect classification covers each initialized, ordinary-rule, charged-interference, aging and continuous-boundary case at the actual causal micro-order; checking only the final state of a same-time batch could hide an intervening unauthorized action. This is stronger than `base + global invariant preservation => mission` only when the adapter fields are actually the proper-scope certificates just described. At present the dependency test and full baseline map still need to be completed; until then the statement is a candidate assembly, not a proved reusable result.
