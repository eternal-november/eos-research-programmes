# Admissibility of an initial partial abort return

An intact threshold-B fixture entering RETURN through its actual sampled FULL release can establish the keeper-specific cam entry from its recent physical history. That result has a different premise from being installed at time zero with a partly retracted abort carriage. For the latter case the outcome depends on the initial-state relation for a digitally acquired host with mechanically intact gates. The inherited documents distinguish the incident classes and explicitly prescribe the uncharged initial state. They leave two materially different readings of this particular charged initial fibre. The distinction affects the direct and reusable proof equally. ## What a compatible history can supply

The historical support theorem keeps the identity of an owner occurrence across different nodes of a diagram and derives insertion/restriction along edges that only discard owner support. For this problem a positive past cleanup sample, its actual target and keeper, later cam/keeper updates, donor command receipts and the particular issuer's EXITING birth have distinct owners. In the reached-return calculation the same physical sampled occurrence can be projected to its cam and blend legs. The kernel then consumes its age and the actual intervening motion. ## Three source decisions with different burdens

1. **Commission physical geometry, then overlay installed capabilities.** Select the ordinary physical entry at every mechanically intact target, including a host already digitally occupied. Overlay arbitrary values only on the actually writable digital/source/raw coordinates of each token. Independently choose the material alternatives of the persistent physical site, retain all true stock bounds, physical claim identities and old charged effects, and apply the declared D₀/initial-output rule. There is no sampled-good, verified-X or future-return premise. This gives a concrete domain with overlapping acquisitions, arbitrary retained digital corruption, genuine common input failure, physical jams and continuing independent exports. It excludes the displaced *initial* return on a digital-only site by definition. If the reference deliberately permitted a broader charged mechanical initialization, this is a restricted source. Both its direct and reusable proofs must be evaluated on this same new domain. It does not authorize reapplying commissioning after release.

2. **Admit interrupted physical entry through an independent prehistory relation.** Choose an earlier physical configuration, actual owners, bounded source inputs and admissible acquisition history. Use the raw physical and ordinary operation laws through time zero; retain all surviving poses, energy, paid children, sampled gate state and donor effects. The history class and allowable earlier actuator/word authority must be fixed independently of the sought successful controller. Where a reachable FULL release, recent successful sample, unchanged physical gates and subsequent signed keeper dynamics justify entry, import the reached result. An arbitrary open-loop prehistory can hold a return for long enough to switch the blend keeper if its proposed driving force is genuinely available. A time-zero bit or a finite speed bound does not exclude that history. A proof that uses an already successful mission to define “reachable” would move the global obligation into the source class. This option and commissioning need not be ordered by inclusion until their concrete earlier domains and constraints are specified.

3. **Keep the displaced initial pose and provide a physical acquisition path.** One candidate for B preserves the existing signed, keeper-indexed one-way rewind and enables it in off-entry RETURN as well as FULL when the independently sampled non-cam pre-park conditions hold. A mechanical seat interlock can retain the return until a *physical* keeper-slot engagement. In the demonstrated no-X, other-contacts-ready branch the actual compiled positive REWIND request can then move the cam toward the retained keeper. Positive MODE alone does not retract the one-way return during this acquisition. The path is at most one 832000-unit circumference at fixed keeper. A proved lower speed, effort under worst permitted opposition, finite work on the existing transmissions, holding reaction, common charge, thermal allocation, paid control/root counts and deadline must still be supplied. At a fixed shaft effort the mechanical work is the integral of signed effort against actual angular travel; a software counter or full-return latch supplies none of it. A jam or broken bearing has its actual physical-fault outcome. The future pose after a stall retains the original debt.

   The single additional clutch is only a candidate for the named branch. Mixed old X can produce negative MODE without enough REWIND. A non-cam cleanup conflict can leave the pre-park clutch closed. A displaced or changing keeper, insufficient work, stale contacts and initial near-seat motion all require explicit cases. A more independent powered re-parking drive would need its own bounded supply, rate, duty/holding work, safe reaction and forced-boundary law, together with actual transfer to the original controller after engagement. A rigid assembly that simply declares every initial RETURN already parked excludes the adversarial observable geometry; it does not preserve a domain admitting that geometry. In any changed mechanism, recompute the outage/thermal and return inequalities, the fault projection and the behavior of all reachable formerly healthy prefixes before claiming a matched source comparison.

A further limitation of a cam-only change concerns the rest of the cleanup train. If the non-cam actuation routes follow the inherited full-endpoint gate in CYCLE, an interior RETURN with blend off anchor or ISO unseated can hold that earlier stage indefinitely. Every non-X helper then requests BLEND or ISO, with no rewind request yet to route. A change covering that fibre would need a usable cleanup train through RETURN as well as the seating interlock.
