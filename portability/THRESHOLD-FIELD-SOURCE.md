## State, physical identity and failure scope

A host has two actual processors, one physical body per bank. Its resident mutable C is represented by8192 words of192 retained bit coordinates x in[-1,1], decoded by sign (the fixed tie convention reads x=0 as1). Runtime LOADC observes those actual cells. Ordinary self-write remains available while its actual resident launch path is powered; threshold reconstruction is licensed only after that path and every old funded write have been excluded. There is no candidate-copy, full-image equality or protected reference-image service in this source.

For each source-bank/physical-target-bank/bit channel retain the held ternary setting, sampler phase and finite counter, three ready/active/withdrawing/refilling capsules, their actual work stocks, a fixed destination, and one aggregate force-output state. The three capsules feed one motor through the finite selector; they are not three independently additive motors. The finite-word control state has zero recoverable work under the inherited finite-word convention. Its actual switching and holding costs are counted below. Finer recoverable-memory physics is not included and would add its actual work state and return paths.

Each capsule follows the finite lifecycle in PULSE-FIELDS. Ready plus pending work is one physical stock. An occupied or underfunded slot rejects; it does not queue a request until a later recharge. The source-bank cut disables new setting-writer capture and every sampler/trigger/rearm route. Already latched setter and trigger descendants keep their actual physical destinations and funded suffixes. U can refill an idle capsule after cutoff, but cannot thereby trigger it. An initial pool is usable only after its actual entry relation or after inhibited parent-tail plus full drain/refill with continuously funded chargers; an engagement based only on a software elapsed-time label is not sufficient. At equality of a bound and a completion event, establish the actual ready state before enabling, or wait strictly past the bound.

The per-channel motor has hard effort bound F=1.01u, u=1/(1000L), L=8192*192. Wrong, absent and jammed outputs are allowed. A failed clock, selector or actuator earns no nominal expiry or sign guarantee, but remains inside the declared hard force, energy and incidence class. A physical bypass of that amplitude limiter or a new rigid/energy path is outside this particular local certificate and needs its actual larger effect/retained-reach bound. This is an intrinsic capacity restriction of the selected mathematical primitive, analogous to a rated launch ceiling; it is not a claim that an arbitrarily destroyed limiter still works.

At a conforming endpoint the least-numbered active capsule selects the ternary command. Expiry recomputes that selector; it never issues an unconditional zero that can erase a newer capsule. The last expiring capsule finances withdrawal; a newly selected capsule finances the same aggregate motor. The output state moves toward the requested sign with the finite slew from PULSE-FIELDS and does not restart an equal-sign transient. Actual effort is additionally multiplied by g(S)=min(1,max(0,S)) for the selected usable motor stock S; all positive-work/control requests similarly scale down at empty stock. Thus an empty device cannot deliver work. Above the operation floor1 the nominal behavior is unchanged. Failed-mode holds are not credited with useful sign or finite expiry.

## A bounded source-held-setting writer

Install one separate2^20-work native setter per source bank. It captures the four actual256-bit IO operands into fixed latches, then runs six serial unsigned comparisons: target<40, bank<2, bit<L and ternary value equal to0,1 or all-one(-1). Its28 mux hops lead to a fixed body/bank/bit endpoint. Two staging bits and one selector commit the held ternary value without exposing a torn ternary code to the sampler. The executable advances one capture/comparator/mux/latch/scrub operation per microstep. Valid requests take3647 steps; invalid payloads finish the same bounded capture/compare/scrub path without a held write.
