## Identity, custody and writable state

A physical lane is e=(o,b_o,r,b_r): source host, source bank, receiving host, receiving bank. The source's actual neighbor list fixes r; neither o nor either bank identity is a payload credential. A maintenance source key3+50*a_o(t)+z maps to receiver key3+50*a_r(t)+z for the same actual target t. Keys0/1 use the installed X/X+Y groups, while each producer still measures its one installed rank-one quantity. Key2 and uninstalled routes drop. The existing arrival decoder and source-owner radix injection retain those identities. There are160 lanes per source owner and at most320480 source-owned record units. Receiver averaging is not used.

Each record has a committed256-bit value, a separate staged256-bit value and64 explicitly resettable control bits, within its old2048-bit owner allocation. A plant countdown uses four of its physical bits and admits15; a maintenance countdown uses ten and admits1023. Clock enable, masking, busy/phase and pending-update validity remain raw state. An input-only acquisition can stop the normal clock or leave a stale busy/masked state after release. Receiving a new payload does not repair those fields. Raw payload, staging, counter and decoder control belong to I; the receiver's private C/R/W, descriptor, predicate and return destination remain separate.

The raw lane includes its source-affine FIFO/parser and arrival-controller state. This deliberately broadens the earlier auxiliary-only compartment map: a lane intrusion can affect that one source at this receiver even in a group where it supplies the primary. The installed shared pair joins two fixed such sources, never an attacker-selected new pair. This is an explicit stronger local reach map, not a claim that FIXED-ISLANDS's old primary exclusion was already this architecture. The same cardinality proof survives: every non-pair cause contributes at most one origin per group; all local pair occurrences have the same at-most-two-origin footprint. With k causes and l>=1 local-pair occurrences, support is at most k-l+2; six causes still give at most seven slots. Primary-frame intrusion separately reaches every slot0 record, while inference can remain intact.

For actual consumer group G_r(k), the primary-frame reach is exactly the payload/control cells of records with origin o=G_r(k)[0], together with that origin's primary-kind shared capture. It does not include the lane FIFO/parser, auxiliary-kind capture or records where that origin occupies another slot. Those broader fields are reachable by their lane/root/pair causes. The primary frame is the union of these backend-affine raw cells. There is no additional writable all-origin raw selector, oscillator or persistent override latch behind that frame. Its private selection remains receiver-funded. A primary input intrusion may write that whole union directly, but normal messages and the new reset paths cannot. A realization adding a common latch needs its actual restoration and footprint; the union representation cannot hide it.

Raw queues, receipt/update engines and capture apparatus are funded by the real U_o outside ordinary bank cuts. Private comparisons use the receiving bank's instruction parent. This distinction persists when a raw clock fails: the private deadline still computes on the actual input or unavailable word. An input failure does not become corrupted inference merely to make a support count work.

## Coherent receipt, counter and parser operations

The normal record machine has one pending native counter/update operation and a staged receipt. A tick captures its decrement operand. A later receipt waits for that old tick to retire, then atomically commits its new payload and nominal countdown. A clock request waiting behind a receipt samples the counter only after that receipt commits. Pending operands are not overwritten by a newer arrival. Old committed data remain readable while a receipt is staged. Tick, staging and busy bits are raw and may be corrupted; the source-row reset clears their actual authority before reuse.

The discarded implementation is concrete: if a delayed tick blindly writes its old decrement after each fresh receipt, genuine2q receipts with lifetime8 give countdowns7,6,5,4,3,2,1,0,... . Fresh payload arrival therefore does not itself establish availability. The executable retains this countercase and checks the serialized transition instead.

Four ordered96-bit symbols carry a256-bit payload with a bounded source key, fragment index and kind. A new start replaces the incomplete prefix; malformed order/type/reserved bits invalidate that prefix without refreshing a record. A complete frame consumes its local claim before dispatch. The fixed decoder then selects an existing source-affine record or drops the frame. There is no payload-origin field. A data frame with a reset-like kind is not a control command.

The implementation keeps the continuously readable committed record during staging. A per-record native update has delay at most64/2^20. The declared narrow oscillator interval[5001/5000,5049/5000], with at most two such native delays, gives completed tick spacing inside[100/101,1]. Four-symbol RX serialization leaves more time than the old tick plus new receipt operation. The nominal receipt lifetimes8/512, arbitrary caps15/1023 and existing refresh inequalities therefore remain available after actual entry. Those are clock/transaction implications, not restored-state declarations.

A source-local DATA slot also consumes its completion capability before invoking an external action. The preserved old Slot callback-order API admits two Python effects from one paid launch under reentry; that is a checker/API counterexample, not a demonstrated admitted physical attack on the old source. The new ordering requires the actual captured completion claim, consumes it before external code and rejects both immediate reentry and an old callback after slot reuse. A new digital busy flag cannot replace that physical one-shot capability. Unfunded, masked, malformed, full, stopped-clock and stale-busy branches retain their actual outcomes. Neither a reset nor a digital flag produces another work parcel.

## Initial state, source ancestry and overlap

An initial active row needs an actual running/coherent native control entry, just as the initial cam row and operating code do. This construction permits arbitrary initial raw values, countdowns and bounded queued symbols, while distinguishing them from a stopped control engine. The one-time operating control entry or a separately executed initial normalization must be bound in THRESHOLD-INITIALIZATION; it is not reapplied after release. A raw record can contain arbitrary bits without being an arbitrarily damaged oscillator. Later recurring acquisitions here explicitly may corrupt normal clock enables and native controls.

A lane debt at(r,o) is removed by o's actual bank-row cycles, not by assuming r's mechanics recover. A paired debt needs the corresponding cycles for both fixed sources. A primary-frame debt can require the rows of all its actual backend sources. Uniform local source-cycle bounds may compose by a maximum, but that same-history proof is not performed here. A failed reset root at o remains an origin-o footprint at every consumer. A permanently failed receiving branch retains its own singleton/pair footprint. If a source root is permanently failed, any proposed transfer of an older raw debt into that already charged footprint needs the common core's actual containment proof; it is not renamed successful restoration.

The earlier band's minimum-dwell proof uses the distinct upper speed11/10; an upper speed alone would not establish this latest bound.

During an ordinary clean cold-row reset, the sibling source bank retains its own rows and publication. The reset operations commute with that sibling's counter/receipt transitions.
