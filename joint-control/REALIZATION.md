## Actual finite image and local computation

The selected processor has a finite source instruction set with explicitly bounded integer/byte operations. Its nominal instruction sequence is ADMIT, QUERY, MEDIAN, COMMAND, CLOCK, STOP. The opcode implementations, including the loops, are in the hashed Python reference. Instructions are not an oracle that returns a successful estimate or a safe action: ADMIT calls the existing fixed-packet parser, MEDIAN calls the existing insertion-sort coordinate median, and COMMAND multiplies those actually stored results by8/5, rounds to a milliunit and clips to the physical output alphabet. UNKNOWN instructions are inert. At most sixteen instructions execute per tick; a conservative instruction budget stops corrupted repeated expensive instructions before10000 counted word operations. This supplies a total timeout/hold outcome instead of deleting a malformed run. The processor starts each invocation at its documented entry point; its current instruction pointer is recorded in the control block.

Each writable block is exactly1024 bytes, so every nominal write transfers8192 bits in one tick at the admitted local write bandwidth. There are eight blocks,65536 bits in total. Unused padding is also overwritten; it is not a hidden store for behavior outside the specified machine.

Local outgoing lists in the host implementation decode the addressed queue bytes, rather than bypassing them. The host's arbitrary-precision integers, dictionaries and absolute event times are convenient simulator representations of the bounded source fields and bounded queues below. The claim is a finite mathematical source processor and its declared timing/energy relation, not compiled firmware correctness or a measured processor performance claim. No theorem here certifies a Python runtime's real wall-clock deadlines.

## Finite communication, inquiry and freshness

A request is16 bits: six row bits, one epoch bit and nine zero reserved bits. Forty-two requests use672 egress bits, within the1024-bit requester cap. Physical requester origin is a labelled endpoint; a reporting credential alone cannot impersonate it. Each provider has thirteen four-bit-range cooldown counters and thirteen epoch bits. Admitting a correctly formed request starts a nine-tick cooldown. Its live epoch relevance expires with the countdown, so reusing the one-bit epoch after drainage cannot cause permanent duplicate rejection. Malformed origin, row, reserved bits or live duplicate have explicit rejection outcomes and processing costs.

The concrete nominal pipeline is exact: request delivery at invocation+1, raw acquisition at+2, and replies in three row lanes at+3,+4,+5. Lane floor(row/14) has fourteen reserved destination slots. This exact pipeline is a subcase of I's broader interval assumptions; arbitrary transport jitter is not claimed by the concrete check. Each provider can batch one fresh raw sample across its pending requesters, while transmitting each actual64-bit reply. A row's worst coincident fan-out is13×64=832 bits; a recipient lane is14×64=896 bits. Neither all42 replies nor all42 requests are incorrectly treated as64-bit words fitting one1024-bit tick.

The channel source provides per-row reserved destination slots. An exposed report path may replace or omit its own word, but cannot consume another row's reserved slot. A common demultiplexer/parser/request path that destroys the whole bundle is a target dependency impairment charged to A_dep/P, not one corrupted row. This is a load-bearing local source-interface assumption: a shared unreserved FIFO admitting arbitrary hostile flood would require another traffic construction or a larger dependency loss. The reference inputs use those reservations; the sixteen-word processor mailbox is a physical bound, not a proof that arbitrary shared-FIFO flooding preserves honest delivery. A hostile outsider who merely saves an old word cannot write every nominal physical row port. Saved/forged words on exposed rows remain allowed forever and count in q. No public-network replay-security theorem follows from the one-bit epoch.

The raw samples are quantized milliunit values with deterministic bounded noise. At actual acquisition time their total error is at most0.0015, below the0.002 information allowance. Faulty exposed rows produce recipient-dependent extreme values, malformed words and old epoch forgeries. Each actor admits the first valid bounded word for a row in its local window, uses zero for missing entries, publishes two actual21-element medians at+8 and holds them until its next publication. Ordinary queries are ten ticks apart. Commissioning, like reconstruction, first executes twelve drain ticks, so nominal initial responses, outstanding source jobs and cooldown records need not be empty. The executable starts with old accepted source jobs, live cooldowns, duplicate old requests and stale local receipts/cache. The actual drain clears publication validity and local queues; intact initial actual effects remain the supplied baselineu0 until fresh feedback arrives by tick24. Initial nonbaseline effect/command state is charged to P/P0, not smuggled into an intact startup path. Faulty metadata is never used as a trustworthy sample timestamp. Distinct actual local estimates are observed in each positive trace. The record additionally names two currently unimpaired recipients whose actual delayed effects and the estimates that produced them differ at the same physical tick, while both satisfy the checked effect-time bound.

World queues retain at most one tick of requests, one tick of admitted sample jobs, three ticks of nominal replies and four ticks of command effects. Per-row cooldowns bound live source jobs per requester; finite per-origin buffers and the physical caps bound all stored records. A convenient explicit capacity is546 request records,546 sample jobs,546 pending reply records and52 world command records. Each request/reply record contains a four-bit requester, six-bit row, one-bit epoch where applicable,64-bit packet and a bounded remaining-delay field. Absolute times used by the simulator are eliminable by ticking those finite remaining delays. They are not part of any local decision history available without a channel.

The statement about pending reply capacity depends on the provider cooldown; it is not a general bound for arbitrary unmetered network hardware. Queues outside these source retention/port limits remain persistent impairments or activate a changed interface proof.

The proof order is the initialized prefix induction in COMPOSITION: already safe prefix ⇒ nominal raw relation and drift ⇒ implemented local information/effect relation and reconstructed support ⇒ next physical/stock/service step.
