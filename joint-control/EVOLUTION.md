# Evolving access, retained contamination and effective support

Status: derived discrete semantics, source-preserving reductions and written proofs; selected algebraic and operational statements are checked in [Evolution.lean](Evolution.lean) and [Restoration.lean](Restoration.lean). [evolution_model.py](evolution_model.py) supplies separate finite operational checks. The joint controller and its information precision are supplied by the I/C workstreams, not assumed proved here. The parent [SOURCE](SOURCE.md), [ASSUMPTIONS](ASSUMPTIONS.md) and full contract remain controlling. No repository acceptance or full-program completion is asserted.

## Carrier and chronological choices

Fix legitimate design data d, possible ownership/incidence maps Γ, and local installed programs π(d). For each admitted true γ, a domain has its actual read, write, credential, effect and maintenance reach. Report names are not independent fault domains. The source state contains the physical state, stocks and service history; each processor's code, control flow and mutable data; recognition/configuration; launched effect and transport queues; current access edges A; retained contamination C; and accumulated attacker knowledge L. Program memories are not reconstructed by folding observation histories after an adversary or installer has written them.

The exact source primitive is an operational interpreter of the actual stored program and data. When direct adversarial access controls an interpreter/actuator it may choose any admitted action. When that access ends, the current stored program runs, including previously installed hostile code. A nominal processor interpreter does not mean the stored program is π(d). The nominal instruction semantics, permitted effects and finite cell descriptions are supplied computational relations. Correctness of the selected image is an I/C/R proof obligation.

Each elapsed base tick has the following causal ordering: due primitive operations complete according to their bounded completion relations; observations and admitted transport receipts become available; invoked local programs compute and issue bounded actions; the adversary may choose admitted current effects, acquisitions and interference using available past/current information; physical evolution and queues advance. A source may expose finer subphases, but each operation consumes its declared real ticks. Completions on the same cell have a declared order or, when simultaneous and unordered, all admitted final-writer outcomes. There is no priority rule making an honest write automatically win. The conservative checks choose adversarial writes after honest completions. Changing this ordering in an instance requires the corresponding refinement; independent simultaneous physical effects are retained jointly.

An acquisition event names its trigger, current source access, affected domain/edge and newly available powers. A report/parser or update event can introduce the same access transition as an external intrusion. Both increment the same acquisition accounting. Reacquiring a released target is another event even if its identity appeared before. A writer already holding access can write repeatedly without another acquisition. Those writes remain enabled and can contaminate state repeatedly; they cannot be ruled out by pretending they consume a fresh event. The per-target tool restriction bounds the footprint of this repeated interference instead.

Release removes the stated current access edges only. It does not change memory, knowledge, recognition or launched effects. A genuine hardware/firmware change outside the writable repair cells stays a fault. Local overwrite may eliminate a stored command but cannot erase a command already in the world queue. Learning is monotone: old secrets remain in L even when no local device stores them. Reporting-only stolen credentials remain able to create arbitrary fresh report content; credentials with write, boot or effect reach remain in the actual access relation. Their authority is not silently demoted to mere evidence corruption.

## Dynamic command envelope and the retained static core

For analysis let N(f,z,i) mean that i's actual current code/configuration and local instruction execution have the prescribed semantics in state z of scenario f. N is not an observable cure flag. The local observation v_i(z) contains only the source-permitted local memory and inputs. The command envelope requires a_i=π_i(d)(v_i(z)) when N holds and admits all source-bounded commands otherwise. The effect relation continues to use the entire actual action tuple, including non-nominal agents. Disabling a command consumer by administrative policy does not disable its physical effect.

[DynamicModel and DStep](Evolution.lean) implement this envelope with a state-dependent nominal predicate. `dynamic_locality` checks equal actual local views yield equal prescribed commands across different scenario indices whenever both occurrences are nominal. `source_step_refines` is the explicit one-way transport: the actual source interpreter establishes the prescribed-command equation at nominal states, and the actual effect belongs to the envelope relation. A stronger envelope supplies sufficient protection when its control theorem holds. Arbitrary choices permitted at non-nominal states are an overapproximation; envelope losing runs are not automatically source impossibilities.

This source interpretation does not assume nominal status from a cure label. The addressed reconstruction theorem establishes actual image equality; the local interpreter then evaluates those installed bytes on its legitimate runtime inputs. The I/C proofs must establish the semantics of that image. Stored intermediate data may thereafter change under nominal computation without becoming corrupt. The taint bookkeeping is therefore a conservative provenance predicate, not a test that all runtime cells always equal a static boot image.

The old Execution.Model is recovered exactly by setting N(f,z,i)=Model.correct(f,i), disabling state corruption, acquired access and reconstruction, and retaining the old observations, initial relation and successor relation. `static_step_exact` and `static_run_exact` prove definitional equality of steps and runs against the unchanged research/Execution.lean. The observation map is unchanged, so every trace property and every local-view equality transports on the identical carrier. This is an actual specialization of the old module, not a claim that its fixed-compliance local-memory fold proves the new mutable-memory semantics. Old protected suppliers retain their original assumptions.

## Fault domains and propagation reduction

Write Rγ(d,t) for the target/evidence/address reach of a currently held source capability. Keep the actual capability relation A_cap separate from its analysis projections. A_direct projects actual write/control/effect authority. The necessary-dependency projection A_dep additionally marks a target whose common requester endpoint, query clock/scheduler, shared query/receipt path or other explicitly listed I/R/realization dependency may be impaired by a held capability. These are capability footprints from the declared interface/ownership map, not observed bad values and not a primitive assertion that useful information exists. A nominal-looking adversary still contributes the entire footprint of its held powers. Independent per-row failures remain in I's cumulative bad-row support; losing a common requester can invalidate the whole responder bundle and is not counted as one faulty row.

For the effective-support theorem below set A_t=A_dep(t). The arbitrary-output C envelope on an impaired path is conservative: an intact executing program that times out or holds old output may belong to A_dep even though no attacker directly chooses its command. DynamicModel's nominal predicate describes prescribed execution; it is not identical to being outside the C impairment set. `enlarge_impaired` checks that enlarging the impairment set preserves a physical effect envelope, and `dependency_projection_monotone` checks capability inclusion. Neither lemma reflects arbitrary envelope outputs back to actual source powers. Negative influence results still require independently exhibited source actions.

Each released dependency has a restoration closure. In the selected subfamily, persistent code/configuration/clock/phase/cooldown/queue/admission state that can disable the common requester is in the enumerated R cells; already launched queries/receipts are covered by I's twelve-tick drain and new-round timing. A directly interfered link whose fault is solely active alteration/delay follows its stated nominal bounded-delivery relation after release, with its old queues retained through that drain. Remote common state, endpoint hardware or surviving access not covered by this local closure stays in P, or requires its own proved bounded-return law. Writing the target does not cure an unaddressed remote dependency. Outside A_dep and P, availability follows the actual nominal endpoint/path and row-processing laws, then I proves useful precision; code equality alone is never its proof. The persistent footprint P includes every target accessible through a tool whose image, clock, port, code or control has ever been compromised, plus irreparable hardware targets and retained write/effect capabilities not removed by transient-access release. The selected numeric subfamily bounds their joint union |P| by r; r_tool separately bounds the tool portion and gives every tool only its specified target reach. A single tool can repeatedly poison that target without additional acquisitions; the target remains in P. A common fault compromising several tool copies contributes their entire combined footprint.

A source-triggered infection is reduced by preserving its trigger and time, adjoining the obtained access edges, modifying the actually reached cells, appending any newly learned secret to L and enqueuing any admitted pending effect. Its direct and necessary-dependency footprints are recomputed from that same capability state, without upgrading a loss of observations into an actual new actuator authority. Later transitions consult those edges. `propagation_is_acquisition`, `reacquisition_counts` and `release_does_not_revoke` check the corresponding elementary event bookkeeping. The full reduction is a simulation by induction on the source events: each original event is copied to the same state components, followed by the identical ordinary interpreter/effect transition. It introduces no early infection, no erased copied credential and no omitted later power. If one incident obtains several target capabilities, count its actual footprint additions, not one incident label, when deriving the numerical target envelope. Γ uncertainty is retained; all claimed cardinality inequalities hold uniformly over Γ or are explicitly known-map subcases.

This gives M42 a transition/composition reduction into the positive E/R/C mechanism: a triggered target acquisition is handled by the same contamination, queue and reconstruction rules as a direct acquisition, while a triggered tool acquisition permanently enlarges P. The preservation result below applies to their joint trace when the resulting target-event and tool-footprint projections satisfy the declared bounds. If propagation exceeds them, the result does not apply. A parser exploit cannot be dismissed as an arbitrary report value while its changed recipient powers are omitted. This is a model-level transition result, not a claim of exploit resistance for a named platform.

## Operational effective-support theorem

Take the periodic reconstruction from [RESTORATION](RESTORATION.md). Let D include halt, all writes, boot, postboot inquiry/inference and the old/new physical effect horizon. Let P_period be the per-target schedule period and H=P_period+D. Its opportunity premise is the source availability of the nominal scheduled operations whenever the tool is intact and no separate external access interferes. The nominal halt itself suppresses resident processor writes. It is not assumed that released code stops being hostile. More general bounded missed opportunities replace P_period with the proved maximum wait until an available complete scheduled attempt.

Let M_t be the set of targets in their scheduled extended interval [start,start+D), whether healthy or damaged. For the staggered schedule D≤S, at most one target is in M_t. Let I0 contain the initially non-nominal target processors and the initial direct target-access footprint; it does not include P, which is charged separately. The source initial envelope bounds |I0| by f0. For the concrete branch I0 is contained in a supplied initial exposure footprint P0 of size at most one, which also includes retained reporting credentials and all initial active access; no additional initial current-access identity is silently exempted. Initially intact baseline commands and queues remain the C startup case, not a claim that fresh feedback exists at time zero.

Define W_H(t)=⋃{A_s : 0≤s≤t and t≤s+H}. Then at every tick, every target outside

    E_t = P ∪ W_H(t) ∪ M_t ∪ (I0 if t<H else ∅)

has nominal physical influence for its current prescribed phase, with the I module's actual current evidence error and timing assumptions. Consequently every detailed source trace is contained in the control model treating E_t as arbitrary physically bounded influence. Evidence support is separate and may remain cumulatively larger. This statement does not grant actors E_t; they follow the same local program without fault/cure diagnosis.

Proof for t≥H: set a=t−H. For a target outside P and W_H(t), no capability impairing a required target dependency is held throughout any tick of [a,t], and its tool has remained nominal. Its next scheduled attempt starts at some s with a≤s<a+P_period. Nominal halt suppresses resident writers; actual write coverage and boot establish the image, fresh inquiry/inference follows, and new effects replace every older queued effect by s+D<t. If further scheduled attempts occur before t, the same argument applies to each. The most recent such attempt either has completed its extended interval or places the target in M_t; the latter case is excluded. Between attempts, no outside writer or direct effect access exists, the declared restored dependency closure remains nominal, and the actual installed interpreter follows its prescribed local mechanism. I then supplies availability and precision from actual rows/receipts at those occurrences. Thus nominal influence holds at t. No corrupt old program is assumed compliant before the first halt/write sequence.

For t<H, a target outside P, I0, W_H(t) and M_t starts nominal and has no external access on its entire prefix. Nominal computation preserves its prescribed semantics; every finished nominal maintenance reestablishes it by the same reconstruction proof. During the initial information-acquisition phase its actual baseline/queued output is the stipulated source startup behavior, which C must protect separately. This proves the early case. Retained leaked reporting credentials do not contradict the claim because I already treats their source domains as arbitrary forever; leaked write/effect reach would instead keep the target in A or P.

The theorem's proof is a written operational induction using the separately kernel-checked addressed sequence, timing arithmetic and schedule nonoverlap. It is not yet a fully mechanized composition of the source interpreter, estimator and coupled dynamics. Those I/C bindings and independent semantic checking remain integration duties; the theorem does not assume a winning invariant or useful decoded information as a source primitive.

## Derived numerical envelope

For L consecutive elapsed ticks, κ(L) bounds newly introduced target dependency footprints derived from the actual source domain/access events and their fixed reach; reacquisitions count again. In this positive per-target source one target-domain acquisition has at most its one target footprint. If one source domain reaches several necessary dependencies, use its resulting target footprint weight. An internal rebind or topology change that expands reach without a new acquisition must also appear in the projection/accounting; the present fixed-incidence branch has no uncharged expansion. A bound on incident names or on already-successful inference is not substituted for this derived event projection. Assume |A_t|≤f_target. For t≥H, every target in W_H(t) either belongs to A_(t−H) or is introduced in one of the H later ticks. Therefore |W_H(t)|≤f_target+κ(H). For t<H, I0 together with W_H(t) has size at most f0+κ(t), when events at tick zero are already included in I0. This is a union bound; projections are from the same scenario, not independent random variables.

Thus |E_t|≤r+f_target+κ(H)+1 after startup, and |E_t|≤r+f0+κ(t)+1 before H. Intersections can make the bound smaller; C may consume the exact phase-dependent union instead. If c_target counts the entire number of acquisition events including reacquisition, it additionally gives κ(L)≤c_target. Finitely many distinct targets alone supplies no event-rate bound. Existing attackers may continue arbitrary tactics forever inside their held support. No unannounced last acquisition is needed by the controller or the proof.

A joint candidate uses n=13, m=8 bounded write blocks, T_I=20, L_Q=4, giving D=34, S=35, P_period=455, H=489. With r=r_tool=f_target=f0=1 and at most one new target event in every 489 consecutive ticks, the physical envelope is at most four. Spacing events by 490 ticks is a sufficient nonempty source schedule and permits eight lifetime acquisitions. The proof covers all admitted placements/tactics satisfying the envelope, not only that schedule. Initial exposed identities must be counted separately in I's cumulative reporting bound unless already included in the lifetime accounting; eight later target events plus one initial exposed target and one tool can require ten bad reporting domains. The physical four-loss bound does not establish a nine-source evidence bound.

## Countermodels and support

Release-with-poisoned-memory, release-with-leaked-key and release-with-pending-effect are all admitted by the state transitions. A per-instant count of active targets can be zero while all three residuals remain. Sequential acquisitions can accumulate enough valid reporting credentials to defeat a fixed quorum even though current access is bounded. The repair construction does not claim to revoke those credentials; it requires the larger cumulative evidence budget. A stolen credential with installation reach defeats the reporting-only interpretation and enlarges effective physical reach.

One faulty installer with unrestricted reach can poison all targets without new acquisitions; this falsifies a bound based only on one installer identity. The selected port restriction prevents exactly that source behavior, and increasing its actual reach changes P. Synchronized repair of every healthy device can remove the whole plant's nominal capacity even with zero Byzantine devices; M_t is therefore mandatory. A propagation event that only increments a diagnostic flag while leaving the recipient's future allowed behavior unchanged is not this source reduction.

The executable exhausts a declared finite two-acquisition trace family, not all infinite traces or real attacks. Its image enumeration independently checks every Boolean image/initial store through four cells and every write permutation. It exercises a thirteen-target numerical schedule with eight separated acquisitions, persistent tool interference and retained knowledge, and records actual reconstructed return times. The written induction supplies the unbounded trace consequence under its hypotheses; executable survival supplies an interpretation check, not a universal proof. Reproduce the record with `python -B evolution_model.py --check` from this folder, using the pinned installed Lean 4.33.0 executable or `--lean PATH`. The JSON records exact source hashes and formal declaration/axiom summaries.

Prior-art relationship: the distinction between active and released-but-corrupt processes and conservative mixed-mode accounting follows the mobile-fault literature assessed in [SOURCES](SOURCES.md). This work does not claim that distinction is new. The contribution here is the explicit mutable-store/physical-queue adapter, actual addressed restoration and its shared timing/capability envelope for this Byzantine-control source. Published pristine-reboot, tamper-proof-code or permanently authenticated-channel assumptions are not silently imported.
