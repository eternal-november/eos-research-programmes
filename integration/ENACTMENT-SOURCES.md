# Enactment: closest results and remaining construction

Status: targeted primary-source assessment checked 2026-10-22 before this construction. The marks below certify inspected definitions, statements and selected proof passages; they do not certify full proof reconstruction or automatic application. The chosen work adapts established composition and resilience ideas. No novelty or exhaustive-frontier claim is made.

| Primary result | Checked scope and construction consequence |
|---|---|
| [Kuznetsov and Tonkikh, Asynchronous Reconfiguration with Byzantine Failures, arXiv v3](https://arxiv.org/pdf/2005.13499) | cited[✓], Sections 3.3-3.6 and 6, Theorems 5.3-5.4 and A.17. Verifiable configurations, confirming phases and forward-secure fencing solve digital problems under active quorum and finite-valid-reconfiguration assumptions. This enactment protocol uses only a fixed scoped approval edge. It neither imports the complete asynchronous algorithm nor substitutes its record guarantee for physical installation. |
| [Li and Lesani, Reconfigurable Heterogeneous Quorum Systems, DISC 2024 v2](https://arxiv.org/html/2304.02156) | cited[✓], Section 5, Theorems 21-22 and proofs. Unrestricted terminating membership/quorum changes cannot simultaneously preserve all stated trust-policy and availability/consistency properties. This supports keeping completion conditional and permitting safe holding. It is not an impossibility result for the guarded substitution protocol here. |
| [Kim et al., Dynamic Contracts for Distributed Temporal Logic Control of Traffic Networks, CDC 2017](https://sadraddini.com/wp-content/uploads/2018/04/cdc17contracts.pdf) | cited[✓], Definition 4, equation (16), Proposition 2 and viable-kernel construction. Terminal guarantees must meet successor entry assumptions, with consistency maintained across handovers. Their central supervisor is not imported. Here one fixed family of local policies and a universal supplier-effect relation construct the handover. |
| [Castro and Liskov, Proactive Recovery in a Byzantine-Fault-Tolerant System, OSDI 2000](https://www.usenix.org/events/osdi2000/castro/castro.pdf) | cited[✓], system assumptions and recovery mechanism. Protected recovery code, key operations, surviving metadata and a vulnerability-window fault bound support the long-lived recovery guarantee. This construction substitutes capacity while retaining a static fault scenario; it does not claim that its READY artifact cleans a compromised process. |
| [Bellare and Miner, A Forward-Secure Digital Signature Scheme, CRYPTO 1999 full version](https://cseweb.ucsd.edu/~mihir/papers/fsig.pdf) | cited[✓], Section 1.2, Definition 2.1 and security experiment. Past-period authentication after later exposure is distinct from healing current leaked keys. The present model admits independent static key compromise and counts signing paths separately from executors; it claims neither key healing nor forward-security protection without an additional implementation. |
| [Garg, Sanfelice and Cardenas, Control Barrier Function based Attack-Recovery with Provable Guarantees, arXiv v2](https://arxiv.org/pdf/2204.03077) | cited[✓], input partition, Assumption 4 and Theorem 1. The inspected recovery result relies on designated secure inputs and a robust control margin. The present alternative permits each inventoried peer effect path to fail in some scenario and derives surviving influence from a joint budget; it does not transfer the continuous barrier theorem. |
| [Haeberlen, Kouznetsov and Druschel, PeerReview, MPI-SWS-2007-003](https://www.mpi-sws.org/tr/2007-003.pdf) | cited[✓], Sections 3.2-3.4 and Appendix A. Protocol evidence, suspicion and exposure have different meanings; physical input truth requires another observation argument. The public certificate here proves scoped issuance and supports a fault-indexed effect argument, not universal installation truth or blame. |

The existing [peer-brake construction](../enforcement/THEORY.md) supplies the closest local effect substrate. Its noisy three-brake parameters cannot simply absorb a fourth braking path and a higher hostile torque. The new integer regime is derived separately: exact intact threshold sources, torque bound seven, normal torque five, four possible engagements, threshold two, one-interval delay, speed bound ten and heat bound eight. The larger replacement-pair family exposes the surviving-effect, maximal-load and service inequalities. This is a changed context with an explicit adapter, not a claim that the old proof already covered substitution.

The remaining target identified before construction was: replace an assumed clean installer/perfect isolation step with local evidence-authorized enactment that covers partial installation and supplier faults, retains pending commands, and preserves actual service on the same runs. A pairwise overlap mechanism was chosen because a readiness artifact can have a useful fault-indexed meaning without claiming it is invariably true. The general slot law then makes the construction compositional across disjoint replacements and common fault budgets. The accepted-artifact/actual-issuance distinction is retained when a signing key is compromised independently of its compliant executor. A protected serial registry would not discharge that target.

Search coverage included Byzantine reconfiguration, heterogeneous quorum changes, proactive recovery, forward-secure authentication, dynamic assume-guarantee switching, attacked-system recovery and accountability. Proactive-sharing sources were identified but not theorem-imported: the older source was image-only, an APSS PDF timed out, and an ePrint PDF returned 403. A recent faultable-network-scheduling lead returned 429. Mobile recovery, arbitrary dynamically chosen configuration proposals, and calibrated physical installation need renewed searches if selected. Bibliographic or search-snippet evidence is not a checked theorem.

The source boundary is fixed-rule specification enforcement. Institutional legitimacy, changing the governing rules, and jurisdictional recognition are separate questions. No result in this source set grants authority merely because an intervention preserves safety.
